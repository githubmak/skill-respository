# Production Quality Knowledge Base

本文件沉淀 `ai-video-agent-mode` 在知识储备、人物/空间一致性与画面质感上的制作级规则。它只提供可迁移的生成判断和拍法语法，不替代 `format_constraints.md`，不改变当前 T2V-only 管线。

正常运行不要全量加载本文件。先使用 `contracts/source_basemap_contract.md`、
`contracts/visual_quality_contract.md` 或 `contracts/aesthetic_directing_contract.md`；只有命中索引未覆盖的
具体制作问题或修改知识规则时，才读取对应标题区域。

## 1. 场景预设不是模板

- 任何场景类型只作为候选池：先按 `场景类型 + 剧情功能 + 情绪温度 + 源文动作/道具 + 已有 Scene Lock` 生成本项目专属空间锁、人物槽位、入口出口、道具活动区和影调色卡。
- 禁止一看到警局、医院、客厅、商业街、走廊、车内、柜台就套用固定左右站位、固定灯光或固定色卡。
- 同一地点跨镜必须复用同一个 `space_id`、同一句 `space_master_sentence`、同一入口出口和道具活动区；若新源文改变人物、道具、门窗或身体状态，必须用源文动作或上一落幅解释。

## 2. 制作级影调色卡

每个场景的色卡必须先成为制作事实，再压缩进单镜。完整色卡至少覆盖：

`场景ID | 剧情情绪功能 | 影调关键词 | 主色60%-70% | 辅助色20%-30% | 点缀色5%-10% | 色温范围 | 主光方向 | 阴影颜色 | 对比度 | 饱和度 | 肤色保护 | 材质反光 | 本场质感锚点 | 允许变化 | 禁止偏色/污染项`

单镜只消费压缩 `visual_scene_prefix` 和一个可见光影落点，不逐镜复制整张色卡。压缩前缀建议 35–80 字，包含画幅、风格、固定空间锚点、主色/色温/光线方向、肤色或黑位控制。

色卡作用域必须分离。人物脸部建立独立中性或暖白主光、低强度中性补光与曝光基准；环境主色只进入背景、衣物边缘和有动机的轮廓反光。墙面旧痕、水渍、灰尘、雾粒、雨雾和粗糙材质属于环境深度，不得迁移到皮肤。丁达尔/体积光束优先位于人物肩后、中景或后景，尘粒只在光束体积内可见；若光束越过脸部，必须有源文依据和独立面部补光，不形成斑驳脏块。

人物表演镜使用 `skin_tone_protection_contract`：`subjects/protection_mode/source_allowed_skin_marks/skin_tone_baseline/face_light_and_exposure/face_fill_shadow_policy/environment_color_boundary/texture_atmosphere_boundary/continuity_lock/fallback`。默认 `natural_protected`；叙事有动机的霓虹或火光染色用 `motivated_color_cast`，但保留一块中性面光、补光、眼神光或自然肤色参照区；伤痕、泪痕、妆容和剧情污迹用 `source_authorized_marks`；源文明确剪影才用 `silhouette`。若发生污染，先降低环境色饱和度、将空气介质退到中后景并加强中性补光，不用长串负面词替代空间边界。

色卡必须转译为可见画面事实：光从哪里来、落在哪个脸/手/道具/墙面/地面上，暗部如何保留黑位，反光是哑光、半反光还是压暗镜面。禁止用“电影感、高级感、质感好”替代可执行事实。

## 2.5 场景生活化与景深层次

每个场景在 Scene Lock 阶段先建立六项扁平事实，不能等到单镜临时装饰：

`foreground_layer | midground_layer | background_layer | genre_visual_signature | lived_in_detail | depth_focus_policy`

- `foreground_layer`：靠近镜头的门框、桌角、窗帘边、玻璃边缘、肩线、植物叶片或局部道具，只承担框景、引导线或轻遮挡；不凭空加入会改变剧情的物品。
- `midground_layer`：人物主要活动区、脚底/座椅/桌沿等真实接触面、关键道具活动区和本场最重要的材质，是动作与对白的主舞台。
- `background_layer`：走廊深处、窗外街景、远端门口、墙面结构、低幅路人或灯光层，只负责纵深和环境呼吸，不出现抢焦清晰人脸、乱字或第二剧情事件。
- `genre_visual_signature`：把题材气味翻成可见事实。都市情感可用克制室内陈设、真实生活杂物和窗外城市散光；悬疑可用遮挡、深处出口、局部低照度和被使用过的证物环境；古装可用时代结构、器物尺度、衣料与自然光；轻喜剧可用更松弛的空间距离、明净但不塑料的生活色彩。只能选与源文题材相符的证据。
- `lived_in_detail`：每场只锁1–2项生活使用痕迹或自然不完美，例如桌沿细划痕、杯垫水印、窗玻璃薄灰、布料自然褶皱、墙角轻磨损、远处低幅活动。不要把“生活化”写成杂物堆积。
- `depth_focus_policy`：明确本场默认实焦层、焦外层、前景遮挡强度、空气透视和背景清晰度。人物脸、口型、活动手与关键道具优先清楚；背景靠距离、景深、低对比和低幅活动退后，不靠异常压黑。

“舒服”不是直接提示词，而是结果：前中后景关系清楚、主体有呼吸空间、光色协调、真实材质不过度光滑、背景有生活但不抢戏。单镜从六项事实中只取与剧情有关的至少两层景物，再加题材气味或生活痕迹中的一项和一项虚实主次；不得逐镜复制全部场景描述。

## 3. 人物一致性与可见人数闸门

- 组级人物表不等于本镜可见人物。每个主镜必须先判断本镜画面内可见人数；肩线、背影、倒影、虚化人影都算可见，纯画外声不算。
- 可见人物必须进入 `performance_priority` 的 primary/supporting/background 分区；画外、OS、OV、非实体声音不得进入可见表演分区。
- 直接提示词开头遇到多人、画外声或同场景人物多于本镜实际入画时，必须写成当前可见事实，例如“本镜画面内可见人数：2人；角色A清晰，角色B只以前景肩线弱虚化入画；角色C画外发声不入画”。
- 不入画人物不能作为视觉目标。禁止写 `A看向/面向/对着B` 诱发生成 B；改写为 `A视线落向画面右侧门口方向/画外右侧声源/窗边固定锚点`，并在约束中声明 B 不入画。
- 人物参考或身份锚点只负责稳定脸、服装、体态和关系；不得用“双人锁脸、强制锁脸”等元词污染单镜正文。

## 3.5 情绪微表演链

情绪不是标签，必须落成当前景别可见的微动作。人物镜、对白镜、情绪转折镜和高叙事权重镜优先使用：

`情绪触发 → 呼吸/停顿 → 眉眼/眼神 → 嘴角/下颌/喉间 → 手指/袖口/道具 → 肩颈/重心 → 视线落点 → 情绪残留`

- 单镜只选择 3–5 个微动作，不把完整情绪词库全塞进去；动作强或多人镜只保留最能读懂剧情的 1–2 个表演证据。
- 微表演必须改写成当前角色、台词、景别、服装和道具：古装可用袖口、发簪、剑柄、衣摆；现代可用手机、杯沿、文件夹、门把；不得照搬示例人物关系。
- 假装生气：眉心轻皱、眼神顿住、嘴角压下轻抿、指尖捏袖口/衣角、视线故意移开、眉尾微挑。用于“嘴硬、试探、撒娇式不满”，不要写成真正爆怒。
- 高傲打量：呼吸平稳、肩颈不动、表情克制、下颌略稳、眼神从上到下短扫、视线停留后淡淡移开。用于权力差、轻蔑、审视；避免只写“高级、傲气、看不上”。
- 开心惊喜：嘴唇微张、眼底慢慢发亮、手快速但轻柔捂嘴、指尖停在唇前、眼角微弯、身体先定住半拍。用于不敢相信的好消息；不要让角色大幅跳动抢镜。
- 惊讶恐惧：呼吸变浅、嘴唇微张、喉间无声发紧、肩颈僵住、手指攥紧衣袖/道具、身体下意识后退半步。用于威胁逼近；退半步必须有空间可退。
- 耍小性子：鼻尖轻吸气、双手缓缓抬起、宽袖/衣摆自然下垂、双臂轻抱、肩膀微收、下巴微抬、斜瞟后躲开。用于亲密关系里的轻微别扭，不用于严肃生死冲突。
- 失望无奈：垂眸半秒、缓慢抬眼、眼神从受伤转为疏冷、很轻地说出台词、说完移开视线。用于“放弃解释/关系降温”；台词必须来自源文或 dialogue_events。
- 伤心怨恨：单侧泪痕滑落、下巴轻颤、呼吸短促、抬眼湿冷发亮、指尖点住掌心压住冲动、笑意慢慢收回。用于爱恨混合；避免夸张哭喊。
- 悲伤痛苦：下颌发紧轻颤、肩颈收住、闭眼低头、抬臂遮眼、借手臂克制擦泪、身体随呼吸细微发颤。用于强忍崩溃；镜头宜固定或低幅推近。
- 所有 OS/OV/画外声情绪都必须绑定可见闭口反应：嘴唇闭合、呼吸变化、眼神/手指/肩颈承接，不生成额外口型。
- 复杂或克制情绪先拆成“内在情绪 → 对外展示 → 面具泄露”：内在层写角色真正怕什么/想护住什么，对外层写角色希望对手看到的控制姿态，泄露层只选一个最小可见破口。前两层是导演推导元数据，正文只写泄露动作及其身体、声音和落幅承接。
- 用 0–5 记录本镜起止强度并计算变化量，只用于检查连续镜是否停滞或无故跳变。不得把“强度3、emotion_delta+2、内心悲伤”等分析语言投喂模型。

## 3.6 角色表演基线

角色表演基线用于防止同一人物跨镜表演风格漂移。它是生成前内部锁，不替代源文，不新增人物性格；必须由源文人设、关系和已发生剧情支撑。

内部先为主要人物压缩：

`人物 | 常态控制方式 | 优先情绪泄露部位 | 默认动作幅度 | 明确爆发阈值 | 禁用/禁止表演习惯`

- 常态控制方式决定普通对白如何反应，例如克制慢半拍、外松内紧、直球外放、敏感退缩或权力压迫。
- 优先泄露部位只选 1–2 类，例如眼睑/眉尾、嘴角/下颌、呼吸/喉间、手指/袖口、当前道具边缘；后续镜头优先沿用这些部位，避免每镜换一套表情手感。
- 默认动作幅度必须稳定为低幅、中幅或外放。低幅角色不随意捂嘴、急退、甩手；外放角色也不能无触发地突然阴冷静止。
- 爆发阈值必须来自源文重大触发，例如羞辱、背叛、失去、保护对象受伤、真相揭开或关系决裂；没有阈值触发时，优先写反应变慢、动作变小、视线改变或道具压力。
- 禁用表演习惯用于压住角色漂移，例如克制角色不连续捂嘴，权力型角色不急促乱动，隐忍角色不无触发泪崩。
- 一个角色最多混合两个基线。源文明确开心、害怕、愤怒或崩溃时，基线只控制表现方式，不反改剧情情绪。

## 4. 空间与物理结构

高风险镜头必须达到线稿级清楚：

`固定锚点 → 物理槽位 → 画面区域 → 前中后景层级 → 身体朝向/视线 → 距离/隔物/接触物 → 活动道具持有人/状态`

- 先写物理拓扑，再写屏幕左右。`画面左/右` 是屏幕坐标，`A的右侧/桌对面/柜台内侧/床左沿` 是人物关系坐标，二者不能混用。
- 柜台、窗口、签字台、车门、餐桌、床、沙发、吊椅、走廊等空间必须写清内侧/外侧、同侧/对侧、支撑点、隔物和可触达范围。
- 概括动作必须翻译成物理链：`起点 → 支撑/接触/方向 → 可见转换 → 稳定终态 → 下一镜继承`。触发词包括躺、伏、靠、抱、扶、摔倒、翻身、坐起、起身、披衣、开门、下车、递给、收起、离开、手机响、屏幕显示、人群围观等。
- 道具转移必须写起点、哪只手、移动路径、接触点、松手/新持有人和尾帧归属。若接收者不可触达，先定位或拆镜，不让道具闪现。

## 5. 镜头组件库

每个子镜最多选择一个组件，并改写成当前人物、空间、道具和台词：

- 听者被击中：肩后近景或 85mm 近景；说话者做前景肩线约 1/5，听者闭口，眼睑/下颌/手指或道具力度停半拍。
- 关系拉开：35mm/50mm 中景；二人之间保留桌面、门框、空位、车门或走廊留白。
- 手部情绪泄露：手/道具近景；只承担压住、攥紧、松开或停在物边，不凭空出现道具。
- 正反打保轴：成对肩后镜复写同一隔物、距离、轴线、前景肩线和背景锚点。
- 手机消息浮层：精确文字默认放画面侧边独立二维绿色气泡/字幕浮层，安全区内，不属于手机、不贴手机、不随手机透视。
- 口型交接：上一说话者闭口 0.2–0.4 秒，听者低幅反应，再让下一人开口；长台词镜头少运镜。
- 结果物件/空镜缓冲：台词峰值后切门缝、停住的手机/卡/杯、空椅或隔物，只定格关系结果，不新增剧情。
- 行走转对白：脚步停稳 → 肩线转正 → 头部跟随 → 视线落点 → 开口；不能背向又面对说话。

## 6. 运镜安全边界

- 人物强动作、道具交换、长台词口型、多人可见关系或支撑姿态变化时，优先固定或低幅推近。
- 安全时保持适度电影感，但只能由可见触发驱动：推近用于压力升高，拉远用于孤立/关系失败，转焦用于脸与道具或说话者与听者之间的一次注意力转移，侧跟用于移动路线。
- 运镜必须写起幅、触发点、路径、距离/角度、焦点对象、停点和保持不变的空间锚点。禁止只写“推近、拉远、环绕、连续运镜”。
- 一镜不要同时承担两项以上高风险任务：运镜、道具转移、说话者切换、转焦、人物穿越、受力接触。超过则拆镜。

## 6.5 特殊视角与运动语法

特殊视角只在它能让观众更快读懂尺度、路线、主观限制、动作受力、人物顺序或地理关系时使用。它不是“ACT/FPV/POV”标签，也不替代空间、人物、道具和落幅合同。每镜先压缩成：

`视角任务 → 摄影机绑定对象 → 相对高度/距离 → 唯一主路径 → 速度曲线 → 至多一次焦点交接 → 稳定落幅`

| 视角 | 适用任务 | 必写的可见规则 | 稳定边界 |
|---|---|---|---|
| 穿越尺度 | 从宏观环境锁定到具体主体，或从远景进入追逐 | 中心锚点、可读层级、同向路径、加速/减速节点、最终跟拍机位 | 每镜只保留一个尺度转换主链；抵近主体前必须减速并落在稳定机位 |
| ACT 第三人称 | 武打、追逐、强动作的受力与攻防阅读 | 摄影机位于主角后方或侧后方、固定相对距离、主角/对手/攻击线同时可读、一次明确打击结果 | 一镜只保留一个动作结果；强受力、交接或多人混战时降运镜或拆镜 |
| FPV 贴身 | 小型高速主体穿越障碍、危险路线、微观动感 | 镜头绑定主体近侧、保留可辨识主体部位、明确障碍路径、抖动来源和恢复节点 | 微抖只能来自推进器/振翅/气流等可见原因；连续急转超过一次或穿越多道障碍时拆段 |
| POV 第一人称 | 恐惧、探索、主观受限信息 | 镜头绑定眼位或胸前，画面边缘保留手电/手/武器等身份锚点，只呈现角色能看见的范围 | 不得无故脱离第一人称、全知揭示或凭空出现第三人称构图；惊吓后要给稳定观察落点 |
| 水平横移 | 多人关系、权力顺序、空间逐一揭示 | 明确从左到右或右到左、人物/物件出现顺序、焦点交接触发、最终停点 | 一次横移只做单向扫场和一次焦点交接；不让被揭示者互换站位或同时抢焦 |
| 鸟瞰实拍 | 城市建立、地理关系、队形/路线规模 | 真实航拍高度、主地标、推进/盘旋中的唯一路线、前中远景层级、落向的叙事区域 | 鸟瞰成片不等于俯视调度图；禁止地图标记、轨迹箭头、文字标签或不可能的全城细节跳变 |

- 将抽象或不稳定的技术词翻成画面事实：`120fps` 默认改为一个碰撞/火花/电弧细节的短暂慢动作；气味、温度和噪声改为烟尘、热扭曲、焦痕、振动、呼吸或物体反应。
- 景深只写当前实焦主体与前后景自然虚化，不并列矛盾的光圈/景深描述。
- 特殊视角与镜头组件不可叠成两套主任务：每子镜只保留一个视角关系、一个主要运镜和一个决定性动作/状态变化。

## 7. 声音锁定与口型

- 生成前应建立项目级角色声音锁定表：每个有台词/OS/OV的人物锁定音色、音调、语速、音量、吐字质感、呼吸感、尾音习惯、情绪上限和禁用声音变化。
- 单镜 `dialogue_events.delivery` 只写本镜因情绪导致的语速、音量、气口、停顿、咬字或尾音微调；不要每镜重造人物声音。
- 可见台词驱动口型；OS/OV/系统音/内心声/非实体声音不生成口型，必须绑定可见人物闭口反应、身体动作、道具反应或空间关系变化。

## 8. 画面质感分层

每镜选择 1–2 个质感锚点：

- 皮肤：自然血色、柔和高光、眼下浅阴影；动态漫/韩漫不写过度真人毛孔。
- 布料：棉麻哑光褶皱、针织柔软形变、西装肩线/袖口折痕、丝绸低强度反光、牛仔粗颗粒。
- 环境：墙面旧痕、地板低亮划痕、玻璃灰尘和压暗反光、金属冷光边缘、纸张纸纹、手机/银行卡边缘硬反光。
- 反光分层：皮肤/墙面哑光，皮革/桌面半反光，玻璃/金属/手机屏幕压暗反光，不让所有物体统一白亮。
- 写实/电影目标必须主动规避镜面水面、塑料墙、均匀雨线、过曝灯管、过度霓虹、廉价 CG 和虚拟摄影棚感。

## 9. 关键帧和空间辅助图触发

普通镜不强制导出关键帧或空间图。以下触发时优先生成当前镜头剧情关键帧或空间调度辅助图：人体支撑、道具/衣物转移、UI文字、门/车/电梯穿越、连续正反打、三人以上多人戏、强运镜、闪回/梦境。

关键帧必须重复人物位置、身体朝向、支撑点、道具归属、画幅风格和场景锚点；若与 T2V `full_prompt` 不一致，以 `full_prompt` 为准并重写辅助提示。

## 10. 前台导演精修层

前台导演精修层用于把已经合规的 `full_prompt` 压成更像即梦导演卡的 `画面描述｜直接复制`。它只重排与润色可见事实，不新增剧情、人物、道具、台词、参考素材或镜头任务。默认顺序：

`画幅/风格 → 场景色卡/影调 → 主体位置与可见人数 → 表演/台词/听者反应 → 运镜路径或稳定状态 → 光影材质 → 落幅`

- 开头 35–100 字必须像成片画面，不像 QA 条款：画幅、风格、空间锚点、色卡/主光一次说清。
- 中段写本镜真正的戏：谁说话、谁闭口受击、哪一个道具或空间压力物让画面有戏。
- 人物/对白镜先选一个构图戏眼：明确实焦主体在画面何处、前中后景如何分层、谁形成遮挡或留白、人物距离/道具如何制造压力；再选择一个由该戏眼或表演重音触发的固定/推近/拉远/横移/拉焦策略。没有因果就固定机位，不为“高级感”叠加第二种运镜。
- 结尾只写当前可见终态，例如“落幅手仍停在杯沿”，不写“尾帧继承/下一镜承接”。
- 高风险镜的必要约束与负面词仍放在独立字段，不塞回正向正文。

## 11. 对白表演核

对白镜默认采用 `dialogue_performance_kernel`，让台词不再只是“人物说话”：

`台词功能 → 潜台词/轮次关系 → 原文重音词 → 说话者口型与说法 → 潜台词可见证据 → 听者低幅反应 → 句末闭口 → 余波落幅`

- 台词功能先判断是试探、压迫、否认、求证、打断、告别、隐瞒、揭示、求和、转移还是回答；再判断本句是发起、回应、闪避、打断、退出、桥接或延续。功能和轮次关系必须来自源文上下文，不得为追求戏剧性改写人物意图。
- 潜台词写“角色此句实际想逼对方承认/保护/回避/试探什么”，不能复述原文；它只用于选择动作与说法，不直接进入正文。
- 每句只选 1–3 个逐字来自原台词的词组作重音。用音量、气息、咬字、短停、尾音和一个可见动作说明其说法，不改字、不改标点、不把每个词都做成重音。
- 说话者口型只服务可见台词；OS/OV/画外声必须闭口。
- 关键词重音不改写原文，只用“说到某个词时呼吸短停/下颌压住/手指停住”等可见动作承载。
- 听者反应优先低幅：眼神停半拍、下颌轻收、手指压住杯沿、视线错开、肩颈收住。
- 句末闭口和余波落幅用于避免口型乱动，并给关系留下可继承的当前事实。
- 潜台词必须有一个可见证据：说话者手眼/呼吸/道具控制，或听者延迟、视线错位、距离变化。多人镜只选最可读的一项，避免“重音 + 三个表情 + 三个听者动作”堆积。
- 源文明确支持时允许真实会话异常：抢话、被打断、话到一半停住、自我修正、重复词、吞音、答非所问或极短声音重叠。只调整时间窗、气口、声音交接和闭口边界，不改字、不增词，也不把普通顺序对白强行演成争抢。

## 12. 情绪残留契约

`emotion_residue_contract` 用于跨镜保持人物情绪手感：

`触发前状态 → 泄露部位 → 压抑/释放方式 → 尾帧残留`

- 触发前状态写常态或上一可见状态，例如“克制冷感/强忍/外放但收住”。
- 泄露部位沿用角色表演基线，优先 1–2 个部位，不每镜换表演系统。
- 压抑/释放方式必须可见：停顿、闭口、收手、移开视线、松开道具、重心回落。
- 尾帧残留只供元数据和下一镜起幅消费；direct-copy 改写成“落幅当前可见状态”。

## 13. 可控创作档位

`creative_profile` 只调节创作自由度，不降低质量门槛：

- `safe`：复杂动作、多人物、道具转移、长台词或高风险镜默认档；优先固定/低幅运镜、清楚站位、一个光影锚点。
- `balanced`：默认档；在稳定前提下增加前台导演精修、对白表演核、一个镜头组件或 1–2 个质感锚点。
- `expressive`：低风险环境镜、动作展示、风格化视角或用户明确要求“更高级/更燃/更有镜头感”时使用；允许更强构图、特殊视角或速度曲线，但仍只能有一个主路径、一次焦点交接和稳定落幅。

任何档位都不允许绕过源文保真、T2V-only、动作预算、direct-copy 密度、validator、golden、provenance 或规则一致性。

## 14. 角色戏剧行动与关系弧

微表演只回答“情绪如何被看见”，戏剧行动还要回答“角色正在对谁做什么”。人物镜先压缩：

`场景目标 → 代价 → 障碍 → 当前策略 → 可见策略证据 → 策略切换/维持原因 → 信息差 → 权力前后状态 → 行动落幅`

- 场景目标必须是可成败的具体结果，例如逼对方承认、阻止离开、争取信任、隐藏证据或确认关系；不要写“表达悲伤”。
- 策略是关系动作，例如试探、拖延、施压、讨好、回避、转移、交换、威胁或退出；同一角色连续受阻时必须变化策略或说明为何执意维持。
- 信息差记录谁知道、谁误判、谁隐瞒；只供导演判断，不把“知识差/策略”标签投喂模型。
- 对手戏额外建立关系弧：关系起点、双方冲突欲望、情绪错位、转折触发、权力变化、关系终态和共同余波。不同人物的情绪可以错峰，不能机械同步升降。

## 15. 风景美学与环境叙事

场景层次解决“画面不空”，风景导演解决“为什么这一刻值得看”。每个场景建立：

`风景身份 → 构图系统 → 自然运动系统 → 环境故事弧 → 揭示顺序 → 光候演进 → 镜头呼吸`

- 风景身份统一地域、季节、时段、地貌/建筑、植被水体、职业或生活活动；不随机拼接花草、薄雾、逆光和湿地反光。
- 构图系统选一个主形体或空间骨架，明确地平线/墙线/门窗分割、引导线、视觉重心、明暗块面、尺度参照和留白方向。人物镜让环境构图服务人物关系，纯环境镜才扩大地理信息。
- 自然运动系统写同一外力下的差速响应：风先推动轻尘和叶尖，再带动枝条、衣摆或水纹；雨雪、云雾、人群各有方向、密度和恢复节点，避免同步摆动和均匀粒子层。
- 环境故事弧写场景起态、剧情触发后的可见变化与余波，例如人群渐散、门缝光收窄、雨声盖住停顿、杯面热气消失。变化必须由源文、时间或自然因果支持。
- 揭示顺序只设计一次主要认知路径：先建立空间，再发现人物/物件，最终停在剧情落点；不能在同一镜里反复横扫多个目标。
- 光候演进允许太阳、云层、窗光、灯具、天气随时间变化，但必须保持主光方向、色温逻辑和受光连续，不为“更美”无故换光。
- 镜头呼吸按功能分配信息：建立镜展示地理和风景身份，人物/口型镜只保留一项环境呼吸，缓冲镜用环境余波承接关系结果。舒服来自主次、留白和自然变化，不来自细节堆积。

## 16. 序列导演语言与联合调度

每场先形成一句视觉论点，再决定单镜：

`建立观察距离 → 保持或推进 → 第一次破格 → 释放/解决 → 余波交接`

- 景别、焦段、机位高度和人物距离形成家族；只有关系、认知或行动发生变化时才破格。
- 构图母题可用隔物、门框、中央留白、纵深出口、上下权力差或同一物件位置建立，随后偏移、破坏或回收。
- 人物 blocking 与摄影机 blocking 联合排演：人物起点/终点、视线三角、遮挡窗口、摄影机路径、焦点交接和停点必须相容。
- 运动必须带来信息收益。摄影机移动后若没有新增空间、关系、动作结果或心理距离，就保持机位。
- 复杂调度准备等价稳定备选：固定关系构图、单向低幅移动或拆成下一主镜；备选不能删除戏眼、口型、动作结果和风景主次。

## 17. 剪辑切点与镜头经济性

切镜只允许由动作、反应、台词重音、声音、延迟认知、匹配形态或场景转换触发。每次决策回答：

`为何此刻切/为何不切 → 切前停留多少 → 切后新增什么 → 声音如何跨越 → 删除该镜会损失什么 → 失败时如何保持`

- `cut on action` 用动作连续隐藏切点；`cut on reaction` 把信息权交给被击中者；`delayed cut` 保留说话者或沉默后的代价；`cut on sound` 让声源先进入或延后退出。
- 反应镜必须带来新的关系信息，不只重复“惊讶”；物件/环境镜必须兑现状态变化、伏笔或余波。
- 少镜头模式优先合并同一叙事目标中的起幅、台词和低幅反应，但不合并第二策略、第二关系结论、回切或新的动作链。
- `hold` 是主动选择：当口型、未完成动作、关系距离或沉默需要连续可读时不切，不能把固定机位当作缺省答案。

## 18. 自适应信息预算

内部分析可以完整，直投正文必须选择性表达：

- environment：优先风景身份、构图、自然运动、光候和唯一叙事落点。
- object：优先物件状态、焦点、接触关系和信息增量。
- action：优先物理链、方向、受力、终态和低竞争运镜。
- dialogue：优先原文、口型、说法、听者反应、关系证据和句末闭口。
- dramatic：优先策略变化、面具泄露、权力可见证据、构图压力和余波。

每镜只允许1–2个视觉增强点。人物目标、关系判断、信息差、镜头段落标签、剪辑理由和质量分值留在元数据；正文不得为证明合同齐全而堆满所有分析结果。

## 19. 空间声音与声画导演

声音不是背景填充。每镜先建立：

`主声源 → 方向/距离 → 房间或环境响应 → 前后声部优先级 → 静音/骤停 → 声音先入/延后退出 → 切点支持`

- 方向和距离用画面空间表达：门外右侧、走廊深处、近距离胸腔声、隔墙低通或街道远端，不写无来源的“环绕声”。
- 房间响应区分卧室短混响、空走廊长尾、车内吸声、门外高频衰减、室外开阔无明显反射；同场跨镜保持一致。
- 对白出现时压低音乐与竞争环境声；沉默、关系断裂或危险揭示可以让环境声短降、骤停或只剩一个声源。
- 声音可以先于画面进入提示空间，也可以在画面离开后延后退出形成余波；两者必须服务揭示或剪辑，不能每镜滥用。
- 原生音频关闭时保留该计划供配音和后期，不把不存在的声音指令塞入即梦画面正文。

## 20. 道具功能面与摄影机可见面

手机屏幕、书页、照片正面、表盘、镜面、电脑屏幕和仪表盘存在“只有朝使用者才可正常操作”的功能面。模型会为了让观众读清内容而擅自旋转道具，因此人物正在看、读、玩或操作时，建立 `prop_functional_surface_contract`：

`使用者 → 功能面朝向与视线 → 摄影机所在侧 → 摄影机可见面 → 握持/接触 → 操作证据 → 内容可见级别 → 稳定终态`

- 默认隐藏内容时，写“屏幕朝本人、背壳/侧边朝摄影机、双手握持或页角接触、拇指点按/屏幕光映脸/视线落屏”等正向可见事实；不要只写“不要翻屏”。
- 需要读清内容时，使用肩后、过肩、俯拍、斜上方或摄影机与使用者处于功能面同一可见侧的机位；若同时还要人物正面表演，拆成内容展示镜与人物反应镜。
- `content_visibility` 只允许 `hidden/partial/readable/post_overlay/not_applicable`。文字内容仍服从 `screen_text_policy`，功能面朝向合同不能替代 UI 文字透视隔离。
- 手机静置、装袋、递交等不涉及观看/操作的动作不触发该合同，仍按普通道具生命周期执行。

## 21. 视觉先验、尺度和修复审计

模型会把“不要护士帽”误联想为医院，把背对镜头仍看向未定位人物画成扭曲姿态，也会为展示手机、照片、镜面或肩线而翻转功能面、增加人物。先识别风险类型，再只写真实身份、服装、空间锚点、可见人数、反射面、摄影机侧和正向朝向关系；不要把错误概念带入正向提示词。

活动道具统一按 `用途 → 可见面 → 起点 → 接触者/接触方式 → 路径 → 终点/方向 → 下一镜状态` 管理。手部接触、受力、遮挡/反射、并行动作、移动道具和实体运镜同时出现时，动作失败概率升高；先保唯一动作链和稳定终态，第二链拆到下一镜。

多人纵深或沿景深移动使用共同地面、地平线/消失线、遮挡顺序和脚底接触点作为尺度证据。近大远小只改变画面投影，不改变真实身材；人物走近/走远时占比连续变化，道具相对手掌和身体的尺寸稳定。失稳时改成同一深度双人中景或固定机位，而不是通过夸张变焦补救。

清晰人物镜的光源拓扑分离动机光、环境光和面部独立光。霓虹、火光、车灯、水波、雾和丁达尔光需要明确体积边界：它们可以扫过墙、地、玻璃、发梢或衣物边缘，未授权时不扫过面中。混合色温在衣领/耳后/轮廓处分界，面部用中性主补光维持肤色和眼窝层次。

关键帧不是单张装饰图。复杂镜以起始、戏眼、结束三帧锁住人物/道具状态差异；每帧重复共同空间、身体朝向、支撑接触、功能面、透视比例和光源。关键帧与T2V正文必须做左右、持物手、支撑状态、屏幕状态/朝向的事实冲突检查。

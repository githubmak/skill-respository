# Seedance阶段格式适配

正式栏目、栏目顺序、人物稳定模板、资产提示词及时间线首先完整继承用户输入的分镜 Markdown；输入文件是唯一输出模板。本文件只补充机器可检查的字段和 Seedance 可执行性规则，不得用通用第6节模板替换用户结构，也不得新增“导演分析/氛围分析/技法说明”栏目。

执行核心三源增强的编译保真：精修采用和保留的名场面、人物处理、复合摄影、空境与漫画化机制保留主体、触发、画面/声音变化、摄影起止、承受及镜尾结果，不压成“增加高级感/情绪升级”或参数清单。格式修复只减复述，不削弱已成立设计。

## 时间线与同源编译

- 摄影与构图写实际采用的观看关系、触发、路径/停止、切换和终幅，不另复制完整分段时间表。
- “画面与表演时间线”下嵌套时间段，使用“时间｜焦距+景别｜运镜方式”（焦距/景别也可分栏）；下一行连续可见画面，再下一行“声音：”及本段事件/语义节点。0.0秒连续到镜尾，焦距与景别均明确，微距不代替景别。
- 完整对白/OS/OV只在“台词与声音层次”按播放顺序出现一次，时间线可引用播放时点和语义命中，不复印完整文字。OS不作说话口型。
- 焦段或机位变化明确内部切因和动作/视线/道具/轴线/声音接力；真实连续移动/变焦写可达路径，焦点交接不能掩饰空间/焦段跳变。
- 画面、摄影、材质和声音来自同一联合创作。只写实际受影响层，不逐项凑响应或给每段强加动作/材质变化。高级运镜与空境细节写入既有栏目，不罗列技法名。
- 单镜最长35秒；两个阶段均可调整非冻结内容、镜头组织和单镜/总时长，具体权限与预算按阶段合同。项目参数写“实际总时长：X秒”与镜长合计一致，格式校验不衡量精彩程度。

## 精修交付与回退

从输入 Markdown 的原首标题开始，只留输入已有的正式栏目；不含HTML交接、原文复印、蓝图、评分、候选或修改记录。原稿有效且未改部分保留原表达；已建资产提示词、适用稳定模板和确认视觉基线原样复用，不重建资产。只同步真正受精修影响的摄影摘要、接点与实际总时长，并保持输入字段和顺序。

另存用户指定目录“<作品名>_精修分镜.md”，输入稿不覆盖/删除；同名精修稿已存在且无覆盖授权时用递增版本名。执行本Skill scripts/validate_storyboard.py --mode refined 并修复重验。格式修复不能削弱原稿成立的名场面/摄影机制；原/新比较与采用按精修合同，用户拥有最终版本选择。

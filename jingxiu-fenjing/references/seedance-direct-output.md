# Seedance阶段格式适配

本文件只补充时间线与 Seedance 可执行性细节；`SKILL.md` 和当前用户明确要求优先。沿用输入中的正式栏目、顺序、人物稳定模板、资产提示词及镜头块结构，不以此文件替换用户结构。当前常用精修块为“### 生成单元 G…｜时长：…｜承载：…｜一句镜头任务”及其六个字段；输入结构不同则沿用输入结构。除非用户明确要求，不新增“导演分析/氛围分析/技法说明”等栏目。

执行核心三源增强的编译保真：精修采用和保留的名场面、人物处理、复合摄影、空境与漫画化机制保留主体、触发、画面/声音变化、摄影起止、承受及镜尾结果，不压成“增加高级感/情绪升级”或参数清单。格式修复只减复述，不削弱已成立设计。

## 时间线与同源编译

- 摄影与构图写实际采用的观看关系、触发、路径/停止、切换和终幅，不另复制完整分段时间表。
- “画面与表演时间线”下嵌套时间段，标准写法为“时间｜承载镜号｜焦距+景别｜运镜方式、连续可见画面与表演。声音：本段声画节点”。画面与声音可写在同一嵌套条目，也可换行续写，但不得拆成新的正式栏目。时间从0.0秒连续到单元镜尾，焦距与景别均明确，微距不代替景别。
- 完整对白/OS/OV只在“台词与声音层次”按播放顺序出现一次，时间线可引用播放时点和语义命中，不复印完整文字。OS不作说话口型。
- 焦段或机位变化明确内部切因和动作/视线/道具/轴线/声音接力；真实连续移动/变焦写可达路径，焦点交接不能掩饰空间/焦段跳变。
- 画面、摄影、材质和声音来自同一联合创作。只写实际受影响层，不逐项凑响应或给每段强加动作/材质变化。高级运镜与空境细节写入既有栏目，不罗列技法名。
- 单生成单元默认最长35秒；用户或平台指定的时长限制优先。可调整非冻结内容、单元内部镜头组织和单元/总时长，具体权限与预算按阶段合同。完整项目已有总时长栏目时写“实际总时长：X秒”并与生成单元时长合计一致；只交付单元片段时不强制补项目总时长。格式校验不衡量精彩程度。

## 精修交付与回退

从输入 Markdown 的原首标题开始，只留输入已有的正式栏目；不含HTML交接、原文复印、蓝图、评分、候选或修改记录。原稿有效且未改部分保留原表达；已建资产提示词、适用稳定模板和确认视觉基线原样复用，不重建资产。只同步真正受精修影响的摄影摘要、接点与实际总时长，并保持输入字段和顺序。

保存位置与是否覆盖遵循 `SKILL.md` 和当前用户的明确要求。另存时使用用户指定目录；未指定但需要保存时写入工作区 `outputs/`。执行本技能目录下 `SKILL_DIR/scripts/validate_storyboard.py <实际文件路径> --mode refined` 并修复重验。格式修复不能削弱原稿成立的名场面/摄影机制；原/新比较与采用按精修合同，用户拥有最终版本选择。

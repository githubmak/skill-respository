# 用户认可范本：质感、演绎、摄影与空境校准

本资源整理用户认可的八个修正范本：落犁开田、门外有声、哥哥偷糕、引气入体、门外先听见杀令、酸意只露一线、神识压境、水滴山林开场。按需挑选与当前任务相近的范本作创作和验收参照，不默认通读全部示例。它们不是来源剧情、用户冻结合同或统一风格母版。角色、台词、道具、16:9、CG、慢动、低魔及各范本负面词仅在相应示例成立；正式生产按实际剧本、色卡、影调与已确认资产执行。

首次生成正式镜头前完整读一次八例，建立克制摄影与大胆摄影的不同有效条件；后续按任务定位对应节，不逐镜反复读取，不要求所有作品复刻八例。生成阶段按[导演核心第G节](director-creation-core.md)把适配机制迁移到当前场的联合导演方案，先设计镜头组再编译正文；本资源提供参照，不另建生成流程。第1—4节校准受力/生活演绎/光声，第5节权力距离，第6节隐情与打断，第7节Dolly Zoom与威压承受，第8节叙事空境。共用示例镜号仅是各自片段编号，不是同一集的连续镜号。

## 值得继承的是因果细节，不是形容词密度

- 写“动作—阻力/反馈—调整—承受”：犁尖受阻、绳索受力、脚步找支撑、呼吸恢复，让材质与身体共同工作；不把汗、风、泥点堆成无关细节。
- 微情绪依附任务与关系：藏食物、抢话、收灯、听声、吐息都要有注意对象和触发；多人有不同任务、时差与回应，不整齐同步。
- 摄影与声音沿同一节拍改变：从接触细节到空间成果，从轻声到暂静，从人物戒备到门的等待，从气息控制到归静。写可见/可听变化，不只写“有质感、悬念、温馨”。
- 光色服从空间：具名来源、照射方向、受光面、反射/遮挡、明暗与颜色面积共同塑形。暖灯低光不等于满场照亮，柔光不等于脸和背景同时糊平。
- 留白有具体状态：停止的是谁的什么动作、还留下什么声音、观众在等什么。结尾保持结果，不用“定格、彻底留白”替代可执行描述。

前四例建立普通镜的质感底线，后四例补充权力、隐情、高级摄影与叙事空境，不是名场面的创作上限。安静、有收益的固定镜可保留；整篇仍须通过导演核心增强第F节，不能复制示例形成全篇安全慢推与同一表情。

## 八类设计的校准与优化示例

以下为局部设计示意，不是正式直投成稿。沿用示例时须补齐核心第6节正式字段、焦距/景别、独立起幅、段内声音及完整台词；不擅改实际来源事实。

### 1. 劳作：先读受力，再打开成果与空间

优点：犁尖细节、双人协作、腰腹发力、土块重量与劳动后呼吸形成身体触感。

需要校正：末段“三人”未在起幅建立，不可擅补身份；若实际来源仅两人则写两人，有第三人则先建立其位置/任务。极近犁尖与两人双手通常不能同时清晰占主读位置；“偏干硬土”不自动推出湿润断面；前进距离与时间、人物起落姿态、沟的长度要匹配。末帧不能无依据变成整片田已开成的长直沟。“定幅”表示摄影机停止，“冻结帧”是剪辑效果，两者区分。

8秒示意：
- 0—1.8秒｜85mm犁尖特写｜贴地固定：刃口受压，土面裂开少量碎屑；握柄的用力由画外木响与呼吸建立，不硬塞全身。声音：木柄受力、刃口磨土。
- 1.8—4.5秒｜切35mm低机位双人中全景｜短距侧向跟移：沈青乔沉肩稳柄，阿丰绷绳踩稳，两人按同一推进节奏处理阻力；土沿犁刃分块翻落而非整齐流水。声音：绳纤维绷响、碎土落地、发力呼吸。
- 4.5—6.5秒｜切24mm全景｜从已开沟的近端低位后退并小幅升高：近处翻土纹理转交两人与坡地尺度，只露本次推进真实产生的沟段；摄影打开劳动与荒坡的差值，不凭空加长成果。声音：受力声退下，风恢复。
- 6.5—8秒｜24mm全景｜定幅保持：两人停步仍稳住犁与绳，缓一口气，土屑落定；长影仅在已确认低角度天光支持时保留。声音：呼吸、余土、远风。

### 2. 悬念：人物主动控制暴露，摄影交出等待对象

优点：脚步压轻、灯照范围、分段门外声与呼吸停顿让悬念不依靠跳吓。

需要校正：油灯唯一有效照明与冷白月光投影是两套方案，应按用户基线选择；若严格单灯，删除月光带/外影，别以“被动光源”规避光源冲突。单次焦点转移不能保证侧脸、低处灯与远处门缝始终处于同一构图；重构机位或明确切镜，不把对焦写成镜头移动。门外影子是否成立也需来源依据。低光面部可由同一灯的有效距离/反射获得体积，不擅加补光灯。

7秒严格单灯示意：
- 0—1.5秒｜35mm背面中景｜随步跟进：沈青乔从阴影到门前，灯照到地面与土墙，暖光随步移动。声音：衣料、轻脚步。
- 1.5—4秒｜切50mm侧面中近景｜短促贴近后停：门外沙沙声一停，她随即停步，将灯收近身体、稳住手，减少光圈晃动；屏息是为辨声音，不只是摆紧张表情。声音：门外一停一响，脚步止，衣料止。
- 4—6秒｜50mm侧面近景｜小幅横移越过既有门框遮挡后定幅：让她的侧脸、收灯的手与门进入有明确前后关系的构图，再将焦点交给油灯能照到的门板下缘。只揭示现有门与等待距离，不新增门外人影。声音：她的吸气短暂中断，主观听感压低风而非宣称世界无声。
- 6—7秒｜同机位定幅：她仍握稳灯，视线等在门上；灯火与轻呼吸尚存，“留白”是没有新声源回应。

### 3. 喜剧：郑重掩饰与小泄漏发生在同一关系里

优点：哥哥正经、妹妹笃定、母亲憋笑形成三方不同策略；抢话与一起停嘴有节奏落差。

需要校正：“固定中景｜全景机位”需区分机位与实际景别；“焦点跳切”需明确是拉焦还是剪辑。母亲要在独立起幅/同场空间中建立。哥哥肩僵后继续把手藏回相同位置，变化可能太小；宜让表面掩饰动作加大而真实泄漏变小，不靠持续皱眉。示例对白只属于此例，不能给其他剧本擅加对白。

6秒示意，保留“娘亲！／我没有！／他有！”：
- 0—1.5秒｜35mm三人关系中全景｜定幅：母亲在桌对面，阿丰挺直背着手，满满探头指向背后，喊“娘亲！”；三人不争抢同一个动作节拍。
- 1.5—3.5秒｜切50mm兄妹双人中景｜随阿丰半步侧移：阿丰抢“我没有！”并用挺胸转身的郑重姿态掩护藏糕手，满满跟着调整指向接“他有！”；横移让观众看到他试图遮挡却未完全遮住的半块糕，不穿越人物身体。身体大掩饰、手上小泄漏、妹妹的跟随共同造笑，不加摔倒或新台词。
- 3.5—5秒｜切85mm母亲近景｜定幅承受：母亲先看哥哥的正经脸，再看藏糕方向，话到嘴边却只抿笑；孩子停嘴等评判，留半拍让反差被读懂。
- 5—6秒｜切35mm三人中全景｜定幅：阿丰肩垮露出原来那半块糕；母亲笑声触发满满叉腰，阿丰小叹；反应有先后，不机械同步。

### 4. 修炼：摄影揭示实际效果，而非绕一圈陈列人物

优点：呼吸、叶影、指尖微光、落叶归位与自然声恢复形成完整起落；克制也可有记忆锚点。

需要校正：“半弧”与“绕至侧前方”的实际路径相符即可，不必凑180度；侧脸近景不是自动等于特写。叶子悬浮是此例已有的世界内效果，不是普通重力结果，需写灵气支撑下的轻颤/缓旋与撤去后的下落，避免“既悬浮又自然重力”自相矛盾。保留轮椅、闭目及三片叶子的身份/数量，不将“脸不动”扩大成全身无呼吸。

9秒示意：
- 0—2.5秒｜35mm右侧中全景｜定幅观察：卫景耘闭目端坐轮椅、手印在膝，三片黄叶尚贴地，建立效果前状态。声音：呼吸、树叶。
- 2.5—5.5秒｜35mm中景｜右侧向侧前方弧移，越过既有树干前景后定幅：遮挡退出时，指尖淡光和三片叶子的离地缓旋被共同揭示；摄影由“看人”转为“看气息对环境的作用”，不是孤立绕美景。声音：树声退下，微气流显出。
- 5.5—7.5秒｜切85mm手印特写｜定幅：吐息声延续，微光沿指尖至手腕隐入原衣袖；指节控制与袖口的轻反馈承接身体，不新增功法。需要侧脸承受时可另设明确子镜并自然重算时长，不能同一特写塞所有细节。
- 7.5—9秒｜切35mm原关系中全景｜定幅保持：支撑消退，原三片叶落回地面，人物仍闭目，呼吸自然；声音恢复风与既有环境声，读懂控制—生效—收束。

### 5. 权力距离：门外先听见杀令（S1-01）

继承机制：超大全景用人物占幅、纵深、门帘分格与空地承载权力；进入运动因命令停止，沉默身体与声场承受杀令，不依靠推脸。固定和慢动在此有明确观看收益。

修正后的9秒参照：
- 起幅与连续性：16:9御书房南侧外廊向北看，叶闻右脚刚过门槛，身体约占画面高度五分之一；北侧叶澜懒倚御椅，女官立于御案西南角，西侧宽榻保持既定位置。叶闻处在南门左门框与玉脂白内帘的遮挡区；按实际拓扑核对叶澜到入口的视线确被遮断，不以“她没注意”代替遮挡成立。
- 摄影与构图：21mm超大全景、胸口高度、深焦；叶闻在近处左侧门框，叶澜在北侧深处，中央朱砂红地毯连接两端。深处表演靠可见的坐姿、下颌朝向和女官背脊变化，眯眼/指节不承担本景别的关键叙事信息。
- 光色与材质：南门散射日光勾出轻甲，东格窗冷调天光与已有金色表面的低亮反射塑形；不将“鎏金”写成无依据的发光源。帘、石地、木柱、礼服和护肩服从同一曝光与色卡。
- 时间线：

  - 0—2秒｜21mm超大全景｜沿门中轴极慢前移约40厘米：叶闻进入时略带归途疲倦，脚步与衣料有惯性；叶澜仍懒坐，女官听令。声音：外廊脚步、远鸟，叶澜开口前吸气。
  - 2—7.5秒｜21mm超大全景｜闻令即停：叶澜仅抬下颌向女官下令，懒坐与杀令形成反差；叶闻停在遮挡区，身体仍朝进入方向；女官背脊收紧。声音：命令清楚落下，脚步停止，环境声在混音中让位。
  - 7.5—9秒｜21mm超大全景｜定幅：叶闻在遮挡内前移半步，半张脸进入厅内光区但仍不进入叶澜视线；女官微低头，叶澜未转向入口。声音：句末混响衰减、衣袖、叶闻平稳呼吸。

- 台词与声音：叶澜：“混账东西！死到临头还敢辱骂朕的长姐！给朕即刻砍了他！”懒坐施压，前半嘲弄、后半决断；不新增女官应答。命令采用自然可听懂的急厉语速，实际朗读超出时间窗时重配镜长与时间线，不赶词保住9秒。
- 落幅：三人仍在上述位置，女官接令，叶闻尚未被叶澜看见；地毯空地与遮挡保留供下镜续接。

验收证据：观众能读出“先听见、尚未被看见”的信息差及权力距离；命令触发停步/停机，余波存在。不能拿深处不可辨识的微表情充当表演完成。

### 6. 隐情与任务：酸意只露一线（S4-17）

继承机制：极近景读出关系衡量与情绪压住，人物没有质问却有话语行动；外部声音使视线转向任务，下一镜再打开全身关系，而非持续皱眉。

修正后的6秒参照：
- 起幅与连续性：宋长雪仍坐东客位、面向画外左侧叶闻，茶盏在案上不入手；100mm眼部极近景，领缘在下摇后才按实际构图进入下缘，不要求眼部与服装同时完整展示。
- 摄影与构图：全程100mm，不推近、不无故换105mm。先读双眼，极小下摇转交下颌/嘴角，允许双眼随构图离开画面；眼神收窄、短暂停留与下颌控制承载酸意，不把瞳孔变化当可靠的单一情绪指标。
- 光色与材质：既有东窗冷白侧光保留眼中细小高光与皮肤结构，苍松绿/月白服装只按可见范围出现，暮云蓝背景不抢主体。删去极近景里未必能辨认、且无必要的南门移动影子。
- 时间线：

  - 0—1.8秒｜100mm双眼极近景｜定幅：视线停在叶闻方向，眼睑稍收，像在衡量共同过去的分量。声音：轻换气。
  - 1.8—3.8秒｜100mm下颌与嘴角极近景｜极小下摇后停：下颌绷紧又松开，以表面平静、尾音极淡上挑说“从小？”声音：问句及自然气口。
  - 3.8—5.2秒｜100mm嘴角/下颌极近景｜定幅承受：嘴角平直，换气压住未出口的话；眼部不在画内时不再声称“眼底一闪”。来源已有的传令脚步由远及近。
  - 5.2—6秒｜100mm由嘴角回到眼部极近景｜极小上摇后定幅：脚步触发眼球转向南门，私人比较被任务注意盖住。声音：脚步到门槛，衣料轻响。

- 台词与声音：宋长雪：“从小？”不加醋意音效或戏谑配乐；脚步只在实际来源已有来人时使用，否则用来源已有的打断信号，不新造传令事件。
- 落幅：视线转向南门声源，情绪收住，身体与茶盏状态未改。来源支持时，下镜从面部局部骤切入厅全身调度，完成私情—公事的尺度转换。

验收证据：下摇/上摇各自交出不同信息，人物从衡量、克制到任务转移有可见过程；画外声音有来源，不靠情绪标签或虚构来人制造转折。

### 7. 高级摄影与承受：神识压境（S-05）

继承机制：主体稳定与背景透视变化构成“人不退、天地逼近”的反差；受压身体、材质和声场共同积累，抬眼之后冻结命中帧。修正技术方向，不削弱设计力度。

修正后的8秒参照：
- 起幅与连续性：仅卫景耘一人，端坐木轮椅、双手扣扶手，侧身朝画面左方断崖虚空；山涧位于其后景，实际山体层次与石台拓扑支持画面纵深。无路人、法相或第二个神识主体。
- 摄影与构图：起始50mm上半身中景，侧前方机位、光轴对准上身稳定锚点，不将“人物视线轴”误作摄影轨道。2—5秒摄影机沿自身光轴后退，同步连续拉长焦距，补偿人物大小；例如对稳定锚点约3米/50mm至4.5米/75mm，仅在石台后方有真实可达退轨空间时采用。主体略前倾时补偿以实际距离为准，保持画面位置与上身占幅，目标相对起始占幅误差≤10%，这是验收目标而非文字提示保证。
- 光色与材质：冷青灰侧后薄暮天光、轮廓薄亮边、正面暗侧保留结构；不靠摄影变焦自动制造光源收缩。低魔威压不发光，不加眼底能量光；背景可出现摄影性的透视压缩，不使山体实体折叠成窄条。
- 时间线：

  - 0—2秒｜50mm上半身中景｜定幅：他扣稳扶手，衣摆受原山风吹动，端坐蓄力而非“静立”。声音：崖风、既有远层低响。
  - 2—5秒｜50→75mm上半身中景，占幅补偿保持｜后退轨＋同步变焦拉长：威压触发摄影介入，后景山壁相对主体逐渐放大、纵深显得压缩；他胸口呼吸被压短、肩背抵住，握扶手更紧。声音：风啸与低频嗡鸣接力，主读声逐渐转交低频。
  - 5—7秒｜75mm上半身中景｜退轨与变焦同时结束、定幅：稳住背景压迫关系，他咬住牙关、喉部短暂吞咽，额角微汗仅按实际可读尺度呈现；木扶手有受力声，不无依据被手指压弯。声音：持续低频、压住的轻闷哼。
  - 7—7.5秒｜75mm同景别｜定幅但人物仍动：他抬眼命中，身体不退。声音：低频随命中收住。
  - 7.5—8秒｜75mm同构图｜明确剪辑冻结帧：冻结刚完成的抬眼帧，不在冻结后继续动作；主观声场抽空半秒，不宣称真实世界停转。

- 台词与声音：无对白。风、低频、呼吸到抽空与人物承受同节拍；不新增文字、符文、光柱或发光能力。
- 落幅：单人轮椅位置与身份未变，主体上身占幅保持，背景保留本次摄影透视关系；下镜若恢复运动，按来源与冻结帧承接，不把冻结效果当世界规则。

技术边界：向前推轨＋同步拉广通常让后景展开/退远；后退轨＋同步拉长适合后景逼近/纵深压缩。纯摄影不使实体变形。若另设计主观空间扭曲、光影收缩，须单独说明作用层、触发、恢复与既有世界依据，不偷塞进“标准Dolly Zoom”。焦点随距离同步维护，不将补偿占幅误写成中景变近景。

验收证据：真实轨道、连续焦距、主体占幅、后景变化方向相容；施压—抵抗—命中—声画冻结有起落。不是仅写“希区柯克”或堆UE5材质词。技术校准参考：[Adobe Dolly Zoom](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)，执行本例不要求联网或调用其他技能。

### 8. 叙事空境：水滴带观众落进雨后山林（S1-01）

继承机制：从微观湿气到宏观采集空间，动作匹配、真实下降、声场扩展和人物入口共同完成开场；空境揭示后续行动空间，而非景观清单。

修正后的14秒参照：
- 起幅与连续性：雨刚停的深山白日，无人林路横向延伸；水滴仍附枝尖，林冠、远雾与枝头遵从同一真实林地。雨后状态仅属于本例，不能用于改变其他场已确认天气。
- 摄影与构图：100mm微距水滴大特写，脱离时动作匹配切20mm高位大全景；广角机沿真实叶隙下降，越过而非穿透两层前景叶。下降后明确切24mm林路低机位大全景，随后短距慢推停在入口与路线关系可读的构图，不伪装跨焦段单镜。
- 光色与材质：右上方云层散射天光，天青远雾、青碧林冠、胡桃棕树干、青灰湿岩；腐叶吸水暗而不黑，细小水珠高光克制。各层共享曝光，不加雾中自发光。
- 时间线：

  - 0—4秒｜100mm水滴大特写｜微距固定，脱离后短幅下摇：水在嫩芽尖聚拢、变重、脱离，只跟到邻近叶隙；不把4秒都写成下落。声音：画外已有落水接触的细滴声，脱离本身不配夸张滴答。
  - 4—9秒｜动作匹配切20mm大全景｜升降臂下降：水滴的向下方向转交摄影机，注意从单滴交给森林；老树、倒木、右侧亮区依次显露，机位到林路高度后停。不宣称同一滴在空中慢落5秒；需要落水接触声时对齐真实接触或明确画外其他滴水。
  - 9—14秒｜明确切24mm低机位大全景｜沿无人林路短距慢推后停：湿腐叶与树根形成路线纵深，左侧入口开放，已揭示锚点仍可定位。声音：滴水由单点扩展为空间声，远鸟渐入，叶片摩擦维持质感。

- 台词与声音：无对白。自然滴水母题由局部转为空间；声源距离、落水接触与声音出现时机一致。
- 落幅：无人路线、主要采集锚点与右上天光成立，左侧入口供后镜人物进入；仅实际来源支持时交接到采集行动，不靠空境新增资源线索或改变人物知情。

验收证据：微观—宏观尺度转换、真实路径、空间锚点、声音递进与行动入口都在画面中兑现。相近任务继承揭示机制，不机械规定每篇从水滴开场。

## 使用时怎样判断继承成功

比较是否能从画面读出任务、阻力、注意变化、遮挡/距离意义和结果，声音是否有同一因果与节奏，光色是否使人物与场景同属真实空间。优秀范本的克制来自有选择的表现，不来自把“快速推拉、夸张动作、炫技、强光”写进通用禁止项。需要燃点、爆点、喜剧或大型揭示时可以大胆加速、急停、拉开尺度和复合表达；只修复不可执行/违反来源之处，不先削弱摄影再求稳定。

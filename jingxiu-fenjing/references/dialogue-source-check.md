# 对照原文核对台词

核对依据是用户提供的原剧本或原文快照，不用本次生成稿、自写摘要或重新整理的台词替代。只有分镜时按其中可确认的原句核对，说明原剧本未覆盖；缺失原文不猜写，其余明确创作继续。仅用户明确批准的新工作稿可更新核对依据，保留原文与授权出处，不能为通过检查改字、删句或修改原文索引。

## 原文与索引

沿用已有原文文件和version=1台词索引；没有索引时从原文一次提取当前授权范围内的发言，核对说话人、对白/OS/OV/旁白类型与发生顺序。原作重复说同一句话也记录为不同发言。逐句回读上下文确认覆盖及归属，脚本不代替这项工作。原文文件保持不变，索引放工作区内部记录，不加入正式分镜正文。

新建索引用本技能自带的 `scripts/index_dialogue.py`：

```text
python3 <SKILL_DIR>/scripts/index_dialogue.py <原文.txt> <已提取话语.json> <台词索引.json>
```

提取文件是对象列表，每项含 `id`（唯一U编号）、`speaker`（原文说话人全名）、`kind`（对白/OS/OV/旁白）与 `text`（原文精确文字）。同句多处出现时，回读原文后补 `source_start` 字符偏移，脚本拒绝自动猜选。输出索引记录原文文件SHA256和逐条字符区间，须核实脚本打印的上下文；不得从新分镜倒推原文索引。来源明确无发言时用空列表，仍检查是否擅加台词。

## 精修核对

```text
python3 <SKILL_DIR>/scripts/validate_storyboard.py <精修稿.md> --mode refined --music off --source <原文.txt> --ledger <台词索引.json>
```

示例中的配乐开关、格式及单元上限换为项目实际设置。`--source`与`--ledger`成对提供。核对每个单元“台词与声音层次”的实际发言，不把时间线中的语义节点再算一次；原文、归属、类型、次数和顺序须一致。跨镜或跨单元续句允许逐段承载，连续片段须按原文精确拼接，不能重复句尾。外层引号可作标记，原句内部文字与标点保留；重音、停连和口型写演绎说明，不改原句。制作阶段索引可直接使用，旧音乐设置与delivery单元分配不改变核对依据，当前实际发言按正文顺序重新核对。

无法可靠解析的归属、未闭合引号/括号等明确列为待核，不能报告台词程序核对通过；将明确的发言写成“人物全名＋话语类型/演绎说明＋冒号＋引语”后复验。明确锁定其他模板且不能解析时完成人工逐句核对，说明程序未覆盖，不为脚本重排用户模板。

未传原文与索引时，旧结构检查仍可运行，但会明确提示“台词原文核对未执行”；不能拿结构通过宣称原文核对完成。提取覆盖、原文实际归属、话语播放时刻、受话信息到达和口型仍由人工核对，程序不证明这些语义或成片效果。

# 摄影与光影规则

同步制作分镜2.0.5的4.1—4.3节，作为精修当前摄影、取景、光影与质感的执行依据；旧导演核心同主题条款仅作补充，冲突以本文件为准。联合视觉完成标准仍由visual-design-contract.md管理。输出层级与字段按当前output-detail.md或output-music.md，不另设表格。

### 4.1 摄影与景别

**数值焦段必填：** 每个成片镜头及其时间窗必须写正数焦段，并同时标明景别；支持 `50mm` 与 `50毫米`，可有空格或小数。不能只写“广角、标准、中长焦、透视特征”，也不能只在全局或单元摄影栏填写而时间窗省略。沿用用户锁定的焦段；未提供时按构图、机位与动作选择具体设计值，不伪称源稿已有或真实镜头参数已校准。非写实画面也填写虚拟摄影的设计/等效数值，并保持项目透视基准一致。连续变焦写起止数值与过程；固定焦段在同一镜各窗保持一致，机位切换另编镜号。数值须与景别、距离、画幅和可见内容相容，不靠数字替代摄影设计。

**焦段与取景核对：** 先确定本镜必须入画的面部、身体、接触或空间关系及观看距离，再选择摄影机可达位置和正数焦段，不先填数字再拼画面。项目首次使用时在已有摄影位置说明焦段的描述基准；未给基准时可采用全画幅等效作为设计读法，标为本次设计基准，不假称真实器材或资产已确认。同一项目和同一镜保持基准一致。核对实际取景能否同时容纳所写动作，近景是否真能读取所写微表情，景深与背景距离是否支持所写散景。窄小空间容不下选定长焦取景时调整可改的机位或焦段；用户锁定项冲突则指出具体缺口，不靠虚构距离解决。同一镜跨窗、跨单元保持焦段一致，只有明确连续变焦才写起止数值、变化过程和接缝值；另一次剪切使用新的镜号。校验器检查缺失和数值衔接，导演复核取景、空间和实际观看收益，不把数值合格当成摄影正确。

摄影先回答：摄影机与谁同感或保持何种观察距离，当前信息应展示、隐藏还是延迟，观众应贴近承受还是通过空间感受处境；再联合选择景别、机位、构图、焦点、运动和切点。景别按主体在画面中的占幅与取景范围判断，焦距数字不等于景别。下表是本文的取景说明，不以固定裁切线取代实际构图；人物、物件和非人主体均按其整体与局部关系判断。

| 景别   | 取景范围与主动选择条件                                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 大远景 | 环境占绝对主导，人物很小或不可辨；宏观地形、群体规模、天地距离或极端渺小感本身构成体验时选用，可直接承载事件与高潮                         |
| 远景   | 人物全身处于较大环境中；需要读懂人物与环境的距离、路线、追逐关系、孤立或共同处境时选用，不能依赖细微表情传递关键信息                       |
| 全景   | 完整人物或主体及其必要活动空间；全身姿态、步态、攻防、身体喜剧、多人调度或动作结果需要整体读取时选用                                       |
| 中全景 | 大致保留人物膝部以上及周围关系，实际裁切避开关节；重心变化、迈步起势、手部任务与面部态度需要共同呈现时选用                                 |
| 中景   | 大致保留腰部以上或相当范围；身体态度、手上动作、对白与同框关系同样重要时选用，具体手部或接触若出框则调整取景                               |
| 近景   | 大致保留胸部以上，面部为主且仍能读到肩颈姿态；需要贴近感受人物说听状态、犹豫或情绪递进，同时保留身体态度时选用                             |
| 特写   | 面部、一个物件或关键接触占据主要画面；局部变化成为观看中心，或贴近能显著增强亲密、压力、触感、信息确认与结果承受时主动选用，可承载持续表演 |
| 大特写 | 进一步集中于眼部、唇部、指尖、物件纹理等很小区域；该细节的变化、感官体验或局部揭示决定这一拍时选用，交代足够的对象归属与前后关系           |

**脸、手与道具的取景闭环：** 持物状态不等于持物动作可见。涉及持物、递接或展示时，先按当前姿态确定持物手的身体左右、手与物品相对脸/胸/腰/腿的实际高度、物品朝向与必要可见部分，再核对实际画幅、机位、上下左右裁切边界、遮挡和焦点。身体右手不等于画面右侧；细长物的上端入画也不等于握持手、接触点或整个物品入画。脸、手、物能同框与三者细节能同时读清是两项检查，须分别成立。

近景以胸部以上为主、面部特写以脸部为主时，垂在腰侧、腿侧或下半身的持物手与物品通常在画外；不得同时写“清楚展示完整脸部、握持手和低位物品”，也不得把同一张覆盖头至腿的画面仍称为面部特写。手部/物件特写可只拍局部，用已建立的归属和相邻镜衔接，不要求完整人脸陪同入画；脸旁已有持物动作时也允许脸手物同框，不设一律禁同框。大件、长件须说明当前需要读取的是整体、握持点还是局部，不能靠缩小物品或拉长手臂塞进构图。

按当前观看目的解决冲突，不规定一律拉远：面部为主且持物状态已经建立时，明确手与物在画外，仅保留实际可见的表演；握持、接触或物品证据为主时，切手部/物件特写并承接原持物手、位置与动作进度；先后读取即可时，可明确摇移、俯仰或拉开的起幅—路径—终幅，脸离开画面后不再要求同时读清其微表情。拉焦只改变清晰区域，不能让画外对象入画。确须同框且相应摄影项可改时，选择实际容纳必要范围的构图并如实标注景别，不把所有镜头改成中景，也不凭广角或长焦名称保证可见。

抬物至脸旁、屈肘、俯身或蹲下会改变人物动作，只能在源稿已有或授权范围内、符合当下任务且不改冻结姿态与结果时选用；须写出移动过程及后续位置，不能为迁就取景默认增加展示动作、换手、悬浮或位置跳变。用户锁定的低位持物、面部特写与三者同时清楚入画确实互斥时，指出具体冲突并提供最小替代，不静默改锁定项。内部可达性检查成立后，将实际边界、主读点与动作交接落实到既有摄影栏、对应时间窗及必要起落状态，不新增输出字段；检查起幅、关键动作点和落幅，避免仅起幅成立而动作中途出框。

**景别选择与衔接：** 先确定此刻需要看见的范围和希望观众感受到的距离，再选择最有效的景别。空间本身有戏时主动展开，表情或局部感受成为中心时主动贴近；近景不足以呈现细微变化或所需亲近感时继续选择特写，不以中景兼顾内容较多为由停留。各景别都可承担情绪、信息与节奏，不限定远景只交代环境、全景只拍动作或特写只交代线索。特写无需增加新剧情事实，其他景别也无需靠新信息证明每次停留；须在实际表演、空间关系和持续时间中体现具体体验。

任何景别都可作为起幅，特写不必由中景慢推进入，远景不必先作为空镜。景别变化可切镜、连续推拉或由人物接近/远离形成，写清实际取景与起止范围；不强制依次经过各档。大幅改变景别时保住主体归属、视线、动作方向与必要空间依据；当前关系已清楚时可直接切换。连续使用相同景别按实际效果保留，不设比例，也不要求一场集齐所有景别。避免无效重复的要求对所有景别同等适用，不把特写、大特写或远景当作需要额外审批的例外。

关系、策略或控制权变化时，先设计有动机的起位与目标位，以距离、朝向、高低、遮挡、中心/边缘、出入口和道具控制呈现变化；摄影机可响应人物调度，也可按观众信息需求主动揭示或延迟空间中的事实；不以摄影运动替代本应发生的人物行动，也不强迫人物先动来触发摄影。场内存在多个有效节点时，观看距离与镜头表现强度须有可感差值，但不机械执行“远—中—近—特”：可突然拉远、由近转全、峰值骤停、以焦点交接代替移动，或回到与开场相似却因人物位置和关系改变而含义相反的构图；每次改变都须绑定信息、关系、身体或结果。

相邻镜重复景别、机位或构图时须对所在节拍有具体作用，如持续同一关系、接续信息、承受情绪或形成有意义的重复，不要求每镜独立创造新含义。固定、运动和非常规机位均按体验选择，运动写清触发、可达路径和终幅，固定写清持续观看的对象与感受。景别、机位与动静分别作出选择；特写可以固定或运动，全景也可以贴近人物感受。新颖来自拍法对本场人物、任务、空间和节点的具体作用，不来自反常角度或持续漂移。

**固定镜头成立条件：** 固定只表示机位不运动，不等于固定中景、人物不调度或关系不变化。先按关键证据选择观看距离，再决定动静；固定方案须在时间线写清观众持续看什么、何种可见变化/声音信息或已建立的结果等待支撑停留、到何处结束。可用固定特写承受选择、固定远景显露距离，或画内调度改变遮挡和控制权；这些是选项，不是必填动作。仅写“凝固、克制、压迫、留白”而无具体证据不成立。移动能更清楚地揭示关系或证据时不得为省事固定；固定更有力时也不得为凑变化加推镜。

**场景摄影节奏：** 在分配单镜前，沿本场事件决定快速跟进、蓄压、贴近/展开及结果读取的位置；按短剧快速推进的取向把变化落实到景别跨度、构图变化、镜头长短、运动速度与切点，具体执行见第 4.2 节。主峰与前后须有可感力度差，长镜通过画内速度、遮挡显露与注意交接持续推进，不仅写“紧凑、渐强”。

**多人同框空间闭环：** 当观察者与被观察对象同时入镜，或人物分别位于前景/中景/后景时，先在内部锁定人物的前后顺序、屏幕左右、纵深位置、躯干朝向、头眼朝向、摄影机所在关系轴一侧、镜头可见的正/侧/背面，以及摄影机运动前后是否换到关系轴另一侧。不得只用“目送、看向、肩部轮廓、前景框景”等语义代替可执行的空间关系；必须能够用一句话说明“摄影机站在哪里、每个人面向哪里、被观看对象位于谁的哪一侧、镜头实际能看到每个人的哪一面”。人物要求远离摄影机并在画面中变小时，运动方向须实际远离镜头；人物、视线和摄影机关系无法同时成立时，先调整人物调度或机位相对位置。

**镜头级空间与可见面锁定：** 全局正负向提示词继续保留，用于维持风格、人物身份与材质、物理空间及跨帧连续性；它们不替代当前镜头的构图指令。凡镜头涉及多人同框、前后景、目送/注视、接近/离开、前景框景，或某人需要露脸/隐藏面部时，必须在该镜头或生成单元的“摄影与构图”中写明：摄影机相对场景与关系轴所在侧；人物相对摄影机的近远层次及画面左右位置；每人的身体朝向、头眼方向与可见面（正面、具体侧面、背面、局部、剪影或不可见）；谁入画、谁是清晰主体、谁为焦外/小比例背景，以及焦点和遮挡关系。不得仅在场景总则中写过后，假定生成模型会继承这些镜头级信息。

镜头级构图、人物朝向、景别、焦点、景深与有意遮挡，优先于任何全局面部清晰、受光或五官可辨要求。面部辨认要求只作用于本镜明确需要辨认面部的人物；明确为背影、侧后方轮廓、剪影、焦外、小比例远景或部分遮挡的人物，按镜头指定呈现，不得为了露脸而转身、改变机位、越轴、重新构图、强行拉焦或补亮。若镜头既要求人物背向摄影机/面部不可见，又要求读清其面部表演，必须在生成前解决冲突：选择符合剧情的转头或调度、改用另一镜头承载面部信息，或明确本镜不呈现该面部信息；不得把互斥要求同时交给生成模型。

“前方、后方、近处、远处、前景、背景”须结合摄影机方位和人物行进方向解释，明确指空间纵深、行进方向还是画面位置；不得用这些词互相替代。远景中的人物或细节仅在其画面占幅、焦点和停留时间足以支持时，才要求观众辨认身份或读出动作；不把写在文字里的细节当成画面已经可见。

**入画范围与不出镜声明：** 场景在场、被看向/被交谈/被操作、被旁白提及或发出声音，都不自动等于进入当前画面。对当前镜头实际提及、且容易被模型补画的对象，在既有“摄影与构图”及对应时间窗明确写入画状态：完整/局部入画，或“本镜不出镜”；画外对象按需要写清相对当前画框的左/右/上/下、人物关系或声音方向。只声明当前相关对象，不逐镜罗列场内所有人和物，不凭空补造无依据的精确站位。出镜对象清单和不出镜声明随实际切镜更新，不能只在全局或单元总则声明一次后默认各镜继承。

例如，采用只拍人物甲的近景时，写“人物甲看向画外右侧的人物乙；人物乙本镜不出镜”，而非仅写“甲看向乙”；实际成稿使用人物全名。近景本身不意味着另一人必定画外，须按已选构图判断。单人反应、正反打、主观视点、对话与画外呼喊均区分观看主体、声音来源和画面主体；人物乙画外说话时仍保留其原台词、发声时点和来源，不为了口型让乙入画，也不把声音改给甲。第一人称主观镜头不默认出现视点人物的脸；手或身体局部只有被设计入画才出现。

“不出镜”指本镜/所注明时间窗内不出现该对象的视觉形象，不等于不在场、离场、消失、停止动作或失去道具。虚焦、背影、剪影、被实体挡住和局部入画均不是完全画外，须如实命名：过肩镜只见乙的肩背就写“乙仅肩背局部入画、面部不出镜”，不能同时写“乙不出镜”；手部特写可写“仅右手与玉佩入画，人物面部不出镜”，持物状态与画外肢体仍按既有事实接续。人物在画内但被挡住时写明遮挡者与当前可见部分，避免把遮挡当成画外位置。明确整个人物不出镜时，不再同时要求其肩背、倒影、影像或可辨剪影出现；若仅本体画外但保留实际成立的镜中像/投影，分别注明，不能笼统宣称完全不出镜。

“本镜不出镜”只用于全镜持续画外的对象；移镜揭示或人物进出画时，改用“起幅不出镜→何动作/摄影变化使其入画→落幅可见范围”，退出也明确退出时点及画外状态，不能全镜禁止入画后又要求出现。先后读取不等于同框，前一对象出画后停止描述其可见表演。画外接触若承担关键因果，须由可拍的相邻镜头或明确移镜承载，不用不出镜声明删掉必要证据。编译后核对摄影栏、动作时间窗、声音、起落与适用正负约束，去掉互相冲突的同框、面部或道具可见要求；不向直投补入只供内部追踪的画外微表情。

**给定机位的可拍摄性：** 对所有镜头检查“摄影机起位与朝向—主体真实位置/朝向—视线通路—画框范围—焦点与占幅—运动终态”是否共同成立；给定机位只是待核对的设计，不能因已写入摄影栏就视为可拍。结合当前动作检查起幅、决定性节点与落幅；普通镜不新增坐标表或检查栏目，只有实际冲突才展开核算。重点核对：侧背面是否被要求读正脸/双眼；过肩人物是否挡住对面表情、手部或接触；俯仰视点是否能看见桌面、容器内部、掌面、纸面或屏幕的有效朝向；前后主体是否互相遮住；远近比例、透视与景深能否支持所写细节；门墙、家具和实体是否阻断观看或运镜路径。反射画面按镜面、主体与摄影机的相对关系成立，不用镜子自动补出正面或画外对象。不能通过拉焦透视实体、凭空增加反射、让人物无因转身或改变物体朝向来解决矛盾。明确启用的虚拟摄影、剖视或风格化透视按其自身规则设计，不把普通实景镜头无说明改为穿墙/透视镜头。

**不可拍内容的修复选择：** 按本镜主要观看收益和信息先后选择，不要求逐项试遍，也不一律拉远。当前机位拍不到的非必要细节可从本镜画面描述移除，仅在内部状态或必要起落中保留，不能仍要求它在画外清晰可见。关键事实、接触、证据、台词和结果不能因此删除：可调整可改的机位、高度、朝向或构图；切至能看清的局部/反向/补充镜头；或用有清楚起幅、路径和终幅的摇移、俯仰、升降、环移、推拉先后读取。前一对象离画、被挡或失焦后，停止要求同时读其细节；焦点交接只能处理已入画且未被实体挡住的对象。需要切镜就明确切点并使用新镜号，不把互斥机位写成同一瞬间；连续运动须有可达路径、读取时间和必要轴线桥。跨镜保持身份、持物手、接触进度、位置、动作方向及声音接续，不重复动作来补拍证据，不靠无因越轴或人物瞬移补画面。

**空间核验的修改权限：** 区分用户明确锁定的导演参数与本技能自行拟定的方案。对自行拟定或用户已授权调整的机位、景别、焦段、运镜及镜头组织，发现具体不可拍证据就直接修复，不因它们已出现在初稿而冻结；优先保持原本成立的表演、动作、观看距离与节奏，不为迁就摄影强迫人物新增动作。用户明确锁定项按授权范围保留；若可用的机位调整、切镜或移镜仍无法兼容全部锁定要求，指出具体冲突并提供最小替代，不把矛盾写进直投。修复同步相关场景摄影规则、场景空间、单元摄影栏、时间窗、镜号/时长及起落状态，不能仅改机位名称或删一句后留下其他栏目继续要求同一不可见内容。

优先组织对本场有效的对比：连续较宽画面后直接贴近，局部细节后突然展开整体，短镜连续推进后停住承受，长时间等待后迅速揭示，或运动中突然保持构图。选择来自已有情境，不套固定顺序和镜数；持续同一拍法也可累积张力，须有清楚的等待对象与兑现点。连续几拍都只用相邻景别、相近时长和同速缓推时，检查是否削弱了已有转折；若更鲜明的距离或速度变化能改善体验，就采用，不因原方案勉强可读而保留。检查方式见第 7.1 节。

场景不是被动背景：从现有门槛、通道、高差、遮挡、可接触表面、关键道具、光区与动态背景中选择能承载任务、阻力、关系或结果的部分，让人物使用空间，空间再以路径、接触、声响、受光或物件状态回应人物。构图除保证可读，还须形成与项目相容的视觉秩序：按实际空间选择轮廓分离、形状呼应、色彩面积、负空间、纵深或有意压平，让观众能感受人物与环境的关系；不把“当前观看重点唯一”写成每镜居中、浅景深虚化背景，也不强迫所有镜头达到海报式饱满。每场冻结一条不输出的人景主构图策略，并允许由人物、关系、信息或结果节点触发阶段性变形：主体与负空间、几何秩序、纵深/遮挡、颜色面积和人物—环境尺度可以在场内开合、交换、压迫或释放；逐镜只写实际采用部分。常规关系、过程或环境镜按需要用尺度、遮挡、焦点、视差、光区或动作建立有效层次；纯肖像、主观压迫、极简或有意压平可以单层。背景提供空间、压力、过程或反差，不与面部和关键动作争抢，但不得因“当前观看重点”规则删除有戏剧作用的次级空间信息。真实峰值须有可读的结果或观看意义变化；可通过空间开合、中心/边缘交换、遮挡解除、同框/分离或前后景换位，也可让构图不动，由人物反应或新证据改变其含义。

**实体场景环境可辨识：** 实体场景的人物镜头默认按以下类型组织取景、景深和后景描述，适用于项目实际画幅，不强制统一为中景或全景。目的是保留人物与既定环境的摄影关系，降低非预期纯色或渐变背景风险，不保证生成结果。

- **普通单人近景：** 优先写为胸上中近景，明确头部、肩部和上胸入画，并给身后环境留出实际可见面积；采用中等景深，人物面部清晰合焦，身后既定环境保留可辨识的结构线条、材质变化与前后空间层次。不能只改景别名称却不说明取景。若放宽画面使必要微表情或观看距离失效，保留更近取景，按面部特写方法呈现环境，不机械退远。
- **面部特写：** 优先采用中等景深，同时保留面部主体占幅及原有观看距离，眼睛、鼻部与嘴唇清晰；周边实际入画的既定场景保留可辨识的结构轮廓、材质变化与空间层次。景别与景深分别描述，不因采用中等景深就改成中近景、拉远摄影机或扩大取景。背景可有适度失焦，不要求与面部同等锐利，不以全画面锐化换取场景辨识；焦外人物、暗处身份与有意遮挡仍按原设计。几乎无后景入画时不强塞景物，中等景深不能凭空增加背景面积，也不保证消除纯色底。用户锁定或剧情必要的浅景深、拉焦仍优先。
**近景与面部特写的逐镜落稿：** 场景层的“中等景深、环境可辨”只规定常态，不算当前镜头已完成设计。每个普通单人近景或面部特写，须在既有“摄影与构图”中按成片镜号写明焦点/清晰主体、实际入画且位于人物身后的既定物体或结构，以及它们的相对位置、层次与清晰程度；有前景肩边时单独说明其焦外/遮挡，不能用前景肩边代替后景设计。“面部清晰”“背景可辨”“中等景深”单独出现都不足以完成这项要求。后景须由当前机位、朝向、裁切和场景拓扑推出，不凭空增添灯、窗、柱或景物；确无后景面积、后景被实体遮住或有意纯色/全虚化时，直接写出实际状态与相容的取景/剧情依据，不为凑后景拉远脸部、转身或造景。浅景深与局部特写按既定例外执行，仍说明实际焦内外范围，不强迫所有层清晰。

同镜焦点和后景关系稳定时在摄影栏写一次，时间线只写动作及有作用的变化，不逐窗重抄；切到另一成片镜或连续移镜、转向、拉焦改变关系时，在对应镜号/时间窗更新后景显露、遮挡和清晰范围。独立G投喂包须带齐其所含镜头的这些信息，不能只携带场景总则。场末复审逐一定位本场适用镜号的焦点与后景证据，并核对几何、占幅和既定资产是否相容；只有场景总则、笼统形容词或物理上看不到的后景时，修对应摄影描述与实际变化窗，不能以栏目非空或焦段已填判为完成。此项并入原复审，不新增字段、报告或审核轮次。

- **中景、关系镜、中全景和全景：** 保留成立的景别、构图和观看收益，优先用与人物纵深及动作相容的中等景深，使主要人物、关键动作与既定环境层次可辨。前景焦外肩边、遮挡、后层小比例人物、侧背可见面和有意暗部仍按本镜设计，不因环境清晰要求锐化所有层次、补亮隐藏身份或让背影转身。
- **手部、道具、接触及面部局部大特写：** 保留关键细节占幅，焦点覆盖实际操作或接触区域；通过实际入画的皮肤、衣料、承托物及接触阴影体现空间，不要求远处建筑入画或清晰，不为环境交代拉小关键接触。
- **场景与运动适配：** 后景服从摄影方向、实体遮挡与实际取景。可以用已有墙面、通路或场景结构说明层次，不强制逐镜枚举家具；室外采用相应地形、植被或其他有依据的环境结构，不机械套用建筑线条。没有依据不新增门窗、花园或灯具，不把人物面前或侧面的物件无因放到身后。横移、弧移与跟拍保持原有观看作用，环境随路径自然显露和退出，近处焦外边缘继续保持焦外。
- **局部修改与编译：** 仅要求环境调整时，保留原台词及归属、镜号、焦段、时间窗、单元时长、动作、视线对象、入画/不出镜、配乐及剧情结果；同步摄影栏、对应时间线和实际受影响的光影、起落描述，不添加站位、建立镜头、资产重制或逐人场景首帧要求。原稿无关矛盾单独说明，不擅修。初稿设计仍可按其他章节选择有效摄影，不因本条把每镜写成同一套模板；共用原则集中说明，当镜只写必要执行差异。

用户明确锁定的景别、浅景深、拉焦、主观画面、纯色或风格化背景优先保留。人物参考图的纯色底不等于剧情背景授权。环境要求与关键表演或隐藏设计冲突时，保住必要观看证据并说明冲突，不通过换背景或擅改人物动作解决。完整正文继续采用第6章原有G单元栏目，不新增后景打卡表，不用“其余不变”省略用户要求交付的修改稿；“环境测试版”只在用户要求测试版时用于文件名，不替代正式主稿命名。

本写法依据当前项目用户反馈“现在看起来比较稳定”纳入使用；该反馈不等于独立同条件对照、所有镜头均有效或灰底根因已确认。文本核对仅确认取景与约束一致，后续成片仍须检查环境是否正确、表演是否可读，不把某个颜色、四宫格、焦段或浅景深直接认定为唯一原因。

**画幅适配与画面取舍：** 先按叙事、情绪与观看目的选择景别，再结合项目已确认的画幅比例设计主体占幅、人物层次、留白与动作范围。画面拥挤或信息无法兼容时，优先减少无作用的背景内容、降低次要信息显著度、减少同时入画的人物，或将必要信息分配至相邻镜头；可通过画外对白、局部入画和已建立的空间关系保持在场人物与因果连续。不得删除必要剧情证据、改变人物在场事实或冻结的信息揭示顺序。已有景别具备明确表达作用时优先保留；剧情确需同时读取身体、接触或空间关系时，再联合调整调度、机位与景别，不为容纳全部内容统一退成中景或全景。竖幅与宽画幅均可使用全部景别，按实际需要组织横向、纵深与上下关系，并核对起幅、运动过程和落幅的可读性。

**画幅规则的适用边界：** 所有画幅均须让实际取景、景别、焦点与表演要求相容；9:16的构图取舍建议仅在竖幅真实容量不足时启用，不迁移为16:9的默认人数、站位或拆镜限制。16:9按实际可用宽度保留成立的多人同框、横向调度、群体关系与同时反应；必要表演、接触和空间关系清楚可读时，不因竖幅条款减少人物、改为单人覆盖或增加切镜。9:16本身也不强制单人或双人构图，同框成立时直接保留。

**9:16竖幅的取景与表演承载：** 画幅是实际取景边界，不能将横幅多人构图直接裁窄后仍要求相同表演可读。选定景别、焦段和可达机位时，先确定当前必须看清的主体、入画身体范围及接触/动作所需范围，再判断其他人物实际能否同时容纳；容不下时在此处重选构图或观看方式，不先写全员表演再补“竖屏适配”。人数不设固定上限，但横向并排的多人近景、同时读取多张脸与手部/全身行动等组合须按实际空间成立，不能只写“均清晰可见”。竖幅横向容量不足时，可用单人、偏侧双人、过肩局部或有依据的纵深组织主次；必要时用相邻镜头或有路径的摇移、交焦依次交付，具体取舍服从当前剧情，不机械套竖屏模板。

当前时间窗只要求画内实际可读的表演：写明谁以何种身体范围入画、谁仅露肩/手/背影、谁在画外或焦外；画外人物保留原有在场事实与声音，但其表情和动作不能被写成此窗的可见证据。近景不能同时要求未入画的脚步、全身受力或低处接触清晰，焦外/被挡人物不能承担必须辨认的微表情。必须同时读清接触双方时，给足接触部位及相对位置，再选择相容景别、站位与机位；纵深压缩和前后排列也须检查遮挡、焦点和人物可达关系，不能为装人无因搬动人物。后撤或变广角可能使面部太小，不能以“全部塞进画框”当作通过。

静态构图核对起幅即可展开；有横向走位、伸手递接、多人交错、环绕或摇移时，在关键节点与落幅核对主体/接触是否出框、裁切是否丢证据、焦点与景别能否支持所写表演。若同框容不下所有必要信息，明确切镜另编镜号，或在同镜不同时间窗依次读取；同步修改时间线、声音归属与起落幅，不仅在摄影栏声称适配。只展开当前镜头真实存在的容量冲突，不新增逐镜容量表或精确坐标。

### 4.2 运镜、切镜与镜头表现强度

每个时间窗在原有摄影描述位置明确摄影机固定或运动；连续镜可简写继承的具体方式，不复制整段路径。“切到某人”和人物推拉动作不能代替摄影机状态。缺漏时按实际方案补全，不默认全改固定，也不为通过检查强加运动。

**短剧节奏与常规节点：** 默认按短剧快速推进的体验联合设计景别、构图、运镜与切点。关键语义、关系转折、发现、反制与高能动作应有鲜明的距离、速度、方向或构图变化，不因原稿已可读就满足于平稳覆盖；普通对白和过渡也以注意交接、同框关系、画内调度及及时切入切出推进，避免连续同速缓推、等长正反打与无变化等待。固定、长镜和有意重复有更明确张力收益时保留，不为凑动感新增事实或装饰动作；判断来自当前剧情、人物与空间，素材库仅供启发。

运镜从观众应经历的距离、速度、发现和情绪过程出发，可由人物行动、观众期待、关系或空间启动，无需等待人物先动。时间线写清起始景别与构图、启动或变速节点、可达路径、焦点与关键证据读取窗口，以及终幅或向下镜交接的方向和动量；连续路径可跨多个节拍加速、减速、改向或保持运动，不要求每段独立新增剧情触发。景别跨度可通过明确剪切实现，不用换焦段数字伪装位移；人物动作、摄影与声音按成立的并行关系组织，不让动作等待运镜完成。

**运动与剪辑的主动选择：** 按具体节点选择足够鲜明的表达，速度、幅度和景别跨度不默认取最小值。以下是可用方向，不是每场必填组合：

| 当场需要的体验               | 可选择的拍法与节奏                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| 判断突然确定、关系骤变       | 直接切入特写、快速推进后停住，或反向拉开展示后果；按需让声音连续，画面先改变距离                 |
| 行动加速、空间被争夺         | 跟拍、横移、后退或弧移与人物调度结合；在行动尚未结束时切到下一有效视角，让动势跨切点延续         |
| 等待、试探、亲密逐步加深     | 稳定停留、持续靠近或横向改变遮挡；把揭示或接触时机作为速度与切点的依据，等待兑现后及时转入下一拍 |
| 规模揭示、成果出现、局面反转 | 从局部直接切到全景/远景，或拉远、升起、移出遮挡形成显著展开；在整体关系可读处决定继续还是停住    |

快速摇移、明确变焦、多阶段运镜及运动中剪切可按题材与空间选用，也可用贴身跟随转抽离、弧移改变前后景或俯冲后交出接触；表中拍法只是方向，不是固定组合。分别写明实际摄影方式，模糊或遮挡可作短暂过渡，关键表演、台词、接触及结果须在运动中或相邻镜可读。快节奏不靠统一缩短镜长、赶词、持续甩镜或震屏；短暂蓄压、命中制动及结果承受服务力度差，不逐镜套“蓄势—加速—停稳—余韵”。慢动作仅放大值得读取的瞬间，兑现后及时恢复相应速度，不稀释整场爆发；镜尾和停留按第 5 节结算。

**摄影方案的展开与完成：** 按[联合视觉设计合同](visual-design-contract.md)第1—5节，把摄影与人物、光影、材质、体积和效果共同构思并兑现到正文；本节继续定义实际摄影与剪切的细则，不以拍法名称、路径成立或参数齐全代替表达完成。

**摄影运动质感：** 先明确本镜采用固定机位、轨道、稳定跟随、手持或已设定的风格化运动，再按目标、路径与终幅组织速度。自然启停需要时平滑加减速，匀速推进、突然停住或提前领拍有叙事依据时保留；不统一套“前缓—中稳—后缓”，不把匀速直接判为机械。

固定机位可以完全稳定，人物、声音与画内关系提供生命感；仅在明确选择手持或相应视点时允许低显著的纠偏、惯性与重心调整，不默认加入周期性呼吸晃动。跟拍可同步、领拍或延迟跟随，依据人物速度、路径、揭示时机与构图需要决定，不套统一延迟秒数或画幅振幅百分比。参数只有在具体工具可控制并已校准时使用；自然语言描述须写清实际起停、跟随关系与终幅，验收主体、口型和关键接触是否稳定可读，不以微晃数量证明真实。

**多种手段的配合：** 人物调度、景别变化、焦点与运镜可共同完成一段体验；例如跟随靠近的同时重排前后景，或在快速展开后将注意交给人物反应。按整体路径判断是否有效，不要求每个组成手段分别增加信息。主次由观众应注意的先后决定；组合更清楚、更有感受时保留，实际争抢表演、关键接触或台词时再调整速度、时机或承载方式。

镜头表现强度来自观看距离、机位、运动速度、焦点、切点与停留在有效节点上的联合变化，不来自单纯更快、更晃、更近或更响。人物应对、关系/控制权、重要信息、关键接触或策略发生变化时，先判断人物实际体验、观众知情和空间压力，再选择有效的镜头表现强度；可贴近人物、拉远揭示代价、跟随夺取空间、后退表现压迫、弧移重排关系、焦点突换命中信息，或固定迫使观众直面结果。摄影表现强度由人物体验、观众知情差、空间压力与类型策略共同决定，可与外在表演形成有依据的反差；人物不动时，观众先知的威胁仍可支持摄影变化。运镜可同步、延迟或反衬情绪，不规定紧张必快、平静必慢。不得用持续晃动、连续强推、密集切换或轰鸣音效把“确认、试探、委屈或克制”误拍成无差别暴怒；同一情绪命中只保留一个主摄影落点。固定观看也可承载亲密、幽默、轻快过程、平等共处或冷静观察，按第 4.1 节写明具体收益，不把固定限定为压迫与凝固。语义转折、信息到达、接触、受力、停止或反馈是候选切点，不是唯一合法切点；可在动作中匹配切换、提前建立预期、延后让结果显露，或跨语句保持镜头。切点以观众何时需要改变观看位置为准，保护关键动作连续与对白完整，避免句句说完再切、动作做完再切。越轴须用可见运动、中性机位或人物换位重建方位。

关键镜须让观众经历有依据的观看变化：由人物、信息、动作或空间触发，改变同感对象、判断、距离感或结果承受。摄影可变化，也可固定，让同一构图因新事实获得不同含义；不要求所有关键镜都改变机位或画面秩序。只并列参数、看不出观众体验时重做。

漫画化视觉用负空间、透视、占幅、分格、遮挡断裂、空间压缩、停格、残像、速度线、边框、画幅/颜色变化或声画匹配强化处境、关系和命中。持续处境优先用构图/关系变化，瞬时命中用节拍变化，明确主观冲击用主观化，因果连接用形色/声音匹配转场；显眼机制须写清 `触发 -> 改变区域 -> 当前观看重点 -> 持续 -> 退出并回到客观连续`。爆点可叠加运镜、剪辑、漫画化视觉、世界内特效和声音，但须服务同一主变化、保持一个当前观看重点，按需错峰进入并清楚退出。能量与破坏只来自原设定；无依据的文字、弹幕、气泡、UI、Logo 与水印不生成；信件、账目、告示或真实界面等剧情必要文字按第 6.1 节制作，不因负向约束删掉关键证据。只有项目风格启用漫画化时才使用对应机制，不要求每场出现；写实或其他风格沿用自身语法。停格、时间拉伸、残像等写具体发生方式和退出，不用导演姓名或“高级运镜”替代可执行描述。

### 4.3 光影、色彩与材质

**四类视觉信息分清后联合编写：** 影调规定整体偏亮或偏暗、明暗面积、反差、黑白位和灰阶过渡；色彩规定主辅色、冷暖、饱和、肤色参考和强调色；布光规定有效光源、方向、高度、软硬、补光和轮廓；成像材质规定高光过渡、纹理、反射、光泽和颗粒。高低调、明暗反差与光线软硬分别判断，不将高调等同过曝、低调等同欠曝或软光等同低反差。可合写在现有栏目，不新增四套输出表。每场基线须有具体明暗与反差，以及当前观看任务所需的人景亮度关系、高光和暗部层次；“冷白、微青、低饱和、电影感”不能代替影调。色温数字辅助可见设计，不优先于光向、塑形、反差与冷暖结果；参考板上的8K等规格不作为影调依据，也不保证实际输出规格。

**视觉规则的范围与覆盖顺序：** 用户当前明确要求、锁定资产与剧情事实优先。项目共用视觉规则只约束跨场风格，不携带房间灯具、色温或关系轴；每场独立写当前摄影和实际光色。当镜有剧情依据的停电、来电、遮挡或新光源改变本场常态时，以时间线上当前有效状态为准，并由后镜继承至实际恢复；局部变化不是擅改用户冻结条件的权限。有意暗部、焦外、背面、局部特写与必要浅景深按4.1的具体设计优先于通用面部/环境清晰要求，不能为提高可辨性补光、露脸或拉远。通用条款之间存在重叠时按这里的范围解释，不叠加互斥要求。

**场景基线的色彩与材质边界：** 编写每场的“场景光色与影调基线”时，明确整体白平衡、冷暖、饱和与灰阶倾向的作用范围，不能用一组环境色名覆盖场景建筑、墙面、家具、服装、道具的资产固有色。允许有来源的受光、环境反色、曝光和统一调色自然影响观感，仍保留可辨识的材质差异、局部明暗分区与空间深度；不把固有色保护误写成物体不受光照影响。除用户明确授权的单色或风格化设计外，不将场景统一染成单色，也不通过平滑色块取代实体环境。

该栏目先写当前场景实际采用的亮暗冷暖、饱和范围、光源逻辑和成像特征，再写资产保护边界。只写“整体色彩约束影调、固有色保持”仍未建立基线；“延续同一基线”不能替代尚未写出的颜色、反差和材质结果。已有等价边界不叠加，具体编写按下段联合落实。

“干净低噪点、细弱颗粒、柔和高光”控制成像质感，不等于抹除墙面纹理、家具材质或暗部层次。“无脏灰、无死黑”等限制只排除非预期成像缺陷，不禁止真实灰色材质、必要阴影及有意隐藏区域。肤色、唇色、伤势与环境色偏分清：仅用于中和肤色偏青的少量粉调须限定于肤色校正，不自动生成环境粉光；剧情局部红肿不扩散成全脸染色或无来源红光。其他颜色采用同样的作用范围原则，不把粉调或冷白设为跨项目默认。

写数值光比时说明比较对象及顺序，例如“人物面部亮侧:暗侧”，不要混用主补光比、面部明暗比及人景亮度比；未有校准依据时优先以可执行的自然语言说明强弱、柔硬与层次，不声称数字已经实测。人物光比不自动规定整个背景亮度，白平衡数值也不替代实体灯源与材质设计。保留本镜既定浅景深、焦外、暗处身份与曝光意图，不为背景可辨而统一补亮；这些要求不能保证解决视频生成中的纯色背景。

**色温区间与视觉读法：** 每场“场景光色与影调基线”以及每个G单元“光影、环境色彩与材质”明确当前有效主光的色温设计区间，并用暖白、中性白、偏冷白等自然语言写出希望呈现的冷暖、肤色与环境效果；例如“主光色温设计5100—5500K，白光；摄影白平衡取偏低于主光的设计值，使白墙略偏冷，肤色保持自然”。示例不是跨项目固定参数，不要求每次额外标白平衡数字。已有光源色温锁定为单值时沿用该值，不为凑区间改动来源；未有实测依据时明确为设计估计，不伪称灯具测量值或可精确控制的生成参数。

光源色温与摄影白平衡分别命名，最终画面冷暖另用可见结果说明，不以一个未标对象的K值兼指灯光和白平衡；两者数值可以相同，但须分别命名，也不单凭K值断言最终偏蓝或偏黄。混合光仅在确有多种有效光源时分别写主光与次光的色温/冷暖和作用区域，不把整场平均成一个数；纯色灯光用具体颜色和覆盖范围说明，不硬套白光色温。单元内停电、来电或改由手机照明时按时段更新有效光源及其色温设计，原灯失效时不继续沿用原区间；完全无有效照明时写明无有效光源，不虚构色温。场景基线写本场有效光源与变化条件；每G光影栏保留当前适用的简短色温/冷暖摘要，这是必要的局部执行信息，不等于重抄整套基线。时间线只在光源实际变化处更新范围和状态，不逐句重复数字。数值不替代光向、柔硬、塑形、景深或材质结果。

**日夜、天气与环境光：** “日”只确定白天，不自动指定晴天、烈日、明亮天空或充足直射光；“夜”也不自动指定全场漆黑。优先继承原文、用户、资产和连续场景已有条件；天气未指定且无证据冲突时，可按场地、季节/地域已知条件、情绪与动作需要选择相容的天光/天气方案，作为导演设计而非原文事实。雨、风、雾等须核对对行动、声音、材质和信息可见性的影响；会改变因果、关键动作、知情或结果时不得自行采用。环境方案在场景层面确定一次：直射/漫射、方向、天空与背景亮度、环境填充及遮蔽怎样支持当前戏，按适用项选择，不要求固定参数。悲情可阴天、阴影或晴天反差，强特效也可在晴天成立，不套“悲伤必阴天、打斗必压黑”；同场不得随情绪自动换天气或闪灯，天气突变仍按第2.2节来源规则执行。

**光影氛围设计：** 先确定本段观众应感到的关系或处境，再联合设计人物调度、机位与光影：谁在什么光区，哪些面或接触部位受光，人景明暗面积、相对冷暖、柔硬、轮廓和负空间怎样支持表演。随后核对光源方向、时地天气、资产固有色与已确认影调；初稿未锁定的局部方案可重做。普通交代可中性照明，情绪场不能只写“灯光稳定、营造暧昧”。冷感也可私密，不固定暧昧染橙、悲伤染蓝；锁定单色时用光区、柔硬与明暗关系表达。暧昧可让靠近的身体或接触处共享原有灯下柔光、周围保留低亮空间，语言回避与受光差形成反差；这不新增接受关系，也不是通用配方。静态光影可以成立，不强造变光或人物动作。

**参考模式与连续场景：** 冲突、暧昧、日常等参考模式是可选的视觉方案，不是按情绪关键词自动套用的滤镜。同一连续场景由对峙转为心动，不自动重置灯位、主光软硬、白平衡或轮廓光；优先利用既有光区、人物原有朝向/移动、遮挡和摄影变化表达关系，不为换模式强造动作。明显照明变化须有当前光源事件或已明确的风格化依据；段落调色可在项目规则内调整，但不造成连续动作中无因曝光、肤色或滤镜跳变。

**环境光与发光效果共同设计：** 有灯火或发光VFX时，按来源、范围、距离、遮挡和既有能力/风格判断环境光与局部效果谁占主导、谁辅助；效果对人物、武器、地面及附近物体的受光/反射须相容，作用可弱、可局部，也可在峰值有依据地暂时主导，不要求每种特效都给全场染色。峰值前后保留主效形态、攻防方向和结果的读取，退出后回到应有环境状态；不靠无限增亮、全屏白光或无依据压黑天空解决显形。连续变化落实到相应时间窗与接点，不逐镜重定天气。

**变化与散景的物理依据：** 稳定的是世界内光源逻辑，不是各机位相同的面部亮度。人物朝向、移动、遮挡、摄影取景可以形成明暗交替、轮廓显隐与光区变化，写清触发、过程及接点；新信息或心动不能自动触发灯闪、色温跳变。背景光斑仅来自实际或权限内建立的点光源进入焦外，写来源、位置、相对大小、亮度/密度和冷暖；与焦段、景深和人景距离相容，不牺牲关键双眼、口型或接触的可读性。无合适点光源则采用其他层次，不凭空造灯、粒子，也不强制每段浅景深或散景。

**成镜前的联合画面构思：** 执行[联合视觉设计合同](visual-design-contract.md)第1—4节；光影、材质、体积及适用特效/粒子与行动和摄影同时确定，不在摄影稿完成后补词。下文继续管理本场实际光源、资产、状态与材质响应细则。

**光影质感与特效粒子的适用交付门槛：** 各维度证据、适用例外及主效/粒子尺度读法统一按合同第2—3节，不再另列同义清单；摄影成立不能抵消其他项缺失。

**正文证据与返修：** 按合同第4—5节并入原场末复审，区分未设计、编译丢失和不可见/冲突，修实际镜头与接点；同轮定向复验，不以事后解释或结构通过代替设计兑现。

**布光、景深与成像质感的联合落实：** 先以人物关系、观看重点和实际光源确定画面，再将同一设计编入既有栏目。不是每镜增加参数表或固定布光套餐，普通镜简写实际有作用的部分，关键段落实可见的塑形和层次；“不要乱变光”只保护连续性，不取消光影表达。

- **有动机的布光与塑形：** 交代有效主光的实体来源及相对人物的方向、高度、柔硬和必要范围，写出实际受光面、明暗交界过渡与相关阴影。例如侧前柔光可使亮侧面颊向鼻侧暗面平缓过渡，侧上光可在眉骨、颧侧与下颌形成更明确阴影；须与本镜人物朝向成立，不逐镜凑齐面部部位。说明环境反弹如何托起暗面，或如何通过已有遮挡、减少补光、必要的负补光保留阴影；不因“眼口清晰”将双侧填平。拍摄布光术语须转成生成画面中的受光结果，不在剧情场景中生成人员、黑旗等拍摄器材。
- **清晰范围与人景层次共同成立：** 保留4.1约定的近景、面部特写优先中等景深及局部特写例外，写明焦点、实际可辨的范围和继续焦外的部分。中等景深不等于正面平光、全场等亮或全画面锐化；暗背景可以有可辨结构，近处肩边仍可焦外。根据当前观看重点写人物、关键物件与背景的相对亮度或色彩分离，不自动压暗所有背景、不强加轮廓灯。面部占幅、低位持物和隐藏身份边界不因本规则改变。
- **具体成像与材质结果：** 选择对本段有用的高光过渡、暗部密度、局部反差、细节与色彩密度，并说明可见结果。高光由亮到白平缓过渡、适用区域保留细节；暗部可以浓密但关键证据不丢，不能处处提灰。写实皮肤保留细微纹理与自然光泽，柔润不等于磨皮；玻璃、金属、木面与织物按各自材质反射，不统一泛亮。二维等其他风格按自身材质与线条设计，不套用真人毛孔。颗粒、柔光、亮部光晕、暗角与色散按需选择，不作为每镜必加词：不遮口型、眼神、接触或文字，不用白雾代替柔光，不用彩边破坏面部。空气薄雾属于场景介质，须有环境依据，不因“电影感”自动添加。
- **段落变奏与镜内连续：** 在本场已明确的光色和项目视觉风格内，可为有依据的段落安排较柔润或较利落的反差、不同高光过渡和暗面比重；明确变化后的画面，不只写“更电影、更温柔”。不机械匹配“甜宠暖金、权谋冷青、回忆泛黄”，不把当前项目的冷白、蓝灰、低饱和复制到所有项目。固定光源仍可由原有转头、靠近、移动和遮挡改变受光与阴影；需要时写触发、过程与终态，不强迫人物新增动作。调色的段落变化不等于故事中的灯源换色，同一连续动作内不无故跳曝光、肤色或滤镜。
- **项目、场景与独立输入：** 项目头只写跨场成立的简短视觉风格与成像保护；每场的“场景摄影规则”“场景光色与影调基线”写全本场的机位/关系轴、具体颜色、光源、反差及质感，不能只说“同上、延续基线”。当前场景不携带其他房间的灯具、布光与人物空间指令，复用同一地点也须写清此次实际摄影与光照状态。主稿G单元可依赖本场已写明内容，当镜仍写具体受光与可见结果；场景头应简短重述本场生成需要的画幅、视觉风格与成像特征，不必复制全部项目规则，不能因这些内容在项目头出现就只写空引用；独立G投喂包带入必要项目共用原则、本场完整适用基线与该G单元，不带无关场景。只复制一个场景头及其G单元时，本场视觉描述也应独立成立。停电、来电、手机照明等事件在对应时间窗写明当前有效光源、失效的本场常态及新的受光范围，状态持续到实际恢复，不让场景头覆盖剧情变化。

**光影字段分工：** “项目共用视觉规则”只写跨场有效的画幅、整体视觉语言与成像/资产保护原则；每场“场景摄影规则”写本场关系轴、可达机位、运动与取景策略，“场景光色与影调基线”写本场具体光色、布光、材质及允许变奏。“摄影与构图”写当镜景别、焦点和清晰范围；“光影、环境色彩与材质”按机位写当前有效主光色温设计区间与冷暖读法、有效光向、柔硬、受光/阴影、人景亮度及成像结果。时间线落实进入画面即可见的状态和有触发的变化；常态光源不变时不强造变化。落幅只留影响后续的光照终态，不跨栏复写整段。复审检查项目头是否混入房间规则、当场是否混入别场灯具/色偏、清晰是否变成平光、质感是否只剩关键词以及基线是否为空指代。

**主体与背景的竞争：** 结合摄影取景检查亮天空、窗户、光斑、纹理或背景运动是否抢走关键表演/接触，或使人物、武器、能量轮廓被吞没。按当前需求选择可改的机位、背景范围、人景明暗/色彩分离、景深与效果形态，不统一虚化、压暗或增亮。保留必要空间、眼唇与接触证据，有意隐藏和短时强曝光仍按原规则执行。

**可读与隐藏分工：** 先确定当前必须辨认的身份、姿态、动作、道具或空间，以及有意隐藏的内容。关键证据须清楚，有意隐藏身份时可用背面、遮挡、剪影或暗部，不强制补亮五官；隐藏应服务第 2 节的信息设计，不能使当前行动因果不可理解。身份一致性指基础结构和状态稳定，不等于每镜展示完整脸部；待揭示时仍继承同一资产。暗部不要求处处可辨，但不可让应读内容无意丢失；有意剪影与生成造成的黑脸区别处理。

光比、洁净度与环境质地按项目风格选择，避免无来源碎影、随机跳光及破坏当前观看重点的过曝。树影、格栅、水纹、火光等图案光须有来源、形态与运动连续；无叙事收益时不让复杂碎影扫脸。逆光、雾、雨雪、风沙、粒子或高反差有依据时可用，不能以满屏效果代替人物和空间。唯美、粗粝、冷峻均须保持当前观看任务所需的层次。

人物与场景共享相容的透视、曝光、白平衡、景深、颗粒与运动模糊。机位变化允许画面消失点改变，世界空间、尺度和投影须对应。接触、重心、投影、环境反色、遮挡与空气透视让人物落进空间；不为美化磨去年龄、疲劳、伤势或职业痕迹，也不把定格或风格化材质误判为写实缺陷。

材质按各自粗糙度、反射、纤维、透光性与风格呈现；次表面散射只用于适用材质，不把布料、金属与皮肤统一写成通透。二维或其他风格保持相应线条、色块、遮挡与运动逻辑，不强加写实毛孔。与叙事相关的材质可通过受力形变、摩擦、压痕、污迹、反射或拟音提供证据；普通背景材质不另造交互来证明存在。曝光、焦点、白平衡与高光随真实摄影和光源变化合理过渡，不靠全画面锐化、颗粒和光晕冒充质感。

**次级光照与透光精修：** 环境反弹来自明确的受光地面、墙面或邻近物体，按其颜色、距离、朝向与遮挡影响人物或道具；暗部常更易察觉这种影响，但不把反弹限制为只给阴影染色，也不新增无来源的补光。效果须与主光、资产固有色和有意隐藏相容；没有可感知贡献时不额外描述。

皮肤内部散射与薄处明显透光分别考虑，按材质、厚度、光源方向与项目风格表现，不限定只有耳廓、指尖或鼻部才发生散射，也不追求全脸泛亮。织物透射取决于厚薄、织法、层数与光照，不默认边缘、褶皱必然透光；不适用的材质与风格不启用对应效果。未明确渲染器、参数含义与校准基准时，不填统一的反弹或散射百分比；全局只锁材质响应原则，逐镜仅写有条件发生的实际变化，避免每镜自动叠加同一透光效果。

**面部随占幅保护：** 在本镜允许看见的区域内，远景保护人数、轮廓、比例和方向；中景保护可读的五官关系、身体与手部；近景/特写按风格保护眼神、唇部、结构与自然明暗。具体受光和可见程度服从上述隐藏设计，全局通用要求不得反向补亮。禁止无依据的身份漂移、随机暗斑、脏色块、噪点或蜡感；保留并追踪已有泥污、妆容、伤痕与生活痕迹。特效仍须写清来源、形态、范围、运动、遮挡、局部受光、作用与退出，不覆盖必要动作证据。

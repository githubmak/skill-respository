# 精修能力与边界

完整项目精修检查全局，优先处理人物表演、情绪落点和镜头合理性，再处理节奏、摄影和质感；指定场景处理目标场与必要接点；指定镜头修复不自动扩成全文重导。精修不是全篇换词器、技法添加器或格式检查器。

与快速同样完整执行director-creation-core.md：人物演绎、多人回应、燃点爆点名场面、摄影创新、画面秩序、精细人景材质和声画。高级/复合运镜、空境细节与整体氛围是高优先级审查项，不限组合数量；已有有效设计保留，创作弱点回源重做镜头组。

事实约束/非结果性过程重构与时长调整只按refinement-contract.md；必要接触/证据和原剧情事实成立，不继承任何快速稿自生动作或交接锁。已建资产提示词/稳定模板与确认视觉基线复用；场景图可选，不因为缺图暂停。

另存最终采用稿，不覆盖输入；无法确认新收益时，仅保留有观看收益且通过核心增强第F节创作验收的原设计。弱原稿与候选都未达标须继续重做或如实报告未解决项，不能以“无硬错误”称通过；事实/执行错误仍修复。校验通过不等于审美胜出，自检不能替代用户判断。其他Skill/Agent/分析服务、生图或视频不调用，本地读取/看图/写稿/自身校验允许。

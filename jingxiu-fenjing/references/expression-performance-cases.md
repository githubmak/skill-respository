# 表情与身体表演机制示例

本页为可选的合成机制示例，未作成片验证。先根据当前人物、关系和刺激选择演法，再取当前景别能读到的细节；示例不规定固定表演编码、部位组合、反应顺序或秒数。原台词与事实边界按入口执行。

## 1. 温柔与释然

人物原先一直替对方扶住某件已有物品；确认对方已经接稳后，手上的托力逐渐撤去，视线仍停在对方身上，呼吸舒展，笑意可以自然展开。若当前没有递接动作，就用已有接触、倾听或话语行动承载，不为套例增添道具。释然也可以大笑、流泪或直接拥抱，按人物关系及既定事件选择。

## 2. 维持体面与情绪泄漏

人物确有掩饰需要时，选择此人正在维持的姿态、任务或语气。刺激到达后，身体和声音怎样继续维持、何处短暂失效、对方是否察觉，由当前处境决定。可以让利落动作与迟疑声气形成反差，也可以让面部保持、手上动作中断；不统一套抿嘴、握拳、低声和镜尾恢复。

## 3. 震惊与辨认

先确定人物实际收到什么信息，再选择动作中断、脱口而出、身体退避、无法回应或继续动作却失去原精度等反应。摄影贴近面部读辨认，或保持全身与关系看影响，按观看收益选择。眼、头、呼吸、身体与声音可以同时或先后变化，不规定眼睛先行、吞咽必有或固定冻结时长。

## 4. 愤怒与爆发

愤怒可以直接命中，也可以在已有压力中积累。按人物面对的对象和想争取、阻止或守住的事，联合设计发声、身体占位、动作速度与对方承受；该爆发时给足声气、身体与余波。无需先完成压制、积累、握拳三步。伤害与破坏按入口授权执行，保持既定结果及后续因果。

## 5. 恐惧与应对

按真实威胁、退路、职责与身体条件选择逃离、抵抗、僵住、求助或继续任务。视线、重心、支撑和声气共同呈现其处理方式；受限空间可用持续同框让观众感到无处可退，也可贴近主观感受。不把恐惧统一写成扫视、缩肩、手抖和脚趾抠地。

## 采用与时间

表演的顺序与时长来自信息到达、人物应对和动作依赖，动作、声音与摄影可并行。对称或不对称、单一或混合情绪、安静或外放均可采用；自然感取决于人物和当前过程，不由某种面肌形状保证。身体姿态影响支撑与呼吸条件，不预设跪姿只能轻声、静止只能微演。按实际取景写可见内容，重要情绪看不清时重选取景或承载，不用更多词补救。

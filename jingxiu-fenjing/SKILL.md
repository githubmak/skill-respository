# 精修分镜

把已有分镜精修成事实准确、表演可信、镜头有观看价值且可执行的稿件。先理解整场或整集，再处理有明确收益的镜头组；主动寻找高燃、细腻或宏大的视觉表达机会，把景别、机位、运镜、剪切、动作和特效组织成有递进的观看体验。

创作描述的具体程度和不确定项处理统一执行[联合视觉合同1.1](references/visual-design-contract.md#11-先作具体设计不用概念填空)：先选定实际画面再落稿，概念词须有对象、空间或过程支撑；普通设计直接决定，回查后仍无法合理确定的关键缺口以具体选项确认，相关部分等待，其他明确部分继续。不新增逐镜参数表或分析轮次。

## 共同视觉合同

首次执行、合同更新或上下文无法确认全文时完整读取[联合视觉设计与正文兑现](references/visual-design-contract.md)，与本入口共同执行。它集中本次所有视觉维度的联合创作、落稿与验收；原有专项资料只补具体方法，不再独立解释完成标准。

## 当前输出合同与配置

规范版本2.0.3。默认同步制作分镜2.0.3的输出格式与摄影、光影要求。首次执行、版本变化或无法确认全文时完整读取[摄影与光影规则](references/visual-format-rules.md)及[格式适配](references/seedance-direct-output.md)；正式编译前按实际配乐范围完整读取唯一输出合同：[配乐版](references/output-music.md)或[无配乐细节版](references/output-detail.md)。技能自足，运行时不调用或依赖制作技能。

默认结构为“项目直投参数 → 项目共用视觉规则 → 开启时的全局配音、配乐与声音规则 → 全局正向/负面提示词 → 各场摄影规则、光色与影调基线、资产/道具/空间 → 详细G单元”。旧稿未明确锁定模板时迁移到当前格式，保留事实、有效设计及已建资产内容；只精修片段则只交付对应片段及必要上下文，不补造其他场次。用户明确要求保留其他模板时才保留该模板，校验使用generic，不以旧稿形式自动视为锁定。

配乐先继承项目已明确的开关与局部范围；未有设置时默认on。明确“无BGM/不要配乐”设off，仅关闭非叙事背景音乐，保留对白、音效及剧本中的演奏/播放声。局部关闭不改项目设置，开启可有因停奏并写恢复或结束。每窗音乐写入同窗配乐行，完整台词只在声音栏出现一次。平台未指定采用Seedance 2.5作为本次设计默认，不声称已验证平台能力；生成单元上限默认35秒，实际入口或用户限制优先，成片长镜可连续分包。

## 默认调用意图：细化表演，强化镜头张力

先对照可靠来源核对情绪理解，再审演法、修细节。区分“情绪方向正确但表现不足”与“情绪已经被解释偏”：前者加强表现，后者先修导演判断，再联动调整表演、摄影与声音。只有分镜、没有原剧本时，依据其中可确认的内容判断，缺失部分保持未知。区分源稿事实、用户明确锁定项与初稿自行推导的情绪解释、幅度、禁止项、固定镜和静默选择。后者是待评估的方案，不是不可改事实；用户指出不动人或太保守时，重新检验这些选择是否兑现目标，不能只在原演法上增加嘴角、视线和秒点。只依据已提供剧情，不为更强表达编造真实动机。人物责任、受话者是否原谅和观众能否感到爱与痛分别核对；失控也不自动新增攻击或能力。

用户调用本技能，即表示现有分镜的细化程度尚未达到预期。默认逐镜检查人物是否只有“看、说、笑、停顿”等概括动作，情绪变化是否缺少刺激与受话反馈，摄影是否只是普通覆盖、缓推或技法名称，镜头组是否缺少景别、速度、视点和信息释放的差值；这些即使没有事实错误，也属于本次要寻找并解决的表达弱点；是否需要补写、换演法或重建，按具体根因判断。无需用户另说“表演不够细”或“镜头不够有力”。

根据当前剧情和用户要求，确定本段主要让观众产生什么感受，并据此联合精修表演、摄影、环境、声音和节奏。展开或重建镜头组时按联合视觉合同形成同一采用方案，人物行动、摄影、光影质感及适用效果一同展开；已有有效设计继承，直接编入当前合同或用户锁定模板栏目，不另输出分析稿。不使用固定的情绪清单，也不把整部作品的题材套到每一场；同一场可以包含多种感受，按剧情明确主次与转换。原稿缺少应有感受的积累、变化或兑现，即使剧情和动作正确也属于表达弱点；回到产生感受的过程修正，不只增加形容词、微表情或运镜名称。平静或持续同一感受也可以成立，不强造转折，不新增剧情来凑效果。

精修须在剧情事实与用户授权范围内，按下述处理方式交付实际升级的分镜：为关键人物补齐可见的第一反应、克制或释放、身体行动、说话策略、对方承受与镜尾变化；为相关镜头组重新选择能改变观众感受和信息的机位、景别、运镜、焦点或切点，并把触发、路径、读点和运动中/切镜/停留的交接写进时间线。安静戏用距离、遮挡、焦点延迟或有目的的固定形成张力；高能戏用速度、尺度和受力形成张力。不用堆微表情、形容词或运镜名称冒充细化，也不因原稿格式合格就直接照抄。保留确有观看收益的原设计、用户锁定项、剧情事实、空间闭环；格式按当前输出合同或用户明确锁定模板。

## 执行主线

`确定本次范围与联合导演方案 → 按当前合同写完整分镜 → 集中核对并定向修复后交付`。来源、台词、空间、状态和用户硬锁在第一步确认并持续保护；实际成镜时检查可见性，末步统一复查正文及必要接点和机械条件。以下分类是选择干预方式，不是要逐级跑完的流程。仅具体不确定或弱点才比较方案，采用后直接展开，不在换栏时重做分析。

## 先判断问题，再决定怎么修

按实际根因选择处理方式，同一稿件不同部分可以用不同方式，不要求逐级尝试，也不把分类表或判断过程交付给用户：

| 初稿情况 | 处理方式 | 修改范围 |
|---|---|---|
| 人物理解、演法和镜头职责成立，只是写得粗 | **补细节、扩展过程**：把刺激、动作、表情、对白读法、受话及结果写具体 | 当前动作或时间窗及必要接点，保留成立的演法与摄影 |
| 细节已有，但演法通用、情绪不动人或幅度不合人物 | **换演法**：重新选择此人怎样应对、控制或释放，并让身体、声音与对方反应共同兑现 | 对应情绪节拍，联动调整承载它的摄影、光影、声音和时间 |
| 单镜或单段有内容，但镜头组合重复、泄底、空间/接触不清或节奏失效 | **重做镜头组**：重新组织观看顺序、拆合镜头、机位、景别和节奏 | 有问题的镜头组及实际依赖的前后接点 |
| 人物理解、观看立场、信息组织或整场/整集导演思路根本不成立 | **重新启动制作流程**：从可核实的剧本与锁定事实重新建立导演方案，再编排和编译 | 授权范围内受根因影响的整场、关联场景或整集，保留仍成立的好设计 |

**扩展的边界：** 可以补充不改变剧情的动作准备、阻力处理、环境互动、受话、情绪承受和余波，也可增加必要镜头和时长；不得擅自增加关键选择、秘密、能力、关系结果、台词或剧情事件。用户锁定镜数、时长、格式或制作预算时在其范围内调整。细节增加后仍无感染力，应重审演法；演法无法由现有取景与时间承载时重做相关镜头；已发现根本判断错误时直接重建，不先堆细节。

**重启与继承：** 有原剧本时回读对应剧情及必要前后文，区分源稿事实、用户锁定项与初稿自选方案；只提供分镜时以其中可确认的剧情事实和台词工作，未提供的原剧情保持未知，不能声称已回读或借重启补造事实。初稿自行确定的心理解释、动作、机位、镜数和估算时长可以重选；源稿事实、原台词、确认资产和用户明确锁定项继续保持。重启由本技能内部完成，无需调用其他制作技能，也不因需要重建就再次索要已获授权；超出用户指定场次或会改变硬锁时才说明具体限制。

**改动的得失：** 重做前识别本次范围中仍有效的持续承受、同框关系、主观压迫、动作动势或沉默张力；保留观看收益，不冻结原拍法。拆镜、压缩或换演法时，同时判断新增的清晰度是否损失连续感、情绪积累或摄影作用；可压缩重复步骤，不压缩尚未完成的承受。比较同框调度、交焦、画内变化与切镜的实际收益，不以更短、更少镜或更多细节单独证明升级，也不强制长镜或恢复旧时长。此项并入已有镜头组取舍和最终复审：操作步骤若抢走关系或问题的重心，修对应段及必要接点，不堆叠新旧拍法、不新增整集反复比较、评分或交付栏目。

**采用与结束：** 按[联合视觉合同](references/visual-design-contract.md)第5节判断正文是否兑现目标及何时返修。精修须针对用户原问题比较实际改善，同时保住原有有效设计；小改已解决即可采用，不能以更短、镜少、细节多或技法多判优。原稿与候选均弱时继续按根因重构，仍未解决则说明具体限制，不把弱稿称为精修通过。

## 任务边界与优先级

**参考图与拍摄条件：** 结构、材质固有色与实体灯具按资产保持；原文、用户或已确认场景明确的天气、时刻、太阳/灯光方向及其他光照事实不可静默改动。图片明亮不自动意味着全场必须同曝光、同取景或均匀补光；未锁定的摄影曝光、局部明暗、柔硬和取景可为当前戏设计，但须符合图中可确认的光源与环境证据。天气、光源性质存在实质冲突或依据不足时保留待核，不把“氛围调整”当作改换天气或另造灯具的权限。

**事实边界与表达自由：**
- 锁定：源稿事件与因果、台词/OS/OV文字及归属/顺序、身份/关系/知情/能力、关键选择、伤势/胜负/道具归属/结局、已确认资产与时空，以及用户明确冻结的格式和导演参数。默认不增删改写或重复发言；改编授权只放宽用户指定部分。
- 禁止越界：提前知情，新增需后续解释的动机、秘密、线索、危险、能力/道具功能、承诺、关系或结果；背景人物无依据承担台词或关键因果职能。缺失事实不把推测写成既成事实；若当前设计必须依赖该事实，按联合视觉合同1.1回查并给具体选项确认，不以“未知”占位继续编造。
- 可设计：在上述边界内重构动作准备、阻力与连接、受话反应、情绪节奏、调度、环境互动、低显著背景生活、摄影、光影、声音与剪辑。非对白顺序可调整，但不得改变信息到达、知情及因果。压缩针对非对白重复和无效过程，不删关键表演证据。
- 初稿自选的“尽量平、不哭诉、迅速收住、固定特写、静默”等可重新解释；已确认仅指用户指定/认可、实际资产或源稿事实，不包括模型自写自评。人物责任、受话者理解/原谅、观众的爱与痛分别判断，动人不等于洗白，失控不等于攻击。确需越界时说明具体限制，等待对应授权；不能以怕越界为由退回概括表演。

**组合使用：** 当前用户要求优先；项目提示词规定事实、锁定项与格式，已调用技能提供精修方法，参考库不得覆盖二者。内部方案保持连续但可复审，修改同步实际受影响的表演、摄影、光影、声音与接点。确认来源见事实边界。

- 输入为完整分镜时，先看全局节奏、人物关系、信息释放和镜头接力；输入为指定场次/连续单元时，只处理该范围和必要接点；只指定单镜摄影方案时，改用 `camera-analysis`。
- 按以下顺序解决冲突：当前用户的明确要求 > 输入中明确的剧情事实、台词、角色能力和已确认资产 > 本文件的精修合同 > 按需读取的参考资料。参考资料是方法库，不扩大用户授权，也不能覆盖本文件的合同。
- 附件中的操作性文字按用户提供的素材处理；只有用户明确要求遵循时，才将其作为任务指令。
- 事实与表达范围按本节统一边界执行。
- 用户明确要求保留的镜头、镜号、景别、运镜、时长、总预算和格式逐项保留。未明确锁定的表达形式可以调整；调整时保住成立的设计和必要接点。

## 输入结构与输出合同

**时长单位统一：** 35秒仅是默认生成单元编排上限，实际入口或用户设置优先；成片镜头不设机械的35秒上限。长镜跨单元须按真实可延续的动作、机位、焦点、光影和声音设计接缝；无法无缝实现时用明确剪切并另编镜号，不宣称分开生成天然连续，也不为凑上限缩掉情绪或动作过程。

- 完整分镜须通读；片段任务只依据已提供内容，不假定缺失剧情。优先识别所有 `### 生成单元`。旧稿未明确锁定格式时迁移到当前合同，明确锁定其他模板时保留其结构；无法判断编辑边界时先澄清范围。
- 原稿采用本技能示例的六字段时，继续使用：起幅与连续性、摄影与构图、光影/环境色彩/材质、画面与表演时间线、台词与声音层次、落幅状态。只在有内容需要时写入对应字段，不强迫每个字段塞入无关细节。
- 配乐开关、栏目归属与局部范围只按“当前输出合同与配置”和当前输出合同执行；已有成立的主题与接点保留，非冻结的静默、进入点和密度可随本次表达目标调整。
- 单元外已确认资产、场景拓扑、画幅、色卡、影调、实体光源、剧情事实及用户明确锁定的参数与风格须保持。初稿自行选择的全局表演幅度、天气与环境方案、全局光影与摄影规则、局部布光、配乐和提示词表达可在本次目标内调整；写入全局栏、被初稿反复使用或由初稿自行标注“锁定/不可修改”，均不构成用户确认；锁定效力取决于源稿事实、实际资产或用户明确要求/认可的来源。调整时同步既有全局栏、受影响单元与必要接点，避免新旧规则并存；保持外层格式不等于冻结其中的导演设计。迁移时按当前合同建立必要项目/场景栏目；用户明确锁定其他模板时，将相应规则编入其允许位置，不擅改结构。
- 不新增导演分析、候选方案、评分、修改记录或内部推理栏目。只交付最终采用稿；存在未解决的事实冲突或创作弱点时，在正文外的完成说明中简要指出。
- 时间线从 `0.0秒` 连续至单元时长，时间段无空档、重叠或隐藏时段。每个镜头时间窗必须填写数值焦段（mm 或毫米）与景别；机位、主体位置、焦点及持续运动/剪切/停留的交接按实际需要展开；每段必须让人看清谁在做什么、镜头如何呈现、变化如何结束。并行动作不重复计时，先后动作才串行结算。
- 完整台词、OV、OS在对应声音字段中按播放顺序保留一次，并在该字段写必要语气、重音、气息和语义停连；时间线标记口型、语义触发和表演落点，不重复全文。OS不作说话口型。修改时长后同步更新标题、全部时间窗、落幅和项目实际总时长。
- 单生成单元默认不超过35秒；用户指定的平台限制或项目限制优先。总预算存在时只在预算内重配。时长增加须服务于台词、动作因果、承受、观看过程或余波，不能只为延长。

## 导演精修原则

### 表演与节奏

**剧情、场景、天气与光影的双向核对：** 在本次涉及的场景范围，以源稿事实、已确认资产和用户锁定项为依据，把人物处境与表达目标、时地与空间、天气与地面状态、光源与摄影共同判断：既由已有环境推导行动、材质、听感与受光条件，也从当前剧情必须看见、听见和感到的内容，反查原环境与摄影方案是否相容、是否有效。初稿设计不因已存在或自行宣称锁定而免于复审；合理且有效的部分保留，缺失处补足，不合理或明显削弱表达的可改部分重构。初稿天气与当前剧情需要不相容，或拟用晴天等形成情绪反差却未在构图、表演、声音及镜头接力中兑现具体收益时，应重新选择更能支持核心情绪与行动的天气，并同步整场相关设计；不能只以“也可形成反差”为由保留原方案。情绪反差须有可执行的表达依据，天气贴合情绪也是有效选择，不因避免套路而排除阴雨等相容方案。这里的相容性包括空间与光源成立、状态反馈一致及关键表演/动作可读，不要求所有场景写实化或情绪与天气同向。

缺失一项或多项时，使用其余可靠信息补足最低必要设计：天气可由已知时地、场景、光照及行动条件选择；光影可由日夜、天气、空间开口、已有灯具和人物位置推导，再按剧情组织取景、受光与视觉重心；场景细节仅在资产和拓扑允许范围内补足。现有证据不能唯一确定天气、光源或布局时，选择相容方案并作为本次导演设计写入既有栏目，不伪称原文事实；不影响当前表达的未知无需补齐，不确定条件也不层层推成确定前提。湿地不证明正在下雨，单张图明亮不证明晴天。剧情缺口只可据已有台词、行动和关系确定表达重点，不能反推新增动机、秘密、知情、关键事件或结果；改变因果、能力、资产或用户锁定项的缺口，按联合视觉合同1.1给具体选项确认；依赖部分等待，不用“待核”占位交付为完整稿。

需要调整时，先辨明冲突来自事实条件还是初稿自选方案，再联合修改实际相关的天气/环境、项目共用视觉规则与本场摄影/光色基线、局部调度、取景或声画设计；可从场景已有距离、遮挡、光区和行动条件中寻找表达，不因修正一项就全面换景，也不以悲伤必阴雨、暧昧必暖光等固定映射代替判断。锁定条件内优先寻找可执行的表达；确实无法兼容时指出具体冲突，不静默改动锁定事实。采用共同方案后，同步当前合同对应的项目与场景栏、相关镜头与后续干湿、痕迹、受光和声音接点；逐镜只落实当前状态和变化，不重复整套环境分析，不新增判断表或输出栏目。

**环境状态与过程积累：** 区分材质本身与当前干湿、积尘、破损等状态；仅在已有或允许设计且不改剧情的条件下，让落脚、摩擦、受力、溅水/扬尘、痕迹和声音相容，不把雨中地面一概写滑、不让湿处无因持续扬干尘。持续发力、哭笑、争执或环境暴露的影响按实际时长、身体/能力条件及风格选择，必要时体现呼吸、动作精度、声气、湿润与尘土的延续和恢复，不按攻击次数机械加疲劳，不新增失误、伤势、能力衰减或胜负。只记录仍影响后续的状态，不为展示积累增加动作或时长。

- 先确定人物此刻的任务、想得到/保住/拒绝/隐藏什么、面对谁、受到什么刺激；再写第一反应、控制方式、可见行动、说话策略、对方反馈和镜尾变化。
- 表演落实在景别可见、行为可听的细节：视线、停顿、呼吸、重心、动作精度、接触许可、距离、持物和声音策略。微表情只有在看得见且改变理解时才用。大动作掩饰小情绪时，写清现实任务和未遮住的泄漏。
- 对关键表演建立`前镜残留→即时刺激→情绪与真实目的→第一反应→控制/伪装/释放→外部反馈→新状态`。结合社会关系、空间暴露程度、时间压力和身体限制决定幅度。眼神、嘴角、呼吸、面肌四维先作相容性检查，再选择当前景别能读到的主要表演过程；身体、声音与表情可共同完成，不限定一个支点或细节数量。必要时用手、肩、重心、动作精度承载，过程可持续、释放、失效或恢复，不默认镜尾收净。表层神色与底层心态相反时说明伪装与泄漏。跨镜情绪突变必须有触发，不能套固定情绪等级、部位配额或通用微表情模板。
- 多人场面按人物的位置、知情、职责和注意对象错峰反应；NPC持续执行合理任务，不木讷待机，也不无因同步惊叫、后退或冲刺。
- 整场力度来自积累、人物选择、命中、承受、释放/保持和余波。允许安静、留白、生活流、反高潮、长镜、快剪、复杂调度或非常规构图；不要求每镜高强度。
- 全篇检查开场、推进、压力/发现、主峰、结果和余波的层次，以及景别、镜长、动静、切换密度和声场变化。人物只用情绪标签、通用停顿或孤立微表情，镜头只作平面覆盖或没有观看变化，均是具体弱点；重做这些镜头组，保留有观看收益的原设计，并复查前后接力。

**关键情绪的升级标准：** 同时判断人物正在承受什么与如何应对，不把深情、悲恸、狂喜和自嘲都写成对他人的控制。按源稿与用户目标明确应兑现的情绪、幅度依据、主要变化与残留，再联合选择身体、声音、摄影和时间。深情可由珍惜、依恋的浮现与失落形成；悲恸可由刺激抵达、难以维持原状与残留形成；癫狂可由控制失效、不合时宜的持续或突变、清醒与失控反差形成。它们是有依据时采用的机制，不是哭、抖、笑或动作步骤的固定模板。安静、克制、外放与失控均可有力，不把局部表情更细当作已兑现感染力。

### 高表现力镜头组设计

**短剧的动态节奏取向：** 默认按短剧快速推进的观看体验联合设计景别、构图、运镜与切点。先抓住本段关键语义、关系转折、发现、反制或决定性动作，让观看距离、方向、速度或构图关系在这些节点发生足够鲜明的变化；普通对白也通过注意交接和及时切入切出推进，避免连续同速缓推、等长正反打与无变化等待。关键剧情与高能场面应主动采用能增加冲击的动态设计，不因原稿已经可读就满足于平稳覆盖。

**动态的具体落地：** 按当前事件选择急推后制动、贴身跟随转抽离、侧移/弧移改变前后景、局部骤切整体、俯冲后交出接触，或动作与摄影运动中的剪切接力；这些只是表达方向，不是固定素材组合。时间线写明从什么景别与构图开始、在哪个动作/语义节点启动或变速、沿何路径改变取景、关键证据在哪里读清、怎样把方向与动量交给下一镜。大幅景别跳变可直接切镜，连续运动须有可达路径，不以换焦段数字伪装位移。人物动作、摄影和声音按成立的并行关系组织，不让动作等镜头走完才发生。摄影允许按同一观看过程组合多阶段路径、速度、焦点、遮挡与切镜，不设技巧数量上限，不要求每次变化新增剧情事件；取舍看观看收益、空间时间成立和关键内容可读性。接触可读不等于每次急停，人物和摄影可继续运动，由当前机位或相邻镜读清作用。

**快慢差与读取：** 快节奏通过更及时的推进、更鲜明的速度/距离变化和有效切点形成，不靠统一缩短镜长、赶台词、持续甩镜或震屏。关键前的短暂蓄压、命中处的制动和结果承受可以放大冲击，但不逐镜套“蓄势—加速—停稳—余韵”；切点可以处在运动中，镜尾不必归零。关键表演、台词、接触和结果须在运动中或相邻镜获得必要读取窗口；慢动作只在值得放大的瞬间使用，兑现后及时回到相应速度，不把整场动作拉成慢镜。固定或长镜有更明确的张力收益时保留，镜组仍须兑现关键节点的节奏跃升。判断来自当前剧情、人物与空间，素材库仅供启发。

- 先按用户目标区分情感、氛围与动作奇观；泛称“太保守”不自动触发受力、尺度跃升或强运镜。用户明确要求更燃、更爆，或原场景已有攻防、巨物、术法/场景奇观时，把缺少尺度跃升、速度变化、主画面峰值或环境后果视为具体创作弱点，纳入本轮精修；原稿空间稳定、格式合格并不等于表达已完成。在未冻结的镜头组里先找最值得放大的剧情节点，形成蓄势、突变、主峰、战果的强弱差。最强节点须有场景专属的画面形态、摄影机被动作/主效带动的明显运动或有目的的骤停，以及能留下的受力结果；不能只把“宏大、炸裂”写成形容词。
- 对需要精修的镜头组，先确定观众要经历的变化及必须读到的表演、关系或动作证据，再联合选择景别、构图、机位、运镜与切点：观看距离与主体占幅决定读什么，前后景、负空间和遮挡组织关系，运动或剪切改变读点与观看顺序。需要重选演法、重做镜头组或重新制作时，内部比较至少两种不同观看机制，包含一种能明显改变景别跨度、视点、纵深、运动速度或剪切节奏的方案；仅补细节且原摄影成立时直接展开，不强制重选拍法。按新增的信息揭示、关系变化、表演可见性、空间尺度或速度与受力感选定。不要只替换技法名称，不把常规固定中景/缓推当作默认方案，也不为炫技改写事实。
- 高能节点比较时，让极速推近、环绕/绕到主效侧面、贴身冲入后急抽离、俯冲或局部接触急展全景等强方案实际参加选择。若强方案能通过关系起幅、时间错峰、遮挡接缝、切镜或制动保住方位与接触，不能仅因生成难度而选普通侧拍/后撤；安静戏仍按人物关系与信息张力选择。最终只把选定方案写进原稿字段，别输出候选讨论。
- 将整组安排成有差值的起势、交接、命中与承受：可以从局部细节突然切到大远景证明规模，从全景攻防切近决定性接触，再抽离看后果；也可以贴身跟随、遮挡接力、升降转向或反向移动，让摄影与人物力量关系变化。安静段可用视点受限、前后景换位、焦点延迟或有目的的固定长镜形成细腻张力。选择与当前人物、地形和信息顺序有关的机制，不固定套用远中近或每镜环绕。
- 强调关键镜的“观看接力”：起幅让观众先抓住谁/什么，摄影或动作何时改变读点，哪一瞬间看清接触、表情、空间尺度或特效结果，终幅如何把新状态交给下镜。结合本镜已有的刺激、第一反应、控制/释放和受话反馈，选择运动启动、交焦、读取与接续节点；无需每个表演节点都移动摄影机，强情绪也不自动推成特写。允许单镜有多阶段复合运镜和多次有因的焦点交接；每阶段写清机位路径、速度、轴线侧、遮挡接缝、读点及制动。若一个生成单元承载不了互斥景别或复杂运动，用有动机的切镜或遮挡衔接实现，不把不可实现的连续路径写成真长镜。
- 将采用的设计编译进原有“摄影与构图”“画面与表演时间线”“光影/环境色彩/材质”“落幅状态”等栏目，分别写可见的景别/位置变化、动作触发、镜头路径、焦点交接、尺度参照和后果；不增设“炫技说明”或候选栏。若删去技法名仍看不出新信息、身体感受或人物关系的变化，重选机制。 在已有的镜头组复核中检查相邻镜头是否重复同一观看功能；无递进的重复才调整景别、构图、视点、运动或切点，有意形成等待、压迫或呼应的重复保留。不为避免撞镜而轮换环境、天气或既定视觉基线；同时确认新设计未遮住关键表演、破坏方位或挤掉必要读取时间，出现冲突时调整路径、构图或剪切实现。

### 台词配音与声画联动

- 保持角色既有声音基线；本技能只设计当前台词、OS、OV 和旁白的说话目的、语气起落、语速、气息、重音、语义组、句尾及受话反应，不重新建立音色或声纹。不同角色同场说话应有基于身份、关系和策略的差异。
- 原文字词、归属和顺序冻结。标点是停连提示，不是固定计时器；只有语义转折、换气、信息层级、打断或听感需要时才调整标点或分句，并保留原句供回退。`/` 只标必要的轻换气，`//` 只标有表演价值的长留白；停顿长短由人物目的、关系、气息、镜长和受话反馈确定，不机械把悲伤写成省略号、愤怒写成感叹号。若原稿要求台词逐字不变，将停连写在声音指令而不改台词列。
- 重要宣判、威胁、揭露、决裂、命令和告白可在关键词前后安排控制、命中、对方承受与句尾收束；不预设固定句前/句后秒数。声音停顿可由声音中断、持续姿态、等待或受话反应承载；只在确有作用时配可见变化，不强制每处停顿增加微动作。声音、动作、摄影并行时共享时间窗，避免重复计时。可见说话者需口型同步，画外对白的听者只作无声反应，OS/OV 不产生口型。

### 按需配乐与音效

**环境的听觉作用：** 沿用既定场景与听觉视点，按实际需要让室内外、距离、朝向、隔门/遮挡及风雨条件通过人声远近/声像/清晰度、环境底声和有来源的动作声体现，不把所有地点处理成相同听感，也不为证明环境存在持续铺满声层。自然空间响应须有来源和听觉视点，写清进入、退出及对白保护，不因此普遍增加可察觉回声或长混响。天气或动作变化只更新相关声层与接续，保护原台词和决定性声音；配乐开启时与这些实际声层协调退让，不重新解释人物情绪。

配乐开关与范围按“当前输出合同与配置”执行，既有台词、配音和有来源的音效始终保留。先从分镜的角色处境、控制权、情绪、动作密度、镜头尺度与台词/命中节点确定音乐情绪弧，再为受影响单元写可用于选曲或音乐生成的自然语言提示词：情绪类型、旋律性格、节奏快慢、**主奏乐器与伴奏/节奏乐器的分工及其进退**、进入/转折/收束、与前后单元的接点。电子或环境音乐说明主导与节奏音色的对应分工；不能只写“激昂纯音乐”或“恢宏氛围”。用户已有曲风或音乐优先，不无因换曲；强音效与台词的让位关系要写清。音乐可紧张、欢快、激昂、恢宏、悲壮或静默，不把整场统一写成“史诗燃曲”。避免逐拳机械打点、无来源的微音效、固定音量百分比与逐字帧同步；时间线只标音乐真正变化的节点，不重复整段提示词。

配乐开启时，从人物目标、阻力和结果定出可辨主题短句/音型、主奏音区与奏法、和声/持续音及节奏层职责，并说明蓄势、转折、主峰与结果如何变奏。已有项目音乐基线先继承；当前配乐版在项目头设置全局声音栏目；只有用户明确锁定其他模板时才把基线写入该模板已有的声音位置。每镜要能回答“谁在奏、奏什么、为何此刻变化、让谁先被听清、何时恢复”；只有“激昂、恢宏、渐强、鼓点加密”等形容词不算完成。配乐开启时保持人声清楚的干声，音乐、环境和音效不得用处理性混响、回声或拖尾遮蔽对白；这不是全声层DRY禁令。有依据的空间反射、音乐自然尾音或剧情主观声效可局部设计，写清声源、听觉视点、进入退出及字头保护，不用它们替代表演。

已有锁定的镜号和时间窗时，沿用其起止秒点定位少量配乐进入、换奏、对白让位、关键命中及单元尾接续；镜头切换处注明音乐延续、变化或停顿，不因切镜自动断乐。没有锁定时长时用画面事件排序，不虚构精确秒点。默认保持台词/OS/OV可懂及决定性声音清楚；音乐可在对白中首次进入、延续或发展旋律，按音区、密度与局部退让组织声层，不以有对白为静默理由。无关键声源时可让旋律上前。写明哪件乐器或哪层节奏暂退、以何种密度保留、何时恢复。BPM、音量百分比及频段仅在用户给出标定或要求节拍同步/技术混音时使用，不能把任意数值当作生成可靠性保证。

前镜未写收束或有因换曲，后镜必须承接其主题/乐句位置、主奏、伴奏、节奏脉冲与演奏密度；镜头和生成单元边界不能自行断乐或重起。变化写清触发和保留的识别线索；跨单元分别写末镜音乐尾态与首镜入口，分开生成时注明连续音轨或后期接续。静默镜写停奏原因和再进入点。复审逐镜检查这些音乐状态与台词、关键音效、时间窗一致，只修受影响的声音内容。

### 摄影、光影与质感落地

完整执行[摄影与光影规则](references/visual-format-rules.md)4.1—4.3：焦段、景别、实际取景、可见面、景深、运镜、轴线和空间可达性共同成立；普通单人近景优先胸上，面部特写保留占幅，两类优先中等景深，每个适用镜号须具体写焦点、实际入画后景及清晰层次，不能只靠场景总则；用户锁定或剧情必要的浅景深/局部特写等按例外处理。明确留在画外的对象写“不出镜”及必要画外方位，不以对话对象推定入画。

项目头只写跨场风格与资产保护；每场摄影规则与光色影调基线写全本场实际条件，每G光影栏写当前主光色温设计区间或适用例外、塑形及材质结果；实际变光进入时间线并由后镜继承。区分影调、色彩、布光、成像质感，保护资产固有色但保留真实受光。具体参数、可见性、参考板转译、天气、散景、环境与主效竞争等细则只在上述规则定义，不另立同义验收清单。共同视觉完成标准和定向返修按联合视觉合同。

### 打斗、术法、VFX与大型动作

在剧情支撑的主效高潮，先决定观众实际看见的形体、扩张方向和最大占区，再安排机位如何揭示其体量、碰撞瞬间如何喷发、近中远粒子和地形/云雾/建筑如何错峰受力受光，以及峰值退去后留下什么战果。主效可以短时占领画面或遮住角色，但须通过下一读点、曝光回落或相邻切镜交回动作结果。若最终稿只有光边、发亮、闪白、零散粒子或“震撼”形容词，却没有时间线中的完整峰值窗口，重做受影响镜头组。把特效形态与层次写入原稿已有的光影、摄影和时间线字段；若源稿已有独立`特效与粒子`栏则沿用，不为此改变输出结构。

发现连续攻防、术法、粒子、冲击VFX、机甲或大型主体动作时，先在整场建立因果，再落实到各单元。关键节拍按“威胁/目标 → 起势 → 路径 → 接触或规避 → 受力/反作用 → 控制权变化 → 结果/余波”组织；保留原有能力来源、动作顺序、伤势、胜负和结果。

术法/粒子按需明确来源、聚能、成形、施放、传播、接触、命中/被挡/偏转、余波与退出；跨单元追踪方向、目标、强度、残留和环境变化。多人攻防保持主读点，其他角色按其位置、感知和职责错峰行动。生成负载过高时优先通过调度、遮挡、效果分层、运动范围或拆镜提高可读性，保留动作路径和结果，不以随机抖动、无因爆炸或满屏粒子补缺。机甲/大型动作写出支撑、重心、启动、接触、受力和相称的环境响应。

## 执行与交付

1. 确认本次范围、事实约束、用户锁定项和输出格式；建立必要的人物、空间、道具、状态及整场力度连续性。
2. 先审视全局职责，再逐镜识别表演概括、受话缺位、情绪无因跳变、摄影覆盖化、镜头组缺少张力等默认精修目标，以及其他创作弱点和客观错误。用户要求更高燃、宏大或炫技时，再对照这些目标检查现有景别跨度、观看顺序、机位运动和场面尺度是否兑现。根据“先判断问题，再决定怎么修”选择补细节、换演法、重做镜头组或重新制作；保留仍有效的设计，不把所有弱点一律升级成镜头组重拍。不得只给诊断、同义词润色或几处孤立微表情就称精修完成。
3. 按选定方式展开或重建：局部补写沿用成立的导演决定；换演法时联动摄影与声音；镜头组失效时重排观看与节奏；根本思路不成立时执行“回读可靠来源与锁定事实 → 重建本次范围的导演方案 → 节拍/镜头组 → 表演与摄影视听 → 时间与生成单元 → 按当前输出合同或用户明确锁定模板编译”。按双向核对同步实际相关的环境、光影、全局规则、时间与落幅，复核改动及必要接点；根因影响整场或整集时扩大到该范围，无关已成立部分保留。
4. 按当前输出合同交付，只有用户明确锁定其他模板时保留该模板。用户指定写入文件或目录时按指定位置保存；用户要求覆盖源文件时按明确要求执行。未指定保存时在对话中交付；若完整稿不适合对话承载，则保存到当前工作区 `outputs/` 并告知绝对路径。不得声称写入了实际未保存的文件。
5. 保存稿件时运行本技能的结构校验脚本：

   ```bash
   SKILL_DIR="<本技能目录绝对路径>"
   python3 "$SKILL_DIR/scripts/validate_storyboard.py" <实际文件路径> --mode refined
   ```

   配乐明确关闭时追加 `--music off`；局部关闭或开启时按实际单元追加 `--unit-music G1=off` / `--unit-music G2=on`（可重复），不靠项目有音乐标题推定全部单元开启；单元内混合范围先按自然接点分包或明确程序未覆盖。当前用户或实际入口覆盖时长上限时追加 `--max-unit-seconds <秒数>`；数值焦段默认强制校验，`--require-focal-length` 仅为旧命令兼容保留，不是开启条件。默认检查当前场景级格式；旧稿迁移后按current检查，legacy仅用于明确保留的旧版；用户锁定自定义项目格式时可用 `--schema generic`，不为通过校验重排用户格式。

   校验检查必需字段与画面/声音非空、承载镜号对应、逐窗摄影方式及时间焦段等机械条件；固定与运动按实际方案明确，剪切或人物动作不能替代摄影说明。总时长字段可保留等价名称并同步秒数；配乐按当前合同写同窗配乐行，明确锁定其他模板时保留其同窗位置。校验只证明这些机械条件通过，不证明正文语义或画面可执行。最终稿先核对分镜传达的情绪方向、强度变化和关系意味是否符合可靠来源，再检查观众感受的积累、变化与兑现，不能因为剧情和动作正确就认为表达已经完成。不能因避免夸张、拖沓或抢戏，就削弱原稿已经明确的情绪力度；也不能为了浓烈而擅自放大。文学比喻不必按字面复刻，但应找到相称的表演与视听表达。发现偏移先修理解，发现力度不足再修表现。仍须检查：事实/台词越界，时间或接点断裂，空间/动作/VFX矛盾，情绪只有标签或细节增多却演法不变，镜头观看关系无实质提升，关键剧情/高能段缺少实际动势与节奏跃升且无更强静止张力依据，逐镜归零或慢镜稀释爆发，高能段看不到主效峰值或结果承受，光影未兑现氛围。失败时按对应导演原则修复相关组及必要接点；不把结构通过称为审美保证，感染力需成片与用户反馈验证。

# 精修分镜

本技能是主导演重构流程，不是快速分镜交接包的下游修补器。用户通常只提供一个完整的 `分镜.md` 文件；不得要求快速交接包、冻结区、锁定报告、来源复印件或前置分析报告。

## 唯一输入与结构契约

1. 必须完整读取用户提供的分镜 Markdown。文件中的剧情、台词、人物、资产、全局设定、场景层级、镜头字段和时间线是本次精修的唯一正式底稿。
2. 原剧本、人物图、场景图、色卡和影调图均为可选补充材料；没有这些材料时，不暂停工作，不自行编造关键事实。
3. 读取输入文件的标题树、栏目顺序、字段名称、镜头块写法和提示词组织方式。最终稿必须保持同一结构、同一顺序和同一栏目命名；不得套用本技能的通用模板或另造“精修版结构”。
4. 允许在原有镜头栏目下增加、拆分、合并、删除或重编号镜头，但新增内容必须使用输入文件已经采用的镜头字段结构。不能把内部分析、评分、候选方案、修改记录、交接说明或锁定报告写进正文。

## 事实边界（无额外冻结文件）

默认保护输入中明确成立的：

- 原台词、OV、OS、说话者、播放顺序和语义；
- 剧情事件、因果链、关键结果、人物身份、关系、知情、能力和世界规则；
- 资产的身份、归属、结构、固有色、数量、持物关系及场景拓扑；
- 已明确的伤势、接触、证据、时地、天气、实体光源、画幅、色卡和影调；
- 当前用户明确要求保留的任何内容。

以上是事实约束，不等于冻结旧镜头的表达形式。输入中没有明确写死的镜号、镜数、景别、焦段、机位、运镜、动作路径、人物调度、反应、剪辑、空境、声音、光影和时长分配，均可由导演重新设计。必要接触和动作证据必须真实成立，不得通过省略过程偷换结果。

## 精修优先级：人物、情绪、镜头合理性

人物表演和情绪落点是最高优先级，先于技法、氛围和装饰性摄影。每个有效镜头都要回答：人物此刻想完成什么、在顾虑什么、对谁有所回应、受到什么刺激、第一反应是什么、如何按性格控制或泄露、动作和语气怎样共同完成任务、镜尾留下什么状态变化。情绪不能只写“平静、惊喜、紧张、温柔”；必须落到视线、停顿、呼吸、重心、手部精度、距离、接触、说话策略、动作失误或刻意保持上，并与当前景别可见、与台词语义一致。

镜头合理性与人物表演同步判断。每镜必须有明确主读点、起因、可见过程和落幅结果；摄影机的景别、焦点、机位和运动必须由人物注意、动作、关系、空间或信息变化触发，不能用运镜替代表演，也不能让摄影抢走关键口型、接触或情绪落点。若镜头在不改变人物任务、观众信息或情绪状态的情况下删除后仍成立，则该镜头需要合并、重写或重新赋予任务。

## 全层面精修标准

精修必须同时检查并在需要时重做以下层面：

- 人物进入状态、欲望/顾虑、策略变化、关系距离、动作选择和情绪落点；
- 每镜的起因、主读点、镜内变化、镜尾状态和摄影合理性；
- 整集开场、推进、压力/发现、主峰、结果和余波的节奏弧线；
- 镜头组的建立—积累—人物选择命中—承受—释放/保持，而非只润色单镜；
- 景别与观看距离、构图秩序、空间拓扑、遮挡、焦点、轴线和注意接力；
- 运镜的触发、路径、速度、停止条件、终幅和可执行性；
- 光源、色彩、材质、环境反馈、声音层次、声桥和剪辑切点；
- 人物、道具、数量、持物、位置、伤势、动作结果和跨镜连续性；
- 资产图提示词、全局摄影/影调/光影规则与最终镜头之间的一致性。

画面不能退化为通用中景、连续资产展示或“电影感”形容词。每镜必须承担明确的信息、任务、情绪、关系、动作、空间或结果变化；不强行给每镜添加炫技，但也不能以“原稿无硬错误”为由放过人物没有可见处理、情绪没有落点或镜头没有必要性的镜头。

## 执行流程

1. 通读完整输入，内部建立事实账、人物状态账、道具/空间连续账和整集节奏认识；不输出这些内部表。
2. 先审整集，再以人物表演、情绪落点和镜头必要性为第一轮诊断，随后定位低收益镜头组和客观执行错误。原稿只作为比较基准，不作为结构模板。
3. 对弱镜头组回到当前场景任务和人物关系重新导演，必要时重切、拆分、合并、增删空境/反应/插入、迁移信息承载、重排和重编号；重复过程是否压缩、合并或保留，由人物任务、情绪价值、信息差和观看节奏共同决定，不设“必须压缩”规则。
4. 先完成“人物判断—可见表演—情绪落点—镜头承载”，再让摄影、构图、光影、材质、声音和剪辑围绕同一主读点联合设计；不逐字段填充，不把多个互不因果的漂亮细节堆在同一时间窗。
5. 对每个重做组比较具体观看收益：人物是否更独有、情绪是否真正落地、镜头是否有必要、信息是否更清楚、峰值是否有积累和余波、空间/材质/声场是否参与、是否损失原稿有效设计。新方案没有明确收益时保留原设计；原稿和新方案都弱时继续重做，不把弱稿判为通过。
6. 重新结算实际镜长和总时长。没有用户明确总时长时可自然增减；有明确总时长时在预算内重配。单镜最长 35 秒，不能赶台词、漏掉接触或压缩关键表演。
7. 按输入文件的原有栏目结构编译最终直投稿，并做格式、时间线、口型、资产、空间、动作、光影、声音和跨镜连续性复审。

结构自检必须逐项确认：首标题一致；全局/场景/资产/镜头的标题树一致；栏目顺序一致；同类字段名称和顺序一致；每个镜头块的时间线、台词声音、落幅和正负约束等字段仍按输入格式出现。镜头数量可以因导演重构变化，但不能因此改变镜头块的字段模板。

## 输出与保存

- 输出文件名为“<作品名>_精修分镜.md”，保存到用户指定目录；不覆盖或删除输入稿。同名文件存在且未获覆盖授权时递增命名。
- 正文第一行、全局栏目、场景栏目、资产栏目、镜头栏目、字段名称和顺序均以输入 Markdown 为准；只改写精修内容，不改变模板结构。
- 默认只交付一份最终采用稿，不输出候选稿、评分、分析表、交接包、冻结清单、HTML报告或来源复印。
- 运行 `python3 scripts/validate_storyboard.py <实际文件路径> --mode refined`，修复结构/时间错误后重验。格式校验不能替代导演质量复审。

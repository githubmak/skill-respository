# 精修分镜

本技能负责完整分镜或完整指定范围的整剧级导演精修。它先读取全部生成单元，判断整场与整集的节奏、信息、人物关系和镜头接力，再逐单元完善内容。检测到打斗、斗法、术法、粒子攻击、VFX冲击、机甲活动或连续攻防时，启用本技能内置的整场动作与特效设计模块；它不是单镜头摄影参数分析器，也不是给每镜机械添加运镜、形容词或特效的“润色器”。

## 文件输出边界

- 默认在对话中交付精修稿；完整项目需要保存时，另存为新 Markdown 文件。
- 用户指定目录时优先使用；未指定时写入当前工作区的 `outputs/`。
- 不覆盖输入稿或冻结素材；同名时使用递增版本名，文件名去除非法字符。
- 只交付最终采用稿；未实际写入文件时不得声称已保存，并在完成后返回绝对路径。

## 与 camera-analysis 的分工

- `jingxiu-fenjing`：输入完整分镜、整场或一组连续生成单元；处理全局节奏与局部镜头组，联合精修表演、动作、摄影、光影、材质、声音和时长；输出仍是原生成单元模板。
- `camera-analysis`：输入一个明确镜头和一个摄影目标；只定向精修该镜头的景别、机位、焦段、构图、焦点、运镜与连续性，不扩写整场表演或重编完整剧本。
- 用户只点名单镜时，不把 `jingxiu-fenjing` 扩成全文重导；用户提交完整分镜要求整体升级时，不把任务拆成互不关联的单镜参数报告。

## 打斗、术法、粒子与机甲能力（内置整场模式）

当完整分镜包含攻击、格挡、闪避、追击、反制、术法、法阵、法器、能量攻击、爆炸、冲击、机甲活动或多人连续攻防时，先在整场层面建立动作与特效因果，再编译到生成单元。此能力独立维护于本技能，不调用 `fight-scene-video`，也不把战斗任务转交给其他 Skill。

### 整场动作因果

每个关键节拍按“威胁/目标 → 起势 → 路径 → 接触或规避 → 受力/反作用 → 控制权变化 → 结果/余波”设计。保留原分镜已经确定的人物、能力来源、动作顺序、伤势、胜负和结果；只补足准备、连接、错峰反应、受力、环境反馈、VFX形态和镜头承载。

### 术法与粒子生命周期

按需组织“来源 → 聚能 → 成形 → 施放 → 运行 → 接触 → 命中/被挡/偏转 → 余波 → 消散”。粒子分为核心能量、结构纹理、流动粒子、命中反馈和残留余波；每一层都要有源点、形态、方向、作用和退出边界。跨生成单元追踪术法阶段、方向、目标、强度、残留、人物受力、环境变化和声音状态。

### 战术预演与多人职责

每个战斗节拍内部完成“新刺激 → 威胁判断 → 当前目标 → 战术意图 → 攻防行动 → 接触或规避 → 反作用 → 新控制权”的一次预演，再决定镜头承载。主攻防保持一个第一读点；其他人物按感知、位置、任务和利益错峰承担护人、避让、警戒、承重、确认伤势或准备介入，不无因同步冲刺、后退或惊叫。战斗的观看距离、景别曲线、切点、运镜和焦点响应动作与控制权变化，不用连续固定中景或特效亮度替代战术因果。

### 生成负载与降级

动作、人物、武器、术法、粒子和环境同时争抢主读点时，先分层或错峰；仍不可读则拆分为“起势/方向 → 接触/作用 → 结果/余波”。生成风险优先通过调度、遮挡、VFX层级、运动范围、镜头拆分和结果停留降级，保留主体、路径、接触/规避和结果，不用随机抖动、无因爆炸、慢动作或满屏粒子填补缺口。

### 机甲与大型动作

机甲或大型主体的活动写清支撑、重心、关节启动、武器挂载、接触路径、受力和环境响应；不得用抖动、爆炸亮度或慢动作代替重量。摄影、VFX和声音共同服务当前动作结果。

### 用户术法视觉输入

用户可以在调用时提供“术法通用视觉表现”，指定色彩、能量材质、粒子形态、运动规律、命中反馈、残留方式和禁止表现。用户输入优先于本技能默认视觉规则；与已冻结剧情、能力或结果冲突时保留事实并说明冲突，不静默改写。

### 打斗与术法示例库（按需读取）

涉及术法、粒子、斗法、VFX或机甲活动时，读取[整场打斗与术法示例库](references/fight-vfx-examples.md)。示例用于选择动作、材质反馈、跨生成单元残留和镜头承载机制，不是固定模板；用户术法视觉输入、全局影调和冻结剧情优先。

## 输入格式与范围

首选输入是包含一个或多个下列单元的 Markdown；完整项目可在这些单元之外包含全局规则、资产、场景空间和其他栏目：

```markdown
### 生成单元 G15｜时长：12 秒｜承载：镜头 S4-04、S4-05｜旧臣仰头，将罪名砸向胜者

- 起幅与连续性：...
- 摄影与构图：...
- 光影、环境色彩与材质：...
- 画面与表演时间线：
  - 0.0—4.0秒｜S4-04｜70mm 低机位近景｜缓慢仰摇后停止。... 声音：...
  - 4.0—12.0秒｜S4-05｜45mm 侧面双人中景｜固定。... 声音：...
- 台词与声音层次：...
- 落幅状态：...
```

- 完整输入时必须通读全文；若用户只提供连续单元片段，则只使用已提供上下文，不假定缺失剧情。
- 标准可编辑块从 `### 生成单元` 标题开始，到下一个同级或更高层级标题之前结束。旧稿若使用 `### 镜头` 且字段相同，可兼容读取，但新输出沿用输入标题形式。
- 生成单元标题、六个字段及其顺序构成输出模板。允许更新标题中的时长和末尾概括；生成单元编号与“承载”镜号默认保留，只有确需拆分、合并或新增承载镜头且不改变事件顺序时才调整。
- 单元之外的全局规则、人物/场景/道具资产、空间关系、画幅、风格、色卡、影调、实体光源和正负提示词均为冻结内容，原样保留。父级 `## Seedance 独立直投生成单元` 若存在，只是容器标题，不代表其全部内容都可改。

## 输出模板合同

每个生成单元继续使用输入中的同一结构，不新增“导演分析、精修说明、候选方案、评分、修改记录”等栏目：

1. `### 生成单元 G…｜时长：…秒｜承载：…｜一句镜头任务`
2. `起幅与连续性`
3. `摄影与构图`
4. `光影、环境色彩与材质`
5. `画面与表演时间线`
6. `台词与声音层次`
7. `落幅状态`

时间线必须从 `0.0秒` 连续到标题时长。每段写明时间、承载镜号、焦距、景别、运镜或固定方式、可见动作/表演和声音。完整台词只在“台词与声音层次”出现一次；时间线只写口型阶段、语义触发或表演落点，不重复抄写全文。

若交付范围包含项目级全局栏目，且本次确实涉及术法、粒子、斗法或能量 VFX，在 `## 全局影调` 后按需增加一次：

```markdown
## 东方玄幻术法通用视觉表现

- 用户指定：{用户输入；无则写无}
- 执行风格：{全局术法视觉总原则}
- 能量材质：{核心材质与受光}
- 粒子层级：{核心、结构、流动、命中、残留}
- 运动与生命周期：{成形、传播、接触、余波、退出}
- 环境反馈：{人物、地面、建筑、尘雾和光声反应}
- 连续性规则：{跨生成单元必须保持的状态}
- 通用负面约束：{只写真实风险}
```

输入只有生成单元且没有项目级全局栏目时，不新增外层栏目；将同一设计作为内部全局基线，并落实到现有六字段。

## 生成单元交付精度

### 时长准确

- 标题时长是生成单元的结算值。时间线从 `0.0秒` 开始，最后一段结束值必须等于标题时长；相邻时间段首尾相接，不得出现空档、重叠或隐藏时段。
- 动作、表演、摄影和声音同时发生时按并行结算，不重复相加；必须先后完成的动作、切镜、镜头运动与结果停留才串行相加。
- 增加时长必须用于完成口型、动作接触、阻力、人物承受、镜头减速/停止、声音退出或余波；不能只为“高级感”延长。删减时长不得压掉因果成立所需的准备、命中和结果。
- 修改单元时长后，同步更新标题、全部时间窗、落幅状态以及完整项目中的实际总时长。不得用“约、片刻、随后、一会儿”等模糊词替代可结算时段。

### 画面构成准确

- 每个时间段必须形成一幅可执行画面：承载镜号、焦段、景别、机位/角度、主体位置、前中后景或遮挡关系、主运动或固定方式、焦点对象、主体动作、停止/切镜条件和声音落点按实际需要写清。
- “摄影与构图”负责概括整单元的观看顺序、空间方向、镜头接力和终幅；时间线负责逐段落实，不得两处写出互相矛盾的焦段、方向、速度或停止位置。
- 每段只设一个第一读点和一个主变化。次要人物、环境和光影只在影响主读点、空间、动作或结果时出现，不能同时抢中心。
- 焦段、景别和距离必须相容；特写不写不可见的全身动作，全景不依赖细小微表情，超广角不无理由贴近人脸。真实连续运镜必须存在可达路径；虚拟穿越、遮挡接缝和焦段切换必须明确切点。
- 固定机位不能同时横移、推进或环绕；“摇”是机位基本不动而镜头转向，“横移”是机位沿轨道移动，“推/拉”是机位前后位移，“变焦”只改变焦距。复合运动要共享同一触发和终点。

### 同镜空间闭环审核

对每个时间段和每个连续成片镜头做同镜审核；多人同框、前后景关系、目送/注视、接近/离开、前景框景、升降/后撤/弧移或需要同时看见人物与被观察对象时，必须执行完整空间闭环。普通单人镜头只做必要的空间检查，不机械增加字段。

审核时内部锁定并相互核对：

- 人物前后顺序、屏幕左右和纵深位置；
- 每个人的躯干朝向、头眼朝向，以及镜头实际看到的正面、侧面或背面；
- 被观察对象相对观察者的位置，视线是否真的能到达对象；
- 摄影机相对关系轴所在侧、起始机位、运动路径和终止机位；
- 摄影机运动前后是否无说明地换到关系轴另一侧，或造成左右位置、人物朝向和远近尺度突变。

同镜成稿必须能够用一句话回答：“摄影机站在哪里、每个人面向哪里、对象位于谁的哪一侧、镜头能看到每个人的哪一面、镜头停在哪里。”不得只用“目送、看向、肩部轮廓、侧后方、前景框景”等语义替代空间关系。人物要求远离摄影机并在画面中变小时，运动方向必须实际远离镜头。

空间审核发现问题时，按以下顺序处理：先调整人物站位、身体/头眼朝向、前后景关系和摄影机相对位置；再检查运动路径是否需要保持在关系轴同侧。用户已锁定的景别、焦段、时长或运镜不得被静默改写；当前空间仍无法成立时，标记为冲突并提出替代方案，只有在权限和用户范围允许时才改动摄影方案。

### 语言描述准确

- 使用“具名主体—可见动作—阻力/承受—结果”和“现实触发—摄影路径—停止条件—稳定终幅”的句式，优先写可观察事实，不用“更高级、更震撼、电影感、情绪拉满、氛围感拉满”代替画面。
- 同一句只表达一个确定关系。区分人物动作、摄影机运动、镜头转向、焦距变化、焦点变化和后期时间效果，不能把不同机制混写成一个含糊动词。
- 人称代词只有在同一句或紧邻上句的指向唯一时才使用；多人场面、跨句动作和时间线起句必须写人物姓名或明确角色名，禁止让“他、她、对方”产生双重指向。
- 事实写肯定句，执行方案写可操作句，特殊负面约束只禁止本单元真实风险；不在成稿保留分析过程、备选判断或“AI自行理解”等元语言。
- 输出前逐句核对主语、动作对象、空间方向、持物关系、声音来源和时间归属。任何一句若无法回答“谁、在何处、做什么、镜头怎样看、结果是什么”，必须重写。

## 精修权限与事实边界

不可改变：

- 剧情事件、因果、人物身份、关系、知情、能力、关键选择和最终结果；
- 原台词、OV、OS的文字、归属、顺序和语义；
- 人物、道具、伤势、证据、数量、持物、场景拓扑、时地、天气和已有实体光源；
- 用户明确要求保留的镜头、动作、构图、时长或形式。

可以精修：

- 景别、机位、焦段、构图、遮挡、焦点、切点、运镜和镜内注意接力；
- 不改变结果的动作准备、阻力、路径、人物调度、受话反应、环境反馈与余波；
- 光影和材质在既有实体光源、资产与场景条件下的镜内变化；
- 环境声、动作声、声桥、声音抽空和台词演绎层次；
- 生成单元内部镜头组织、分段和时长。

若用户未锁总时长或单元时长，可为完整动作、口型、承受、镜头停止和余波增加时长，也可压缩重复停留；不把“增加时长”当作默认升级。单生成单元最长 35 秒；存在明确总预算时只能在预算内重配。

## 整剧级精修重点

硬优先级：

`事实与全局素材 > 输入模板与冻结范围 > 同镜空间/空间/动作/道具连续 > 人物表演与动作因果 > 整场/整集节奏 > 镜头力度与锐度 > 光影/材质/声音放大 > 技法新奇度`

### 全局统筹

- 先检查整篇的开场、推进、压力/发现、主峰、结果和余波，再处理单元；局部升级不能提前耗尽主峰、破坏跨单元接力或让中后段退回同一种拍法。
- 对全部生成单元完成一轮审视，但只重做有明确弱点的部分。成立的镜头保留，不为制造修改量而全文换词。
- 每个单元必须有明确镜头任务、主读点和镜尾结果；相邻单元之间交接人物状态、位置、朝向、道具、伤势、光声环境和未完成压力。单元内部另按“同镜空间闭环审核”检查人物、对象与摄影机是否能同时成立。

### 超大巨物的跨镜尺度与镜头设计（按需启用）

当剧情或资产明确设定超大生物、人物、器物或建筑，或用户指出主体“看起来不够大”时，整组镜头必须让观众读出其在场景中的真实体量，而非只在单镜占满画框。先从输入锁定巨物与人物、树木、建筑等常规尺度物的相对比例、共享地面和场景拓扑；未给尺寸时不编造精确米数，不改变冻结资产。

- 为整组镜头分配不同任务：在需要的镜头建立可信比例，在动作镜展示支撑、接触与重量，在人物镜承接观察、躲避或情绪结果。无需每镜同时拍清全貌与人物，但离开全貌后仍通过局部接触、影子、遮挡、视线或前镜建立的空间关系维持尺度；人物近景或特写也可以是最终落幅。
- 至少在观众需要确认巨物体量的位置，让常规尺度参照物与巨物处于相近纵深、共享地面或明确接触面，读得出足底、根部、基座、投影或受力关系。低机位、广角、近大远小、夸张形容词和震地声不能单独充当比例证据；不得缩小参照物或把它推远伪造体量。
- 按本镜任务选择平视、仰视、俯视、局部越框、渐次揭示或带参照的全景，不预设必须仰拍。若宽阔远景把巨物完整收进画面却缺少比例锚点，应重配机位、景别或遮挡，而非仅加重“巨大”字样。摄影机高度、距离、焦段和运动路径必须与空间及相邻镜头相容；透视变化不能造成巨物忽大忽小。
- 巨物动作写清重心、支撑、接触路径和与其材质、质量相称的局部环境响应；不用无依据的地震、建筑损毁或慢动作代替重量。跨单元复核巨物、人物、参照物的相对尺寸、地面位置、屏幕方向、视线高度与起落幅；每处关键尺度证据都落实到原有字段和时间线，不增设输出栏目。

### 表演与力度

- 先确定人物此刻想获得、保住、确认、拒绝或隐藏什么，再写刺激、第一冲动、控制方式、可见行动、声音策略、对方承受和镜尾变化。
- 力度来自“积累—人物选择—动作或语义命中—人物/环境承受—结果与余波”，不来自持续喊叫、持续推近、音效轰炸或每镜高强度。
- 微表情只在景别可见且改变理解时使用；优先写现实任务、距离、重心、接触、道具控制、呼吸和说话方式。关键听者在有效语义点错峰反应。
- 除原台词、OV、OS原文外，画面与时间线使用人物姓名或明确角色名，不用“他、她、对方、人物”等模糊指代。

### 摄影锐度与创意

- 每个时间窗只有一个第一读点和一个主变化；切镜落在动作、视线、语义、控制权、证据或观看尺度真正改变的位置。
- 强运镜必须写清主体、现实触发、可达路径、幅度/速度、焦点行为、停止条件和停后的新结果；一个连续时间窗只保留一个主运动和至多一次主焦点交接。
- 固定镜头必须承担等待、压迫、观察、对峙或结果停留；不因保守而默认固定中景，也不因追求创意机械改成环绕或 POV。
- 弱镜头组至少内部比较两种非同构方案。需要高辨识摄影机制时读取 [经典运镜候选库](references/classic-camera-movement-candidates.md)；只迁移机制，不在成稿写片名、导演名或致敬标签。候选不满足事实、空间、动作、时长或生成稳定性时使用降级方案。

## 执行流程

1. 通读完整输入，内部建立事实、素材、人物状态、道具/空间连续和整集力度曲线；不输出这些内部表。
2. 识别全部 `### 生成单元`，冻结单元外内容，检查每个单元在整场与整集中的职责。
3. 判断是否存在打斗、术法、粒子、VFX或机甲活动；若存在，先执行本技能内置的整场动作因果、术法生命周期、粒子层级、环境受力和状态承接设计，并生成或更新全局术法视觉表现。
4. 保留成立设计；对弱单元或弱镜头组联合重做人物判断、可见表演、动作落点、摄影、光影材质、声音和余波。
5. 按原六字段模板编译最终采用稿，必要时重配时长、拆分或合并内部承载镜头，并重新计算所有时间窗。
6. 逐单元执行同镜空间闭环审核，复查人物口型、动作接触、持物、伤势、术法阶段、粒子路径、VFX残留、轴线、光声、镜尾与下一单元起幅连续性；确认冻结区无变化。若空间审核失败，先修人物调度和机位相对关系，不静默改变已锁定的景别、焦段、时长或运镜。
7. 统一使用本技能目录下的校验入口：

   ```bash
   SKILL_DIR="<jingxiu-fenjing 技能目录>"
   python3 "$SKILL_DIR/scripts/validate_storyboard.py" <实际文件路径> --mode refined
   ```

   `SKILL_DIR` 必须解析为本技能目录的绝对路径；不要依赖当前工作目录。结构校验通过后仍须完成导演质量复审。

## 输出与保存

- 输出为完整 Markdown 或用户指定的完整单元范围；格式、字段名、字段顺序和列表层级跟随输入。
- 完整项目默认另存为“<作品名>_精修分镜.md”，不覆盖输入稿；同名文件存在且未获覆盖授权时使用递增版本名。
- 只交付一份最终采用稿，不输出候选、评分、内部分析表、交接包或 HTML 报告。

# 剧本保真优先的打斗与斗法分镜

把源剧本当作不可越过的剧情边界，把模型当作拥有充分创造力的动作导演、VFX导演、摄影指导和声音设计师。目标不是把提示词写得保守，而是在剧情零改写、空间连续、动作可读的前提下，主动权衡真实器材可拍性与AI虚拟摄影表达，最大化动作气质、画面记忆点、特效规模、真实粒子、物理反馈、压迫感、紧张感和连续成片能力。

本技能只设计虚构动作。涉及真人实拍时，输出仅作为创意预演，并提醒由合格动作指导、特技团队和现场安全人员落地。

## 权限顺序

发生冲突时按以下顺序裁决：

1. 源剧本明确写出的角色、事件、动作、顺序、因果、时间与力度词、台词、能力规则、胜负和结果。
2. 空间与动作因果的成立性：站位、高度、遮挡、景别可见范围、敌我轴线、VFX占区、接触点、落点和结果必须可复原；摄影机可以是现实器材无法架设的虚拟机位，但不能无因瞬移、穿过不透明实体或让观众无法判断动作来源与结果。
3. 用户当前明确要求中不与源剧本和空间成立性冲突的设定、风格、平台、素材和禁止项。
4. 让源剧本成为可见画面所必需、且能由上下文唯一推出的状态。
5. 不改变剧情的动作连接、VFX、环境、摄影、光影、粒子、声音和表演增强。
6. 生成稳定性、格式和工程偏好。

低层级不得修改高层级。空间不可成立或动作不可读时，先换高度、轴线、焦点、景别、遮挡时机、VFX层次或虚拟机位路径，再考虑内切、拆镜或拆生成段；不得用“清楚可见、同时同框、全程可读”等词掩盖矛盾，也不得因为真实器材困难就删除、替换、改序、延迟或弱化源剧情事实。

## 两种输入模式

### 源剧本模式

用户提供剧本、小说动作段、既有分镜或台词时，逐项锁定原文。存在多个合理解释且选择会改变人物、能力、因果、顺序、结果或战力时，先指出歧义；不要擅自选择更炫的剧情。

### 原创模式

用户要求随机设计或原创斗法时，先在内部创作一个规模适合当前时长的完整事件，冻结人物、目的、站位、能力来源与规则、攻防顺序、控制权变化和最终结果，再进入导演设计。冻结后同样禁止边做分镜边改剧情。

用户提供参考分镜但要求另行创作时，只迁移抽象质量特征，不复刻人物、造型、场景、色彩、能力、动作链、镜头顺序、时长结构、构图或措辞。

## 创作自由保护

本技能是权限和验收协议，不是镜头模板、招式菜单或奇观配额。

- 不预设镜头数量、景别顺序、运镜轨道、VFX阶段、慢镜位置、高潮数量、色彩、粒子种类或动作链。
- 不用固定秒数表、风险分数、关键帧比例、奇观等级或母题库替模型选择创意。
- 先在不可变事实内独立发散，再做后置稳定审查；不得因担心生成失败而提前退化成通用冲刺、对砍、光球、闪白、爆炸或站桩蓄力。
- 参考作品和示例只校准质量，不提供可复制答案。删除参考的专有元素后，当前方案仍应由本场人物、场景、能力和剧情自然推出。
- 稳定性只修正身份、空间、归属、因果、遮挡和负载，不得同步缩小仍可执行的创意、VFX、粒子、光影或环境后果。

## 唯一工作流

严格按权限顺序执行，内部过程默认不向用户展开：

```text
冻结剧情事实与本段边界
-> 建立可观察的动作因果骨架
-> 镜头空间预演、摄影机类型选择与主观看任务拆分
-> 独立生成本场导演创意与非同构惊喜候选
-> 把创意锚定到每个剧情事件
-> 设计动作、VFX、环境、摄影、光影与声音
-> 编排为不超过30秒的可生成段
-> 后置审查与自动修复
-> 汇总为单一Markdown交付
```

### 1. 冻结剧情事实

内部记录每个事件的：

`原文证据 -> 执行者 -> 肢体/道具/能力 -> 起点与宏观路径 -> 作用对象 -> 接触/规避/显化 -> 结果 -> 控制权变化 -> 可继承状态`

同时锁定本段起点、终点和暂不制作的后续事件。对白、OS、OV和系统音逐字保留；只有用户明确授权时才修正文意。

多步源动作必须逐项覆盖。原文中的“瞬间、骤然、同时、一次、无声、无尘”等时间和力度事实不能被慢蓄力、分批、重复、轰鸣或扬尘反向改写。

### 2. 镜头空间预演与摄影机类型

完成动作因果骨架后，必须读取 [references/shot-physical-director.md](references/shot-physical-director.md)。先把剧情节拍拆成空间连续、动作因果可读的摄影机镜头，而不是把“现实器材能否架设”当成唯一准入门。每镜明确选择现实摄影机、增强虚拟摄影机或有形态桥的转场摄影机；再证明机位在哪里、路径从哪里到哪里、会被什么遮挡、当前景别实际能看见什么、主观看任务是什么、看不见的信息由哪一镜承接。虚拟摄影机允许现实设备难以完成的速度、高度和曲线，但路径必须在当前世界空间中可解释，或由明确遮挡/VFX形态桥完成转换。

每镜先定一个主观看任务：路径、接触、结果、规模、反应或余波。随后验证机位、景别可见范围、遮挡、VFX占区、摄影机路径、主体速度、焦点交接和正常观看速度。景别不是气氛标签；标题里的景别必须能看见正文要求观众读取的身体范围、武器范围、源点、接触点、落点或反应。若近景要求全身路径、远景要求微表情、关键动作被人物或不透明VFX遮挡、摄影机无因穿过实体或同镜存在多个互斥观看任务，必须重选路径、改变前后景层次、安排读取窗口、内切或拆镜。

禁止用“全知复合镜头”补洞：一镜不得同时承担脸部微反应、手部细节、全身路径、群体阵型、VFX源点、接触点和环境结果。需要观众知道这些信息时，按观看任务拆成相邻镜头，用动作方向、视线、声音、残留或遮挡切点连接。标题第三栏必须留下可验证的机位/角度/路径，不得只写“创意运镜、快速飞掠、环绕展示、全程跟拍、镜头穿梭、清楚可见”等无法落地的摄影词。

对峙关系也要连续：如果上一镜是两人正面对峙，下一镜要么继续保持同一深度关系，要么明确改成反打、过肩、双人中景或切到单人反应镜；不要把一人写成近景主角、另一人却退成后景观察者，还假装两人仍处于同一面对面关系。

空间与主动作读取通过后，才进入动作美感、VFX美术、情绪控制权和光影设计。炫酷运镜与大型特效发生冲突时，不先删除或缩小：依次尝试改变摄影机高度/侧向、调整VFX前后景占区、用焦点交接保住主动作、让遮挡成为转场、在透明烟尘/粒子/能量表面中建立穿越窗口，或把来源与结果拆给相邻镜。只有路径必须无因穿过墙、身体、武器、爆炸核心等不透明实体，或任何调整都无法保住剧情因果时，才放弃该方案。

### 3. 独立导演创意

读取工程参考之前，依据人物、能力、空间、剧情位置和情绪压力自由构思本场独有的：

- 动作气质与宏观运动弧；
- VFX形态、行为规律和形态转移；
- 环境怎样证明力量方向、尺度和结果；
- 控制权怎样通过距离、高度、占区、光权和声音变化被看见；
- 摄影机怎样在空间可解释范围内增加来源、路径、接触、尺度、反应或结果信息；现实摄影机与虚拟摄影机哪一种更能服务本镜；
- 最有记忆力的构图、声音落点或反高潮。

正式落镜前，在内部提出至少三个非同构的导演惊喜候选。候选必须来自当前人物、能力规则、场景材质、遮挡、距离、高度、声音或控制权，不能只是把同一动作换焦段、换颜色或换机位。分别写清：`锚定的原剧情节拍 -> 观众原预期 -> 揭示/反转机制 -> 新增的观看信息或情绪作用 -> 现实/虚拟摄影机选择与空间形态桥 -> 结果残留`。只选择最贴合本场的一条或数条落稿，不输出候选过程。

惊喜是高能段的硬质量门，不是可选装饰。每个承担启动、攻防转折或终结的生成段，至少要有一个无法被通用固定机位、普通侧拍或过肩覆盖等价替换的场景专属导演机制。它可以让观众先看到结果再发现来源、让遮挡在决定性时刻改变信息、让环境材质接力动作、让声音抽空重排压力，或用其他由本场事实自然推出的方式完成；这些只是机制说明，不是镜头菜单。惊喜必须推进信息揭示、控制权变化、情绪转折或动作因果。只为“更酷”而存在，或删除后观看信息完全不变的设计，退回重想。

新增设计仍须通过剧情删除测试：删除表现层后，剧情、战力、人物决策、动作顺序、空间结果和结局完全不变。否则属于越权新增。反过来，若删除所有场景专属摄影、声音、材质与构图设计后，成品仍能被同一套通用覆盖镜头完整替代，则创意质量不合格，必须二次发散。不要把“现实中难以架设”误判为剧情越权；只要虚拟摄影机空间连续且观看收益明确，就可保留。

本次独立创意方向形成后，必须读取 [references/creative-quality-checklist.md](references/creative-quality-checklist.md) 做无示例污染的质量校准。用它检查并继续抬升动作气质、记忆画面、VFX母题、镜间动势、节奏反差、术法连续、光影构图、声音压力和余波。只要任何高能段仍可被通用覆盖镜头等价替代，就视为缺少惊喜，必须读取 [references/creative-quality-reference.md](references/creative-quality-reference.md) 做二次发散；该参考只校准质量，不提供人物、招式、场景、镜头顺序或时长答案，一旦出现具体元素趋同，立即丢弃该分支并重新发散。任何二次发散不得推翻已经通过的空间因果；若新创意造成空间不可复原，回到空间预演重拆。

### 4. 动作与打击

每个主动作写清足以避免误读的起始状态、决定性变化、接触或规避、力量方向和结果。原文未规定的重心转移、四肢协调、惯性缓冲、衣发随动和自然补间交给模型，不逐关节、逐步或逐秒编舞。

打击感来自支撑、加速、接触面、受击块位移、攻击者反作用、材质二次反馈和恢复中的实际需要项，不机械写满。原文是闪避、擦身或落空时，只强化风压、距离、急停、衣物受力和落地承重，不得新增命中。

运镜只保留能新增观看信息、控制权或情绪压力的部分；能被 shot-physical-director 直接判断的，不再额外调动作摄影参考。现实摄影机优先用于接触、表演和关系读取；增强虚拟摄影机可用于高速追击、垂直位移、尺度揭示和VFX形态桥，只要路径连续、不无因穿透不透明实体、不被VFX完全吞没，也不遮掉决定性动作。无观看收益的环绕、甩镜、漂移和持续乱晃应删除，但不得仅因现实器材难以完成而删除有叙事收益的虚拟运镜。

### 5. VFX、粒子与宏大场面

术法和超能力必须能追溯来源、可辨形态、传播或占区、第一作用、环境/光影后果和残留。先建立与人物、能力规则和场景材质相称的VFX美术母题，再按本镜理解所需选择证据，不机械写满阶段。

- 大型结构允许突然出现、展开、压缩、折叠、分裂或先见结果后揭示来源，只要能力规则允许且相邻状态存在可见形态桥。
- 宏大感由尺度参照、空间占领、环境压迫、力量传播、光域变化、声音距离和战场后果证明，不靠形容词、全屏高亮或无因巨物。
- 粒子必须有来源、材质、方向、受力和停止/残留条件；不得穿过实体、逆受力飞行或让主动作等待装饰完成。
- 人物主体突出通过焦点、锐度、局部对比、遮挡、负空间、光权和空间分布完成。宏大VFX可以短暂占据大部分画面、形成受控遮挡或让人物压成剪影，只要来源、关键动作窗口和结果仍在本镜或相邻镜清楚回收；不要为了人物始终正面清晰而把VFX降级成背景泛光。
- 慢镜或升格只提供观察窗口，不改变原动作的叙事速度、次数、顺序和结果。

需要高能慢镜、复杂自发光/材质/残留时，再补读对应专项参考。

### 6. 多人活性

每个清楚可见的非主要人物都绑定一个由身份、信息、威胁、受力、关系或既有任务推出的反应职责。反应可以是观察、维持任务、保护既有目标、承受环境、错峰避让、确认伤势或响应同伴；具体眼神、呼吸、重心和补间交给模型。

配角不得静止木偶化、同步复制、无因面向镜头，也不得凭空新增攻击、反制、伤势、对白、决策或控制权。远景群体可以按不同信息区、受力区和关系区形成错峰状态，不要求逐人特写。

### 7. 空间锁与连续合并

空间锁定锁关系，不锁僵硬坐标。段首镜建立当前段需要的场景边界、地标、敌我轴线、相对方位与高度、屏幕侧、面向、道具/伤势归属、VFX来源与占区、环境后态和主光。后续镜只重述当前可见、已经变化、剧情必需或高漂移风险的状态。

道具也必须锁连续状态：谁持有、哪只手/身体哪侧、是否放在桌面/地面/鞘中/阵眼、开合、破损、染血、发光、残留、方向和与人物的距离都不能无因改变。若道具从手中变到地上、从闭合变打开、从左手变右手、从完好变破损、从近身变远处，必须在本镜或前一镜给出可见交接、掉落、收回、击飞、打开、破损或移动原因；否则拆镜或重述正确状态。

共享时空、轴线、目标和动作因果的镜头可以编排进同一个自足生成段，但不得优先于空间成立性和主观看任务。编排后每个剧情事件必须仍有唯一可见或可听证据，且每镜的景别、现实/虚拟机位和遮挡仍能成立地呈现主事件。出现互斥姿态、独立控制权变化、动作归属不清、强遮挡、无因换轴、人物深度关系冲突、道具归属或状态漂移、可见范围冲突或结果不可读时，先换证明角度、焦点或VFX层次，仍不清楚再内切或拆镜。

多人合并、错峰反应和空间重建更复杂时，再补读对应专项参考。

### 8. 节奏、负载与时长

镜头负载按独立事件、互斥姿态、控制权变化、空间重建、道具归属变化、强遮挡、景别可见范围冲突、摄影机路径冲突和焦点交接判断，不按字数、镜头数、形容词数或固定分值判断。

高视觉表达密度与低微动作控制密度必须同时成立：画面可以丰富，但只锁剧情事实和防误读所需控制点。若过载，按以下顺序收敛：

`删除无锚点装饰 -> 压缩必要补间 -> 去重复和伪精确 -> 调整运镜/VFX前后景和焦点交接 -> 简化无观看收益的运镜与次级VFX -> 按主观看任务拆镜或内切 -> 聚合同一动作弧中空间兼容的部分 -> 拆生成段`

镜头时长取动作、对白、VFX结果、环境后果和运镜必要时间区间的并集，不机械相加。每个生成段内镜头时长之和必须不超过30秒；超过时在自然因果接缝拆段，不得加速、删剧情或快读台词。Markdown文件可以汇总多个生成段，文件总时长不受30秒限制。

交付前先跑格式校验；只有确实需要节奏、时长或脚本差分审查时，再补读对应专项参考。

## 精简参考读取纪律

默认只读三件套：[references/shot-physical-director.md](references/shot-physical-director.md)、[references/creative-quality-checklist.md](references/creative-quality-checklist.md)、[references/copy-ready-markdown.md](references/copy-ready-markdown.md)，最后运行 `scripts/validate_storyboard_format.py`。不调用外部技能，不运行轨迹图、关键帧、表演、音效、连续性、九宫格、XLSX或其他流水线。只有用户明确要求相应产物，或当前复杂空间/成片诊断确实需要时才启用；外部工具只能翻译已锁定事实，不能重新选择剧情、招式、高潮或镜头答案。历史原始素材不保留手动入口，也不作为正常创作、改编、审片和自动修复的读取对象。

## 固定交付合同

用户要求分镜、提示词、Markdown或可复制成品时，读取 [references/copy-ready-markdown.md](references/copy-ready-markdown.md)。默认只交付一个UTF-8 Markdown文件。单场超过30秒时，在同一文件内按自然因果接缝建立多个生成段；每段可单独复制投喂，文件负责汇总全场。只有用户明确要求“每段单独文件”时才拆成多个文件。

多段文件由生成段标题和连续镜头块组成：

```text
生成段 01｜段名｜28s

镜号 01｜景别｜主要运镜与机位/角度｜时长s

画面内容：……

特效：……

光影：……

音效：……

台词：无
```

严格规则：

- 多段文件第一行直接以 `生成段 01｜` 开始；生成段编号连续，标题时长必须等于该段镜头时长之和且不超过30秒。全场镜号从01开始跨段连续递增，不在新段重置。
- 只有一个生成段时仍优先使用同一结构；为兼容既有工作流，也允许省略生成段标题并直接以 `镜号 01｜` 开始。
- 除生成段标题外，不加文档标题、摘要、表格、说明或段外分析。
- 每镜只保留 `画面内容、特效、光影、音效、台词` 五个正文字段，顺序和空行固定；没有内容写 `无`。
- 内部事件编号、事实分级、审计标签、风险分数、负面提示词、关键帧、地图标注和参考分析不得进入主文件。
- 第一镜建立完整必要锚点；后续镜写具体增量状态，不用“上一镜、同上、沿用”等空指代，也不机械复制全套设定。
- 标题中的景别、运镜和机位必须与正文可见范围一致；近景不承担全身路径，远景不承担微表情。标题须明确现实摄影机、增强虚拟摄影机或遮挡/VFX转场路径；运动机位不得无因穿过不透明实体，短暂VFX遮挡必须留下读取窗口或相邻结果镜。
- 每个生成段第一镜或首个高能镜的 `特效` 字段必须落下本段VFX母题的可见规则；关键转折镜在 `画面内容` 或 `音效` 中给出控制权/情绪节奏变化，不新增字段。
- 文件写为UTF-8 `.md`并作为交付正文的唯一真源；聊天只需说明文件位置、生成段数量和校验结果，除非用户明确要求粘贴全文。

负面约束只在用户提供真实失败成片并明确要求诊断时作为独立修复信息使用，不属于可复制分镜正文，也不得在每镜默认生成。

## 自动修复闭环

交付前执行正向覆盖和反向复述：源事实逐项能找到承载镜号；只看最终镜头又能按唯一顺序复述谁用什么对谁做了什么、是否接触或规避、能力怎样作用、控制权如何变化、结果与残留是什么。

以下任一失败，不交付中间稿：

- 漏、改、增、改序、力度冲突或台词变更；
- 身份、肢体、道具归属、伤势、左右屏、轴线、高度或移动方向漂移；
- 景别标题与画面内容可见范围冲突，或现实/虚拟机位路径都无法让主事件、关键接触与结果成立；
- VFX无来源、形态跳变、穿模、遮住关键动作、光照不响应或环境无因复原；
- 合并后事件漏演、结果不清、配角木偶化或焦点竞争；
- 提示词被微动作、顺序词、精确时间码或装饰细节占满；
- 任一生成段总时长超过30秒、生成段标题时长与镜头合计不一致，或对白自然说不完；
- 承担启动、攻防转折或终结的高能生成段只有通用覆盖镜头，没有通过“非同构候选、观看增益、空间证明、场景专属残留”质量门；
- 成品只剩“人物做动作、特效出现、环境震动”的干瘪摘要；
- 方案明显复刻参考示例，而不是由当前剧本生成。

自动按最早根因修复：`身份/肢体 -> 空间/轴线 -> 动作因果/接触 -> 主动作读取窗口 -> VFX来源/占区/光照 -> 现实或虚拟摄影机路径 -> 多人活性 -> 质感`。每轮做最小改动，优先救回有观看收益的炫酷运镜和VFX规模，再重新执行覆盖、反向复述、空间连续和时长审查，直到通过。

最后运行：

```bash
python3 scripts/validate_storyboard_format.py <成品.md>
```

格式错误和脚本可识别的物理矛盾必须清零；脚本只拦常见景别可见范围、摄影机穿实体、VFX遮主事件等高频问题。剧情保真、复杂空间连续、语义负载和创意质量仍由人工/模型审片，不能因固定阈值删改源剧情。

## 成片复盘

只有用户提供视频、关键帧或失败描述时读取 [references/generation-feedback-loop.md](references/generation-feedback-loop.md)。从最早错误帧定位根因，先恢复剧本、身份、空间和动作因果，再恢复VFX规模、场面层次与质感。没有真实成片时只能评价设计，不能声称平台通过率或最低抽卡率已经被实测证明。

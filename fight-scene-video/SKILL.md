# 剧本保真资格门下的打斗戏视频设计

把源剧本当作不可越过的剧情基线，把大模型当作受约束的动作导演、VFX概念导演和场面调度导演。先完整锁定剧本事实，再在原事件内部创造动作证据、特效奇观、场面力量、空间层次和运镜；任何演绎都只能让剧本更清楚、更有力、更可生成，不能把剧本变成另一场戏。

本技能设计虚构动作戏。涉及真人实拍时，只输出创意预演，并提醒由合格动作指导、特技团队和现场安全人员完成落地。

## 创作权威

按以下优先级裁决冲突：

1. 源剧本明确写出的角色、事件、动作、顺序、因果、时间力度词、台词、能力规则、胜负与结果。
2. 用户当前明确要求中不与源剧本冲突的设定、风格、尺度、平台和禁止项。
3. 为表现源剧本所必需的可见补足，以及从剧本可唯一推出的状态。
4. VFX、粒子、额外辅助动作、摄影、光影、声音和场面调度的导演表达。
5. 生成稳定性、空间量化、轨迹图、格式和评测规则。

低层级不得反向修改高层级。若剧本动作单镜难以生成，优先拆成连续覆盖、降低同屏同时性、改换证明角度或分阶段显化；不得删除、替换、改序或延迟剧本动作，也不得用更炫的特效、运镜或原创动作抢占其结果。

## 设计重心

默认把主要设计注意力放在五个相互驱动的方向：

1. `打斗`：在剧本允许范围内强化原动作的力量传递、接触反馈、规避证据与局面结果；不得为追求原创而新增独立攻防事件。
2. `特效`：拥有行为规律、形态演化、材质作用和光影后果的VFX，不只增加颜色与粒子。
3. `场面力`：主力量如何占领空间、压迫对手、撼动环境并在一个画面内形成清楚的强弱关系；不等于堆满人物和爆炸。
4. `层次感`：动作前后层、VFX传播层、环境反应层、空间高低层、光影明暗层和声音远近层共同推进，而不是所有信息同时贴在同一平面。
5. `宏大感`：用尺度参照、由近及远的力量传播、收缩与释放、环境级后果及余波证明规模，不靠“宏大、史诗、震撼”等形容词冒充画面。

高能、仙侠、超能力或战争型场景默认强化这五项。贴身写实或狭小空间不强行加入巨物，但仍通过力量密度、空间压迫、材质反馈和景别反差建立场面力。

用户未另行要求克制、写实或低调时，高能术法的 `特效、粒子、光影` 默认采用大气磅礴的导演方向：优先扩大力量的空间占区、纵深传播、环境压迫、尺度参照和光权变化，不把“大气磅礴”简化为更亮、更密或全屏爆炸。宏大显化仍必须服务已锁定的剧情动作，并保留主体、路径和落幅可读性。

生成预算按固定优先级分配：`剧本事件/台词/动作 -> 人物身份与动作归属 -> 接触/规避和结果证据 -> 服务原动作的VFX/粒子/环境后果 -> 服务原动作的运镜 -> 装饰性表演与氛围`。先保证高层级完整，再以最优有效密度强化低层级；若继续增加会降低主体、动作、因果或稳定结果的可读性，允许保留安全余量，不得机械用满预算。不得为了保留炫技运镜、粒子或新增动作而压缩剧本事实。

## 画面密度与光影硬门

`单镜一个主动作链/主VFX事件`只限制叙事焦点，不限制画面层次。不得把动作预算、生成稳定性或“减少人物微动作”误写成简单背景、单层构图、空洞大远景或只有人物加泛光的画面。用户要求减少表演、手势或招式数量时，把释放出的信息预算转移给环境参与、VFX传播、空间层次、尺度参照、材质反应和光影变化；不能同步降低整镜画面密度。

画面丰富度必须来自节奏推进中的动作、关系和状态变化，不能来自形容词、材质名、粒子种类或字段数量的堆积。每个新增细节必须至少服务一项：动作路径更清楚、威胁升级、空间改变、控制权转移、人物意图或不可逆后果；删除描述词后若镜头没有新变化，判定为无效丰富并合并或删除。

### 主体突出与VFX密度解耦门

把 `突出人物主体` 视为画面读取层级问题，不得把它执行成特效规模、行为、粒子、光影或环境后果的同步降级。人物可以拥有最高锐度、局部对比、身份完整度和第一读点，同时让主VFX占领更大的纵深、高低空间或环境范围；`视觉重要性`不等于`屏幕面积`。

- 调整主体时，优先改变焦点、锐度、亮度峰值、色彩对比、遮挡、空间分布、运动频率和摄影绑定；不得先删除主VFX的源点、结构、路径、碰撞、环境受力、粒子动力、光照后果或残留。
- 全局VFX蓝图只锁规则，不能替代逐镜局部描述。每个高能镜头必须重新写明本镜发生的 `前态/来源 -> 本镜形态变化 -> 传播或占区 -> 第一作用 -> 环境/光影反应 -> 可继承后态`；没有变化的字段可简写，但不能用“沿用全局特效”跳过本镜事实。
- 人物主体增强后，逐镜特效仍需保留功能性信息密度。特效可以退到人物身后、下方、边缘或纵深，可以降低相对亮度与锐度，但不能退化为小泛光、薄雾、几颗粒子或一句“特效环绕”。
- 若人物、主动作和完整VFX链同镜过载，拆成相邻覆盖并分配来源、展开、作用和余波；必须保留源剧本规定的VFX事实及预算内最强演绎证据。允许删除重复、无锚点或超预算的E演绎项，但必须记录差分，不得以稳定性为由静默删去源点、路径、第一作用、结果和必要场面层次。
- 修改既有分镜时，先执行 `VFX保真差分`：逐镜比较修改前后的主VFX机制、规模占区、环境链、粒子链、光权变化和残留。任何源剧本事实或必要功能项无剧情理由减少都判定为过度收敛；但允许记录后把非源文E演绎资源从普通镜重新分配给真正高潮，使全场峰值更清楚，不能机械要求每镜原样保留同等亮度、占区和粒子密度。

详细的逐镜主体/VFX并重写法与差分表见 [references/vfx-physics-compositing.md](references/vfx-physics-compositing.md) 和 [references/copy-ready-markdown.md](references/copy-ready-markdown.md)。

除纯触发特写、必要反应镜和转场镜外，每个高能镜头进入工程收敛前必须通过：

1. `主体层`：主要角色的清楚姿态、动作线、控制权或受力状态。
2. `路径层`：主动作/VFX的来源、方向、占区、碰撞或规则变化。
3. `环境层`：至少一条由近及远的环境反应链；高潮镜至少包含两种不同材质或尺度的连锁后果。
4. `空间层`：前景受力证据、中景攻防主体、后景尺度参照中至少三项可读，并写清高低关系。
5. `光影层`：环境主光、VFX染色、遮挡/投影、材质反射、曝光变化和下一镜恢复/继承中，凡本镜发生者必须具体写出。
6. `落幅层`：画面结束时人物、敌人、VFX、环境残留和控制权有唯一稳定状态。

高潮英雄镜必须在同一决定性构图内同时看见主体、主VFX路径或占区、环境受力和尺度参照。若单镜负载过高，拆成相邻覆盖建立来源与过程，但必须保留一个聚合这些要素的稳定英雄落幅。若镜头只能被概括为“人物做动作/站立 + 特效出现 + 环境震动”，视为画面设计未完成，返回动作/VFX/摄影设计继续扩展。

整场必须先设计 `光权变化曲线`：环境光由谁掌控、敌方如何遮蔽或污染、主角如何夺回曝光、高潮怎样短暂抬升、余波怎样恢复。不能用“电影感光影、神秘光、炫目光芒、史诗照明”等抽象词代替光源方向、作用距离、遮挡、反射、投影、体积介质和曝光后果。

### 奇观峰值资源分配门

逐镜写作前必须按剧情职责为整场分配 `L0静场、L1源点、L2威胁、L3蓄压、L4唯一高潮、L5余波`，把最大尺度、最大空间占区、完整环境传播、最高粒子密度和全场光权峰值保留给L4高潮组。普通高能镜只使用证明本镜P事件所需的资源，不能因为“每镜完整”而提前用尽高潮资产；高潮相对相邻高能镜必须在尺度维度、压迫轴、VFX形态、环境传播或光影拓扑中至少产生两项清楚跃迁。详细分配、三轴压迫和光影注入合同见 [references/spectacle-scale-light-curve.md](references/spectacle-scale-light-curve.md)。

区分 `光源效果` 与 `可见光源物体`。源剧本只写月光、日光、灯光、火光从某方向照来时，只设计照射方向、轮廓、投影和反射，不得自动在画面中生成完整月盘、太阳、灯具或巨大火源。只有源剧本明确要求该物体入画，或用户提供的场景事实已锁定其可见位置时才可呈现；可见强光物体不得无因贴在人物头后、遮挡手势或成为第一读点。

### 术法规模连续性门

用户要求宏大、碾压、高能、巨物或环境级术法时，强制建立 `清晰源点 -> 结构展开 -> 空间占领 -> 环境压迫 -> 战场后果` 五阶段尺度链。人物动作可以极小，术法显化不能因此保持小气；`小动作`与`小特效`不是同一件事。

- `清晰源点`：让观众知道术法从手、法器、阵眼或环境何处开始，但源点特写不承担最终规模。
- `结构展开`：在相邻宽镜中让符、阵、法相、召唤或能量显出独有轮廓、厚度、层级与生长方式；不能长期停留为掌心符、普通光球、小法印或平面圆阵。
- `空间占领`：大型术法至少与人物、建筑、街道、山体或天空中的一个明确参照形成数倍尺度差，并改变可通行区、视野、光域或上下空间。
- `环境压迫`：在真正命中前就让风压、投影、遮光、地面承重、建筑形变、尘雾或水体证明其存在；不能只在爆炸后补环境反应。
- `战场后果`：最终作用范围、力量方向和残留必须与此前显化规模一致。

若大型结构压缩、折叠、汇聚或消散为后续攻击，写清体积/能量如何转移，保留可追踪的路径、密度变化、光照变化和环境响应；禁止巨大结构无因果瞬间消失，再凭空出现街区级爆炸。小型源点可以作为精密控制或反差，但必须在一到两个相邻覆盖内完成可见扩张，或由同等清楚的环境占区证明规模。

宏大术法的核心显化至少满足下列两项：超过人物数倍的清楚轮廓；占领建筑/街道/天空区域；拥有地标尺度参照；投下可见光影或空间压力；引发由近及远的环境连锁。若结果影响整条街、战场或天地，而主要显化始终只有掌心符、普通光球、小法印或平面圆阵，判定尺度链断裂，返回VFX设计阶段。

### 秒杀与碾压战果硬门

剧情包含秒杀、碾压、群体清场、一击破法或瞬间处决时，强制建立 `威胁承诺 -> 代表性个体受术证据 -> 群体/战场结果 -> 残留` 战果链。大全景负责证明规模，近景或特写负责证明术法怎样赢；二者不能互相替代。

- 至少选择一个代表性目标，用近景、特写或同等清楚的局部覆盖呈现三个可读状态：命中前仍具威胁、力量介入并打断其动作、不可逆的败亡/失能落幅。
- 受术证据必须体现本场能力规则，如运动骤停、能量沿躯体传播、材质焦枯/结晶/剥离/坍缩、轮廓失真或被阵法回收；不得只用闪白、爆炸遮挡、倒飞或切到空景代替。
- 默认景别节奏为 `主角/术法英雄宽镜 -> 敌方秒杀近景或特写 -> 群体覆灭大全景 -> 环境残留`。可因节奏调整顺序，但不能同时删除局部战果证据和全局规模结果。
- `减少主角微动作、微表情或表演`不等于减少敌方受术证据。秒杀特写拍的是力量规则和目标状态变化，不是主角表演。
- 只有当同一宽镜能在正常观看速度下一眼读清一个代表性目标的介入过程与不可逆落幅时，才可省略独立特写；必须在分镜说明中指出该局部证据位于画面何处。

若观众只能知道“敌人消失了”，却看不清“为何被这一术秒杀”，判定战果链断裂，返回动作/VFX/摄影设计补镜。

## 唯一工作流

必须依次执行：

```text
不可变事实提取
-> 剧情摘要与本段覆盖边界
-> 剧情动作骨架
-> 剧本保真资格门
-> 大模型内部条件化演绎发散
-> 剧本锚定演绎融合
-> 演绎质量门
-> 动作/VFX/运镜完整设计
-> 后置工程收敛
-> 生成提示词与交付
-> 成片复盘
```

不存在“先锁动作/VFX/预算再演绎”的备用路径。不得因时间短、输入少、用户只要最终提示词或需要批量输出而跳过剧本保真资格门、条件化演绎发散、剧本锚定融合和演绎质量门。剧情摘要、动作骨架和本段覆盖边界必须先于所有美术润色；未被本段覆盖的后续剧情不算缺失。

### 三层生成架构与八道执行门

所有镜头依次通过三层，后一层只能翻译、证明和放大前一层，不能反向改写：

1. `剧情真值层（零改写自由度）`：逐句锁定 `原文证据 -> 人物意图 -> 触发原因 -> 动作执行者 -> 使用肢体/道具/能力 -> 起点与路径 -> 作用对象 -> 接触/规避 -> 结果 -> 控制权变化与稳定落幅`。不得改动作归属、肢体、顺序、方向、敌方数量、能力规则、台词、结果或原文力度。
2. `导演演绎层（条件化高自由度）`：只在每个剧本事件内部推断表演轻重、发力和反作用、连接动作、材质反馈、VFX结构、粒子、光影、声音、环境参与与摄影。每镜先写一句内部 `唯一叙事目标`；一切新增设计必须能指回原文证据，删除后不得改变剧情。原创、独特钩子、角色专属动作语言和环境机关只有在剧本保真资格门与Seedance执行预算同时允许时才启用，不是无条件交付义务。
3. `Seedance 2.5执行层（翻译自由度）`：把已定设计写成时间顺序明确、单镜自足、主体稳定、空间关系清楚、一个核心动作与一个主运镜的中文可见事实。平台适配只能拆分和澄清，不能改剧本。

交付前逐镜通过八道阻断门：`剧本覆盖与顺序门`、`剧本动作逐项保真门`、`时间力度修饰冲突门`、`动作归属与肢体转换门`、`单镜独立状态门`、`动作负载与稳定结果门`、`运镜叙事因果门`、`Seedance反向复述门`。任一失败只返回对应层修复，不得用删特效、改动作或泛化描述掩盖。完整语法见 [references/seedance-execution-grammar.md](references/seedance-execution-grammar.md)。

## 1. 提取不可变事实与创作空间

先分成两组，不要把所有输入都变成限制。

### 不可变事实

- 源剧本中每一句叙述、动作、对白、OS、OV及其先后关系；先逐段编号并保留可核对的原文证据。
- 为什么打、剧情必须到达的结果、胜负条件和不能改变的事件。
- 角色身份、已声明武器/能力、战力边界、伤害尺度和禁用内容。
- 场景时代、关键地标、必须保留的道具、素材ID、时长、平台和画幅。
- 用户明确指定的风格、镜头、台词、高潮画面或必须出现的招式。

### 创作空间

- 原动作内部如何补足预备、发力、路径、接触/规避、反作用、回收和落幅；不得新增改变局面的独立攻防事件。
- 仅当剧本已经写出或明确留有响应空间时，补足对手的观察、试探、诱导、反制和打法升级。
- VFX采用什么视觉母题、行为规律、显化阶段和光影主题。
- 哪个环境元素参与攻防，战场如何被逐步改变。
- 动作节奏、反转、高潮构图、摄影机关系和声音留白。

缺失信息分级处理：能由上下文唯一推出的必要可见状态可以补足；存在多个合理答案且任一答案会改变人物、能力、因果、顺序、结果或战力时不得擅自续写。风格化推断只用于表现层，不用于补剧情。

### 剧情优先输出（强制）

在任何条件化演绎发散、镜头设计或提示词之前，先输出以下三项：

1. `剧情摘要`：用1-3句话说明本段发生了什么、谁想改变什么、控制权如何变化。
2. `本段覆盖边界`：明确起点、终点，以及用户暂时不制作的后续事件。未覆盖事件标记为“后续制作”，不能在复盘中当作遗漏。
3. `剧情动作骨架`：只写可观察的因果链，不写镜头风格和装饰词：
   `目标/意图 -> 触发原因 -> 动作执行者 -> 使用肢体/道具/能力 -> 起点/路径 -> 作用对象 -> 接触/规避/显化 -> 受力或环境反应 -> 控制权变化 -> 稳定落幅`。

为每个剧情事件分配唯一编号（如 `P1-P6`），并标记 `必做`、`本段不做` 或 `可创作`。每个后续镜头、关键帧和提示词必须引用至少一个 `P` 编号；没有 `P` 编号的特效、动作或奇观只能作为润色候选，不能改变事件因果。

同时建立内部 `剧本保真矩阵`：`原文位置/原句 | P事件 | 必保人物/动作/台词/力度词 | 允许的可见补足 | 禁止推断 | 承载镜号 | 最终结果 | 通过/退回`。逐项覆盖率必须为100%，顺序必须与原文一致；任何无原文锚点的新增内容标为 `E演绎`，且必须满足“删除E后剧情、战力、空间结果和人物决策完全不变”。

### 剧本保真资格门

进入任何演绎发散前逐项检查：

- 能否不看景别和特效，用一句话复述本段剧情结果。
- 每个 `必做` 事件是否有明确起因、动作承诺、结果和唯一稳定落幅。
- 每个动词是否能唯一回答“谁用哪只肢体或何种能力，对谁做什么”；多人同镜时重复角色名，不用可能换主语的“她/它/其”。手型或持物状态改变时，先写松开、换手或重新构型，并写清闲置手停在哪里。
- 角色的动作是否改变了空间、威胁、信息或控制权；只有摆姿势或展示特效的段落不能作为动作事件。
- 本段终点是否与用户指定的截断位置一致；“后续制作”事件不得被静默补写或静默判定为失败。
- 若用户指定的时长或单镜承载不了全部 `必做` 事件，先拆成本段/下段或相邻镜头，并保留事件编号，不得直接删掉剧情动作。

### 节奏经济与语义保真门

进入条件化演绎发散和演绎润色前，先完成一次时间与动词审核；画面丰富度不能通过增加无效镜头或等待粒子完成来获得：

- 动作冷开场默认在前3秒内出现角色的明确意图或不可收回动作，在前6秒内出现第一个有效术法结果；只有用户明确要求慢蓄压时才放宽。
- 每镜必须新增至少一项 `动作、威胁、信息、空间、控制权或不可逆状态`。只增加粒子、反光、尘雾或同一姿态的镜头合并处理，不得独立成镜。
- 次级环境链、敌方状态链和光权链必须在主动作窗口内并行发生，不能为每条链额外分配等待时长；`稳定落幅`是剪辑交接点，不是默认停帧。
- 2-3秒只承载一个触发或反应，4-6秒承载一次决定性动作及后果，7-8秒只在确有“接近 -> 承诺 -> 解决”的连续三段链时使用；时长是上限参考，不是默认配额。
- 单镜时长按时间轴关键路径计算，禁止把动作、对白、VFX、环境反应和运镜时长机械相加。先标出各必要事件的开始与结束：完全并行时取 `max(T动作, T对白, TVFX/结果, T运镜)`；部分并行时计算所有时间区间的并集；只有确实位于动作前后且不能重叠的部分才顺序增加。镜头结束点取最晚必要结果的结束时间，并包含0.2-0.5秒稳定可读窗口。
- 对白时长只统计实际说出的正文，不统计角色名、OS/OV/系统音标签和表演说明；按角色状态选择语速并计入标点停顿：沉静正常约3.5-4.0汉字/秒，明确急促约4.0-4.5汉字/秒，低语、迟疑或情绪停顿约2.5-3.5汉字/秒。对白与动作可以并行，但不得让口型、呼吸或发声状态与剧本动作物理冲突。
- 每个主动作按 `起幅 -> 承诺 -> 过程 -> 结果` 形成可读曲线；镜尾为结果保留约0.2-0.5秒稳定可读状态。人物躲避使用最短有效路径、单次明确发力和干净制动，不附加无剧情作用的翻滚、旋转、摆拍或二次闪避。
- 相邻两镜若仍是同一P事件、同一控制权、同一主VFX形态且没有新信息，必须合并或改为动作内切，不得用不同材质描述掩盖重复。
- 保留原文的时间和力度动词。`骤然、凭空炸燃、瞬间、霎时、快一倍、无尘`等词不得在分镜中被改写为缓慢生成、分轮逼近、长时间停留或重复完成同一战果。
- 对同一主动作执行 `修饰词碰撞检查`：原文写 `骤然/瞬间/急速/猛然/齐齐/只一次/无声/无尘` 时，画面、特效、运镜和声音任何字段都不得再写 `缓慢/逐渐/由慢到快/分批/再次/连续多次/轰鸣/扬尘` 等相反事实。辅助演绎只能发生在动作前后的独立对象上，不能改变原动作体感。
- 每个P事件应当是一个可复述的剧情变化。落地、第三者打断、对白掩饰和离场等不同控制变化不得全部塞进同一个P编号。

详细表格、阈值例外、动词保真、物理来源和形态连续性检查见 [references/pacing-physical-audit.md](references/pacing-physical-audit.md)。

同时执行双向原剧本对照审计：正向逐项确认每条S原文事实被具体镜号完整承载，反向逐项确认最终每个动作、能力、台词与结果均能指回S、N或合法E锚点；差分统一标记为 `漏、改、增、序、力度冲突、台词变更`。任一差分未清零即不具备交付资格，不进入评分，也不进入VFX、摄影、光影或表演润色。

## 2. 大模型内部条件化演绎发散

在读取任何工程参考前，围绕同一套已锁定剧本动作内部构思可行的演绎方向。只有当源剧本留有表现空间且Seedance预算允许时才比较多个方向；输入明确、空间狭窄或多方向会诱发越权时，直接形成一个保真方向。方向只能改变表现机制、覆盖和视听设计，不能提出不同的事件、动作结果、对手策略或剧情升级：

- `运动引擎`：压迫推进、精密拆解、借力反冲、空间折叠、群体错峰、追逐拦截、垂直猎杀等。
- `招式演绎语言`：只从剧本已有动作、能力和性格中提炼角色化的距离偏好、身体/武器节奏与发力方式；剧本未写诱导、反击或代价时不得新增。
- `VFX母题`：能量像什么、如何生长/聚集/分裂/捕猎/污染/崩解，而不只是“什么颜色的光”。
- `环境证明`：优先使用当前场景独有的材质反应、尺度参照或受力后果；只有剧本明确允许时才让环境改变攻防路径、人物选择或控制权。
- `场面力引擎`：哪股力量主导空间，如何扩张、反压、改写战场并留下后果。
- `层次与尺度`：前中后景、高低空间、局部/战场/天地尺度怎样逐步揭示，而不是一开始全部摊开。
- `升级路径`：信息、速度、尺度、控制权或规则如何逐级变化，不只提高亮度和爆炸范围。
- `高潮画面`：一个可以单独描述、具有清楚剪影和视觉记忆点的英雄镜头。
- `摄影与光影母题`：镜头距离、运动节奏、明暗变化怎样随权力关系演化。

默认不向用户展示全部发散草稿。用户只要成品时，在内部选择并融合；用户要求方案比较时再输出候选方向。

发散阶段禁止：

- 读取动作预算、复杂度分值、武器动作模板、VFX层数、量化镜头、轨迹图或评测表。
- 因担心生成失败而提前缩小想象力。
- 用片名、类型词、招式名称或形容词代替真正的动作机制与视觉变化。
- 从参考作品复刻角色、服装、场景、完整招式段落或标志性镜头。

## 3. 剧本锚定演绎融合

选择最能服务人物、剧情与场景且不超过Seedance预算的方向，并吸收其他方向中兼容的强点，形成唯一 `剧本锚定演绎蓝图`：

```text
剧情摘要：[本段1-3句剧情结果]
本段覆盖边界：[起点 -> 终点；后续制作事件]
剧情动作骨架：[P1 -> P2 -> ...；每项的因果和落幅]
一句话演绎钩子：[若剧本与预算允许，这场打斗在表现上最易辨识的视觉或动作证据；无合法空间时写“服从原剧本，不强制新增”]
角色演绎签名：[从剧本已有动作、能力与性格提炼的运动节奏和发力方式；不得制造新招式、诱导、反制或代价]
VFX视觉母题：[形态隐喻、行为规律、显化阶段、色彩与材质语言]
环境参与证明：[地标/材质如何证明已发生的力量；仅在剧本允许时改变战场]
场面力设计：[主力量怎样占领空间、压迫对手、推动环境并形成强弱构图]
层次与规模设计：[动作/VFX/环境/空间/光影层次；局部到战场再到天地尺度的揭示]
宏大感证据链：[尺度参照 -> 力量传播 -> 环境级后果 -> 视听余波]
战果证据链：[代表性目标如何从威胁状态被本场能力规则不可逆击溃 -> 群体结果如何扩展 -> 留下什么残留]
对手博弈：[双方如何获取信息、误判、适应和夺回主动权]
升级曲线：[开场规则 -> 第一次反转 -> 被迫升级 -> 高潮 -> 余波]
摄影与光影母题：[镜头和明暗如何跟随控制权变化]
英雄镜头：[最具记忆点的动作/VFX/构图瞬间]
预算内演绎核：[通过剧本资格门并位于Seedance执行预算内时优先保留的机制或画面]
```

参考影片或动作类型只作为词汇与审美坐标，不作为方案本身。用户未指定参考时，不必为了填表强行选择某部作品。

## 4. 演绎质量门

在工程收敛前检查：

- 剧情摘要、动作骨架和本段覆盖边界是否已锁定；删除所有美术词后，`P`编号仍能复述完整因果。
- 每个高能镜头承担的剧情事件是否唯一；特效不能替代角色意图、路径、受力和控制权变化。
- 演绎润色是否只改变表演、摄影、光影、材质和声音，不得改写已锁定的动作路径、事件顺序或剧情结果。
- 若剧本与预算允许演绎强化，能否用一句话说出这场打斗区别于普通“冲刺、对砍、爆炸”的地方；若无合法空间，不因缺少原创钩子阻断交付。
- 动作、能力、环境和人物性格是否互相生成，而不是四层独立装饰。
- 若剧本存在学习或反制，对手反应是否被清楚演出；若不存在，不得为增强戏剧性主动添加。
- VFX是否拥有行为和演化，能通过轮廓、路径、材质与光影被识别。
- 场面力是否来自力量占区、环境受力和清楚的强弱构图，而不是同屏元素数量。
- 是否至少形成动作、VFX、环境、空间、光影或声音中的三层递进，并让观众分阶段读懂。
- 宏大感是否有尺度参照、力量传播和环境级后果；若只剩形容词、大远景和全屏强光，重新设计。
- 环境级结果之前是否完成 `源点 -> 展开 -> 占区 -> 压迫 -> 后果` 的尺度链；若小型术法显化无过渡地产生巨大后果，重新设计。
- 秒杀、碾压或清场是否同时拥有至少一个代表性目标的局部受术证据和一个群体/战场结果镜；若只见强光、消失或大全景清场，补入近景/特写战果镜。
- 升级是否改变规则、空间或控制权，而不是只加粒子、亮度、数量和尺度。
- 是否通过节奏经济门：首个有效动作及时出现、每镜有新增信息、同一状态没有连续停留、次级链没有被串行化。
- 是否通过语义保真门：原文的动作力度、时序和不可逆结果没有被演绎润色软化或重复。
- 是否通过物理与连续门：每个环境反应有明确力量来源和方向，主要材质反应不超过两种，怪物/VFX形态变化有可见过渡。
- 剧本已有的反转是否由前文规则推出并被清楚呈现；剧本没有反转时不得为通过质量门制造反转。英雄镜头只能聚合原事件，不能新增剧情结果。
- 若源剧本提供了角色性格、能力或动作依据，删除角色名后动作是否仍然像任何人都能使用；若是，优先强化原动作内部的角色化发力与节奏，不得为通过本项新增招式。
- 突出人物或提高一致性后，逐镜VFX是否仍保留原定机制、规模、环境作用、粒子动力、光权和残留；若功能信息减少，判定为过度收敛并补回，不能以“主体更清楚”作为通过理由。

未通过时返回第2步重新演绎；若失败原因是源剧本没有合法创作空间，则保留最清楚的原动作执行，不得为追求演绎分数越权新增内容。

## 5. 完成动作、VFX与摄影设计

基于已通过剧本保真资格门与节奏经济门的剧本保真矩阵扩展整场打斗。节拍数量服从剧本与台词时长，不预设固定3到6拍。先写逐字可对照的“剧本动作版”，再写“演绎润色版”；动作版冻结事件、顺序、运动路径、接触/规避、受力和落幅，润色版只能叠加不会改变局面的连接动作、表演、摄影、VFX、光影、材质和声音。

### 具体演绎设计层（动作冻结后，可扩展）

动作版通过后，建立本段的 `演绎模块清单`，按动作事件选择需要的模块，不设固定数量。每个模块必须引用 `P` 编号和动作落幅，不得新增事件、改变胜负或替换动作机制。以下六项是常见示例，不是完整清单：

1. `造型层`：锁定角色身份、服装轮廓、发型、道具、材质和可持续识别点；先保证主体剪影，再加装饰。
2. `怪物层`：锁定数量、透明度、无脸/多嘴等形态事实、运动行为、威胁等级和受术后的不可逆状态；不得把抽象烟影自动改成通用动物或人形怪兽。
3. `特效层`：写清源点、触发、结构展开、传播路径、占区、遮挡、碰撞/克制和残留；不得用“炫光、魔法阵、爆炸”替代能力规则，也不得以全局VFX说明代替逐镜局部演化。
4. `粒子层`：表现特效和环境的可追踪后果，并优先建立前景受力、中景传播、后景尺度和高空/地面的远近层；每种粒子要有来源、方向、材质反应、尺度参照和停止条件，不能只堆密度。一次主要冲击最多突出两种材质反应，其他材质只作为低幅背景响应。
5. `光影层`：规定环境主光、VFX染色、投影/遮挡、反射、体积介质、曝光变化和下一镜光权继承；大气磅礴时要让光域、阴影、墙面反射、湿地反光或天空体积介质证明力量已经占领空间，不能只写“电影感、神秘光”。
6. `摄影层`：在已锁定的起幅/动作/落幅上选择景别、机位、焦点、遮挡和一个主运镜；摄影负责让主体、动作路径、特效占区和环境后果同时可读，不能靠换角度掩盖动作不清。

可按本段需要启用或新增以下模块：`人物表演/情绪`、`对白/旁白/声音`、`造型/妆发/服装`、`道具/武器`、`场景/置景/环境材质`、`怪物/对手/群演`、`特效结构与物理`、`粒子与碎屑`、`光影/色彩/曝光`、`摄影/运镜/焦点`、`剪辑/转场/节奏`、`连续性/后期合成`。每个模块只回答“如何把已锁定的剧情动作演出来”，并写出：服务的 `P` 事件、可见设计、不能改变的事实、客观验收条件。

演绎模块的默认依赖顺序为：`主体身份与场景锚点 -> 对手/道具状态 -> 人物表演与声音 -> VFX路径与材质 -> 粒子/环境后果 -> 光影与曝光 -> 摄影与剪辑呈现`。具体项目可调整顺序，但必须说明依赖关系；摄影或粒子不能先于动作决定事件，装饰模块不能反向决定剧情。

### 大气磅礴视觉门

高能术法的特效、粒子和光影通过以下检查后才算完成：

- `源点`清楚，但不能长期停留在掌心、小法印或局部光符。
- `展开`拥有独有轮廓、厚度、层级和生长方向，而不是平面图案突然变大。
- `占区`与人物、街道、建筑、天空或地标形成明确尺度差，并改变可通行区、视野或上下空间。
- `压迫`在命中前已经通过风压、投影、遮光、地面承重、墙面反射、尘雾或水体反应被看见。
- `后果`保留力量方向、密度变化、光照变化和残留，不能巨大结构无因消失或凭空变成普通爆炸。
- 至少保留一个主体清楚、主VFX路径清楚、环境受力清楚、尺度参照清楚的英雄落幅。

大气磅礴可以通过局部蓄压、宽镜展开、环境级占区和余波恢复逐级建立；不要求每一镜都满屏高亮，也不能用粒子遮住角色、动作或关键受术证据。

### 逐镜演绎完整性门（交付阻断）

剧情动作优先只冻结因果，不允许把演绎退化为泛光或空景。完成分镜或提示词后，必须主动逐镜审计，不等待用户提醒。逐镜完整度按奇观等级分配：L1保证源点、主体和落幅；L2补一条路径或环境证据；L3建立至少两条空间压迫轴和曝光欠债；L4聚合主体、三维尺度跃迁、代表性作用、环境传播和光权峰值；L5负责回收与恢复。除纯触发特写、必要反应镜和转场镜外，每个高能镜头仍必须能明确指出：

- 对应的 `P` 剧情事件和本镜唯一主动作链。
- 与本镜等级匹配的主体、主路径、尺度参照和空间关系；L1/L2不得为凑齐三层提前消耗L4峰值资源，L4必须同时读出前中后景与低中高空间中的有效关系。
- 至少一条能证明力量方向或控制权变化的环境连锁；高潮镜可使用第二种不同材质或尺度的反应，但一次主冲击最多突出两种，不能为凑数量添加无关物。
- 粒子的来源、方向、材质反馈和停止/残留状态。
- 环境主光、VFX染色、投影/遮挡、反射和曝光变化。
- 人物、怪物、VFX、环境与控制权的唯一稳定落幅。
- 若本镜来自“突出主体、修一致性、降负载”的改稿，必须能指出修改前保留了哪些VFX机制、规模、环境链、粒子链、光权和残留；功能项不得无因减少。

纯特写豁免的空间信息必须由前后相邻宽镜补回，并在审计中指出承载镜号。任一镜头缺少其等级所需证据时，返回具体演绎设计层补写；不得以“动作已清楚”“提示词需要精简”或“用户未明确要求”为由交付低密度画面，也不得以“完整性”为由把每镜写成同等峰值。

### 场面关系与演化门（交付阻断）

画面丰富度来自元素之间的因果关系，不来自字段数量或装饰堆叠。每个高能镜头必须同时通过：

1. `环境因果门`：若本镜存在可见环境且剧本动作会对其产生可推导的作用，选择一个当前场景独有的环境元素证明力量来源、方向、尺度或既定结果，并写清 `动作前状态 -> 受力方式 -> 动作后状态`。源剧本没有环境作用、当前动作不产生外溢力量或Seedance预算不足时，不以缺少环境机制阻断交付。只有源剧本明确写出或唯一允许时，环境才可改变力量路径、可通行区、支撑、控制权或敌我选择；不得为通过本门强造环境机关。
2. `并行动作链门`：除唯一主动作链外，按剧情需要选择一至两条次级证据链，如环境材质链、敌方状态链、光权链、粒子回收链或空间封锁链。普通高能镜保留一条最强证据即可；只有高潮、复杂空间反转或群体战果需要第二条。次级链只能证明和放大 `P` 事件，不能新增剧情，必须在主动作窗口内错峰并行，不得增加镜头等待时长；第二条若不提供新证据就不创建。
3. `场景演化门`：逐镜继承地面、墙体、空中、光照、怪物、道具和粒子残留。每镜至少推进一个场景状态，不得在无解释时恢复原状；高潮后的恢复也要按明确次序发生。
4. `形态升级门`：相邻高能镜头的主VFX不能长期重复同一种圆形扩张、光束、烟雾或爆炸形态。应随剧情动作在点/线/面/体、贴地/垂直/包围、展开/压缩/断裂/回流等状态间产生有因果的变化。

环境机制和次级链必须来自当前人物、能力和场景，不得为了填门加入无关道具、随机天气、通用碎片或没有前后状态的装饰物。

交付前必须执行一次内部 `逐镜画面关系表`：`镜号 | P事件 | 奇观L级 | 唯一叙事目标 | 节奏职责/时长 | 独立起始状态 | 主动作执行者/肢体/对象 | 起点/路径/接触或规避 | 新增信息或控制权 | 环境机制（前/中/后） | 次级链A/B（并行窗口） | 前景/中景/后景 | 高低空间/压迫轴 | 主要材质（最多两种） | 粒子路径 | 力量来源/方向 | 光权变化 | 峰值资源占用/相邻差值 | 运镜绑定/触发/揭示/制动 | 本镜新增状态 | 稳定落幅 | 反向复述 | 通过/退回`。该表默认不展示给用户，但所有镜头通过后才允许导出文件或最终提示词。

演绎验收顺序为：`动作可读性 -> 主体/身份连续 -> 事件所需模块完整 -> 层次与光权 -> 摄影/剪辑可读性`。任何一项不通过，先修该项；不得回退为泛化动作或删除 `P` 事件。

每个节拍先回答原剧本在这里写了什么，再回答怎样把它演清楚：角色想改变什么、剧本规定对手如何回应、原动作/VFX如何发生、环境怎样证明力量、控制权发生什么变化。补充动作只能连接、支撑、回收或证明原动作，不能形成新的攻击、躲避、反制、能力或控制权变化。

整场按 `局部动作证据 -> 中层攻防关系 -> 战场范围改变 -> 高潮尺度揭示 -> 余波落地` 组织场面。不是每镜都塞满五层，但关键高潮镜至少同时看见主体动作、主VFX路径、环境受力和一个尺度参照；前镜负责蓄压，高潮负责释放，后镜负责证明后果。

秒杀与碾压段落先锁定一个 `代表性败亡镜`：镜头聚焦最接近主角、威胁剪影最清楚或最能展示克制关系的目标，让术法介入路径、敌方动作中断、材质/能量状态变化和不可逆落幅在正常速度下可读；再切回宽镜证明同一规则如何同时作用于全体。不得把“减少人物表演”误用为删除该镜。

为每个高能节拍先写一条与奇观等级匹配的 `画面密度句`。L1/L2只承担本镜必要的源点、路径或一条证据；L3按 `压迫轴 -> 主体 -> 威胁占区 -> 曝光欠债 -> 落幅` 蓄压；L4按 `前景受力证据 -> 中景主体与主路径 -> 后景尺度跃迁 -> 低中高空间 -> 光权峰值 -> 稳定落幅` 完成释放；L5明确回收。环境反应不能永远停留在裂地、扬尘或全屏爆炸；根据当前地标与材质设计具有方向、传播次序和残留的连锁反应。

打击感来自完整力量证据：支撑与蓄势、加速、接触面变化、受击者重心/身体块位移、攻击者反作用与回收、护具/武器/地面的二次反馈。微表情只能补充决策或疼痛，不能替代动作和特效。

摄影机不是记录员。每镜按 `绑定对象 -> 动作触发 -> 单一轨道 -> 揭示新信息 -> 结果制动 -> 为下一动作预留空间` 设计；只揭示来源、路径、接触/规避或结果。高速躲避优先稳定机位或短跟随，尺度展开才拉开，冲击证据出现时制动；不得为了“炫”让摄影机抢走动作或无因换向。

### 视觉动力交接门（后置保护）

剧本动作版、剧情节奏和已选演绎核锁定后，再审核 `第一读点 -> 主动作/VFX路径 -> 结果证据 -> 下一镜入口`。本门只允许调整画面主次、VFX状态桥、粒子受力证据和摄影机轨道；不得增删、改序或改时 `P` 事件，不得改写对白、人物意图、情绪落点、剧本招式和结果。若发生冲突，让摄影机、粒子和次级特效适配已锁定剧情，不能反向修改剧情。

相邻镜头必须继承至少一项可见动力：主体/VFX运动方向、屏幕位置、形态残留、遮光区、受力粒子或声音趋势。摄影机以主体、接触点或VFX波前之一为绑定对象，只为揭示来源、路径、控制权变化或战果而运动，并在结果可读时制动；不得追逐装饰粒子、无因反向或在切镜后把动作重置为中性起幅。详细审核见 [references/pacing-physical-audit.md](references/pacing-physical-audit.md)。

1. 先写出必须保留的 `剧本事实`，再写不与其冲突且位于执行预算内的 `预算内演绎核`。
2. 找到真正的生成风险，不因“可能不稳定”泛化删减。
3. 优先拆镜、改变覆盖角度、分阶段显化、降低同时性或移动摄影机复杂度；先保证剧本事件、动作和结果，再使用剩余预算保留最大演绎强度。
4. 不无故删除服务原剧本的招式证据、VFX母题、环境机关、场面层次、尺度参照、宏大感证据链、代表性败亡镜或英雄镜头；若它们与剧本动作可读性或Seedance 2.5执行合同冲突，按生成预算优先级收敛，并记录被删E项。
5. 不把已定大型术法的展开/占区阶段压缩成掌心符、普通光球、小法印或平面圆阵；平台负载过高时拆分源点、展开和作用覆盖，并保持体积/能量连续。
6. 若平台限制迫使核心变化，明确说明冲突并给出保真度最高的替代，不静默退回通用动作。
7. 收敛后再次做演绎保真检查；若原钩子、场面力、高潮尺度和英雄镜头仍在剧本与执行预算内却无法复述，返回第5步；若它们超出预算，则记录E项差分并保留最强的剧本动作与结果证据。

## 7. 制作镜头与专家协作

需要完整制作时读取 [references/integrated-workflow.md](references/integrated-workflow.md)。先把 `剧本保真矩阵`、`剧本锚定演绎蓝图` 和 `预算内演绎核` 传给所选模块，再传后置工程字段。按任务实际需要选择模块，不得默认全部调用；未启用的模块不运行，也不输出空字段。

- `frames-analysis`：细化构图、材质、光源和遮挡，不能改写动作或VFX母题。
- `camera-analysis`：量化已定摄影意图，不能用默认机位替换英雄镜头，也不能裁掉建立宏大感的尺度参照。
- `overhead-trajectory-map`：仅在复杂走位、高度、VFX占区或移动摄影机需要空间确认时使用；只翻译事实，不新增动作。
- `continuity-ledger`：记录每镜落幅、武器、伤势、残留和曝光状态。
- `audio-design`：在动作时点确定后设计冲击、材质、静音和余波。
- `emotion-analysis`：只在表演直接影响佯攻、判断、忍痛或恢复时调用，每镜最多一个必要锚点。

一个生成片段可因平台限制只保留一个主动作链和一个主运镜，但整场创意不受此限制。复杂英雄动作应拆成连续覆盖，而不是简化成普通动作。

完整制作在内部保留 `设计台账`，记录完整构图、场面层次、环境连锁、光影、奇观密度与拆镜去向；该台账不得跳过Seedance预算直接成为用户成品。最终主文件只交付已经完成动作预算拆分、对白时长校准、独立状态补足和反向复述的 `Seedance 2.5生成版`。用户未明确索要时，不交付内部设计台账；即使索要，台账也必须与最终生成文件分开并标明不可直接投喂。

## 8. 关键帧、轨迹与即梦提示词

需要姿态控制时，用 [references/keyframe-motion-control.md](references/keyframe-motion-control.md) 把已定事件拆成 `K0起幅 -> K1预备 -> K2承诺 -> K3接触/反转 -> K4落幅`。关键帧只锁状态，不重新设计动作。

需要双视图时，把人物平面起终点、高度、道具、主VFX路径/占区、摄影机轨道和前镜状态交给 `overhead-trajectory-map`。最终视频提示词只保留真实画面事实，不出现虚线、S/E、CAM、图例、俯视图或立面图等地图标注。

即梦/Seedance 2.5提示词采用中文可见描述，不设固定字数上限。可以删除重复形容、同义复述和无执行价值句子，但不得压缩必要独立起始状态、动作归属与肢体、起点与路径、接触/规避、反作用、稳定结果、源剧本规定的VFX、必要粒子/环境后果、光影结果、声音和台词。字数不等于执行预算；文字再长也只能承载预算允许的一个核心动作和一个主运镜，过载时拆镜。内部先绑定 `原文证据 + P编号 + 唯一叙事目标`；最终正文不写内部编号，而按上述事实写成顺序明确的执行链。禁止跨镜替代语、抽象意图代替可见动作、同一时段互斥姿态、多个主运镜或让特效先于动作决定结果。

每镜生成前先做 `动作归属表`，生成后再做 `反向复述`：仅凭最终该镜文字，能否唯一回答谁、在哪里、以哪只肢体/何种能力、沿何路径、对谁、是否接触或躲开、结束在哪里、谁取得控制权。去掉风格词和特效形容后仍不能还原原剧本动作，或存在第二种合理解读，立即退回重写。

每镜负面提示词针对真实风险，不用通用长名单替代正向设计。参考影片只能转译为动作节奏、接触反馈、VFX克制、环境利用和摄影机语言，不能要求复刻原片。

## 9. 交付与Markdown导出

- 内部制作台账读取 [references/delivery-template.md](references/delivery-template.md)，记录剧本保真矩阵、剧本锚定演绎蓝图、预算内演绎核、双向原剧本审计与工程控制；该台账不是默认成品。
- 用户明确索要制作台账时，分析部分按 `剧情摘要 -> 本段覆盖边界 -> 剧情动作骨架 -> 剧本保真资格门结果 -> 剧本锚定演绎蓝图` 组织并另建补充文件；这些分析不得混入最终逐镜Markdown。
- 用户要求分镜、Markdown、一键复制或最终提示词时，读取 [references/copy-ready-markdown.md](references/copy-ready-markdown.md)，并把其中的六字段逐镜格式视为固定交付合同，而非参考偏好。
- 最终主交付必须是已经通过剧本保真资格门、动作预算、并行时长校准、独立状态与反向复述的 `Seedance 2.5生成版`；不得以导演版、蓝图、审计表或未经拆镜的完整设计代替。
- 写出UTF-8 `.md` 文件，并在最终回复用一个代码块逐字展示同一正文。制作分析与最终可复制文本分别交付，不混在同一文件。
- `ai-video-agent-mode` 只用于跨场景项目、批量QA、XLSX或更大流水线；单场打斗的Markdown由本技能直接完成。

### 固定逐镜输出合同（交付阻断）

最终分镜正文只能由连续镜头块组成。每个镜头严格使用以下顺序，字段名、全角分隔符、冒号、两位镜号、时长单位和空行均不得改变：

```text
镜号 01｜超远全景｜镜头缓慢向前匀速推进，微俯角｜2.2s

画面内容：……

特效：……

光影：……

音效：……

台词：无
```

- 标题只允许 `镜号 NN｜景别｜一个主运镜及角度｜时长s`；不加 `P编号`、Markdown标题符号、粗体或其他栏目。
- 正文只允许且必须依次出现 `画面内容、特效、光影、音效、台词` 五个字段；每字段独占一个自然段，段间保留一个空行。无内容时写 `无`，不得省略字段。
- `画面内容`严格按 `必要独立起始状态 -> 唯一叙事目标的主动作 -> 执行者/肢体/路径 -> 接触或规避 -> 反作用 -> 稳定落幅` 组织；`特效`严格按 `可见源点 -> 动作触发 -> 主体结构 -> 传播/第一作用 -> 核心粒子与环境反应 -> 停止或残留` 组织。不得另设 `人物主体、动作证据、动作与打击、场面与层次、落幅与衔接、负面提示词` 等字段。
- 每个镜头块必须自足。连续性在内部台账中继承，但最终文字必须把该镜所需的人物位置/朝向/肢体状态、敌方位置/正在进行的威胁、活跃VFX、环境破坏与光照状态重新写出；不得使用跨镜指代替代这些事实。
- `P`编号、连续性台账、VFX差分和质量门只用于内部审核，不进入最终逐镜正文。对白、OS、OV、系统音等均收进 `台词` 一栏并保留身份标记；对白过长时拆镜，不增加字段。
- 输出后先按 [references/script-fidelity-timing-audit.md](references/script-fidelity-timing-audit.md) 完成双向原剧本资格、文字负载和并行时长审计，再运行 `python scripts/validate_storyboard_format.py <成品.md>`。任一验证失败时先修复再交付；不得以信息密度高为由改回扩展字段。

## 10. 成片复盘

用户提供成片、关键帧或失败描述时，先恢复源剧本与剧本保真矩阵，再保护预算内的演绎核，随后读取 [references/generation-feedback-loop.md](references/generation-feedback-loop.md)。定位最早错误帧，区分剧本保真、演绎翻译和平台生成问题。

复盘先对照 `剧情摘要`、`P`编号和本段覆盖边界，再评估风格和质感。报告必须区分：`未覆盖的后续事件`、`已覆盖但动作因果错误`、`动作正确但演绎/VFX偏移`，不能把三者合并成“剧情缺失”。

修复顺序为：身份/肢体 -> 空间/轴线 -> 动作因果/接触 -> VFX来源/遮挡/光照 -> 摄影机 -> 质感。每轮只修一个主根因；不得用全量重写、通用动作或删除英雄镜头掩盖局部失败。

标准评测必须同时报告 `打斗/VFX表现`、`场面力/层次/宏大尺度保真` 和 `生成可读性与稳定性`。没有真实成片时只能评设计，不能声称平台通过率。

# 创意优先的打斗戏视频设计

把大模型当作动作导演、VFX概念导演和场面调度导演。先创造打斗机制、特效奇观、场面力量、空间层次和宏大尺度，再进行导演整合；动作预算、物理、连续性、轨迹和平台稳定性只在创意定案后介入。

本技能设计虚构动作戏。涉及真人实拍时，只输出创意预演，并提醒由合格动作指导、特技团队和现场安全人员完成落地。

## 创作权威

按以下优先级裁决冲突：

1. 用户明确设定、剧情结果、角色身份、能力边界和禁止项。
2. 大模型完成的 `创意导演蓝图` 与其中标记的 `不可牺牲创意核`。
3. 动作、VFX、摄影和声音的导演表达。
4. 生成稳定性、空间量化、轨迹图、格式和评测规则。

工程规则只能让创意更可读、更连续、更可生成，不能决定创意是什么。若一个想法单镜无法生成，优先拆成多个镜头、改换覆盖角度或分阶段显化；不得自动替换成普通冲拳、常规横斩、泛用光束、全屏爆炸或模板化慢动作。

## 设计重心

默认把主要设计注意力放在五个相互驱动的方向：

1. `打斗`：原创攻防机制、力量传递、接触反馈、反制与局面改变。
2. `特效`：拥有行为规律、形态演化、材质作用和光影后果的VFX，不只增加颜色与粒子。
3. `场面力`：主力量如何占领空间、压迫对手、撼动环境并在一个画面内形成清楚的强弱关系；不等于堆满人物和爆炸。
4. `层次感`：动作前后层、VFX传播层、环境反应层、空间高低层、光影明暗层和声音远近层共同推进，而不是所有信息同时贴在同一平面。
5. `宏大感`：用尺度参照、由近及远的力量传播、收缩与释放、环境级后果及余波证明规模，不靠“宏大、史诗、震撼”等形容词冒充画面。

高能、仙侠、超能力或战争型场景默认强化这五项。贴身写实或狭小空间不强行加入巨物，但仍通过力量密度、空间压迫、材质反馈和景别反差建立场面力。

## 画面密度与光影硬门

`单镜一个主动作链/主VFX事件`只限制叙事焦点，不限制画面层次。不得把动作预算、生成稳定性或“减少人物微动作”误写成简单背景、单层构图、空洞大远景或只有人物加泛光的画面。用户要求减少表演、手势或招式数量时，把释放出的信息预算转移给环境参与、VFX传播、空间层次、尺度参照、材质反应和光影变化；不能同步降低整镜画面密度。

除纯触发特写、必要反应镜和转场镜外，每个高能镜头进入工程收敛前必须通过：

1. `主体层`：主要角色的清楚姿态、动作线、控制权或受力状态。
2. `路径层`：主动作/VFX的来源、方向、占区、碰撞或规则变化。
3. `环境层`：至少一条由近及远的环境反应链；高潮镜至少包含两种不同材质或尺度的连锁后果。
4. `空间层`：前景受力证据、中景攻防主体、后景尺度参照中至少三项可读，并写清高低关系。
5. `光影层`：环境主光、VFX染色、遮挡/投影、材质反射、曝光变化和下一镜恢复/继承中，凡本镜发生者必须具体写出。
6. `落幅层`：画面结束时人物、敌人、VFX、环境残留和控制权有唯一稳定状态。

高潮英雄镜必须在同一决定性构图内同时看见主体、主VFX路径或占区、环境受力和尺度参照。若单镜负载过高，拆成相邻覆盖建立来源与过程，但必须保留一个聚合这些要素的稳定英雄落幅。若镜头只能被概括为“人物做动作/站立 + 特效出现 + 环境震动”，视为画面设计未完成，返回动作/VFX/摄影设计继续扩展。

整场必须先设计 `光权变化曲线`：环境光由谁掌控、敌方如何遮蔽或污染、主角如何夺回曝光、高潮怎样短暂抬升、余波怎样恢复。不能用“电影感光影、神秘光、炫目光芒、史诗照明”等抽象词代替光源方向、作用距离、遮挡、反射、投影、体积介质和曝光后果。

### 术法规模连续性门

用户要求宏大、碾压、高能、巨物或环境级术法时，强制建立 `清晰源点 -> 结构展开 -> 空间占领 -> 环境压迫 -> 战场后果` 五阶段尺度链。人物动作可以极小，术法显化不能因此保持小气；`小动作`与`小特效`不是同一件事。

- `清晰源点`：让观众知道术法从手、法器、阵眼或环境何处开始，但源点特写不承担最终规模。
- `结构展开`：在相邻宽镜中让符、阵、法相、召唤或能量显出独有轮廓、厚度、层级与生长方式；不能长期停留为掌心符、普通光球、小法印或平面圆阵。
- `空间占领`：大型术法至少与人物、建筑、街道、山体或天空中的一个明确参照形成数倍尺度差，并改变可通行区、视野、光域或上下空间。
- `环境压迫`：在真正命中前就让风压、投影、遮光、地面承重、建筑形变、尘雾或水体证明其存在；不能只在爆炸后补环境反应。
- `战场后果`：最终作用范围、力量方向和残留必须与此前显化规模一致。

若大型结构压缩、折叠、汇聚或消散为后续攻击，写清体积/能量如何转移，保留可追踪的路径、密度变化、光照变化和环境响应；禁止巨大结构无因果瞬间消失，再凭空出现街区级爆炸。小型源点可以作为精密控制或反差，但必须在一到两个相邻覆盖内完成可见扩张，或由同等清楚的环境占区证明规模。

宏大术法的核心显化至少满足下列两项：超过人物数倍的清楚轮廓；占领建筑/街道/天空区域；拥有地标尺度参照；投下可见光影或空间压力；引发由近及远的环境连锁。若结果影响整条街、战场或天地，而主要显化始终只有掌心符、普通光球、小法印或平面圆阵，判定尺度链断裂，返回VFX设计阶段。

### 秒杀与碾压战果硬门

剧情包含秒杀、碾压、群体清场、一击破法或瞬间处决时，强制建立 `威胁承诺 -> 代表性个体受术证据 -> 群体/战场结果 -> 残留` 战果链。大全景负责证明规模，近景或特写负责证明术法怎样赢；二者不能互相替代。

- 至少选择一个代表性目标，用近景、特写或同等清楚的局部覆盖呈现三个可读状态：命中前仍具威胁、力量介入并打断其动作、不可逆的败亡/失能落幅。
- 受术证据必须体现本场能力规则，如运动骤停、能量沿躯体传播、材质焦枯/结晶/剥离/坍缩、轮廓失真或被阵法回收；不得只用闪白、爆炸遮挡、倒飞或切到空景代替。
- 默认景别节奏为 `主角/术法英雄宽镜 -> 敌方秒杀近景或特写 -> 群体覆灭大全景 -> 环境残留`。可因节奏调整顺序，但不能同时删除局部战果证据和全局规模结果。
- `减少主角微动作、微表情或表演`不等于减少敌方受术证据。秒杀特写拍的是力量规则和目标状态变化，不是主角表演。
- 只有当同一宽镜能在正常观看速度下一眼读清一个代表性目标的介入过程与不可逆落幅时，才可省略独立特写；必须在分镜说明中指出该局部证据位于画面何处。

若观众只能知道“敌人消失了”，却看不清“为何被这一术秒杀”，判定战果链断裂，返回动作/VFX/摄影设计补镜。

## 唯一工作流

必须依次执行：

```text
不可变事实提取
-> 大模型内部创意发散
-> 导演选择与融合
-> 创意质量门
-> 动作/VFX/运镜完整设计
-> 后置工程收敛
-> 生成提示词与交付
-> 成片复盘
```

不存在“先锁动作/VFX/预算再创作”的备用路径。不得因时间短、输入少、用户只要最终提示词或需要批量输出而跳过创意发散、导演融合和创意质量门。

## 1. 提取不可变事实与创作空间

先分成两组，不要把所有输入都变成限制。

### 不可变事实

- 为什么打、剧情必须到达的结果、胜负条件和不能改变的事件。
- 角色身份、已声明武器/能力、战力边界、伤害尺度和禁用内容。
- 场景时代、关键地标、必须保留的道具、素材ID、时长、平台和画幅。
- 用户明确指定的风格、镜头、台词、高潮画面或必须出现的招式。

### 创作空间

- 角色如何利用能力、身体、武器和环境形成独有打法。
- 对手如何观察、试探、诱导、反制和迫使打法升级。
- VFX采用什么视觉母题、行为规律、显化阶段和光影主题。
- 哪个环境元素参与攻防，战场如何被逐步改变。
- 动作节奏、反转、高潮构图、摄影机关系和声音留白。

缺失信息优先做有风格、有因果的创造性推断，不使用“最保守、最常规”的默认答案。只有缺失项会改变角色身份、能力边界、剧情结局或内容尺度时才询问。

## 2. 大模型内部创意发散

在读取任何工程参考前，内部构思至少三个本质不同的方向。三个方向不能只是颜色、武器或镜头景别不同，而要在下列维度形成不同组合：

- `运动引擎`：压迫推进、精密拆解、借力反冲、空间折叠、群体错峰、追逐拦截、垂直猎杀等。
- `招式语言`：角色独有的距离偏好、身体/武器节奏、诱导方式、反击逻辑和代价。
- `VFX母题`：能量像什么、如何生长/聚集/分裂/捕猎/污染/崩解，而不只是“什么颜色的光”。
- `环境机制`：至少一个只在当前场景成立的攻防机关、材质反应或地形变化。
- `场面力引擎`：哪股力量主导空间，如何扩张、反压、改写战场并留下后果。
- `层次与尺度`：前中后景、高低空间、局部/战场/天地尺度怎样逐步揭示，而不是一开始全部摊开。
- `升级路径`：信息、速度、尺度、控制权或规则如何逐级变化，不只提高亮度和爆炸范围。
- `高潮画面`：一个可以单独描述、具有清楚剪影和视觉记忆点的英雄镜头。
- `摄影与光影母题`：镜头距离、运动节奏、明暗变化怎样随权力关系演化。

默认不向用户展示全部发散草稿。用户只要成品时，在内部选择并融合；用户要求方案比较时再输出候选方向。

发散阶段禁止：

- 读取动作预算、复杂度分值、武器动作模板、VFX层数、量化镜头、轨迹图或评测表。
- 因担心生成失败而提前缩小想象力。
- 用片名、类型词、招式名称或形容词代替真正的动作机制与视觉变化。
- 从参考作品复刻角色、服装、场景、完整招式段落或标志性镜头。

## 3. 导演选择与融合

选择最能服务人物、剧情与场景的方向，并吸收其他方向中兼容的强点，形成唯一 `创意导演蓝图`：

```text
一句话创意钩子：[这场打斗独特在哪里]
角色动作签名：[每个主要角色的运动引擎、偏好距离、诱导/反制方式、代价]
VFX视觉母题：[形态隐喻、行为规律、显化阶段、色彩与材质语言]
环境参与机制：[地标/材质如何被利用，并怎样改变战场]
场面力设计：[主力量怎样占领空间、压迫对手、推动环境并形成强弱构图]
层次与规模设计：[动作/VFX/环境/空间/光影层次；局部到战场再到天地尺度的揭示]
宏大感证据链：[尺度参照 -> 力量传播 -> 环境级后果 -> 视听余波]
战果证据链：[代表性目标如何从威胁状态被本场能力规则不可逆击溃 -> 群体结果如何扩展 -> 留下什么残留]
对手博弈：[双方如何获取信息、误判、适应和夺回主动权]
升级曲线：[开场规则 -> 第一次反转 -> 被迫升级 -> 高潮 -> 余波]
摄影与光影母题：[镜头和明暗如何跟随控制权变化]
英雄镜头：[最具记忆点的动作/VFX/构图瞬间]
不可牺牲创意核：[后续拆镜、生成适配和修复都必须保留的机制或画面]
```

参考影片或动作类型只作为词汇与审美坐标，不作为方案本身。用户未指定参考时，不必为了填表强行选择某部作品。

## 4. 创意质量门

在工程收敛前检查：

- 能否用一句话说出这场打斗区别于普通“冲刺、对砍、爆炸”的地方。
- 动作、能力、环境和人物性格是否互相生成，而不是四层独立装饰。
- 对手是否会学习和反制，而不是等待主角展示技能。
- VFX是否拥有行为和演化，能通过轮廓、路径、材质与光影被识别。
- 场面力是否来自力量占区、环境受力和清楚的强弱构图，而不是同屏元素数量。
- 是否至少形成动作、VFX、环境、空间、光影或声音中的三层递进，并让观众分阶段读懂。
- 宏大感是否有尺度参照、力量传播和环境级后果；若只剩形容词、大远景和全屏强光，重新设计。
- 环境级结果之前是否完成 `源点 -> 展开 -> 占区 -> 压迫 -> 后果` 的尺度链；若小型术法显化无过渡地产生巨大后果，重新设计。
- 秒杀、碾压或清场是否同时拥有至少一个代表性目标的局部受术证据和一个群体/战场结果镜；若只见强光、消失或大全景清场，补入近景/特写战果镜。
- 升级是否改变规则、空间或控制权，而不是只加粒子、亮度、数量和尺度。
- 是否存在至少一个由前文规则推导出的意外反转和一个清楚的英雄镜头。
- 删除角色名后，动作是否仍然像任何人都能使用；若是，重新发散。

未通过时返回第2步重新创作，不能进入工程阶段后用更多表格掩盖创意贫乏。

## 5. 完成动作、VFX与摄影设计

基于创意导演蓝图扩展整场打斗。节拍数量服从剧情与时长，不预设固定3到6拍。

每个节拍回答：角色想改变什么、对手如何回应、标志性动作/VFX如何发生、环境怎样参与、控制权发生什么变化。动作应有发力、路径、接触或规避、反作用和新局面；斗法应有来源、行为、碰撞、克制、环境反馈和残留。

整场按 `局部动作证据 -> 中层攻防关系 -> 战场范围改变 -> 高潮尺度揭示 -> 余波落地` 组织场面。不是每镜都塞满五层，但关键高潮镜至少同时看见主体动作、主VFX路径、环境受力和一个尺度参照；前镜负责蓄压，高潮负责释放，后镜负责证明后果。

秒杀与碾压段落先锁定一个 `代表性败亡镜`：镜头聚焦最接近主角、威胁剪影最清楚或最能展示克制关系的目标，让术法介入路径、敌方动作中断、材质/能量状态变化和不可逆落幅在正常速度下可读；再切回宽镜证明同一规则如何同时作用于全体。不得把“减少人物表演”误用为删除该镜。

为每个高能节拍先写一条 `画面密度句`，按 `前景受力证据 -> 中景主体与主路径 -> 后景尺度变化 -> 高低空间 -> 光权变化 -> 稳定落幅` 描述同一画面。纯特写可以只承担源点或决定，但相邻宽镜必须补回被省略的空间、环境与尺度。环境反应不能永远停留在裂地、扬尘或全屏爆炸；根据当前地标与材质设计具有方向、传播次序和残留的连锁反应。

打击感来自完整力量证据：支撑与蓄势、加速、接触面变化、受击者重心/身体块位移、攻击者反作用与回收、护具/武器/地面的二次反馈。微表情只能补充决策或疼痛，不能替代动作和特效。

摄影机不是记录员。为创意蓝图设计景别梯度、距离变化、速度、遮挡、焦点与光影反转；命中是否稳定、环绕是否越轴、英雄镜头是否拉开尺度，全部服务本场独有的动作与VFX。

工程收敛遵守最小干预：

1. 先写出必须保留的 `不可牺牲创意核`。
2. 找到真正的生成风险，不因“可能不稳定”泛化删减。
3. 优先拆镜、改变覆盖角度、分阶段显化、降低同时性或移动摄影机复杂度。
4. 不删除招式机制、VFX母题、环境机关、反转逻辑、场面层次、尺度参照、宏大感证据链、代表性败亡镜或英雄镜头。
5. 不把已定大型术法的展开/占区阶段压缩成掌心符、普通光球、小法印或平面圆阵；平台负载过高时拆分源点、展开和作用覆盖，并保持体积/能量连续。
6. 若平台限制迫使核心变化，明确说明冲突并给出保真度最高的替代，不静默退回通用动作。
7. 收敛后再次做创意保真检查；无法复述原钩子、场面力、高潮尺度和英雄镜头时返回第5步，而不是继续降级。

## 7. 制作镜头与专家协作

需要完整制作时读取 [references/integrated-workflow.md](references/integrated-workflow.md)。先把 `创意导演蓝图` 和 `不可牺牲创意核` 传给所有模块，再传后置工程字段。

- `frames-analysis`：细化构图、材质、光源和遮挡，不能改写动作或VFX母题。
- `camera-analysis`：量化已定摄影意图，不能用默认机位替换英雄镜头，也不能裁掉建立宏大感的尺度参照。
- `overhead-trajectory-map`：仅在复杂走位、高度、VFX占区或移动摄影机需要空间确认时使用；只翻译事实，不新增动作。
- `continuity-ledger`：记录每镜落幅、武器、伤势、残留和曝光状态。
- `audio-design`：在动作时点确定后设计冲击、材质、静音和余波。
- `natural-emotion-performance`：只在表演直接影响佯攻、判断、忍痛或恢复时调用，每镜最多一个必要锚点。

一个生成片段可因平台限制只保留一个主动作链和一个主运镜，但整场创意不受此限制。复杂英雄动作应拆成连续覆盖，而不是简化成普通动作。

完整分镜默认分为两层：

- `导演版分镜`：先保留完整构图、场面层次、环境连锁、光影和奇观密度，不让生成限制反向决定创意。
- `生成版拆镜`：再把导演版事件拆为平台可承受的相邻片段；每次拆分记录被分配到哪一镜，不得删除英雄落幅、尺度证据或光权变化。

用户只要求一种分镜时，默认交付导演信息密度完整、同时已经通过动作预算拆分的版本；不能直接输出只有景别、人物动作和一句泛化特效的简表。

## 8. 关键帧、轨迹与即梦提示词

需要姿态控制时，用 [references/keyframe-motion-control.md](references/keyframe-motion-control.md) 把已定事件拆成 `K0起幅 -> K1预备 -> K2承诺 -> K3接触/反转 -> K4落幅`。关键帧只锁状态，不重新设计动作。

需要双视图时，把人物平面起终点、高度、道具、主VFX路径/占区、摄影机轨道和前镜状态交给 `overhead-trajectory-map`。最终视频提示词只保留真实画面事实，不出现虚线、S/E、CAM、图例、俯视图或立面图等地图标注。

即梦提示词采用中文可见描述，通常每镜180到420字。先写该镜承担的创意事件，再写角色与场景、动作/VFX、场面层次与尺度参照、摄影机、光影、材质后果和稳定落幅。提示词过载时，优先拆镜；删减顺序从装饰性微表情、重复形容、次级粒子开始，不删除创意核、场面层次、宏大感证据或代表性败亡镜。

每镜负面提示词针对真实风险，不用通用长名单替代正向设计。参考影片只能转译为动作节奏、接触反馈、VFX克制、环境利用和摄影机语言，不能要求复刻原片。

## 10. 成片复盘

用户提供成片、关键帧或失败描述时，先保护原创意核，再读取 [references/generation-feedback-loop.md](references/generation-feedback-loop.md)。定位最早错误帧，区分创意问题、翻译问题和生成问题。

修复顺序为：身份/肢体 -> 空间/轴线 -> 动作因果/接触 -> VFX来源/遮挡/光照 -> 摄影机 -> 质感。每轮只修一个主根因；不得用全量重写、通用动作或删除英雄镜头掩盖局部失败。

标准评测必须同时报告 `打斗/VFX表现`、`场面力/层次/宏大尺度保真` 和 `生成可读性与稳定性`。没有真实成片时只能评设计，不能声称平台通过率。

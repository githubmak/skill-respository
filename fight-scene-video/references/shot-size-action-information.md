# 打斗景别与动作承载

景别不从“最大信息量”或“最低风险”开始选择。先完成威胁、战术、情绪和动作骨架，再决定观众应当感受战场规模、速度、重量、压迫、失衡还是疼痛，并为动作因果安排清晰读取窗口。

## 联合设计顺序

```text
威胁与控制权变化
-> 攻防动作骨架
-> 观众心理距离与动作体感
-> 起幅景别
-> 运镜和焦点交接
-> 终幅景别
-> 反向设计具体站位、攻防路径、VFX纵深和环境受力
-> 校正动作因果与物理空间
```

景别决定某一时刻能看见战场、全身发力、武器路线、接触点、表情还是伤势；运镜决定观众怎样跟随、压近、拉开、俯冲、扫视或停留。必须同时成立的攻击双方和接触或规避放在同一读取窗口；可以顺序读取的来源、路径、破绽、反应、伤势和结果，可以交给镜内变化或相邻镜头。

## 景别承载范围

- 大全景：宏大环境、战场尺度、阵型和 VFX 占区；不承担微表情、手印和精确接触。
- 全景：全身攻防、脚下借力、多人站位、位移路线和落点；不承担眼神和手指细节。
- 中全景：全身姿态、敌我距离、武器大幅路线和明显受力；不承担局部材质或精细表情。
- 中景：近身攻防、上半身发力、武器交锋和控制权关系；不承担大范围追逐或复杂脚步。
- 中近景或近景：表情压力、手臂与武器局部、接触前停顿和受击反应；不承担全身路径和群体阵型。
- 特写或大特写：单一关键接触、刃口、手印、伤势、力量源点或战果细节；不同时承担战场关系。

## 组合原则

- 起幅先承载第一层动作信息，运镜只在能产生第二层读取或体感时使用，终幅必须稳定可读。
- 近身格挡可以从中全景读敌我位置和武器路线，镜头沿受力方向靠近到中景，在接触发生时停稳；若还需看刃口或伤手，再切独立特写，不让一个镜头承担互斥范围。
- 控制权翻转可以从接触近景拉开到全景，让观众看见失衡人物、地标和新距离；伤势冲击也可以固定在近景，让表演和声音承担重量。
- 固定中景合法。它适合近身僵持、控制动作、接触窗口和余波观察；只有横移、跟随、推进、拉开、升降、反打或特殊运镜能更准确传达路径、重量、速度、压迫或结果时，才选择其他组合。
- 连续固定中景不是自动错误，连续没有战术和观看理由的固定中景才是问题。机械轮换景别同样无效。

隐式校正：写全身位移或脚下受力必须使用能看见全身的景别；写近身控制或武器交锋至少能看见双方上半身与接触关系；写眼神、手印、刃口或伤口才进入近景或特写。一个读取窗口同时要求全身路径和微表情时，拆镜或用先后景别完成，不写“同时清楚可见”。

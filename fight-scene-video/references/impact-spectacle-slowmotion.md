# 表现放大：慢镜、宏大特效、真实粒子与打击反馈

只在源剧本事实、动作骨架、空间锚点和导演演绎蓝图已经通过保真门后读取。本参考允许放大观感，不允许改写事件。

## 1. 叙事时间与观看时间分离

原剧本的时间、速度、次数和结果属于S事实，不能被放慢、重复、延迟或改序。慢镜/升格只改变观众观察动作的时间分辨率，不改变角色在剧情中的实际完成时间。

- 可在决定性接触、擦身闪避、规则介入、控制权突变、落地承重或宏大结构展开处短暂升格，让力量方向、材质反应和人物状态可读。
- 升格结束必须回到原动作的速度体感，或通过声音、残影、光权和连续轨迹明确回到正常时序。
- 原文写“瞬间、骤然、急速、同时、只一次”时，不得把整段改成慢蓄力、分批发生或重复完成；可以只放大关键观察窗口。
- 慢镜不自动添加新攻击、反击、表情、伤势、对白、能力或控制权变化。

## 2. 宏大特效放大

宏大不是把画面变亮、变满或增加爆炸数量。只在当前能力和场景允许时，从以下证据中动态选择：源点、独有轮廓、结构展开、纵深占区、地标尺度、环境压迫、光域变化、战场后果和余波。它们不是固定阶段、固定镜头数或最低层数。

- 先锁能力来源与规则，再扩大传播、占区、遮蔽和环境后果。
- 大型结构不得无因从小光点跳成巨物，也不得无因消失后变成不相称爆炸；若有压缩、折叠、汇聚或分裂，写清可继承的形态桥。
- 人物仍保留身份、动作归属、脸、手势、接触点和结果第一读点；主体突出只能调整焦点、锐度、对比、遮挡和空间分布，不能把主VFX降级为泛光。
- 宏大表现可以发生在宽镜、长镜、局部特写、声音、负空间或环境余波中，不要求所有证据同镜出现。

## 3. 真实粒子与环境受力

粒子必须有来源、材质、方向、受力和停止/残留条件。优先使用当前场景独有的石屑、尘土、金属火花、水汽、布料纤维、能量碎片或黑雾边缘，而不是无因通用粒子名堆叠。

- 粒子方向服从人物动作、VFX传播、压力波、碰撞面、重力或风场；不同来源可并行但不能互相矛盾。
- 粒子只能证明速度、重量、尺度、材质或控制权，不让主动作停下来等待装饰完成。
- 受力后态要能被下一镜继承：尘雾残留、碎石落点、墙面痕迹、地面压坑、能量余电、黑雾回流或曝光恢复。
- 粒子可以在慢镜中被看清，但不能凭空改变S事件的范围、方向或结果。

## 4. 拳拳到肉的打击感

只有源剧本存在身体、武器或环境接触时才写直接命中反馈。若原文是闪避、擦身、空挥或未命中，打击感应转译为接触边缘、风压、急停、失衡修正、支撑变化、衣物受力和落地承重，不能新增命中。

直接接触可从当前动作选择足够证据：支撑/蓄势、加速、接触面压缩或偏转、受击者身体块位移、攻击者反作用、护具/武器振动、地面或环境二次反馈、回收和恢复。不要机械写满全部项目，也不要用疼痛表情代替受力。

## 5. 动态开启顺序

先完成：`S剧情与动作 -> 身份/空间/轴线 -> 接触或规避结果 -> VFX规则与环境后果 -> 真实粒子与光权 -> 慢镜观察窗口 -> 摄影装饰`。若表现资源导致主事件不可读，按E演绎、N补间、重复运镜、次级粒子顺序收敛；不得删改S。

## 6. 交付复核

逐镜回答：慢镜是否有明确观察收益？宏大特效是否仍能追溯来源与结果？粒子是否服从受力方向并可继承？打击感是否与原文接触事实一致？删除所有放大层后，S剧情能否完整复述；保留放大层后，是否仍能感到速度、重量、压迫和场面规模。任一答案是否定，先修表现层，不改剧情层。

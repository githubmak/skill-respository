# 镜头空间、物理与视觉强度导演门

本参考在冻结剧情事实之后、设计正式镜头之前读取。它负责判断空间、动作因果和观看任务是否成立，并在真实摄影机可拍性、AI虚拟运镜与VFX视觉强度之间做主动权衡。现实器材无法架设不是单独的否决理由；只要虚拟摄影机路径连续、观众能复原空间、关键动作与结果可读，就允许保留高难度运镜。只有无因穿透不透明实体、无桥跳位、可见范围互斥或遮挡破坏关键因果时才硬阻断。

## 1. 镜头定义

一镜是一次连续摄影机方案和一个主观看任务，不等同于一个剧情节拍。一个剧情节拍可以拆成多镜：关系建立、路径证明、接触窗口、反应落点、VFX尺度、战果余波都可以各自成镜。

拆镜不是降低连贯性；把互斥观看任务硬塞进一镜才会污染生成。只有同一机位或连续运镜能在正常观看速度下清楚保住主事件、接触或规避、结果和必要反应时，才合并。

## 2. 空间预演与摄影机类型

每镜先选择最合适的摄影机类型，不默认把现实器材当作上限：

- **现实摄影机**：固定、手持、稳定器、轨道、摇臂、升降、长焦或无人机等可解释设备。适合接触窗口、表演、多人关系和需要可信重量的镜头。
- **增强虚拟摄影机**：允许现实设备难以完成的瞬时加速、贴身追随、垂直俯冲、急停、曲线绕行和超高/超低机位。路径仍须在当前空间连续，不穿透不透明实体，不无因跨轴，并在正常观看速度下保住主体。
- **转场摄影机**：借前景遮挡、烟尘、透明能量表面、粒子流、强光曝光变化或术法空间转换完成机位跃迁。必须写清进入媒介、遮挡窗口、转换后空间参照和焦点交接；不能用“镜头穿梭”代替路径证明。

硬约束是剧情因果、空间可复原、动作归属、接触/规避和结果可读。现实器材架设难度、摄影机速度和VFX占屏比例属于可权衡项。炫酷方案触碰可权衡项时先救回，触碰硬约束时才重设。

每镜在选择景别和运镜前，内部回答：

- 机位在哪里，相对地标、敌我轴线、主体高度、VFX源点和遮挡物处于哪一侧；
- 选择现实摄影机、增强虚拟摄影机还是转场摄影机；该选择比更稳妥的覆盖镜头增加了什么观看信息、控制权或情绪压力；
- 摄影机路径能否在当前空间连续解释；若现实器材难以完成但虚拟路径成立，保留并写清起终点、速度变化和空间参照；
- 当前景别能看见哪些身体范围、武器范围、脚下支撑、手部结印、脸部反应、VFX源点和结果区域；
- 哪些物体或特效会遮住人物、武器、接触点、落点、视线或光源；
- 摄影机是否无因穿过墙体、柱子、人物、武器或爆炸核心等不透明实体；烟尘、透明能量、薄粒子层和非实体VFX可作为受控穿越或转场媒介，但不能吞掉关键动作；
- 若机位发生跃迁，是否存在明确前景遮挡、光效曝光、透明媒介、幻境、记忆或术法空间转换作为形态桥；
- 主体高速移动时，摄影机是稳定观察、侧向跟随、纵深压缩、短促制动还是切到结果窗口；
- 当前镜是否同时要求看清脸、手、脚、全身路径、群体反应、VFX源点和环境结果；若其中两项互相排斥，拆镜或重选主任务。

不能只写“可见、清楚、同框”来解决矛盾。先尝试改高度、侧向、焦点交接、前后景层次、VFX透明度窗口或转场媒介；仍无法成立时再改景别、内切或拆镜。

对峙镜要保持深度关系一致：上一镜若两人已是面对面，下一镜若要切单人近景，就把另一人处理成反打、过肩前景、同深度的双人中景，或干脆切出单人反应镜；不要让一个人近景正面出镜，另一个人只剩后景轮廓，还声称仍在同一面对面关系中。

道具必须通过同一条物理时间线：手持、放置、插入、掉落、击飞、收回、打开、闭合、破损、染血、发光和残留都要有可见原因。若上一镜道具在右手，下一镜不能无因到左手；上一镜在桌上，下一镜不能无因回到腰间；上一镜完好，下一镜不能无因破损或消失。看不清交接时，补手部/落点/道具反应镜，或在当前镜重述仍成立的道具状态。

## 2.1 摄影机证明卡

每镜进入正文前，内部生成一张不交付给用户的证明卡：

```text
主观看任务：[路径/接触/结果/规模/反应/余波，仅一项为第一读点]
摄影机类型：[现实摄影机/增强虚拟摄影机/转场摄影机]
机位与高度：[相对人物/地标/轴线的空间位置]
镜头路径：[固定/推进/后退/横移/升降/绕行/俯冲/急停/媒介转场的起终点；无路径写固定]
观看收益：[相较稳妥覆盖镜头新增的来源/路径/接触/尺度/反应/控制权信息]
可见范围：[此景别能稳定看见的身体、武器、VFX源点、接触点、落点或环境]
遮挡检查：[前景、人物、墙柱、武器、VFX、烟尘、爆炸如何遮挡；关键读取窗口在哪里]
空间桥：[虚拟路径或机位跃迁怎样由地标、遮挡、透明媒介、VFX形态或焦点交接连接；现实摄影机写无]
放弃信息：[本镜不负责的脸/手/脚/全场/群体/结果，由哪一镜承接]
判定：[保留 / 调整层次 / 改机位 / 改景别 / 内切 / 拆镜]
```

判定不是“保留”时，不得写最终镜头。最终正文虽然不输出证明卡，但标题第三栏和五字段内容必须能反推出摄影机类型、观看收益与空间桥；反推不出来，视为空间未成立。现实器材难以完成但增强虚拟摄影机证明成立时，判定仍可为“保留”。

## 3. 景别绑定可见范围

景别必须服务主观看任务，并明确它放弃了什么：

| 景别 | 适合承担 | 不适合硬塞 |
|---|---|---|
| 远景/大全景 | 战场尺度、阵型、VFX占区、路径方向、群体受力 | 手部结印、细微表情、精确接触点 |
| 全景/中全景 | 全身攻防、脚下借力、位移路线、多人相对方位 | 眼神细节、微表情、复杂手指法诀 |
| 中景 | 近身互动、武器接触、上半身发力、双人控制权 | 大范围追逐、脚下复杂步法、宏大尺度 |
| 中近景/近景 | 表情压力、手臂/武器局部、接触前停顿、控制权反应 | 同时保全身路径和群体位置 |
| 特写/大特写 | 眼神、伤口、手印、符纹、武器刃口、关键证据 | 空间关系、敌我距离、战场后果 |

如果一个镜头标题写近景，却要求看到脚下发力和全身闪避，必须改成中全景/全景或拆出脚下镜。若标题写大全景，却要求观众读出眼神变化，必须补近景反应镜或降低表情任务。

## 4. 单镜主观看任务

每镜只保留一个第一读点和一个主事件。次级反应、粒子、环境、光影和声音可以存在，但必须从属。

常见主观看任务：

- 路径：谁从哪里到哪里，速度和方向怎样被证明；
- 接触：攻击、格挡、擦身、命中、落空或锁定发生在哪里；
- 结果：谁失衡、受限、退位、夺得控制权，环境留下什么战果；
- 规模：VFX如何占领空间，人物与地标如何证明尺度；
- 反应：谁真正接收了威胁、压住情绪、暴露破绽或完成判断；
- 余波：光、尘、裂纹、声音、姿态和距离如何留下下一镜入口。

一个镜头若同时承担两个同等强的主观看任务，先判断是否能用连续运镜完成明确的观看交接；不行就拆镜。不要用“同时、全程、清楚可见”把互斥任务粘在一起。

## 5. 动作美感

动作美感来自角色目的、空间利用、力的方向和节奏反差，不来自堆招式。设计每个攻防段时至少选择一个能让动作有记忆点的来源：

- 借地形：墙、柱、台阶、屋檐、兵器架、水面、碎石、门框成为发力或遮挡的一部分；
- 错位：攻击看似冲向A，真正改变的是距离、占区、退路或B的反应；
- 反节奏：高速前有短静止，重击后有抽空，宏大VFX前有小动作承诺；
- 失败递进：一次落空、一次被截、一次被反用，每次带来不同信息或控制权变化；
- 反作用：攻击者也承受支撑、惯性、回震或能力代价；
- 结果残留：裂纹、光痕、尘线、衣料受力、武器震颤或沉默证明动作已经发生。

不能为了美感新增胜负、伤势、能力、攻击次数或剧情结果。美感只放大已有事实。

## 6. VFX美术母题

每段斗法建立一个统一但会变化的能力母题：形状、材质、颜色、运动规律、声音质感、残留方式和与环境的相互作用。母题要跟人物身份、能力规则和场景材质有关，不要默认光球、闪电、烟柱和全屏爆炸。

VFX每次出现都回答：

`源点 -> 形态 -> 传播/占区 -> 第一作用 -> 光影染色 -> 材质反馈 -> 残留/消散`

宏大感优先由尺度参照和光权变化证明：人物被压小、地标被遮住、阴影移动、远处群体错峰反应、声音延迟或环境材料受力。粒子只保留能证明方向、速度、占区或残留的部分。

大型VFX不要求人物全程正面清晰。允许人物短暂压成剪影、被烟尘或能量边缘局部遮挡、让摄影机穿过透明粒子层或先展示环境结果，只要关键手势/来源、接触或规避窗口、最终战果在本镜或相邻镜被明确回收。VFX与人物争夺画面时，先调整纵深层级、焦点、亮度边界、透明窗口和镜头时机，不先缩小VFX规模。

## 7. 情绪与控制权曲线

打斗的张弛由人物目标和控制权变化推动。每段内部建立：

`当前目标 -> 首次受阻 -> 调整策略 -> 暴露代价或破绽 -> 控制权转移 -> 余波`

高强度不等于连续爆炸。强攻之间需要用静止、喘息、错视、被遮挡、声音抽空、距离突然拉开或光域改变形成读取窗口。情绪只写成可见动作：肩背、呼吸、支撑、眼神落点、握持力度、起跳迟疑、落地稳不稳。

## 8. 光影与构图

光影必须先服从真实光源、VFX自发光和遮挡关系，再追求美感。

- 主光方向跨镜连续，除非时间、空间、光源或VFX占区改变；
- 自发光特效要染到近处人物、地面、墙体、尘雾和武器反光，随距离衰减；
- 黑位和高光保留主体轮廓，不能用白闪或黑影遮掉接触点；
- 构图用前景遮挡、负空间、层次明暗、尺度对比和地标线条制造记忆点；
- 每镜明确第一读点，最亮、最大、最快的元素不能抢走主事件。

如果光影漂亮但让动作来源、接触或结果不可读，先保留光效设计意图并重排曝光窗口、轮廓边缘或相邻结果镜；仍无法恢复因果时才降低光效。不要把“人物始终均匀曝光”误当成唯一正确答案。

## 9. 交付前权衡门

以下属于硬阻断，必须重写或拆镜：

- 景别标题与画面内容要求的可见范围冲突；
- 摄影机无因穿过墙体、人物、武器或爆炸核心等不透明实体，或无空间桥瞬移/跨轴；
- 摄影机依赖全知视角、无限小镜头、穿入瞳孔/身体后继续展示外部战场；
- 运镜、焦点、主体动作和粒子路径混成同一个主语；
- 关键接触、规避、源点、落点或控制权结果被遮挡；
- 同一镜要求正常速度下读不完的多重任务；
- 大特效让人物身份、动作来源与战果在本镜及相邻镜都无法回收；
- 光影方向、染色或投影与光源/VFX源点不一致；
- 动作很炫但删掉后不能还原原剧本，或新增了剧情事实；
- 镜头只剩“人物攻击、特效爆发、环境震动”的摘要，没有具体动作美感和结果证据。

以下不构成单独阻断：现实器材难以架设、摄影机速度超过实拍设备、虚拟机位贴近高速主体、短暂穿过烟尘/透明能量/粒子层、人物被大型VFX暂时压成剪影、特效占据大部分屏幕。只要空间桥、观看收益、关键读取窗口和结果回收成立，就应保留其视觉强度。

冲突时按以下顺序救回炫酷方案：`保剧情与空间因果 -> 保主动作读取窗口 -> 改摄影机高度/侧向/速度曲线 -> 改VFX纵深/透明窗口/焦点 -> 用遮挡或形态桥转场 -> 把来源与结果交给相邻镜 -> 最后才缩小特效或删除运镜`。

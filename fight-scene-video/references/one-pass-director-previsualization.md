# 一次内部动作导演预演

本预演只在八字段落稿前进行一次。它从源剧本直接生成并冻结镜头答案，不是成稿后的审查或返工循环。

## 连续战术与动作时间线

先连续演算整场，不从机位或强制动作表开始：

```text
原文事实与当前控制权
-> 人物获得的新刺激
-> 威胁判断、当前目标和混合情绪
-> 战术意图、身体先兆与动作承诺
-> 主动作、接触或规避与反作用
-> 对手和其他可见人物的错峰反应
-> VFX、环境受力和声音余波
-> 新控制权与下一行动倾向
```

动作必须由人物目标、已知信息、能力规则与代价、伤势、对手习惯、场地和既定结果推出。为重要节拍比较不同动作候选，选择最符合人物气质、战术和力量方向的方案。情绪必须改变风险承受、距离偏好、出手时机、力量分配或战术选择；怒目、握拳和喘息只能作为先兆或余波。

动作阶段只冻结动作性质、先后因果、作用对象、接触或规避和结果，不提前把精细站位、路径、幅度、逐步落脚和 VFX 层次写死。允许补充准备、连接、受力、反作用、收势和环境反馈，但不能新增招式功能、攻击轮次、伤势、胜负或控制权变化。

## 从体感进入摄影设计

每个节拍同时回答“观众必须看懂什么”和“观众此刻应该感到什么”。先形成战场观看距离与静动曲线，再联合设计：

```text
起幅景别 -> 起幅第一读点 -> 攻防触发 -> 摄像机行为
-> 焦点交接 -> 终幅景别 -> 终幅新增读取 -> 相邻镜头怎样回收因果
```

起幅可以建立战场、阵型或武器路径，运动过程可以跟随速度、沿受力方向移动或揭开遮挡，终幅可以落在接触、破绽、伤势或结果。若连续运动无法让各阶段稳定可读，就拆成关系镜、路径镜、接触镜和反应镜；不能把来源、全身路径、微表情、接触和战果写成“同时清楚可见”。

整场远近与静动变化必须从战术、距离、武器、VFX、控制权和结果自然长出，不机械套固定顺序，也不把固定中景当安全默认。固定机位在蓄势、僵持、接触窗口和余波时可以最有力量；特殊运动只在确实改变动作体感、观看顺序或控制权读取时使用。

启动、转折和终结节拍比较表演与调度、遮挡与环境、摄影机与焦点等机制不同的候选。惊喜必须改变来源、路径、接触、尺度、反应或结果的观看顺序，不能只换颜色、普通推近、无信息环绕或高速乱甩。

## 反向设计动作画面

摄影方案形成后，再设计具体站位、攻防路径、身体发力、武器路线、VFX 纵深、环境受力、构图、光影和声音。每个阶段只写当前景别确实看得到的内容：近景不承担全身路线，大全景不承担眼神，特写不承担敌我距离。

只提前冻结战场边界、地标、实体障碍、敌我初始关系、武器与道具归属、能力源点和结果位置。此时进行一次物理校正：人物、武器、能力、粒子和环境处于同一空间；摄影机路径连续，不穿过不透明实体或无桥越轴；来源、路径、接触或规避和结果可复述；VFX 遮挡拥有读取窗口；伤势、道具、朝向和残留不无因漂移。

候选不成立时，在本次预演中改调度、景别、视角、焦点、遮挡、VFX 层次、运动范围或拆镜。物理成立是底线，不是自动退回固定中景的理由。增强虚拟运动可以保留，但最终 Markdown 只写可见摄像机行为和空间参照，不输出摄影机类型、证明卡、坐标、距离、角度、焦距或工程参数。

## 多人和 OV/OS 时间线

每个受信息、威胁、受力、关系或任务影响的可见人物都有：

`刺激 -> 判断 -> 战术意图 -> 独立动作或主动保持 -> 控制权或任务残留`

主攻防只有一个第一读点，其他人物错峰护人、避让、警戒、承重、确认伤势或准备介入。非现场 OV 不被画中人物听见，人物也不等待 OV 结束。整段选择一处现实攻防、伤势应对、持续警戒、VFX 残留或环境受力承接时间；控制权再次变化时才增加新的主要反应。OS 不做口型，其他人物不能读心。

## 镜尾冻结

每镜结束时冻结下一镜真正需要的少量可见状态：人物屏幕侧和朝向、受力与落点、道具和伤势归属、未完成动作、VFX 与环境残留、战术余波。下一镜用动作接力、状态接力、反应接力或转场起镜自足复述这些状态。全场最后一镜仍写稳定的胜负和余波尾帧。

预演按剧情保真、战术与情绪行动、动作气质、观看收益、多人生命感、物理空间、VFX 连贯和镜间推进的综合结果选定镜头组，随后冻结，不启动第二轮导演审查。

# 一次内部动作导演预演

本文件是打斗技能的生成阶段核心参考。预演只进行一次，发生在八字段落稿前；不检查已经写出的分镜，不在成稿后启动导演返工。

## 同一条动作时间线

从生成段起态连续演算到尾帧：

`剧情事实/当前控制权 -> 新刺激 -> 威胁判断与混合情绪 -> 战术选择与身体先兆 -> 主动作/接触或规避 -> 对手与其他可见人物错峰反应 -> VFX/粒子/环境受力 -> 景别/机位/运镜/焦点揭示 -> 新控制权 -> 尾帧与下一镜起态`

动作必须由人物目标、已知信息、能力代价、伤势、站位、对手习惯和剧情结果推出。情绪要改变风险承受、距离偏好、出手时机或力量分配；怒目、握拳、喘息只能作为先兆或余波。不得新增招式功能、攻击轮次、伤势、胜负或原文没有的控制权变化。

## 物理世界准入

先冻结战场边界、地标和实体障碍、敌我槽位/高度/朝向、武器和道具归属、能力源点与VFX占区、受力方向、关系轴线、环境后态，以及摄影机可处位置与连续路径。

候选必须满足：

- 人物、武器、能力、粒子和环境处于同一个可复原空间；来源、路径、接触/规避、落点和结果唯一可读。
- 现实摄影机有可架设位置与运动通道。增强虚拟摄影机可以采用现实器材难以完成的高度、速度和曲线，但不能无因穿过不透明墙体、人物、武器或爆炸核心，也不能瞬移/无桥越轴。
- 景别能拍到主观看任务：远/全景读规模、阵型、路径，中景读身体发力和攻防关系，近景/特写读接触、伤势、战术破绽或关键源点。近景不承担全身路径，远景不承担微表情。
- VFX、烟尘、爆炸和人物身体不得永久遮住关键动作；短暂遮挡必须有读取窗口或相邻结果镜。
- 道具、伤势、能力残留和人物朝向不无因漂移；变化要有可见交接、受击、掉落、破损、回收或转身原因。

物理空间不成立的候选直接淘汰，在同次预演中改机位、景别、遮挡时机、VFX纵深、焦点或拆镜，不进入创意比较。

## 情绪、多人和OV

每个正在影响主攻防的人物分别生成：`刺激 -> 判断 -> 战术意图 -> 身体先兆 -> 独立动作 -> 控制权/任务残留`。主注意力中心只有一个，其他人物以护人、避让、警戒、承重、确认伤势、观察或维持任务错峰存在，不同步冲刺、怒吼或后退。

台词的直接听者在有效语义点反应，反应可与攻防重叠。非现场OV不能被画中人物听见，也不能让人物等待OV结束。为整段选择一个主要时间承载：现实攻防/伤势应对、持续警戒任务、VFX残留或环境受力；默认一名关键人物发生一次主要变化，控制权再次变化时才增加第二处错峰变化。OS只有持有者泄露身体压力，不做口型。

## 景别、运镜和惊喜

每次景别切换回答“观众此刻必须新看见什么”。没有新增尺度、路径、证据、反应或控制权信息时，保持景别或改变观看重点，不为空泛节奏强行切换。

启动、攻防转折或终结节拍比较至少三种非同构方向：表演/调度、遮挡/环境、摄影机/焦点。候选写清：

`剧情锚点 -> 观众原预期 -> 揭示/反转机制 -> 摄影机类型 -> 现实触发 -> 起幅 -> 连续路径/速度 -> 焦点交接 -> 稳定落幅 -> 新增观看信息 -> 结果残留`

优先选择能重排来源、接触、尺度、反应或结果观看顺序的方案。普通推近、无信息环绕、高速乱甩和只换颜色/焦段不算惊喜。增强虚拟运镜的成立依据是空间连续和观看收益，不是现实器材能否架设；但任何运镜都不能让动作来源和结果不可读。

## VFX和控制负载

术法/能力必须有可追溯来源、可辨形态、传播/占区、第一作用、环境/光影后果和残留。粒子有材质、方向、受力、停止/残留条件；自发光按距离、遮挡和材质同步影响人物、武器与环境。

每镜只锁剧情事实和防误读所需控制点。出现互斥姿态、多次控制权变化、强遮挡、多主动作、空间重建、焦点冲突或时长超载时，先删无锚点装饰和重复控制，再调整VFX纵深/透明窗口、运镜和焦点；仍不清楚才按主观看任务拆镜或拆生成段。

## 镜间接力与冻结

每镜尾帧冻结：人物屏幕侧/朝向、身体姿态/受力/落点、肢体/道具/伤势归属、未完成动作和速度方向、VFX形态/占区/传播、环境/光影/声音残留、情绪/战术余波。下一镜用动作接力、状态接力、反应接力或转场起镜继承当前景别可见且高漂移的2-4项。

只有通过物理世界与空间连续证明的候选，才按“剧情因果、情绪行动、动作气质、观看信息、多人生命感、场景专属惊喜、镜间推进”选择最终镜头组。预演内完成候选替换后冻结答案，不启动第二次预演。

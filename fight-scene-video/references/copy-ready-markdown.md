# 一键复制 Markdown 导出

在源剧本事实、导演设计、生成段聚合、语义预算和对白时长已经形成后读取。本文件负责把已生成内容整理成可复制正文，不允许反向改变剧情动作。

## 1. 发布单位

- 默认一场戏只交付一个 `.md` 文件；文件可以按自然因果接缝汇总多个生成段。
- 每个生成段是独立复制投喂单位，可以含多个连续镜头；段内镜头时长之和必须不超过30秒。30秒是生成段硬上限，不是文件上限，也不是必须填满的配额。
- 多段文件用固定生成段标题分隔，禁止为了减少段数删改S原文事实。只有用户明确要求“每段单独文件”时，才拆成多个文件。
- 审计表、诊断性负面约束、剧情说明和生成报告仍放在主文件之外；固定的 `Seedance 2.5 专属提示词` 列表作为全场信息保留在正文中，不逐镜重复。

## 2. 固定输出合同

默认正文第一项先输出全局风格锁定，再输出全场视觉母版、提示词、生成段标题与镜头列表项。严格保持以下结构、字段、全角分隔符和缩进：

```text
- 全局风格锁定
  - 用户指定风格：……
  - 剧本推断补全：……；推断依据：……
  - 最终执行风格：……

- 全局色卡/影调/光影
  - 全局影调：时间/天气与整体明暗……；人物和战场的亮度关系……；暗处仍可辨……；最亮处保留……；空气/材质呈现……并形成……情绪压力
  - 全局色卡：环境底色……；各阵营/人物服装与肤色……；武器/道具……；能力/VFX与实体灯光……；各颜色以冷暖、明暗和饱和度关系区分……
  - 全局光影：光源实体、方向与高度……；分别照亮……；被……遮挡后在……留下阴影；材质反射……；VFX出现、接触和收束时人物与环境同步……

- Seedance 2.5 专属提示词
  - 正向提示词：……
  - 负向提示词：……

生成段 01｜段名｜28s

- 镜头 01｜时长s
  - 起始状态：场景起镜｜完整起态
  - 景别机位：景别、摄影机类型、相对人物/地标的位置和角度
  - 构图/光影：……
  - 画面/表演：……
  - 运镜/焦点：运动触发、路径、速度、起止画面和焦点落点
  - 特效：……
  - 台词/音效：台词：……；音效：……
  - 尾帧：具体终态；末镜写可稳定停留的收束终态
```

规则：

- 文档第一项固定为 `- 全局风格锁定`，其下依次写 `用户指定风格、剧本推断补全、最终执行风格`。用户提供的部分优先且不得被推断覆盖；推断只填空缺维度并写依据；最终执行风格必须消除冲突和摇摆选项。未提供明确风格时如实写明由剧本推断。
- 文档第二项固定为 `- 全局色卡/影调/光影`，其下依次写 `全局影调、全局色卡、全局光影`。三个字段都必须让不懂摄影术语的人直接复原画面：影调完整说明时间天气、整场亮暗层次、人物/战场亮度关系、暗部和最亮处的可见细节、空气材质与情绪压力；色卡把环境、各阵营/人物服装与肤色、武器/道具、能力/VFX和灯光色逐项分配，并说明冷暖、明暗、饱和度及辨识作用，默认不写 HEX；光影逐个写明光源实体、方向、高度、覆盖对象、遮挡阴影、距离衰减、材质反射，以及VFX出现、接触和收束时人物与环境怎样同步变化。三项不得互相矛盾，禁止只列“冷色调、莫兰迪、低调、中高反差、黑位、主光、辅光、动机光、统一塑造、曝光层级、色温关系”等标签或参数。
- 文档第三项固定为 `- Seedance 2.5 专属提示词`，其下依次写 `正向提示词、负向提示词`。正向词先编译最终执行风格，再编译本场统一曝光、肤色纹理、材质与VFX光照响应；负向词覆盖Seedance 2.5常见曝光、偏色、塑料肤质、结构、穿模、鬼影、道具与清晰度问题，并按本场增删。
- 生成段标题固定为 `生成段 NN｜段名｜时长s`；段号从01连续递增，标题时长等于本段全部镜头时长之和且不超过30秒。
- 全场镜头编号从01开始跨生成段连续递增，不在新段重置。段名只概括该段现有剧情，不新增事件、胜负或能力。
- 只有一个生成段时仍优先保留生成段标题；为兼容旧工作流，也允许在全局视觉母版之后省略标题并直接写 `- 镜头 01｜`。
- 镜头列表项固定为 `- 镜头 NN｜时长s`，只承担编号与时长；字段作为缩进子列表，不使用表格。
- `景别机位` 必须写景别、现实摄影机/增强虚拟摄影机/转场摄影机类型，以及相对人物、地标、轴线、高度或角度的位置；必须与正文主任务的可见范围一致。
- `运镜/焦点` 必须写固定/推进/后退/横移/升降/俯冲/绕行/媒介转场等运动方式、起止路径、速度变化和焦点交接。不得只写“创意运镜、快速飞掠、环绕展示、全程跟拍、镜头穿梭、清楚可见”；路径写不清就拆镜。
- 若前后镜是明确对峙关系，下一镜不允许把两人写成“一个近景、一个后景”却仍维持同一面对面关系；这种情况优先改成反打、过肩、双人中景或单人反应镜。
- 全局视觉母版之后，镜头正文只允许且必须依次出现 `- 镜头 NN｜时长s` 及其下方八个缩进字段：`起始状态、景别机位、构图/光影、画面/表演、运镜/焦点、特效、台词/音效、尾帧`；禁止Markdown表格和平铺段落。
- `特效` 没有内容写 `无`；`台词/音效` 固定写成 `台词：……；音效：……`，无对白写 `台词：无`，无音效写 `音效：无`；`画面/表演、运镜/焦点、尾帧` 不得省略、留空或写 `无`。最后一镜同样必须写具体尾帧，不能用 `结束、无后续镜、无需承接` 占位。
- 除固定全局风格锁定、视觉母版、Seedance 2.5 专属提示词和生成段标题外，不加Markdown标题、粗体、表格、镜头外说明、P编号、S/N/E标签、动作预算、诊断性负面约束或代码围栏。
- 文件为UTF-8并作为交付正文的唯一真源；聊天只需报告路径、段数和校验结果，除非用户明确要求粘贴全文。

## 3. 段内镜头写法

### 第一镜：建立完整锚点

生成段第一镜完整建立本段实际需要的：

- 地点、时间、环境与主要遮挡；
- 人物身份、敌我关系、位置、朝向、高度和关键道具；
- 关键道具的归属、手持/放置位置、左右手/身体侧、开合、破损、染血、发光、方向和残留状态；
- 活跃能力、伤态、环境破坏与主光；
- 本镜视觉主事件和动作入口。

不要求复制与当前段无关的全量人物设定。

全文第一镜写 `起始状态：场景起镜｜……`。若该生成段不是本场第一段且与前段连续，段首镜仍使用动作接力、状态接力或反应接力，并用具体事实重建前段末镜的 `尾帧`；若开启新时空则写 `起始状态：转场起镜｜……`。不得因生成段分隔省略接力，也不得引用前段或前镜，因为本段必须能独立投喂。

### 后续镜：只写增量状态

后续镜头写：

- 在 `起始状态` 中选择动作接力、状态接力、反应接力或转场起镜，自足复述前镜 `尾帧` 中当前可见且最容易漂移的 2–4 项；
- 当前可见且会影响本镜生成的状态；
- 相比前一镜新增或改变的动作、位置、道具状态、VFX、环境和光影；
- 本镜的视觉主事件；
- 下一镜入口或本镜明确结果。

禁止只写 `继承镜XX、上一镜、同上、沿用` 等空指代；允许写 `半脸傩纹已经成型的宋棠仍悬在巷心上空` 这类当镜可见事实。不得机械复述全套服装、场景、粒子、光照和肢体状态。

接力类型按前镜 `尾帧` 选择：动作接力保留屏幕方向、速度/受力、落点或未完成动作；状态接力保留稳定站位、面向、伤态、持物和控制权；反应接力先保留接收者位置、面向与持物，再由已成立的声音、视线、入画攻击或环境后果触发。切镜不能让人物恢复中性站姿、让同一动作重新起手、让VFX或环境后果无因复原。若当前景别看不见某项终态，改写为可见残留证据或调整景别/机位，不写不可见控制。

### 末镜：写收束终态

- 普通镜的 `尾帧` 是接力快照；生成段末镜若后续还有生成段，它同时是下一段首镜的跨段锚点。
- 全场最后一镜也必须写 `尾帧`，但不再预告下一镜；它记录已经成立的最终胜负、人物位置/面向与姿态、道具/伤势归属、VFX消散或残留、环境破坏和声音余波中最关键的 2–4 项。
- 收束尾帧必须可稳定停留，不写新的起手、追击、转身离场或能力变化；原剧本没有这些后续动作时，不得为了“有结尾”自行补演。
- 禁止写 `尾帧：结束、尾帧：无后续镜、尾帧：无需承接`。这些是流程说明，不是可见画面。

## 4. 各字段内部顺序

- `起始状态`：接力类型 -> 当前景别可见的自足起态；只负责从前镜尾帧进入本镜，不写本镜新动作。
- `景别机位`：景别 -> 摄影机类型 -> 相对主体/地标的位置 -> 高度/角度/轴线侧。
- `构图/光影`：用语义化自然语言依次写人物/阵营在画面中的位置与距离 -> 前景、建筑、烟尘或VFX怎样分隔/遮挡 -> 光从哪里来、人物/武器/环境哪些部位更亮或更暗 -> 接触点、结果和表情是否看得清 -> 色彩或反射怎样随动作发生可见变化。不要只写“压背景、做强调、主辅关系、光权、曝光层级”等部门速记；若使用术语，紧接它在画面中的具体结果。段首镜建立主要色调和光源，后续镜只写有因变化。
- `画面/表演`：本镜必要增量状态 -> 视觉主事件 -> S动作的执行者/能力/对象 -> 关键接触或规避 -> 说话者策略、听者语义触发反应和其他可见人物的任务维持 -> 明确结果。OV/OS期间先选一个主要时间承载，默认只保留一名关键人物的一次主要现实变化，其余人物主动保持；必要时用战场残留或环境受力承接时间。只有控制权再次变化时才增加第二处错峰反应，人物可在 OV 未结束时行动，禁止等待 OV 说完再反应。
- `运镜/焦点`：动作触发 -> 摄影机运动/固定方式 -> 连续路径与速度变化 -> 焦点对象/交接 -> 稳定落幅。
- `画面/表演`必须让 `景别机位` 能够拍到：近景不写全身路径和群体阵型，远景不写细微眼神，移动机位不写无法绕开的实体穿越。若需要多种可见范围，拆成相邻镜头。
- `画面/表演`不得把“脸部反应、手部细节、全身位移、群体相对方位、VFX源点、接触点、落点、环境结果”压进同一镜的同等主任务。保留一个第一读点，其余信息若必须可见就拆镜或写成从属反应。
- 若同镜出现两个人，且其中一人被写成近景/特写主角，另一人被放入后景/背景/后侧，还要同时维持面对面、对峙或正面相对关系，判为深度连续性冲突；请改为反打、过肩、双人中景或拆镜。
- `画面/表演`涉及关键道具时，必须保留当前镜可见的道具归属和状态；道具的持有者、左右手、放置点、开合、破损、染血、发光、方向或残留发生变化时，必须写出可见原因，不能用“场景不变、陈设统一”掩盖道具漂移。
- 多人同镜时，在`画面/表演`中以自然语言保留非主要人物的当前反应职责、信息/受力来源和与主事件的关系；有台词时给直接听者和旁观者不同的语义触发点与错峰反应。OV/OS时默认一处主要变化加其余人物主动保持，不要求每个人持续移动，也不把 OV 结束当作后续反应的触发点。不要把配角写成无任务的木偶，也不要编排逐人逐关节动作；配角活性不得新增攻击、反制、对白、伤势或控制权变化。
- `特效`：从源点、形态变化、传播/第一作用、必要环境反应、停止/残留中选择本镜真正承担的项目，不机械写满。本段确有VFX时，生成段第一镜或首个高能镜用一句可见规则建立本段VFX母题，如形状、材质、颜色、运动规律、染光或残留方式；后续镜写母题如何变化。没有特效写 `无`，不写抽象设定说明。
- `台词/音效`：固定先写台词再写音效。台词逐字保留源剧本和身份标记，多人对白、OS、OV或系统音按发生顺序串联；音效按环境底噪 -> 动作起动 -> 接触/规避 -> 声音桥或余波。
- `尾帧`：本镜结束时人物位置/面向、姿态/运动、道具/伤势归属、VFX/环境残留，以及会改变下一镜动作选择的情绪/战术残留中的 2–4 项具体状态；普通镜选择下一镜需要或高漂移项，生成段末镜选择跨段锚点，全场末镜选择最终结果和稳定收束项。不得写过程、计划、空洞指代或“结束/无后续镜/无需承接”。

固定字段不等于每镜重复全部信息。每个生成段自足，`起始状态` 与 `尾帧` 只保留当前接力需要的具体状态，`画面/表演` 采用增量事件，以减少注意力稀释和相互污染。文件合并不等于跨段省略锚点；新生成段第一镜仍须写出独立投喂所需状态。

固定字段也不等于把动作过程写满。每镜只写剧情实际需要的 `起始/身份、决定性动作、关键作用、结果/下一镜入口` 控制点；不要求四项机械齐全。原文未规定的身体协调、重心转移、惯性、衣发随动、粒子湍流和自然摄影补偿交给模型演绎。

### 双密度写法

最终正文采用 `高视觉表达密度 + 低微动作控制密度`，不得把两者混为一谈：

- 控制点保持少而准：只规定剧情必需的动作承诺、作用对象、力量方向和结果边界。
- 视觉表达保持丰而实：写出同一动作的姿态气质、宏观轨迹、速度/重量性质、敌我压迫关系、VFX可辨形态与演化、环境受力、光权变化和声音节奏。
- 丰富描述只要共同证明同一视觉主事件，就不因字数较多自动构成过载；过载取决于独立事件、互斥姿态、控制权变化和必须精确兑现的中间步骤数量。
- 精简优先删除重复同义词、空洞赞美、伪精确数字和N/E身体补间；不得把“反手光弧劈穿黑雾核心”“沿两侧墙面交替借力拔高”“环形风压撕开下方浓雾”压缩成“释放特效”“蹬墙跳起”“气场爆发”。
- 如果去掉风格词后剧情仍完整，但成品只剩工程摘要，补回动作形态、空间关系、VFX行为、环境/光影反应和声音落点，不新增剧情事件。

## 5. 信息取舍

最终文本按三层处理：

- `A级S事实`必须显式保留：人物、事件、动作、顺序、因果、台词、能力规则、关键VFX和结果。
- `B级锚点`按漂移风险保留：身份、空间方向、主要运镜、关键光影和环境证据。
- `C级补间`默认交给模型：非剧情关键的厘米距离、重复材质、细碎肢体轨迹、粒子参数和装饰性回收。

精简时只删除重复形容、同义复述、无执行价值标签、无原文锚点的E装饰和可安全省略的C补间。不得以“提示词过长”“镜头太多”或“模型承载不足”为理由删除、概括、改序或弱化S原文事实。

过载处理顺序为：`删无锚点E -> 压缩N -> 去重复与伪精确 -> 简化非关键运镜/VFX -> 按主观看任务拆镜或内切 -> 聚合同一动作弧中物理兼容的部分 -> 拆生成段`。

正文禁止把N/E补间写成逐秒或亚秒时间码、逐关节角度、连续厘米位移、逐步落脚或密集“先—再—随后—立即”清单。只有原文明确规定或为避免S动作归属歧义所必需的细节才进入正文；若这些S控制点在现有时长内无法自然完成，延长镜头或拆分，不得压缩表演时间。

## 6. 时长与台词

- 每个生成段中所有镜头标题时长之和必须 `<=30秒`；整份多段文件可以超过30秒。超限只拆生成段，不拆文件，不得删改S剧情或强行加速。
- 生成段标题时长必须与段内镜头合计完全一致；校验器按生成段分别计算。
- 镜头时长按动作、对白、VFX结果和运镜的并行时间区间计算，不机械相加。
- 中间镜头可以切在运动入口、威胁逼近或动作承诺上；决定性结果和段末结果必须可读。
- 台词只统计实际说出的正文，按自然语速、标点、换气和表演停顿估算。
- 对白与动作可以并行，但口型、发声、呼吸和受力必须兼容。
- 说不完时优先延长镜头或在自然语义点拆镜；不得删字、改写、快读或增加新对白字段。

## 8. 交付前轻量检查

- 文档依次包含一份用户优先的全局风格锁定、一份全局视觉母版、一份不误伤本场设定的 Seedance 2.5 正负向提示词，以及生成段/镜头列表；母版是否复制到实际投喂内容由用户决定。
- 生成段和镜头编号连续，段标题时长等于段内镜头合计且不超过30秒。
- 每镜八字段顺序正确，硬必填字段非空，台词/OS/OV逐字保留，每镜包括全场末镜都有具体尾帧。
- 交付阶段不重新评价剧情、空间、动作、VFX、运镜、多人活性、光影或创意，也不触发二次改稿；这些已经在生成阶段一次决定。
- 运行 `python3 scripts/validate_storyboard_format.py <成品.md>`，脚本只检查上述机器可判定的结构完整性。

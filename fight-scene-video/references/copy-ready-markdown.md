# 连续战斗生成单元 Markdown 合同

整场连续战斗也按 `### 生成单元 G…` 交付。一个 Markdown 文件依次汇总多个 G 单元；每个单元可承载一个或多个连续镜头。用户给出镜号、时长、焦段或更细的模板时优先继承，未给焦段时可按实际镜头设计选择并在摄影说明与时间线保持一致。只交最终采用稿，不把内部候选、审计表、全局卡或旧式八字段镜头表插在单元之前。

## 固定结构

```text
### 生成单元 G1 ｜时长：8 秒｜承载：镜头 S1-01、S1-02｜单元任务

- 起幅与连续性：本单元起始的人物、武器、伤势、能力、方位、动作入口及与前单元的接点。
- 摄影与构图：逐镜写镜号、焦段、景别、机位所在侧、前中后景、人物左右和远近、可见正面/侧面/背面、焦点、切点及稳定落幅。
- 光影、环境色彩与材质：所给色卡/影调在当前地点的落实；实体光源、能力自发光怎样照到人物与环境，材质反射与亮度回落。
- 特效与粒子：本单元能力或撞击的源点、形体、传播、真正的规模峰值、碰撞喷发、近中远粒子的方向与速度差、环境作用和残留；无主动特效时明确写无。
- 画面与表演时间线：
  - 0.0—3.0秒｜S1-01｜50毫米·中景｜动作触发的运镜。主体行为、攻防因果、接触或规避、表演和结果。声音：本镜台词进入/退出与有来源的音效；配乐：仅开启配乐时写本镜实际奏法、让位和接续。
  - 3.0—8.0秒｜S1-02｜70毫米·近景｜切至固定。承接前镜可见状态，写本镜主变化、焦点与尾态。声音：……；配乐：仅开启时写。
- 台词与声音层次：逐字保留原台词/OS/OV、说话人、时间窗、口型可见性或画外声、声音前后层；无台词写无。配乐开启时概述本单元声音关系。
- 落幅状态：可停留的具体人物、武器、伤势、能力残留、环境和声音状态，供下一单元承接。
```

每个 G 单元严格按上述七个栏目及顺序书写。`本生成单元特殊正向约束` 和 `本生成单元特殊负面约束` 仅在当前单元确有新增生成风险时，依次附于落幅之后；不得把泛用负面词逐段重复。没有必要时不出现这两个栏目。不要另设全局风格卡、场景卡、Seedance 总提示词、第二个 VFX 栏、配乐栏、审计栏或旧式 `生成段 NN` 标题。全局视觉、能力、声音与空间规则需在首单元起幅和适用单元的既有栏目中自然落实；多个单元共享的音乐主题在首单元 `台词与声音层次` 确立，后续单元承接即可。单独投喂某个 G 单元时，其起幅须足以重建当前人物关系与关键状态。

## 时间与承载

- G 编号按剧情顺序连续递增；同一场内镜号按源稿连续承载，不重号、不漏掉明确事件。标题时长等于时间线最后的结束时间，时间窗从 0.0 秒连续到标题时长，不留空档或倒退。
- 默认单元不超过 35 秒。用户指定不同上限或已核实的平台规格时按其要求；这只是本技能的生成单位设计上限，不保证平台可直接接受。单元长短由动作、台词与结果读取决定，不为填满上限延长。
- 每个时间窗以 `起止秒｜镜号｜焦段·景别｜运镜` 开始，之后写该镜头可见的主事件和声音。时间线可并行承载台词、动作和特效；必须先后读取的起势、接触、伤势和结果要有足够窗口。完整台词只在 `台词与声音层次` 写一次，时间线标注语义位置与声音进入/退出即可。
- 用户提供的焦段必须保留并核对机位、景别与面部可见性；未给焦段时可按导演意图设计，不机械套用示例焦段。若镜内从一种焦段切到另一机位，明确写“切”，不要让单个摄影机在未切镜时凭空换位。

## 空间与表演

- `起幅与连续性` 和 `落幅状态` 具体写武器持手、伤势、能力形态、人物相对方位、视线、运动方向与可继承的 VFX 残留。跨单元开头重述必要状态，避免“上一镜同上”代替事实。
- 连续战斗在上述两栏继承会改变下一轮选择的能力余量、伤处限制、装备破损、场地痕迹与双方已知线索；不写虚构数值。`画面与表演时间线` 写它们如何具体改变起手、步法、施法精度、防守范围或诱敌判断，并明确由哪一上一轮动作留下；已有剧情不支持消耗或新伤时不强加。
- `摄影与构图` 对多人同框、同向行进、远近景交错、追逐与目送必须锁定同一机位下的画面左右、摄影机距离、身体/头眼朝向、谁可见正脸/哪侧脸/背影、谁焦外。近者占幅大不意味着能看见正脸；两人同向背离机位且未回头时，不能让近者清晰露脸而远者保持背影。若切镜或人物转身改变可见面，写出触发与切点。
- `画面与表演时间线` 让威胁判断、身体准备、发力、对手反制、接触或规避、反作用、微表情和余波按实际可见顺序发生。面部、嘴形与微表情只写在当前景别、机位与焦点确能看清的窗口；远景或背影用姿态、行动、声音承载表演。
- 决定性命中在时间线给出与接触面相符的传力链：命中/格挡点、身体或武器形变与震颤、支撑脚和重心、环境碎屑、恢复或失衡，再将结果交给下一镜。撕裂、出血和持续性体表变化只有剧情支持才写；不得用一句“冲击力极强”替代可见反馈。
- 摄影写清动作触发、摄影机升降/横移/迎击/后撤/制动、新读点与停住位置；炫技需要带来路径、接触、规模或情绪的新信息。用户明确要求环绕、极速推镜等时，选择适配的高能时间窗，在 `摄影与构图` 写起始机位与路线，在同镜时间线写触发、加速、观看收益、接触前制动和终幅；如跨轴或改向，在后续关系镜重建方位。一次高速追随结束后可切到固定远景证明战场尺度，不把所有信息挤在同一模糊画面。

## 特效、光影与声音

- `光影、环境色彩与材质` 回答光从哪里来、照到了什么、何时恢复原影调；`特效与粒子` 回答能力/撞击长什么样、占据多大空间、碎片怎样在纵深中运动以及留下什么。两个栏目互相对应，不用把完整特效压缩在光影栏；时间线负责让这些状态依攻防先后真正发生。
- 主效先有源点和攻击方向，再有传播、接触或规避、环境受光受力与残留。羽、霜、冰、火花、烟、血、气浪各按自身材质运动；自发光本体、照到人物/武器/树木的光、体积雾、反射和曝光回落分别在画面中成立。允许主效短时支配全画面，随后必须交回人物位置、接触结果和伤势。
- 粒子由明确事件触发，分前中远景错峰飞散；关键高潮写出大碎片或近镜粒子、中层碰撞喷发、远层光尘与环境余波各自的运动、受光、遮挡和退场。有主效的高能段要让主效在至少一个可读窗口真正占领画面，再借亮度回落交回接触和战果；不要让每层同亮、同速、同方向。伤势、破损、羽片和血液跨镜继承，不在切镜后自动复原。原文未允许的招式、能力、胜负或代价不得从特效规模反推新增。
- 配乐默认关闭。用户明确要求配乐、BGM、纯音乐或要求依所给带配乐模板完整交付时开启；保留用户已给的配乐。开启时，首单元明确整场可辨主题、主奏与伴奏/节奏音色及剧情弧；每个时间窗在 `声音：` 后写 `配乐：`，交代实际奏法、台词或决定性音效让位、镜尾与下一镜/单元接续。静默处写清停奏与再进入，不因切镜无因重起。关闭时不写配乐子项。
- 台词/OS/OV 逐字保留，不变更说话人和顺序；现场配音与画面可见口型相合，画外声注明来源和连续性。不能为了压进时长快读、删字或让非说话者同步张嘴。音效须有来源、距离、起落与先后，血珠等无可听来源的细节不强行配声。

## 交付检查

核对每个单元七栏目顺序、时间线连续、标题时长、镜号承载、焦段和景别；再人工核对剧情事件、台词、攻防因果、空间闭环、持物和伤势、VFX 受光与残留。

连续战斗再查状态与反转：每个重要反击能否指向前段真实留下的线索、代价或地形条件；重大命中、消耗和场地变化是否在下一轮改变行动；双方同框能力能否不靠颜色分辨来源；原创或概述性战斗有设计空间时，是否有一处先铺垫再兑现的控制权反转。若原剧本锁定单向压制或转折，不把新增反转当格式必填项。

用户点名运镜时另做**成稿运镜兑现审读**：只读最终七栏目，确认至少有符合剧情的镜头实际采用所点名运动，并能复述起点、触发、路径、读点、停点和接触后方位；仅在内部候选或风格词中提到不算兑现。

强特效任务再做一次**成稿可见性审读**：只读交付正文，逐个选定高潮回答“主效由什么实体发出、在哪个时间窗真正扩张到峰值、镜头如何展示其尺度、哪些近景粒子与远景环境反馈由它触发、峰值后露出什么明确战果”。答不出来时修改 `特效与粒子`、对应时间窗、受光描述和 `落幅状态`；不要再另加栏目或把失败藏进负面提示词。对白或静止蓄势段不强行补爆发，场面强度由剧情节拍决定。

用户要求保存时写入指定位置，不覆盖源剧本或旧成稿，同名用版本号。

```bash
python3 "$SKILL_DIR/scripts/validate_storyboard.py" <成品.md> --mode units
```

若用户明确要求每个镜头给出焦段，追加 `--require-focal-length`；若指定新的单元上限，追加 `--max-unit-seconds <秒数>`。脚本只验证机器可判定的格式与时长，不能代替画面和剧情审查。

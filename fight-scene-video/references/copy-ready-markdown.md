# 一键复制 Markdown 导出

在剧情、动作、摄影、视觉、声音、生成段和连续性已经冻结后读取。本文件只负责一次编译正文，不允许反向改变剧情、动作或镜头答案。

## 发布单位

- 默认一场戏交付一个 UTF-8 Markdown 文件，可汇总多个生成段。
- 每个生成段是独立复制投喂单位，段内镜头时长之和不超过30秒；30秒是生成段上限，不是文件上限或必须填满的配额。
- 多段文件用固定生成段标题分隔。只有用户明确要求每段单独文件时才拆文件。
- 全局风格、视觉母版和 Seedance 2.5 提示词全场各一份；每个场景另有一份从全局母版推导的场景视觉方案。

## 固定结构

```text
- 全局风格锁定
  - 用户指定风格：……
  - 剧本推断补全：……；推断依据：……
  - 最终执行风格：……

- 全局色卡/影调/光影
  - 全局影调：……
  - 全局色卡：……
  - 全局光影：……

- Seedance 2.5 专属提示词
  - 正向提示词：……
  - 负向提示词：……

- 场景 01｜场景名
  - 场景影调：……
  - 场景色卡：……
  - 场景光影：……

生成段 01｜段名｜28s

- 镜头 01｜时长s
  - 起始状态：场景起镜｜完整起态
  - 景别机位：景别、语义化视角、主体/敌我/地标关系及本镜读取重点
  - 构图/光影：对象位置、遮挡、实体光源或 VFX 受光及本镜变化
  - 画面/表演：动作因果、接触或规避、多人职责、环境受力和结果
  - 运镜/焦点：语义化运动、自然节奏、稳定落幅、具体焦点与读取交接
  - 特效：源点、形态、作用、环境反馈与残留；没有写无
  - 台词/音效：台词：逐字保留的台词/OS/OV或无；音效：环境、动作、接触或声音桥
  - 尾帧：具体终态；末镜写可稳定停留的收束终态
```

## 语义化正文

除编号、镜头时长和生成段时长外，所有字段都必须是 AI 能直接生成的自然语言。内部物理证明、工程参数和审计标签不得进入正文。

- `景别机位`：写景别和可见关系，例如“中全景，从持刀者侧后方看向退路，双方全身、刀锋路线和巷口都在画面中”。不写摄影机类型、设备、坐标、轴线编号、距离或角度数值。
- `运镜/焦点`：写动作触发、摄像机行为、自然速度、可见边界、稳定落幅和具体焦点，例如“镜头沿刀锋挥动方向平稳横移，格挡发生时立即停住，焦点保持在交叉刀刃和双方受力手臂”。不写轨迹参数、速度曲线、焦距或逐秒分段。
- `画面/表演`：写动作性质、力量方向、接触或规避、人物反应和结果；不写逐关节角度、连续厘米位移、逐步落脚、骨骼或动画控制。
- `构图/光影`：写人物与物体在画面中的具体位置、遮挡、光源和可见明暗结果；不用“光权、曝光层级、主辅比”等速记代替画面。
- `特效`：写来源、材质、形态、传播或占区、作用、环境反馈和残留；不写粒子数量、模拟参数、合成层或占屏比例。
- Seedance 正负向提示词使用完整自然语言。负向词只选择本场真实风险，带条件避免误伤剧情需要的颜色、强光、静止、服装、道具和能力。

最终正文禁止出现：XYZ 轴、坐标、米或厘米、角度数值、焦距数值、人物画面占比、器材名称、机位证明卡、工程量化、风险等级、校验记录、逐秒或亚秒动作表。

## 段内连续

- 首镜 `起始状态` 使用 `场景起镜`，建立当前段实际需要的地点、人物、敌我关系、持物、伤势、能力和动作入口。
- 后续镜使用 `动作接力、状态接力、反应接力、转场起镜`，自足复述前镜尾帧中当前可见且容易漂移的少量状态；禁止只写“上一镜、同上、沿用”。
- 切镜不能让人物恢复中性站姿、让同一动作重新起手、让武器换手、让伤势或 VFX 无因消失，也不能让环境结果复原。
- 关系、路径、位置、控制权或战场尺度改变后，及时用能复原空间的关系镜确认新状态。
- 普通镜 `尾帧` 保留下一镜需要的具体状态；生成段末镜保留跨段锚点；全场末镜保留既定胜负、人物位置和姿态、道具或伤势、VFX 与环境余波，且能够稳定停留。

## 字段规则

- `画面/表演、运镜/焦点、尾帧` 不得省略、留空或写 `无`。
- 无特效写 `特效：无`；无台词或音效分别写 `台词：无`、`音效：无`。
- `画面/表演` 先写第一读点和主事件，再写从属反应、环境与结果；不把全身路径、面部细节、群体方位、VFX 源点、接触和落点并列为同等任务。
- 台词、OS、OV 逐字保留。对白与动作可以并行，但口型、呼吸和受力必须相容；说不完时延长镜头或在自然语义点拆镜，不删字、不快读。
- OV 期间选择一处现实攻防、伤势应对、持续任务、VFX 残留或环境受力承接时间；人物不回应非现场声音，也不等待 OV 结束才反应。
- `尾帧` 不写过程、计划、空指代、“结束、无后续镜、无需承接”。

## 视觉与时长

- 全局影调、色卡和光影由整部剧的类型、世界观、总体情绪和用户风格决定；场景方案由具体地点、时段、天气、材质、光源、能力和战术压力落实。
- 色卡使用明确语义颜色并分配给环境、人物或阵营、肤色、武器、能力和灯光，默认不用 HEX。
- 生成段标题时长必须等于段内镜头时长之和且不超过30秒；镜头编号跨段连续。
- 镜头时长按动作、对白、VFX 和运镜可以并行的自然时间估算，不机械相加。

## 交付前轻量检查

- 全局和场景视觉、Seedance 提示词、生成段、镜头编号及时长结构完整。
- 每镜八字段顺序正确，台词/OS/OV 未改，所有镜头包括末镜都有具体尾帧。
- 扫描正文，确认没有工程参数、内部分类、候选分析、检查表、风险标签或校验记录。
- 运行 `python3 scripts/validate_storyboard_format.py <成品.md>`。脚本只检查机器可判定的结构，不触发成稿后的二次导演改写。

# 一键复制 Markdown 导出

只在源剧本事实、导演设计、生成段聚合、语义预算、对白时长和剧本资格审计全部通过后读取。本文件只负责发布，不允许反向改变剧情动作。

## 1. 发布单位

- 默认一场戏只交付一个 `.md` 文件；文件可以按自然因果接缝汇总多个生成段。
- 每个生成段是独立复制投喂单位，可以含多个连续镜头；段内镜头时长之和必须不超过30秒。30秒是生成段硬上限，不是文件上限，也不是必须填满的配额。
- 多段文件用固定生成段标题分隔，禁止为了减少段数删改S原文事实。只有用户明确要求“每段单独文件”时，才拆成多个文件。
- 审计表、负面提示、剧情说明和生成报告仍放在主文件之外，不得混入生成段正文。

## 2. 固定输出合同

默认多段正文第一行直接以 `生成段 01｜` 开始。生成段标题与镜头块严格保持以下结构、字段、全角分隔符和空行：

```text
生成段 01｜段名｜28s

镜号 01｜景别｜主要运镜与机位/角度｜时长s

画面内容：……

特效：……

光影：……

音效：……

台词：……
```

规则：

- 生成段标题固定为 `生成段 NN｜段名｜时长s`；段号从01连续递增，标题时长等于本段全部镜头时长之和且不超过30秒。
- 全场镜号从01开始跨生成段连续递增，不在新段重置。段名只概括该段现有剧情，不新增事件、胜负或能力。
- 只有一个生成段时仍优先保留生成段标题；为兼容旧工作流，也允许省略标题并直接从 `镜号 01｜` 开始。
- 标题必须同时包含 `镜号、景别、主要运镜、机位/角度、时长`；运镜和机位共同写在第三栏，不新增字段。
- 标题里的景别必须与正文主任务的可见范围一致；第三栏必须写出现实摄影机、增强虚拟摄影机或转场摄影机，以及固定/推进/后退/横移/升降/俯冲/绕行/媒介转场中的一种和相对人物、地标、轴线、高度或角度的位置。若空间路径无法成立或机位无法让观众读取正文要求的动作、接触、源点、落点或反应，禁止发布；现实器材难以架设不单独构成阻断。
- 第三栏不得只写抽象摄影词，如“创意运镜、快速飞掠、环绕展示、全程跟拍、镜头穿梭、清楚可见”。若镜头需要从一个观看任务转到另一个观看任务，必须写出可拍的路径和焦点交接；路径写不清就拆镜。
- 若前后镜是明确对峙关系，下一镜不允许把两人写成“一个近景、一个后景”却仍维持同一面对面关系；这种情况优先改成反打、过肩、双人中景或单人反应镜。
- 正文只允许且必须依次出现 `画面内容、特效、光影、音效、台词` 五个字段，每字段一个自然段。
- 没有内容写 `无`，不得省略字段。
- 除固定生成段标题外，不加Markdown标题、粗体、表格、镜头外说明、P编号、S/N/E标签、动作预算、负面提示词或代码围栏。
- 文件为UTF-8并作为交付正文的唯一真源；聊天只需报告路径、段数和校验结果，除非用户明确要求粘贴全文。

## 3. 段内镜头写法

### 第一镜：建立完整锚点

生成段第一镜完整建立本段实际需要的：

- 地点、时间、环境与主要遮挡；
- 人物身份、敌我关系、位置、朝向、高度和关键道具；
- 关键道具的归属、手持/放置位置、左右手/身体侧、开合、破损、染血、发光、方向和残留状态；
- 活跃能力、伤态、环境破坏与主光；
- 本镜视觉主事件和动作入口。

不要求复制与当前段无关的全量人物设定。

### 后续镜：只写增量状态

后续镜头写：

- 当前可见且会影响本镜生成的状态；
- 相比前一镜新增或改变的动作、位置、道具状态、VFX、环境和光影；
- 本镜的视觉主事件；
- 下一镜入口或本镜明确结果。

禁止只写 `继承镜XX、上一镜、同上、沿用` 等空指代；允许写 `半脸傩纹已经成型的宋棠仍悬在巷心上空` 这类当镜可见事实。不得机械复述全套服装、场景、粒子、光照和肢体状态。

## 4. 各字段内部顺序

- `画面内容`：段首完整锚点或本镜必要增量状态 -> 视觉主事件 -> S动作的执行者/能力/对象 -> 关键接触或规避 -> 下一镜入口或明确结果。
- `画面内容`必须让标题景别能够拍到：近景不写全身路径和群体阵型，远景不写细微眼神，移动机位不写无法绕开的实体穿越。若需要多种可见范围，拆成相邻镜头。
- `画面内容`不得把“脸部反应、手部细节、全身位移、群体相对方位、VFX源点、接触点、落点、环境结果”压进同一镜的同等主任务。保留一个第一读点，其余信息若必须可见就拆镜或写成从属反应。
- 若同镜出现两个人，且其中一人被写成近景/特写主角，另一人被放入后景/背景/后侧，还要同时维持面对面、对峙或正面相对关系，判为深度连续性冲突；请改为反打、过肩、双人中景或拆镜。
- `画面内容`涉及关键道具时，必须保留当前镜可见的道具归属和状态；道具的持有者、左右手、放置点、开合、破损、染血、发光、方向或残留发生变化时，必须写出可见原因，不能用“场景不变、陈设统一”掩盖道具漂移。
- 多人同镜时，在`画面内容`中以自然语言保留非主要人物的当前反应职责、信息/受力来源和与主事件的关系；具体表演由模型自由演绎。不要把配角写成“站着不动”，也不要编排逐人逐关节动作；配角活性不得新增攻击、反制、对白、伤势或控制权变化。
- `特效`：从源点、形态变化、传播/第一作用、必要环境反应、停止/残留中选择本镜真正承担的项目，不机械写满。每个生成段第一镜或首个高能镜要用一句可见规则建立本段VFX母题，如形状、材质、颜色、运动规律、染光或残留方式；后续镜写母题如何变化，不写抽象设定说明。
- `光影`：环境主光 -> VFX染色、投影、遮挡或反射 -> 本镜曝光/光权变化。
- `音效`：环境底噪 -> 动作起动 -> 接触/规避 -> 声音桥或余波。关键控制权变化处用声音强弱、抽空、延迟、压迫或余音帮助情绪张弛，不新增对白或解释。
- `台词`：逐字保留源剧本和身份标记；多人对白、OS、OV或系统音在同一字段内按发生顺序串联；无内容写 `无`。

固定字段不等于每镜重复全部信息。每个生成段自足，后续镜头采用具体增量状态，以减少注意力稀释和相互污染。文件合并不等于跨段省略锚点；新生成段第一镜仍须写出独立投喂所需状态。

固定字段也不等于把动作过程写满。每镜只写剧情实际需要的 `起始/身份、决定性动作、关键作用、结果/下一镜入口` 控制点；不要求四项机械齐全。原文未规定的身体协调、重心转移、惯性、衣发随动、粒子湍流和自然摄影补偿交给模型演绎。

### 双密度写法

最终正文采用 `高视觉表达密度 + 低微动作控制密度`，不得把两者混为一谈：

- 控制点保持少而准：只规定剧情必需的动作承诺、作用对象、力量方向和结果边界。
- 视觉表达保持丰而实：写出同一动作的姿态气质、宏观轨迹、速度/重量性质、敌我压迫关系、VFX可辨形态与演化、环境受力、光权变化和声音节奏。
- 丰富描述只要共同证明同一视觉主事件，就不因字数较多自动构成过载；过载取决于独立事件、互斥姿态、控制权变化和必须精确兑现的中间步骤数量。
- 精简优先删除重复同义词、空洞赞美、伪精确数字和N/E身体补间；不得把“反手光弧劈穿黑雾核心”“沿两侧墙面交替借力拔高”“环形风压撕开下方浓雾”压缩成“释放特效”“蹬墙跳起”“气场爆发”。
- 如果去掉风格词后剧情仍完整，但成品只剩工程摘要，补回动作形态、空间关系、VFX行为、环境/光影反应和声音落点，不新增剧情事件。

## 5. 信息取舍

最终文本按三层处理：

- `A级S事实`必须显式保留：人物、事件、动作、顺序、因果、台词、能力规则、关键VFX和结果。
- `B级锚点`按漂移风险保留：身份、空间方向、主要运镜、关键光影和环境证据。
- `C级补间`默认交给模型：非剧情关键的厘米距离、重复材质、细碎肢体轨迹、粒子参数和装饰性回收。

精简时只删除重复形容、同义复述、无执行价值标签、无原文锚点的E装饰和可安全省略的C补间。不得以“提示词过长”“镜头太多”或“模型承载不足”为理由删除、概括、改序或弱化S原文事实。

过载处理顺序为：`删无锚点E -> 压缩N -> 去重复与伪精确 -> 简化非关键运镜/VFX -> 按主观看任务拆镜或内切 -> 聚合同一动作弧中物理兼容的部分 -> 拆生成段`。

正文禁止把N/E补间写成逐秒或亚秒时间码、逐关节角度、连续厘米位移、逐步落脚或密集“先—再—随后—立即”清单。只有原文明确规定或为避免S动作归属歧义所必需的细节才进入正文；若这些S控制点在现有时长内无法自然完成，延长镜头或拆分，不得压缩表演时间。

## 6. 时长与台词

- 每个生成段中所有镜头标题时长之和必须 `<=30秒`；整份多段文件可以超过30秒。超限只拆生成段，不拆文件，不得删改S剧情或强行加速。
- 生成段标题时长必须与段内镜头合计完全一致；校验器按生成段分别计算。
- 镜头时长按动作、对白、VFX结果和运镜的并行时间区间计算，不机械相加。
- 中间镜头可以切在运动入口、威胁逼近或动作承诺上；决定性结果和段末结果必须可读。
- 台词只统计实际说出的正文，按自然语速、标点、换气和表演停顿估算。
- 对白与动作可以并行，但口型、发声、呼吸和受力必须兼容。
- 说不完时优先延长镜头或在自然语义点拆镜；不得删字、改写、快读或增加新对白字段。

## 7. 唯一默认示例

```text
生成段 01｜夜巷立势｜2.2s

镜号 01｜超远全景｜镜头缓慢向前匀速推进，微俯角机位｜2.2s

画面内容：深夜都市背街，狭长小巷向黑暗深处延伸，两侧围墙与远处高层住宅形成纵深；巷心只有宋棠一人，她面向巷口站定，成为画面第一读点。

特效：空气中漂浮少量都市扬尘颗粒。

光影：高位冷白月光压暗巷道，零星路灯形成微弱暖黄点光，宋棠轮廓清晰。

音效：远处车流底噪，巷内安静。

台词：无
```

## 8. 发布前检查

- 默认文档第一行直接以 `生成段 01｜` 开始，全文只含固定生成段标题与镜头块；旧版单段兼容格式可直接以 `镜号 01｜` 开始。
- 生成段编号连续；全场镜号从01开始跨段连续；每段标题时长等于段内镜头合计。
- 每镜严格匹配 `标题 -> 画面内容 -> 特效 -> 光影 -> 音效 -> 台词`，字段间一个空行。
- 标题含镜号、景别、主要运镜、机位/角度和时长。
- 每个生成段镜头时长之和不超过30秒；文件总时长可以超过30秒。没有为了填满30秒增加动作，也没有为了压进30秒缩短S动作。
- 生成段第一镜完整建立必要锚点，后续镜只写具体增量状态，无空洞跨镜指代，也无全套机械复述。
- 多人镜头通过群体活性审查：非主要人物有身份、信息差、受力差或关系差驱动的可见状态变化，反应允许错峰和局部遮挡；不得全部同步、复制粘贴或因“主体突出”变成木偶。
- 每个镜头有清楚的观看目的；可以采用单一摄影意图，也可以采用由同一动作因果驱动、空间连续且主体可追踪的复合摄影意图；同一动作弧没有因动词数量被机械切碎。
- 每个镜头通过镜头空间门：景别可见范围、机位遮挡、摄影机路径和VFX占区不互相冲突；不存在近景看全身、远景读微表情、运镜无桥穿过不透明实体、特效遮掉接触点等空间不可成立要求。
- 每个镜头都能反推出内部摄影机证明卡：主观看任务、现实/虚拟机位类型、高度/角度、路径起终点、观看收益、可见范围、遮挡读取窗口、空间桥和放弃信息。若只能靠“全知视角、无桥瞬移、同时看清、无因穿梭”成立，判定失败并拆镜；可解释的增强虚拟运镜应保留。
- 每个生成段的VFX母题已经落进 `特效` 字段并跨镜递进；关键控制权和情绪张弛已经落进 `画面内容`、`光影` 或 `音效`，不是只停留在内部分析。
- 承担启动、攻防转折或终结的高能生成段已经通过场景专属惊喜门；把关键镜替换成固定全景、普通侧拍、反打或过肩后会损失明确的观看信息，而不是只损失风格词。
- 选中的惊喜能从当前剧情、人物、能力、环境材质或声音推出，具备现实/虚拟机位与形态桥、结果残留，没有复用参考示例的具体镜头答案。
- 动作的速度、重量、方向、压迫和冲击已经通过宏观轨迹、环境视差、接触反馈、光影或声音得到可见证明；运镜只保留新增观看信息，不因追求动感无因换向或遮挡主动作。
- 每镜只保留最少充分控制点，正文不存在原文未规定的亚秒编舞、逐关节轨迹、连续精确位移或密集N/E微动作；模型自由区仍然存在。
- 每镜保持高视觉表达密度；动作气质、宏观运动弧、敌我压迫关系、VFX形态演化、环境受力、光权变化和声音节奏没有随微动作收敛一起被删掉。
- 负载按独立事件与互斥姿态判断，不按字数直接判断；不存在为了“简短”而交付“人物做动作＋特效出现＋环境震动”的干瘪摘要。
- S事实覆盖率100%，顺序、执行者、肢体/能力、对象、力度、能力规则、台词和结果不变。
- 去掉E后仍能按原顺序反向复述原剧情；不存在新增攻击、躲避、反制、伤势、能力、台词或控制权变化。
- 高风险语义已按既定收敛顺序处理；若仍装不下，拆生成段而不是删剧情。
- 台词时长自然，动作、VFX、光影和声音在同一时间轴上物理兼容。
- 文件不含内部标记、负面提示词或代码围栏。
- 交付前运行 `python3 scripts/validate_storyboard_format.py <成品.md>`；脚本检查单文件多生成段格式、段号与镜号、段标题时长、每段30秒硬上限、空洞跨镜指代、内部标记，以及常见景别可见范围、摄影机穿实体和VFX遮主事件风险。台词时长、复杂语义负载、剧情保真、空间连续与创意质量必须人工/模型审片，不能交给固定阈值替代。

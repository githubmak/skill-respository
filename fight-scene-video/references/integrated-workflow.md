# 剧本基线优先的完整打斗制作协作流程

只在 `fight-scene-video` 已完成剧本保真资格门、条件化演绎发散、剧本锚定融合和演绎质量门后使用。这里的“模块”是技能内部的条件式审查角色，不是每次都要调用的外部技能。仅在当前风险真实存在时启用，未启用项不分析、不输出空字段；任何模块都不能提出替代剧情或用默认模板覆盖剧本动作、顺序、台词和结果。

## 主状态包

所有模块都先接收：

```text
source_fidelity: 原文位置/原句、P事件、必保事实、N必要补足、E演绎增强、禁止推断、承载镜号
immutable_script: 角色、事件、动作、顺序、因果、力度词、台词、能力规则、胜负与结果
performance_hook: 剧本与预算允许时的演绎辨识点；没有合法空间时服从原剧本
script_anchored_blueprint: 角色演绎签名、VFX母题、场面力、层次与规模、当前风格所需证据、环境证明、剧本已有博弈、升级、摄影光影、可选记忆点构图
budgeted_performance_kernel: 通过剧本资格门且位于Seedance执行预算内时优先保留的机制与画面
immutable_user_facts: 用户设定、平台、素材和禁止项
```

只有以上内容确认后，才追加执行字段：

```text
scene_state: 地标、材质、光源、合法路线、危险区
fight_beat: 当前剧本事件、原文规定的双方选择、控制权变化
action_vector: 起始姿态 -> 路径 -> 接触/规避 -> 受力/反作用 -> 落幅
ability_state: 来源、行为、交互、环境反馈、残留
spectacle_state: 力量占区、前中后景/高低层、尺度参照、环境级后果、余波
camera_intent: 本镜怎样呈现剧本事件与权力变化
timing: 动作/对白/VFX/环境/运镜的时间区间、并行关键路径、冲击点、稳定落幅、切点
```

## 条件式审查角色

### 构图与材质审查

按当前导演方案细化需要的空间层次、接触面、材质、VFX染色/遮挡、尺度参照和强弱构图；可以多层，也可以极简或利用负空间。返回内容必须服务 `performance_hook` 且不能越过源剧本；不得用常规人物居中构图替换已经选择的记忆点构图。

### 摄影与轨道审查

量化已定 `camera_intent` 的景别、角度、轨迹、速度、焦点、轴线和落幅。若原构想单镜不稳定，提出覆盖拆分，不能另选默认机位、删除剧本事件或无因裁掉预算内尺度参照。

### 平面/高度关系审查

只接收批准后的平面、高度、道具、VFX占区和摄影机事实。返回调度参考，不改变剧本锚定演绎蓝图；没有明显空间风险时不强制生成。

### 连续性审查

记录每镜真实落幅、剧本事实与 `budgeted_performance_kernel` 的跨镜载体，包括动作势能、武器归属、伤势、VFX残留、环境破坏、曝光和控制权。下一镜内部从这些状态继续，最终提示词仍独立重述必要状态。

### 音效审查

在剧本动作时点确定后设计预备、路径、接触、材质、静音和余波。声音强化原动作与VFX行为，不用通用轰鸣掩盖视觉因果。

### 表演与群体活性审查

在表演能改变佯攻、判断、忍痛、恢复、人物关系或观看意味时调用。锚点数量由当前节拍需要决定，不新增会改变剧情的情绪支线；表演可与动作/VFX共享信息预算，不设固定配额。

## 工程变更协议

任何条件式审查建议改动时必须返回：

```text
保留的剧本事实/演绎核：[原文事件、动作、结果；可保留机制/画面]
发现的具体风险：[可验证问题]
最小改动：[拆镜/换覆盖/分阶段/降低同时性/稳定落幅]
剧本保真检查：[原文覆盖、顺序、动作、台词、结果是否仍成立；演绎核保留情况]
```

禁止只返回“简化动作”“减少特效”或“改成稳定镜头”。先保证剧本事实；演绎核无法保留时把冲突交回 `fight-scene-video` 按生成预算裁决，不得静默替换剧本。

## 合并质量门

1. 最终镜头逐项覆盖 `source_fidelity`，顺序、动作、台词和结果与源剧本一致；在预算允许时保留 `performance_kernel`。
2. 动作、VFX、环境、摄影和声音围绕一个或多个因果连续的剧本事件形成可读关系，不是无因并列装饰。
3. 当前导演方案选择的场面力、尺度、留白、克制或宏大证据在工程调整后仍然成立。
4. 工程修改均有具体风险证据，且采用最小干预。
5. 位置、轴线、道具、伤势、残留、曝光和落幅连续。
6. 轨迹图、关键帧和提示词只是同一剧本事实与预算内演绎的不同表达。
7. 最终提示词不含专家元数据、地图标注或内部分析标签。

# 动作动势与摄影自适应层

只在剧情真值、导演演绎和空间锚点锁定后读取。本参考把动作的速度感、重量感和压迫感翻译成摄影与环境证据，不提供固定镜头模板。摄影方案必须由当前剧本事件、空间、人物能力和观看目的动态生成。

## 1. 先提取动作动势

对每个主动作只提取实际存在的性质，不强行填满：

`速度体感 / 重量体感 / 运动方向 / 距离变化 / 垂直变化 / 接触冲击 / 控制权压力 / 情绪张力`

例如“瞬间沿巷道直线冲刺”需要证明速度、直线方向和距离骤减；“沉重地砸入地面”需要证明重量、垂直方向、支撑受力和冲击后果；“无声逼近”需要保留压力但不能无因加入轰鸣。原剧本没有写出的性质只作为导演可选表达，不得改变动作力度。

## 2. 动势到摄影的动态选择

根据观看目的自由选择一种或多种摄影动势。下表是可选关系，不是硬编码配额：

| 动作性质 | 可证明它的摄影/画面手段 | 必须避免 |
|---|---|---|
| 高速直线移动 | 侧向跟拍、纵深推进、环境视差、进入画面后的制动 | 无因环绕、乱晃、越轴、切掉路径 |
| 突然加速或瞬移式变化 | 固定观察后主体瞬间占位、短促推镜、遮挡揭示、声音先行 | 把“瞬间”写成慢蓄力或连续多次移动 |
| 沉重打击 | 接触前稳定构图、命中瞬间短震、冲击后拉远或低机位承重 | 用高速摄影掩盖接触点，或让受击者无因飞远 |
| 近身连续攻防 | 侧后三分之四跟随、短弧环绕、局部遮挡内切、脚下和武器线保留 | 正面重叠、频繁换轴、每个微动作独立切镜 |
| 大型VFX展开 | 从源点跟随到空间占领、拉远揭示尺度、地标视差、光域扩张 | 只用全屏亮光、让人物和来源消失 |
| 受压或碾压 | 缓慢逼近、压低机位、负空间收缩、群体反应错峰 | 无因加快节奏、配角同步摆拍 |
| 突然静止或规则冻结 | 运动中断后的固定观察、声音抽空、残留粒子停滞 | 继续添加高速运镜或新攻击 |

一项动作可以有丰富画面和运镜，但所有摄影变化必须回答“观众因此新增看清了什么”。没有新增来源、路径、接触、受力、尺度、控制权或结果信息的运镜，删除或改为模型自然补偿。

## 3. 迅捷动作的最小充分表达

需要体现人物迅捷时，提示词至少选择以下可见证据中的足够组合，不固定数量：

- 人物宏观轨迹：贴地、纵深、横向、垂直或跨障碍的连续运动弧；
- 环境视差：墙柱、轨道、地面纹理、雨幕、尘雾或光带沿运动方向产生相对位移；
- 动作触发：脚下受力、武器发光、能力启动、目标暴露或声音突变；
- 摄影响应：跟随、短推、横移、遮挡揭示、接触前制动或冲击后拉远；
- 结果窗口：攻击线、接触点、受力方向、落点或新距离必须在正常观看速度下可读。

不要用“超快、极致速度、电影感”替代这些可见证据。也不要把这些证据写成逐帧路径、每个关节或厘米位移。

## 4. 摄影稳定与空间连续

摄影可以复杂，但要维护以下动态状态：

- 绑定对象明确：摄影机跟随谁、何时交接焦点、何时制动；
- 攻防轴线可追踪：移动方向、屏幕侧、地标和高度关系至少继承一项；
- 复杂运镜由动作触发：加速、闪避、接触、爆发、坠落、规则改变或结果揭示；
- 关键证据不被遮挡：来源、路径、接触、受力和结果至少有清楚的承担镜面；
- 多人镜头保持活性分层：主要人物承担主事件，非主要人物按身份、信息、受力或关系错峰反应，不同步木偶化。

摄影风险出现时，先缩短无功能的轨道或减少无因换向；保留主动作、VFX行为、环境受力和结果证据。不能为了让摄影稳定而删除原剧本动作或把宏大VFX降成泛光。

## 5. 后置复核

完成镜头后做三问：

1. 删除运镜词后，原剧情动作和结果是否仍然成立？若否，说明动作设计不足，不能靠摄影补救。
2. 删除风格词后，观众是否仍能感到速度、重量或压迫？若否，补回宏观轨迹、环境视差、接触反馈或光影/声音后果，不新增剧情。
3. 是否因为追求动感而改变动作归属、方向、顺序、力度、空间轴线或配角决策？若是，退回最小修复。

只有通过三问，才把摄影动势写入固定五字段交付正文。

## 6. 慢镜与速度对比

慢镜不是速度的反义词。对于原文明确“猛然、快、瞬间、擦着边缘”等动作，保持叙事时间的突然性，在接触边缘、爪影擦过、粒子受力或落地承重的极短观察窗口使用升格；前后用正常速度、声音加速、运动拖影或摄影机突停形成速度对比。若升格让动作看起来像缓慢完成，删除升格或缩短观察窗口。

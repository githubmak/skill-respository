# 特殊视角与运动语法库

只在剧本锚定演绎蓝图已经确定特殊视角承担的叙事任务后读取。本参考翻译摄影机与主体的关系、路径、焦点和落幅，不从视角菜单反向生成打斗，也不得把预算内视角设计改成默认ACT或普通侧拍。

## 基础区分

- `视角`：摄影机与主体、动作轴线及观众知情范围的关系。
- `运镜`：摄影机从起点到终点的路径及速度变化。
- `焦点交接`：观众注意力从一个对象转移到另一个对象的可见触发。
- `稳定落幅`：高速运动后留出可辨认的终点构图，为下一镜提供位置、朝向和动作状态。

每个生成片段锁定一个视角关系、一个主运镜、一个决定性动作链和最多一次焦点交接。特殊视角不能替代动作因果、打击反馈或空间调度。

## 选型表

| 视角 | 叙事价值 | 适合动作 | 不适合 |
|---|---|---|---|
| 穿越尺度 | 从宏观威胁锁定微观目标，制造失重与不可阻挡感 | 天外降临、垂直追击、剑气/法器跨层飞行、从城池锁定单人 | 普通近战起手、无目标的景观巡游、频繁改变方向 |
| ACT第三人称 | 同时看清主角操作、敌人攻击线和环境路线 | 双人近战、冷兵器拆招、追逃、Boss压迫 | 脸部微表情主导、多人拥挤缠斗、全程高速环绕 |
| FPV贴身 | 让观众与高速小主体或弹体共享危险路线 | 灵虫、飞剑、弹体、无人机、车辆缝隙穿越 | 稳重人物对白、需要完整看清双人身体接触的镜头 |
| POV第一人称 | 限制观众知情范围，放大恐惧、疼痛、眩晕与反应 | 伏击、负伤逃生、持械格挡、失明恢复、狭窄空间搜索 | 展示角色全身武术、需要客观确认背后动作的镜头 |
| 水平横移 | 逐个揭示人物、战线和权力关系，保留横向空间连续 | 列阵对峙、多组战线、侧面追逐、逐人接力动作 | 垂直落差主导、复杂环绕、同一时刻多次焦点跳转 |
| 鸟瞰实拍视角 | 展示地形、队形、追逃路线、阵法和巨型VFX范围 | 群战建立、包围变化、车辆追逐、阵法启闭、环境毁伤 | 证明拳脚接触、表情表演、精细兵器拆招 |

## 六类视角的生成规则

### 1. 穿越尺度

锁定一个持续可追踪的中心锚点，例如地球、城市光源、道路、车辆、坠落人物或飞行剑气。按 `短暂停留建立尺度 -> 沿单一路径加速 -> 穿越可见空间层 -> 接近目标前明显制动 -> 转为相对稳定跟拍 -> 落幅` 设计。

- 每穿越一层空间都给一个边界证据：近地轨道、大气辉光、云顶、山脉、道路、地表尘土。
- 极端尺度变化必须保持方向连续，不能在云层遮挡后无故换轴、瞬移或更换目标。
- 速度感来自目标放大率、前景掠过、视差、空气/云雾受力和制动，不只来自动态模糊。
- 跨越三层以上空间默认拆镜，并用中心目标、运动方向或遮挡做匹配；仅在路径单一且锚点始终清楚时使用一镜到底。
- 用于战斗时必须在落幅进入战术关系，例如贴车追拍、锁定坠落敌人、跟随剑气抵达战场，不能只落到风景。

### 2. ACT第三人称

摄影机绑定主角后侧或侧后方，保持相对距离和高度，让主角、敌人及攻击线在关键时刻同时可见。把“游戏感”翻译为可见摄影机关系，不要只写 `ACT视角`。

- 主角通常占画面约四分之一到三分之一，前方保留敌人与路线空间。
- 进入接触前减少晃动和环绕幅度，以侧面或三分之四角度看清武器路线、接触点和受力方向。
- 主角闪避或冲刺时摄影机跟随同一主路径；敌人腾空等新威胁通过短摇镜或焦点转移揭示，不叠加第二条复杂轨道。
- 慢动作只服务一次决定性接触或反转，结束后恢复稳定速度并展示后果。
- 连续三段以上剑招、空翻、俯冲、冲刺和收剑不能全部塞进一个生成片段；按承诺攻击、接触、结果拆分。

### 3. FPV贴身

摄影机与高速主体近似同轨，画面能看见主体的稳定识别部位，并通过近物视差和危险间隙读出速度。FPV不是随机抖动。

- 锁定绑定对象、可见识别部位、相对距离、避障方向和最终出口。
- 不规则动力学每镜最多选两类：Z字、一次锐角急转、短暂停悬后加速、侧飞擦边、被冲击掀翻后恢复。
- 最多一次焦点交接，只在即将碰撞的危险物与主体之间切换；其余时间保护主体轮廓。
- 微震必须有物理来源，如电弧干扰、发动机共振、撞击余波；振幅小于主路径，不能遮掉避障逻辑。
- 失重自旋或慢动作只占一个短节拍，随后用固定方向锚点恢复空间感。
- “臭氧味、烧焦气味、燥热”等不可见感受改写为电离尘埃、热浪扭曲、表面灼痕、烟气、呼吸或眯眼反应。

### 4. POV第一人称

摄影机与角色头部/胸口运动绑定，遵守角色真实视线权限。用手、武器、袖口、呼吸起伏或受伤遮挡建立“这是角色在看”，不要凭空展示角色背后和遮挡外的信息。

- 走动微晃来自脚步和呼吸，奔跑晃动仍要保留门、出口、敌人等方向锚点。
- 攻击前让威胁来源进入视野；若角色未看见，只能先用影子、反光、声音对应的转头反应或环境变化提示。
- 手电、武器或法器的朝向必须与视线一致，不能脱离持握位置漂移。
- 眩晕、失明、受击可用短暂失焦、视野偏移、眨眼遮挡表现，但必须恢复到可识别落幅。
- POV适合制造不确定性，不适合客观展示完整武术动作；需要确认全身招式时切到外部机位。

### 5. 水平横移

摄影机沿一条水平轨道平滑移动，人物按横向顺序和前后景层级被依次揭示。焦点交接必须由遮挡退出、人物动作、眼神、道具或摄影机到位触发。

- 以创意蓝图中既定的人物横向次序、间距、姿态、朝向和遮挡关系为基准，再量化摄影机起终点。
- 每个片段只做一次主要焦点交接；多人逐个揭示应拆成镜头组或保持较深景深展示关系。
- 用于打斗时，横移轨道应平行于追逐路线或接触轴线，侧面看清双方距离变化和受力，不在接触瞬间随意越轴。
- 浅景深写成“当前主体清晰、前后人物自然虚化、焦点平滑转移”，不要写互相矛盾的光圈参数。
- 横移结尾必须停在权力变化、威胁来源或决定性人物上，而不是无目的扫完整个场景。

### 6. 鸟瞰实拍视角

这是最终视频中的高位摄影机画面，不是双视图轨迹调度图。画面只显示真实人物、地形、阵法和特效，不显示起终点圆圈、彩色虚线、CAM轨道、箭头或图例。

- 用道路、河流、屋顶、城墙、竹林空地等大地标建立方向和尺度。
- 让队形、包围圈、撤离口、阵法边界或巨型特效覆盖范围成为主体信息。
- 摄影机可固定、缓推或垂直升降三选一；高速群战时优先稳定，让人物群组有清楚阵营标识。
- 鸟瞰不负责表现面部和精细接触；决定性打击前后切入地面机位，再回鸟瞰展示路线或环境后果。
- 城市或战场建立镜头只保留与后续战术有关的地标，避免堆砌无剧情作用的建筑清单。

## 即梦翻译规则

| 原始说法 | 改写为可见规则 |
|---|---|
| ACT动作游戏视角 | 摄影机位于主角后侧低位，保持固定相对距离跟随，主角、敌人和攻击线同时可见，接触瞬间减速并稳定 |
| FPV高速感 | 摄影机与高速主体同轨贴身跟随，近处障碍快速放大擦过，主体识别部位保持清晰，转向后迅速恢复方向锚点 |
| POV沉浸感 | 摄影机绑定角色视线，画面边缘可见持械手与呼吸起伏，只展示角色能看见的威胁和遮挡 |
| 360度高速环绕 | 仅在空间规则改变时使用短弧环绕，主体保持中心、轴线变化可见；完整环绕若遮掉接触则改为半环绕 |
| 120fps高帧率 | 平台支持且用户要求时，写成一次短暂高速慢动作，明确需要看清的接触、电弧、碎屑或形变 |
| 4K/8K电影质感 | 改写为需要稳定的脸、手、武器、布料、发丝、材质破坏和粒子层次，不让分辨率词替代内容 |
| f/12超大光圈、极浅景深 | 删除矛盾参数，写当前主体锐利清楚、前后景自然虚化、焦点平滑交接 |
| 气味、燥热、压迫感 | 改写为烟雾、热浪扭曲、电离尘埃、冷凝、呼吸、眯眼、衣物受风和环境声音对应的可见反应 |
| 强烈手持晃动 | 先写清主轨道，再叠加有来源的小幅惯性微震；接触、避障和落幅时恢复稳定 |

## 双视图轨迹图交接

| 视频视角 | 俯视栏必须标 | 正视栏必须标 |
|---|---|---|
| 穿越尺度 | 投影路径、目标锚点、进入局部战场后的相对路线 | 起始高度、穿越层级、下降/上升曲线、制动点、落幅高度 |
| ACT第三人称 | 主角路径与摄影机平行/跟随轨道、侧后偏移、敌人攻击线 | 镜头高度、与主角距离、敌人腾空/落地和接触高度 |
| FPV贴身 | 主体与摄影机近似同轨、障碍间隙、急转点、出口 | 高低变化、擦边高度、翻滚/失重段、恢复稳定高度 |
| POV第一人称 | 角色路径与摄影机同起终点、朝向与视锥、转头节点 | 眼位/胸位高度、蹲伏/跌倒/起身变化、视线角度 |
| 水平横移 | 与人物排列或动作轴线平行的直线轨道、停点 | 恒定或明确变化的镜头高度、人物前后层级、焦点对象 |
| 鸟瞰实拍视角 | 高位摄影机投影位置、缓推/固定/升降的平面关系、地标 | 摄影机高度、俯角、升降路径、覆盖范围 |

轨迹图只负责验证空间。写即梦视频提示词时，把轨迹事实翻译成真实摄影机关系，删除地图标注语言。

## 失败检查

- 视角名称出现了，但没有摄影机相对位置、路径、焦点或落幅。
- 同一片段同时俯冲、环绕、甩镜、横移、升降，主体无法稳定追踪。
- 高速运动遮掉攻击来源、接触点、受力方向或最终位置。
- POV看见角色不可能看见的背后动作，FPV丢失绑定主体，ACT只剩晃动。
- 鸟瞰视频画面出现轨迹图标记，或轨迹图被当作最终成片构图。
- 技术参数互相矛盾，或分辨率、帧率、镜头名词替代可见画面规则。

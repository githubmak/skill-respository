# 节奏与物理审核

本参考用于内部设计台账和最终Seedance 2.5生成版的交付前审核。它解决“画面很丰富但拖沓、物理反应像填表、动作与原文力度不一致、VFX形态跳变、镜间动力重置”的问题，不替代剧本锚定演绎蓝图，也不要求所有项目采用固定总时长。

## 目录

1. 审核顺序与节奏经济门
2. 原文动词保真
3. 物理与光学门
4. VFX形态连续门
5. 视觉动力交接门
6. 人物意图与空间连续
7. 交付审计表

## 审核顺序

```text
剧情动作保真
-> 首个有效动作与节奏曲线
-> 镜头新增信息/控制权
-> 力量来源与材料物理
-> VFX形态连续
-> 画面主次、粒子动力与运镜交接
-> 光影、构图与生成稳定性
```

## 节奏经济门

### 首个有效动作

- 前3秒出现明确意图、前6秒出现有效术法结果只作为商业短视频的节奏观察点，不是交付门。慢蓄压、误导、静默对峙、空间建立或延迟爆发只要持续提供威胁、信息、关系或观看收益即可成立。
- 建立镜只有在交代路线、危险区、角色目标或关键地标时才独立存在。若主体已在场且下一动作已经开始，直接把建立信息并入动作镜。
- `P前态`不能只代表“人物站着、环境有反应”。如果没有意图改变、威胁出现或空间规则变化，删除或并入P1。

### 镜头新增信息

每个镜头通常应推进下列至少一项，或有意维持一种仍在增长的压力；故意停顿、重复、仪式、观察和余波只要产生观看收益，不因缺少新状态而自动失败：

1. 角色意图或决策改变；
2. 威胁的来源、路径、速度或攻击层改变；
3. VFX形态、规则或作用范围改变；
4. 环境可通行区、遮挡、支撑或残留改变；
5. 控制权或不可逆战果改变。

只有观众已经读懂且继续停留不再增加压力、证据、节奏或意义时，才合并镜头或改成镜内动作。

### 并行不加时

次级链优先在主动作窗口内并行或错峰，不能无意让主动作停住等待装饰完成；有意的悬念延迟、仪式过程、余波归属、对白反应或控制权停顿可以拥有独立时间。稳定落幅按正常观看速度保留足够可读时间，不设统一0.2-0.5秒模板。

动作、对白、VFX第一作用、环境结果与运镜不是默认串行。先标出各自开始与结束时间，单镜时长取必要时间区间的并集，并以最晚必要结果为结束点：完全并行时取最大值；部分并行时只累加前后不可重叠部分。只有对白必须等动作完成、或动作必须由对白结束触发时，才顺序增加对应时间。对白优先采用实测配音；没有音频时按人物状态、句法、换气、力度和停顿估算，常见字符速度只作容量提示。并行时还要检查口型、发声、呼吸和身体受力是否兼容。

### 时长参考

下表只用于节奏诊断，不是自动拆镜或删减剧情的承载上限：

| 时长 | 适合承载 | 交付警告 |
|---:|---|---|
| 1-3秒 | 一个触发、一次反应、一个结果或短动作切片 | 警惕同时重建空间、完成复杂攻防并换机位 |
| 3-5秒 | 一次决定性动作或一次连续显化 | 检查是否出现互斥姿态或第二视觉中心 |
| 5-7秒 | 同一动作弧的接近/承诺/解决 | 保持一个主要观看目的，连续微动作优先聚合 |
| 7秒以上 | 连续演化、英雄宽镜、代表性结果或余波 | 必须持续推进状态，不能用重复姿态和粒子等待填充 |

同一事件连续覆盖多镜时，检查每次重复是否增加证据、压力、视角、节奏或关系；没有任何观看收益时才合并。多个镜头连续以悬停、定住、保持、静默或制动收尾可能是问题，也可能是有意蓄压；根据整场效果判断，不用数量直接触发重排。

### 30秒硬上限与模型演绎空间

- 一个可投喂文件对应一个生成段，镜头时长之和必须不超过30秒。剧情节拍可以跨段，平台生成段不能超限。
- 每镜最终正文只锁S规定或防止误读所需的起始、决定性动作、关键作用和结果控制点；控制点之间的身体协调、惯性、衣发、粒子湍流和次级运动默认交给模型。
- 多个逐秒/亚秒时间码、逐关节轨迹、连续厘米位移、逐步落脚或密集顺序词意味着提示词正在替模型逐帧编舞。先删除N/E微步骤，改成动作性质、力量方向、作用和结果边界。
- S原文明确规定的多步动作不能删除；若自然时间不足，延长镜头，超过30秒时拆镜或拆生成段。

## 原文动词保真

先把每个核心动词改写为不可歧义的动作证据：`执行者 -> 肢体/道具/能力 -> 起点 -> 路径 -> 作用对象 -> 接触/规避 -> 反作用 -> 终点`。多人同镜时，核心动词前重复角色名；若删去特效与风格词后不能唯一还原动作归属、左右肢体、方向、命中/躲开和结果，语义保真失败。

手型、持物或发力部位改变时必须写可见转换。例如“十指交叠结印”转为“右手并指横切”，应先写十指松开、左手收回位置、右手食中二指并拢，再写横切起终点；不得让模型自行补全互斥姿态。

把原文中的力度和时间词列为不可牺牲事实，逐镜对照：

| 原文语义 | 允许的可视化 | 禁止的软化/重复 |
|---|---|---|
| 骤然、骤然结印 | 直接进入手势承诺，快速完成 | 先观察环境、慢慢抬手再结印 |
| 凭空炸燃、瞬间显现 | 源点与亮起在同一动作窗口完成 | 先翻出、停顿、再逐股渗出 |
| 猛地向下一坠、笔直浇落 | 垂直路径迅速占据画面并命中 | 长时间横向旋转、等待环境反应 |
| 瞬间包裹、齐齐扑来 | 同一宽镜建立群体威胁并快速进入接触前 | 分三轮等待每个目标到位 |
| 快一倍、疯狂涌去 | 重组与追击连续加速 | 先慢速重组再长时间蓄势 |
| 霎时、猛然僵住、彻底沉寂 | 冲击、锁停、受术和静音形成短促落幅 | 先切断一次、再重新显形、再重复击杀 |
| 无尘、没有惊起一粒尘土 | 落地时明确保持环境静止 | 先扬尘再用剪辑隐藏落地 |

## 物理与光学门

### 力量来源

每条环境反应都写成：`动作前状态 -> 作用来源/方向 -> 材质反应 -> 动作后状态`。若无法说明来源，删除该反应或改成明确的法术规则。

- 石板能裂、崩角、扬粉和翘起边缘；裂缝本身不能“抬高”。
- 木门可震动、弯曲、劈裂或落灰；需要足够压力和方向，不能无源内凹后自动复原。
- 烟雾可以被气流、热浪和压力边界推移；半透明无实体怪影与环境接触时，要明确是气流排尘还是本体碰撞。
- 布料、发丝和尘埃应沿同一受力方向响应；不要只让一个方便的道具受力。

### 光影

- 自发光特效必须对邻近人物、墙面、尘雾和粗糙青石产生随距离衰减的染光。
- 分色火焰优先表现为不同颜色的染光、反射、体积光和烟尘分层；不要把多个相近光源写成清楚的多层实体影子，除非光源空间位置与遮挡关系可见。
- 冲击波或强光必须保留主体五官、轮廓、路径和暗部回归；不能用白闪替代接触证据。

### 材质可读性

一次主要冲击通常突出最能证明力量方向和战果的少量材质；不设固定两种上限。更多材质只有在各自提供不同尺度、方向或结果证据且画面仍可读时保留。选材优先级为：

1. 能证明主力量方向的材质；
2. 能证明控制权或战果的材质；
3. 其余装饰性材质删除。

## VFX形态连续门

每次形态变化必须写出一条可见桥接：`上一形态的残留/密度 -> 压缩或展开动作 -> 新形态轮廓 -> 新形态的第一作用`。

- 烟影变黑柱：写清碎片如何沿墙影或裂缝汇聚，柱体如何保留嘴影/躯体记忆。
- 黑柱被气浪命中：写清柱壳被剥离、压扁或冻结，内部怪影怎样保留为代表性受术目标。
- 怪物焦枯回收：写清能量介入点、运动中断、材质变化和灰丝回流，不能用“消失”跳过。
- 同一战果只完成一次；锁停、切断、焦枯、回收必须分工清楚。

## 视觉动力交接门

本门位于剧本动作冻结之后。不得用它增删、改序或改时 `P` 事件，不得修改对白、人物意图、情绪落点、剧本招式和结果；只修画面主次、粒子受力、VFX状态桥与摄影机推进。预算内演绎核与剧本动作可读性冲突时，按生成预算优先级收敛E项。

### 画面读取顺序

每镜明确 `第一读点 -> 主路径 -> 结果证据`：第一读点是当前控制权主体或迫近威胁；主路径连接力量源点与作用对象；结果证据证明空间、控制权或战果已经改变。次级特效可以丰富画面，但不得以更高亮度、更大面积或更快运动抢走第一读点。删除颜色和形容词后若仍看不出这三项，返回构图与动作覆盖，不增加装饰。

### VFX与粒子推进

- 跨镜VFX按 `前镜形态/残留 -> 本镜承担的主要变化 -> 第一作用 -> 可继承后态` 推进；不得在新镜恢复成未触发状态或重复显化。
- 粒子按 `来源 -> 受力方向 -> 传播载体 -> 停止/回收条件` 描述，只保留能证明力量方向、速度、占区、控制权或战果的粒子。
- 粒子可承接切镜动力，例如前镜被波前推向画外，下一镜从同方向进入；它只能传递主动作，不能让主动作等待粒子完成。

### 运镜推进

- 每镜写清 `绑定对象 -> 启动触发 -> 单一主轨道 -> 制动点 -> 下一镜入口`。绑定对象只选主体、接触点或主VFX波前之一。
- 摄影机运动必须新增来源、路径、空间占区、控制权或战果信息。对象已高速运动时可稳定摄影；尺度展开或控制权反转时再改变距离或高度。
- 相邻镜确属同一连续动作时，应继承足以维持因果的主体/VFX方向、屏幕位置、形态残留、遮光区、受力粒子、声音趋势或其他状态；故意断裂、冲击硬切、时空跳转或策略重置可以中断。前镜落幅不应在无解释时被重置成中性站姿。
- 摄影机不得追逐装饰粒子、无动作原因反向、同时执行两个主轨道，或用环绕和甩镜代替接触与战果。

每个主运镜用 `观看对象 -> 动作触发 -> 物理路径 -> 揭示新信息 -> 结果或切点` 复核。路径可以单一或复合，只要物理连续且不争抢主动作；高速躲避、术法扩大和冲击证据没有固定拍法，最终以来源、路径和结果可读为准。

### 生成段连续状态与反向复述

最终提示词以整个生成段为自足单位。第一镜完整建立必要人物、空间、能力、环境与主光锚点；后续镜只重述当前可见、剧情必需、发生变化或存在漂移风险的状态。不得以“前镜、上一镜、继承镜XX、同上、沿用、继续上一镜”等空指代替代可见事实，也不得机械复制全套设定。

只看同一生成段的连续镜头，审片者必须能按原顺序唯一回答谁使用何种原文规定的肢体/道具/能力，对谁做什么，是否接触或躲开，能力如何作用，以及最终谁取得控制权。C级补间不要求唯一；A级S事实存在第二种合理答案即退回。这项语义检查不能由格式校验器替代。

## 人物意图与空间连续

- 角色的动作必须服务本镜目标。掩饰、诱导、试探和假装无事时，移动速度、视线、身体距离与台词必须互相支持。
- 对手真正夺得控制权时，主角必须有可见的受限状态；如果所有攻击都在主角预设通道内，不能同时宣称敌方取得主动。
- 每次改变高度、左右关系或攻击轴线，都要交代地标、转身或中性重置镜；不能只靠换景别跳转。

## 交付审计表

| 生成段/镜号 | 剧情事件/既定时长 | 段首锚点或本镜增量状态 | 执行者/能力→对象→动作→结果 | 第一读点→主路径→结果 | 力量/粒子来源→方向→停点 | 主要材质与叙事作用 | VFX前态→变化→后态 | 运镜触发→路径→揭示→切点/制动 | 本镜入口/结果 | 段级反向复述 | 通过/退回 |
|---|---|---|---|---|---|---|---|---|---|---|

任何一项退回时，先合并或重写镜头，再补充画面层次；不得用更多粒子、材质或形容词通过审核。

# 东方术法动作母题库

只在源剧本的术法、触发、作用与结果已经逐项锁定后读取。下表仅校验文化语义、显化结构、尺度与生成风险，不是招式菜单；不得从表中添加剧本未写的能力、触发、代价、招式阶段、反制或结果。剧本与表格冲突时无条件以剧本为准，只把兼容项作为E演绎候选。

| 母题 | 核心触发 | 动作/VFX递进 | 镜头重点 | 必查风险 |
|---|---|---|---|---|
| 灵丝/骨笛/环境绞杀 | 指尖、骨笛、银饰、咒纹牵引；柔丝绷紧成刃 | 预警物被切 -> 后仰/滑步格挡 -> 借反冲走位 -> 腾空控丝 -> 网阵张紧 -> 环境被切割 -> 收丝 | 微距建立丝线；沿单根丝看张力目标；远景展示网阵占地 | 来源、张力、遮挡和目标材质清楚；禁止穿身、乱结、骨笛漂移 |
| 音律化形/琴弦召唤 | 指法、主弦回弹、乐器共鸣 | 流光丝线 -> 环形音浪 -> 液态灵光升空 -> 神鸟/羽翼成形 -> 冲击目标 -> 回栖乐器 | 手指/琴弦近景与召唤物全景分镜；音浪推动衣物和植物 | 乐器位置和开合稳定；召唤物结构完整；残影不遮手 |

## 法天象地/巨型法相可选检查坐标

只有源剧本明确包含相应状态时才使用下列阶段；“肉身显弱、维持代价、反噬、破绽”等均不是默认剧情，不得为了完整模板擅自添加。

| 阶段 | 剧情包含时可见证据 |
|---|---|
| 肉身显弱 | 流血、喘息、握力下降、跪地或衣物/饰品受环境压力，先建立施法代价 |
| 触发蓄势 | 十指、剑、符箓、眉心或胸前灵核明确收束能量，不凭空出现巨影 |
| 显化建立 | 从本体身后、脚下阵纹、虚空裂隙或神魂投影升起，并与本体形成固定轴线 |
| 结构稳定 | 头部、躯干、手臂/多层巨手清楚分层；透明度允许看见本体轮廓 |
| 尺度压迫 | 用建筑/树木/山体/地面投影作参照，并让地面、碎石、空气和衣物出现一致受力 |
| 维持/反噬 | 持续结印、灵力/神魂消耗、固定本体或暴露破绽；落幅写清维持、攻击、消散或反噬 |

```text
法相ID：[名称]
来源/附着：[本体背后虚空 / 脚下阵纹 / 剑身 / 眉心神魂]
显化轴线：[本体后方距离；面向；是否同步姿态]
尺度与参照：[相对本体高度；最高点；地面投影；场景参照物]
结构：[头、躯干、手臂/多层巨手；近景只展示可稳定局部]
环境压迫：[地面、碎石、尘埃、空气、衣物的受力方向]
落幅：[完全显化 / 维持手印 / 发动攻击 / 开始消散 / 本体反噬]
```

拆镜数量服从源剧本、导演方案和执行负载。可以分别覆盖触发来源、显化结构与环境压迫，也可以在物理连续且观看中心清楚时同镜完成复杂结印、显化、攻击与环境结果；不得增加“肉身失势、反噬或恢复控制”等原文没有的事件。

## 母题组合规则

- 一镜可以使用一个或多个母题；多个母题必须共享源剧本依据、因果关系和清楚的视觉层级，不能互相争抢动作归属或凭空展开第二套剧情结果。
- 从剧本锚定演绎蓝图确认既定战术功能，再检查预算内VFX母题是否把剧本已有的封路、缴械、显形、压制、救援、破阵、逃生或击杀转化为可见行为；不得从本表反选母题或新增战术功能。
- 召唤物从来源、成形、运动范围、目标、结构与消散/停留状态中呈现当前剧情理解所需的证据；可从结果开场后再揭示来源，不机械补齐全链。
- 符文、阵法和光环必须与动作、地面或法器对齐，不作为随机背景贴图。
- 幻术、时间凝滞、神魂攻击必须给现实世界的可见揭示线索和后果。
- 人物复杂身法、大范围召唤、环境毁伤同镜出现会提高生成风险；先保护完整导演构想，只有动作归属、空间路径、作用关系或结果无法读清时才拆镜。

## 尺度与代价

| 等级 | 影响范围 | 可见代价 |
|---|---|---|
| 小术 | 单个肢体、武器、局部视线或一步路线 | 呼吸变化、手臂酸麻、短暂暴露 |
| 中术 | 掩体、房间、狭窄街道、小型阵区 | 经脉疼痛、法器冷却、移动受限 |
| 大术 | 整个战场、山谷、城墙、天空层 | 神魂透支、固定施法、地形永久改变、友军撤离 |

只有剧本写出升级和代价时才使用本表量化；不得用本参考给角色追加灵力消耗、冷却、受伤或能力限制。升级可以突出一个或多个维度；同时变化时通过构图、节奏、声音和焦点组织可读性，不因维度数量自动拆镜。

## 质量门

- 技能源点与触发原因能在需要理解机制的时间点被确认；允许先见结果、延迟揭示或有意制造短暂悬念。
- 能沿空间连续路径追踪技能到目标或边界。
- 环境反应符合材质，且下一镜继承残留和代价。
- 角色、法器、召唤物和阵法在切点有可继承状态；开放、暧昧或运动中状态按剧情成立。
- 光污染、装饰或仪式元素若服务人物、情绪、世界观或审美母题可以保留；只删除无因重复、遮蔽关键证据或与能力规则冲突者。

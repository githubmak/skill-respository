# 东方玄幻与仙侠打斗

与[共用方法](shared-craft.md)配合读取。本册负责武学身份、境界、术法、法器、阵区与东方视觉材料，也收纳用户先前提供的法天象地及其他东方斗法原始素材；不把宗门职业、五行颜色或升级顺序写成通用世界规则。

## 武学身份进入攻防

剑修、体修、法修、符修与阵修只提示角色依靠身体、兵器、介质、法器还是预布区域获得优势，并不绑定固定能力。同为剑修，可贴身夺线、远距御剑或控住战区；体修可轻巧试探，法修也可近身施法。依据人物性格和既有能力定惯用距离、准备动作、被逼近后的应对与收势。

| 当前重心 | 攻防问题 | 可见证据 |
| --- | --- | --- |
| 兵器与御物 | 兵器离身后怎样守住自身，如何改线或回收 | 本体视线/姿态、兵器路径、归属与接触点连续 |
| 肉身近距 | 怎样越过远距压制，接触后如何维持优势 | 接地、重心、格挡反作用与环境受力 |
| 术法介质 | 发动和传播能否被观察、绕开或利用 | 源点、介质变化、占区边界与残留 |
| 符文阵区 | 布置、触发、维持和退出如何影响位置 | 节点、边界、出口及人物位置稳定 |

## 境界与复合术法

剧情已有境界时，从可达范围、反应速度、持续时间、同时控制对象和环境作用中选真正受等级影响的维度。升级应改变旧打法、对手的回避成本或战场目标；强光粒子可增长，也可因控制精细而收敛。同一能力在不同等级保留可追踪的发力起点、形状、材质或声音。高境界不默认瞬移、毁城、反噬或固定施法代价。

两种术法结合时，先决定它们如何接力、互相约束、改变传播介质或共同影响目标；交汇处的可见形态由作用关系推出。御物与环境操控须能追踪操控者、受控物、作用范围和落点；手势、视线、符纹或声响可以说明联系，未必一一对应运动方向，也不必总画能量线。

## 特殊战场与视觉材料

- **天象或巨大外力对抗**：确认人物要承受、避开、引导，还是完成某项仪式；不默认固定雷击轮次、颜色或终结爆炸。
- **宗门与阵战**：说明队形为何存在、局部哪里承压、谁能补位，以及个人选择怎样影响阵线；群像与人物镜头根据问题交接。
- **秘境或目标争夺**：宝物、出口、禁制、危险地形必须改变路径与控制权；发光目标可以定位，不代替人物目标。
- **文化材质**：云纹、墨韵、符字、霜晶、气流与光晕可建立气质，但须有源点、运动介质、接触或残留。符字受法器或阵区约束，墨迹有扩散方向；颜色不固定代表属性。

宏大奇观应短时真正占领画面，并通过本体、战场与远处地标的受光受力证明规模；近战转入高潮时，原有巨型能力不能无因退成装饰。具体显化、攻击与消散仍服从当前剧情和下方的法天象地原始素材。

仙侠广域效果可在天空、阵区、山川或人物身边建立多个尺度参照；境界差应体现为对手可用路线、抵御方式或阵线任务的变化，不把“境界越高必然毁天灭地”当成定律。劫云、剑阵、法域或空间异象若存在，先定其真实覆盖边界和当前第一作用，再决定云纹、符字、电弧、岩尘怎样从源点传播到接触处。法相或领域的主视觉可以明亮，也可以借剪影与压迫显得巨大。

## 常见名技能的打斗与特效坐标

下列名称是东方玄幻创作中常见的**能力意象标签**，不同故事可能赋予完全不同的规则。仅在用户、源剧情或原创设定已允许对应能力时使用；不凭名字自动追加杀伤、瞬移、分身、代价或破解方式。每项先问“它在本场改变什么攻防条件”，再选形态、光域、粒子与镜头。例示的颜色、材料和动作均可替换，不构成固定招式链。

### 御剑术与万剑成阵

- **作用与攻防**：确定操控的是一柄剑、多剑还是剑气；是追击、封路、护身、分割战区还是形成阵眼。剑离手后，本体的视线、手势、步位和防护选择仍须成立；多剑不自动同时命中。
- **画面与特效**：让一柄主剑或一组关键剑保持可追踪，其余剑按编队、错峰或不同任务形成规模。剑身金属反光、剑罡、拖尾、阵纹可分层出现；拖尾沿实际飞行弧线，不把天空画成均匀光雨。接触时区分剑体、剑气与目标材质的反应。
- **连续性检查**：剑的数量、来源、归属、转向、回收与停留位置可复述；阵列若封住一条路线，对手下一步必须面对该限制。

### 剑域、剑意开天与天地一线

- **作用与攻防**：先分清是扩大感知、限制入域者、改变剑的可达范围，还是发出一次定向斩击。“开天”可只是强烈的空间感和远景后果，不默认真的切开天空或山脉。
- **画面与特效**：领域用可辨边界、方向一致的剑痕或环境反应建立占区；定向大斩先保留持剑者和挥剑线，再让近处介质与远处云、雨、山脊按同一方向回应。主光可沿剑锋推进，粒子和碎屑在锋面之后才出现。
- **连续性检查**：区分领域持续与单次剑击；明确谁在范围内、边界是否移动，以及结果是否由剧情允许。

### 缩地成寸与空间遁行

- **作用与攻防**：确定它是高速移动、折叠路径、短距传送还是视觉误判；对手能观察到起点、终点或中途痕迹中的哪一种。它应改变距离与朝向，不默认拥有无代价脱困能力。
- **画面与特效**：保留固定地标、未完成动作、衣物/尘雨扰动或声源，帮助观众对齐前后空间。地面纹路收缩、景物错位、局部折射或空镜停顿都是可选表达；无需每次残影加电光。
- **连续性检查**：移动前后的武器、伤势、敌我屏幕侧、攻击路径与落点一致；若穿越障碍，规则中须允许。

### 袖里乾坤与掌中空间

- **作用与攻防**：确认它是收纳、封锁、改变尺度、隔绝攻击还是开辟通路。袖口或掌心并不自动能吸走一切；作用边界、目标条件和释放位置由设定决定。
- **画面与特效**：用袖缘、掌纹、目标轮廓与背景视差建立“内外”关系；空间变形可从目标接触处向内收束，或用大场景与小入口的尺度反差证明能力。粒子沿被改变的边界运动，不用满屏黑洞代替空间关系。
- **连续性检查**：进入和离开的物体、人物位置及状态有明确去向；对手是否能攻击施术者、入口或外部环境要按剧情决定。

### 一气化三清与化身分影

- **作用与攻防**：先规定化身是实体、投影、共享感知还是只制造误导；数量、行动自主性和本体关系由当前能力确定。多个身影应承担包夹、诱导、护卫或信息误判中的具体任务。
- **画面与特效**：可用相同姿态的短暂错峰、不同受光、脚下接地和环境触碰区分真实接触与虚影；不靠随机透明度猜哪个是真身。若化身同时行动，给每个关键身影清楚的进入和退出路径。
- **连续性检查**：本体位置、化身数量、受击反馈和消散状态继承；不要为了反转临时改写化身规则。

### 三昧真火与异火控焰

- **作用与攻防**：确认火作用于目标材质、能量、防护还是空间范围；燃烧、吞噬、封路、炼化等功能不能互相自动推导。火焰威力可通过对手的避让和介质变化证明，不只靠面积。
- **画面与特效**：火源、燃烧前缘、卷吸、热扰动、火星与余烬沿同一传播关系组织；核心可高亮，人物与地面受光随距离变化。异火的独特性可来自火形、反常的运动或残留，而非固定红金配色。
- **连续性检查**：火是否需要燃料、能否被水/风改变、是否会蔓延到友方与场景，均由既有规则决定；不凭名字添加焚天或不灭属性。

### 五雷正法与九天劫雷

- **作用与攻防**：分清角色主动引雷、借天气施法、法器放电，还是天地降劫；打击对象、预兆和可规避范围应可理解。雷击不自动等于连环九道或越打越强。
- **画面与特效**：起点可以是云层、阵区、兵器或身体；主放电路径与接触位置明确，次级电弧、短时染光、尘雾和地面反馈随后接力。宏大雷法可先改变整片天空的光域，再由一处明确落点收束观众视线。
- **连续性检查**：雷与被击目标之间的路径、遮挡和环境响应一致；是否留下焦痕、麻痹、地裂或反噬只按剧情成立。

### 周天星斗阵与山河大阵

- **作用与攻防**：确定阵法由哪些节点、阵眼、布置者或天象关系维持；当前功能是守护、封锁、移位、感知还是输出。大阵的震撼来自范围与战术约束，而不只是地面图案越画越密。
- **画面与特效**：先让一两个关键节点和边界可辨，再用连线、天光、地表材质或群体受力显出整体尺度；高空图形与地面出口要对得上。主效峰值可以由阵区闭合、被冲破或重新分配力量触发。
- **连续性检查**：阵眼、人员站位、通行路径和损坏状态跨镜稳定；阵法未在设定中允许时，不自动传送或切割空间。

### 言出法随与真言敕令

- **作用与攻防**：先确认言语改变的是物体运动、规则条件、感知、契约还是他人的选择；有效对象、语义边界与是否必须被听见由设定决定。此类能力的刺激来自一句话改变战术关系，不是每字都引发爆炸。
- **画面与特效**：可以让声音先作用于灯火、风、尘、符文或目标动作，再揭示施术者；文字具象、声波或无形压力任选，需与能力机制相符。强效时环境按语言所指的作用方向依次响应。
- **连续性检查**：说出的内容、实际生效对象和结果一致；不得借模糊台词临时扩张能力范围或改写既定胜负。

### 神魂出窍、幻境与识海交锋

- **作用与攻防**：区分神魂真的离体、共享意识空间、精神攻击或感知误导；现实肉身是否仍受威胁必须按设定明确。心战可以争夺记忆、判断与行动时机，不必变成两团灵光互撞。
- **画面与特效**：以现实场景中的一件物体、姿态或声音作锚，在意识空间改变其尺度、材质或意义；微小的环境异常可比大面积泛光更有压迫。若出现神魂形体，要说明它与本体、目标和意识空间的关系。
- **连续性检查**：现实与主观空间切换时，伤势、物件、时间进度和旁人可见反应不混淆；识破或脱离条件由剧情决定。

这些坐标用于扩展当前人物与场景的导演候选。若某技能名称未在输入出现，不能为了“名技能更华丽”擅自赋予角色；若用户要求原创，可先建立最低必要规则，再比较至少三个攻防机制不同的候选。宏大尺度、粒子时间层与受力反馈按[共用方法](shared-craft.md)校正，成稿格式仍服从主技能。

## 法天象地/巨型法相可选检查坐标

先核对本体及法相的来源/附着、显化位置、结构、尺度参照、第一作用与稳定落幅。只采用源剧情或用户要求已经给出的阶段与代价；“肉身显弱、维持代价、反噬、破绽”等均不是默认剧情，不得为了完整模板擅自添加。下表和内部记录模板是可选证据，不规定显化与出招顺序。

若法天象地是本场核心奇观，安排至少一个让巨像真正支配战场的观看窗口：本体仍能被定位，法相轮廓与远景形成明确尺度差，近处与远处环境沿同一力量方向受光或受力，主效可以强烈发亮并短暂遮挡人物；接触和结果在前后镜头回收。巨像应在攻防或结局中承担具体作用，不因转入近战就自动退成装饰或提前消散。具体显化、攻击与退场仍服从当前人物能力和剧情，不照搬下方历史动作链。

| 阶段 | 剧情包含时可见证据 |
|---|---|
| 肉身显弱 | 流血、喘息、握力下降、跪地或衣物/饰品受环境压力，先建立施法代价 |
| 触发蓄势 | 十指、剑、符箓、眉心或胸前灵核明确收束能量，不凭空出现巨影 |
| 显化建立 | 从本体身后、脚下阵纹、虚空裂隙或神魂投影升起，并与本体形成固定轴线 |
| 结构稳定 | 头部、躯干、手臂/多层巨手清楚分层；透明度允许看见本体轮廓 |
| 尺度压迫 | 用建筑/树木/山体/地面投影作参照，并让地面、碎石、空气和衣物出现一致受力 |
| 维持/反噬 | 持续结印、灵力/神魂消耗、固定本体或暴露破绽；落幅写清维持、攻击、消散或反噬 |

```text
法相ID：[名称]
来源/附着：[本体背后虚空 / 脚下阵纹 / 剑身 / 眉心神魂]
显化轴线：[本体后方距离；面向；是否同步姿态]
尺度与参照：[相对本体高度；最高点；地面投影；场景参照物]
结构：[头、躯干、手臂/多层巨手；近景只展示可稳定局部]
环境压迫：[地面、碎石、尘埃、空气、衣物的受力方向]
落幅：[完全显化 / 维持手印 / 发动攻击 / 开始消散 / 本体反噬]
```

拆镜数量服从源剧本、导演方案和执行负载。可以分别覆盖触发来源、显化结构与环境压迫，也可以在物理连续且观看中心清楚时同镜完成复杂结印、显化、攻击与环境结果；不得增加“肉身失势、反噬或恢复控制”等原文没有的事件。

## 母题组合规则

- 一镜可以使用一个或多个母题；多个母题必须共享源剧本依据、因果关系和清楚的视觉层级，不能互相争抢动作归属或凭空展开第二套剧情结果。
- 从剧本锚定演绎蓝图确认既定战术功能，再检查预算内VFX母题是否把剧本已有的封路、缴械、显形、压制、救援、破阵、逃生或击杀转化为可见行为；不得从本表反选母题或新增战术功能。
- 召唤物从来源、成形、运动范围、目标、结构与消散/停留状态中呈现当前剧情理解所需的证据；可从结果开场后再揭示来源，不机械补齐全链。
- 符文、阵法和光环必须与动作、地面或法器对齐，不作为随机背景贴图。
- 幻术、时间凝滞、神魂攻击必须给现实世界的可见揭示线索和后果。
- 人物复杂身法、大范围召唤、环境毁伤同镜出现会提高生成风险；先保护完整导演构想，只有动作归属、空间路径、作用关系或结果无法读清时才拆镜。

## 尺度与代价

| 等级 | 影响范围 | 可见代价 |
|---|---|---|
| 小术 | 单个肢体、武器、局部视线或一步路线 | 呼吸变化、手臂酸麻、短暂暴露 |
| 中术 | 掩体、房间、狭窄街道、小型阵区 | 经脉疼痛、法器冷却、移动受限 |
| 大术 | 整个战场、山谷、城墙、天空层 | 神魂透支、固定施法、地形永久改变、友军撤离 |

只有剧本写出升级和代价时才使用本表量化；不得用本参考给角色追加灵力消耗、冷却、受伤或能力限制。升级可以突出一个或多个维度；同时变化时通过构图、节奏、声音和焦点组织可读性，不因维度数量自动拆镜。

## 质量门

- 技能源点与触发原因能在需要理解机制的时间点被确认；允许先见结果、延迟揭示或有意制造短暂悬念。
- 能沿空间连续路径追踪技能到目标或边界。
- 环境反应符合材质，且下一镜继承残留和代价。
- 角色、法器、召唤物和阵法在切点有可继承状态；开放、暧昧或运动中状态按剧情成立。
- 光污染、装饰或仪式元素若服务人物、情绪、世界观或审美母题可以保留；只删除无因重复、遮蔽关键证据或与能力规则冲突者。

# 共用打斗创作方法

先服从剧情已明确的人物、能力、伤势、空间、顺序和结局。本册只存五类题材都可使用的创意判断；题材特有的打法、特效材质和约束见各分册。不以作品为目录，不提供固定招式链、时长配额或必选特效。

## 攻防与角色

一场交锋的推进来自新信息与新局面：一方攻击或试探，对手看见/感到线索，改变距离、朝向、支撑、掩体、武器控制或目标，下一次行动再回应这个变化。强弱不要求均势，也不预设“试探—识破—反杀”。即使遮掉特效，双方惯用距离、起动方式、防守、收势与风险偏好也应可辨。

速度需要必要的起动、路径、制动与接触证据；可以省略中间运动，但用地标、尾迹、环境反应或声音维持方向。情绪通过观察时间、出手时机、风险和保护对象改变动作，怒吼或慢镜不能替代选择。已发生的受力、物件归属、伤势和环境残留进入下一镜。

## 能力与效果的因果

为主效内部确定 `源点 → 传播/介质 → 占区 → 接触或规避 → 环境反馈 → 残留`。镜头可延迟揭示来源，不要求每镜展示全链；观众最终能复原能力怎样改变攻防。复合能力应在接力、约束、改变介质或共同作用中产生新关系；只把两套颜色、光束或爆炸叠加，不算组合。

| 作用 | 可选形态 | 必须读回的结果 |
| --- | --- | --- |
| 切割/穿透 | 定向锋面、切线碎片 | 接触部位与切痕连续 |
| 冲击/压制 | 宽前缘、压力方向 | 主体、近处和远处环境按体量响应 |
| 束缚/牵引 | 张力线、受力点 | 目标失衡、路线或可用动作改变 |
| 防护/偏转 | 局部边界受击、沿面传播 | 攻击被阻、转向或突破的状态明确 |
| 显化/召唤 | 来源与结构逐步可辨 | 新主体实际改变遮挡、距离或选择 |

材质不靠换色区分：火、冰、水、金属、尘、能量场各有适合自身设定的流动、破裂、透明、反光、停止和残留方式。护盾反馈先从接触点出现；裂纹或强光不自动代表破盾、受伤或耗尽。

## 光影、粒子与重量

亮度分别服务主效核心、受光主体、环境回声与余辉残留。宏大主效可短时占屏；相邻读取窗口须回收人物选择、接触和战果。强光可使局部过曝，整体仍需留轮廓、黑位、受力方向或接触边界。巨大主体先有整体剪影，再用边缘光、接地阴影和远近受光证明厚度。

### 宏大场面的尺度证据链

先确定本次力量实际覆盖到哪里，再从**主体尺度、空间占区、环境受力、远处响应、人物选择**中挑能证明它的证据。背景天气、空间扰动、主效、目标交互和前景遮挡可以形成纵深，但不是每镜都要叠满的五层模板。观看上可先见人物与地标，后见主效接管，再由接触和远处后果证明范围；顺序可因悬念或视角改变。若删去主效后人物仍能照原路线行动、局部与远景毫无不同，规模尚未进入战斗。

空间层级和时间层级分开设计：远景宏观变化、近处主体与前景碎屑可同时存在，然而第一读点应随发动、传播、接触、结果交接。主效可以最亮，也可以是黑暗裂隙、巨大阴影或无光的压力场；面积、透明度、亮度和持续时间由当前动作与材质决定，不套统一百分比或秒数。

粒子按**预兆、主传播、接触喷发、环境迟滞、余波**选用，不按数量评判壮观。来源、方向、深度、响应时间和落点决定其意义：高速可用稀疏定向尾迹，重量可用大物先动、细尘后起，广域效果可让远近层密度与反应不同。接触处才出现碰撞碎屑；摄影机近处粒子可短暂遮挡，却不能长期吞掉主体、路径和结果。

### 粒子的四种叙事职责

| 职责 | 要回答的问题 | 可用表现 |
| --- | --- | --- |
| 能量/作用 | 力从哪里来、往哪里去、边界在哪 | 收束、锋面、流束、边界脉冲 |
| 环境/尺度 | 哪种材质受力、影响传播多远 | 尘、石、水、雪、草木按不同惯性响应 |
| 损伤/接触 | 击中还是擦过、哪处受损 | 局部火花、碎屑、裂片、滴落物 |
| 识别/文化 | 这属于谁、什么能力或阵营 | 符号、纹理、频率、色温或残留方式 |

一粒子群可承担多个职责，也可完全不用粒子。每种粒子在设计时只需明确源点、运动规律、深度、受光和消散条件；不设同屏总数、统一寿命或统一速度。识别粒子不能抢过主要接触点；环境粒子若在命中前就均匀爆发，会使受力失真。

同一击可产生不同速度的后果：主接触与变形先发生，较大物体随后移动，细屑、烟、水雾或远处地标再回应。只展示最能证明力量的两三环，避免所有物质同刻爆开。若剧情未授权，不因追求重量新增重大伤势、建筑坍塌或资源耗尽。

### 受力反馈的传递链

接触发生时，内部追踪 `施力主体/能力 → 接触部位或防护边界 → 受击主体的姿态/结构 → 支撑面或周边介质 → 可继承的状态`。按戏剧需要选最有价值的可见环节，不要求每击同时具备身体形变、冲击波、粒子喷发和环境破坏。轻击可以只改变眼神、呼吸与手腕；巨大力量也可能被护盾吸收或导走，使远处响应弱于预期。反馈强弱由能力规则、目标材质、接触角度和既定结果决定，不按固定伤害等级套硬直时长或裂缝半径。

## 场地、摄影与声音

高度、狭口、边界、可破坏掩体、湿滑地面、可传力介质与可移动物件，只有改变战术才成为有效场景机制。多人或巨物战先明确个人目标、局部争夺和整体局势中实际存在的层级；远景回答战局，近景回答执行与代价，顺序由观看需求决定。

摄影阶段可分别确认威胁来源、跟住路径、放大接触、揭示尺度、观察对手、证明结果。猛烈运动由动作触发，在需读清的节点给稳定窗口；若一镜承载互斥信息，拆给相邻镜头并恢复敌我方位。声音按起动、传播、接触、余振选择主声部；光峰与声峰可错开，但须符合能力传播和空间距离。

复杂画面让形体、主效作用、环境证据、气氛粒子依次交接第一读点。需要更华丽时，优先增加形态变化、空间跨度、材质交互和时间层，再增加亮度或粒子数量。高潮可以是命中、防守成功、目标脱险、退路封闭或既定失败得到证明；不设统一节奏、慢镜时长与剪辑秒数。

## 使用判断

先选当前剧情的核心动作关系与视听证据，再比较至少三个机制不同的候选。删去主特效后战局若仍原样发生、换空白场地后攻防若毫无变化、遮掉风格词后双方打法若无法区分，应重设受影响节拍，而不是追加装饰。本册与题材分册均为内部参考，不成为成稿中的引用清单或额外字段。

# 现代异能打斗

与[共用方法](shared-craft.md)配合读取。本册处理现代环境中的超常能力如何改变身体、物件、介质、空间与时间。它可以含科技或仪式元素，具体边界由剧情决定；不默认所有异能都需鼻血、虚脱、失控、冷却或生理代价。

## 按作用对象区分能力

| 能力影响 | 核心攻防问题 | 可见证明 |
| --- | --- | --- |
| 身体强化 | 增强的是速度、力量、耐受还是恢复；对手能利用什么差异 | 起动、制动、接地、受击反应与原有伤势连续 |
| 元素/介质 | 能力接触什么才起效，能否改变掩体与路线 | 火、水、冰、雷、空气或其他介质的源点、占区和残留 |
| 隔空操控 | 如何选择目标、获知其状态、同时控制几条路径 | 被控物原位置、归属、运动和落点可追踪 |
| 空间作用 | 改变主体位置、连通关系还是观察角度 | 出入点、地标、未完成动作与敌我方向保持一致 |
| 时间作用 | 改变谁的速度、感知或事件顺序 | 未受影响的参照物与动作状态持续可核对 |
| 精神影响 | 谁接收信息、现实身体处于何处 | 主观感知与客观战场有区分线索 |

身体强化仍需要人物的判断和情绪。强者可快速移动或承受冲击，但速度与力量具体作用由设定决定，不能自动追加音爆、地裂或刀枪不入。念动力不要求手势方向等于物体运动方向；眼神、姿态、声响、物体反应或环境变化都可表示控制关系。

## 空间时间与主客观连续

瞬移、减速、暂停和幻觉须区分“世界真的改变”与“观众暂时看错”。先冻结发动前的双方位置、物件归属、未完成动作与环境残留，再设计发动后的变化。可用固定地标、声音、遮挡或动作接力帮助观众复原；残影、电光、蓝紫色并非必选。暂停或回溯不能无视用户既有的能力范围、代价与结果。

## 现代环境中的视觉证据

异能越不可见，越需要其**第一作用对象**提供证据：物体偏转、屏幕/灯具干扰、玻璃应力、空气折射、尘雨路径或旁人反应。强能力可以没有发光粒子；若使用粒子，确定来源、速度、接触点和残留。城市灯光、车体、玻璃、金属与人群提供现实尺度；超常光域应影响它们，同时给角色脸与结果留读取窗口。

能力达到街区或更大范围时，用多处相距明确的城市地标和错峰环境响应证明覆盖，而不是把每栋楼、每辆车同时摧毁。空间褶皱、风暴、火海或大范围念动力只在当前能力允许时出现；主观画面扭曲与客观物体位移应区分。能力造成的城市变化需回到人物：谁失去路线、谁得到掩体、谁必须改变目标。

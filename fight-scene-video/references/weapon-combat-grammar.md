# 武器与身体动作语法

只在剧本锚定演绎蓝图完成后读取。本参考把剧本允许范围内的拳脚或冷兵器构想翻译成可信距离、重心、攻防线和接触反馈，不提供默认招式方案，也不得把原剧本动作或预算内角色化演绎替换为表中的通用链条。

## 距离带

| 距离带 | 空间关系 | 常见动作 | 核心风险 |
|---|---|---|---|
| D0贴身 | 肩胸可接触，长武器难展开 | 肘膝、擒拿、撞墙、缴械、短刃 | 肢体穿插、武器穿身、归属混乱 |
| D1近距 | 一步内可命中 | 拳腿、短刀、剑柄、盾击、快速格挡 | 连续接触过多、双方同时高速移动 |
| D2中距 | 一次垫步或武器前段可达 | 剑刀劈刺、棍扫、长枪突刺 | 攻击线不清、武器长度漂移 |
| D3长距 | 长兵器或投射物控制区 | 枪矛压线、鞭索、弓弩、飞剑 | 远端穿模、路径失真、命中缺少反应 |
| D4脱离 | 当前无法直接命中 | 绕侧、找掩体、蓄力、撤离、诱敌 | 无目的跑动、距离突然跳变 |

每个节拍从 `起始距离、进入方式、承诺攻击、防守方式、回收窗口、结束距离` 中写出理解当前攻防所需的事实，不机械补齐完整链条；缺省环节可由连续表演自然连接。

## 发力与反馈链

写实力量遵守：`脚掌支撑 -> 髋部/躯干传力 -> 肩肘/腕或武器加速 -> 接触 -> 反作用力 -> 回收`。轻灵武侠可以弱化重量，但不能删除发力方向和落点控制。

- 直线力：刺、冲拳、盾撞，受力者沿攻击线后退或转体卸力。
- 弧线力：横斩、摆拳、棍扫，受力者出现旋转、侧移或防具偏转。
- 下压力：重劈、砸击、压制，地面、膝盖和武器格挡承担垂直负荷。
- 上挑力：撩剑、挑枪、上勾，改变下颌、手臂、武器或身体高度。
- 扭转力：擒拿、绞剑、锁链，必须显示支点、控制端和被控关节/武器。

命中反馈要有与力度、材质和剧情结果相称的可见证据，可以落在身体、武器、服装、尘水、地面、道具、光影或空间关系上，不强制身体与环境各占一项，也不把所有攻击都写成爆炸。重击应让反作用力可被感知，但具体落在手腕肩背承震、武器回弹、支撑脚滑移、回收硬直或其他物理结果上，由当前招式与构图决定。

打击感优先通过接触面压缩/偏转、身体块位移、护具或武器震动、地面支撑变化和后续恢复表现。表情只能补充疼痛后果，不能代替重心破坏、位移和硬直。

原文明确未命中、擦身或闪避时，不新增拳脚或武器接触；将“拳拳到肉”的观看强度转译为攻击线贴身掠过、衣物与皮肤表面受风、支撑脚急停、地面碎屑被切开、身体重心修正和落地承重。只有原文明确命中或唯一推出接触时，才写接触面压缩、身体块位移和反作用冲击。

## 武器语法库

| 类型 | 优势距离/战术 | 可读动作链 | 必有代价/破绽 | AI生成约束 |
|---|---|---|---|---|
| 徒手拳腿 | D0-D1；节奏、角度、重心破坏 | 逼近或假动作 -> 单次承诺攻击 -> 格挡/闪避 -> 失衡或重置 | 重拳回收慢，踢击短暂单脚支撑，连续攻击耗气 | 优先让主要接触可读；复杂摔投可一镜连贯完成，也可按入锁与落地拆镜 |
| 长剑 | D1-D2；刺线、切线、挑开武器 | 剑尖控距 -> 刺/斩 -> 对刃偏转 -> 收剑护中线 | 剑路过长会露侧身，贴身时剑尖失效 | 保持一剑一归属；先显示握把和剑尖方向再接触 |
| 刀 | D1-D2；劈砍压迫、连续逼退 | 沉肩蓄势 -> 弧线劈斩 -> 格挡震开 -> 借势回刀 | 大幅挥斩有硬直，回刀路线可能被截断 | 少写高速刀花；用清楚弧线和受力后退表现凶猛 |
| 枪矛 | D2-D3；直线封路、连续变点 | 枪尖试探 -> 垫步突刺 -> 对方侧闪/拨开 -> 枪尾回护 | 被贴身或枪杆被卡后威力骤降 | 枪杆长度固定；连续刺线、变点或拨压若同属一个可读动作弧可以同镜完成 |
| 棍杖 | D1-D3；扫线、架挡、支撑位移 | 棍端控距 -> 横扫/下压 -> 双手承震 -> 回棍封门 | 大范围扫击受狭窄空间限制，双手被占用 | 保留双手握点；禁止棍体弯折、穿肩或长度跳变 |
| 双短兵器 | D0-D1；左右夹线、攻守分工 | 一手封挡 -> 另一手短刺/切腕 -> 交叉回护 | 身份与左右手极易混乱，防御薄弱 | 保护左右手归属与攻守关系；双手可以连续或同时变化，但动作线不能互相污染 |
| 重兵器 | D1-D2；压制、破甲、破坏掩体 | 扎稳重心 -> 大幅承诺挥击 -> 接触停顿 -> 惯性拖动/回收 | 启动和回收慢，转向迟钝，落空后暴露 | 强调预备和硬直；禁止连续无停顿重击 |
| 盾牌加武器 | D0-D2；推进、封线、制造安全侧 | 盾挡 -> 身体推进 -> 侧面短击 -> 重新覆体 | 视野受限，盾后侧和武器侧存在盲区 | 锁定盾与武器左右归属；命中先见盾面受力再反击 |
| 鞭索/锁链 | D1-D3；缠绕、拉拽、封路 | 起点甩出 -> 弧线绕过 -> 命中/缠住固定目标 -> 张紧拉扯 | 路径易被障碍截断，贴身时自缠风险高 | 每条主弧和张力目标都要可追踪；允许多弧、多锚点或交错控制，但不得穿身乱结 |
| 弓弩/投射 | D3-D4；压制路线、逼出掩体 | 瞄准或张弦 -> 释放 -> 可见飞行线索 -> 命中材质/逼迫走位 | 近身弱、装填或再蓄力有空窗 | 发射者、弹道和落点至少两项同镜可读；不要凭空命中 |

## 攻防关系

- 硬格挡：武器/护具承受力量，必须有震动、火花、退步或握力变化。
- 偏转卸力：接触角度改变攻击线，防守者沿弧线引导，不原地硬吃。
- 空间闪避：先看见可逃路线，再移出攻击线；闪避后必须进入新距离。
- 截击断招：在攻击尚未完成时打击手腕、枪杆、支撑脚或施力关节。
- 以伤换位：明确接受的轻伤、换取的致命角度和持续后果。
- 缴械：先破握力或杠杆，再显示武器脱手、落点和下一镜归属。

## 克制与场景

- 长兵器克制开阔地，窄门、密林、桌椅和贴身距离削弱其展开。
- 重兵器克制固定防线和护甲，速度型角色通过绕侧、诱导落空和回收窗口取胜。
- 短兵器在贴身有利，但进入前必须承担长武器攻击区。
- 盾牌克制单向投射，侧后方、地面、高位和持续缠绕可绕过其正面优势。
- 软兵器依赖净空和固定张力点，柱、树、栏杆既可增强也可截断路径。

## 生成适配

贴身接触、双手换武器、摔投、双方反向高速移动、软兵器缠绕、武器落地再拾取、复杂可破坏物、镜头越轴都会提高生成风险。先保留导演构想；只有当执行者、路径、接触、结果或空间继承已无法同时读清时才拆镜。

把既定动作链组织成可读连续覆盖：每镜从 `预备、主攻防变化、差异化反应、可继承落幅` 中保留当前观看目的所需的阶段；同一动作弧可以一镜连贯完成，也可以由下一镜从落幅继续。源剧本已有角色化节奏、诱导/反制、关键接触或预算内英雄镜头时不得缩减成通用单击；源剧本未写时不得为满足角色专属性主动添加。也不要用更多残影、火花或晃镜掩盖动作不可读。

## 质量门

- 武器长度、左右手归属、握点和刃口方向跨镜一致。
- 攻击发生在武器优势距离内；若不在，剧情必须说明诱敌、受限或失误。
- 接触前能看见承诺路径，接触后能看见受力方向和回收窗口。
- 重量型、速度型、技巧型角色在预备、路径、反馈和恢复上明显不同。
- 装饰性招式即使不改变距离、平衡、控制权、路线或伤势，也可因人物性格、仪式感、误导、节奏、世界观或审美母题保留；只删除无因重复且挤压主动作可读性的装饰。

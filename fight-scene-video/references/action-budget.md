# 动作预算与生成稳定性

只在剧本保真矩阵、剧本锚定演绎蓝图、预算内演绎核和完整动作/VFX设计通过演绎质量门后读取。本参考只判断“如何分镜实现源剧本”，不判断“应该发生什么”；不得因复杂度分值删除、替换、改序或延迟剧本事件。

## 时长预算

| 片段时长 | 稳定内容上限 | 避免 |
|---:|---|---|
| 2-3秒 | 一个触发、一次明确反应或一个动作结果；只允许同窗的受力证据 | 完整攻防交换、复杂手型转换、大幅换位 |
| 4-6秒 | 一次决定性动作及结果；允许一条与主动作并行的VFX/环境证据链 | 独立回应动作、连续多次命中、移动中换武器、两个主运镜 |
| 7-8秒 | 同一主动作的接近、承诺、解决三段链；一条连续镜头路径 | 第二次决定性动作、多次反转、越轴覆盖、独立支线 |

把它们视为动作密度硬上限。需要延长时优先增加发力/蓄能、接触停留、力量/能量传播、反作用、恢复和环境后果，不增加微表情或更多招式。提示词不设固定字数上限，但不得因文字写得更长而突破动作密度。

## 动作、对白与结果的并行时长

先在内部为 `动作、对白、VFX第一作用、环境结果、运镜制动、稳定落幅` 标出开始与结束时间。单镜时长取全部必要时间区间的并集长度，结束点取最晚必要结果；禁止把各项时长机械相加。

- 完全并行：`T镜 = max(T动作, T对白, TVFX/结果, T运镜)`。
- 部分并行：`T镜 = 前置非重叠 + 并行段最大值 + 后置非重叠`。
- 只有对白必须在动作结束后才发生、或动作必须等待对白触发时，才累加不可重叠部分。
- 稳定落幅默认0.2-0.5秒；若角色在稳定姿态中继续说话，可与对白重叠，否则计入镜尾。

对白只统计实际说出的正文，不统计角色名、OS/OV/系统音标签和表演说明。沉静正常按3.5-4.0汉字/秒，明确急促按4.0-4.5汉字/秒，低语、迟疑或情绪停顿按2.5-3.5汉字/秒，并额外计入标点和表演停顿。动作与对白即使时长可并行，也必须检查发声、呼吸、口型与身体动作是否物理兼容。

## 信息预算优先级

单镜按：`剧本事件/台词/动作 -> 身份与动作归属 -> 接触/规避和结果 -> VFX与材质交互 -> 运镜/光影 -> 装饰性表演` 分配。只有剧本写出或唯一隐含迟疑、佯攻、疼痛时才增加表演锚点。过载先删无原文锚点的额外动作、微表情、炫技运镜和次级粒子，不能删剧本动作或结果证据。

## 复杂度计分

给单个生成片段累计分值：

| 元素 | 分值 |
|---|---:|
| 一个主要人物动作或一次明确反应 | 1 |
| 双人身体/武器接触 | 2 |
| 摔倒、腾空、翻滚或复杂手部动作 | 2 |
| 武器/道具换手、落地再拾取 | 2 |
| 主VFX或可破坏环境 | 2 |
| 移动摄影机 | 1 |
| 环绕、越轴、强遮挡或焦点交接 | 2 |
| 每增加一名活跃角色 | 2 |

`0-4分`通常可单镜尝试；`5-6分`必须优先拆覆盖或降低同时性，并写明为何仍可单镜；`7分以上`默认拆镜。分值只是风险信号，不是演绎删除指令，也不写进即梦提示词。

## 动作语法

每个节拍包含四部分：

1. `意图`：接近、护路、夺物、逼退、救人或制造出口。
2. `承诺`：一次清楚攻击、推撞、格挡、闪避、位移或环境互动。
3. `回应`：招架、躲避、吸收、反向占位、脱离或利用掩体。
4. `结果`：距离、朝向、平衡、道具、障碍或权力关系改变。

把结果作为下一节拍起点。没有改变局面的攻击通常是装饰，删除或改成有后果的反应。

## 空间原则

- 用中心地标、入口方向和动作轴线建立稳定参照。
- 给每个角色一个路线偏好：直线压迫、弧线绕侧、寻找掩体、向出口撤退或利用垂直地形。只有可见原因才能改变偏好。
- 把障碍变成选择：绕行、翻越、撞击、掩护或困住，不当作纯背景。
- 保持180度关系；越轴时展示人物转身、摄影机弧线或中性全景重置。
- 显式跟踪状态：站立 -> 扎稳 -> 失衡 -> 倒地 -> 恢复；武器抬起 -> 被挡 -> 下压 -> 脱手 -> 重新取得。

## 保真收敛

以下元素任意两项同镜出现时优先拆分覆盖或分阶段呈现：贴身接触、双方反向高速移动、小武器靠近身体、跌落、道具转移、强遮挡、镜头角度变化、可破坏物。

每次收敛先写明剧本事实，再写预算内演绎核。表中的稳定方案只示范拆分方式，不得把剧本动作替换为通用攻防；演绎核与剧本或Seedance 2.5执行预算冲突时，先保剧本，再按层级收敛E演绎项。

| 高风险需求 | 更稳定的画面方案 |
|---|---|
| 密集五连击 | 拆成2-3个连续覆盖，每镜看清一段攻防节奏，并保留第五击的决定性结果 |
| 复杂锁技或摔投 | 先拍入锁，身体转动处切镜，下一镜从落地状态开始 |
| 移动中换武器 | 切前和切后分别确认归属，把交接做成独立镜头 |
| 多人同时攻击 | 全景建立原有同时威胁，再用错峰覆盖逐一看清，但不改变既定围攻关系和反制顺序 |
| 高速旋转镜头加冲击 | 把旋转逼近与决定性命中分配到相邻覆盖，保留同一摄影母题和冲击结果 |

## 安全与语气

保持虚构和电影化。涉及真人执行时，明确动作接触、武器、跌落和可破坏道具需要合格动作团队、排练及制作现场安全控制。

# 动作预算与生成稳定性

只在创意导演蓝图、不可牺牲创意核和完整动作/VFX设计通过创意质量门后读取。本参考判断“如何分镜实现”，不判断“应该创作什么”；不得因复杂度分值删除原创机制、反转或英雄镜头。

## 时长预算

| 片段时长 | 稳定内容上限 | 避免 |
|---:|---|---|
| 2-3秒 | 一次前进/后退、一次闪避、一次攻击预备或一次明确反应 | 完整攻防交换、大幅换位 |
| 4-6秒 | 起势、一次决定性攻击或环境动作、一次回应、稳定落幅 | 连续多次命中、移动中换武器、两个主运镜 |
| 7-8秒 | 简单三段链：接近、承诺、解决；一条连续镜头路径 | 多次反转、越轴覆盖、独立支线 |

把它们视为动作密度上限。需要延长时优先增加发力/蓄能、接触停留、力量/能量传播、反作用、恢复和环境后果，不增加微表情或更多招式。

## 信息预算优先级

单镜先分配动作与视效信息：`攻防动作 -> 接触/碰撞 -> 受力/能量传播 -> VFX与材质交互 -> 运镜/光影 -> 稳定落幅`。只有迟疑、佯攻、疼痛或对白会改变攻防决策时，才增加一个表演锚点。信息过载先删微表情、装饰性小动作和次级粒子，不能删接触证据或主VFX路径。

## 复杂度计分

给单个生成片段累计分值：

| 元素 | 分值 |
|---|---:|
| 一个主要人物动作或一次明确反应 | 1 |
| 双人身体/武器接触 | 2 |
| 摔倒、腾空、翻滚或复杂手部动作 | 2 |
| 武器/道具换手、落地再拾取 | 2 |
| 主VFX或可破坏环境 | 2 |
| 移动摄影机 | 1 |
| 环绕、越轴、强遮挡或焦点交接 | 2 |
| 每增加一名活跃角色 | 2 |

`0-5分`通常可单镜尝试；`6-7分`优先拆覆盖或降低同时性；`8分以上`通常拆镜。分值只是风险信号，不是创意删除指令，也不写进即梦提示词。

## 动作语法

每个节拍包含四部分：

1. `意图`：接近、护路、夺物、逼退、救人或制造出口。
2. `承诺`：一次清楚攻击、推撞、格挡、闪避、位移或环境互动。
3. `回应`：招架、躲避、吸收、反向占位、脱离或利用掩体。
4. `结果`：距离、朝向、平衡、道具、障碍或权力关系改变。

把结果作为下一节拍起点。没有改变局面的攻击通常是装饰，删除或改成有后果的反应。

## 空间原则

- 用中心地标、入口方向和动作轴线建立稳定参照。
- 给每个角色一个路线偏好：直线压迫、弧线绕侧、寻找掩体、向出口撤退或利用垂直地形。只有可见原因才能改变偏好。
- 把障碍变成选择：绕行、翻越、撞击、掩护或困住，不当作纯背景。
- 保持180度关系；越轴时展示人物转身、摄影机弧线或中性全景重置。
- 显式跟踪状态：站立 -> 扎稳 -> 失衡 -> 倒地 -> 恢复；武器抬起 -> 被挡 -> 下压 -> 脱手 -> 重新取得。

## 保真收敛

以下元素任意两项同镜出现时优先拆分覆盖或分阶段呈现：贴身接触、双方反向高速移动、小武器靠近身体、跌落、道具转移、强遮挡、镜头角度变化、可破坏物。

每次收敛先写明不可牺牲创意核。表中的稳定方案只示范拆分方式，不得把原创动作、VFX母题、环境机关或英雄镜头替换为通用攻防。

| 高风险需求 | 更稳定的画面方案 |
|---|---|
| 密集五连击 | 拆成2-3个连续覆盖，每镜看清一段攻防节奏，并保留第五击的决定性结果 |
| 复杂锁技或摔投 | 先拍入锁，身体转动处切镜，下一镜从落地状态开始 |
| 移动中换武器 | 切前和切后分别确认归属，把交接做成独立镜头 |
| 多人同时攻击 | 全景建立原有同时威胁，再用错峰覆盖逐一看清，但不改变既定围攻关系和反制顺序 |
| 高速旋转镜头加冲击 | 把旋转逼近与决定性命中分配到相邻覆盖，保留同一摄影母题和冲击结果 |

## 安全与语气

保持虚构和电影化。涉及真人执行时，明确动作接触、武器、跌落和可破坏道具需要合格动作团队、排练及制作现场安全控制。

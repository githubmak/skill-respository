# 生成段语义预算与稳定性

只在剧本事实、导演设计和动作/VFX因果已经确定后读取。本参考判断“如何把原剧情稳定交付给模型”，不判断“剧情应该发生什么”。任何风险分值都不能授权删除、替换、改序、延迟或弱化S原文事实。

## 1. 预算对象

分别评估两层：

- `镜头预算`：观众能否看清一个视觉主事件及其摄影意图。
- `生成段预算`：模型能否在一次生成中维持人物、空间、动作因果、VFX和镜头切换的整体连续性。

镜头多不必然过载，文字长也不必然过载。真正的高风险来自：互斥姿态、多个独立控制权变化、频繁重建空间、无因换轴、多人同时复杂接触、道具归属变化、强遮挡和相互竞争的镜头命令。

## 2. 时长只作诊断

| 镜头时长 | 常见稳定用途 | 风险提示 |
|---:|---|---|
| 约2-3秒 | 建立、触发、明确反应、冲击结果或短动作切片 | 不宜同时重建空间、完成复杂攻防并换机位 |
| 约4-6秒 | 一个完整动作弧及并行VFX/环境结果 | 注意第二个独立视觉中心和互斥姿态 |
| 约7秒以上 | 连续的接近、承诺、作用、结果或平滑演化 | 必须有状态推进，不能靠重复姿态和装饰填时 |

这些区间不是硬上限。短镜可能很复杂，长镜也可能只有一次平滑演化；应按语义中心和状态转换判断，而不是看到秒数或动词数量就自动拆分。

生成段不设固定目标时长或镜头数，但Seedance单次生成硬上限为30秒，同一可投喂文件内镜头时长之和必须 `<=30秒`。平台实际测试结果仍决定是否要在30秒前提前拆段；不得把30秒当作必须填满的配额。

## 3. 信息优先级

按以下顺序分配文本注意力：

1. `A级S事实`：人物、事件、动作、顺序、因果、台词、能力规则、关键VFX和结果。
2. `B级锚点`：身份、敌我轴线、关键位置、主要运镜、关键光影和环境证据。
3. `C级补间`：模型可自然完成且不改变剧情的细碎肢体轨迹、厘米量化、重复材质、次级粒子和装饰性回收。

A级必须显式保留；B级按漂移风险保留；C级默认交给模型。S事实不属于“可压缩装饰”。

## 4. 模型自由区预算

把提示词视为关键约束而不是动作逐帧脚本。每镜最多只保留剧情实际需要的四类控制点：`起始/身份、决定性动作、关键作用、结果/下一镜入口`；不要求机械写满。

以下内容在原文未规定且不影响S唯一复述时，默认留给模型：

- 预备动作的具体幅度、重心如何移动、四肢怎样协调；
- 惯性缓冲、呼吸、衣发随动、自然运动模糊；
- 粒子的小尺度湍流、次级碎屑路径和不改变结果的材质余振；
- 同一主轨道内的细微摄影补偿与动作间自然补间。

出现以下任一情况，判定模型自由区被挤占：

- 在正文内使用多个逐秒/亚秒时间码安排动作；
- 原文未规定却连续描述关节角度、厘米位移、每一步落脚或每次转头；
- 一镜用密集顺序词串联多个N/E微动作；
- 为了“完整”同时规定人物、VFX、环境和摄影的每个中间态。

修复时先删除N/E微步骤，改写为 `动作性质 + 力量方向 + 关键作用 + 结果边界`。若剩余S控制点仍无法在自然速度下完成，增加时长或拆镜/拆生成段，不能继续压缩。

## 5. 风险计分

对单镜或整个生成段累计风险信号：

| 元素 | 风险分 |
|---|---:|
| 一个独立视觉主事件 | 1 |
| 双人贴身身体/武器接触 | 2 |
| 腾空、摔落、翻滚或复杂手部转换 | 2 |
| 道具换手、脱手、拾取或归属变化 | 2 |
| 主VFX与可破坏环境同时作用 | 2 |
| 一次明确机位/镜头轨道变化 | 1 |
| 环绕、越轴、强遮挡或焦点交接 | 2 |
| 每增加一名同时执行复杂动作的角色 | 2 |
| 需要重新建立地点、身份或空间轴线 | 3 |

分值只触发人工审片：

- `0-4`：通常可直接尝试。
- `5-6`：检查是否能聚合同一动作弧、减少C信息或简化摄影。
- `7及以上`：高风险警告；检查独立视觉中心、状态跳变与模型测试结果，再决定拆镜或拆生成段。

不得把分数写进最终提示词，也不得把“7分以上”当作强制拆镜规则。

## 6. 收敛顺序

过载时依次执行：

1. 删除无原文锚点、无剧情证明作用的E装饰。
2. 合并或简写不改变S的N补间。
3. 删除重复状态、同义复述、无执行价值审美词和伪精确量化。
4. 合并同一目标、轴线、控制权和结果下的微动作。
5. 简化非剧情关键运镜、次级粒子和次级环境反应。
6. 仍有多个独立视觉中心时按原顺序拆镜。
7. 整体仍无法在一次生成中兑现全部S时，在自然因果接缝处拆生成段。

每次收敛都先写明不可变S事实。任何步骤都不能删改S；原剧情疑似有误时停止静默处理，明确指出并请用户确认。

## 7. 拆镜与拆生成段

优先拆镜的情况：

- 同一时间窗里出现两个竞争的视觉中心。
- 必须看清不同执行者的独立决策或控制权变化。
- 姿态、景别或观察方向互斥，连续演化会导致主体融化或动作不可读。
- 接触、规避、道具归属或结果在当前构图中无法证明。

优先拆生成段的情况：

- 场景、时间或主身份锚点发生重置。
- 需要重新建立空间轴线，且无法通过一个明确过渡镜完成。
- 多轮控制权变化、对白和大型VFX使整段即使删除E、压缩N、聚合微动作后仍无法完整兑现A级事实。
- 实际测试表明模型在该语义负载下持续丢失剧情事件或角色连续性。
- 同一文件镜头时长之和超过30秒，或只有牺牲S动作自然演化时间才能压到30秒以内。

拆分只改变交付边界，不改变原剧情内容和顺序。

## 8. 并行时长

为动作、对白、VFX第一作用、必要环境结果、运镜和切点标记时间区间。镜头时长取这些必要区间的并集：

- 完全并行：`T镜 = max(T动作, T对白, TVFX/结果, T运镜)`。
- 部分并行：`T镜 = 前置非重叠 + 并行段最大值 + 后置非重叠`。
- 只累加物理上确实不能重叠的部分。

对白按人物状态估算自然语速并计入停顿；即使时间可重叠，仍需检查发声、呼吸、口型和受力动作是否兼容。说不完时优先延时或在自然语义点拆镜，不得删改、快读或重写原台词。

最后计算 `T段 = ΣT镜`。超过30秒必须拆生成段；未超过30秒仍需通过语义负载和模型自由区审核。

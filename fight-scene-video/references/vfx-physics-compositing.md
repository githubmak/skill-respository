# VFX物理、光照与合成规则

只在剧本锚定演绎蓝图已经确定预算内VFX视觉母题、行为规律、显化阶段和英雄镜头后读取。本参考负责物理、光照与合成翻译，不能从常见特效语法表反向选择演绎，也不能把预算内独有母题降级为泛用光束、护盾或爆炸。

## 特效分层

### 主体突出不降级

突出人物时，先锁人物的第一读点、身份完整度、锐度和局部对比，再让VFX占据人物身后、下方、边缘、前后景纵深或环境表面。不要用缩小术法、删除粒子、取消环境作用或把主特效改成低幅泛光来换人物清楚。

每个高能镜头必须在局部正文中写出可见VFX链：`前镜前态/残留 -> 本镜源点或触发 -> 主体形态与厚度 -> 传播方向/速度/占区 -> 第一作用或碰撞 -> 材质/粒子/光照后果 -> 本镜残留/下镜入口`。全局母题与色板不能代替这条链。

修改已有镜头时，比较以下六项：`主机制、尺度占区、环境反应、粒子动力、光权、残留`。人物层级可以增强，六项功能覆盖不得无因减少；单镜无法同时承载时，拆分相邻覆盖，并让来源、展开、作用和余波合计完整。

每个主特效最多使用五层，并明确各层寿命：

1. `源点层`：手、武器、法器、阵眼或环境裂口，负责说明从哪里来。
2. `主体层`：光束、火焰体、剑气、护盾面、召唤物躯体，负责主要形状与路径。
3. `边缘层`：电弧、火舌、折射、轮廓辉光、碎屑，用来解释能量边界。
4. `交互层`：地面裂纹、金属反光、水汽、扬尘、衣物受风、人体受力。
5. `残留层`：焦痕、余烬、雾、电荷、裂纹、冻结、符文暗淡、空间涟漪。

低风险镜头使用源点+主体+交互；高潮镜头再增加边缘和残留。禁止五层同时覆盖人物脸、手和接触点。

每镜先选一个主视觉节拍：显化、加速、碰撞、破盾、扩散或消散。让形状、密度、速度和亮度围绕该节拍变化；其余层只负责证明空间、力量与材质，不争抢视觉中心。

## 光照与曝光

- 自发光特效必须照亮邻近人物、武器和环境；染色强度随距离衰减，不能只在空中发亮。
- 强光靠近脸时保留五官和眼神，使用轮廓染色、局部高光和受控曝光，不让皮肤整片过曝。
- 光束、火球、阵法经过墙、柱、人体或烟尘后必须产生合理遮挡；被遮住的部分不能透视显示。
- 不透明物体产生方向一致的投影或遮光区；半透明法相产生较软的彩色阴影、散射或折射，不使用实体黑影。
- 金属出现锐利高光和色彩反射；湿地、水面和玻璃出现拉长反光；粗糙石木只保留宽而弱的染色。
- 烟、雾、尘中出现体积光路和浓淡变化；清洁空气中不要无缘由显示整条实体光柱。
- 爆发瞬间允许短暂亮度抬升，但下一节拍必须恢复环境曝光，并保留亮后残像、眯眼或暗部回归。

颜色只设一个主色和一个受控辅色。升级通过亮度、密度、频率、结构完整度或范围表达，不随意换成彩虹色。

## 材质交互

| 材质 | 主要反应 | 残留 | 避免 |
|---|---|---|---|
| 石/混凝土 | 崩角、裂纹、粉尘、碎块受力飞散 | 裂缝、粉尘、焦化或冻结边缘 | 整块无重量漂浮、命中后瞬间复原 |
| 木/竹 | 弯曲、劈裂、纤维飞散、燃烧或结霜 | 断口、木屑、余火、水汽 | 像玻璃整齐爆碎、断口消失 |
| 金属 | 火花、凹陷、振动、导电、热变色 | 划痕、熔痕、余电 | 大量石尘、无声无反作用力 |
| 水/湿地 | 波纹、凹陷、水柱、蒸汽、冻结、导电 | 水雾、涟漪、冰层裂纹 | 水体凭空减少、飞溅方向与受力相反 |
| 冰/雪 | 放射裂纹、冰屑、压实、融化或再冻结 | 裂面反光、雾气、雪尘 | 无材质差异地变成普通石块 |
| 布料/发丝 | 被气流、热浪、静电或冲击推向一致方向 | 烧焦边、霜、静电回落 | 与能量方向相反、穿身或无限飘动 |
| 玻璃/晶体 | 裂纹传播、折射、碎片、彩色焦散 | 裂面、碎片落地 | 碎片停在空中无原因、反射方向混乱 |
| 土壤/沙尘 | 压坑、喷溅、尘墙、被风切开 | 沟槽、尘雾、脚印被覆盖 | 所有颗粒等速向四周均匀爆开 |
| 护甲/护盾 | 局部受压、裂纹、能量沿表面分流 | 裂纹持续、局部暗淡、碎片或余电 | 整面同时闪烁、背面无规则爆炸 |

同一命中最多突出两种材质反应，优先选择能证明力量方向和战术结果的材质。

## VFX行为校验例

以下类型只用于检查已定预算内母题是否可读，不能从表中选择成品概念。生成困难时先保留源剧本VFX事实，再保留执行预算内的独有行为、剧本已有反转、环境后果和英雄镜头，通过拆阶段或换覆盖解决。

| 类型示例 | 可读链条 | 镜头关键 | 保真适配方式 |
|---|---|---|---|
| 光束/剑气 | 源点收束 -> 方向承诺 -> 延展 -> 命中/擦过 -> 路径残留 | 中远景保留源点到落点；近景只拍收束或接触 | 把源点、独有飞行行为和碰撞后果分到相邻覆盖，保持同一路径逻辑 |
| 护盾 | 生成边界 -> 正面承压 -> 局部凹陷/裂纹 -> 分流或破裂 -> 余片消散 | 三分之四角看见攻击线与盾面夹角 | 分拍展示成形、承压与既定破裂机制，保持盾面反应与攻击夹角 |
| 火焰/爆炸 | 点火源 -> 膨胀 -> 压力波领先 -> 火焰/碎屑随后 -> 烟尘和热浪 | 先见触发，再见压力和材料后果 | 用触发近景、冲击覆盖和后果远景承载完整事件，保留独有爆破形态与地形改变 |
| 雷电 | 电荷积聚 -> 寻路分支 -> 主通道击穿 -> 沿导体传播 -> 余电跳跃 | 显示导体或最近路径；避免随机满屏树枝 | 分开积聚、寻路和击穿阶段，保留剧本允许的捕猎/分支规律与导体反馈 |
| 冰冻 | 冷源/雾 -> 表面结晶前沿推进 -> 结构变脆 -> 开裂/限制移动 | 显示冻结从接触点扩散，不瞬间全场变冰 | 用局部覆盖证明起点和传播，再用宽景展示既定范围、限制方式与裂解结果 |
| 冲击波 | 爆心/动作触发 -> 空气边界扩张 -> 衣物/尘土先受力 -> 人物/物体位移 -> 尘环残留 | 远景看范围，近景看受力证据 | 将触发、传播和位移后果拆开，保持剧本锚定波形、方向与控制权变化 |
| 阵法/结界 | 节点点亮 -> 连线闭合 -> 边界成形 -> 作用生效 -> 节点受损/熄灭 | 俯视看结构，地面角度看边界高度和遮挡 | 分阶段点亮节点并切换俯视/地面覆盖，保留几何规则、出口和反转节点 |
| 传送/空间裂隙 | 锚点扭曲 -> 边界撕开 -> 前后空间可见 -> 对象穿越 -> 边缘闭合 | 明确入口出口对应方向和尺度 | 分镜建立入口、出口与穿越过程，保持两端方向、尺度和预算内边缘行为 |
| 幻术/神魂 | 现实锚点异常 -> 感知替换 -> 人物反应 -> 现实威胁介入 -> 识破/破碎 | 保留一个现实道具或动作作为双层锚点 | 用匹配构图分开现实、替换和识破，保留误导机制、现实锚点与既定反转 |
| 召唤物/法相 | 来源显化 -> 骨架/轮廓成形 -> 结构稳定 -> 与本体/目标互动 -> 维持或消散 | 近景稳定本体，远景展示完整结构与尺度 | 拆分来源、完整显化和攻击覆盖，保留独有结构、尺度、环境压迫与代价 |

## 景别适配

- 特写：只展示源点、表面反应或局部残留；不要塞入完整巨物。
- 中近景：保护脸、手势、武器和附着点，辉光控制在轮廓外侧。
- 中远景：展示完整发射路径、攻防几何和双方反应。
- 全景/鸟瞰：展示范围、阵型、地形改变和安全区，不追求手指细节。
- 高速FPV：主体层必须简化，边缘粒子沿运动方向拖曳，不能遮掉避障物。

## 复杂度预算

| 等级 | 单镜允许 | 适用 |
|---|---|---|
| L1 | 一个源点、一个主体形状、一种材质反应 | 近景触发、普通攻防 |
| L2 | 一个主特效、一个次残留、两种材质反馈 | 决定性命中、中型技能 |
| L3 | 主特效、完整环境压迫、召唤/巨物、持续残留 | 高潮远景；本体复杂动作必须拆开 |

出现两名角色复杂接触、移动摄影机、透明巨物、全场破坏中的任意三项时，禁止L3同镜，先拆镜或固定摄影机。

## 质量门

- 源点、路径、遮挡、落点和残留在空间上连续。
- 自发光对人物、环境、烟尘和反射材质产生方向一致的影响。
- 特效没有遮住身份、手势、武器接触、受力反应和最终位置。
- 特效规模与战术后果、能量代价、环境破坏相匹配。
- 下一镜继承曝光恢复、残留材质、冷却、裂纹和召唤物状态。
- 发现光污染时先减少层级、辅色和屏幕覆盖率，不只是降低亮度形容词。

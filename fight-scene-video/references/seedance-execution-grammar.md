# Seedance生成段动作因果与固定分镜语法

本参考只在源剧本逐项锁定、剧本保真矩阵通过后读取。它负责把已经确定的剧情和导演设计编译成Seedance 2.5/即梦容易执行的一次生成文本，不负责改剧情、换动作、补反转或缩小源剧本规定的特效。

## 1. 三层权限与保真分级

- `剧情真值层`：锁定人物、事件、动作、顺序、因果、台词、肢体/道具/能力、对象、力度、能力规则与结果，零改写自由度。
- `导演演绎层`：只补足让原动作可见的发力、反作用、连接、材质、环境、VFX、光影、声音和摄影；删除后不得改变剧情。
- `Seedance执行层`：只决定如何聚合、压缩、拆镜、拆生成段和改写为可见时序，不得删除、替换、改序或弱化剧情真值。

交付信息分为：

- `S原文事实`：原剧本明确内容，必须100%覆盖并保持原顺序。
- `N必要补足`：让S成为可见动作所必需、且能由上下文唯一推出的状态。
- `E演绎增强`：强化S的VFX、环境、运镜、声音和不改变局面的连接动作。

提示词再按执行必要度分层：

- `A级`：S原文事实，包括人物、原动作、顺序、因果、台词、能力规则、关键VFX与结果，必须显式写出。
- `B级`：身份、空间方向、主运镜、关键光影与环境证据，按漂移风险保留。
- `C级`：非剧情关键的左右手脚细分、厘米距离、粒子参数、重复状态与装饰性回收，默认交给模型补间或从正文删除。

A级与S不是可删减预算。原剧情疑似存在冲突、遗漏或事实错误时，只标记冲突并向用户确认，不静默修正。

## 2. 生成段与镜头

### 生成段

`生成段`是一次提交给模型的完整生成单位。默认把满足以下条件的连续镜头聚合进同一生成段：

1. 同一地点、时间和人物身份锚点。
2. 空间轴线可以连续追踪。
3. 动作因果相连，后一个节拍以之前的可见结果为起点。
4. 不需要模型凭空重建角色、场景或能力规则。
5. 全段能按原剧情顺序兑现全部A级事实。

生成段没有固定目标秒数或固定镜头数，但Seedance单次生成存在30秒硬上限：同一可投喂文件内所有镜头标称时长之和必须 `<=30秒`。10秒、20秒等只是可选项目参数，30秒也不是必须填满的目标。剧情节拍可长于30秒；此时保持同一P事件和原顺序，在清楚的阶段性状态或自然因果接缝拆成相邻生成段。

### 镜头

`镜头`是生成段内部的主要视觉语义节拍，也是固定模板中的基本块。每镜保留：

- 一个清楚的视觉主事件或同一结果下的完整动作弧；
- 一个主要观看目的，摄影路径可简单或复合；
- 一项明确的新信息、威胁、空间变化、控制权变化或结果。

同一原动作内部的预备、发力、路径、接触/规避、反作用和结果可以形成一条完整动作弧，不因出现多个动词就机械拆镜。只有出现新的视觉中心、互斥姿态、独立控制权变化、必须改变观察轴线，或当前动作已经无法看清时才拆镜。

判断口诀：`看不清就拆镜，整段装不下才拆生成段。`

## 3. 段内连续状态

- 生成段第一镜完整建立地点、人物身份、敌我位置、朝向/高度、关键道具、活跃能力、环境状态和主光。
- 后续镜只写当前可见状态和新增变化，重述发生变化、剧情必需或存在漂移风险的锚点。
- 禁止只写 `继承镜XX、上一镜、同上、沿用` 等空指代；允许写 `半脸傩纹已经成型的宋棠仍悬在巷心上空` 这类具体增量状态。
- 不机械重复全套服装、场景、粒子、光照、双手双脚和人物简介。重复文本会稀释新的动作指令。
- 镜头切换不等于时间重置。后镜必须从前镜已经可见的结果继续，除非源剧本明确发生跳时、转场或空间重置。

## 4. 动作归属与时序

每个S核心动作必须唯一回答：

`谁 -> 用原文规定的肢体/道具/能力 -> 对谁或何物 -> 做什么 -> 关键路径 -> 接触或明确规避 -> 产生什么结果。`

执行规则：

- 多角色同镜时，在关键动词前重复角色名；代词可能换主语时不用代词。
- 原文规定左右肢体、手型、次数、方向、速度或突然性时必须保留；原文未规定且不影响剧情时，不为追求精确强行量化。
- 同一动作弧按 `起幅 -> 承诺 -> 过程 -> 结果` 排列，只保留理解因果所需的中间态。
- “瞬间、骤然、只一次、同时”是剧情规则，不能被E演绎改成缓慢、逐渐、分批或再次。
- 新增动作只能是预备、发力证明、原动作内部连接或回收。若会形成新攻击、躲避、反制、伤势、能力、决策或控制权变化，就越过了交付层权限。

## 5. 模型演绎空间

最终提示词控制剧情边界，不承担逐帧动画。每镜可用以下类别检查 `最少充分控制点`：

1. `起始/身份`：谁在什么关键状态与空间关系中。
2. `决定性动作`：原文规定谁对谁做什么。
3. `关键作用`：必须看清的接触、规避、能力第一作用或状态转移。
4. `结果/入口`：原文规定的结果或下一镜可见入口。

这四类不是固定四段式、字段模板或数量上限；并非每镜都要写满，也允许原文明确规定的更多控制点。只写S原文规定或防止误读必需的内容。控制点之间的自然预备、重心转移、四肢协调、惯性、呼吸、衣发随动、运动模糊、粒子湍流、次级材质响应和镜头连续补间属于 `模型自由区`。

- 对模型自由区只规定运动性质、力量方向、速度体感和不可越过的结果边界，不规定每一步怎样完成。
- 禁止把原文未规定的N/E补间写成逐秒或亚秒时间码、逐关节姿态、连续厘米位移、逐步落脚和密集的“先—再—随后—立即”动作清单。
- 原文明确规定的多步动作仍是S，必须逐项保留；若现有时长不足，增加时长或拆镜/拆生成段，不得省略或交给模型自由改写。
- 若删去所有N/E微动作后，仍能按原顺序还原S动作、关键作用和结果，说明自由区保留正确；若删去后S也不清楚，则补回必要控制点。

## 6. 运镜与切镜因果

每镜标题中的运镜和机位写成可执行的主要摄影意图：

`观察对象 + 机位/角度 + 动作触发 + 主轨道或固定方式 + 揭示信息 + 切镜/制动点。`

- 镜头可以硬切、匹配切、动作切或遮挡切；切点必须由动作、视线、冲击、遮挡或信息揭示触发。
- 高速闪避优先固定机位、短跟移或动作后的轻震，让原攻击线与人物新位置可比较。
- 术法从局部扩到环境级时先锁源点，再用后续镜头拉开尺度。
- 一个镜头保持一个主要观看目的；摄影机可使用单一路径或物理连续、不会争抢主动作的复合路径。一个生成段可以包含多个因果相连的镜头和不同机位。
- 中间镜头可以结束在运动入口、威胁逼近或动作承诺上；决定性控制权变化和生成段末尾必须留下可读结果。不得强迫每镜都停成静态落幅。

## 7. VFX、光影与声音

主VFX按剧情需要从以下链条中选择必要项：

`源点 -> 动作触发 -> 结构变化 -> 传播/第一作用 -> 环境证据 -> 光权变化 -> 停止或残留。`

- 不机械写满每一环；只保留证明原动作、空间尺度和结果所需的环节。
- 生成段内的VFX是连续状态。后镜只写它的新形态、传播或作用，不重复全部起源说明。
- 粒子用于证明力量方向、速度、材质和尺度，不用无关粒子名堆砌画面。
- 光线描述不能自动生成光源实体；只有源剧本或已锁定场景明确要求时，才让月盘、太阳、灯具或火源入画。
- 声音跟随动作起动、接触/规避、材质反应和余波；台词逐字保留，不因节奏压缩或改写。

## 8. 语义负载与收敛顺序

时长、动作数量和顺序连接词只用于风险诊断，不作为自动删剧情或机械拆镜的硬阈值。发生过载时严格按下列顺序处理：

1. 移除无原文锚点、无剧情证明作用的E装饰。
2. 合并或简写不改变S的N补间。
3. 删除重复状态、同义复述、无执行价值的审美标签和伪精确量化。
4. 把同一目标、轴线、控制权和结果下的微动作合并为一个完整动作弧。
5. 简化非剧情关键的运镜、粒子和次级环境反应。
6. 若仍有多个独立视觉中心，按原顺序拆镜。
7. 若整个生成段仍无法完整兑现全部S事实，才在自然因果接缝处拆成相邻生成段。

任何步骤都不得删除、替换、改序、延迟、弱化或泛化S原文事实。拆生成段时，后一段首镜完整重建必要锚点，但不得重复或改写前一段已经完成的剧情事件。

## 9. 时长合同

为每镜标记动作、对白、VFX第一作用、必要环境结果、运镜和切点的时间区间。镜头时长取必要区间的并集，不机械相加：

- 完全并行：`T镜 = max(T动作, T对白, TVFX/结果, T运镜)`。
- 部分并行：只累加确实不能重叠的前置和后置部分。
- 中间镜的切点只需让动作意图和状态转移可读；决定性结果或段末结果按正常观看速度保留足够可读窗口，不设统一0.2-0.5秒模板。

再计算 `T段 = ΣT镜`。`T段 > 30秒` 为阻断错误，必须在自然因果接缝拆生成段；`T段 <=30秒` 只代表通过平台时长门，不代表语义负载一定稳定。不得为压进30秒缩短S动作的自然可读时间。

对白只统计实际说出的正文，不统计人物名、OS/OV/系统音标签和表演说明。优先使用实测配音；没有音频时按人物、句法、力度、标点、换气和表演停顿估算，常见字符速度仅作容量提示。对白与动作可并行，但发声、呼吸、口型和身体受力必须物理兼容。

## 10. 八道交付阻断门

1. `剧本覆盖与顺序门`：S覆盖率100%，对白逐字保留，六类差分 `漏、改、增、序、力度冲突、台词变更` 清零。
2. `剧本动作逐项保真门`：去掉E后仍能还原原文动作、力度、方向、能力规则和结果。
3. `时间力度修饰冲突门`：E不得反向软化或扩大原文的速度、突然性、同步性、次数、声音与环境力度。
4. `动作归属与肢体转换门`：每个核心动词的执行者、能力/肢体和对象唯一明确。
5. `生成段连续状态门`：段首锚点完整，后续状态增量明确，切镜前后不存在身份、空间、道具、伤态和VFX跳变。
6. `语义负载与结果兑现门`：全段不超过30秒；微动作已经聚合；提示词只锁最少充分控制点并保留模型自由区；每个独立视觉中心可读；所有S结果按原顺序兑现。
7. `运镜叙事因果门`：每镜保持一个主要观看目的，摄影路径可简单或复合；切换由动作或信息触发，不干扰动作阅读。
8. `Seedance段级反向复述门`：仅凭同一生成段的连续镜头，能按原顺序唯一还原全部A级S事实和最终控制权结果。

## 11. 固定字段内部排序

- `镜头标题`：镜号 -> 景别 -> 主要运镜与机位/角度 -> 时长。
- `画面内容`：段首完整锚点或本镜必要增量状态 -> 视觉主事件 -> S动作归属/对象 -> 接触或规避 -> 下一镜入口或明确结果。
- `特效`：本镜实际承担的源点、形态变化、传播/第一作用、必要环境反应、停止/残留。
- `光影`：环境主光 -> VFX染色/遮挡/反射 -> 本镜光权变化。
- `音效`：环境底噪 -> 动作起动 -> 接触/规避 -> 声音桥或余波。
- `台词`：逐字保留原文和身份标记；无内容写 `无`。

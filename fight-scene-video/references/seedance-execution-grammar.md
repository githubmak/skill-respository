# Seedance动作因果与独立镜头语法

本参考只在源剧本逐项锁定、剧本保真矩阵通过后读取。它负责把剧本和受约束的导演设计翻译成Seedance 2.5/即梦容易执行的时间顺序文字，不负责改剧情、换动作、补反转或缩小特效。

## 1. 三层权限

### 剧情真值层：低自由度

逐事件锁定：`原文位置/原句 -> 人物意图 -> 触发原因 -> 动作执行者 -> 肢体/道具/能力 -> 起点 -> 路径 -> 作用对象 -> 接触/规避 -> 结果 -> 控制权与稳定落幅`。

严禁推断或替换：执行者、左右肢体、手型、持物、动作顺序、方向、高度、目标、敌方数量、命中或躲开、能力规则、台词、胜负与结局。

### 导演演绎层：高自由度

允许推断：表演轻重、微表情、原动作内部的预备/发力/回收、材质反馈、环境参与、VFX外观、粒子运动、光权、声音、镜头缓急和剪辑覆盖。所有推断必须拥有原文锚点并证明剧情真值，不得与真值竞争；删除新增内容后，剧情、战力、人物决策、空间结果与动作顺序必须完全不变。

### Seedance执行层：翻译自由度

只把已锁定事实改写成可见、按时序、无歧义、自足的自然语言。删去平台看不见的抽象意图，把它转换为眼神、身体重心、路径、接触和结果证据。复杂度过高时拆成连续覆盖，不用平台适配为理由改变剧本。

### 剧本保真分级

- `S原文事实`：原剧本明确内容，零改写自由度，必须100%覆盖并保持顺序。
- `N必要补足`：让S成为可见动作所必需、且能由上下文唯一推出的状态，如起始重心、发力反作用和镜尾回收。
- `E演绎增强`：特效、粒子、运镜、环境证明、声音和不改变局面的连接动作。E必须指向一个S事件，删除E后剧情完全不变。
- 存在多个合理解释、会产生新攻击/躲避/反制/能力/伤势/决策/控制权的内容，不属于N或E；未经用户授权不得添加。

### 双向原剧本资格审计

生成前完成正向审计：每条S原文事实必须绑定具体镜号并保持原顺序、动作归属、肢体、方向、力度、台词、能力规则与结果。生成后完成反向审计：最终每个动作、能力、台词和结果必须能指回S、N或合法E。差分只使用 `漏、改、增、序、力度冲突、台词变更` 六类；任一差分未清零，成品不具备交付资格，不进入演绎评分。

## 2. 单镜叙事目标

每镜先写一句不进入成品的目标：`镜尾观众必须明白______。`

逐句验收：若一句画面、动作、特效、光影、音效或运镜既不建立目标，也不制造目标所需阻力，更不证明结果，就删除、合并或移到其他镜头。

整场张弛曲线必须从剧本已有事件中提取。剧本若本来具备压迫、拆解、升级、清场与余波，可用景别、速度、声音、粒子密度和光权强化层次；不得为凑曲线添加原剧本没有的受伤、受限、失败、反制、规则变化或战力反转。

每镜至少改变一项：信息、速度、轴线、高度、可通行区、控制权或不可逆状态。相邻镜若六项都不变，合并或重构。

## 3. 动作归属语法

每个核心动作写全：

`谁 -> 用哪只手/脚/身体部位/道具/能力 -> 从何位置起动 -> 沿何方向和路径 -> 对谁或何物做什么 -> 接触或明确规避 -> 反作用与回收 -> 停在何处。`

规则：

- 多角色同镜时，核心动词前重复角色名；只要“她/它/其”可能换主语，就不用代词。
- 写“宋棠右手食指与中指并拢横切”，不要只写“并指横切”；写清横切起点、终点、掌心朝向和左手状态。
- 手型或持物改变时先写释放转换：`宋棠松开十指交叠，左手收回胸前，右手食指与中指并拢`。一个手型不能无过渡同时承担另一手型。
- 躲避写最短有效链：威胁到达 -> 单次发力 -> 身体离开攻击线 -> 攻击从原位置掠过或相撞 -> 干净制动。禁止无意义旋转、连续翻滚、空中摆拍和重复闪避。
- “瞬间、骤然、只轻点一次”是动作规则，不是气氛词；必须通过短前摇、单一发力和明确结果兑现。
- 额外动作只允许四类：`预备`、`发力证明`、`原动作内部连接`、`回收/稳定`。若新增动作能单独改变攻防、距离结论、能力信息、人物决策或控制权，删除或请求授权。

## 4. 动作起伏与负载

单镜主动作采用四拍：`起幅 -> 承诺 -> 过程 -> 结果`。

- 起幅：交代可见起始状态和力量来源。
- 承诺：角色做出不可收回的决定性动作。
- 过程：只保留理解路径、接触或规避所需的中间态。
- 结果：人物、敌方、VFX和环境落到唯一可读状态，并保留约0.2-0.5秒制动窗口。

2-3秒最多一个核心身体动作；4-6秒最多一个决定性动作与一条并行后果；更长镜头必须有明确的接近、承诺、解决三段变化。超载时拆成起因覆盖、动作覆盖、结果覆盖，不删除结果或特效链。

## 5. 独立起始状态

每镜不得自动继承，必须按需要重述：

1. 地点、时段和当前环境破坏/遮挡/主光。
2. 主角在画面和场景中的位置、朝向、重心、高度、双手/双脚、持物与服装识别锚点。
3. 对手数量、位置、朝向、距离和正在进行的威胁动作。
4. 当前仍活跃的术法结构、粒子、烟雾、碎屑、光权或残留。
5. 本镜动作结束后的唯一稳定状态。

只重述影响当前动作生成的必要事实，不复制整份设定。禁用：`继承镜XX、镜XX状态、前镜、上一镜、下一镜、同上、沿用、继续上一镜、保持此前状态`。

## 6. 运镜因果语法

每镜主运镜写成：

`绑定对象 -> 由哪个动作触发启动 -> 沿一个主轨道运动 -> 揭示哪项新信息 -> 在何结果上制动 -> 为下一动作留下什么画面空间。`

- 动作路径尚未读清时，摄影机不越过路径、不抢先环绕、不追装饰粒子。
- 高速躲避优先固定机位、短距离同向跟移或动作后轻微震动，让“原攻击线”和“人物新位置”同屏可比。
- 术法从局部扩到环境级时，先锁源点，再拉开尺度；冲击或秒杀证据出现时停止继续推拉。
- 运镜必须揭示来源、路径、接触/规避、控制权或结果之一；否则固定机位通常更有效。
- 镜尾构图要给下一动作的来向、人物移动方向或视线方向留出空间，但最终提示词仍需独立重述下一镜起始状态。

## 7. VFX与粒子执行链

每个主VFX按：`可见源点 -> 动作触发 -> 主体结构 -> 传播方向 -> 第一作用 -> 核心粒子 -> 环境反应 -> 光权变化 -> 停止/残留`。

普通高能镜使用一个主奇观、一个核心粒子系统和一至两条环境反应；高潮可扩大空间层级，但不得让粒子遮掉人物动作或命中证据。

粒子至少写清：来源、粒径或密度梯度、速度/加速度、前中后景视差、流动方式、停止或回收条件。粒子要证明力量方向和尺度，不只负责“炫”。

不要反复写“低亮、少粒子、无爆炸、不要抢主体”等负向约束来削弱特效。人物主体通过锐度、局部对比、构图位置、运动制动和光照优先级成为第一读点；VFX仍可占领更大空间。

“最大可能发挥”采用不改剧情的扩展顺序：先强化原动作的力量来源和路径，再强化接触/规避证据，再扩展空间占区和尺度参照，再增加环境与光权后果，最后增加粒子细节与声音。任何层若开始遮挡、延迟或改变原动作，就退回上一层；宏大不等于让VFX成为新的剧情施力者。

光线描述不能自动生成光源实体。原文写“月光从身后穿过”时，只能推出背后冷白照射、轮廓光和投影方向，不能推出完整月盘位于人物头后；同理，日光、灯光与火光不自动产生太阳、灯具或巨大火源入画。只有源剧本或已锁定场景事实明确要求可见物体时才写入，并确保它不取代人物与剧本动作的第一读点。

## 8. Seedance 2.5执行合同

- 每镜只保留一个剧情核心动作和一个主运镜；并行VFX与环境反应在同一动作窗口内证明核心动作。
- 按真实时间顺序写起始状态、触发、过程、接触/规避、反作用和稳定结果，不把动作拆成互相矛盾的同时指令。
- 明确角色身份锚点、位置、朝向、高度、肢体、目标和空间关系；每镜独立自足，但与内部连续性台账一致。
- 摄影机用可执行的单一轨道、速度变化和制动点；复杂动作时简化摄影机，复杂摄影时简化同屏身体动作，不简化剧本事件。
- 使用可见事实和可验证结果，不用“震撼、电影感、实力碾压、情绪拉满”等抽象词替代动作证据。
- 镜尾必须有稳定可读结果；角色、道具、怪物、VFX和环境残留的终态只有一种解释。
- 无法在既定时长内完成时拆镜或合理延时；对白按自然语速分配，不快读，不让粒子展示挤占剧本动作与台词。提示词不设固定字数上限，但字数不能扩张动作预算；可精简重复措辞，不得压缩生成所需画面事实。

### 并行时长合同

内部为动作、对白、VFX第一作用、环境结果、运镜制动和稳定落幅分别标记时间区间。镜头时长取这些必要区间的并集，并以最晚必要结果作为结束点，禁止机械相加。完全并行时使用 `max(T动作, T对白, TVFX/结果, T运镜)`；部分并行时只累加前后不可重叠部分。稳定落幅0.2-0.5秒可在稳定姿态对白中重叠，否则计入镜尾。

对白只统计实际说出的正文，不统计角色名、OS/OV/系统音标签和表演说明；沉静正常按3.5-4.0汉字/秒，明确急促按4.0-4.5汉字/秒，低语、迟疑或情绪停顿按2.5-3.5汉字/秒，并计入标点与表演停顿。时长可并行不代表表演必然兼容；发声、呼吸、口型和身体受力冲突时必须错开或拆镜。

## 9. 八道交付阻断门

1. `剧本覆盖与顺序门`：执行双向原剧本资格审计；S事实覆盖率100%，对白逐字保留，镜头顺序与原文一致，六类差分全部清零。
2. `剧本动作逐项保真门`：去掉所有E内容后，仍能还原剧本动词、力度、顺序、方向和结果。
3. `时间力度修饰冲突门`：逐字段对照原文速度、突然性、同步性、次数、声音和环境力度；E演绎不得用“缓慢、逐渐、由慢到快、分批、再次、轰鸣、扬尘”等词反向软化或扩大原动作。
4. `动作归属与肢体转换门`：每个核心动词只有一个执行者、一个目标；手脚与持物变化存在可见过渡。
5. `单镜独立状态门`：只看本镜也能建立必要起始状态，不出现跨镜替代语。
6. `动作负载与稳定结果门`：时长按并行时间轴关键路径容纳动作四拍、对白和必要结果，镜尾存在唯一结果和制动窗口。
7. `运镜叙事因果门`：运镜有绑定、触发、轨道、揭示和制动，不干扰动作阅读。
8. `Seedance反向复述门`：仅凭成品文字，审片者能唯一回答谁、在哪里、哪只肢体/何种能力、沿何路径、对谁、是否接触或躲开、结束在哪里、谁控制局面；存在第二种合理答案即失败。

## 10. 固定字段内部排序

- `画面内容`：必要独立起始状态 -> 主体第一读点 -> 主动作执行者/肢体/路径 -> 接触或规避 -> 反作用 -> 稳定结果。
- `特效`：可见源点 -> 动作触发 -> 主体结构 -> 传播/第一作用 -> 粒子与环境反应 -> 停止或残留。
- `光影`：环境主光 -> VFX染色/遮挡/反射 -> 光权变化 -> 镜尾曝光。
- `音效`：环境底噪 -> 动作起动 -> 接触/规避 -> 余波；需要时用短静音放大冲击。
- `台词`：保留原文与身份标记，按角色状态计算实际对白正文和停顿；与动作可并行但不机械相加，物理冲突时错开；对白说不完就拆镜或延时，不快读。

# 动态合并与空间稳定协议

只在剧情真值层、动作骨架和导演演绎蓝图完成后读取。本参考是后置审查协议，不是创意生成器；它不规定镜头答案，只验证一个答案是否能稳定兑现已锁定事实。

## 1. 三份动态账本

对每个源剧情事件建立三份内部账本。账本只用于审计，不进入最终可复制提示词。

### 剧情账本（S）

逐项记录：原文证据、执行者、肢体/道具/能力、起点、路径、作用对象、接触/规避、时间与力度、结果、控制权变化、对白/系统音和段末状态。S项只能原样保留、拆分覆盖或换证明角度，不能概括成“完成攻击”或“发生战斗”。

### 视觉账本（V）

记录该事件为了被看懂而选择的宏观证据：主体剪影、敌我相对位置、力量方向、VFX形态及变化、环境受力、光权、声音落点和下一镜可继承状态。V项可以自由替换，只要仍然证明同一个S事件；不设固定层数、材质数、光色或镜头数量。

### 漂移账本（D）

只记录可能导致抽卡或穿帮的状态：身份外观、伤势、武器归属、手持状态、屏幕侧、面向、敌我轴线、地标相对位置、地面高度、VFX来源/占区/残留、主光方向和镜头绑定对象。D项的作用是提醒模型，不能转化为逐关节坐标、厘米位移或固定机位配额。

## 2. 合并前的动态判断

把候选镜头按原剧情顺序放入一个生成段，逐段回答以下问题：

1. 所有镜头是否共享同一时空锚点，或存在可见且有因果的时空过渡？
2. 是否共享同一敌我轴线，或已有转轴事件/中性机位/明确转身证明换轴？
3. 每个镜头的主观看中心是否由同一动作弧驱动，还是出现新的独立控制权变化？
4. 事件之间是否存在互斥姿态、互斥持物状态、互斥高度或必须分别读取的接触结果？
5. 合并后每一条S项是否仍能在正常观看速度下找到唯一的可见或可听证据？
6. 生成段末是否留下可复述的稳定状态，或明确处于允许开放的连续运动？

满足这些条件才允许合并。任一条件不满足时，先尝试保持创意的内切、遮挡转场或证明角度；仍不清楚再拆成相邻镜头，超出生成容量才拆段。不得因为镜头数量少就强行合并，也不得因为镜头数量多就机械拆分。

## 3. 合并后的“必演绎保护”

合并不是删除源镜头，而是把源镜头的必要事实压缩为事件级控制点。每个S事件至少保留以下与当前事件相关的可见证据，具体选择由导演决定：

- 执行者与作用对象能被唯一辨认；多人同镜时不用“他/她/其”承担关键动作主语。
- 起点、宏观路径或力量方向至少有一项可读；不要求逐步轨迹。
- 接触、规避、显化、命中或失能至少有一项直接证据；不能用泛光、切空景或爆炸遮挡替代关键因果。
- 结果、控制权变化和必要残留可被看见或听见；开放运动可保留开放，不强制停帧。
- 本事件所需的VFX来源、行为、第一作用和后态不能被“沿用前效”省略。

这些是“必演绎证据”，不是额外动作。若同一构图已同时证明多项，不补镜；若一项被遮挡，改变焦点、遮挡时机、景别或相邻覆盖，而不是新增剧情动作。

## 3.1 群体活性门：让非主要人物真实存在

多人同镜时，先给每个非主要人物绑定一个不改变剧情的 `反应职责`，再允许模型自由生成具体表演。反应职责从当前剧本可推出的状态中选择，例如：观察并寻找信息、承受同一力量、保护既有目标、维持既有阻挡、被环境逼退、确认伤势、响应同伴、执行已写出的任务或保持既有恐惧/决心。若剧本没有足够依据，只保留“维持当前任务与受力状态”，不要替配角发明新决策。

动态检查以下关系，而非检查固定动作清单：

- **信息差**：谁看见了攻击来源、谁只看见结果、谁被遮挡或来不及反应；不同信息应产生不同的视线、朝向、迟疑或动作节奏。
- **受力差**：离VFX源点远近、遮挡物、站立支撑和伤势不同，人物的身体状态不能整齐同步；受力只改变可见反应，不自动改变剧情结果。
- **关系差**：同伴、敌人、旁观者、被保护者和执行者的注意对象与情绪方向不同；避免所有人都面向镜头或同时看向主角。
- **时间错峰**：群体反应允许前后错开、互相打断、局部遮挡和不同恢复速度；不要求每人都获得独立特写，也不允许所有人同时做复杂动作。
- **主次隔离**：主要人物保留第一读点；配角通过呼吸、重心、眼神、持物状态、短暂避让、环境互动或关系回应保持活性，但不得用新招式、新对白、新伤势或新控制权抢戏。

最终提示词只需写“谁承担什么反应职责、反应朝向/受力来源、与主事件的时间关系和停止条件”，不写逐人逐关节编舞。验收时，静帧抽查每个可见配角是否有合理任务/受力/关系状态；连续画面抽查其状态是否随威胁、冲击、遮挡和控制权变化而变化。若所有配角像复制粘贴，优先增加信息差、受力差或时间错峰锚点；若配角开始创造新剧情，删去越权决策而保留活性。

## 4. 空间锚点锁（关系锁，不是硬编码）

段首镜用自然语言建立完整锚点，后续镜只重述发生变化或高漂移风险的项。优先使用稳定地标和相对关系：

`场景边界/地标 -> 敌我轴线 -> 各角色相对方位与高度 -> 屏幕侧与面向 -> 道具/伤势归属 -> VFX源点、传播方向与占区 -> 地面/墙体/光照后态 -> 摄影机绑定对象`

允许使用“巷口在画面左后方、宋棠位于巷心、对手压在右侧墙根、攻击沿巷道纵深向巷口推进”这类可见关系；不要把所有镜头写成固定XYZ坐标。只有当漂移风险无法靠关系描述消除时，才补充一个最小量化锚点，并在内部标记其理由。

每次切镜只需继承一项以上稳定状态：屏幕左右、运动方向、遮挡形状、声音趋势、VFX残留、光权或地标相对位置。若故意断裂，则在台账注明“策略重置/时空跳转/冲击硬切”，并重新建立必要锚点。

## 5. 负载审查：事件数，不是字数

不要用字数、形容词数量、粒子种类或固定分数判断过载。动态统计同一时间窗内的：独立S事件、互斥姿态、控制权变化、空间重建次数、道具归属变化、强遮挡和摄影焦点交接。高视觉描述只要共同服务同一S事件，不应被压成干瘪摘要。

出现风险时按以下顺序处理：

1. 移除无原文锚点且不承担证明功能的E演绎。
2. 合并不改变S的N补间，删除重复同义句和伪精确数字。
3. 合并同一目标、同一轴线、同一控制权和同一结果下的动作弧。
4. 简化非关键摄影转折和次级粒子，但保留主VFX行为、环境因果、光权后果和声音落点。
5. 换证明角度或在同一段内拆镜；仍无法兑现全部S时才拆生成段。

每次处理记录“保留的S项、替换的V项、删除的E/N项、原因”。禁止静默删除源点、路径、第一作用、受术证据、结果或必要空间后态。

## 6. 穿帮与漏演阻断门

以下任一项失败，禁止直接导出；先做最小修复并重新反向复述：

- 角色身份、服装剪影、伤势或武器在无因时跳变。
- 左右屏、面向、敌我轴线、地面高度或移动方向无过渡反转。
- 道具无因换手、复制、消失，或闲置手状态与下一镜冲突。
- 攻击来源、作用对象、接触点、规避路径或受力方向无法唯一判断。
- 大型VFX无因缩小、瞬移、换材质，或从巨大结构直接变成不相称结果。
- 环境在受力后无因复原，粒子穿过实体，光影方向与光源/遮挡不符。
- 镜头运动遮掉决定性动作，焦点在结果前切走，或越轴造成敌我关系反转。
- 合并后只剩“人物做动作+特效出现+环境震动”，但观众无法复述原剧情。

修复优先级：`身份/肢体 -> 空间/轴线 -> 动作因果/接触 -> VFX来源/遮挡/光照 -> 摄影机 -> 质感`。每轮只修一个主根因，不做全量重写。

## 7. 交付前反向复述

去掉风格词、E演绎和装饰音效，只看连续镜头块，按原顺序复述：谁用什么对谁做了什么，是否接触或规避，能力如何作用，控制权如何变化，结果与残留是什么。复述必须唯一对应S账本；若出现多个解释，增加最小必要锚点或拆分承担证据的镜头。

反向复述通过后，再做正向覆盖核对：源剧本每条S项都有镜号承载；未覆盖的后续事件明确标记为后续制作。只有正向覆盖100%、反向复述唯一、空间状态可继承且总时长不超过30秒，才允许导出可直接复制的Markdown。

## 8. 创意自由复核

交付前询问：当前方案是否只是因为某个稳定模板而被迫采用？如果是，回到导演演绎层重新发散；模板只能作为诊断参考。只要新方案满足S覆盖、空间关系、结果证据和生成容量，允许使用不同的镜头数量、VFX母题、运镜、节奏、高潮位置和收束方式。

# 对手决策与多人时间调度

只在剧本保真矩阵已经确认源剧本确有对手决策、反制或多人调度后读取。本参考只校验原文已有的信息权限、反制因果与多人错峰，不提供默认战术剧情，也不得添加观察、试探、学习、代价或反击节拍。

## 决策状态

每个节拍更新以下状态：

| 状态 | 问题 |
|---|---|
| 信息 | 角色看见了什么，误判了什么，哪些能力仍未知 |
| 距离 | 当前处于D0-D4哪个距离带，谁能先命中 |
| 主动权 | 谁在迫使对方回应，谁只能恢复或撤退 |
| 攻防线 | 武器、身体、法术和出口分别控制哪条路线 |
| 平衡/姿态 | 扎稳、移动、腾空、失衡、倒地还是恢复中 |
| 资源 | 体力、握力、弹药、灵力、法器冷却、护盾完整度 |
| 地形权限 | 谁控制出口、高地、掩体、阵眼、窄门或可破坏物 |
| 情绪控制 | 冷静、急躁、恐惧、留手、复仇冲动如何改变选择 |

## 高手博弈循环

```text
观察 -> 试探 -> 读取反应 -> 制造诱导 -> 迫使承诺
-> 截断/避开回收 -> 取得角度或资源优势 -> 造成结果 -> 重新评估
```

只有源剧本写出或明确暗示“获得信息”时才呈现该节拍；不得为了让反击更合理而插入原文没有的观察或试探。原文直接反击时，通过已有视线、距离和动作承诺把因果拍清楚，不新增事件。

### 可见预判线索

- 呼吸骤停或吸气：即将爆发或施法。
- 前脚压实、后脚蹬地：直线前冲。
- 髋肩先转、武器端点后置：弧线重击。
- 握把改变、剑尖偏移：变招或准备缴械。
- 视线先看出口/阵眼：真实目标不是眼前对手。
- 灵力向指尖、法器或地面节点收束：技能类型和作用方向可被推断。
- 旧伤保护、握力下降、落地迟缓：可利用但必须承担诱敌风险。

预判不能读心。若线索被遮挡、角色背对或首次见到未知能力，只能保守试探或付出代价后学习。

## 承诺与回收窗口

| 窗口 | 可用战术 |
|---|---|
| 预备前 | 压迫距离、封路线、打断视线、迫使提前出招 |
| 预备中 | 识别方向、调整防线、制造假目标 |
| 承诺后 | 闪避、偏转、截击支撑点；攻击者难以完全改线 |
| 接触后 | 利用后坐、武器弹开、单脚支撑、法器冷却 |
| 回收中 | 绕侧、缴械、抢出口、建立阵法或安全距离 |

战力变化、优势数量和取胜方式完全服从源剧本。本表只能解释剧本已有的窗口，不能用“合理性”改写原文规定的突然爆发、秒杀或碾压。

## 角色决策风格

| 类型 | 常用选择 | 可利用偏差 |
|---|---|---|
| 压迫型 | 直线逼近、封退路、连续迫使回应 | 对侧后变化迟钝，重招回收明显 |
| 反击型 | 保持距离、读取预备、在承诺后出手 | 面对假动作和多目标容易迟疑 |
| 诡计型 | 遮挡、诱导、假弱点、改变真实目标 | 正面交换能力弱，计划被打断后恢复慢 |
| 控场型 | 阵法、地形、远程线、资源消耗 | 阵眼/法器被贴身后选择受限 |
| 牺牲型 | 以伤换位、保护目标、拖延时间 | 伤势和资源必须持续恶化，不能无代价重复 |

## 多人战场分区

先把场景划为明确区域：主要接触区、远程压制区、侧翼路线、辅助/阵眼区、撤离口、范围技能危险区。每个角色在一个时间窗只承担一个功能。

### 时间错峰规则

- 单个生成镜头只允许一个主要接触组；其他角色只能移动、瞄准、维持防御、撤离或作背景反应。
- 远程攻击必须避开友军路线，或明确友军先撤、护盾隔离、施术者接受误伤。
- 范围技能按 `预警 -> 队友撤离/敌人受限 -> 释放 -> 余波 -> 重组阵型` 调度。
- 援护动作必须先创造窗口，再让被援护者移动；不能两人同时穿过同一空间。
- 镜头切换跟随主动权，不按角色名单平均分配时长。

## 多人时间表模板

```text
时间窗：[起止时间]
主要接触组：[角色A vs 角色B；本窗唯一复杂接触]
主动权与目的：[谁迫使谁回应；要改变什么]
其他角色：[各自区域；移动/压制/维持/撤离/恢复]
远程/VFX：[来源；安全线；预警；释放；误伤约束]
摄影机：[覆盖职责；主焦点；不得遮挡的关系]
窗口结果：[新位置、伤势、资源、阵区和下一接触组]
```

## 团队协同母式

| 母式 | 时间顺序 | 代价/反制 |
|---|---|---|
| 盾压+侧击 | 前排封线 -> 敌人攻击盾面 -> 侧翼进入 -> 单次打击 -> 前排重组 | 敌人可后退拉开或攻击侧翼进入点 |
| 诱敌+远程 | 诱饵暴露 -> 敌人承诺追击 -> 远程线清空 -> 射击/法术 -> 诱饵脱离 | 诱饵承担真实受伤风险 |
| 控场+处决 | 阵法限制路线 -> 主攻手确认安全区 -> 决定性攻击 -> 阵法耗尽 | 阵眼可被破坏，主攻手必须等待窗口 |
| 救援撤离 | 一人制造遮挡/格挡 -> 伤者移动 -> 援护者最后撤离 | 援护者失去先手或承受资源消耗 |
| 范围清场 | 明确预警 -> 友军撤出 -> 敌人被封路 -> 大招释放 -> 尘烟后重组 | 敌人可抢出口或逼施术者中止 |

## 质量门

- 每个决定都基于角色当时可获得的信息。
- 剧本已有的线索、试探或承诺窗口均被保留；剧本未写时没有擅自添加。
- 每个时间窗只有一个主要接触组，其他角色状态可说明。
- 团队配合有时间先后、安全线、失败可能和资源代价。
- 多人落幅能供应下一时间窗，不出现无解释换区、复活或资源恢复。

# 小说改动态漫剧本

将用户授权改编的小说文本或小说文档转换为标准动态漫剧本格式。用户已提供集数、场次要求时直接采用；缺少但不影响改编的制作信息使用合理默认值，并在必要时标明。只对会改变片段边界、人物关系、因果或用户要求的输出结构的关键歧义集中提问，不逐步索要确认。输出格式参考 `references/output-example.md` 中的完整剧本示例。

## 每次调用的更新检查

每次调用都重新读取当前版本的本入口和实际命中的参考文件，不使用上一轮对话缓存。开始改编前执行：

1. 检查 `references/output-example.md` 的当前内容，确认格式速查卡与示例没有冲突；
2. 若任务涉及平台发布、审核或监管要求，自动核对当前可访问的官方/权威公开规则，并在内部记录检查日期与来源；
3. 网络或权威来源不可访问时，明确标记“未实时更新”，只把本地参考作为初步创作依据，不声称最新或保证过审。

更新检查不改变原文事实、人物关系和用户确认的集数/场次；只用于刷新格式和合规判断。

## 文件输出边界

- 默认在对话中输出剧本；只有用户明确要求保存或提供文件路径时才写入文件。
- 用户指定目录时优先使用；未指定时写入当前工作区的 `outputs/`。
- 不覆盖小说原文或已有剧本；同名时使用递增版本名，文件名去除非法字符。
- 完成后报告绝对路径；未实际写入文件时不得声称已保存。

## 动态漫格式标准

动态漫剧本使用五种格式元素：

| 元素 | 格式 | 用途 |
|------|------|------|
| **画面描述** | `△` 开头 | 视觉画面描写，细致可视化 |
| **旁白** | `OV：` 话外音 | 交代整体故事，开场叙述卖点和亮点 |
| **内心独白** | `姓名OS：` | 人物心理活动 |
| **角色对话** | `姓名：` | 人物对白 |
| **场序** | `X-X 天气/场景 地点 主要人物：角色A、角色B` | 场景信息头 |

## 输出格式详解

### 场序行格式

`{集号}-{场号} {天气}/{场景} {地点}  主要人物：{角色1} {角色2}（{关系标注}）`

天气值：`日` / `夜` / `雨夜` / `黄昏` / `晨` 等
场景值：`内`（室内）/ `外`（室外） / `内外`（半室内）
人物间用空格分隔，关系标注如（弟弟）（哥哥）放在人物名后

示例：`1-1 日 内 侯府房间  主要人物：宋妩 沈知非（弟弟）`

### 对话格式

对话中可嵌入动作/情绪/语气描述，放在括号内位于姓名与冒号之间：

`姓名（情绪或动作描述）：对话内容`

示例：`沈知非（俯身贴近，嗓音低沉，唇边笑意邪肆）：夫人，还跑么？`
示例：`宋曦（声音尖锐，带着几分任性的蛮横）：娘亲，我不嫁沈寂安，我要嫁弟弟沈知非！`
示例：`宋母（眉头深锁，指腹轻轻捻着手里的茶盏盖，语气不解）：你不是非要嫁给哥哥么？`

### 内心独白格式

内心独白使用 `OS` 标注，紧接在情绪/动作描述后：`姓名（OS）` 或 `姓名（情绪,OS）`

示例：`宋妩（喘了口粗气，庆幸,OS）：我……我重生了……`
示例：`沈寂安（盯着她看了一瞬，目光沉静，OS）：嗯。宿在书房。`

### 闪回/时间跳转格式

| 标记 | 用法 |
|------|------|
| `【闪回】` | 标记闪回开始 |
| `【闪回结束】` | 闪回结束 |
| `【接1-2】` | 闪回后接回的场次标记 |
| `【梦中闪回】` | 梦境闪回 |
| `【翌日】` | 次日时间跳转 |

### 镜头/画面特殊标记

| 标记 | 用法 | 示例 |
|------|------|------|
| `△【特写】` | 镜头特写 | `△【特写】黄瓜` |
| `△（镜头切至XX）` | 镜头转换 | `△（镜头切至别墅门口）` |

## 小说转剧本的核心规则

### 一、提炼主线，保留精华

- 剧本聚焦围绕主角展开的主线故事
- 去掉或精简支线，同时保持剧情连贯不跳脱
- 保留故事中的爽点、甜点、虐点
- 每次转换只处理1集剧情的文本量
- 爽点/钩子/悬念尽量放在每集末尾

### 二、避免过多文字铺垫

- 不需要过多的情绪、环境描写
- 语言精炼，以台词+画面为主要表现形式
- 背景描写/环境描写/人物心理描写 → 精简或转为台词和画面
- 心理独白 → 外化为可见的细微动作
- 大段环境描写 → 提炼3个视觉层次
- 时间流逝 → 转为视觉符号（蜡烛燃尽/光线变化/翻页/落叶）

### 三、原著事实与改编权限

**默认使用忠实改编模式。用户对台词、删减或顺序的明确授权只覆盖该项，其余原著事实与因果继续锁定。**

- **对话保真**：默认保留原文台词的文字、归属和顺序；用户未授权改写时不得润色或新增台词。确需压缩时优先删减重复信息，并标明处理。
- **因果保真**：保持事件因果、人物选择、关系、能力、关键线索和结局。不得擅自增加新事件、人物关系、背景设定或改变结局。
- **人物保真**：人物性格、说话风格、行为逻辑不能偏离小说设定（禁止OOC — Out of Character）
- **顺序默认保真**：沿原作信息顺序改编。只有用户明确要求改编重排、强化开篇或倒叙结构时，才调整呈现顺序；不得借重排改变因果、人物知情或提前泄露结局。

**每场输出后必须逐项自检（不合格须修正后重输出）**：
1. 对话是否保留原文文字、归属和顺序？经用户授权的改写是否严格限于授权范围？
2. 是否擅自添加事件、人物关系、能力、关键线索或改变原文因果？如有，删除或标为待核实。
3. 人物是否符合原著性格？（说话方式、决策逻辑、情感反应）
4. 画面、OS/OV 是否引入原文没有的信息？过渡性动作应只显化已有事实；其他增补须有明确改编授权。

**默认忠实模式下禁止**：
- ✖ 自行增加原文没有的对话或内心独白
- ✖ 将原文的叙述性文字改写为角色对话（除非原文明确是对话内容）
- ✖ 让人物说出不符合其性格的话
- ✖ 凭空添加情节转折、冲突、悬念
- ✖ 未获授权时美化或"优化"原文表达——保留原文的语言风格
- ✖ 将多个人物的台词合并到一个人物身上

### 四、开篇处理

- 默认沿原文开篇与信息顺序，用画面和原有台词建立场景；只有用户授权重排时，才把后文亮点提前。
- 不强制添加概述全剧的 OV、悬念或爽点；只有原文依据或用户改编授权支持时才设计。
- 以台词和画面承载信息，压缩重复铺垫但不删掉理解人物选择所需的因果。

### 五、发布合规边界

本技能负责改编，不自行替用户审查或软化题材表达。用户要求检查即梦或其他平台发布风险时，转由 `jimeng-script-review` 按其审核流程处理；不得把风格判断写成法律或平台规则。

## 工作流

1. 确认用户提供了小说片段且明确要求小说改编。用户只提供片段、未说明用途时，只按片段转换，不推断整集内容。
2. 一次检查片段边界、集数/场序要求、保真等级、台词改写授权、目标格式和文件要求。已有内容足够时直接开始；仅当歧义会改变事实或交付范围时，集中询问相关项。
3. 通读本次片段，建立事件顺序、人物知情、动机、关键道具、转折和结尾状态；按场景/时空/行动变化划场，不设固定场次数上限。
4. 将叙述转化为可视画面、原有对白、必要 OS/OV 和场序。新增过渡性画面只用于呈现原文已含动作或事实，不发明新因果。
5. 输出前逐场检查：
   - 对白是否保持原文、归属和顺序，所有改写是否获得用户授权；
   - 是否改变事件因果、人物关系、能力、关键线索或结局；
   - 人物台词和行动是否符合已知设定；
   - 画面/OS/OV 是否误增原文没有的信息；
   - 所有实质删减、合并、压缩或经授权的顺序调整是否有简短说明。
6. 对有歧义的事实标“待核实”，不把推断写成原著事实；完成后交付剧本和必要的简短改编说明。用户后续要求调整或继续时再处理下一段。

## 参考文件

完整的剧本输出示例见 `references/output-example.md`，其中包含3集完整的动态漫剧本，展示了所有格式元素的标准用法。

仅在以下情况读取 `references/output-example.md`：
1. 首次使用本技能且不熟悉动态漫剧本格式
2. 遇到模糊的格式边界（如闪回嵌套、多人对话分层、特殊镜头标记）需要参照示例
3. 用户明确要求对照示例格式

一般情况下，以下内联的"格式速查卡"已足够覆盖常规格式需求，无需每次加载完整3集示例文件（约180行）。

### 格式速查卡（内联，无需外读）

**场序行**：`{集号}-{场号} {天气} {场景} {地点}  主要人物：{角色A} {角色B}（{关系}）`
- 天气：日/夜/雨夜/黄昏/晨 | 场景：内/外/内外

**画面描述**：`△` 开头，每行一个画面单元
**旁白**：`OV：` 话外音
**内心独白**：`姓名OS：` 或 `姓名（情绪,OS）：`
**角色对话**：`姓名（情绪或动作描述）：对话内容`

**闪回标记**：`【闪回】` 开始 → `【闪回结束】` → `【接X-X】` 接回
**梦境闪回**：`【梦中闪回】` | **次日跳转**：`【翌日】`

**特殊镜头**：`△【特写】` 物体 | `△（镜头切至XX）` 转场

## 可调用命令

当用户以自然语言提出小说转剧本请求时，直接执行上述工作流。
用户也可使用 `/dynamic-manga-script` 触发本技能。

## 现有技能关系

- 本 `dynamic-manga-script` 技能专注于严格遵循参考示例的格式输出，适用于需要精确格式控制的场景。
- 不依赖个人技能库中不存在的小说转换、场景提示词或项目状态技能。

## 可配合的技能

本技能主要输出剧本正文。用户如需将剧本生成AI图文/视频，可后续配合以下技能：
- `cinematic-character-prompt` - 角色画面提示词
- `jimeng-dialogue-performance-storyboard` - 即梦 Seedance 视频分镜

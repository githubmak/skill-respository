# 大型动作、连续攻防与特效设计

出现连续攻防、多阶段重动作、巨物或主要术法峰值时按需读取。以共同导演方案、源稿能力规则和结果为输入；不扩大改编权限，不建立另一套格式。方法提炼自即梦动作与奇观参考，删除固定规模等级、片段数量、单一介质与镜长配额；实际规模服从源稿证据和观看收益。

## 1. 先让战术变化成立

锁定当前目标、阻力/威胁方向、可用空间/能力、人物身体与持物状态、既定胜负及必须读清的决定性作用。攻防升级来自路径被封、距离改变、招法失效/换法、保护对象、资源或控制权变化；不靠第二次更亮的爆炸冒充新进展。

对实际发生的过程组织：支撑与准备 → 启动/传播 → 规避/接触/对抗 → 受力与反作用 → 位置或局势结果 → 余波。各阶段可以重叠，也可跨镜承担，不要求每阶段独立成镜。递接/拉拽/碰撞等同样遵守；关键接触不能被无依据闪白、遮挡或场外音抹掉。

多人分别继承位置、视线、任务、知情和动作进度。主攻、承受者与背景错峰，不全员同步；摄影、能量路径和人物移动保持同一可读方向。攻击前的取景需给够理解距离与退路的依据，已有空间清楚时不重复建立。

## 2. 规模要有参照和后果

先确认原文允许且结果需要的最大有效规模，再选人物、武器、门窗、建筑或地形作为熟悉参照。巨物可以局部先显，但须通过遮挡关系、相对运动、投影/受力或整体揭示让观众确认体量；低机位、广角与“巨大”字样不能单独证明规模。

源稿需要山河或场景级奇观时，不能因生成困难默认缩成手边泛光。先比较关系/规模镜、随动传播、从环境作用揭示来源、局部接触切整体结果等承载方式，保留决定性尺度证据。原稿只有局部能力时不自行放大破坏范围、伤势或代价。

规模揭示同时回答人物如何被影响：路线、支撑、遮挡、相对位置、已成立的伤势/胜负或结果。无剧情依据不得增加坍塌、飞散人群、新伤、消耗或能力衰减。

## 3. 特效按真实阶段演化

按实际发生项设计前兆、激活、成形、传播/对抗、主峰、消散与现实后果。每段只写当前可见内容，不把未来命中提前画出。来源、主形态、扩张方向/速度、最大占区、遮挡、受光/受力和退出必须相容。

需要层次时，从可识别核心、主轮廓、次级纹理、空间介质、人物/物体反射、环境受力与残留中选真正有用的层。主轮廓先可读，次级粒子退后；纵深、速度和形态的差异共同表现力量，不让所有层同时争峰。颜色在能力设定与资产边界内选择；能量染光随距离、遮挡与材质变化，退出后回到应有环境，损坏和尘雾按因果保留。

强光/烟尘可以短时主导，但必须有来源、明确窗口和交回动作/结果的读点，不能全程白屏。未激活、已退出且无后果的效果零提及。世界内能量/破坏与非世界内的残像、速度线、曝光/剪辑修辞分清；后者须项目风格支持，不能伪造角色真的获得新能力或新事实。

## 4. 人物、摄影和主效一起编排

先定每一阶段观众要读的主体，再安排动作、摄影、光影和声音的进入。可让前兆由声音领入，起势看支撑，传播由跟随承载，接触时制动/切镜，结果用尺度展开或固定承受；这是可比较机制，不是每场固定链条。

强方案可以是贴身跟进、弧移到主效侧面、贴地追踪、俯冲、突然抽离、微观接触切宏观结果，也可以是不可逃离的固定见证。按当前空间写真实路径、触发、速度改变和读取窗口；不为了技法名称强造人物动作。与口型、接触或结果争抢时错峰、转移承载或有因切镜，不把技术简化变成删除高潮。

关键音效先读清作用与方向，配乐按开关和已定主题让位/接续，不逐拳重新起曲。主峰之后保留足够确认人物、环境或声音后果的窗口，具体由剧情结果决定，不凑三类余波。

## 5. 跨单元承接与验收

超过当前生成上限时，按真实动作/作用阶段分单元；连续长镜保持机位、焦点、方向、形态与音轨接缝，无法稳定拼接时明确剪切另编镜号。前尾与后首继承人物状态、持物手、重心、接触点、能量方向/形态、遮挡、光色、尘雾/损坏、声音和未完成动作。

检查实际时间线是否看得见战术变化、尺度参照、完整峰值窗口和结果；只有光边、发亮、零散粒子、技术名词或“震撼”不算兑现。失败只重做受影响组及接点，不为提高强度增加源稿没有的攻击、伤害或破坏。所有内容编译到原输出合同的摄影、光影、时间线、声音和落幅，禁止新增“特效设计表”等正式栏目。

# 联合视觉设计与正文兑现

规范版本2.0.0；入口与所用必读合同任一更新时刷新对应全文。

本文件整合人物行动、空间、摄影、景别、运镜、光影色彩、体积、材质质感、特效和粒子的共同设计与验收口径。它是本技能内部的创作合同，依本技能入口读取；不调用其他技能。用户当前要求、源稿事实、确认资产及授权范围优先，题材和输出格式继续按原规范。首稿、精修和转译都不能以“格式合格”替代设计充分；文本合同也不保证模型执行或成片审美。

## 1. 从一段可观看的画面开始

先确定观众要经历的关系、行动、信息或感官变化，结合来源与风格，联合构思这段实际怎样发生、怎样被看见和听见：人物行动与受话、空间/接触、光区和材质、适用主效与粒子，以及能承载它们的取景、运动和切点同时推敲。不是先写摄影、后补光影，再补材质词与特效清单，也不是先锁特效后强迫人物配合。它沿用原有导演方案，不新增分析阶段或额外交付表，不公开内部推演。

按镜头组确定进入、积累/持续、命中或变化、结果与交接中实际发生的部分；安静或无转折段可以保持同一种感受，不强造高潮。普通镜与高潮有同等必要精度，不要求相同强度、字数或技巧数。关键节点比较实际不同的观看机制，依据人物专属性、信息/情绪、力量/尺度与可执行性选一套；普通镜已有方案充分成立就展开，不逐镜反复竞赛。

## 2. 一套画面中的各个维度

下表是相互配合的设计责任，不是逐镜必填表。选定且适用的内容必须有可见结果；无关内容不占位，不适用时不造事件。

| 维度 | 要构思并写出的画面 | 不能当作已经完成的替代物 |
| --- | --- | --- |
| 人物行动与表演 | 当前目标/感受怎样改变话语、动作、注意或有意义的保持；必要支撑、路径、接触、抵抗、受话和结果连续成立，变化在实际占幅与停留下可见 | 看、说、笑等无对象过程；微表情清单；为展示材质而新增任务或关键选择 |
| 空间、摄影与景别 | 观众站在哪一侧、看谁、何时知道什么；主体占幅、前后层次、可见面、裁切、遮挡与焦点能承载脸/手/物、关系或尺度；画内外状态一致 | 焦段数字等于景别；写了细节就当拍得到；近景强塞低位手物；强求所有层同样清楚 |
| 运镜、调度与剪切 | 摄影和主体怎样靠近/远离、跟上/落后、擦身或保持；构图、视差、焦点和注意怎样沿可达路径交接；切入/退出保住事件进度与感受 | 运镜名称、平稳陪走或每镜归零；无实际观看收益的换焦段；减速摄影等于人物停手 |
| 光影、色彩与塑形 | 有效来源、实际光向/软硬、亮暗面积、反差与灰阶、高光暗部层次、人景分离及肤色；这些关系怎样显出人物与行动，变化由真实光源/移动/遮挡或明确风格依据产生 | 暖光等于暧昧、冷光等于悲伤；K值兼指光源/白平衡/观感；只写低饱和、光源不变或电影感 |
| 体积、尺度、材质与质感 | 身体/器物/主效的厚度、曲面、遮挡和空间参照；材质在受光、接触、运动时的反射、接触影、受压/挠曲、褶皱或适用透光；形体与表面结果匹配 | 巨大、厚重、PBR、自然皮肤、细腻衣料；只有亮度没有体积；用贴镜占幅冒充世界内巨大 |
| 主特效及环境作用 | 既定能力的来源、可辨形体、体积读法、相对人景尺度与阶段占区；传播、抵抗、形变/导向、峰值、退出及既定后果中实际发生的过程，与人物/环境受光受力相容 | 换色光束、泛光、爆炸词；只写规模不被看见；无来源染光或破坏；切镜清空持续主效 |
| 粒子与介质 | 既定形态和来源、相对大小参照、群体疏密、初始路径与随后受力/控制；本段需要的近远投影、遮挡、速度、密度与存留差异，怎样伴随主效演化 | 全部细屑碎芒或均匀亮点；以云海受力代替粒子设计；把近镜大投影当真实大粒径；无源碎石、电弧 |

声音与配乐沿同一导演判断定位动作、对白、接触、远近空间和交接；遵守既有音乐开关与人声清晰规则，不为粒子或不可听细节凭空造声，不用音乐宣判代替人物/行动。

## 3. 充分展开，不套固定套餐

- **技巧组合不设数量上限。** 多阶段推拉、跟随、弧移、升降、焦点、遮挡、调度与剪切可共同服务一个连续观看过程，不要求每阶段新增剧情事件。实际发生剪切另计成片镜，不能将机位跳变伪装成长镜；人物与摄影可同时进行，关键接触可由运动中机位或切镜看清，不逢接触必急停。
- **静态也须设计。** 固定机位、稳定光、安静表演可以靠距离、构图、负空间、受光、受话或既定结果的保持产生感受；无需为了丰富强迫人物忙碌、灯光变色或摄影漂移。不能仅写“固定凝视、稳定光源”便认定完成。
- **体积与尺度分别证明。** 厚度可由侧面、截面、曲面明暗、遮挡或相对运动显出；世界内大小须有熟悉参照及必要整体关系。薄刃、透明体或二维风格按自身设定呈现，不把所有效果实体化；局部触感与宏观展开可跨镜接力，不强制同一画面兼顾全部。
- **材质回应真实条件。** 接触影、皮肤轻微受压、衣料张力/褶皱、金属反光移动等只在当前材料、动作、景别与风格支持时使用；不靠锐化、毛孔、磨皮、泛亮、颗粒或光晕统一刷质感。无接触时可凭稳定受光与反射读材质，不为此新增接触。
- **粒子大小不是三档配额。** 按既定能量或介质设计片、丝、颗粒、液滴等实际形态；粗大剥离与细密尾迹等差异在需要时充分展开，来源不支持就不新增。单一粒径可用距离投影、遮挡与运动形成层次，不强制近中远三层。能量粒子不机械套实体重力，云、尘、水与能量的作用分别成立。
- **丰富度与可读性共同设计。** 先用形态、亮暗、轮廓、色彩、纵深、时序和观看接力组织密度；不能默认删粒子、缩主效、减运动来求稳定。出现实际冲突才改时序、取景、切镜或生成单元，保住源稿的尺度、动作、力度和必要表演；不新增能力、伤势或毁坏补场面。

## 4. 从构思到正文不缩水

跨场风格、当前场景条件、当前镜头的事件和接点按本技能原格式分工。一个决定只形成一次：稳定光色/材质属性放适用基线，镜头的取景与路径放摄影位置，实际变化、接触、主效与粒子演化进入时间线或连续画面描述，落幅只结算仍需继承的状态。不重复写几遍，也不在编译时把完整过程压成“柔和、宏大、丰富”等词。

空间、焦点、速度与时长必须让采用的内容实际可读。小局部占幅、遮挡、焦外、暗处或读取时间不足时，修取景/承载而不是追加不可见细节；有意隐藏继续保留，不能为展示材质或人脸擅自补亮、转身。跨镜保持人物、道具、伤势、受力、光源、主效进度、粒子残留和声画接续，不能切镜复位。独立投喂按本技能补齐必要上下文，不虚构上传素材或生成能力。

## 当场体验的判断

动笔前只确定本段实际需要的感受及其可见发生点，再共同选择人物处理、空间距离、光区/材质、摄影与声音；不是先写普通覆盖再补气氛词。暧昧按具体人物的试探、被察觉与回应组织，亲近、迟疑或距离保持须有正文依据；光源、明暗和取景共同支持它，不靠暖色宣称心动。速度/逼近须在主体与摄影或参照物的相对运动中发生，重量/抵抗须有持续作用与承受；大型术法须有相容形体、空间参照与展开/作用过程。按本段适用项判断，不强加关系回应、运动、大招或固定情绪曲线。

复审只读采用稿，指出目标体验由哪段实际动作、画面与声音形成，关键前后或持续过程怎样使其被感到；“更电影、有张力、有观看收益”及栏目齐全均不是证据。设计本身只达成普通交代却未兑现本次表达目标时，回到相关演法/打法与拍法重选，不用追加形容词、颗粒或技术标签补救。正文已能兑现则结束，不以还有更复杂方案为由重做，也不以文本判断承诺成片效果。

## 5. 同轮核对、按根因修正文

在原有统一复审中，逐项定位本段实际适用维度的镜号/时间窗或连续过程；可跨镜成立，稳定有效内容不逐镜复述。核对分三种失败，不新增三轮流程：

1. **没有设计：** 只有目标词或风格标签，回到该段联合画面补构思，再同步相关动作、摄影、光色与效果。
2. **设计有了，正文丢了：** 内部方案、基线或工程说明具体，实际镜头/Prompt却只剩概括词，修编译及接点；不能靠交付后口头解释补证据。
3. **正文写了，却看不到或互相打架：** 占幅、景深、遮挡、速度、时长或空间关系使证据不可读，或光影/粒子抢掉关键行动，调整真实依赖的机位、时序或承载，不牺牲既定剧情和有效表达。

各适用维度分别成立：动作/摄影通过不能抵消光影、材质、体积或粒子缺口；栏目非空、参数齐全、词多或程序通过均不等于创作通过。每个维度有充分的本段证据即可，不要求每镜填满表或每秒有变化。只记录具体问题、位置、修复与复验，使用本技能既有最小记录，不另造审核输出表。

“一轮统一复审”表示集中判断并定向修复，不是发现缺口也只能看一遍；同轮修复后复验受影响部分及接点。没有具体缺口则结束，不因还能想到别的技巧而无限重做。硬锁、来源或制作条件阻碍未解决时，明确具体限制与待完成项，不称已完善；文本成立仍须由实际生成与用户观看验证。

## 本技能落点

本合同与共同导演规范组成同一制作依据。人物/事实见共同规范0—3，摄影细则见4.1—4.2，场景光色、材质和状态见4.3，大型动作/特效按需读专项；本合同归属联合构思与跨维度验收，不替换输出合同。首稿在场末复审前应已写出采用设计，复审不承担事后凭空补齐全部视觉。

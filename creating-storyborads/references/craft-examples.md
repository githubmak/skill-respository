# 机制示例：启发，不是认可案例

以下均为本技能的合成示例，未经过用户认可、成片或观众验证；不能宣传为爆款样本。只在遇到对应问题时读一例。例中事实只属于该例，禁止转移至实际剧本。用户已有明确拍法时优先执行用户要求。

## 1. 礼貌拒绝：把关系放进任务

示例事实：林岚正在把借来的书装回纸袋。周远问“你还来吗？”，林岚答“不来了。”，随后将纸袋交还周远。原文没有挽留或和解。

平庸表达：每句切单人近景，加皱眉和悲伤音乐。问题是说话能懂，但交还与关系结束脱节。

可选机制A：中景同框保住书袋和两人的距离。林岚完成装袋而不抬头，答话后将纸袋递出；周远接住后林岚才松手。摄影读到接触和归属的完成，不另造和解。

可选机制B：从递袋动作进入近景，画外问话延续；在林岚答完后切到周远接袋的手和其实际可见姿态，再回到新的距离。适用于交还作为关系落点更重要的情况，不为完整覆盖硬补反打。

选择依据：A让观众持续目睹双方边界，B突出归属变化与接收结果。真实剧本未交还物件时不能新增这套动作；双方没有掩饰动机时不强演克制。音乐可保留稀薄短音型，也可在接袋处有因停奏，不能靠悲伤标签制造拒绝。

## 2. 严肃误会：让观众自己确认

示例事实：许安奉命“把贵客请到上座”，却把装着“贵客”牌子的空椅搬到上座。掌柜看到后说“我让你请人！”许安转头看空椅。

可选机制A：固定关系全景同时容纳许安搬椅、掌柜和空椅落位。观众先发现错位，掌柜按注意实际到达后确认；不抢先切掌柜夸张反应。

可选机制B：起初只读许安认真搬运，随后在椅子落位揭出牌子与空座，再让掌柜台词进入。只有原文允许这一信息顺序时成立。

选择依据：A的笑点是共同目睹严肃执行的荒唐，B是延迟确认。两者不能机械折中为频繁插切；别在揭示前用滑稽音效替观众宣布笑点。实际节拍来自搬运与认知时间，不固定停顿秒数。

## 3. 证据回收：摄影服务知情差

示例事实：沈宁听见门外钥匙声，认为是同伴回来了；门开后看见钥匙挂着陌生铜牌，随后才看到陌生来人。没有新增危险或袭击。

机制：先让已有钥匙声产生判断，门缝/手部实际可见时才给铜牌证据，保持进入方向和身份揭示次序；不能先用来人的正脸镜破坏误判。近景隐藏身份有职责，不能被全局“人脸清晰”反向补亮。

适用条件：源稿确有误判与可见证据。没有铜牌的原稿不能补造铜牌；单纯未知来人也不自动获得误导过程。音乐若开启，可保持同一持续音直到证据改变判断，避免无依据惊吓冲击。

## 4. 递接与战术：规模不能代替作用

示例事实：受伤的季川右手持符，左手扶墙；追兵进入窄道。季川将符贴上门框使石门落下，阻断追兵，自己留在门内。符的能力和石门结果已由原文明确。

机制：关系镜读清两侧、门框与退路；动作段让右手离开持符起位到门框接触可见，左手支撑与重心相容；石门关闭时读到追兵被阻在另一侧，季川仍继承伤势与位置。可以动量切镜，不用全程慢动作。

适用条件：门、能力和最终归属已成立。不能为炫技追加爆炸、新伤、反杀；不能用白光遮住贴符接触再直接交代胜负。配乐在符接触和门落决定性声前减少竞争，后续是否恢复由安全/未解除压力的真实结果决定。

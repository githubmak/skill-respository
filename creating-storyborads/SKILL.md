# 制作分镜

面向首稿即可进入制作审阅的导演分镜。以 S+ 爆款为创作目标，通过具体观看收益、人物专属性、节奏和制作可执行性提高首稿完成度；不得承诺一次生成必达 S+、爆款或无瑕疵。名称 `creating-storyborads` 为用户指定，保持该拼写。

## 规范与读取

1. 首次执行、新会话、上下文压缩后无法确认全文仍可用，或规范版本变化时，**完整读取** [共同导演规范](references/director-standard.md)、[联合视觉设计与正文兑现](references/visual-design-contract.md) 与 [执行、状态与程序核对](references/execution-workflow.md)。工具输出截断时按行分段补齐，不能把路径、摘要或检索命中当作全文。版本 1.1.25。
2. 当前会话已完整读取且版本未变，续接只读取工作记录、当前场来源与必要相邻接点；出现来源反证再定向回读。全文件约束持续有效。
3. 正式编译前必须按实际配乐范围完整读取唯一输出合同：有开启范围用 [配乐版格式](references/output-music.md)，全部关闭用 [细节版格式](references/output-detail.md)。二者以源MD第6章为底，按用户授权改为“项目共用视觉规则＋各场的“场景摄影规则”“场景光色与影调基线”＋资产/空间＋详细G单元”。严格执行当前合同的标题、栏目、顺序和层级；G单元、时间线及自然语言台词格式保留，不为脚本加入U编号、JSON原文行或无配乐全局声音栏。
4. 配乐开启时完整读取 [配乐设计](references/music-design.md)；关闭时跳过。先沿用导演方案中的人物与情绪判断，再设计音乐。
5. 专项困难才读取 [创作工具箱](references/creative-toolkit.md) 对应章节；想找表达机制时读取 [机制示例](references/craft-examples.md) 对应案例。不要每场加载整库。示例未经过用户认可或成片验证，不称为成功案例。

长文件优先用 [分段读取脚本](scripts/read_text.py)：`python3 <技能目录>/scripts/read_text.py <文件路径>`。每次只输出一段原文（默认不超过6000字符、100行），带文件SHA256、段号与行号/字符范围；依输出的 `NEXT` 命令读到末段，续读会核对版本。尽量在段落或行尾切分，超长单行按字符拆分并标明行内边界，不摘要、不删减。工具仍截断时减小 `--max-chars` 重读；预算变化后段号会重排，须从第1段重新确认覆盖。脚本只证明输出范围，不证明已读或已理解；完整读取条件仍按上列规则执行，不因哈希未变或到达末段而自动跳过必读内容。脚本不可用时按行分段读取。

用户当前明确要求与冻结事实优先；本入口确定开关与执行机制，共同导演规范定义创作和输出，配乐模块仅在开启范围生效，专项与示例只补方法；正式格式以本次选定的当前输出合同为准。用户明确要求仅按另一份独立 MD 时按其执行，不将本技能模板或检查格式强加进去。用户明确要求结合多份资料时，先解决冲突后统一执行。本技能自足，不调用，不要求安装其他分镜技能。

## 配置：不为默认项中断任务

- `music` 默认 `on`。用户说“不要配乐／无BGM／配乐关闭”则设 `off`；“配乐开启／加BGM”设 `on`。“不要人声配乐／纯音乐”只限制音乐人声，不取消人物对白。
- 作用范围按用户明确的全剧、场景、单元或时间段记录；“这场不配乐”只覆盖本场，下一场恢复项目设置。全局明确关闭后在同一项目持续关闭，直到用户改口；新项目无明确说明重新默认开启。模糊“这里静一点”优先作局部让位，不擅自关掉全剧音乐。
- `off` 只关闭非叙事背景音乐设计：不输出背景主题、编配或逐镜配乐行。剧本原有歌唱、演奏、播放设备声等叙事声源仍保留。音效、拟音、环境、人声与声音桥始终按需设计。
- `on` 不等于全程有乐；有因停奏需写恢复触发或场末结束。对白中可以进入与发展音乐，以实际咬字、关键表演与声音证据可听为准。
- 默认忠实导演模式，台词、OS、OV、归属与顺序逐字保留；改编只放宽用户明确授权部分。小说转分场不自动获得改编授权。
- 默认平台写 Seedance 2.5（本技能设计默认，不是已核实的产品能力声明）；默认**生成单元编排上限35秒**，实际入口限制与用户要求优先，取可用上限。成片镜头不设机械35秒上限，长镜可分单元但必须设计接缝。不得继承旧技能的30秒单镜限制。
- 画幅和风格沿用用户/资产；普通缺项用相容的导演选择并标为本次设计。关键身份、知情、台词归属、能力、胜负等歧义集中询问，其余工作继续。人物外观缺少依据时不补造服装、发型、年龄等信息。

## 首稿工作流

`读全稿与锁事实 → 建立/恢复项目记录 → 整集观看与本场导演决定 → 节拍和镜头组 → 镜头与时间预算 → 生成单元编译 → 场末统一复审与定向修复 → 写入主稿与状态 → 授权范围完成后整集跨场复核、原文格式与程序核对及定向修复 → 交付`

### 一份导演决定供所有栏目使用

根据当前剧情和用户要求，先确定本段主要让观众产生什么感受，再联合设计表演、摄影、环境、声音和节奏。不使用固定的情绪清单，也不把整部作品的题材套到每一场；同一场可以包含多种感受，按剧情明确主次与转换。把这种感受的积累、变化和兑现落实到实际时间线，不只写感受标签；平静或持续同一感受也可以成立，不强造转折，不新增剧情来凑效果。

从源稿中提取真正存在的期待、人物欲望/顾虑与应对、观众知情、变化与结果，同时辨明原稿明确的情绪性质、主次、强度变化与关系意味；事实和导演解释分开。转换成分镜时，为这些内容找到可见可听的对应过程，不能只保留事件和台词，却无依据地把情绪改轻、改冷或转成另一种感受。只记录会影响当前设计的结论与简短出处，不交付推理过程。记录归属统一遵循[最小记录规则](references/execution-workflow.md#1-一次取源与最小记录)：同一决定只存一处，其余位置引用定位，不在分析、状态和复审中复写。先建立整场观看过程和镜头组职责，不从输出栏目、平台时长或镜数倒造剧情。

关键节点在初稿就落实具体过程：观众等待什么，人物怎样处理，何处命中，镜头和声音怎样让人读到，结果由谁或什么承受。源稿缺少冲突时从过程、关系、发现、喜剧时机或触感寻找收益，不自行新增危险、秘密、反转或决定性选择。

### 关键节点做实质选择，成立后停止搜索

开场、主峰、重要揭示与关系转折在确有不同观看收益时比较两种非同构机制；比较须落实为当前场景的注意起点、摄影与主体的距离/运动关系、构图变化及读取/切换时机，不只比较方案标签。区别可为同框关系与听者承受、连续过程与证据切入、近距离体验与空间后果等，不能只是换焦段或运镜名称。普通镜已有方案能兑现本段表达目标时直接展开，有具体表现缺口或实际不确定性才比较；摄影展开与完成标准统一按共同规范4.2执行。

选择依据为人物专属性、观众理解/情绪兑现、题材收益与空间时间可执行性；不混合所有候选。 已有分镜时，先识别本次改动范围中值得保留的持续承受、同框关系、主观压迫、动作动势或沉默张力；保留实际观看收益，不冻结初稿拍法。新稿更清楚、更短或细节更多，不单独构成升级依据。只保存采用案、简短理由和依赖。方案既可执行、又已具体兑现本段表达目标后进入成稿；清楚交代事实不单独构成摄影表达完成。出现具体表现缺口、来源反证或执行冲突时重开相关部分，不因存在其他可能拍法而反复比较。

### 先导演化，再编译栏目

人物表演、对白、摄影、光影、材质、环境声、配乐共用同一判断；编译不能分别重解释人物。成镜前按[联合视觉设计合同](references/visual-design-contract.md)形成连续可观看的画面，再同步展开镜头组并编入现有栏目；各适用维度的设计责任、组合自由、编译保真与返修标准只在该合同集中定义，不另交分析表。关键情绪先按共同规范3.1“情绪改变行动”落实人物正在做什么、情绪怎样影响其处理方式与仍有效的残留，再展开微表情；没有阻力不强造受阻。用动作/话语行动、空间、取景、可听变化与切点形成过程，不能以“深情、爆燃、电影感”代替。

普通镜同样精准，但无需每镜完整心理弧、每人每句反应、每秒微动作或全景别配额。关键表演看不清时修取景或承载方式，不靠增加文字冒充可见。全部镜头按共同规范4.1检查给定机位能否实际看见所写内容及运动全程是否可达；对本镜提及但明确留在画外的人物、手部、物品或声源，须写明“不出镜”及必要画外方位，不能只写看向/对话对象后让模型推定入画；拍不到时调整未锁定的机位/构图、切镜或连续移镜，非必要细节可不在本镜拍摄，关键过程须转移承载而不能删掉。涉及脸、持物手与道具时，核对实际高度、裁切、遮挡与焦点；近景/特写不自动包含腰侧或下垂手中的物品，不为同框擅自抬手、换手或改姿态。绝对方位与屏幕左右冲突时用创作工具箱的平面投影核算；改景别或机位须同步相关场景摄影规则、场景空间、摄影栏、时间窗与起落，不能只改一个栏目。人物、环境、光影和动作按实际条件响应；动作接触与结果不能为规避生成风险省掉。

效率来自决定共用、对白索引、只更新变化、按场写入和局部复验。用户说“快一点”不自动减少表演精度、音乐设计或后半段细节。按实际竞争决定时间窗，不填满35秒；未经音频实测只称自然语义估时，不能声称完成真人或音频试读。

### 视觉编写统一执行口径

- **归属与输入边界：** 项目头只写跨场视觉风格与成像/资产保护原则；具体空间摄影、灯具、光向和色彩放在每场“场景摄影规则”“场景光色与影调基线”。每场基线写完整，不指向上一房间。场景头＋本场G单元须有可独立使用的本场视觉依据；单独G投喂包另带必要项目规则与本场上下文，不默认每G重抄全场。输出顺序以当前合同为准。
- **光影、景深与质感：** 细则统一由共同规范4.1“实体场景环境可辨识”和4.3负责。普通单人近景优先胸上取景，面部特写保留原占幅，两类优先中等景深；局部特写、焦外、侧背、隐藏身份和用户锁定拍法按实际需要处理。光影写有效光源、塑形与人景亮暗，质感写高光暗部和材质结果，不把清晰写成平光、全场等亮或全画面锐化。
- **色温与状态：** 场景基线写本场实际光色；每G光影栏用短句写当前有效主光的色温设计区间与冷暖读法，不重复整套基线。区分光源色温、摄影白平衡与最终观感，数字不代替布光；已有锁定单值、纯色光和无有效照明按4.3例外处理。停电、来电和手机光由当镜事件更新并传递到后镜，不被场景常态覆盖。
- **参考理解：** 参考板先区分影调、色彩、布光与成像材质；保留用户要求的画面效果，核对板中文字、参数与示例是否一致，不将含糊标注自动视为用户冻结条件。具体处理统一按共同规范1节与4.3节执行。
- **参考转译与交付：** 只供分析、未交给生成端的参考图须转译为自足的光色、质感与构图文字；确实附带并关联的素材才用@标识，不虚构上传或图号。正文不以“参考图、延续基线、保持电影感”替代实际描述。仅作环境修订时保留台词、动作、时长和未授权改动项，适用例外与修改范围按共同规范执行；不要求重做资产或逐人首帧。

### 复审只修具体问题

每场完成后立即进行一轮统一创作复审、定向修复并按场写入，记录一次完成位置后进入下一场，不集中拖到全文写完才检查。整集完成后沿用已通过的场内结果，专门复核跨场期待、人物辨认、主峰位置、母题变化、拍法重复和集尾收益，再核对原文格式并运行程序，不把尚未生成的后场台词当作漏词。程序发现问题只修对应项并复验；整集跨场检查不重复场内分析，也不能被“只做局部复验”跳过。以镜号/时间窗和具体画面或声音定位：事实台词、期待兑现、人物/关系、可见性、物理/连续、节奏与配乐是否共同成立。机械通过不等于创作通过；内部方案成立也不等于正文已经写出。

复审先核对分镜传达的情绪方向、强度变化和关系意味是否符合可靠来源，再检查观众感受的积累、变化与兑现；不能因为剧情和动作正确就认为表达已经完成。不能因避免夸张、拖沓或抢戏，就削弱原稿已经明确的情绪力度；也不能为了浓烈而擅自放大。文学比喻不必按字面复刻，但应找到相称的表演与视听表达。发现偏移先修理解，发现力度不足再修表现。 对实际改动的关键镜头组，连同必要接点核对新增的清晰度是否损失情绪积累、连续共处或摄影作用，操作步骤是否抢走关系与问题的重心；有损失就修对应段，不把新旧拍法全部叠加。此项并入本轮复审，不新增整集比较、评分或记录。发现感受未成立、同义反应、重复慢推、通用情绪、抢拍笑点、关系结果缺失或关键动作不可读时，修相应根因。表演模板化须回到当前人物的动机与处境，调整其处理任务、接触或话语的过程，不以轮换微动作掩盖。只复查改动、必要接缝与实际依赖；影响全场节奏或跨场状态才扩大。没有具体失败即结束，不额外加一轮“全面优化”。复审仍实际执行，记录只留具体问题、镜号/时间窗、修复及复验结果；无问题只记一次完成标记，不逐镜重抄通过理由。

### 文件交付与恢复

有文件能力时默认在用户工作区 `outputs/<作品名>/` 保存 `作品名_分镜_时长.md`，在其 `.storyboard/` 保存工作记录、台词来源索引和核对报告；不得覆盖输入或同步 sources 文件。现有成稿仅在用户要求更新该稿时原位编辑，否则创建不冲突文件名。

主稿严格采用当前配乐开关对应的输出合同：项目共用视觉规则＋各场摄影/光色基线与资产/空间＋详细G单元。复制当前场景头与其G单元即可获得本场视觉依据，不需要用户从章节全局删除其他房间的光色；独立G投喂包再带齐项目必要规则与本场上下文，不携带其他场景布光。若只要求局部或聊天输出，完成其范围；无文件能力用精简续接摘要，不声称跨会话自动记忆。

用户要求整集/全文时连续完成授权范围，只有明确要求逐场确认才等待。最终简短说明完成范围、music状态、文件和实际验证层级；资产缺失时明确未锁定，未执行动态预演/生成/混音时不声称成片已验证。

| 人物同质、表演平、关系压力/释放、多阶段受话 | 创作工具箱“人物与声音”“复杂关系”；人物化过程与结果成立即停 |
| 通用反打、连续慢推、用户提供拍法、构图读不清 | 创作工具箱“摄影与观看”；确定观看机制、可见面与路径即停 |

| 递接/换手、多人交错、追逐 | 创作工具箱“动作与连续”；接触、作用与结果能承接即停 |

# 制作分镜

面向首稿即可进入制作审阅的导演分镜。以 S+ 爆款为创作目标，通过具体观看收益、人物专属性、节奏和制作可执行性提高首稿完成度；不得承诺一次生成必达 S+、爆款或无瑕疵。名称 `creating-storyborads` 为用户指定，保持该拼写。

## 规范与读取

1. 首次执行、新会话、上下文压缩后无法确认全文仍可用，或规范版本变化时，**完整读取** [共同导演规范](references/director-standard.md) 与 [执行、状态与程序核对](references/execution-workflow.md)。工具输出截断时按行分段补齐，不能把路径、摘要或检索命中当作全文。版本 1.1.0。
2. 当前会话已完整读取且版本未变，续接只读取工作记录、当前场来源与必要相邻接点；出现来源反证再定向回读。全文件约束持续有效。
3. 正式编译前必须按实际配乐范围完整读取唯一输出合同：有开启范围用 [配乐版格式](references/output-music.md)，全部关闭用 [细节版格式](references/output-detail.md)。二者原样摘自对应源MD第6章，严格沿用标题、栏目名、顺序、层级、时间线和台词自然语言要求；不得为了脚本加入U编号、JSON原文行、无配乐全局声音栏或其他自创结构。
4. 配乐开启时完整读取 [配乐设计](references/music-design.md)；关闭时跳过。先沿用导演方案中的人物与情绪判断，再设计音乐。
5. 专项困难才读取 [创作工具箱](references/creative-toolkit.md) 对应章节；想找表达机制时读取 [机制示例](references/craft-examples.md) 对应案例。不要每场加载整库。示例未经过用户认可或成片验证，不称为成功案例。

用户当前明确要求与冻结事实优先；本入口确定开关与执行机制，共同导演规范定义创作和输出，配乐模块仅在开启范围生效，专项与示例只补方法；正式格式以本次选定的原文第6章为准。用户明确要求仅按另一份独立 MD 时按其执行，不将本技能模板或检查格式强加进去。用户明确要求结合多份资料时，先解决冲突后统一执行。本技能自足，不调用旧即梦技能入口，也不要求安装其他分镜技能。

## 配置：不为默认项中断任务

- `music` 默认 `on`。用户说“不要配乐／无BGM／配乐关闭”则设 `off`；“配乐开启／加BGM”设 `on`。“不要人声配乐／纯音乐”只限制音乐人声，不取消人物对白。
- 作用范围按用户明确的全剧、场景、单元或时间段记录；“这场不配乐”只覆盖本场，下一场恢复项目设置。全局明确关闭后在同一项目持续关闭，直到用户改口；新项目无明确说明重新默认开启。模糊“这里静一点”优先作局部让位，不擅自关掉全剧音乐。
- `off` 只关闭非叙事背景音乐设计：不输出背景主题、编配或逐镜配乐行。剧本原有歌唱、演奏、播放设备声等叙事声源仍保留。音效、拟音、环境、人声与声音桥始终按需设计。
- `on` 不等于全程有乐；有因停奏需写恢复触发或场末结束。对白中可以进入与发展音乐，以实际咬字、关键表演与声音证据可听为准。
- 默认忠实导演模式，台词、OS、OV、归属与顺序逐字保留；改编只放宽用户明确授权部分。小说转分场不自动获得改编授权。
- 默认平台写 Seedance 2.5（本技能设计默认，不是已核实的产品能力声明）；默认**生成单元编排上限35秒**，实际入口限制与用户要求优先，取可用上限。成片镜头不设机械35秒上限，长镜可分单元但必须设计接缝。不得继承旧技能的30秒单镜限制。
- 画幅和风格沿用用户/资产；普通缺项用相容的导演选择并标为本次设计。关键身份、知情、台词归属、能力、胜负等歧义集中询问，其余工作继续。人物外观缺少依据时不补造服装、发型、年龄等信息。

## 首稿工作流

`读全稿与锁事实 → 建立/恢复项目记录 → 整集观看与本场导演决定 → 节拍和镜头组 → 镜头与时间预算 → 生成单元编译 → 场末统一复审与定向修复 → 写入主稿与状态 → 授权范围完成后整集跨场复核、原文格式与程序核对及定向修复 → 交付`

### 一份导演决定供所有栏目使用

从源稿中提取真正存在的期待、人物欲望/顾虑与应对、观众知情、变化与结果；事实和导演解释分开。只记录会影响当前设计的结论与简短出处，不交付推理过程。先建立整场观看过程和镜头组职责，不从输出栏目、平台时长或镜数倒造剧情。

关键节点在初稿就落实具体过程：观众等待什么，人物怎样处理，何处命中，镜头和声音怎样让人读到，结果由谁或什么承受。源稿缺少冲突时从过程、关系、发现、喜剧时机或触感寻找收益，不自行新增危险、秘密、反转或决定性选择。

### 关键节点做实质选择，成立后停止搜索

开场、主峰、重要揭示与关系转折在确有不同观看收益时比较两种非同构机制；普通镜已有方案成立直接展开，存在实际不确定性才比较。区别应是同框关系与听者承受、连续过程与证据切入、近距离体验与空间后果等，不能只是换焦段或运镜名称。

选择依据为人物专属性、观众理解/情绪兑现、题材收益与空间时间可执行性；不混合所有候选。只保存采用案、简短理由和依赖。方案成立后进入成稿，仅当出现具体反证、表达失败或执行冲突时重开。

### 先导演化，再编译栏目

人物表演、对白、摄影、光影、材质、环境声、配乐共用同一判断；编译不能分别重解释人物。用动作/话语行动、空间、取景、可听变化与切点形成过程，不能以“深情、爆燃、电影感”代替。

普通镜同样精准，但无需每镜完整心理弧、每人每句反应、每秒微动作或全景别配额。关键表演看不清时修取景或承载方式，不靠增加文字冒充可见。绝对方位与屏幕左右冲突时用创作工具箱的平面投影核算；改景别或机位须同步相关全局声明、场景空间、摄影栏、时间窗与起落，不能只改一个栏目。人物、环境、光影和动作按实际条件响应；动作接触与结果不能为规避生成风险省掉。

效率来自决定共用、对白索引、只更新变化、按场写入和局部复验。用户说“快一点”不自动减少表演精度、音乐设计或后半段细节。按实际竞争决定时间窗，不填满35秒；未经音频实测只称自然语义估时，不能声称完成真人或音频试读。

### 复审只修具体问题

每场一轮统一创作复审；整集完成后沿用已通过的场内结果，专门复核跨场期待、人物辨认、主峰位置、母题变化、拍法重复和集尾收益，再核对原文格式并运行程序，不把尚未生成的后场台词当作漏词。程序发现问题只修对应项并复验；整集跨场检查不重复场内分析，也不能被“只做局部复验”跳过。以镜号/时间窗和具体画面或声音定位：事实台词、期待兑现、人物/关系、可见性、物理/连续、节奏与配乐是否共同成立。机械通过不等于创作通过；内部方案成立也不等于正文已经写出。

发现同义反应、重复慢推、通用情绪、抢拍笑点、关系结果缺失或关键动作不可读时，修相应根因。只复查改动、必要接缝与实际依赖；影响全场节奏或跨场状态才扩大。没有具体失败即结束，不额外加一轮“全面优化”。

### 文件交付与恢复

有文件能力时默认在用户工作区 `outputs/<作品名>/` 保存 `作品名_分镜_时长.md`，在其 `.storyboard/` 保存工作记录、台词来源索引和核对报告；不得覆盖输入或同步 sources 文件。现有成稿仅在用户要求更新该稿时原位编辑，否则创建不冲突文件名。

主稿严格采用本次配乐开关对应的原MD第6章：全局规则＋各场资产/空间＋详细G单元；只有用户要求单独投喂包才带齐适用全局上下文，不默认每单元重抄全局。若只要求局部或聊天输出，完成其范围；无文件能力用精简续接摘要，不声称跨会话自动记忆。

用户要求整集/全文时连续完成授权范围，只有明确要求逐场确认才等待。最终简短说明完成范围、music状态、文件和实际验证层级；资产缺失时明确未锁定，未执行动态预演/生成/混音时不声称成片已验证。

## 创作专项索引

| 具体问题 | 读取位置与停止条件 |
|---|---|
| 人物同质、表演平、关系压力/释放、多阶段受话 | 创作工具箱“人物与声音”“复杂关系”；人物化过程与结果成立即停 |
| 通用反打、连续慢推、用户提供拍法、构图读不清 | 创作工具箱“摄影与观看”；确定观看机制、可见面与路径即停 |
| 喜剧抢拍、悬疑泄底、工序/奇观只有形容词 | 创作工具箱“题材兑现”；因果与观看收益落实即停 |
| 递接/换手、多人交错、追逐 | 创作工具箱“动作与连续”；接触、作用与结果能承接即停 |
| 连续攻防、大型主体、术法或主效峰值 | [大型动作与特效](references/action-vfx-design.md)；战术、尺度、分层、峰值与余波落实即停 |
| 重复工序压缩、并行对照、连续证据片段 | [蒙太奇组织](references/montage-transition.md)“蒙太奇”；每片段职责、时空与出入口成立即停 |
| 明确转场、跨场声画或情绪承接 | [转场设计](references/montage-transition.md)“转场”；双端锚点和声音/状态接力落实即停 |
| 参考图、多视图、PDF或资产文件夹 | 创作工具箱“素材读取与空间映射”；实际读图、地点/版本归组与镜头可达性确认即停 |
| 台词、动作、反应争时长 | 创作工具箱“时间预算”；得到自然且可读的编排即停 |
| 掩饰、错位喜剧、证据揭示等需要机制启发 | 机制示例对应案例；只迁移条件与选择依据，不复刻人物、道具、秒数 |

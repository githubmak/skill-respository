# 2560×1440 版式规范

本规范用于把参考图的内容层级重排为原生 16:9 画板。版面可按题材改变装饰语言，但不得改变两张图各自承担的内容职责。

## 共同规格

- 画布：2560×1440 px，RGB，PNG，横版 16:9。
- 安全边距：四周 44–64 px；所有正文、HEX 值和标签留在安全区内。
- 视觉层级：主标题 > 分区标题 > 卡片标题 > 说明文字 > 辅助标注。
- 建议字号：主标题 72–92 px，副标题 28–38 px，分区标题 30–40 px，卡片标题 24–32 px，正文与 HEX 值 18–25 px；根据字体实际字面大小微调。
- 优先使用当前系统可用、字形完整的中文字体；标题可使用与题材相符的展示字体，正文使用高可读黑体或宋体。字体缺字时立即更换，不用乱码占位。
- 采用模块化网格与统一圆角、描边、间距。背景可带低对比度纹理或项目意象，但不能干扰文字和色块判断。
- 代表画面统一长宽比、裁切逻辑和美术风格。画面上不直接生成正文文字，文字由排版层添加。
- 不复制模板中的剧名、印章、英文副题、山水装饰或固定栏目数量；根据用户项目重新设计。

## 全剧色卡图

推荐自上而下分为四层：

1. **标题与项目气质区（约 13% 高度）**：项目名、`全剧色卡`、一句色彩总纲，可加入与项目相关的低对比度装饰意象。
2. **核心母色与比例区（约 23%）**：左侧或主体区域放 6–8 个核心色块，标注色名、HEX、功能；右侧放主色/辅助色/强调色比例与 4–6 条色彩原则。
3. **场景衍生色区（约 38%）**：放 3–5 张横向场景卡。每张包含代表画面、4–6 个色块、HEX 值、场景名与关键词。场景卡应共同覆盖整剧主要视觉状态。
4. **功能与落地参考区（约 20%）**：包含服装/道具/材质功能色、肤色保护参考、关键材质缩略图和适用场景标签。信息过多时宁可减少重复标签，也不压缩到不可读。

色卡图必须能回答：整剧是什么颜色、颜色如何分配、不同场景如何变化、人物肤色如何保护、材质和道具如何落地。

## 全剧影调图

推荐自上而下分为四层：

1. **标题与总述区（约 12% 高度）**：项目名、`全剧影调与光影风格`、一句光影总纲。
2. **光影弧线区（约 10%）**：用一条连续时间轴呈现 3–5 个剧情阶段的亮度、冷暖、反差或饱和度变化；阶段名称来自内容，不照搬模板。
3. **典型场景影调区（约 52%）**：推荐 4–5 列、2 行，共 8–10 张场景卡。每卡包含代表画面、场景名、关键词、4–6 个取样色块和一句影调说明。每张场景卡至少体现一项独特的光线条件或情绪任务。
4. **人物与执行规则区（约 20%）**：人物光影示例 4–6 张，并列说明全剧光影关键特征、常用光影元素和氛围关键词。

影调图必须能回答：整剧光线怎样变化、典型场景怎样曝光和打光、人物如何保持肤色与身份、摄影与后期应遵守哪些统一规则。

## 画面与文字的分工

- 生成图负责世界观、环境、人物和光线示意；排版层负责所有准确文字、色值、比例、箭头和分区边界。
- 色块必须以标注 HEX 的真实填充色绘制，不能从示意图截图近似取色后再写另一个数值。
- 小尺寸代表图优先展示清楚的光线和空间关系，不塞入多人群像或难辨识细节。
- 项目若无人物资料，人物光影可用不具身份指向的轮廓、局部或人物类型示意，但不得冒充已确定角色。

## 可变风格

版式骨架保持专业视觉圣经感，装饰语言随题材变化：古装可用纸张、纹样和器物结构；现代都市可用简洁网格和建筑线条；科幻可用界面化坐标与材质样本；悬疑可加强留白、暗部和冷暖警示。装饰风格不得压过色彩与影调信息本身。

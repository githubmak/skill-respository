# 色卡影调设计skill

把用户提供的叙事内容转化为整剧统一的色彩、影调和光影视觉规范。最终交付必须是两张不同的图片，不把色卡与影调合并在同一张图中。

## 内容输入门槛

开始设计前，先确认用户是否提供了至少一种可分析内容：

- 剧本、小说正文或明确的剧情片段；
- 故事梗概、分集大纲、人物与世界观设定；
- 分镜脚本、场景清单或其他能判断题材、情绪和场景变化的文本；
- 含上述内容且当前可读取的附件。

仅有“帮我设计色卡/影调”、剧名、类型标签、参考风格图或零散形容词，不算已经提供剧情内容。若没有可分析内容、附件无法读取或内容为空，立即停止，不生成通用模板、不自行编写剧情，只输出：

```markdown
开始色卡与影调设计前，还需要你提供可分析的整剧内容。

请发送或上传以下任意一种：剧本、小说正文、故事梗概、分集大纲、人物与世界观设定、分镜脚本或场景清单。收到内容后，我会分别生成一张 2560×1440 的全剧色卡 PNG 和一张 2560×1440 的全剧影调 PNG。
```

用户补充后仍无有效内容时，继续只提示补充。只要内容足以判断核心题材、情绪走向和主要场景，就直接执行；剧名、平台、画风等非必要信息可以合理推导，不逐项追问。若用户明确给出视觉风格、品牌色、禁用色或平台要求，优先遵守。

## 固定交付

必须同时交付：

1. `全剧色卡.png`：2560×1440，展示整剧核心母色、场景衍生色、比例、功能色、肤色与材质关系；
2. `全剧影调.png`：2560×1440，展示整剧情绪光影弧线、典型场景影调、人物光影、光影规律与氛围关键词。

两张图均使用 RGB、PNG 格式，横版 16:9。用户指定项目名时，推荐命名为 `{项目名}_全剧色卡.png` 与 `{项目名}_全剧影调.png`。不得只交付提示词、文字方案、合并长图、网页、SVG 或编辑源文件来代替两张 PNG。

## 文件输出边界

- 用户指定输出目录时优先使用；未指定时写入当前工作区的 `outputs/`，不写入系统目录或用户主目录。
- 不覆盖原始输入或同名已有文件；同名时使用递增版本名。
- 文件名去除换行及 `/`、`\\`、`:`、`*`、`?`、`"`、`<`、`>`、`|` 等非法字符。
- 只写入本次请求明确需要的两张 PNG；完成后返回绝对路径、像素尺寸和格式验收结果。

## 设计流程

### 1. 提取整剧视觉依据

从用户内容中提取并统一：

- 题材、时代、地域、世界规则与美术风格；
- 主冲突、主题、情绪曲线、阶段性转折与结局余韵；
- 高频场景、标志性空间、昼夜季节、天气与自然环境；
- 主要人物阵营、服装材质、肤色保护需求、关键道具与视觉特效；
- 暖冷关系、明暗关系、饱和度、反差、黑位、雾度和主光方向。

不得为了填满版面虚构关键剧情。内容未明确的细节只做与题材相容的最低限度视觉推导，并保持全剧逻辑一致。

### 2. 建立全剧色彩圣经

先确定统一母色，再建立场景衍生色和功能色：

- 核心母色通常 6–8 个，每个包含中文色名、准确 HEX 值、视觉功能和适用情绪；
- 场景衍生体系通常 3–5 组，每组包含代表画面、4–6 个色块、HEX 值、场景说明和关键词；
- 明确主色、辅助色、强调色的建议比例，总和为 100%；
- 补充服装、道具、材质、肤色保护和特殊元素用色；
- 色彩随剧情阶段变化，但必须能追溯到同一母色体系，避免每场戏像不同项目。

### 3. 建立全剧影调与光影弧线

把剧情阶段转化为一条可见的光影演变轴，例如“建立—升温—压迫—决战—余韵”，阶段数量按内容决定，不套固定剧情词。再选择最能覆盖整剧差异的典型场景：

- 典型影调通常 8–10 组，覆盖日/夜、内/外、平静/冲突、现实/幻境或其他核心对比；
- 每组包含代表画面、色温、亮度、反差、饱和度、黑位、主光方向和氛围说明；
- 人物光影示例通常 4–6 组，说明肤色保护、轮廓光、眼神光、环境染色与情绪作用；
- 统一光影原则、常用视觉元素和整剧氛围关键词，确保连续场景可执行。

### 4. 生成与合成

- 代表场景、人物光影或材质缩略图属于视觉素材，可使用内置图像生成工具制作；每张素材都要服从同一剧集世界、画风、角色身份和色彩体系。
- 所有标题、说明、色名、HEX 值和比例必须通过确定性排版方式合成到最终画板，例如 HTML/CSS、SVG/Canvas 或 Pillow；不要依赖图像模型直接绘制大量中文文字。
- 先完成色彩与影调逻辑，再生成示意图；不要让偶然生成的示意图反向决定整剧规则。
- 保持中文可读、层级清楚、文字与背景有足够对比；不添加水印、无关 Logo、乱码或伪文字。
- 若使用用户提供的视觉参考，先区分其用途是人物、场景、材质、风格还是构图参考；只继承用户要求的部分。

### 5. 尺寸与质量验收

保存后逐张检查：

- 像素尺寸必须精确为 2560×1440；不符时重新按 16:9 排版或无损重渲染，不拉伸文字和图像；
- 两张图必须是不同文件，标题和内容职责不能互换；
- 色卡中的色块颜色与标注 HEX 一致，比例总和为 100%；
- 影调卡能看出亮度、反差、色温和情绪差异，不只是换色滤镜；
- 剧情阶段、典型场景和人物光影均有用户内容依据；
- 中文无乱码、重叠、截断、溢出或过小难读；
- 全剧视觉统一，同时保留关键场景应有的变化。

未通过检查的图片不得标为最终交付。若工具输出分辨率不精确，必须完成最终尺寸处理并再次读取像素尺寸确认。

## 最终回复

用最少文字展示两张已验收图片并提供各自文件链接，注明均为 2560×1440 PNG。可附 2–4 句概括核心母色、影调弧线和关键设计依据；不要把长篇分析重复贴到聊天中。

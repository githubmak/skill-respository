# STYLE MASTER视觉DNA

收到用户选定的母版图片后，先检查它们是否属于同一视觉体系。若人物比例、渲染媒介、基础色调、材质模型或光影逻辑互相冲突，指出冲突并要求用户缩小选择，不能把不相容图片平均成模糊风格。

## 提取字段

```markdown
# STYLE_BIBLE_V1

状态：待确认或已锁定
来源：原著范围与用户选定母版图

- 视觉类型：
- 写实程度：
- 人物艺术化程度：
- 主要环境色：
- 辅助色与强调色：
- 饱和度与明度：
- 主要材质：
- 光源类型与方向：
- 阴影颜色与对比度：
- 空气介质：
- 反射与微表面：
- 空间纵深与细节密度：
- 人物与环境融合方式：
- 整体审美气质：

## 必须继承
- 可跨场景复用的风格规则。

## 禁止复制
- 母版中的具体建筑、人物、道具、构图、入口、台阶、云海和空间拓扑。

## 局部状态变量
- 天气、火光、血迹、损毁、节庆或室内光线等不会改写基础风格的变量。

## 负面风格项
- 与本项目冲突的媒介、色彩、材质、人物比例、曝光和空间表现。
```

## 提取原则

- 图片决定具体美术呈现，原著决定覆盖范围和叙事适配性。
- 把“风格”与“图中内容”分开描述。
- 不把单张图片的偶然色偏、构图、天气或特殊特效误判为全剧硬规则。
- 不能仅凭文字提示词声称完成了基于图片的视觉DNA提取。
- 用户确认前标记为`待确认`；确认后才建立或升级版本号。

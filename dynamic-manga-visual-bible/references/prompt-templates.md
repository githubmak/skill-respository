# 平台提示词模板

## Midjourney风格测试

每个测试主体单独一条。提示词结构：

```text
风格类型 + 写实程度 + 关键色彩 + 关键材质 + 光影与空气 + 当前测试主体 + 极短负面约束 + MJ参数
```

不要加入完整剧情梗概、角色小传、长篇制作规范、场景连续性规则或多个测试主体。交付前用`../scripts/count_prompt_chars.py`计数；每条不超过1024字符，建议850至950字符。

## GPT Image场景

```text
将上传图片作为项目的STYLE_MASTER，只继承视觉风格、渲染方式、写实程度、综合色彩、光影逻辑、材质表现、空气透视、细节密度和整体美学气质。不要复制STYLE_MASTER中的具体建筑、人物、构图、道具或空间结构。

【STYLE_MASTER视觉DNA】
视觉类型：...
写实程度：...
主要环境色：...
辅助色与强调色：...
主要材质：...
光影逻辑：...
空气与环境介质：...
整体气质：...

【当前SET_MASTER与场景状态】
空间结构与固定物：...
时间、天气与实际光源：...

【新场景描述】
场景内容、空间关系和观察位置：...

【负面约束】
列出与当前项目确有冲突的项目；不要无差别堆砌通用负面词。
```

## GPT Image人物进入场景

```text
STYLE_MASTER视觉DNA
+ 当前CHARACTER_FACTS中的身份与造型事实
+ 当前SET_MASTER和实际场景光源
+ 当前动作、表情、视线与构图
```

`CHARACTER_FACTS`只使用原著和用户确认的文字设定，包括身份、脸型、五官比例、发型发色、身体比例、服装结构、纹样位置、固定配饰和整体气质。最终人物必须接受场景色温、阴影方向、接触阴影和环境反射。

## Seedance视频

```text
以@图片1为全剧STYLE_MASTER，继承【动画风词】【视觉风格词】。不要复制图1中的具体建筑、构图、人物、道具和空间布局。人物与环境处于同一光照空间，接受当前场景实际光源，保持一致的曝光、色温、阴影方向、接触阴影、环境反射和材质质感。禁止棚拍白光、白底抠图感和人物贴图感。

【全局核心要求】
严格执行分镜中的动作、表情、视线、节奏、对白与音效；镜头衔接自然。画面不出现字幕、说明文字、浮字、水印、logo、分镜编号或额外图形。除非用户要求，不额外添加背景音乐。

【人物文字事实】
根据CHARACTER_FACTS呈现角色身份、脸型、五官比例、眼鼻唇形、发型发色、身体比例、服装结构、纹样位置、固定配饰和整体气质。

【本镜头分镜】
动作：...
表情与视线：...
镜头运动与节奏：...
环境变化：...
对白与音效：...
```

【动画风词】只描述动画媒介和人物表现方式；【视觉风格词】只描述当前STYLE_MASTER提取出的风格DNA。不要在两处重复剧情和镜头动作。

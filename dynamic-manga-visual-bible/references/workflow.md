# 阶段流程与责任人

## 阶段0 项目登记

责任人：用户提供材料，大模型登记。

记录项目名称、原著类型、材料范围、是否完整、批次编号、目标平台、画幅、计划时长、人物文字设定和已存在的场景资产。分批材料必须持续归入同一项目，不得用最后一批覆盖先前结论。

停止条件：材料未完整时，可以继续收集或给出暂定诊断，但不得进入最终风格锁定。

## 阶段1 全剧视觉诊断

责任人：大模型。

扫描完整材料，提取：

1. 故事类型与子类型。
2. 长期核心情绪和审美气质。
3. 时代、世界观、地域、势力、建筑、自然环境和能力体系。
4. 主要人物共同审美与差异化需求。
5. 重复出现的颜色、材质、光源、纹样、道具和空间母题。
6. 大场面、动作、对白、情绪特写、恐怖诡异和喜感场面的比例。
7. 时间、天气、季节和剧情状态变化范围。
8. 目标受众和平台观看气质。
9. 适合的写实度、人物美型度、材质复杂度和动作可执行性。

据此提出2至3套差异清楚、都能覆盖全剧的视觉方向。不要只根据某个最抢眼的场景定全剧风格。

## 阶段2 MJ风格母版候选

责任人：大模型写提示词，用户提交Midjourney，Midjourney生成图片，用户选图。

每套方向建议测试：

- 代表全剧气质的主环境。
- 室内或封闭空间。
- 夜景、低光或诡异状态。
- 动作、法术或大场面。

每个测试主体单独生成提示词。候选图用于测试视觉语言，不是最终剧情场景。

暂停条件：交付MJ提示词和选图标准后停止。等待用户回传选定的母版包，不得自动进入视觉DNA提取。

推荐回传包：1张主视觉、1张室内或封闭空间、1张夜景低光、可选1张动作法术。图片必须属于同一视觉体系。

## 阶段3 STYLE_MASTER视觉DNA

责任人：用户回传图片，大模型结合原著提取。

从图片提取可复用风格，不复制具体内容。按[style-dna.md](style-dna.md)输出，并要求用户确认或修改。确认后建立版本号，例如`STYLE_BIBLE_V1`。

停止条件：用户未确认视觉DNA时，不应批量生成后续场景。

## 阶段4 人物事实与场景资产规则

责任人：大模型整理，用户确认关键设定。

建立场景清单和`SET_MASTER`需求，从原著与用户确认的文字设定中登记`CHARACTER_FACTS`，说明每个镜头调用哪些人物事实和场景资产。人物身份与造型来自文字事实，最终光照来自STYLE_MASTER和当前场景。

## 阶段5 生图与视频生产

责任人：大模型组装提示词，目标模型生成结果，用户或制作团队验收。

- GPT Image等图像模型：由`STYLE_MASTER视觉DNA + SET_MASTER空间事实 + 当前场景状态`生成场景；人物进入场景时再叠加`CHARACTER_FACTS`。
- Seedance等视频模型：由`STYLE_MASTER + CHARACTER_FACTS + SHOT_KEYFRAME + 本镜头动作和声音`组装视频提示词。

## 阶段6 统一性测试与批量生产

责任人：大模型制定测试，用户或制作团队选片确认。

至少测试七类场景并按[quality-gates.md](quality-gates.md)验收。修改主色、写实度、人物比例、材质或基础光影逻辑时必须新建版本；同一批镜头不能混用版本。

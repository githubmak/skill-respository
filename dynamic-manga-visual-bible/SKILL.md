# 漫剧全剧视觉圣经

把整部作品的视觉决策固定成可复用、可版本化的生产规则，并明确大模型、Midjourney、用户、图像生成模型和视频生成模型各自负责的环节。

## 工作方式

先判断当前处于哪个阶段，不要在信息不足时跳过需要用户选择或外部生成的节点。完整阶段、责任人和暂停条件见 [references/workflow.md](references/workflow.md)。

1. 登记完整小说、剧本或同一项目的分批材料。
2. 进行全剧视觉诊断，提出2至3套视觉方向。
3. 由大模型编写Midjourney风格测试提示词；交付后暂停，等待用户在MJ生成并回传选定图片。
4. 收到选定母版包后，结合原著提取`STYLE_MASTER`视觉DNA。
5. 建立`SET_MASTER`、`CHARACTER_FACTS`和`SHOT_KEYFRAME`的职责边界，再生成图像与视频提示词。
6. 通过跨场景测试后锁定版本，才进入批量生产。

若用户只提供部分原著，登记批次和缺失范围；可以输出阶段性诊断，但不得把它称为最终全剧风格。若用户明确只要快速概念方案，可给出标注为“暂定”的方向，不得伪装成完成了全书分析。

## 外部生成边界

- Midjourney默认是外部步骤。本技能负责生成MJ提示词，不得声称已经生成MJ候选图。
- 交付MJ提示词后，明确要求用户返回最终选中的1至4张风格一致图片。没有回传图片，不得执行基于图片的视觉DNA提取。
- 若当前环境确有图像生成工具，只有用户明确要求改用该工具时才可替代MJ；需标明替代关系，不得继续称结果为MJ图。
- 从候选图提取DNA时必须同时参考原著。图片决定具体美术表现，原著决定世界观、内容范围和长期叙事需求。

## 三类视觉锚点与人物事实

- `STYLE_MASTER`：锁定全剧画风、写实度、色彩、光影、材质、空气感、空间层次和审美气质；不锁定具体建筑、构图或人物。
- `CHARACTER_FACTS`：只从原著和用户确认的文字设定中登记人物身份、脸型、五官比例、发型、体型、服装结构、纹样、固定配饰及气质。
- `SET_MASTER`：锁定具体地点的空间拓扑、固定物、入口出口、材质尺度、可行动区域和状态连续性。
- `SHOT_KEYFRAME`：锁定单镜头的起始构图、人物和道具位置、动作起点、实际光源及视频运动起点。

不得让一种锚点代替另一种锚点。尤其不得把STYLE_MASTER里的宫殿、台阶、云海或构图复制到所有新场景。

## 必须保持的规则

- 每套MJ提示词不超过1024个Unicode字符，并在交付时标注字符数。建议控制在850至950字符，为平台参数与误差留余量。使用`scripts/count_prompt_chars.py`进行确定性计数。
- 每个测试主体单独一条MJ提示词，同一视觉方向复用同一短版风格前缀，只替换测试主体。
- 大模型提出方向，用户选择最终`STYLE_MASTER`；不得替用户默认选定。
- 人物身份和造型信息只从原著及用户确认的文字设定整理为`CHARACTER_FACTS`。
- 特殊天气、火光、血迹、损毁和室内灯光只能作为局部状态，不能改写全剧基础风格。
- 输出中把事实、建议、暂定项和已锁定项明确分开。
- 没有经过大环境、室内对白、人物全身、人物近景、夜景低光、动作法术、温暖或喜感场面的统一性测试，不得宣布可批量生产。

## 默认交付语言

跟随用户语言。平台提示词可以按用户指定输出中文、英文或双语；未指定时，用中文说明并给出适合目标平台的提示词正文。

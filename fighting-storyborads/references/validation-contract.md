# A/B 校验与编号约定

本页是共用规范的结构校验补充，仅统一编号、时长及映射元信息，不替换四类规范的内容字段。正文按以下标题书写，字段可保留原规范粗体、方括号和引用装饰。

## A 单份导演稿

保留题材规范的全局导演说明，补一行 `导演稿总时长：70秒`（必填，填写实际合计）。每个单元不超过 35 秒，全场可跨多个单元：

```markdown
### 生成单元 G01｜时长：35秒
【镜头 01｜攻防核心镜｜20秒｜视觉母题｜本镜战术意图】
1. 机位、景别与运镜：具体内容
2. 人物调度与专属打法：具体内容
3. 招式与视觉母题：具体内容
4. 动作结果与反馈：具体内容
5. 人物表演细节：具体内容
6. 情绪锚点：具体内容
7. 画面完整描述：具体内容
【镜头 02｜身法/调度镜｜15秒｜视觉母题｜本镜战术意图】
（按题材原名完整填 1–7 项，不使用此占位说明）
```

A 中的生成单元是时长分组标题，不是旧 G 七栏目。镜号全场唯一；单元时长须等于所属镜头合计；35秒只限制生成单元/实际包，不限制成片镜或工程镜。成片长镜超过上限时保留一个镜号及一份完整七项正文，置于分包表之前；随后用生成单元标题列片段映射，不重复七项或新增剪切。

长镜映射例：

```markdown
### 生成单元 G01｜时长：35秒｜承载镜号：01｜成片区间：0—35秒
接缝：35秒时人物、摄影、主效与声音的实际进行状态及续接方式。
### 生成单元 G02｜时长：15秒｜承载镜号：01｜成片区间：35—50秒
接缝：继承同一运动，说明终态，不重演前段。
```

一个映射单元承载一个长镜片段；普通多镜分组仍按上例。各片段按成片时间顺序连续覆盖全镜，合计只计一次镜长。B的完整工程镜同样可超过包上限，实际包按阶段映射并独立描述；无法保住连续设计而需新增剪切时回A修改，不把分包当切镜。

## B 工程稿及投喂包

保留主规范的全局基线、工程字段和可见投喂字段；校验及接续检查内部完成，按共用规范的展示约定执行。实际包的参考资产与接缝等六项检查默认不展示；有真实素材时将引用写入 Prompt。工程镜前加编号映射标题，随后保留原规范的分镜名称/节奏标题与全部工程字段：

```markdown
### 工程镜头 E01｜对应 A 镜号：01｜时长：20秒
【本镜名称｜20秒｜节奏标注】
（全部工程字段，沿用主规范精确字段名）
### 生成单元 G01｜对应 A 镜号：01｜工程镜号：E01｜包时长：20秒
目标：当前动作变化及结果。
投喂 Prompt：完整自然语言，可分行续写。
```

多个编号用逗号列出，不用范围缩写。分包不能重新演完整动作。部分交付时以本批完整 A 源稿片段传给校验器，并在交付说明标明全稿未完；不以通过宣称全部完成。仅工程稿/仅投喂包的范围例外仍有效，当前完整 B 校验器会报告缺少另一板块，此时明确为用户限定范围的人工审读，不伪称完整 B 检查通过。

## 命令与边界

```text
python -X utf8 <SKILL_DIR>/scripts/validate_storyboard.py <A稿.md> --mode a --genre eastern
python -X utf8 <SKILL_DIR>/scripts/validate_storyboard.py <B稿.md> --mode b --genre eastern --source-a <A稿.md>
```

`SKILL_DIR` 使用本技能绝对目录；题材值为 eastern（玄幻）、wuxia（古代）、scifi（科幻）、western（西幻）。`--max-unit-seconds` 可指定更短限制，不能超过 35。旧 units/single/rapid/refined 模式转交历史校验器。

机器检查：按所选题材核对七项名称与工程字段名称、非空目标/Prompt、必填导演稿总时长、正时长、35秒硬上限、单元合计、当前A源稿结构（外部/历史源稿仅核对可识别镜号与明确时长）、映射覆盖及重复引用、实际 Prompt 的明显跨包替代语，并按映射连通组检查 A→工程→包的时长守恒（包括合镜和拆包）；阶段、接缝与隐藏检查项由内部语义核对，不以可见字段是否出现作通过条件。它不能证明拆包阶段实际无重叠/遗漏、复杂多镜包的逐镜时长分配正确、招式结果保真或空间物理成立；这些须人工语义审读。角色稳定和打击感需看成片。

## 回归与证据边界

- 使用上述实际稿件校验命令检查结构与边界；结果不代表创意或成片质量。
- 实际行为测试按[测试与审核](testing-and-review.md)执行；样稿与确定性测试不能替代新请求、多次独立输出及成片检查。

## 外部与历史源稿

`--source-a`可传入用户指定的完整导演稿或历史G稿，无需改写源文件。默认`--source-format auto`识别当前A稿；当前A仍完整检查结构。需要明确类型时用`--source-format a`或`--source-format external`。外部稿接受数字镜号与S1-01式镜号，B映射保留对应标识；历史G稿从时间线提取成片镜号及片段时长。无法识别唯一镜号时报告具体缺口，不凭记忆补稿；缺少源镜秒数时明确A→工程时长守恒未覆盖，来源完整性、时间窗连续性与语义保真仍须人工核对。CLI显示这些未覆盖项，不将结构通过称为完整来源验证。

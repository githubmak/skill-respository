# 即梦 AI 漫剧/短剧导演分镜

把用户提供的剧情导演化为可拍、可生成、情绪有因果、画面有节奏的分镜。模型自行运用已有的编剧、导演、摄影、表演、灯光、声音和剪辑知识；本技能只规定会改变结果的边界、最低质量合同、按需路由和交付格式。

蓝图冻结前只使用本文件和当前内容实际触发的专项参考，不读取 [references/production-contract.md](references/production-contract.md)，也不预加载其他参考。冻结后需要正式交付时，再完整读取生产合同进行双文件编译；成稿后按合同后置复审。这样改变的是规则进入时机，不减少最终栏目、信息覆盖或演绎颗粒度。

## 创作保护

本技能增强模型的导演判断，不替代模型判断。母版色卡、全局影调、视觉风格、人物与资产固有色属于全剧视觉连续性硬约束；它们统一全剧的颜色体系、影调基线和材质显色，但不固定单镜的景别、构图、焦段、运镜、光位、曝光变化或颜色面积。

全剧所有镜头都应在导演设计阶段形成与项目视觉体系一致的美学完成度，包括普通镜、对白镜、过渡镜和稳定镜；不得把成稿复审当作补充画面层次与演绎感的创作阶段。每镜至少形成一项与本镜职责直接相关、观众能够感知的叙事性视听承载，可以来自构图纵深、人物/环境行为、光影动机、声音组织、节奏、静止或留白；不要求每镜增加运镜、浅景深、逆光、滤镜、粒子、微动作或其他显眼手法，也不按固定层数和技巧数量打卡。

除事实、知情、台词归属、用户冻结内容、母版色卡、全局影调、视觉风格、资产边界、物理、空间、口型、跨镜连续、时长可执行性和直投纯净度外，其余内容均为结果合同和按需导演工具。情绪链、摄影指纹、关系调度、节奏波形、视觉母题、光影曲线、动作阶段、候选方案和表格不得整体套用、逐项填满或反向决定镜头。

## 输入与边界

用户明确指定仅按 `分镜-标准.md` 或其他独立 MD 规范执行时，退出本技能，不加载本技能入口或任何内部参考，也不把两套规则合并。正式交付需要剧本或目标片段、画幅、视觉风格和全剧母色卡。只有人物身份/关系、因果顺序、地点切换、台词归属、能力规则、伤势胜负、结果结局或片段边界不清时集中提问；其他视觉未知按剧情建立足以支持拍摄和世界质感的可信空间。

- 不改人物、身份、性格、关系、知情、事件顺序、因果、能力、伤势、关键动作、胜负、结果和结局。
- 台词、OS、OV 默认逐字、逐句、按原归属和顺序保留。除非用户明确授权改写，不删减、合并、润色、证据化增强或替换措辞。
- 资产图锁定人物身份、服装、道具、材质、固有色和场景拓扑；固有色在真实受光、反射、阴影和综合色彩响应中仍须可辨，不把“防改色”误写成平光或人物贴片。
- 不输出俯视调度图。完整项目每个场景先冻结不含坐标的拓扑共识，再输出无人物场景资产正向提示词与负向约束；重要复用场景从同一拓扑派生实际需要的功能视角，每个视角只改变摄影方向与覆盖范围，不为普通单轴场景凑多视图。每个进入剧情因果链或需要跨镜锁定外观的关键道具输出独立道具资产提示词。局部镜头、修复或审核任务只输出用户要求的资产范围，无关键道具时按当前交付范围结算。
- 不考虑本地化、投放数据或数据回流，只完成分镜脚本和直投提示词层面的导演设计。

## 分阶段单源工作流

1. **事实锁**：锁定原文事实、人物知情、台词载荷、起始状态和不可改变的结果；只对会改变事实的歧义集中提问。
2. **导演设计**：先从原文识别主/辅题材承诺、场景任务、人物现实任务和观众收益，为每场形成从进入秩序到离场结果的情绪/信息/关系或过程曲线及镜头组；再为每镜生成“通过什么观看、人物/环境行为和视听递进，让观众具体感受什么，最后停在什么结果”的逐镜导演命题，联合设计人物策略、关系变化、真实存在时的压力来源/方向/受限选择、主导拍摄语法，并主动判断一个视频生成单元采用连续长镜头、时间线内有因切镜还是拆成独立镜头，同时完成完整演绎、题材化节奏、人景融合、干净影像和不改剧情的世界质感。不等待用户提醒强化拍法、情绪、动作或节奏，不预防性过审，也不因生成风险提前退回通用覆盖。
3. **蓝图冻结**：从同一份内部镜头蓝图联合冻结场景级导演曲线、各视听轴的递进/转折/释放、镜头组边界与不可替代职责，再冻结逐镜导演命题、观众感受、职责与首读点、注意力推进或有意保持、起态、刺激、人物策略与做事方式、主要变化、摄影结构及各段主机制、空间层次、光影材质、台词声音、人景共同响应、合理补充的氛围性世界细节、落态和具体风险。普通镜也先作为完整成片冻结；它可以减少事件和显眼技巧，不能减少当前镜实际需要的空间、人物/环境状态、表演、摄影、材质声音和镜尾完成度。冻结前做反事实专属性检查；相邻镜只有持续增加进度、压力、信息、关系或触感时才可承担相同作用。真实压力场景还须确认各视听部门服务同一主压力方向。若找不到特殊拍法，以最可观察的现实因果形成简单完整方案，不用通用中景、无动机推近或外加奇观代替判断。内部蓝图不交付。
4. **交付编译**：蓝图冻结后完整读取 [references/production-contract.md](references/production-contract.md)，按任务范围生成完整双文件、单镜头或专项结果。所有栏目都从冻结蓝图和连续状态派生；导演版保留整场视听设计、镜头组曲线与关键创作结论，直投版删除分析过程但完整保留有效、可执行的空间纵深、人物做事方式、演绎、人景/材质/声音响应、主摄影机制和镜尾画面。不得因提示词长度或预设 Seedance 执行负担而降质，也不无因二次导演。
5. **后置复审**：只修事实、知情、物理、时长、口型、空间、连续性和实际编译损失，不承担创造画面层次与演绎感，也不得临时堆动作、运镜、声音或美术细节。若发现生成源没有完成上述设计，命中具体失败时才局部回源并重新生成受影响蓝图；没有具体失败证据时不改成立方案。
6. **局部修复**：只回到受影响蓝图项、镜头或章节，随后重新编译对应内容；不因格式完整性、关键词或字段数量重新导演整集。正常工作流不调用外部技能、代理或脚本校验器；用户明确要求时除外。

### 稳定调用顺序

导演阶段按以下顺序组织判断：锁事实与知情 -> 识别题材承诺/场景任务/人物现实任务 -> 找观众等待与结果兑现 -> 形成场景级变化曲线与镜头组 -> 逐镜把事实动作转成观众体验与镜尾画面 -> 判断真实存在的压力来源/方向/受限选择 -> 设计注意力递进或有意保持、人物演绎，并选择连续拍摄/内部切镜/独立拆镜及对应摄影机制 -> 联合空间、光影、材质、声音和受控世界细节 -> 按时长冻结蓝图。没有压力任务时跳过压力判断；此顺序不增加节点配额或固定词汇。

### 按需路由优先级

- 每场先内部识别题材承诺、场景任务、人物现实任务、过程乐趣和结果兑现，冻结从进入秩序到离场结果的主变化轴、真实转折/释放、镜头组及空间/摄影/声音/表演能量分配；每镜再形成具体导演命题。根据题材和场景任务动态选择主导轴与辅助轴：冲突/悬疑侧重信息控制、压力、光影与节奏，种田/生活流侧重过程触感、空间、生活细节与声场，关系戏侧重距离、视线、停顿与表演，未列题材由其核心满足自行推导，不套固定模板。无冲突场景可以用过程、关系、认知或氛围曲线，不强造升级；普通低风险镜直接选择简单完整、可执行的方案，不能以“生活戏、过渡镜、信息少”为由默认中景覆盖或只列动作。
- 题材需要专项过程/建设/经营/职业/关系/悬疑/喜剧/治愈/动作/奇观语法，或首轮出现通用反打、重复中景、无动机推近、信息/关系/情绪距离不可读时，读取拍摄手法参考。明显成立的单一方案可直接冻结；只有两种观看机制确实会改变结果且难以取舍时，才比较一套非同构替代，不输出候选。
- 单一关键情绪先按本入口的结果合同直接导演；出现多阶段心理反转、三人以上反应传播、多个关系控制权连续变化，或权力入场、公开审视、威胁逼近、资源挤压、空间困锁、关系压制等真实压力任务，或首轮仍表演压平、动作无人物专属性、关系结果/压力方向不可读时，才读取表演与摄影导演引擎。是否复杂一时难判但已经出现两项以上迹象时，先读取最窄相关参考，不预加载全部；首轮成稿命中具体失败后立即补读对应参考并局部重开。冷调、沉默、多人同场不单独触发；普通对白、单次情绪变化和已经成立的关键镜不加载重型引擎。
- 场景图、人物图或道具图：再读取视觉输入和实体连续性参考。
- 完整项目或有人物进入场景的正式镜头读取光影色彩圣经的人景融合与干净影像规则；长台词、多阶段动作、打斗、VFX、蒙太奇或特殊转场再读取对应专项参考。
- 任何任务完成后：优先回看实际正文的事实、表演、关系、摄影、连续性和资产是否成立，不以关键词或字段数量代替判断。

## 必须成立的结果

以下条款规定最终镜头需要成立的结果，不规定必须采用的导演手段。涉及事实、物理、连续性、口型、时长、母版色卡、全局影调和交付的内容为硬约束；涉及表演、摄影、调度、声音和局部光影的内容，只在对应剧情实际存在时成立。静止、保持、不回应、不移动、不运镜或不改变光影也可以是有效结果，只要具有清楚的剧情职责、观看价值和美学完成度。

### 台词自然语气编译硬门

台词语气不得由“平静、认真、愤怒、悲伤、冷漠、紧张”等状态词直接推导。先锁定说话者正在对谁说、这句话此刻要完成什么现实作用、希望对方怎样理解或回应，以及人物准备显露什么、控制什么；语气首先服务话语行动和关系策略，情绪只调节外显幅度。

平静、冷静、克制和礼貌不等于语气平直、均速或没有自然起伏；认真不等于播报或训诫，愤怒不等于提高音量，悲伤不等于哭腔，紧张不等于结巴。除非原文明确要求机械、麻木、背诵、播报或失去情感，台词必须保留自然口语的语义分组、轻重层级、音高运动、呼吸连接和句尾方向。

完整台词的时长先按符合人物、关系和情境的自然试读确定，再安排动作、反应和摄影；复核实际字数、真实停顿和各语义段速度，某段同时要求减速或停顿却只能靠赶词完成时视为时长冲突。时长不足先压缩装饰动作、非关键反应或延长镜头，不得把台词压成快速、均匀、机械的朗读。正式交付按生产合同把同一话语行动编译为身体表演、自然声音弧线和受话者反应；直投版删除长篇分析，但须以简洁、人物化的自然语言保留说话者正在对谁完成什么现实行动、希望对方怎样理解或回应，声音参数只能补充而不能取代这项行动。若换成关系、性格和目的不同的人物后，现有声音描述仍完全成立，视为只有通用情绪，须只重写话语行动、语义推进或话落期待，不靠增加参数制造差异。

- 每场先让情绪、信息、关系/控制、空间距离、动作动量、摄影距离/运动和声音密度中的实际主导轴、辅助轴形成有对比的递进、转折或释放，再划分各有不可替代职责的镜头组；各轴不必同时上升，爆发也可以用骤停、静默或拉远完成，不能把整场机械写成连续慢推、逐镜收紧或重复特写。每镜随后形成明确导演命题，确定注意力、连续拍摄/内部切镜/独立拆镜、人物/环境演绎和落幅；没有新增读取的镜头合并或重定职责。
- 情绪不能压成“紧张地说”“错愕地看”等标签。关键转变必须呈现刺激、人物认知、第一冲动、控制或泄漏、新行动、反馈和镜尾残留；节拍数量由剧情和时长决定，不套固定模板。
- 每名主要人物先建立简洁表演锚点：性格底色、当前目标、核心顾虑、关系策略、压力下的控制方式、可见泄漏、禁演方向，以及语义分组、咬字、气息连接、句尾和关系差异构成的说话身份倾向。锚点不是固定语速或音高；逐镜表演和声音由锚点、对象、话语行动与当下刺激共同推导。
- 普通镜不套完整深演链，但仍须形成完整表演整体：人物处于真实任务、关系和环境中，进入状态、性格化做事方式或有意保持、当前注意、身体/道具/环境反馈与镜尾余势共同成立；无人镜由环境、物件、时间或声音的状态变化承担。价值重估、能力认知、身份判断和安静的亲近/疏离即使低声量、无冲突，也按实际戏剧价值深化。静止、失语或维持原动作可以独立成立，无须强造外部动作；一个词或一句即时短反应不自动展开完整表演链。不得把阶段名复述成“看、走、说、继续”，也不为丰富强加微动作。
- 关键转折镜按可拍时间顺序写到刺激进入、感知/确认、认知变化、第一反应、自我控制或泄漏、动作启动/路径/接触、对方反馈和镜尾余韵中的实际发生项；心理结论必须落到镜头可读载体。景别只决定可见粒度，不规定动作数量：特写/近景可保留有因的眼睑、呼吸、指节、口唇、肌肉控制或接触细节，中景联合任务动作、重心、距离与关键面部变化，全景/远景优先姿态轮廓、走位、群体关系和环境反馈；不得跨镜重复同类微动作代替情绪发展。
- 双人或多人戏必须写清距离、朝向、视线、谁掌握空间/道具/话语主动、刺激如何传播，以及关系变化怎样落到走位、构图、遮挡、焦点或停顿；不机械补齐无效反应镜。
- 场景真实存在压力时，先锁一条主方向：谁或什么施压、主要传向谁、对方的选择如何受限、怎样应对、空间/群体/道具/声音如何反馈及镜尾留下什么结果。推近、暗光、慢动作、皱眉和全员转头本身不等于压迫；各部门不得各自制造互不相关的紧张效果。没有压力任务时不建立该链。
- 对白必须与表演握手：先依据人物知情、关系对象、这句话当下要完成的现实作用、对外策略和未完全外露的压力，统一确定身体表演与声音弧线，再落实说前准备、说中关键词或语义转折、说后余波。音画同源不等于动作与声音逐点同频，身体和声音可以存在符合人物的延迟、错位或反差；只选择足以区分演绎的最少声音变化，不以标点、停顿、重音、语速、音高和气息反复强调同一语义结果，也不把完整语义组切成逐词停顿。语气不能只由标点或情绪词推断；受话者不能提前知道尚未说出的内容，口型只属于说话者。
- 情感深度来自旧情绪残留、当前欲望/顾虑与外在策略之间的张力。每个有效节拍选择最少但足以让当前景别读懂的动作、距离、道具、面部或声音载体；不把细腻误写成通用微表情堆叠，也不把克制误写成没有变化。
- 动作按真实物理顺序写清预备、路径、接触、受力、结果和保持；不存在的阶段删除，不为填格式虚构动作。
- 摄影机必须处于空间中可到达的位置，交代机位侧别、高度、朝向、景别、焦段、轴线、运动路径、停止点和终幅可见范围。炫技必须服务剧情读取，不能破坏空间或人物可见性。
- 一个交付“镜头”是视频生成单元，不自动等于一次连续摄影镜头。时间线从 `0.0秒` 连续覆盖到镜尾；连续段写可追踪摄影路径，内部切镜以 `子镜A/子镜B·景别或机位` 标记并交代切前落态、切后起态、轴线/视线/道具状态和声音桥，切换须增加新读取。子镜具有独立叙事落点、需要不同起落状态或在实际时长内会争抢主读取时才拆成独立镜头；不规定切镜或子镜数量。每段写具名主体、触发或进入基线、可见/可听过程和停止/保持状态，时间码不宣称某个字必然落在某个小数秒点。
- 前镜落幅与后镜起幅在人物位置、朝向、视线、重心、动作接点、道具控制者、光源方向和声音接点上连续；前镜已经完成的感知、确认和情绪形成由后镜直接继承，除非有新刺激、人物有依据地再次确认或重复具有明确关系意义，不得切镜后重新表演同一认知过程。直投每镜仍须自足，不能写“同上”或“沿用上一镜”。
- 人物与场景共享透视、焦段、景深、曝光、白平衡、颗粒/锐度和运动状态；接触阴影、环境反射、遮挡、天气和材质共同响应。人物转身、走位、跨光区或接触改变后，至少一种共同摄影关系应随之可见变化；若全部保持不变，视为融合失败，纯肖像稳定镜除外。常规关系镜、过程镜和环境参与明显的镜头从前景遮挡/虚边、中景主体、背景环境中选择至少两个真正参与叙事的空间层次；纯肖像、主观压迫或有意压平空间可用单层，但须以受光、负空间、声音或表演承担等效作用，不机械添加虚焦前景。光影采用清楚主光、大面积低频明暗、稳定中间调和受控背景，面部暗侧连续有纹理，不出现随机暗斑、脏块、噪点或环境纹理污染。实体来源、连续形状、运动方向和叙事职责明确的图案光可以短时使用，但须保持身份和五官可读；唯美不靠满屏逆光、雾、粒子与光晕。
- 声音按剧情需要选择人物台词、动作拟音、环境、空间方向、声音桥和音乐；每场先规划底层环境、动作/空间中层与台词/关键音顶层怎样进入、让位、抽空和回归，单镜只启用实际需要的层次，不要求三层同时响，静默或声音抽空也可成为顶层设计结果。人声身份跨镜稳定，远近、遮挡、混响和底噪随人物空间与观看位置变化。台词优先，声音不抢关键读取；声音母题只在承担信息、关系或节奏职责时建立。不存在的 OS、OV 或特效零提及；音乐在用户授权或项目风格允许且有叙事职责时可以设计。
- 每个时间窗保持一个主首读点，并允许服务主读点的次级信息。观看对象、信息尺度、人物立场或情绪落点真实转换时可主动使用内部有因切点；同一动作重量、空间压力、对白表演或持续体验需要完整时采用连续拍摄。人物揭示、长台词、复杂动作、多人反应、运镜或特效互相争夺注意力时串行或拆镜，不靠赶词、全员同步动作或持续运镜硬塞时长。
- 本镜特殊正负向只处理可见、可听或物理上的新增结果与失败风险，不描述或臆测平台内部优先级、识别机制或未经证实的控制能力；正向目标与负向排除不得互相矛盾。

## 创作自治

- 除母色卡输入门、不可改事实、人物知情与台词归属、资产边界、空间可达、物理因果、口型归属、跨镜连续、时长覆盖和直投语义纯净度外，其余镜头数量、景别变化、节拍结构、动作数量、情绪载体、运镜、光影、音乐、插切、蒙太奇、特效层数、信息颗粒与表现强度由模型按剧情收益自行决定；不设人为字数、字段长度或细节数量上限，只删除重复、冲突或没有观看收益的堆叠。
- 参考文件中的数量、百分比、时长区间、候选方案和常见结构默认是启发式参考，不是配额、上限或必经流程；只有明确标注为事实/安全/物理/平台/交付硬约束的条目才强制执行。
- 允许安静、静止、留白、反高潮、重复母题、长镜头、快速剪辑、复杂调度或非常规构图，只要它们有清楚的剧情职责、可读结果和可实现路径。可主动补充与时代、地域、季节、地点和已知日夜相容的天光、天气细节、远景生活活动、植被、炊烟、环境声与材质反馈，用于空间层次、生活状态、题材气质或镜尾余韵；不得因此新增人物知情、线索、危险、关键行动、因果或结果，持续增补须纳入连续状态。不要为了命中术语、字段或结构而添加原本不需要的反转、动作、微表情、旁观反应、光效、音乐或镜头。
- 普通低风险场景可直接选择最符合人物、空间、节奏和情绪收益的一种简单完整方案，不必输出或内部穷举固定数量候选；“简单”只减少事件和显眼技巧，不减少构图空间、人物演绎、人景材质声音响应与镜尾完成度。命中自动成熟拍摄路由时只比较一套非同构替代，不把候选折中进同一镜。

# 即梦 AI 漫剧/短剧导演分镜

把剧情导演化为可拍、可生成、情绪有因果、画面有层次的分镜。模型自行使用导演、摄影、表演、灯光、声音和剪辑知识；本技能只保留改变结果的边界、流程、质量门与交付格式。

**读取完整性**：开始前完整读取本入口；参考只在触发时完整读取。遇截断、分页、省略或缺段须缩小范围补读，未补齐不得执行依赖阶段或声称读完。

底稿冻结前只使用本入口及已触发的专项参考，不读取 [生产合同](references/production-contract.md)，也不预载全部参考；冻结后需要正式交付时，完整项目在首个场景底稿冻结、开始直投整理前完整读取生产合同，随后按同一合同逐场整理并复审。这只降低运行负担，不减少交付颗粒。

**创作优先与减负**：先完成剧情事实、人物知情与本场变化；再完成演绎、关系/压力、构图与摄影机制；再检查物理、空间和连续；最后才整理资产、栏目、模板与复审。每镜在连续、资产、口型和格式校验前，先决定唯一主读点所需的观看距离与镜头力度；后项只能验证或否决不可执行方案，不得替代景别判断。只去重复解释、全局基线逐镜复制和无风险空项；人物化处理、动作因果、构图、运镜、色影、声音、连续时间线与镜尾状态仍须完整可导演、可拍、可生成。各项只在其权威段落写一次，不新增栏目或逐镜填表。

## 输入与边界

用户明确指定仅按 `分镜-标准.md` 或其他独立 MD 规范执行时，退出本技能，不加载本技能入口或任何内部参考，也不把两套规则合并。正式交付需剧本/片段、画幅、视觉风格和全剧母色卡；只有会改变人物身份/关系、因果、场景、台词归属、能力、伤势、胜负、结局或片段边界的歧义才集中询问。

- 不改人物、身份、性格、关系、知情、事件顺序、因果、能力、伤势、关键动作/信息、胜负、结果和结局；这些锁“发生什么”，不锁景别、机位、调度、切镜、动作载体、声画关系、环境细节和镜尾等“怎样表达”。
- 台词、OS、OV 默认逐字、逐句、按原归属和顺序保留；除非用户明确授权改写（影视化改编），不删改、合并或润色。获授权后只可压缩重复说明、把可见信息视觉化或提纯措辞，仍须保持说话者、核心信息、到达时点、关系策略、人物口吻、因果和结果。
- 母版色卡、全局影调、视觉风格和资产固有色统一全剧，但不固定单镜景别、构图、焦段、运镜、光位、曝光或颜色面积。
- 完整项目每个场景冻结无坐标拓扑共识、无人物场景资产提示词及关键道具资产；重要复用场景才从同一拓扑派生所需功能视角，普通单轴场景不凑视图。不输出俯视调度图。局部镜头、修复或审核任务只输出用户要求的范围。
- 新剧本不自动继承旧项目的专属拍法；同项目续集继承已冻结资产与视觉连续性，跨项目共用审美只在用户明确要求时沿用。

## 整集—场景—镜头生成链

在前述事实锁与台词授权边界上，完整项目只做一次整集导演设计，冻结题材核心看点、关系轨迹、影调资产、全剧摄影机观看位置与总体节奏；存在可写的最终 MD 目标时，先写全局头，再逐场冻结连续成片底稿并立即把该场完整直投块追加到同一文件，每批只继承上一批必要的人物、道具、空间、情绪、声音与摄影状态，不重新导演，也不把已写直投正文重读为创作输入；无可写目标时仍按此顺序生成，但不得声称已写入文件。环境允许持续写入时自动完成全部批次；受聊天长度限制时仅分批交付，不重复提交剧本或重新分析。

术语只作内部简写，交付时必须译成可见、可听的结果：本场核心变化＝人物带着何种状态进入、经历何事、最后留下何种变化；观看关系＝观众借摄影机站在谁身边、离多近、先看什么；主要呈现方式＝主要靠动作、构图距离、摄影、声音或光影中的哪一项让观众感到变化；镜头力度＝固定观察、缓慢靠近、贴身跟随、快速变化或骤停带来的观看强弱；画面位置强弱＝谁占位、谁被挤压、隔开或暴露；第一眼主读点＝观众最先必须读到的人、事或变化；内部镜头设计底稿＝所有镜头共享的已定剧情、表演、摄影与连续状态；题材核心看点＝该题材应让观众获得的过程乐趣或结果满足；压力过程＝压力如何到来、累积、逼人物处理并留下结果；人物表演基线＝人物此刻怎样做事、控制自己及最易泄漏何处；全剧摄影机观看位置＝摄影机通常陪伴、观察或介入人物的方式；直投稿清洁规则＝只留可执行内容，不写分析、候选或内部说明。冻结指内部定稿，整理指把底稿写成直投稿。它们只指导内部取舍，不能单独充当直投指令。

每场先在内部冻结一句本场核心变化：`谁带着什么状态进入 -> 经什么压力或行动发生什么变化 -> 最终留下什么结果`；继承整集基线后，决定主节奏、观众观看关系与主要呈现方式，并只记录相对全剧实际改变的空间、构图策略、节奏、色影/声场与资产状态。拆镜前还冻结场级观看生成源：观看任务；由既有事实形成的观看峰值、过程乐趣或结果停留；实际的强弱与镜头力度曲线；允许增补及须暂停确认的边界。安静、生活、治愈或纯过程场只选择实际存在的项，不套“钩子—命中”公式；这些只指导底稿，不新增直投栏目或逐镜填表。同一份内部镜头设计底稿联合冻结时，每镜先把事实转成“观众怎样看见并感受什么”，先锁唯一主变化：谁以何种性格化处理改变什么、观众凭何种人物/物件/空间/声音反馈确认；只把影响独立执行的继承状态编译为起幅快照，其余只运行一次联合判断：`本镜剧情作用/事实 -> 旧残留、欲望/顾虑与刺激意义 -> 唯一主变化及其可见证据 -> 摄影机站位、距离与镜头力度 -> 镜尾结果`。本镜由场级观看生成源选择观看关系、信息显隐、距离和力度；再由人物策略落实表演与动作，连续性只验证可执行性。每镜须新增信息、关系、压力、任务进度、画面位置强弱、主观感受、身体动作或结果余波之一；没有新增意义则合并、改写观看关系，或明确承担蓄压、凝视、母题推进或留白。对白、身体、受话者、配角与环境从同一人物策略整理：未受刺激者继续任务，受刺激者才按知情、距离、利益和性格错峰响应；不让配角木讷，也不为保活堆无关小动作或特效。

长项目用三级继承减负：全剧层一次冻结全剧事实、人物/资产、色影和摄影观看基线；场景层只记录本场相对全剧的空间、构图策略、节奏、色影/声场与资产变化；镜头层只记录起幅必要继承事实、本镜表演与视听变化和落幅变项。独立直投时再把该镜必需的上层事实编译成简洁完整句，不写“同上”，也不在多个栏目反复复述。

冻结后完整读取 [生产合同](references/production-contract.md)，按其整理默认完整直投主稿，用户要求时再衍生导演审核版，不二次导演。合同中的整理与复审规则负责保留已冻结的观看峰值/过程乐趣、镜头力度变化、允许增补的实际作用和结果停留，但不把场级生成源写成新字段；复审不负责临时创造，不能用关键词命中代替导演判断，具体失败时才局部回到底稿，修受影响底稿、正文及接点。普通工作流不调用外部技能、代理或脚本校验器，用户明确要求时除外。

## 导演核心

以下是同一底稿的五个判断面，不是逐项填表、动作数量或技巧配额；静止、留白、极简、长镜或固定机位只要产生清楚结果均可成立。

### 1. 题材、人物与压力

题材必须改变拍摄对象、过程颗粒、节奏和结果呈现：冲突/悬疑读信息、压力与控制权，种田/生活流读工序、空间、生活触感和声场，关系戏读距离、视线、停顿与回应，其他题材按核心看点推导。全剧任何镜头——对白、独处、发现、关系、冲突、过程、过渡或结果——首先是可观看事件，不得以情绪词、剧情结论、工序概述、景别/运镜名称或 OS 代替演绎。每场开端在不改变原文事实、因果与顺序的前提下，于最早可用观看窗让观众读到正在进行的目标/任务、关系边界、已有结果余波、可感压力、工序触感、信息限制或有意义空间状态之一；安静段可用人物—环境关系、持续任务或声音建立，不以无职责空景替代，不规定秒数或强造钩子、反转、危机与高潮。镜头可承担简洁交代、铺垫蓄压或拐点峰值，作为取舍而非标签；简洁镜也须把当前事实落成一项可观察、可归因的处理变化，至少改变注意目标、任务方式、重心/距离/接触、说话方式、道具控制、空间占位或受话/环境回应之一。“看、说、笑、转身、继续做事”只有对象、前后差量和可见/可听结果都明确时才成立。重要变化从旧残留、欲望/顾虑和刺激的主观意义，经过人物惯用的控制、伪装、抵抗或释放，落到任务、身体、距离、接触、道具或声音的改变，再由对方/空间反馈为镜尾余波；纯内在冲击的优先载体可以是可感知的注意、短暂失语、身体冻结、构图或隔离，无须强造外部动作。掩饰动作必须完成现实任务或改变关系，泄漏只从有因的启动、力度、精度、未完成、声画错位或动作后残留读取。爆发前保留积累，命中后保留结果。

台词先锁对象、话语行动、期待回应和显露/控制，再按自然语义分组、咬字、气息连接、句尾和关系差异组织声音；平静不等于平直，状态词不能直接决定语气，声音身份不是固定语速或音高，不赶词，完整语义组不得被切成逐词停顿。关系、性格和目的不同的人物换人后仍成立时，重写话语行动、语义推进或话落期待，不靠增加参数制造差异。多人戏锁主关系和刺激传播：配角带任务、注意和立场入镜，未受刺激者继续，受刺激者依知情、距离、利益和性格错峰响应；真实压力须使选择、策略或外部关系进入新状态，摄影变化本身不算释放。

### 2. 摄影、构图与切镜

按观看关系、信息控制和情绪距离选择拍法，不默认固定中景、机械正反打或连续慢推。摄影按“唯一主变化及证据 -> 观看距离与镜头力度 -> 构图/机位 -> 连续与生成验证”决定；后项只能否决不可执行方案，不能反过来把拍法拉回中景或轻推。首选中全/中景/中近景时，先在内部比较贴近或拉远后的主读点是否更清楚；只有人物关系、全身受力与路径确需同读时才保留中距离，这项比较不新增栏目或逐镜说明。每场冻结有差值的观看距离与镜头力度曲线，固定观察须产生承受、凝视或距离结果。明显成立的单一方案直接冻结，只有两种观看方式都成立且难以取舍时才比较非同构替代。控制突破、注意突变、逼近/退离、接触许可、关系中心或控制权改变时优先比较动态介入；采用强运镜时写清外化触发、主体/关系中心、可达路径、速度、停止条件和停后新结果，同一时窗一个主运动，炫技必须服务剧情读取。每场冻结一条服务关系与题材体验的构图策略：主体与负空间、主要几何秩序、纵深、遮挡、颜色面积及人物—环境尺度；峰值用空间开合、中心/边缘交换、遮挡解除、同框/分离、负空间或前后景权力换位形成可读视觉秩序变化，不把浅景深、逆光、虚焦前景或对称构图当作唯美。仅当用户已选漫画化风格，或题材世界、平台能力与当前节拍共同支持时，才在既有摄影、光影和时间线中使用分格重组、冲击边框、方向性速度线、残像、局部冻结、画面比例变化或非世界内影子/色温脉冲；它们须服务已发生的动作、信息命中、关系变化或主观冲击并有进入、主读点和退出，世界内气场/能量/破坏必须来自原文或用户设定。除原文明确的真实界面外，不生成可读文字、弹幕、对白气泡、UI 或水印，手机端保持一个主窗及安全可读的人脸、手、接触和证据。

“镜头”是生成单元：动作重量、空间压力、对白或沉浸需完整时连续拍；观看对象、信息尺度、人物立场或情绪落点真实转换且增加读取时，才以 `子镜A/子镜B·景别或机位` 内切并承接人物位置、轴线、视线、动作、道具和声音；有独立落点或争抢首读点时再拆镜。

### 3. 空间、动作与画面

摄影机和人物路径可达；关键动作保留必要支撑、启动、路径、接触、受力、终点与保持，前后镜连续跟踪位置、朝向、视线、重心、伤势、持物手、道具、轴线、光源和声音，不用切镜制造瞬移或复位。近距离双人接触、换手/递接、拉拽/搀扶、摔倒、多人交错、连贯攻防或多阶段动作，先锁意图、起势、决定性接触/作用与结果；单一生成单元只承载能稳定保持身份、肢体、道具和主读点的连续阶段，其余按“起势/方向 -> 接触或作用 -> 结果/余波”拆为可承接子镜或相邻镜，逐段写接点、持物手、重心、位置、受力方向和声音桥。不得因生成风险删去关键接触、伤势、胜负、道具归属或结果；接触点若是剧情证据或关系转折，须以短时清楚接触、遮挡后的即时受力结果或可追踪声画桥成立。每镜以一个观众能够感知的主要呈现方式、第一眼主读点和低调辅助层承载变化；景别只决定可见粒度。常规关系/过程/环境镜至少两层空间参与叙事，纯肖像、主观压迫或有意压平时由受光、负空间、声音或表演承担等效作用。

人物与场景共享透视、景深、曝光、白平衡和运动状态，以接触阴影、遮挡、环境反射、天气与材质形成共同响应；人物转身、跨越光区或接触改变后至少一种可见变化，纯肖像除外。保持清楚主光、稳定中间调和受控背景；唯美来自构图、颜色面积、空间和材质，不靠随机暗斑、噪点、满屏逆光、雾、粒子或光晕。

### 4. 声音、时长与直投

声音按剧情只启用需要的底层环境、动作/空间、台词/关键音层次，远近、方向、遮挡和混响随空间变化；静默或声音抽空也可成立，声画反差、主观听觉、J/L-Cut和声音匹配切仅在改变信息、心理距离或节奏时使用，不强制使用。时间线从 `0.0秒` 连续到镜尾，所有阶段共同服务已冻结的唯一主变化；每窗写具名主体、触发/基线、人物化处理、过程、外部反馈和终态，不把多项独立工序或情绪结果平均罗列，也不把“眼中一亮、轻笑、决定、情绪升级”这类结果性概括当作过程。一个词或一句即时短反应不自动展开完整表演链，复杂信息无法共享观看目标时串行或拆镜，不宣称某个字必然落在某个小数秒点。镜长按自然台词、动作、反应和余波确定，不因提示词长度降质。

直投每镜自足但不逐栏复述：同一事实完整写一次，其他栏只补新增变化；既有字段内先写第一眼主读点的具名主体、正在发生的动作/状态与空间关系，再写必要的摄影、光影、声音和连续条件，导演推理不进入直投正文。所有改变剧情、人物、动作物理、空间、道具、摄影能量或镜尾结果的过程留在连续时间窗中，不得缩成“情绪升级/镜头推近/人物爆发”。全局负向只写持续风险，特殊正负向只写本镜新增风险。

## 按需参考

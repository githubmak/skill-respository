# 即梦 Seedance 全题材导演分镜

将用户已有的剧本、分场稿、对白片段或已冻结的镜头任务，编译为可导演、可拍摄、可生成、可续接的 Seedance 视频分镜。适用于对白、关系、动作、打斗、悬疑、调查、家庭、爱情、喜剧、经营、成长、生活、治愈、恐怖、奇观、幻想和混合题材。小说分集分场改编仍需用户明确授权；用户只提供小说片段时，先说明需要改编授权或仅按片段导演化。

本技能默认偏向 Seedance 2.5：同步生成画面、人物动作、对白声音与口型；单个成片镜头的生成时长上限为 30 秒。用户明确指定其他平台、模型或时长时，以用户指定为准。30 秒是执行上限，不要求每镜达到该时长。

## 1. 执行边界与优先级

### 1.1 模式判定

- 用户明确指定某个独立 Markdown 规范（例如 `分镜.md`、`分镜-标准.md`）时，退出本技能，不读取本技能参考，不与独立规范合并。
- 未指定独立规范且请求即梦、Seedance、漫剧或视频分镜时，使用本技能。
- 默认使用忠实导演模式：保持人物、身份、性格、关系、知情、事件顺序、因果、能力、伤势、关键动作/信息、胜负、结局、台词归属和台词顺序。
- 用户明确授权影视化改编、压缩重复或改写台词时，仅在授权范围内使用改编优化模式；“精修分镜、增强表演、优化镜头”不等于授权改写剧本。
- 只有会改变人物身份/关系、因果、场景、台词归属、能力、伤势、胜负、结局或片段边界的歧义才询问。普通视觉缺项采用最小相容假设，并在交付说明中标明资产或验证限制。

### 1.2 约束优先级

1. 用户明确冻结内容、当前工作稿、台词授权和用户指定的平台条件。
2. 人物身份/关系/知情/能力、道具归属、伤势、空间拓扑、动作物理、口型和跨镜连续。
3. 现有剧情因果、观众信息顺序、人物选择和结果。
4. Seedance 生成稳定性、直投自足性和声音清晰度。
5. 摄影、构图、光影、材质、剪辑和风格化表达。

技术风险不能删掉关键因果证据；摄影变化不能代替人物选择；特效、漫画化、音乐和慢动作不能代替剧情结果。

### 1.3 文件与状态

- 默认在对话中分批交付。用户明确要求保存或给出最终 Markdown 目标时才写文件；未指定时使用当前工作区 `outputs/`。
- 不覆盖用户输入的剧本、底稿或已有成稿；若用户明确要求直接修改指定技能或文件，则按该授权修改。
- 长项目只完整读取剧本一次。全剧层冻结事实、人物、资产、色影、声音和摄影观看基线；场景层冻结本场状态、变化、节奏和空间；镜头/生成单元层只记录本单元必要起态、过程和落幅。
- 同一执行事实只在最合适的交付栏目完整写一次；其他栏目只补新增信息。直投稿不写“同上”“沿用上一镜”“参考前文”等省略指代。

## 2. 处理链

按以下顺序执行，后一步不得反向改变前一步已经冻结的事实：

`读取剧本与用户约束 -> 判定模式与题材 -> 建立全剧状态 -> 冻结场景核心变化 -> 路由专项参考 -> 冻结镜头组和生成单元 -> 编译独立直投模板 -> 连续性/时长/声音/资产复审 -> 交付`

### 2.1 事实与观众任务

先写内部一句场景核心变化：

`谁带着什么状态进入 -> 经什么压力、行动、发现或过程发生什么变化 -> 最终留下什么结果`

每场至少锁定：

- 进入状态、当前目标/任务和关系边界；
- 观众先知道什么、人物先知道什么、什么信息需要延迟；
- 压力、发现、关系变化、工序、能力规则或奇观过程的真实来源；
- 本场主峰、过程乐趣或结果停留（若实际存在）；
- 允许增补和禁止新增的边界；
- 场尾仍需继承的身体、道具、空间、声音、知情、关系和未完成压力。

低压力、生活、治愈或纯过程场不强造钩子、反转、危机或高潮；安静镜必须通过人物—环境关系、持续任务、空间状态、声音或过程变化提供观看收益。

### 2.2 镜头与生成单元

- **成片镜头**：两次可见剪切之间的连续画面。镜内焦点、机位或观看重点变化不自动产生新镜头；发生剪切且改变观看位置时另计成片镜头。
- **生成单元**：一次 Seedance 生成的视频片段，可承载一个或多个连续成片镜头，或一个长镜头的一部分。生成单元不自动等于连续摄影。
- 动作重量、空间压力、对白表演或沉浸需要完整感受时保持连续；观看对象、信息尺度、人物立场或情绪落点真实转换且增加读取时，使用内部切镜或拆分成片镜头。
- 每镜先锁唯一主读点和唯一主变化，再决定景别、机位、构图、运镜、光影、声音和时长。没有新增信息、关系、压力、任务进度、身体变化、画面位置变化、主观感受或结果余波的镜头合并、改写观看关系或删除。
- 每个生成单元不超过 30 秒；复杂接触、长对白、多人反应、VFX 或跨单元连续优先按 `起势/方向 -> 接触/作用 -> 结果/余波` 拆分，并逐段承接位置、朝向、持物手、重心、受力、声音和道具状态。

### 2.3 表演与声音

人物表演从欲望、顾虑、任务、关系、知情和身体条件出发。关键节拍可按：

`前态/任务 -> 刺激意义 -> 第一冲动 -> 性格化控制/伪装/抵抗/释放 -> 行动与声音 -> 外部反馈 -> 镜尾结果`

普通镜不强求完整心理链，但必须有一项可见或可听的处理变化。情绪词、剧情结论、景别名、运镜名和 OS 不能替代表演过程。

对白按说话者、受话者、话语行动、期待回应、显露/控制和自然语义组组织。台词、OS、OV 默认逐字、逐句、按原归属和顺序保留。说话者可见嘴部时同步口型；画面展示听话者、环境、道具或其他反应时使用连续画外对白，不生成与画外对白对应的口型，听话者可有自然呼吸、吞咽或无声反应。OS 无口型且不被画内人物无因听见；OV 不被画内人物无因回应。

全项目人声保持清晰干声：无混响、回声、延迟尾音、双重人声和拖尾处理。音乐、环境、拟音和特效在对白/OS/OV 出现时让位。跨单元对白默认采用自然语义分配；确需一条连续干声音轨时，采用连续音轨并在首次承载处标明覆盖单元，后续不得重复合成人声。

### 2.4 摄影、空间、光影与物理

摄影先决定摄影机与谁同感、观看距离、信息显隐和镜头力度，再决定景别、机位、构图、焦点、运动和切点。固定、长镜、远景、特写、非常规构图均可使用，但必须在时间线上产生明确的等待、发现、关系、空间、动作或结果收益。

摄影机路径必须可达；轴线、人物位置、朝向、视线、屏幕侧、前后景、遮挡和正/侧/背可见面必须同时成立。动作保留支撑、启动、路径、接触、受力、结果和停止状态；切镜不得制造瞬移、换手、伤势消失、道具复制或状态清零。

全剧锁定资产固有色、空间拓扑、实体光源、影调、材质和摄影观看基线。逐场可按时地、天气、剧情和空间真实变化；不因环境色彩覆盖人物、家具、道具和场景固有色。漫画化、粒子、能量、破坏、速度线、残像和画幅变化只在项目风格、题材世界和当前节拍共同支持时启用，必须写清触发、主读点、持续和退出。

冻结底稿前按下表逐项判断。命中即完整读取对应参考；未命中不读取。条件不确定时读取，不凭“看起来复杂”跳过。每场先读能解决主要问题的最窄参考，只有仍有具体未解决问题才补读第二份。已读重型参考覆盖同一问题后不再叠加功能重叠参考。

## 4. Seedance 独立直投编译规则

正式直投默认只交付一份完整主稿，不同时生成导演审核版。完整项目的资产图提示词、场景空间关系和每个生成单元均写入同一主稿。用户要求导演分析、人工审核或双版本时，才按生产合同追加导演审核版。

- 默认平台：Seedance 2.5。
- 默认单镜生成上限：30 秒；镜头实际时长按自然对白、动作、反应和余波决定。
- 每个生成单元时间线从 `0.0秒` 连续覆盖到单元末尾，时间窗不留空档、不重叠。
- 台词原文在对应“台词与声音层次”中按播放顺序出现一次；时间线只引用语义节点和声音事件，不重复整句。
- 当前单元独立投喂必须带齐当前人物、空间、起态、资产约束、声音规则和本单元新增风险，不写“同上”。
- 全局正向和负面模板只在全局头出现一次；单元特殊正负向只写本单元新增且会改变结果的风险。
- 无人物参考图时，不补造未确认的脸型、年龄、肤色、发型、服装、饰品或体型；只能写身份、动作、姿态、朝向、位置、关系、临时剪影和受光。

### 5.1 栏目职责

- **项目直投参数**：画幅、平台、模型、单镜上限、风格和已确认制作条件。默认写 Seedance 2.5 与 30 秒上限。
- **全局摄影规则/影调/光影/环境色彩**：只写跨镜基线，不写逐镜变化。
- **场景资产图提示词**：首次建立场景拓扑、光源、材质和拍摄区；复用场景只写变化部分。
- **道具资产图提示词**：首次建立关键道具单体资产；无关键道具时写“无关键道具资产”。
- **场景空间位置关系**：写出入口、锚点、拍摄区、人物起位/距离、路径、遮挡、光源、关系轴和屏幕侧。多人同框时补躯干/头眼朝向、正侧背可见面和摄影机相对关系轴所在侧。
- **起幅与连续性**：写可独立投喂的完整起态，不写“承接上一个镜头”。
- **摄影与构图**：写当前成片镜头实际采用的观看距离、景别、机位、焦点、运镜、主体站位和主读点。
- **光影、环境色彩与材质**：写当前单元真实发生且影响读取、连续或结果的光影、色彩、材质和共同响应。
- **画面与表演时间线**：从 `0.0秒` 连续到单元末尾，写具名主体、动作过程、表演证据、摄影/声音响应和阶段终态。内部切镜写清镜号、切因和承接。
- **台词与声音层次**：按播放顺序写实际台词、OS/OV、声音表演、口型、受话、环境、拟音、音乐让位和跨单元声音桥；实际发言原文只出现一次。
- **落幅状态**：结算人物、道具、空间、光影、声音、焦点、关系和未完成压力中后续仍需继承的变化。
- **特殊正/负向约束**：仅在当前生成单元有新增风险且丢失会改变结果时保留。

## 6. 复审门

交付前按以下顺序复审：

1. **事实**：人物、身份、关系、知情、台词、能力、时空、伤势、道具、胜负、结果未被改写。
2. **观看**：每场有实际观看任务；每个镜头组有过程、发现、关系变化、动作结果或结果承受；不靠形容词和特效制造峰值。
3. **人物**：行动、台词和处境有因果；关键应对换人后不应完全相同；关系对象有感知、边界和实际回应。
4. **反事实专属性**：替换人物、任务或地点后，关键应对不应仍能原样成立；相邻镜头不能无增长地重复同一作用。
5. **连续**：起落、位置、朝向、接触、重心、道具、口型、声音、光线和知情可承接；时间省略有证据。
6. **执行**：每单元不超过 30 秒；时间线连续；主读点清楚；对白不重复、不丢失、不被音乐环境遮蔽；平台投喂上下文自足。
7. **模板**：最终栏目、顺序、字段名与第 5 节完全一致；删除空特殊约束、内部分析、候选方案、路径、色码和省略指代。

用户仅要求分镜文本时，完成剧本与分镜文本层复审，并简短说明未执行动态预演或成片验证；不声称已经验证生成效果。

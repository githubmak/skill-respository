# 即梦 AI 漫剧/短剧导演分镜

本技能是唯一运行能力入口，也是自包含的独立技能。完整导演分镜所需的剧情、表演、摄影、声音、连续性、光影和交付能力，均由本技能及其目录内的 `references/` 实现；外部文档仅作为用户输入素材，不覆盖冻结的导演源。

从同一份冻结镜头蓝图编译。当前技能采用“导演源 + 逐镜执行账本 + 双文件编译”三层结构：导演源决定剧情、创意导演策略和摄影，逐镜账本把动作、表演、光影、材质和实体状态落到秒级，双文件只做格式转换，不再在成稿后补救表现力。

1. `作品名_导演审核版.md`：保留剧情、类型、反转、表演、摄影、光影、空间、声音和对白事实映射结论。
2. `作品名_Seedance独立直投版.md`：只保留可执行自然语言，每镜自足。

两文件的镜号、顺序、时长、最终台词/OS/OV、关键动作、结果、道具归属和起落状态一致。

## 不可改写边界

- 不改人物、身份、性格、关系、知情、事件顺序、因果、能力、伤势、关键动作、胜负、结果和结局。
- 锁定台词/OS/OV 的归属、事实载荷、知情、核心意图、功能和关键顺序。OS/OV 默认逐字保留。
- 可删除同义重复，或用说话者已知且原文已建立的人物、时间、地点、道具、行为、矛盾、证据和后果进行证据化增强；不新增证据、秘密、罪名、承诺、关系、结论或事件。
- 可从已有刺激、目标、关系、空间、道具和任务推出表演、反应、声音、观看顺序和物理余波；不为爆点新增事实。
- 资产图锁定五官、服装、材质、花纹、固有色和场景结构；母色卡只控制未被资产锁定的环境、空气和背景。

硬约束只用于保护剧情事实、人物身份、因果知情、能力规则、物理终态、资产一致性、空间可达性和直投纯净度。题材数量、镜头数量、动作层数、景别变化、炫技次数、特效层数和强度不设全局固定上限；按剧情收益、秒级时长、首读点与跨镜连续动态设计。任何“常见数量/通常范围”都是生成稳定参考，不得反向压低有依据的爽点、反差、表演、华丽奇观和摄影创造力。

修改技能时完整执行 [references/non-regression-baseline.md](references/non-regression-baseline.md)；普通生成不读该维护基线。

## 单一能力执行协议

本文件和其列明的核心参考共同构成一套能力，不能拆成“普通分镜模式”和“创意导演模式”两套互相覆盖的提示词。正式生成前必须完整读取本文件，并完成核心能力与专项路由覆盖；不得只按用户关键词跳读某一类规则。

所有项目必读的核心能力由以下五个参考共同承载：导演源与事实/知情/表演/摄影、类型与观众收益、时长与密度、光影与资产、双文件交付。核心能力必须在同一份导演源中联合冻结，不能因项目看似简单而省略剧情曲线、情绪表演、空间连续、光影、声音或创意导演职责。

专项参考不再靠隐含判断加载。扫描输入后，先建立“能力覆盖账本”，逐项登记 `核心已读 / 专项命中并完整读取 / 专项不命中并明确删除 / 事实歧义待确认`。只有明确登记“不命中并删除”的专项才可以不加载；任何未登记项都视为覆盖不完整，不能进入逐镜输出。

能力覆盖账本只记录结构化状态，不输出思维链。账本至少覆盖：事实与知情、类型承诺与留存、观众预期/公平线索/兑现/新债、选择代价/见证者、情绪与性格准入、摄影与非同构、视觉母题/注意力路径、场景节奏波形、空间与道具、时长与 AI 负载、光影/滤镜/资产、声音与对白/声音母题、动作/VFX/蒙太奇、转场/全景/空镜、提示词压缩层级、创意保真降级、直投交付和硬错误验证。

## 最小执行协议（整合与去重）

本技能已经把剧情、表演、摄影、声音、连续性、光影、类型和交付整合为一套能力；同一镜头只由一份导演源统一设计。

1. 每个任务只读取一次本入口和五个核心参考；`ai-manga-dramatic-direction-engine.md` 是导演结论唯一真源，时长、光影、类型和双文件合同只补充其专属约束，不重算剧情或摄影。
2. 输入扫描只做一次。专项参考按覆盖账本命中后各读取一次；未命中项登记“明确删除”，不为确认已冻结能力重复读取参考。
3. 只生成一份导演源表；观众预期、选择代价、视觉母题、节奏波形、注意力路径、反应传播和降级优先级在同一轮冻结。
4. 由同一源表连续编译导演版和直投版；不得在直投阶段重新拆镜、重选摄影、重写表演或重新计算时长。
5. 交付验证只运行一次；失败后只局部修复命中的章节/镜头，再复跑验证器，不重读全部参考、不重算整集导演源。
6. `references/non-regression-baseline.md` 仅用于技能维护和回归测试，普通生成不读取。

## 输入与视觉资料

正式交付需要剧本/片段、画幅、用户视觉风格和全剧母色卡。缺母色卡时只询问母色卡并暂停正式输出。场景图与参考拍摄手法为可选输入。

进入导演源前集中处理歧义：只有人物身份/关系、因果/顺序、地点/切场、台词归属、能力规则、伤势/胜负/结果、结局或片段边界不明确时暂停并一次提问；非事实性的视觉未知按最小可拍空间推导，不因缺装饰、背景或机位细节暂停，也不回退固定中景。

母色卡的颜色、影调和光影职责由 [references/cinematic-lighting-color-bible.md](references/cinematic-lighting-color-bible.md) 在核心读取中直接处理；只有母色卡的文本项目不加载视觉资产模块。有角色/道具/场景资产、场景图、多视图、PDF 或文件夹时，再完整执行 [references/visual-input-governance.md](references/visual-input-governance.md)：自动按地点归组并提取结构、出入口、遮挡、锚点、实体光源、人物/摄影机活动区、通路和关系轴，不要求用户重新口述。每个有图场景自动生成对应的 5—8 句客观空间描述；无图场景按剧本建立最小可拍空间。

有用户参考手法时，完整执行 [references/shooting-method-reference.md](references/shooting-method-reference.md)；只迁移观看距离、机位、运动、剪辑、焦点、遮挡、声音和停止方法，不复制参考内容。

## 生成流程

```text
扫描输入并决定参考路由
-> 建立能力覆盖账本，逐项登记核心已读、专项命中/不命中或事实歧义
-> 锁定事实、台词载荷、人物知情、关键动作与结果
-> 同轮生成每场事实/知情/状态预演表与关系覆盖策略
-> 冻结开场停留钩子、观众主问题、观众预期/公平线索/误判窗口/重解释/兑现/新债、爽点兑现账本、角色选择/收益/不可逆代价/见证者、反差萌/角色记忆资产、场景记忆点和兑现后再钩子
-> 冻结叙事立场、类型母版、全局摄影圣经、手机端和空间模型
-> 一次完成剧情曲线、反转链、表演/微动作、台词语气和压迫/情绪传递
-> 将情绪状态账本、场景压力、动作连续、道具终态、面部/资产边界和声音层纳入同一导演源
-> 冻结每场节奏波形、声音母题、视觉母题生命周期、首读→次读→结果确认路径和反应传播链
-> 按“刺激—升级—翻转—释放—尾钩”复核每场的观众观看承诺、策略变化、结果确认和再钩
-> 为主要反转比较三套非同构摄影候选，拒绝同构指纹后只冻结一套
-> 完成整集节拍/声音曲线、时长预算、光影曲线、滤镜/后期影像曲线、分场继承和特效受光
-> 联合设计场景轴、人物轴、光影轴、条件大气介质、主构图母题与主要奇观允许规模/分层
-> 为每镜写入秒级动作/微动作时间线、六阶段物理节点、情绪状态、对白前中后与声音层、景别级面光、滤镜/后期影像状态、材质反馈、场景关系、道具控制者与物理终态；直投动作描述按从 0.0 秒到镜尾的连续时间窗逐段输出
-> 在同一轮源表生成中完成切镜、镜长、表演载体去重、景别/运镜非同构、具体落幅、转场桥、光影材质、空间连续和新增负向约束
-> 每镜冻结主驱动力时间窗、交接触发、耦合响应、插切容量/退路与版本继承差量
-> 为高负载镜冻结“不可删核心→可压缩支撑→可删除装饰”的提示词层级和创意保真降级顺序
-> 在冻结前运行创意感染力源头自检：只做定性通过/补强，不评分、不统计关键词、不后置返工
-> 根据已成立的源表冻结唯一镜头蓝图；AI 负载只用于必要拆段，不得主动降级表现
-> 连续编译双文件，只修复硬错误命中的镜头或章节
```

强起幅、景别、运镜、秒级动作时间线、微动作触发、逐镜情绪状态、景别级面光、材质反馈、道具物理终态、台词语气、光影变化和爆点必须在源头蓝图内成立，不在成稿后靠检查词、随机特写、甩镜、变色或补形容词伪造强度。直投版不得把已冻结的动作时间线压缩成无时间顺序的散文段落；除单一静止状态的低风险镜头外，必须逐行写连续时间窗、具名主体、触发、动作/物理过程、耦合响应和阶段终态。默认保留最大可执行表现负载，只有具体生成故障风险才拆段或局部降载。

## 源头冻结闸门

在镜头蓝图冻结前一次生成 [references/ai-manga-dramatic-direction-engine.md](references/ai-manga-dramatic-direction-engine.md) 的完整导演源表，并在生成每一行时直接满足全部首次生成必成条件，再握手已登记命中的题材、光影、滤镜/后期影像、特效、道具、转场、全景/空镜和空间专项。剧情、类型承诺、观众收益、表演、六阶段动作、秒级微动作、情绪状态、场景关系、摄影、光影/滤镜/材质、声音、时长和物理终态必须在同一份源表中联合生成；不先产出低质量草稿，不另做创意评分或关键词扫描，也不进入双文件后重写正文。

冻结前必须完成以下覆盖确认：每场有事实/知情/状态预演表、观众预期与公平线索、选择代价与见证者、节奏波形和场景反差；每个主要转折有策略失效、新策略、非面部行动、不可逆代价和关系结果；每镜有唯一剧情/节奏职责、主驱动力、起落幅、首读→次读→结果确认路径、反应传播链、视觉句/母题阶段、情绪残留、空间/道具终态、台词前中后和声音层；每个命中特效、转场、道具、全景/空镜或参考手法专项均已写入源表；未命中专项已明确删除。覆盖确认只作生成闸门，不做成稿后的创意评分。

创意感染力自检必须在导演源冻结前完成：检查每场是否有可感知的开场停留点、观众可回看的公平线索、清楚的目标/代价、人物选择与不可逆代价、至少一次真正改变状态轴的升级、由旧策略失效推动的翻转、足够的结果确认、视觉母题的阶段推进、节奏波形的停顿与余波、由已成立结果推出的尾钩；检查关键情绪是否转成性格化非面部行动，摄影是否形成不可替代的视觉句和首读→次读→结果确认路径，反应是否沿关系网传播，台词/声音桥/声音母题/环境声/光影/滤镜后期是否共同放大而不替代因果，手机端是否有唯一首读点；同时冻结高负载镜的不可删核心与降级顺序。自检只写“成立/需补强及补强位置”，不进入交付验证器，不生成分数或关键词报告。

## 交付与验证

严格执行 [references/seedance-dual-delivery-contract.md](references/seedance-dual-delivery-contract.md)。直投版按“项目直投参数 -> 全局摄影/影调（含滤镜/后期影像）/光影/环境色彩 -> 分场光影继承表 -> 全局正负向 -> 场景 -> 逐镜”排列，场景和镜头标题使用 `｜` 分隔，每镜先写本镜环境色彩，再写连续性、起幅、摄影、光影/滤镜/材质、逐行时间线、声音和落幅。不存在的 OS、OV、BGM、特效或本镜特殊约束删除整项；直投版禁止内部版本名、色卡编号、HEX/RGB、路径、图片占位符、导演分析和“沿用上一镜/同上”。

全局正向必须逐字且只出现一次身份固定模板；普通 3D 或明确 3D CG/次世代写实项目再逐字且只出现一次 3D 写实渲染模板，明确非写实三维与非 3D 项目禁止加入该模板。全局负向必须逐字且只出现一次面部稳定模板。媒介开关、完整原文与顺序只执行 [references/seedance-dual-delivery-contract.md](references/seedance-dual-delivery-contract.md) 的唯一模板定义，禁止从视觉输入模块或其他参考复制第二版本，也禁止在逐镜特殊约束重复。

交付前只运行硬错误验证：

```bash
python3 scripts/validate_seedance_delivery.py <作品名_Seedance独立直投版.md> --source <源剧本> --director <作品名_导演审核版.md>
```

验证只检查格式、事实、可见性、道具跳变和连续性硬错误；其中时间线只检查是否按逐行时间窗从 0.0 秒连续覆盖到镜尾，不评价动作创意或表演质量。创意感染力自检已经在导演源冻结前完成，不在验证器中重复评分。验证不检查表演深度、摄影强度、景别比例、镜长倾向、光影丰富度或关键词覆盖率。技能不提供创意审核或自动创意返工入口；验证失败只修命中的硬错误，不重读全部参考、不重算剧情、不重选摄影候选。

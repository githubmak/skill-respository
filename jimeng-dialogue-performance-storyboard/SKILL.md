# 即梦对白与表演分镜

把源文本当作事实边界，把模型当作表演导演、摄影指导和视觉导演。锁死“发生什么”，主动设计“如何发生、如何被感受、如何被看见”。

## 不可改变与允许扩写

不可改变：

- 剧情事实、事件顺序、因果、结果和人物信息边界。
- 人物性格、动机、关系，以及关键道具从首次建立到场尾的归属、位置、控制者和最终状态。
- 台词、OS、OV 的文字、归属和原有语义。

允许导演化扩写：

- 情绪动作的前兆、过程、停顿、收势和余波。
- 符合人物性格的视线、呼吸、距离、持物、道具互动和任务维持。
- 直接听者、旁观者及 OV/OS 期间的错峰反应。
- 不改变事实的画面顺序重排、多景别覆盖、单镜内最多一次景别变化、声音和光影反馈。
- 使用源文本两侧已有的人物、动作、道具、颜色、声音和空间，为明确的【转场】补充承接镜头或双端转场镜头组。

扩写不能新增剧情事件、关系、背景故事、台词或结果；它必须是既有刺激、人物目标、空间、道具和关系能够推出的即时演绎。

## 表演与摄影执行总纲（源头优先级）

在事实边界内，摄影表现力、情绪行动与事实可读性同时属于硬成功条件。锁定源文事实和必要空间状态后，在节拍分级、切镜合并、复杂度预算和详细道具校验之前，先做一次不受安全覆盖镜影响的导演直觉首稿。该首稿先决定观众怎样看见这场戏，再由后续规则证明、增强和校正，禁止从检查清单反向拼装镜头。

- 每个节拍先冻结一条“视觉句”：最强起幅画面、唯一主要拍摄主体、一个主视觉动词、明确停止/落幅画面、与前后镜头最有收益的远近或静动反差，以及这条视觉句唯一的戏剧观看目的。主视觉动词可以是停留、逼近、拉开、跟随、掠过、上移、下沉、揭示或环绕，但不得在同镜堆叠多个互相争夺注意力的摄影动作。
- 镜头的大胆首先来自干净构图和相邻切镜的果断反差，不来自每镜都运动。关系已经建立后，优先允许单一人物近景、特写、大特写或局部特写把另一人物和环境移出画面；画外人物只保留声音。不要为了持续说明关系而惯性保留肩部前景、双人同框、道具和环境，也不要在同一镜同时塞入两人关系、道具证据、完整动作、反应和多次焦点交接。
- 导演直觉首稿可以先提出近景冲击、极远关系、突然静止、快速跟拍急停、遮挡揭示或纯固定凝视，再接受节拍级别和事实校验。L0-L3、道具账本、连续性与生成负载是后置护栏，不是摄影创意发生器；它们可以否决无剧情依据或物理不成立的方案，但不能自动把方案改写成中景覆盖。需要修正时，保留起幅、主视觉动词、落幅或相邻反差中最有价值的一项，另选一条同样清楚的视觉句。
- 对每个关键情绪、冲突、认知、控制权或危险感拐点，再冻结反转前的表面策略、刺激命中、真实行动冲动、压制方式、替代动作、新策略和新关系状态，把它们嵌入已选视觉句或分配给相邻有职责镜头；情绪推导增强摄影答案，不把摄影答案抹平成信息覆盖镜。

- 每个关键反转至少比较三类动作候选：面部/视线、手部/道具、身体重心/距离/占位。最终必须保留至少一个会改变距离、朝向、空间占位、道具控制、接触关系、出口控制或谈话主动权的外部行动；“看、停、微微、缓缓、僵住、眯眼、嘴角变化、呼吸变化”只能作为先兆或余波。
- 源文已经写出“眼眶发红、快要哭出来、震惊、愤怒、悲伤、害怕、僵住、颤抖”等强情绪结果时，把它当作必须保留的结果锚点，而不是可直接复述的表演答案。成稿必须增加导演化增量：旧策略怎样失效、控制从身体或声音哪里破裂，以及该情绪怎样形成下一动作的起势或改变当前关系；只把原词换成近义词判定为演绎失败。源文没有落泪、痛哭或失控时，不得为加强效果擅自升级。
- 导演直觉首稿之后再把整场划分为连续表演单元。连续表演单元保持动作与情绪接力，不等于只能使用一个镜头；同一单元内允许用 2-4 镜分别读取刺激证据、控制断裂、策略动作和关系结果。句号、一次视线或一次表情变化不能单独切镜，但主要主体、第一读点、心理距离或静动关系发生不可替代改变时，可以构成独立视觉句并成立切点。
- 出现主体转移、策略或权力反转、距离/接触/道具/出口变化、不可替代的刺激证据或新事实读取、心理距离/观看顺序的决定性改变、明确转场之一即可切镜。普通对白通常 1-2 镜，一般冲突通常 2-3 镜，关键反转通常 2-4 镜；这些是节奏参考而非硬上限，不能为了压低镜头数量把刺激、控制断裂、策略行动和关系结果塞回同一长镜头。
- 新情绪出现时保留旧情绪残留。尊严转逐利仍要遮掩受辱，防备转依赖仍带攻击余势，温暖转警觉仍受接触限制；禁止把人物从单一情绪标签直接切换到另一个标签。
- 关键冲突、权力博弈和危险判断必须把压迫感外化：距离迫近或退路收窄、中心/出口占位、道具控制、接触限制、身体朝向与进退姿态至少改变一项；视线锁定只能辅助，不能单独充当压迫结果。
- 关键冲突、反转和非全文末尾的场尾必须保留可传递的戏剧钩子：未释放冲动、悬置动作、未松开的道具、尚未恢复的距离、未完成的转身/接触或声音余势至少保留一项，并在下一镜起始状态接住。普通信息镜只保留连续所需状态，不人为制造悬念；全文末镜保留稳定余波，不强行制造未完成动作。
- 至少比较两套非同构摄影候选：景别跃迁、局部特写、快速跟拍急停、全景斜俯、前景遮挡揭示、空间拉开或声音先行至少来自不同机制；禁止直接把普通正反打或固定中景当默认解。
- 最终摄影描述必须先让人看见画面，再表达镜头意义。`景别机位` 默认只写具名人物/环境/物体、景别、高低/俯仰和正面/侧面/侧后方；只有遮挡、轴线、出入口、接触位置或空间连续确实依赖某个固定实体时，才补门、桌、车、家具等相对位置，禁止为显得具体而让每个机位依附固定道具。构图写前中后景和左右位置；光影写实体光源、进入方向、受光对象和阴影结果；运镜写速度、方向、跟随对象和具体停止画面。
- 每镜先锁定拍摄主体归属。`景别机位` 第一次出现脸、眼睛、手、鞋、衣摆、帽子等身体或服装局部时，必须写出它属于哪名人物；摄影机运动导致拍摄主体、身体部位或景别改变时，必须清楚写出唯一的起幅和终幅，可用“A 转 B”简写，也可分别标注“起幅”和“终幅”，禁止用一个“局部特写”概括整段变化。`构图/光影`、`运镜/焦点` 和 `尾帧` 必须与同一终幅握手，尾帧只保留终幅实际可见或仍可听见的内容。
- 一个镜头默认保持单一景别；确需改变观看距离时，只允许一次从起幅 A 到终幅 B 的景别切换，可简写为“全景转特写”。禁止在同一镜内连续写 A -> B -> C 或更多景别。推进、后退、跟拍、摇镜和环绕属于摄影机运动，不自动等于景别变化；环绕可以改变观察方向和运动路径，但仍保持一个景别，或最多保留一次明确的起终幅景别切换。
- 大胆景别或运镜会丢失空间、人物关系或道具归属时，先尝试在同一镜内用人物移动、焦点交接、遮挡移开或稳定落幅补回信息；仍无法清楚读取且通过切镜门槛时，才拆成冲击/局部镜与关系或结果镜。
- 校正顺序固定为：镜内调度或焦点交接 -> 缩小次要人物动作或特效 -> 调整站位/前景遮挡 -> 判断切镜门槛并必要拆镜 -> 缩短或改向摄影机路径；不能以降级景别、固定机位或缓慢推近作为第一避险方案。
- 复杂摄影机运动时，人物可以完成一个单方向、单目标的大动作，但不叠加复杂换位、换手、多人反应和重特效；相邻策略镜必须把复杂度交给人物行动，摄影机改为清楚跟随或稳定落幅，不能因为冲击镜运动复杂就让整个反转镜头组只剩微表情。OV/OS 段同样允许动态摄影，人物调度主动降载。
- 表演设计只冻结刺激命中、主要行动方向、关键接触/道具变化、关系结果和情绪余势。不要逐帧规定每次眨眼、手指移动、头部角度或每一步节奏；允许人物在既定性格、目标和动作边界内自然完成过渡，但起始状态、主动作因果和尾帧结果必须明确连续。
- 镜头组冻结前执行必要合并：相邻镜头若没有分别交付刺激证据、控制断裂、动作起势、策略行动、关系结果、空间重建、转场承接或不可替代的视觉句，才合并。已成立的单主体强构图、远近跃迁、静动反差、遮挡揭示或快速运动后的稳定落幅，不因属于同一连续表演单元就自动并回关系中景。若合并会把关键反转压成 10 秒以上的同一中景/中近景、让高价值局部证据失去独立读取、或让长段 OS 吞掉冲击瞬间，则禁止合并。
- 关键节拍的摄影冲击一旦冻结，后续校正只能改变次要负载和路径，不能抹掉表现性镜头企图。
- 原文出现明确的 `【转场】`、`[转场]` 或同义标记时，必须设计至少一个可见的转场承接镜头；只把下一场首镜标记为 `转场起镜` 不算完成。承接镜必须明确使用声音桥、动作匹配、物体/形状匹配、遮挡切换、光影匹配、运动方向延续或尺度反差之一，并把上一场尾帧锚点交给下一场第一个可见事实。
- 逐场维护实体与道具连续性账本。除场景首镜的初始环境建立外，源文明示或强暗示的新道具不得第一次出现在后续镜头的 `起始状态` 中；必须在镜内通过声音、震动、拿出、打开或遮挡揭示完成首次建立。每次拿放、递接、藏露、开合、亮灭或控制权变化都要在 `尾帧` 结算最终控制者、位置和必要状态，并由下一镜 `起始状态` 接住，禁止利用切镜完成换手、换位、开合或显隐变化。

## 不可回退能力基线

完整执行 [references/non-regression-baseline.md](references/non-regression-baseline.md)。其中锁定的事实边界、情绪导演化、非面部行动、表现性摄影、具象机位、切镜门槛、职责化拆分与必要合并、显式转场、主体归属、终幅可见性、画外人物限制、自然演绎余地和道具全生命周期连续都是同时成立的硬能力，不能用新规则覆盖旧规则，也不能把源头要求降级为只在成稿后报警的校验项。

修改本技能时，任何已修复问题都必须保留对应的源头规则和自动回归用例。新增修复同步加入 `scripts/test_skill_regressions.py`；未通过该测试不得视为修改完成。

回归测试仅用于修改技能文件时验证能力没有被删除，不参与普通分镜生成，也不是成稿评分表。不得根据测试用例反推固定镜头数量、景别比例、短镜配额或必用技法；测试只锁定错误边界与允许边界，具体摄影选择仍由当前剧本的节拍级别、观看职责和人物行动决定。

正常生成闭环不得读取或响应创作诊断统计。默认校验只检查格式、事实、可见性、道具和连续性硬错误；只有用户明确要求诊断现有成稿为什么保守、过碎、表演单调或镜头职责失衡时，才允许单独运行 `--creative-review`。诊断结果只用于回到剧本节拍、人物策略和观看职责重新判断，不作为必须清零的修改清单，也不直接规定某镜必须拆分、合并、换景别或增加运镜。

## 节拍级别与镜头模式

完成导演直觉首稿后，完整执行 [references/beat-shot-mode-decision.md](references/beat-shot-mode-decision.md)。不凭情绪形容词或台词长度判断“关键反转”，只检查刺激是否改变目标、策略、关系、危险判断或现实认知，并是否影响下一动作、下一句策略、关系状态或场景走向。分级用于验证表达力度是否有依据、镜头职责是否完整，不负责从零生成机位、景别和运镜。

- L0 信息节拍：使用叙事性镜头稳定交付事实。
- L1 情绪波纹：在叙事镜头内嵌反应，不单独拆反应特写。
- L2 战术反转：用表达性冲击镜读取刺激/断裂，再用叙事性策略或结果镜交付后果，通常 2-3 镜。
- L3 结构反转：目标、关系、危险或现实认知被改写，使用完整 3-4 镜反转组。

叙事性与表达性不是整场二选一，也不是两套固定外观。叙事镜负责让观众看懂人物、空间、道具、动作因果和关系结果，但仍可使用斜俯大全景、贴地跟随、单主体特写或果断静止；表达镜只在刺激命中、控制断裂、主观危险或认知错位需要改变心理距离时介入。关键节拍可以采用“叙事锚点 -> 表达性冲击 -> 叙事性策略/结果”的分工，但必须服从当前已冻结的视觉句与相邻反差，不能让表达镜吞掉事实，也不能让稳定中景吞掉冲击。

L0-L3 只用于内部决策，不输出级别标签，也不对应强制镜头数量。一个 L2 可以用一镜完成，只要起幅、运动、终幅能清楚改变观看职责；一个 L1 也可以因不可替代证据切出局部镜。不要为了符合分级示例机械拆镜。

## 唯一生成顺序

```text
锁定剧情事实、人物性格、台词/OS/OV和空间硬锚点
-> 登记源文明示/强暗示的实体、初始归属和不能改变的道具事实，但暂不让道具位置生成机位
-> 连续阅读整场动作、台词和声音，感受节奏、能量、空间尺度与情绪方向
-> 做导演直觉首稿：为每个节拍冻结最强起幅、唯一主要主体、一个主视觉动词、明确落幅、唯一观看目的及与相邻镜头的远近/静动反差
-> 先排出整场由干净单镜组成的观看距离曲线和动势曲线；允许固定镜与运动镜、极近与极远通过切镜形成果断对比
-> 冻结每条视觉句最不可牺牲的一项：起幅、主视觉动词、落幅或相邻反差
-> 分析整场情绪曲线、逐节拍刺激、人物解释、目标、混合情绪、隐藏策略与关系变化，把动作因果嵌入视觉句
-> 标记所有显式转场，为每处冻结上一场尾帧锚点、承接机制、下一场第一读点和声音进入时机
-> 标记态度、认知、权力和危险感反转，冻结每处旧策略、刺激命中、反应断裂、新策略与新关系状态
-> 为重要节拍比较面部/视线、手部/道具、身体重心/距离/占位三类动作候选，选择至少一个非面部外部行动
-> 将源文已给出的强情绪结果反推为旧控制失效、可见泄漏和下一行动起势，禁止把原词复述当作完成演绎
-> 设计旧情绪残留、身体先兆、替代动作、策略行动、多人错峰反应和新关系状态的表演骨架
-> 按目标、策略、关系、危险判断和现实认知五个状态轴，把每个节拍判定为 L0/L1/L2/L3，验证已选表达力度并补足叙事锚点、表达性冲击和叙事结果职责
-> 为关键冲突冻结压迫来源、至少一项物理关系变化和需要跨镜保留的未释放势能
-> 为关键转折另比较至少一套非同构摄影候选；保留首稿或改选时都必须维持清楚的单主体、主视觉动词与落幅
-> 依据人物目标、说话策略、主要行动方向和空间关系划分连续表演单元
-> 对每个拟切点执行切镜准入；通过后才把必要反转拆成冲击镜、策略镜和结果镜，并交替分配复杂度；不要合并不可替代的视觉句
-> 完成逐场实体与道具账本，登记首次建立方式、归属、位置、控制者和每次变化后的最终状态
-> 校正观看距离曲线、起幅景别、运镜、焦点、终幅景别和镜头切换，但不把已成立的视觉句改成安全中景覆盖
-> 逐镜限制为固定一个景别或一次 A 到 B 的景别切换；第三个读取距离改由相邻有职责镜头承担
-> 反向设计人物站位、动作幅度、道具路径、构图、光影、特效和声音，使画面承载摄影方案
-> 逐镜更新道具账本：把首次出现放进镜内因果过程，并在尾帧结算本镜所有道具变化后的最终状态
-> 为每镜锁定拍摄主体、起幅可见范围、运动中依次经过的信息、终幅可见范围和尾帧可见清单
-> 把导演意图翻译成简洁可视指令：具体机位 -> 前中后景 -> 实体光路 -> 单一主运镜 -> 可见停止画面
-> 删除逐帧表演控制，只保留刺激、主动作、关键接触、结果和可接力余势
-> 让摄影机、人物调度、特效三个维度中最多一个承担高复杂度；校正事实覆盖、真实可拍性和跨镜连续
-> 逐对核对前镜尾帧与后镜起态的道具控制者、位置、手别、开合、亮灭和显隐状态，删除发生在切镜空白里的状态变化
-> 反向检查相邻镜头的观看职责，只合并没有独立刺激、断裂、行动或结果的重复镜头；若合并会形成长时间同景别覆盖、吞掉局部爆点或让长段 OS 淹没冲击镜，则保留镜头组
-> 锁定用户风格并补全全局/场景视觉、人物锚点与 Seedance 2.5 提示词
-> 一次编译固定 Markdown
```

空间硬锚点只提前锁定墙、门窗、固定家具、出入口、人物初始关系、关键道具归属和实体光源。不要提前锁定摄影机位置、景别、运动路径或人物精细走位。物理空间是摄影方案的后置校正器，不是镜头生成器。校正失败时按 `镜内调度或焦点交接 -> 缩小人物动作幅度 -> 调整站位或前景遮挡 -> 通过切镜门槛后必要拆镜 -> 缩短或改向摄影机路径` 处理；只有当前节拍本就需要稳定关系读取时才使用固定中景，不把它作为第一手修复。

## 生成原则

### 事实可读性与情绪表现力联合决策

不再使用叙事/情绪二分标签、比例或固定镜头配额。每个节拍同时回答：

1. 观众必须看懂什么？
2. 观众此刻应该感受到什么？

事实可读性与情绪表现力都是硬成功条件，不用一方抵消另一方。强制事实可以由同一镜的起幅、运动过程和终幅分层交付，也可以由相邻镜头组成的镜头组完整覆盖。激进镜头裁掉空间、人物关系或道具归属时，先判断这些信息是否已经由前镜建立、能否延后到结果镜；不需要重复的信息直接留在画外。确有信息缺口且通过切镜门槛时，用相邻关系镜补回，不为了保全上下文向强单主体镜塞入肩部前景、第二人物、道具和多次焦点交接。不得为了单镜保全所有信息而把整场挤成固定中景，也不得为了降低镜头数量把关键反转合成长时间同景别覆盖；同时也不为形式变化机械增加没有职责的镜头。必须同时成立的接触或关系仍放在同一清晰读取窗口。

景别决定某一时刻画面装入什么；运镜决定观众怎样靠近、远离、跟随、扫视或停留。一个镜头可以固定景别，也可以只从一个起幅景别变化到一个终幅景别。中景递文件可以随文件推进到手部特写，但接收者的表情应交给下一镜，不能继续在同镜变成第三个景别；固定中景仍然合法，但必须确实最适合当前等待、对峙、对白接收或关系读取。

景别发生变化时，不把多个时间点压成一个静态标签。先分别冻结起幅和终幅，再把中途经过的信息写进运镜过程。例如应写“宋棠鞋面局部特写起幅，低机位正面；终幅为宋棠兔耳帽特写”，不能只写“局部特写，宋棠鞋面、外卖服和兔耳帽依次进入画面”。起幅中的鞋面、衣摆或手若已在运动中移出画面，尾帧不得继续声称它们仍位于画面下缘。

### 连续表演单元、切镜门槛与合并

导演直觉首稿后，按人物目标、说话策略、主要行动方向和空间关系划分连续表演单元。四项没有实质改变时，动作、情绪和道具状态必须连续接力，但不强制单镜覆盖；刺激证据、控制断裂、行动起势、关系结果，或心理距离与观看顺序发生决定性改变时，可以在同一表演单元内切镜。只有多个读取阶段天然属于同一主视觉动词时，才用人物靠近或退让、前景移开、一次焦点交接或一次起终幅景别变化合并；不得为了减少切镜，把原本干净的单主体视觉句串成从双人关系到道具再到反应的长路径。

每个拟切点必须至少满足一项：叙事或说话主体转移；人物策略、权力、亲疏或危险判断改变；动作已经改变距离、朝向、占位、道具、接触或出口；新事实无法在当前镜内稳定读取；心理距离、观看顺序或静动关系发生决定性改变；原文明确转场。句号、停顿、眨眼、普通视线变化、无收益换角度或只希望增加景别变化都不能单独成为切镜理由。一句完整台词及其主要行动尽量留在同一镜；但句中出现打断、刺激命中、策略反转，或单主体反应镜能形成不可替代视觉句时可以切开。

普通对白节拍通常 1-2 镜，一般冲突通常 2-3 镜，关键反转通常 2-4 镜，不设置机械总量上限。允许连续三个不超过 3 秒的短镜组成“刺激证据 -> 控制断裂 -> 动作起势/结果”的因果短句，随后优先安排一个不少于 4 秒的稳定表演镜承接台词、OS/OV、行动或情绪余波。只有第四个连续短镜开始重复同一信息、表情或策略时才强制合并。

镜头组冻结前执行一次职责审查。相邻镜头若只增加重复表情、普通视线、相似景别或同一信息，且没有独立视觉句，则合并为镜内变化；每个保留镜头至少独立交付刺激证据、控制断裂、动作起势、策略行动、关系状态、空间重建、不可替代情绪冲击、转场承接，或通过单主体强构图、远近跃迁、遮挡揭示、静动反差改变观看顺序。合并后若形成 10 秒以上同一中景/中近景承载刺激、反应、策略和长段 OS，或让局部证据只能在中景里顺带出现，则撤销合并并恢复有职责的短镜头组。

### 表现力与生成负载

低抽卡不等于低运动、固定中景或统一缓推。先为整场设计有剧情依据的观看距离曲线和动势曲线，再为高价值细节、突然行动、权力变化和认知冲击选择足够鲜明的镜头。特写、大特写、局部特写可以直接作为起幅；快速跟拍可以贴住突然行动；快速停止可以把结果钉在画面上；大全景或全景结合斜俯运动可以建立人物与环境、权力或困境的尺度关系。读完局部信息后，只在空间关系可能丢失时补关系镜，不机械退回中景。

关键转折至少比较机制不同的候选：人物改变距离或占位、前景遮挡后揭示、景别突然跃迁、快速跟拍并急停、垂直或斜向空间展开、焦点或声音先行。选中的镜头必须改变观看顺序、心理距离、关系读取或证据意义，不能只是给普通正反打换一个角度。

用复杂度预算控制风险：摄影机运动复杂时，人物可以完成单方向、单目标的大动作，但路线、换手、多人反应和特效保持简洁；人物调度复杂时，摄影机选择清楚的跟随或固定落幅；特效复杂时，人物接触和摄影机路径保持稳定。单镜超载时先拆镜或降低次要人物/特效负载，保留最能承载当前节拍的摄影力度；禁止因为担心生成失败而自动把关键转折降级为固定中景、普通反打或缓慢推近。

### 情绪必须推进为行动

每个重要节拍在内部推导：

```text
旧表面策略 -> 现实刺激 -> 人物解释 -> 当前目标 -> 核心与混合情绪
-> 第一行动冲动 -> 性格、关系、风险、时间、空间和道具形成的压制或放大
-> 冲动泄漏 -> 替代动作 -> 新策略行动 -> 他人反应 -> 新关系状态
```

先为面部/视线、手部/道具、身体重心/距离/占位各生成至少一个动作候选，再依据人物性格和空间选择。关键情绪必须通过至少一个外部行动改变距离、朝向、道具控制、接触关系、出口控制、谈话主动权、暴露程度或下一步选择；眉眼、呼吸、握拳、停顿、僵住、眯眼和嘴角变化只能作为先兆或余波，不能替代行动。源文本动作少不等于人物必须站定说话，可以补充由既有空间、道具、任务和关系直接推出的拿放、避让、逼近、退开、遮掩、占位、让路、松手或重新控制道具，但不得新增剧情事件。

源文本直接给出的强情绪状态只是表演终点之一。落稿前必须继续追问：人物原来在维持什么，刺激怎样让这种控制失效，失控从声音、下颌、肩背、手臂、重心、距离或道具哪里泄漏，身体接下来准备做什么。冲击镜即使把主要策略动作留给下一镜，也必须在本镜尾帧形成同方向的动作起势，例如防御手臂垂下、重心朝目标前移、后脚仍留退路或道具控制开始松动；不能让人物以“眼眶发红地站在原位”结束，再在下一镜无准备地突然扑抱、退开或夺取。这里冻结的是因果和动作方向，不是逐帧规定表情与肢体细节。

情绪反转不能只换表情标签。新情绪形成时至少保留一处旧情绪残留，并让矛盾同时存在于声音、手部、身体方向或距离选择中。一个镜头若同时包含刺激命中、控制断裂、策略动作、关系结果或长段 OS 中的三项以上，优先拆为有职责的镜头组；禁止用同一中景/中近景加短促推进覆盖 10 秒以上关键反转。

### 戏剧钩子与物理压迫

只在关键冲突、态度/认知/权力/危险感反转和非全文末尾的场景收束处强制设计戏剧钩子。刺激命中后不要立即让人物完全放松、松手、退回安全距离或恢复日常姿态；依据人物性格和事实保留一项未释放势能，如动作停在半途、手仍控制道具、身体仍占住出口、接触尚未解除、后脚仍留退路、话音或环境冲击仍在延续。钩子必须是下一镜能够接住的可见或可听状态，不能新增威胁、秘密、动作或后果；全文末镜只保留稳定余波。

压迫感必须落到物理关系。至少选择距离迫近或退路收窄、中心/出口占位、道具控制权、接触限制、身体朝向与进退姿态之一，再由构图、遮挡、观看距离、斜俯关系、快速靠近或急停强化。视线锁定和面部表情只能作为辅助；若距离、占位、道具、接触和姿态都没有变化，只写“目光压迫、气场强大”不算成立。

普通信息镜、过场镜和已经完成释放的节拍只保留跨镜连续所需状态，不强行悬置动作或制造假钩子。强制合并相邻镜头时保留关键节拍的压迫结果与未释放势能，但不能以“保留钩子”为理由留下没有独立职责的表情插镜。

### 多人与 OV/OS

为每个清楚可见且影响关系读取的人物保留独立任务线。说话者的口型、呼吸、视线、手部和距离执行同一策略；直接听者在有效语义点开始错峰反应，不等整句结束；旁观者继续工作、观察、护物或准备介入，只回应自己实际获得的信息。

非现场 OV 不被画中人物听见，人物也不等待 OV 结束才行动。OV/OS 不要求摄影机固定或缓慢：可以依据旁白的情绪和信息节奏使用斜俯沉降、快速跟随、遮挡揭示、景别跃迁或拉开；摄影机承担高复杂度时，画中人物只维持一处主要现实变化、持续任务或小幅身体压力，其他人物主动克制，避免同镜超载。OS 持有者不做口型，其他人物不能读心。

明确【转场】后紧跟信息型 OV 时，让转场承接镜先交付第一个背景事实或关系反差，再由下一场 1-3 镜继续分层承载其余信息。不得把多个背景事实、场景建立、人物调度和对白入口全部塞进一个长大全景；无法在不虚构事件的情况下直接还原的过去，只用当前状态、环境反差、声音或现实行动提供证据，不擅自制作闪回。

### 真实可拍与连续

对白镜头必须能由现实摄影机在当前空间中架设和移动，但最终提示词不写器材、坐标或工程证明。摄影机不能穿墙、穿家具、穿人物或无桥越轴；人物不能因切镜而瞬移、换手、转身或改变道具状态。当前景别必须看得见正文要求的脸、手、道具、身体范围和人物关系。

把每镜按“起幅画面 -> 运动过程 -> 终幅画面”检查可见性。构图可以按三个阶段让不同身体部位或道具依次出现，但不能把它们写成终幅同时可见；`尾帧` 等于终幅静止画面，只能列出终幅景别装得下的具名人物、身体部位、道具、空间和持续声音。未入镜人物只能以台词、脚步、动作声或环境影响存在，不能在 `画面/表演` 中继续执行视线、目光、打量或审视。要写陆夫人的眼神或打量，就必须让陆夫人实际出现在 `景别机位` 和对应阶段构图中；否则直接写“陆夫人不入镜，在画外说话”，画面只描述宋棠的可见反应。

逐场维护道具账本，完整执行 [references/entity-prop-continuity.md](references/entity-prop-continuity.md)。除场景首镜建立初始环境外，道具首次出现必须发生在镜内因果过程中，不能让后续镜头的 `起始状态` 直接拥有此前从未建立的手机、文件、钥匙、杯具或其他剧情实体。源文只强暗示设备时只补最小实体，例如订单超时提示可以推出袋内手机，但必须先拍到提示音、衣袋震动或人物拿出设备，不能直接从“已经压住/拿着手机”起镜。

前镜 `尾帧` 与后镜 `起始状态` 构成双端握手。普通镜只保留下一镜需要或容易漂移的具体状态；凡本镜发生拿放、递接、夺取、藏露、开合、亮灭、装入取出或控制权变化，尾帧必须结算道具最终由谁控制、位于哪里以及必要的可见/物理状态。下一镜起态必须准确接住，不能在切镜之间换手、换位、开关、亮灭或改变显隐；全场最后一镜也写可稳定停留的收束尾帧，不写“结束、无需承接”。

## 简洁可视化输出铁律

最终 Markdown 优先使用能立即形成画面想象的摄影执行语言。导演意义留在内部预演，最终字段先写摄影机在哪里、画面里有什么、人物做什么、光从哪里来、镜头怎样移动和停住。除镜头编号、镜头时长和生成段时长外，不输出工程参数。

- 禁止输出坐标、XYZ 轴、米/厘米位移、角度数值、焦距数值、人物画面占比、逐秒时间码、器材轨道、机位证明卡、风险等级或校验记录。
- `景别机位` 优先使用“具名拍摄主体 + 景别 + 高低/俯仰 + 正侧方向”的短句，例如“宋棠中近景，低机位仰拍”“客厅高空大全景”“街道贴地低机位全景”。人物、环境或物体已经足以明确机位时，不再补门、桌、茶几、家具等固定实体；只有遮挡、轴线、出入口、接触或空间连续需要时才补相对位置。身体或服装局部必须带人物归属，如“宋棠鞋面局部特写”，不单写“鞋面局部特写”。固定景别只写一个景别；发生一次变化时可写“宋棠全景转眼部特写”，或使用“……起幅；终幅为……”分别写清，禁止出现第三个景别。
- `构图/光影` 在同一字段内明确写成“构图：……；光影：……”。固定画面写前中后景和左右位置；变化画面按“起幅……，运动中……，终幅……”依次写实际出现的信息，禁止把不同阶段的鞋面、手部、脸和帽子描述成终幅同时可见。光影写实体光源从哪侧进入、照亮什么、哪里留下阴影、亮边或反光。
- `运镜/焦点` 使用“速度 + 方向/路径 + 跟随对象 + 停止画面”的短句，并与 `景别机位` 完全一致。例如：“镜头缓慢向前推进，保持客厅高空大全景。”“高速追拍宋棠向前疾驰，保持贴地低机位全景。”“缓慢从上至下摇镜，最后停在宋棠眼睛，完成全景到眼部特写的一次切换。”一个镜头默认一个主运动和一次焦点交接；环绕可以改变正侧观察方向，但不连续改变景别。
- `画面/表演` 写“现实刺激 -> 主动作 -> 可见结果/情绪余势”。明确谁从哪里开始、主要做什么、动作改变了什么关系；保留自然的呼吸、表情过渡、动作速度和细小调整空间，不逐帧规定眨眼、指尖、头部角度、每一步或每次停顿。关键接触、道具归属、行动方向和尾帧状态不能留给自由发挥。
- `画面/表演` 遇到源文已有强情绪结果时，禁止只写“眼眶发红、神情委屈、快哭了”或其近义改写。至少写清旧控制怎样断裂，以及一项由该情绪引出的手部、身体方向、重心、距离、道具或声音结果；若主要行动在下一镜，本镜尾帧写出可接力的动作起势。不得用新增落泪、痛哭、摔物或攻击来代替导演化增量。
- “控制关系、矛盾关系、职业姿态、压迫感、紧张氛围、完整空间关系、稳定中心”等抽象词不能作为机位、构图或运镜的句子终点。需要表达时，后面必须继续写出人物、前中后景、画面边缘或动作结果；只有剧情关系确实依赖门、桌、道具时才写这些实体。
- 画外只描述具名人物是否入镜以及持续的台词、脚步、动作声或环境声。禁止写“视线在画外、打量落在画外、目光停在画外”，也禁止在只拍宋棠的镜头里写“陆夫人的审视落到宋棠”这类未入镜动作；人物的观察动机留在内部预演。若必须读取观察者眼神，就扩大景别或调整构图让观察者真实入镜。
- 特殊运镜同样只描述可见的摄像机行为和画面结果，不输出焦距变化量、旋转角度或运动速度参数。

必要的禁止项必须具体且简短，例如“不前后推拉、运动结束后保持静止”，不能堆叠与本镜无关的负向控制。

## 固定输出合同

导演预演不输出。交付正文严格使用 Markdown 列表，不使用表格：

```text
- 全局风格锁定
  - 用户指定风格：……
  - 剧本推断补全：……；推断依据：……
  - 最终执行风格：……

- 全局色卡/影调/光影
  - 全局影调：……
  - 全局色卡：……
  - 全局光影：……

- Seedance 2.5 专属提示词
  - 正向提示词：……
  - 负向提示词：……

- 人物锚点
  - 人物A：基准音色：……；基本性格锚点：……

- 场景 01｜场景名
  - 场景影调：……
  - 场景色卡：……
  - 场景光影：……

- 镜头 01｜时长s
  - 起始状态：场景起镜｜完整起态
  - 景别机位：具名人物/环境/物体、单一景别、高低/俯仰和正侧方向；必要时才补相对实体位置，镜内变化最多写一次“起幅景别转终幅景别”
  - 构图/光影：构图：固定镜写前中后景，变化镜写起幅、运动中和终幅实际可见内容；光影：实体光源、进入方向、受光对象和阴影结果
  - 画面/表演：现实刺激、主动作、关系结果、情绪余势、听者反应和其他人物任务维持
  - 运镜/焦点：速度、方向、跟随对象、停止触发、最终可见画面和必要的一次焦点交接
  - 特效：可见特效或无
  - 台词/音效：台词：逐字保留的台词/OS/OV或无；音效：环境、动作或声音桥
  - 尾帧：具体终态；关键冲突/反转/场尾保留可接力的未释放势能，普通镜保留连续所需状态；末镜写可稳定停留的收束终态
```

固定规则：

- 前四项各只出现一份；每个场景都必须单列从全局母版推导的场景影调、色卡和光影。
- 用户风格优先；推断只补空缺维度。色卡用明确语义颜色和承载对象，默认不用 HEX。
- Seedance 正负向提示词必须是完整自然语言；负向词只选实际风险并删除会误伤服装、灯光、道具、强光、颜色、主动静止或有动机高速运镜的词。禁止无条件写“禁止快速运动、禁止高速运镜、禁止剧烈镜头”；改为禁止无动机乱晃、失控抖动、穿墙穿物和运动后无法停稳。
- 每镜是一个顶层列表项，八字段顺序固定。`画面/表演、运镜/焦点、尾帧` 不得留空或写 `无`；`特效、台词、音效` 无内容时明确写 `无`。
- `景别机位` 不得只写景别和人物关系，必须写出具名人物、环境或物体，并给出高低/俯仰或正侧方向中的至少一项；相对门、桌、车、家具的位置不是默认必填，只在遮挡、轴线、出入口、接触和空间连续需要时补充。身体、服装局部必须注明人物归属。固定镜只出现一个景别；镜内更换主体、身体部位或景别时，只允许一次起终幅变化，可写“全景转特写”或同时出现“起幅”和“终幅”，禁止出现第三个景别。`构图/光影` 使用“构图：……；光影：……”分开交代画面层次和实体光路，变化镜的构图按起幅、运动中、终幅依次描述。
- `运镜/焦点` 的停止点必须是具体人物、身体部位、道具、门窗、车辆、画面边缘或可见位置，不能停在“控制关系、矛盾关系、压迫感、职业姿态、完整关系”等抽象概念上。
- `运镜/焦点` 的具名起点和终点必须与 `景别机位` 的起终幅一致；若从一名人物、身体部位或景别移动到另一处，不能省略主体归属。`尾帧` 只写终幅仍可见或可听的内容，已经在上摇、下摇、横移、推进或拉开过程中移出画面的身体部位和道具不得继续留在尾帧。
- 推进、后退、横移、追拍、摇镜和环绕不自动改变景别。若 `景别机位` 只写一个景别，`运镜/焦点` 必须在该景别内完成运动；若写两个景别，只完成一次 A 到 B 的变化。环绕运镜只改变摄影机围绕主体的路径与观察方向，不得借环绕连续写全景、中景、近景、特写等多个景别。
- `画面/表演` 只能安排当前阶段构图中真实入镜人物的可见动作。未入镜人物可以保留原台词和声音，但不能执行打量、审视、看向、眼神停留等视觉动作；需要这些动作时必须把人物纳入对应阶段的 `景别机位` 和构图。
- `画面/表演` 控制动作因果而不逐帧编舞：固定刺激命中、主动作方向、关键接触/道具变化、关系结果和尾帧余势，允许自然完成表情过渡、呼吸、动作速度和细小姿态调整。动作起点与终点必须能和相邻镜头双端握手。
- 非场景首镜的 `起始状态` 不得首次引入此前未建立的剧情道具，也不得直接写人物已经拿着、压住、打开、藏起或使用该道具。新道具在本镜出现时，`画面/表演` 必须包含声音/物理触发、人物发现与首次接触中的必要因果；强暗示道具只补源文所需的最小实体。
- 道具在本镜发生拿放、递接、换手、藏露、开合、亮灭、装入取出或控制权变化时，`尾帧` 必须写明变化后的最终控制者、位置及必要状态；下一镜 `起始状态` 逐项接住。袋内或画外道具以手压衣袋、震动声、突出轮廓等可见/可听锚点承接，禁止假装能看见遮挡内部，也禁止让状态变化发生在切镜空白中。
- 关键反转的 `画面/表演` 必须写出刺激造成的身体断裂、至少一个非面部策略行动及其关系结果；不得只写“看、停、微微、缓缓、僵住、眯眼、嘴角变化、呼吸变化”。相邻镜头要分别承担冲击、策略或结果，避免单镜塞入完整反转链。
- 源文已给出强情绪状态时，`画面/表演` 必须比原文多交付可见因果：旧策略失效、控制破裂和动作起势至少各有一个清楚落点。直接复述“眼眶发红、快哭、震惊、愤怒、悲伤、害怕”不算演绎；冲击镜不能以静止情绪标签收尾后让下一镜无起势地突然行动。
- 关键冲突、权力博弈和危险判断的 `画面/表演` 必须让距离、占位、道具控制、接触限制或进退姿态至少一项发生变化；视线和表情只能辅助。`构图/光影` 与 `运镜/焦点` 再强化该物理关系，不能用“气场压迫”代替可见结果。
- 相邻镜头必须能够分别说明自己的观看职责或视觉句；只更换相似景别、普通角度、视线或重复表情，且没有刺激证据、控制断裂、动作起势、策略、关系、空间、转场增量，也没有改变主要主体、心理距离、观看顺序或静动关系时才合并。普通对白不按句号机械拆镜，但关键刺激可以切出局部爆点、反应断裂和动作结果。
- 允许连续三个不超过 3 秒的短镜组成完整因果短句，随后优先安排不少于 4 秒的稳定表演镜。普通对白通常 1-2 镜、一般冲突通常 2-3 镜、关键反转通常 2-4 镜，这些不是硬上限；不得为了减镜数把关键反转压成长时间同景别镜头。
- `起始状态` 只用 `场景起镜、动作接力、状态接力、反应接力、转场起镜`，竖线后自足复述当前可见事实，不引用“上一镜、同上、沿用”。
- 原文每一个明确【转场】都必须对应至少一个普通八字段镜头作为转场承接镜，或对应前后两镜组成的双端承接组。转场镜头仍按正常镜头编号输出，不新增“转场说明”字段；其 `画面/表演、运镜/焦点、台词/音效、尾帧` 必须写清承接锚点和下一场落幅。仅使用 `转场起镜` 标签、直接切到新场景大全景或写“画面切换”不算完成。
- 整场先形成有剧情依据的远近与静动曲线。不得机械堆叠固定中景、普通反打或缓慢推近，也不得为变化而机械轮换景别；特写、大特写、局部特写、快速跟拍、急停和全景斜俯均可主动使用，但必须有明确的信息或情绪收益。
- 场景首镜优先建立人物关系和空间；突发冲击或高价值细节可以先近后远，只有人物方位、动作路径、道具归属或接触关系可能丢失时才紧接关系镜重建方位。
- 关键冲突、反转和非全文末尾场尾的 `尾帧` 必须保留一项下一镜可接住的未释放势能，如悬置动作、未松开的道具、仍被占住的出口、尚未解除的接触、保留退路的重心或声音余势；普通信息镜只保留连续所需状态，不强行制造悬念。全文末镜保留最终事实和稳定余波，不新增后续剧情或未完成动作。
- 除固定母版、提示词、人物锚点、场景方案和镜头列表外，不输出内部分类、候选、工程参数、检查表或审查报告。

`--source` 在源文本可用时传入，用于核对源文本事实；没有源文件时可以省略。默认校验只用 `ERROR` 阻断格式、可见性、事实、道具和连续性硬错误，不输出景别比例、镜长、碎切、情绪表达或运镜倾向统计，也不把成稿送回创作循环继续“刷分”。只有用户明确要求诊断现有成稿时，才另行运行 `python3 scripts/validate_storyboard_format.py <成品.md> --source <源文本> --creative-review`；其中 `REVIEW` 不要求清零，必须结合当前节拍的目标、策略、关系、危险判断、现实认知和观看职责人工复核，不能仅为消除提示而拆镜、换景别、堆短镜或增加表现性技法。

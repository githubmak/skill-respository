# 即梦对白表演分镜

## 必填输入

只询问缺失的必填输入：

- 导出目录（`export_dir`）
- 视觉风格（`style`）
- 画幅比例（`aspect_ratio`）
- 源文本或源文件

除非源文本缺失或无法读取，不要额外询问格式选择。

## 低耗上下文加载

常规生成只读：

- [runtime-brief.md](references/runtime-brief.md)：生成流程和取舍顺序。
- [output-template.md](references/output-template.md)：最终 Markdown 结构和字段。
- [stable-shot-contract.md](references/stable-shot-contract.md)：单镜稳定边界。

按需追加：

- 对白密集、情绪弱、节拍缺戏剧性、关键反应镜头：读 [prompt-performance-rules.md](references/prompt-performance-rules.md)。
- 用户要求画面质感、吸引力、材质真实、构图、焦段、运镜高级感、胶片感、转场氛围，或生成内容显得塑料、平、廉价、背景假：读 [visual-attraction-rules.md](references/visual-attraction-rules.md)。
- 多人物、桌/柜台/车/门口/走廊、医院/警局/街道等空间、道具或衣物转移、行走/离场、闪回/梦境、提示词过载、用户指出空间/镜头/听者问题：读 [spatial-camera-continuity.md](references/spatial-camera-continuity.md)、[physical-structure-continuity.md](references/physical-structure-continuity.md) 和 [shot-patterns.md](references/shot-patterns.md)。
- 源文出现躺、伏、靠、抱、扶、摔倒、急刹、坐姿/坐在吊椅或沙发、翻身、坐起、披衣、开门、下车、屏幕文字、人群围观等概括动作词时，必须读 [physical-structure-continuity.md](references/physical-structure-continuity.md)。
- 保存前运行 `scripts/validate_storyboard.py <output.md>`；脚本覆盖不了的高风险歧义才读 [validation-checklist.md](references/validation-checklist.md)。

本技能只面向当前固定模板；旧 Markdown 与当前规则冲突时，按当前模板重写，不做兼容。

## 总控规则

- 默认按不同场景拆分导出 Markdown：源文有几个不同场景，就在 `export_dir` 生成几个场景文件；拆分的是交付文件，不是空间连续性。生成前必须先建立 `本集空间锁定总表`，为每个地点分配稳定空间ID、固定锚点、人物槽位基准、入口/出口和道具活动区；各场景文件只能复用或截取这张总表，不能重新解释空间。
- 每个场景文件使用同一套模板、使用说明、全局锁定和通用负面提示词；`全局锁定` 中必须保留一致的 `本集空间锁定索引`。每个文件只替换本场景的详细 `场景状态表` 与 `分镜投喂卡`，但本场景状态表开头必须复写该场景的 `空间主锁定句`。若全篇只有一个场景，才导出一个 Markdown；除非用户明确要求“合并成一个文件”，不要把所有场景放进同一个 Markdown。
- 同一地点跨文件再次出现时，必须复用同一个空间ID和同一句空间主锁定；若人物、道具、门窗或站位从上一段发生变化，必须用上一段尾帧状态或源文新动作解释，不得因新文件重新开局、重排左右或重置道具。
- 生成前必须建立 `本集影调色卡索引`：根据剧本情绪、场景功能和现实层，为每个场景分配影调、主色、辅助色、点缀色、光线质感和情绪用途。多文件输出时，各文件的全局锁定必须保留同一份影调色卡索引；单镜提示词只写本镜需要的光色变化，不逐镜堆满色卡词。
- 影调必须转译为本镜可见质感：每条直接提示词按需写清光源方向、受光面、浅阴影/反光控制、背景虚化和一项剧情相关材质；不要用 `高级感、电影感、质感很好` 替代可见光影。
- 构图、焦段、运镜、材质只服务本镜唯一任务。每条直接提示词最多选择 1-2 个视觉增强点；若本镜已有长台词、多人反应、道具转移或复杂运镜，优先保稳定，只保留一个光影/构图锚点。
- 场景文件命名使用可排序格式，例如 `第七集_S1_商业街_即梦投喂分镜.md`、`第七集_S2_警局_即梦投喂分镜.md`；文件名去掉斜杠、冒号、换行等系统非法字符。
- 直接导出最终 Markdown 到 `export_dir`，使用当前模板；不输出草稿表，不兼容旧格式，不引用其他本地技能。如需任务内副本，再复制到当前任务 `outputs/`。
- 重跑时只以源文和当前规则为输入，不读取旧分镜做批量补丁。
- 生成阶段优先：先通读完整源文，建立 `源头约束底图`，再写镜头。底图必须一次性锁定剧情节拍、空间位置、人物朝向、状态/道具、物理反推、张弛曲线、情绪钩子、多人体反应、影调色卡、光影质感、构图焦段、声音文本/口型处理和单镜风险；后期校验只兜底，不承担主要修复。
- 除非用户允许修改，原样保留所有台词、OS、OV、系统音、内心独白、标点、引号、省略号、异常空格和疑似错名。
- 可见人物说出口的台词、OS、OV、系统音、内心独白和旁白默认必须进入 `【画面描述｜直接复制】`；可见台词驱动正确口型，OS/OV/系统音/内心独白/旁白写成 `标签：“原文。”` 且画面中可见人物闭口。所有声音文本进入画面描述时，必须同句绑定可见情绪、身体动作、道具反应或空间关系变化，不能只写声音文字。手机聊天消息、来电名称、通知弹窗等 UI 文本默认由 AI 直接生成画面侧边绿色气泡/字幕浮层，具体文字进入 `【画面描述｜直接复制】`；必须声明独立二维浮层、安全区、不属于手机屏幕、不贴手机背面、不跟随手机透视。只有用户明确要求“不要AI生成文字/后期叠字处理/后期加字”时，才改为后期叠字路线，并把具体文字移到 `【表演与声音】` 中的后期文字句。
- 每个子镜头 `<=15s`；`【画面描述｜直接复制】` 必须是可独立投喂即梦的正向提示词，`<=500` 个中文字符，优先 220-380 字。
- 复杂镜头可按需添加 `【关键帧生图提示】` 和 `【即梦视频提示｜配合关键帧】`；普通镜头不强制，字段名不得使用旧英文缩写表头。
- 高风险镜头按需在单镜末尾追加两条 Markdown 输出：`【本镜必要约束｜直接复制】` 写正向逻辑连续性约束，`【本镜补充负面提示词｜直接复制】` 写本镜坏相压制；普通低风险镜头不要强制输出，避免臃肿。
- 全局锁定仍承载完整索引；但每个子镜头的 `【画面描述｜直接复制】` 开头必须写压缩版 `视觉场景前缀`：画幅/视觉风格 + 本场景固定锚点 + 本场景影调光线。不要整段复制全局锁定，也不要遗漏本镜真实可见主体、必要听者/肩线、必要道具和固定锚点。
- 缺失视觉细节可按原文语境合理推断，重要假设写入 `使用说明`。

## 生成权重

所有镜头先走四系统：空间、状态、镜头、表演。

1. 硬门槛：人物不瞬移、不换位、不多出无关人物；面向、距离、隔物、道具归属、口型和单镜任务稳定。未过门槛时，拆镜、补定位、减少入画人物或降低运镜。
2. 创作默认：剧情节拍与观众认知 > 非台词张力点 > 情绪表演×景别运镜匹配度 > 声音氛围。安全以后必须让画面有戏；关键台词后优先给被击中者独立余波镜，并在尾帧给出关系定格。
3. 多人活体默认：多人戏中，清晰入画的具名非主表演者不能只是“闭口站着”。写镜头前为每个可见人物分配主表演、受击反应、观察反应或背景弱化角色；若没有反应容量，就把该人物降为肩线、边缘虚化或画外，不要让清晰人物呆滞占画面。
4. 张弛有度：每个镜头组先判断张力功能：铺垫、升压、峰值、释放或缓冲。不要每个镜头都强推近/强表情/强停顿；强张力后必须给短余波或关系缓冲，轻对白中也要保留一个非台词张力点。
5. 质感与流畅默认：单镜先定光影锚点和动作过渡链。人物强动作时镜头少动；镜头明显推/拉/转焦时，人物只做低幅动作；道具、转身、起身、接触和离场必须写出中间过渡帧，避免结果跳变。

局部优先级：

- 对白卡：`说话者正确口型 > 听者反应 > 运镜`。
- 道具/身体变化卡：`开头状态 > 可见转换 > 稳定终态 > 台词/反应 > 尾帧状态`。

## 直接提示词红线

- 禁用元叙述/占位词：`继承`、`延续上一镜`、`上一镜`、`尾帧`、`位置不变`、`剪辑`、`切到`、`反打到`、`后期插入`、`脑海浮现`、`当前主角`、`当前对话者` 等。`【状态继承】` 可以记录上一镜结束事实，但 `【画面描述｜直接复制】` 只能写本镜开头已经可见的当前事实。
- 人物参考图负责脸部身份；提示词只写可见连续事实，不用“双人锁脸/强制锁脸”等元词，不让组级人物表污染单镜。
- 普通对白不能是“地点 + 站位 + 台词”；必须有空间锚点、物理关系、身体朝向、道具状态、情绪泄露、镜头状态和尾帧。
- 普通画面不能只写 `电影感、细腻质感、光影高级`；必须落成光源方向、脸/手/道具受光位置、背景虚化或反光控制、可见材质纹理中的一到两项。
- 朝向、接物、道具归属必须有可见链条；上一镜背向/侧身/面向固定物，下一镜不能无转身就面对说话或接物。
- 一镜不承担三项以上高风险任务；正反打成对保轴，手部/物件镜用特写或斜俯近景，关键虚化/距离/道具关系按需轻量量化。

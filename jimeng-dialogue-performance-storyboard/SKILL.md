# 即梦对白与表演分镜

先保留原文事实，再证明现实空间与摄影机实际可拍，最后在已成立的剧情和空间内追求情绪深度、关系读取和场景专属导演惊喜。

硬优先级：

`原剧本事实 > 真实空间/物理可拍 > 人物与道具连续 > 用户指定风格 > 剧本推断风格 > 场景级导演策略 > 单镜主观看任务 > 情绪与创意落实 > Seedance表达`

后项不能推翻前项。创意可以改变观看顺序、表演层次、构图意义和声音压力，不能补造人物换位、道具交接、台词含义、外部事件或新反转。

## 唯一工作流

```text
冻结原文事实与空间关系
-> 为重要节拍生成刺激—理解—目标—情绪—策略—动作链
-> 锁定用户风格并依据剧本补全空缺维度
-> 生成全局视觉母版、逐场景视觉方案、人物锚点和Seedance 2.5提示词
-> 进行唯一一次内部导演预演
-> 比较物理可拍的非同构导演候选并冻结镜头组
-> 一次编译八字段、镜尾接力和Markdown交付
```

所有语义决策必须在八字段落稿前完成。在同一次预演中解决原文保真、人物行动因果、多人/OV活性、单一主观看任务、景别可见范围、现实站位、家具遮挡、现实摄影机位置与路径、焦点、光影、尾帧和下一镜起态。候选冲突时直接改调度、景别、机位、焦点或镜头边界，不先写问题镜头再启动第二轮导演审查。

## 生成阶段必读

按以下顺序完整读取并执行，详细规则只以对应参考为真源：

1. [references/visual-character-master.md](references/visual-character-master.md)：先锁定用户提供的风格，只依据剧本补全用户未定义的维度，再生成唯一一份语义化全局影调、对象色卡、实体光影；为每个场景从该母版推导独立影调、色卡和实体光影；再生成人物基准音色/基本性格锚点和按整场裁剪的Seedance 2.5正负向提示词。
2. [references/one-pass-director-previsualization.md](references/one-pass-director-previsualization.md)：在一条连续时间线上联合推演情绪到行动、多人错峰反应、OV/OS活性、真实空间、景别机位、焦点、惊喜和镜间接力。

只在当前任务确实需要细化空间、景别、构图、表演、情绪反差、Seedance表达或二维空间图时读取 [references/on-demand-storyboard-reference.md](references/on-demand-storyboard-reference.md) 的对应小节，不把示例或技巧当固定镜头模板。

## 生成原则

### 原文与情绪行动

锁定事件顺序、因果、人物动机、台词归属、OS/OV归属和场景基础设定。台词、OS、OV逐字保留；只有用户明确授权时才改文意。

每个重要节拍先在内部完成：

```text
上一状态
-> 人物实际看见/听见的刺激
-> 主观解释
-> 此刻想得到、保住、确认、拒绝或隐藏什么
-> 核心情绪与混合情绪
-> 第一行动冲动
-> 关系、风险、时间、道具和空间造成的压制/放大
-> 2-3个合理动作候选
-> 选择最符合人物习惯且会改变关系信息的动作
-> 身体先兆 -> 可见行动 -> 对方反应 -> 新关系状态
```

情绪不是给既定动作补表情。它必须改变人物距离、朝向、道具控制、谈话主动权、暴露程度或下一步选择之一。表层表演、身体破绽和隐藏策略可以同时存在，但最终必须推进为行动；眉眼、呼吸、手指和停顿不能独立代替行动。合理推断即时反应，不发明背景故事、人物关系或剧情事件。

人物锚点只固定稳定基线：`基准音色`写音高、声质、共鸣、吐字和常态语速；`基本性格锚点`写会影响行动选择的稳定倾向。锚点不等于每镜同一种情绪，也不写完整人物小传或未经原文支持的背景。

### 多人与OV/OS

每个清楚可见且影响关系读取的人物都拥有独立任务线：

`实际获得的信息 -> 与当前事件的关系 -> 正在维持的任务 -> 反应阈值 -> 触发点 -> 可见反应 -> 下一倾向`

- 说话者的口型、呼吸、视线、手部和身体距离共同执行同一策略。
- 直接听者在有效语义点开始小幅错峰反应，不等整句说完才统一响应。
- 旁观者继续核对、观察、护物、工作或准备介入，只回应自己实际获得的信息，不站成无任务背景。
- 非现场OV不被画中人物听见，人物也不等待OV结束才行动。整段优先用一处现实微动作、正在维持的任务或环境动态承接时间；默认一名关键人物发生一次主要变化，其余人物主动保持，现实关系再次变化时才增加第二处错峰变化。
- OS持有者不做口型，其他人物不能读心，只回应现实刺激。

“无明显反应”必须表现为主动克制：目光、呼吸、重心、姿态、持物或任务仍有可读压力。人物不必持续增加新动作，也不按时间轴机械轮流动。

### 现实摄影机与观看任务

对白技能只使用现实中可架设、可移动、可完成的摄影机方案。固定、肩扛/手持、稳定器、滑轨、摇臂等器材必须有机身/支撑、操作者和连续运动通道；摄影机不得穿过墙、家具、门板或人物身体，也不得用“AI摄影机”绕过场地宽度和景别可见范围。

每镜只保留一个第一读点和一个主观看任务。景别必须拍得到正文要求读取的脸、手、道具、身体范围和人物关系；近景不承担全身路径，远景不承担微表情。换机位、换景别不等于人物自动换位、转身、换手或改变道具状态；这些变化必须由镜内可见动作或明确转场成立。

景别切换回答“观众此刻必须新看见什么”。没有新增关系、证据、反应、尺度或控制权信息时，保持景别，改用表演、构图、遮挡、道具或声音推进。关键转折在同次预演中比较表演/调度、构图/道具、声音/观看顺序等非同构候选；惊喜必须增加关系或策略读取，普通推近、无信息环绕、突然低机位和高速甩镜不算惊喜。

`运镜/焦点` 分开写摄影机运动、人物视线和焦点变化。固定镜头明确写“摄影机全程固定不移动”。焦点只落在具名人物的面部/眼睛/手、具名道具或明确空间平面；禁止写“焦点交给关系/情绪/氛围、带到某人”。多人同时可读时写中等/较深景深和清晰范围；抽焦默认只做一次主交接，写清现实触发、起始对象、终点对象和保持到尾帧。

### 视觉与连续

全局影调、色卡和光影必须由剧本的时间、天气、空间、材质、人物服装/关系、情绪曲线、关键道具和实体光源推导。影调写亮暗/空气和关系压力；色卡把语义化颜色分给具体对象，默认不用HEX；光影写实体来源、方向、高度、覆盖、遮挡、衰减、材质反射和剧情变化。三个字段必须互相一致，不能只列“莫兰迪、冷峻、主光、曝光层级”等标签。

全局视觉母版只负责跨场一致性，不能替代场景设计。每个发生地点、时间、天气、人物关系阶段或主光条件变化的场景都必须单列 `场景影调、场景色卡、场景光影`：先写它继承母版的稳定规则，再写此场因空间、时段、情绪、道具或实体光源而发生的具体变化。即使整份脚本只有一个场景，也必须输出一份场景视觉方案；它不是重复全局三项，而是把该场最亮区、暗部可读范围、对象颜色主次、光源方向/遮挡和关系压力落到具体时空。

每镜 `构图/光影` 写 `具体对象 + 画面位置 + 光源来源 + 受光/遮挡结果 + 本镜变化`。观众应能从自然语言复原谁在画面哪一侧、家具怎样分隔、光照到脸/手/道具的哪一面、什么细节仍清楚，以及关系变化如何成为具体可见结果。

每镜尾帧冻结人物屏幕侧/朝向、姿态/重心、肢体/道具归属、未完成动作、环境/声音残留和情绪/关系余波。下一镜只继承当前景别可见且高漂移的2-4项，并选择动作接力、状态接力、反应接力或转场起镜。全场最后一镜也必须写可稳定停留的收束终态，不得写“结束、无后续镜、无需承接”。

## 固定输出合同

导演预演不输出。交付正文严格使用Markdown列表，不使用表格：

```text
- 全局风格锁定
  - 用户指定风格：……
  - 剧本推断补全：……；推断依据：……
  - 最终执行风格：……

- 全局色卡/影调/光影
  - 全局影调：……
  - 全局色卡：……
  - 全局光影：……

- Seedance 2.5 专属提示词
  - 正向提示词：……
  - 负向提示词：……

- 人物锚点
  - 人物A：基准音色：……；基本性格锚点：……
  - 人物B：基准音色：……；基本性格锚点：……

- 场景 01｜场景名
  - 场景影调：继承全局的……；此场……形成……亮暗、空气与关系压力，……仍保持可读。
  - 场景色卡：继承……；本场由……承载……色，……退为……，用于区分……。
  - 场景光影：……作为实体光源从……方向照向……；被……遮挡后……，……移动/剧情变化时……。

- 镜头 01｜时长s
  - 起始状态：场景起镜｜完整起态
  - 景别机位：景别、现实摄影机承载方式、相对人物/地标的位置、角度和轴线侧
  - 构图/光影：基于全局母版的对象位置、遮挡、光源、受光结果和本镜变化
  - 画面/表演：本镜可见事件、说话者策略、听者反应和其他人物任务维持
  - 运镜/焦点：摄影机运动/固定、触发、连续路径、速度、焦点对象/交接和稳定落幅
  - 特效：可见特效或无
  - 台词/音效：台词：逐字保留的台词/OS/OV或无；音效：环境、动作或声音桥
  - 尾帧：具体终态；末镜写可稳定停留的收束终态
```

固定规则：

- 前四项依次为全局风格锁定、全局视觉母版、Seedance 2.5提示词和人物锚点，各只出现一份。其后每个场景必须出现一次 `场景 NN｜场景名` 及场景影调、场景色卡、场景光影，再列出该场镜头；用户明确内容进入 `用户指定风格`，模型只补用户未定义的维度，`最终执行风格` 冲突时只采用用户版本；未提供风格时必须明确标注由剧本推断，不得伪造用户指定。
- 场景视觉方案从全局母版推导，不复制母版全文，也不得另起一套无来源的调色或补光。场景发生时空、空间、主光、天气或关系阶段变化时，必须新建场景方案；同一连续场景内只在镜头 `构图/光影` 写由调度、遮挡、动作和情绪触发的可见增量。
- 最终执行风格必须编译进正向提示词，逐镜不得无因漂移画风、材质、人物比例、表演尺度或时代审美；人物锚点每名主要人物只写基准音色和基本性格锚点。
- 负向提示词只选本场实际风险；颜色、强光和静止必须带“无剧情/无光源/无任务依据”的条件，与服装、灯光、道具、特效或主动克制冲突时删除。
- 每镜是一个顶层列表项，标题固定为 `- 镜头 NN｜时长s`，编号从01连续递增；其下八字段顺序固定，字段之间不插空行，相邻镜头之间留一个空行。
- `起始状态` 只使用 `场景起镜、动作接力、状态接力、反应接力、转场起镜`，竖线后写自足起态，不用“上一镜、继续上一镜、同上、沿用”替代事实。
- `景别机位` 必须明确现实摄影机承载方式、位置、角度和轴线侧，并与场地和可见范围一致。
- `画面/表演` 先写主动作/说话者策略，再写关键听者的语义触发反应和其他可见人物的任务维持；只写观众可见的动作、停顿、呼吸、视线、重心和幅度，不写不可见心理。
- `运镜/焦点` 先写摄影机是否移动及具体路径，再写景深和具体焦点对象；单镜默认最多一次主焦点交接。
- `特效` 有内容时写可见源点、形态、作用和残留，没有写 `无`；特效造成的照明/反射写入 `构图/光影`。
- `台词/音效` 固定写成 `台词：……；音效：……`；无内容分别写 `无`，台词/OS/OV逐字保留。
- `画面/表演、运镜/焦点、尾帧` 不得省略、留空或写 `无`。普通镜尾帧保留下一镜所需或高漂移的2-4项；全场末镜保留最终结果和稳定收束，不新增原文没有的后续动作。
- 除固定风格/全局视觉/场景视觉/提示词/人物母版和镜头列表外，不加表格、导演卡、候选分析或检查报告。

交付前运行：

```bash
python3 scripts/validate_storyboard_format.py <成品.md>
```

校验器只检查固定结构、字段、编号、接力类型、非空内容和明确空洞指代。原文保真、物理空间、景别、遮挡、情绪、多人反应、OV动作量、光影和创意收益已在唯一一次预演中解决，不在输出阶段重新评审或整组改写。

# 电影级光影、影调与色卡圣经

本文件只负责已冻结剧情与视觉句的光影、色彩、材质、曝光、滤镜/后期影像和特效受光编译；压力曲线、视觉母题、节奏波形和镜头主机制由 `ai-manga-dramatic-direction-engine.md` 一次冻结，不在本文件重新导演。

本文件是全剧曝光、光比、色温、光源方向、色卡继承、滤镜/后期影像继承、光影剧情曲线和特效受光的唯一真源。目标是形成摄影指导级控制，不把“电影感、柔和窗光、冷暖对比”当成结论，也不在直投版逐镜复制相同环境色段落。

## 全局光影圣经

拆镜前从视觉风格、母色卡、时空、天气、场景材质、人物关系和剧情曲线冻结以下结论：

1. **曝光层级**：环境基准、人物脸、关键手部/道具、背景和高光的相对亮度。导演版可用相对档位或 EV 范围；直投版改写成“人物略亮于背景、暗侧仍有纹理”等可见结果。
2. **主辅光比**：主光、环境补光和背景亮度关系，说明阴影是否柔和、深邃、硬切或逐步收紧。没有测光依据时给关系范围，不伪造唯一精确值。
3. **白平衡与色温关系**：主光、实景灯和反射补光的冷暖范围及混光边界。导演版可登记 Kelvin 范围；直投版转成中性日光、轻暖墙面反射、冷色环境边缘等自然语言。
4. **实体光源与方向**：窗、门、天空、灯、火、屏幕或街道反射从何处进入，经过什么遮挡，照亮谁，阴影落向哪里；反打和人物移动后方向仍成立。
5. **反差、黑位与高光**：全片对比、饱和、黑位密度、中间调、肤色、高光滚降、空气和材质响应；人脸保护不等于无方向平光。
6. **色卡层级**：母色卡控制环境颜色家族、冷暖、明暗、饱和和面积；资产固有色与真实受光优先。每场只选实际需要的 3—7 个颜色角色，不机械用满全部色块。
7. **人物/情境曝光原则**：谁在常态下更稳定、更亮、更受遮挡；权力、亲密、危险、真相和余波变化时，曝光与阴影怎样响应人物行动。
8. **特效受光边界**：特效是否自发光、遮光、反射、投影或改变空气密度；作用范围、人物/材质响应、消散后恢复或保留的状态。
9. **滤镜/后期影像基线**：常驻的扩散/柔化、胶片颗粒、光晕/晕映、色散、快门拖影或局部降饱和等后期语法；写清服务的观看目的、覆盖范围、面部与资产保护边界，不用滤镜替代实体光源、构图或动作因果。

技术数值只用于建立稳定关系，不以参数堆积代替画面。写实日景可以参考人物相对近邻背景略亮约 0.3—0.7EV、室内主辅光比约 2:1—3:1、室外面部明暗比约 1.5:1—2:1，但必须按场景、媒介、色卡和戏剧目的调整，不能机械套用。

## 视觉版本继承与升级门

全剧视觉版本按唯一层级向下继承：

`STYLE（媒介/渲染范式） -> TONE（综合色调与黑位） -> FILTER BASE（滤镜/后期影像基线） -> MASTER PALETTE（母色卡颜色家族/面积职责） -> SCENE VERSION（地点、时段、天气、实体光源） -> SHOT DELTA（本镜真实变化）`

- `STYLE` 和 `TONE` 全剧固定；`MASTER PALETTE` 只约束未被资产锁定的环境/空气/背景。
- `FILTER BASE` 固定全片的影像质感边界，例如颗粒粗细、扩散/光晕是否存在、边缘衰减、色散上限、运动拖影和高光响应；它不改变人物五官、服装固有色、道具身份或场景结构。
- `SCENE VERSION` 只有在时间、天气、门窗、灯具、停电、火焰、屏幕或已成立世界规则改变时升级；每次升级登记触发镜、保留结构/肤色/材质项和变化的亮暗/冷暖边界。
- `SHOT DELTA` 同时记录真实光影差量和有因果的滤镜差量；无真实触发就继承当前版本，不随机换滤镜。
- 优先级固定为 `资产固有色 > 真实实体受光 > SCENE VERSION > MASTER PALETTE`。母色卡不得改写衣服、道具、皮肤或纹样固有色；特效只能在自身作用范围改变受光，作用范围外恢复版本基线。

### 滤镜/后期影像执行规则

滤镜是构图和叙事的后期影像层，不是“电影感”形容词。每个项目先冻结 `FILTER BASE`，再按场景和镜头登记真实差量；滤镜不得单独承担人物身份、空间关系、动作结果或关键证据的可读性。

- **常驻质感**：可选择干净数字、细腻胶片颗粒、轻微高光扩散、柔和高光滚降或克制边缘衰减；同一项目保持纹理、颗粒和光学质感连续。
- **注意力滤镜**：只有在画面已有主驱动力时，才用局部降饱和、边缘压暗、背景柔化、局部扩散或高光分离引导首读点；主体脸、手、关键道具和动作接触区不得被滤镜吞没。
- **光学触发**：光晕、炫光、镜面反射、色散、运动拖影或曝光脉冲必须由画面内的实体光源、反射面、快速运动、遮挡切换或已成立特效触发，并写清开始、峰值、衰减和停止状态。
- **情绪/认知变化**：滤镜可以随已成立的压迫、回忆、失控或结果余波改变对比、清晰度、颗粒或色彩分离，但必须有剧情触发和前后可见差异；不得用默认黑白、棕黄、蓝橙或高饱和替代情绪导演。
- **人脸与资产保护**：禁止锐化光晕、颗粒污染眼睛/嘴唇、色散拆开五官轮廓、滤镜改变肤色基线、衣服固有色或道具身份；运动拖影不得制造多张脸或重复道具。
- **手机端与生成稳定**：高频颗粒、强闪烁、重色散、厚重晕影和持续脉冲只在确有剧情收益时短时使用；首读点、台词口型、手部接触和落幅状态必须在滤镜下仍清楚可读。

滤镜状态采用 `关闭 -> 常驻/前兆 -> 局部激活 -> 衰减 -> 余波`，每次变化至少写触发、覆盖区域、观看收益和恢复/保留结果。没有因果差量时写当前滤镜基线的可见结果，不写“换滤镜”或套用风格名。

条件特效使用独立叠加链：`VFX SOURCE -> EFFECT GATE -> VFX LIFECYCLE -> SHOT DELTA`。门默认关闭，只有原文/用户设定中的来源、触发、能力规则和当前可见阶段同时成立才开启；它只能局部叠加到当前镜差量，不能反向修改 `STYLE/TONE/MASTER PALETTE/SCENE VERSION`。消散后按现实余波决定恢复基线还是保留破损、烟尘、湿润或温度结果。

项目存在多种既定能力/异常视觉时，在导演源内建立条件特效库；每个模块登记所属对象、唯一身份职责、触发/前兆/出现/持续/消散/结束条件、颜色层职责、形态/透明度/密度/速度/方向、与重力/风/碰撞/遮挡/材质的关系、局部照明/受力/温度/破损、作用范围/衰减、禁止污染对象和现实余波。用户未提供永久颜色时不得自行指定。

每镜门状态只允许：关闭、可见前兆、激活/持续、消散、结束余波。关闭状态在直投正向、负面、色彩、光影、参考图和时间线中对该模块零提及；前兆不得提前出现完整特效；激活只调用当前阶段；消散写恢复过程；结束只保留有依据的现实后果。多个模块只有原文明确同时可见才并行，并分别锁定来源、位置、身份色、遮挡、对象和结果。

导演版可记录内部版本标签和技术关系用于人工核对；直投版只翻译成“当前人物处在何种亮暗/冷暖/受光结果”，不得泄露标签、编号、HEX/RGB 或版本名。

### 风格、影调、场景灯光与景深分层

`STYLE` 只固定媒介/渲染范式、写实程度、时代质感、人物比例/解剖、材质审美、摄影气质、表演呈现和帧间稳定。具体焦段、景别、机位、轨迹、构图重心、全片浅景深、单场家具/天气/灯位、单镜逆光/曝光/焦点和情绪光影都不得上提为全剧风格常量。

`TONE` 固定综合色彩、对比/饱和边界、黑位、中间调、高光滚降、白平衡基准、人物/背景关系、肤色底线和材质显色；场景灯光负责实际时间、地点、天气、灯位、色温和衰减。场景可以在影调边界内改变明度、色温和颜色主次，不能改变全剧黑位、高光滚降、肤色基准和材质逻辑。

景深随信息任务变化：大全景、空间建立和多人调度优先中等/较深景深；双人关系镜根据权力与观看顺序决定两人是否同时清晰；近景/特写可用浅景深分离主体，但保留必要空间线索。禁止用全片大光圈浅景深掩盖空间、关系和群像调度。

## 场景、人物与光影一体构图

每场先建立三条可见轴，再联合选择构图，不把人物贴在漂亮背景前：

1. **场景轴**：入口/出口、通路、纵深、地形/家具、危险区、时代材质和可形成前景的实体边界。
2. **人物轴**：人物目标、朝向、关系距离、动作路径、控制/退让位置、需要被看见的脸/手/道具与最终落点。
3. **光影轴**：实体主光来源、入射方向、遮挡、空气介质、亮暗路径、反射补光、投影方向、背景亮度和材质响应。

构图至少让人物与两个场景关系发生作用，例如“人物与出口/压力源”“人物与道具/见证者”“人物与光区/阴影边界”。优先用前景框架、纵深路径、引导线、负空间、对角运动、反射层、框中框、中心/边缘权力和明暗面积，把人物目标与压力直接变成画面结构。前景不能遮掉唯一动作，背景不能只作装饰。

每个场景选择一个视觉主构图母题和可随剧情变化的构图参数：人物距离、中心/边缘、可用空间、遮挡开合、景深、主光面积、背景亮度或空气密度。建立、加压、翻转和兑现必须让其中至少一项发生可见变化；变化可以多层联动，不设固定数量，但必须由人物调度、光源、天气、门窗、特效或摄影机位置触发。

### 高级光影候选生成器

光影先回答“观众此刻需要看见什么、谁掌握空间、人物要隐藏/暴露什么、材质如何证明动作”，再从候选家族组合；示例是候选语法，不是场景模板：

- **实体方向**：窗/门/天光/火/屏幕/车灯/街灯/反射墙地/水面/金属反弹形成侧光、侧逆光、轮廓、窄光、负补光、局部硬切、反射光或多源混光；
- **空间压迫**：出口亮而人物暗、人物进入窄光、前景遮挡切开光区、顶光压低空间、长廊光带逐步收缩、群体背光形成社会墙；
- **认知翻转**：先藏来源后让实体光源揭示、反射中出现关系、阴影先到人物后到物体、光区变化伴随门窗/遮挡/能力触发、背景突然从亮面变为真实暗面；
- **情绪与关系**：共享光区/分离光区、两人不同色温但同一实体体系、人物靠近时亮暗边界移动、触碰后局部反射改变、关系断裂时同框光线分层；
- **自然大气**：晨霭、雨幕、雪粒、尘土、炊烟、水汽、蒸汽、雾、烟尘或热浪只在场景存在且有光源/风向/背景条件时显形；
- **奇观受光**：世界内特效局部自发光、遮光、投影、折射、体积密度或热浪改变附近人物、材质、阴影与空气，作用范围外保持稳定；
- **风格化后期语法**：高反差黑位、柔和高光、彩色边缘、曝光脉冲、短时色温偏移、冻结后余光或镜面光学，只强化已成立刺激，不伪造事实。

主要光影节拍可比较不同光影机制，按剧情收益、面部可读、空间连贯、材质证明、手机端阅读和特效受光选择一套或分窗口交接；数量由场景复杂度决定。连续场景若复用同一窗光、蓝橙对冲、金色逆光、霓虹染脸或体积光，应确认复用仍有叙事职责。具体丁达尔、轮廓、负补光等只在物理条件成立时调用，不能因示例出现就默认套用。

### 真实大气光与丁达尔效应

丁达尔光/体积光束只有同时满足以下条件才生成：明确的方向性强光；雾、晨霭、水汽、烟尘、谷物粉尘或空气颗粒等可见介质；门窗、树冠、屋檐、缝隙或建筑形成束状遮挡；光束背后存在足够暗的背景或侧逆光角度。缺少任一条件时，改用薄雾泛光、轮廓光、长阴影或空气透视，不凭空画出光柱。

清晨农村可在剧本时空和天气允许时采用：低角度暖色晨光从树隙、屋檐、谷仓门或窗缝斜入；冷色天空环境光保持远处田野和阴影层次；晨雾、炊烟、扬尘或谷物粉尘让光束分层可见；人物在侧逆光边缘获得轮廓，脸部由泥地、白墙、木板或浅色作物的真实反射托回可读中间调；露水、叶片、工具金属和湿土只在对应角度出现细小高光。光束必须被人物走动、门板开合、牲畜/工具或风向真实遮挡并产生连续变化。

农村晨景不能自动等于金黄滤镜和满屏光柱。没有雾尘或遮挡时，使用清冷晨气、低角长影、逆光露水、薄暖地平线和远近田垄形成层次；人物肤色与资产固有色仍服从真实受光和母色卡边界。

### 典型场景的条件构图机会

- **都市夜景**：以玻璃、屏幕、车灯、街灯、办公室顶灯或店铺实景灯建立多层反射和纵深；湿地反光、玻璃叠影和霓虹只在场景存在时使用，颜色不得污染肤色和身份色。
- **古代/宫廷**：用门框、帘幕、台阶、座次、柱列、屏风和烛灯/窗光形成礼制空间；高位人物占据光区或中心不是固定公式，权力翻转时可让原中心失去光区、出口或完整构图。
- **田野/工坊/种田**：让田垄、灌溉线、工具、作物高度、蒸汽、粉尘、火候、湿土和劳动队列成为引导线与材质节奏；成果镜必须呈现工序前后差值和人物尺度。
- **雨雪/风暴**：用侧逆光读清雨雪方向、地面反射、衣料吸水、呼吸白雾和风力；天气必须影响人物动作、声音、能见度和路线，而非背景循环贴片。
- **玄幻/斗法/异世界**：让世界内特效成为局部动态光源或遮光体，改变附近人物、材质、阴影和空气；以熟悉人物/道具、地面或建筑作为尺度参照，避免只有漂亮能量背景。
- **言情/亲密**：光影服务触碰许可、距离和伪装破裂，可用共享/分离光区、反射、窗框或浅景深，但保留关系位置和环境声音，不默认奶油平光。

典型机会不是模板。每场只调用物理条件和剧情职责成立的部分，并结合用户风格、母色卡、资产图和真实空间重新设计。

## 景别级面部曝光保护

逐镜先根据人物实际画面尺寸确定面部保护等级，再决定情绪阴影和背景压暗；环境可以低调，但不能用黑脸代替压迫感：

- **大全景/远景**：保证人数、轮廓、身份色、朝向、位置和身体关系；可见面部不得纯黑或过曝白块，不要求特写级眼神细节。
- **全景/中景**：保证主要人物五官结构、自然肤色、眼窝和下颌关系可读；次要人物达到身份可辨，保留主光方向和暗侧体积。
- **中近景/近景**：保护双眼、鼻梁、嘴唇、下颌、暗侧肤色、低频皮肤纹理和稳定眼神光；转头与运镜期间曝光、白平衡和肤色连续。
- **特写/大特写**：保护实际入画区域的五官、湿润高光、发丝投影和皮肤微纹理边界；禁止锐化光晕、细碎阴影扫脸、妆容漂移和无来源平光。

多人镜头按每个人的画面尺寸分别执行。面部保护不是把整张脸抬平，而是由墙面、地面、天空、灯具或其他实体反射把暗侧托回可读中间调，同时保留主光方向、骨骼转折和环境暗度。

逆光/侧逆光、夜景、烛光、背景亮于面部、人物跨越明暗区、快速转头、近景湿润眼眶、哭戏、受伤污渍、格栅/树影/玻璃/水面投影均为面部高风险镜头。逐镜必须写补光的实体来源、受影响区域、阴影边界、运动曝光和白平衡连续性；细碎投影优先落在墙面、地面、肩背或服装，不得随机扫过眼睛、鼻梁和嘴唇。

## 光影剧情曲线

全剧必须形成“建立 -> 侵入/加压 -> 翻转 -> 兑现/余波”的光影变化曲线：

- **建立**：首个有效场景冻结现实光源、白平衡、肤色基线和主要颜色面积。
- **加压**：由人物移动、门窗开合、天气、灯具、遮挡或已成立特效逐步改变亮暗边界，不随机换滤镜。
- **翻转**：关键证据、关系或危险出现时，让曝光层级、冷暖面积、阴影边界、空气密度或高光响应按真实触发联动变化；不设固定变化项数量，但必须保留世界光源逻辑、人物可读性和清楚主差异。
- **兑现/余波**：让人物、道具、空间或材质承担变化后的稳定结果；特效结束时写清光色、阴影和反射是否恢复。

喜剧不靠突然升饱和，言情不靠奶油平光，打斗不靠全场频闪，宫斗不靠无来源顶光，玄幻不靠整屋无因变色。光影必须由实体或世界规则触发并服务当前类型承诺。

## 场景与逐镜编译

直投版每场视觉方案固定五项：

- **场景影调**：明暗、对比、饱和、黑位和人物/背景层级。
- **场景滤镜/后期影像**：继承 `FILTER BASE` 的颗粒、扩散、光晕、边缘衰减、色散、运动拖影和清晰度边界；存在剧情/光学变化时写触发、覆盖区域、观看收益、峰值、衰减和恢复结果。
- **场景环境色彩**：颜色家族、冷暖、作用区域和面积关系，不写色卡编号或 HEX/RGB。
- **场景光影**：实体主光、辅光/反射、方向、硬软、遮挡和人脸保护。
- **光影变化触发**：从哪个既有动作、声音、信息、灯具、天气或特效开始改变，何时稳定。

逐镜 `光影/色彩/材质` 必须按“当前景别级面部曝光 + 主光/辅光实际落点 + 背景亮度关系 + 当前滤镜/后期影像状态 + 关键材质反馈 + 落幅稳定状态”展开，再补相对场景方案的真实差量。每镜至少写清：人物脸的亮暗侧、肤色/白平衡连续性、关键手部或道具的受光、滤镜基线的可见结果、一个主要材质的反射/摩擦/湿润/破损反馈，以及移动、遮挡、接触、光学条件或特效导致的光影/滤镜变化区间。没有物理或滤镜变化时也要明确当前主体处于哪个光区、面部按哪级保护、滤镜基线怎样保持、道具控制者和材质状态如何保持；禁止用“光影不变”“沿用场景光”“套用电影滤镜”代替执行事实，也禁止逐镜复制整段全局色卡。

这条规则明确替代旧式“逐镜 `光影/色彩/材质` 只写相对场景方案的实际差量”的过度压缩写法；差量仍保留，但必须附带当前镜头的完整执行快照。

## 逐镜材质反馈矩阵

只展开当前镜实际出现并参与动作、证据、光影或余波的材质：

- **皮肤/头发**：自然次表面散射、低频纹理、稳定湿润高光和发丝投影；运动中不强化毛孔、不产生蜡感、斑驳或环境纹理迁移。
- **布料/皮革**：写褶皱方向、拉伸/回弹、摩擦、摆动滞后、粗糙度和受光变化；衣料反馈必须服从身体方向和风力。
- **金属/玻璃/屏幕**：写实体光源反射、锐边高光、粗糙度、透明/遮挡、指纹或破损边界；反射不能生成不存在的人物、文字或场景。
- **木材/石材/墙地面**：写粗糙度、接触阴影、摩擦、裂纹、尘屑、湿润或受力位置；纹理不迁移到人物或其他资产。
- **纸张/液体/烟尘/雨雪**：写滑动、弯折、液面惯性、扩散、沉降、附着、遮挡和声音延迟；方向、速度和衰减服从动作/风/重力。
- **VFX影响材质**：写自发光/遮光、局部反射、投影、受力、温度、烟尘和消散恢复；作用范围之外的肤色、资产固有色和背景保持稳定。

每镜至少选择一个最能证明动作、力度、证据或情绪结果的材质反馈。存在多个关键材质时可全部写入秒级时间线，但要分别标出触发、受影响对象、方向、强度、停止和落幅状态。

## 跨场景视觉连续与版本继承

换场保持媒介/渲染范式、黑位、高光滚降、饱和边界、肤色基线和材质显色逻辑；新场只根据时间、地点、天气和实体光源重新分配环境颜色与亮度。资产固有色不随母色卡改色。

同地点同时间复用既有场景光源与空间结构；只有时间、天气、门窗、灯具、火灾、停电或特效等真实物理条件改变时才升级场景版本，并登记变化原因、起始镜头、保留项和变化项。硬切可以改变亮度/色温，但肤色、材质和全剧综合色彩家族不能漂移；声音、运动方向、道具色、遮挡或光向至少选择一个因果桥承接余压。

## 特效光影生命周期

世界内特效按当前镜真实阶段处理：

`前兆 -> 激活 -> 传播/作用 -> 峰值 -> 消散 -> 现实余波`

每个阶段只回答当前可见的来源、亮度/遮光、颜色、范围、方向、速度、投影、人物/材质反射和环境后果。非发光烟雾不能产生强彩色补光；自发光特效必须同步改变附近皮肤、布料、墙面和阴影，但不吞掉首读点。未出现、未激活或结束后无后果时，直投版零提及。

## 手机端与首次生成必成条件

以下光影、曝光、材质和手机端可读结论随全局、分场及逐镜源表同轮生成，不在直投成稿后扫描亮度词或补通用光效：

- 导演版已写清曝光层级、主辅光比、色温关系、实体光源、分场光影继承表、光影变化曲线和特效受光边界。

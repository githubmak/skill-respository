# 显式转场镜头语法

原文出现 `【转场】`、`[转场]`、`转场：` 或明确要求承接时，必须生成实际编号的转场镜头或双端镜头组。只结束旧场、创建新场卡片，或把新场首镜标为“转场起镜”不算完成。

## 四项冻结

```text
上一场最后一个可见/可听锚点
-> 一个主承接机制
-> 下一场第一个可见读点
-> 台词/OS/OV/环境声/动作声的进入侧与时机
```

转场镜使用普通直投逐镜字段。它可以单镜跨场，也可以由旧场尾镜与新场首镜双端完成，但观众必须直接感知旧场如何变成新场。

## 承接机制

- **声音桥**：旧场尾句、动作声、提示音或环境声跨切延续，再由新场声源接管。
- **动作匹配**：落杯、关门、转身、抬手、落脚或移动方向在新场接续。
- **物体/形状匹配**：两场真实存在的屏幕、杯沿、车窗、门框、灯或衣料匹配。
- **遮挡切换**：衣料、门板、车身、实体前景或阴影占满画面，退开后进入新场。
- **光影匹配**：旧场亮面/暗部接新场同方向光区，不无因改变时段。
- **运动方向延续**：新场以相同方向和相近速度接住旧场运动，再稳定落幅。
- **尺度/意义反差**：局部与大全景、温暖近景与压迫全景形成反差，但还需声音、形状、颜色或运动之一作为实际桥梁。

每个时间窗有一个主承接机制；较长转场可让声音桥、动作/形状匹配、遮挡和光影按先后交接，但每一项都必须增加可读的时空联系，不能无职责堆叠。

## 信息型 OV

转场后的 OV 含多个背景事实时，转场镜只交付第一个事实、身份反差或因果入口；下一场 1-3 镜再分别交付人物现状、空间关系和现实行动。过去事件没有明确场面时，不虚构闪回，用当前状态、环境反差、已有道具、声音和现实行动证明结果。

## 双端握手

旧场尾镜至少留下具体声音、占满画面的实体、运动方向、颜色/亮面或未完成动作之一。新场转场镜的起始状态既要自足建立新场，也要在画面/表演、摄影/焦点或声音中接住该锚点。

合格结构示意：“旧场门板合拢并以关门声收束 -> 新场从车门打开起镜，尾响延续为车门声 -> 门让开后落到新场人物。”实际使用必须替换为源文本两侧真实存在的动作、实体、颜色和声音，不能为转场新增关键物件或事件。

转场还必须继承上一场未解除的情绪压力、身体残留、道具归属和声音余势。高张力、未决冲突或未完成动作不能被无因唯美空镜清零；应通过声音、运动方向、遮挡、光向、道具或构图把余压带入下一场，直到剧情明确释放。新场不得静默重置人物情绪、光源版本、空间方向或物理终态。

## 首次生成必成条件

旧场锚点、新场接点、桥接机制、跨场余势和新事实随转场镜同轮生成，不把标签留给后置创意检查：

- 有实际编号镜头，不只写场景卡、自然转场或画面切换。
- 旧场有明确锚点，新场在起幅或声音中接住。
- 转场交付一个新的事实、关系或情绪意义，并稳定落幅。
- 信息型 OV 已分层，不挤入单个长大全景。
- 未虚构源文本没有提供的过去事件。

# 显式转场镜头语法

原文出现 `【转场】`、`[转场]`、`转场：` 或明确要求转场承接时，必须把它当作一个导演节拍。不能只结束上一场、创建下一场卡片，再把新场首镜标为 `转场起镜`。

## 四项冻结

为每处显式转场先冻结：

```text
上一场最后一个可见或可听锚点
-> 使用哪一种承接机制
-> 下一场第一个可见读点
-> 台词、OS、OV、环境声或动作声在哪一侧进入
```

转场镜仍是普通八字段镜头。可以是一镜跨场完成，也可以由上一场尾镜与下一场首镜构成双端承接组；两种方式都必须让观众直接感知“上一场怎样变成下一场”。

## 可用承接机制

- 声音桥：上一场动作声、提示音、尾句或环境声延续到下一场，第一个新画面出现后再完成声音交接。
- 动作匹配：上一场落杯、关门、转身、抬手或移动方向，与下一场开门、落脚、车辆驶入或同方向动作匹配。
- 物体/形状匹配：手机屏、杯沿、车窗、门框、圆形灯、黑色衣料等真实存在的形状或颜色相接。
- 遮挡切换：人物衣料、门板、车身、前景物或阴影占满画面，遮挡退开后进入下一场。
- 光影匹配：旧场亮面、屏光、窗光或黑场接入新场同方向亮面或暗部，不无因改变时段。
- 运动方向延续：上一场镜头向左、向下、向前或快速甩动，下一场以相同方向和相近速度接住，再稳定落幅。
- 尺度或意义反差：上一场局部窘迫物件切到下一场宏大环境，或温暖近景切到压迫性全景；必须有声音、形状、颜色或运动中的另一项作为实际桥梁，不能只靠反差口号。

每处转场只选一个主机制，必要时叠加一个辅助机制。不要把叠化、甩镜、黑场、声音桥和物体匹配全部写进同一镜。

## 信息型 OV 的承载

转场后 OV 含有两个以上背景事实时：

1. 转场承接镜交付第一个事实、身份反差或因果入口。
2. 下一场 1-3 镜分别交付人物当前状态、空间关系和现实行动。
3. 对话开始前确保观众已经读清最必要的背景事实。

不能用一个长大全景同时承担转场、环境建立、多个背景事实、多人追赶和对白入口。过去事件没有明确场面时，不擅自生成中毒、医院、事故或回忆闪回；改用当前人物状态、真实环境反差、已有道具、声音和现实行动证明结果。

## 双端握手

上一场尾镜至少留下一个可承接锚点：具体声音、占满画面的实体、运动方向、颜色亮面或未完成动作。下一场转场镜的起始状态必须自足复述新场事实，同时在 `画面/表演`、`运镜/焦点` 或 `台词/音效` 中明确接住该锚点。

- 不合格：“转场起镜｜陆钦站在别墅外。镜头斜俯建立别墅。”只有新场建立，没有承接。
- 不合格：“画面切换到别墅外。”没有可见机制和稳定落幅。
- 合格：“手机提示音尾声持续，冷白屏光占满画面；匹配切到出租车车窗的冷白反光，镜头快速拉开，最终定格陆钦、出租车和身后的别墅，画外音从车窗出现时进入。”
- 合格双端组：上一场尾镜让门板向镜头合拢并以关门声收束；下一场首镜从另一扇车门打开起镜，关门尾响延续为车门声，镜头随车门让开后落到新场人物。

合格示例只说明承接结构。实际使用时必须换成源文本两侧真实存在的动作、道具、颜色和声音，不能为了转场新增关键物件或剧情事件。

## 转场完成度闸门

- 是否存在实际编号的转场镜头，而不只是场景卡或 `转场起镜` 标签？
- 上一场是否留下明确锚点？
- 下一场是否在起幅或声音中接住锚点？
- 转场是否交付了一个新的事实、关系或情绪意义？
- 信息型 OV 是否被分层，而不是压进单个长大全景？
- 是否避免虚构源文本没有提供的过去事件？

任一关键项缺失时，在一次预演中补转场镜、改尾帧锚点或拆分 OV 视觉节拍，不用“自然转场、电影感切换、画面淡出”等空话代替。

# 表现性反转镜头组示例

只学习“冲击镜交付刺激、策略镜交付人物行动、结果镜交付新关系”的职责分工和八字段写法。人物、台词、动作、光影与机位必须依据当前源文本重写，不能复制本例剧情，也不能把所有反转都套成短促逼近。

```markdown
- 镜头 07｜2s
  - 起始状态：反应接力｜林岚站在桌面右侧，右手压住文件，周启站在桌面左侧与她对视，双方尚未移动
  - 景别机位：局部特写，从周启手臂旁看向林岚压住文件的右手，本镜只读取台词命中后手部压力突然消失
  - 构图/光影：林岚右手与文件位于画面中央，周启袖口形成虚化前景，窗光照亮纸面折痕
  - 画面/表演：周启的声音从前景外传来；林岚原本压紧文件的手指突然松开，掌心离开纸面，旧有强硬姿态第一次断裂
  - 运镜/焦点：声音命中时直接切入手部局部特写，摄影机保持固定，焦点锁定从压紧到松开的手指
  - 特效：无
  - 台词/音效：台词：周启：你一直都知道。；音效：纸张恢复平整的轻响，室内底噪压低
  - 尾帧：林岚右手已经离开文件，文件仍留在桌面中央，周启袖口位于前景

- 镜头 08｜3s
  - 起始状态：动作接力｜林岚站在桌面右侧并已松开文件，周启站在左侧，文件留在两人之间
  - 景别机位：中全景，从桌面侧面完整读取林岚、周启、文件和门口关系
  - 构图/光影：两人分处桌面两侧，文件位于中央，门口留在林岚身后；窗光横过桌面形成清楚边界
  - 画面/表演：林岚仍维持冷静口吻，却把文件推回周启一侧，随后侧身让出桌边并向门口退开一步；周启没有追近，只低头看向被推回的文件
  - 运镜/焦点：摄影机沿文件被推回的方向清楚横移，林岚退向门口时小幅让开遮挡，停在能同时读清她、周启和文件的新位置
  - 特效：无
  - 台词/音效：台词：无；音效：纸张滑过桌面的摩擦声，林岚一步落地声
  - 尾帧：文件停在周启一侧，林岚退到靠近门口的位置，周启仍站在桌边看向文件

- 镜头 09｜3s
  - 起始状态：状态接力｜文件停在周启一侧，林岚位于门口附近，周启站在桌边，双方距离已经拉开
  - 景别机位：全景斜俯，从房间高处读取桌面、门口和两人新的空间关系
  - 构图/光影：周启与文件被留在房间内侧，林岚靠近门口，桌面斜向切开两人；窗光停在空出的桌边位置
  - 画面/表演：林岚没有立刻离开，身体朝门口、视线却仍留在周启身上，强硬残留与退让同时存在；周启抬眼看她，手没有碰文件
  - 运镜/焦点：镜头从斜俯全景小幅沉降后静止，以清楚景深冻结文件归属、两人距离和出口关系
  - 特效：无
  - 台词/音效：台词：无；音效：安静室内环境声，远处门外声
  - 尾帧：林岚停在门口方向但仍回看周启，周启与文件留在桌边，两人被桌面和距离共同分开
```

本组按镜头交接复杂度：镜头 07 用局部切入交付冲击，镜头 08 让人物通过推回文件和退向出口完成新策略，镜头 09 用斜俯关系冻结结果。若源文本不支持文件、退向门口或关系疏远，必须换成当前场景真实存在的道具、距离、接触或占位动作。

不同反转应更换主机制：态度转变可以声音先行后接道具或身体策略；身份认出可以遮挡揭示后接单方向快速靠近；权力变化可以先改变道具或出口控制再用关系全景；温情转危险可以先读异常局部，再让空闲手、视线和重心进入验证或脱离准备。不要连续复用“眼部大特写 + 短促逼近 + 急停”。

# 校验清单

先运行 `scripts/validate_storyboard.py <output.md>`。本清单只用于脚本校验后的精简人工复核。

## 结构

- 文件只使用当前精简 `output-template.md` 结构；不要接受旧标题、草稿表格或兼容别名。
- 多场景源文默认拆成多个 Markdown 文件；每个文件都包含完整模板、相同全局锁定和通用负面提示词，只保留本场景 `场景状态表` 与 `分镜投喂卡`。除非用户明确要求合并版，不接受所有场景挤在一个 Markdown 里。
- 拆文件不能拆空间锁。抽查每个文件的 `全局锁定`：必须有一致的 `本集空间锁定索引`。抽查每个 `场景状态表`：开头必须复写本场景 `空间ID` 和 `空间主锁定句`；同一地点跨文件再次出现时，空间ID和空间主锁定句必须完全一致。
- 同一地点跨文件再次出现，人物/道具/门窗/槽位若变化，必须能追溯到上一段尾帧或源文新动作；否则判为新文件重置空间。
- 抽查 `全局锁定` 是否包含一致的 `本集影调色卡索引`；每个 `场景状态表` 必须复写本场景 `影调色卡句`。同一场景内影调不得随镜头乱换；除非闪回、梦境、时间/光源变化或情绪峰值有源文支撑。
- 每条 `【画面描述｜直接复制】` 开头必须有压缩 `视觉场景前缀`，包含画幅/视觉风格、本场景固定锚点、本场景影调光线；不能只依赖顶部全局锁定。前缀不应整段复制全局锁定，通常控制在 35-80 个中文字符。
- 影调色卡必须服务剧情功能，且不能污染人物服装、肤色、伤痕和关键道具颜色。若直接提示词逐镜堆满主色/辅助色/点缀色，导致信息过载或色彩抢戏，判为色卡使用过度。
- 抽查每条普通剧情/对白直接提示词是否把影调落成可见质感：至少有光源方向、受光/阴影落点、背景虚化/反光控制或剧情相关材质中的一项。只写 `电影感、高级感、细腻质感、光影很好`，判为空泛质感。
- 视觉增强不能过载：同一条直接提示词若同时堆皮肤、布料、墙面、玻璃、金属、胶片、雾、尘埃、强构图、焦段和复杂运镜，判为吸引力堆料失败。普通镜头最多 1-2 个视觉增强点，复杂口型/道具/多人镜头只保留一个光影或构图锚点。
- 每个 `#### S场景-节拍` 组有一个组级 `【出现人物】`，后面直接接一个或多个本组内编号的 `【镜号】1/2/...` 子镜头。每个子镜头都有四个默认字段；可选字段只在对应生成风险真实存在时出现。
- 高风险镜头可追加 `【本镜必要约束｜直接复制】` 和 `【本镜补充负面提示词｜直接复制】`。普通低风险镜头不要强制输出这两栏；若输出，必要约束最多 3 条正向事实，补充负面最多 12 个短词。
- `【本镜必要约束｜直接复制】` 只写逻辑连续性和生成优先级：出现人物范围、口型闭合、道具位置、身体朝向、UI后期叠字安全区。不得写 `不要手崩、不要换脸` 这类坏相。
- `【本镜补充负面提示词｜直接复制】` 只写本镜坏相压制：手指畸形、道具漂浮穿手、非说话者口型乱动、屏幕乱字、站位互换、背景人物抢焦等。不得写人物站位、道具归属、情绪递进或动作链逻辑。
- 组级 `【出现人物】` 只是本组曾经可见的人物索引，不是每条子镜头的画面人数要求，也不随单条子镜头一起投喂即梦。抽查每个子镜头：直接提示词只写本镜真实可见主体、必要听者/肩线、必要道具和固定锚点；不能为了照顾组级人物表把无关人物塞进背景。
- 多人戏抽查清晰入画人物是否有活体层级：主表演者、受击反应者、观察反应者或背景弱化者。清晰具名人物不能只写 `闭口站着`、`看着`、`在旁边`；至少要有闭口口型控制、视线方向、呼吸/眨眼或一项低幅身体/手部反应。若没有反应容量，应被写成边缘肩线、后景弱虚化或不入画。
- 一条镜头中若所有人同时明显动作，判为抢焦过载；安全状态应是一个主表演者、一个明显反应者，其他人物低幅活体状态。
- 对白戏抽查 `【画面描述｜直接复制】` 和 `【表演与声音】`：必须有开口前锁位、唯一可见说话者、说完闭口，以及触发词或句末后一个主要听者低幅反应。若只有说话者口型、其他清晰人物“闭口看着”，判为对话活体不足。
- 连续多句对白中，听者反应不能机械重复同一动作；至少按剧情压力在视线、手/道具、肩背/距离或独立余波中轮换。
- 每个镜头都 `<=15s`。
- 组级 `【出现人物】` 只列可见人物/群体，每行一个。不要列 OS/系统音或提到但不出画的人，也不要在子镜头内重复该字段。
- `【画面描述｜直接复制】` 不超过 500 个中文字符，并且能作为即梦正向提示词独立成立。
- 除手部特写、空景、纯物件插入外，普通对白/剧情镜头不能过瘦。直接提示词至少要自然包含固定锚点、人物物理关系、前后层级或遮挡、身体朝向、道具状态、可见情绪泄露、镜头静止理由或单一路径、画面结束状态中的大部分；不能只是地点、站位和台词。
- 普通对白/剧情镜头还要包含一个具体画面质感落点：脸/手/道具受光、浅阴影、玻璃/手机/纸面/金属/衣料等材质，或背景虚化/反光压暗。若质感词没有对应可见对象，判为无效。
- 构图必须写成画面事实，不只写术语。`黄金分割、九宫格、留白、框架构图、对称构图` 若没有人物占画比例、眼睛/脸部落点、门框/窗框/柜台等可见框架或画面侧关系，判为无效构图。
- 可见人物说出口的台词默认必须原样进入 `【画面描述｜直接复制】`，保留引号、标点和省略号，并同时写清开口者的可见动作/情绪和听者反应。`【表演与声音】`、`【口型分窗】` 可重复用于声音/口型控制，但不能成为可见台词唯一出现的位置。只有用户明确要求不放入画面描述，才允许不写入直接提示词。
- OS、OV、系统音、内心独白、旁白若有具体文本，默认必须进入 `【画面描述｜直接复制】`，写成 `OS：“...”`、`OV：“...”`、`系统音：“...”` 这种标签、冒号、引号格式；不要裸写，也不要写成 `OS以...响起：“...”`。
- OS/OV/系统音/内心独白/旁白不驱动画面中人物嘴巴，但必须在同一条 `【画面描述｜直接复制】` 内绑定可见反应：人物闭口、眼/眉/呼吸/肩背/手/道具/距离变化中的至少一项。若只有声音文本，没有画面反应，判为声音画面脱节。
- `## 通用负面提示词｜直接复制` 包含基础身份稳定、画面稳定和防僵硬词。

## 源文保真

- 生成前必须通读完整源文，并在同一连续动作段内做后续动作反推：后文若要翻身、坐起、起身、下车、开门、递物、撞到道具、换位或离场，前文姿态、道具、门车门、衣物和屏幕状态必须支持该动作。
- 每句原对白、OS、OV、系统音、内心独白、动作节拍、人群节拍、旁白、闪回标记、道具/服装变化和反应节拍都要内部核对。只有需要该附录时，才出现在 `附录｜原文保留检查` 中。
- 推动剧情的非对白节拍必须出现在直接提示词或明确的后期处理说明中，不能只写在含糊的校验备注里。
- 除非用户允许修改，必须保留原文措辞。
- 跨场景服装、道具、伤痕和 UI 变化在本集状态线中出现一次，并在每次变化后作为当前可见事实重写。
- 每个重要剧情转折均在内部检查为 `观众开场认知 -> 可见线索 -> 情绪转折 -> 观众终场认知/状态`。这个母节拍不输出为镜头卡，由子镜头共同完成。

## 直接提示词安全

- 任何直接提示词都不包含简称或元叙述：`继承`、`延续上一镜`、`上一镜`、`尾帧`、`空间保持`、`位置继承`、`物理座位不变`、`剪辑`、`切到`、`反打到`、`下一镜执行`、`脑海浮现`、`后期插入`、`声音语气：`、`表情：`、`动作：`、`情绪：`、`左外`。
- 相邻镜头衔接必须使用“下一镜开头当前事实重写”。若 `【画面描述｜直接复制】` 直接写 `上一镜尾帧/继承/切到/接上一镜`，判为切镜穿帮风险；正确做法是把上一镜结束事实改写成当前镜头开头可见事实。
- 每个复杂镜头都以静态锚点开头，并先写物理关系，再写画面构图。
- 空间语言必须写清基准：画面侧、人物相对侧、桌/门/车侧、前景/背景。
- 重要代词必须消解：执行者、说话者、道具持有人、移动者、接收者和听者都要具名。

## 空间、道具和连续性

- 概括动作词必须转成物理结构链：`起点 -> 支撑/接触/方向 -> 可见转换 -> 稳定终态 -> 下一镜继承`。抽查 `躺、伏、靠、抱、扶、摔倒、急刹、翻身、坐起、披衣、开门、下车、屏幕显示、人群围观、走过去、离开`，不能只保留概括词。
- 复杂人体姿态必须写头部、肩背、腰臀、双腿、双脚、支撑点、接触点和非接触边界中的关键项。若后文要翻身、坐起、起身或撞到道具，前文姿态必须物理上支持该动作；否则判为姿态跳变。
- 检查相邻镜头人体支撑点承接：上一镜 `【状态继承】` 若写了臀部/腰臀/腰部/肩背/双腿与吊椅、座垫、靠背、扶手、沙发、床等承载物的接触关系，下一镜开头必须复写同一支撑点。若下一镜直接写 `坐在吊椅中间/坐在椅子上/坐着/靠着/躺着` 而没有手撑、脚踩、腰臀挪动、重心转移和新支撑点稳定，判为姿态支撑跳变。
- 亲密接触镜头必须写接触边界：哪些部位接触、哪些部位不接触，是否跨坐/缠绕/压住对方，腰臀是否仍在座椅/床/沙发。边界应是正向事实，不写进负面提示词。
- 场景状态表、人物位置/机位侧表、道具表与直接提示词使用同一套词汇。
- 使用任何场景模板时，都必须有源文证据支持固定锚点、入口/出口、物理槽位、隔物和道具。若证据不足，回到通用空间锁定。
- 同侧双人组先作为一个整体稳定，再做画面层次；对侧人物必须留在隔物另一侧，不能插入同侧双人组之间。
- 斜向镜头要说明近端/远端顺序，但不能改变物理座位。
- 活动道具必须有起点、接触手/边缘、路径、松手/新持有人和尾帧停放位置。
- 转身、递物、起身、坐下、靠近、离场、手机离耳、门车门开合必须有中间过渡帧。若上一状态和下一状态之间只写结果，例如 `转身看向`、`递给`、`起身站到`、`把手机收起`，但没有脚步/肩线/接触/支撑/松手/稳定终态，判为动作跳变。
- 检查相邻镜头物品承接：上一镜 `【状态继承】` 若写了物品在某人手里/包内/口袋/桌面/台面，下一镜第一帧必须同样写明；如果变成另一持有人、另一只手、另一容器或另一表面，必须先写接触、移动、松手/放下和稳定终态。否则判为物品跳变。
- 人物只能移动可见触达范围内的道具；否则先写接近/伸手路径。
- 每个人物/道具/服装/门窗状态变化，都要在下一镜开头重写为当前可见事实。
- 衣物变化必须写衣物起点、谁哪只手拿住哪一处、接触身体部位、是否穿进袖子、衣摆/领口/肩部状态和尾帧归属。
- 门、车门、窗、柜门变化必须写开头状态、接触把手/门边的手、开合方向、人物是否跨过门槛/车门线、尾帧门状态和人物所在侧。
- 屏幕/UI必须先判断屏幕是否对镜头可见，再写屏幕朝向、画内是否生成清晰文字、AI绿色气泡/字幕浮层安全区、人物嘴巴是否闭合。手机聊天消息、来电名称、通知弹窗等 UI 文本默认 AI 直接生成画面侧边绿色气泡/字幕浮层，具体文字默认进入 `【画面描述｜直接复制】`。
- 只有用户明确要求“不要AI生成文字/后期叠字处理/后期加字”时，才走后期叠字模式：`【画面描述｜直接复制】` 只允许写预留安全区、模糊界面或贴合屏幕平面的预留位置，不允许把具体 UI/消息文字用引号写进直接提示词；具体文字应写在 `【表演与声音】` 中的后期文字句。否则即使写了“后期”，即梦仍可能把字生成到错误物体表面。
- 若手机背面朝向镜头、屏幕朝向人物本人或屏幕不可见，直接提示词不得写 `屏幕显示、模糊微信聊天界面、聊天界面、屏幕文字、屏幕光照出文字`；否则模型会把文字贴到手机背面。
- 屏幕不可见但需要消息可见时，默认写成画面侧边独立二维绿色气泡/字幕浮层，并明确 `不属于手机屏幕、不贴手机背面、不跟随手机透视、避开脸和活动手`。若只写 `后期叠字放在安全区` 但同时写了手机屏幕界面，判为UI朝向冲突。
- AI 直接生成绿色气泡文字时，必须限制为单个画面侧边安全区气泡、平行画面二维浮层，并在 `【本镜必要约束｜直接复制】` 和 `【本镜补充负面提示词｜直接复制】` 中分别约束 `气泡不属于手机` 与 `聊天气泡贴手机/文字贴手机壳`。文字较长时不自动改后期，但要增强为 `大号清晰气泡、文字居中、背景留白干净`。
- 人群/背景人物必须写人数或范围、区域、虚化程度、是否靠近主角、是否有可见口型和是否抢焦。
- 每个同卡状态变化都有明确开头状态、一个可见转换和一个稳定终态，并且终态在对白/反应前完成。旧状态和新状态不能同时描述。
- 只要存在 `【镜内状态转换】`，其中的 `终态直投句` 和 `尾帧直投句` 必须原句出现在 `【画面描述｜直接复制】` 中；只写在状态表或制作备注里不算。
- 一条对白卡最多包含一个高影响状态变化。如果还需要转移、穿越、另一个变化或非静止运镜，必须拆分。
- 电话状态变化要明确写活动手和耳朵：通话姿势 -> 挂断接触 -> 手机离开耳边 -> 最终手里/桌上/口袋位置 -> 耳边无手机 -> 对白。下一镜必须从这个最终位置开始。

## 表演、声音和口型同步

- 每个重要情绪都有：触发 -> 可见脸部/身体/道具泄露 -> 声音结果。
- 重要反应至少包含两类可见证据：面部控制、身体姿态、手/道具动作、距离变化、遮挡变化或镜头落点。只写 `闭口、皱眉、看着对方` 不算完成表演。
- 重要对白镜头组至少有一个非台词张力点：反应延迟、手/道具压力、距离变化、遮挡关系、视线错位、道具/手部插入或有意义切空。若整组只有说话者开口和听者闭口，判为成片偏平，需要重写其中一个子镜头；不要为了过审强塞无源文支撑的特写。
- 重要对白或对手戏连续 2-4 个镜头组内，必须能看出张弛变化：至少包含铺垫/升压/峰值/释放或缓冲中的两个不同档位。若连续多组都是固定中近景平对白，或连续多组都是近景强压迫，判为节奏失败。
- 峰值镜头必须有前置铺垫或升压，且峰值后必须有 0.5-1.5 秒可见余波、关系定格、物件结果或拉开缓冲；除非源文明确立刻切场/动作打断。
- 每个镜头组只能有一个主要张力手段。若同一卡同时写强台词、道具转移、转身走位、复杂运镜、多人强反应，判为过载，应拆成“定位/转换/落点/余波”。
- 张力必须是可投喂即梦的可见事实。只写 `压迫感、窒息感、暧昧拉扯、日漫感、情绪爆发`，但没有具体身体、道具、距离、遮挡、视线或镜头落点，判为无效张力。
- 景别必须服务张弛：中景/关系镜用于铺垫或缓冲，中近景用于升压，近景/肩后近景用于台词刺点或被击中反应，特写/插入用于手和道具泄露。若远景写眼部微表情、特写承载多人关系或长对白，判为景别错配。
- 焦段必须匹配任务：24mm/35mm 用于空间和动线，50mm 用于自然对白，85mm 用于情绪近景，135mm 用于压缩孤立或远距离观察。若广角承载脸部特写、135mm 在空间未锁定时制造多人位置关系，判为焦段错配。
- 如果源文在拒绝、承认、质问、关系重定义、道具归还、保护动作或听者被一句话击中后停住，默认最后一张子镜头应是 0.8–1.5 秒独立情绪余波镜；它必须先重写上一镜终态，再拍被击中者或关系结果，并在尾帧定格新的关系状态。只有下一组第一镜已经专门承接反应，或源文马上进入更高优先级动作，才允许把 0.6–1.2 秒余波留在信息落点镜尾部。
- 独立余波镜不新增台词、不改变道具归属、不让人物突然换朝向；它至少包含一项可读面部证据和一项身体/道具/距离证据。只写 `闭口看着` 不算完成。
- 表情必须匹配景别。近景/特写有眼睑、眉尾、嘴角、下颌、喉咙、呼吸等可读细节；中近景有脸部加肩背/手；中景/全景用距离、道具、遮挡和身体动作承载情绪，不依赖细微眼神。`眼神复杂、微微皱眉、表情平淡、神色变化` 不能作为主要表演。
- 子镜头组中的每张卡只贡献一个新的剧情/表演阶段：线索或压力泄露 -> 感知变化 -> 信息落点 -> 余波结果；不重复完整情绪链，也不在每张卡复述同一种泛化微动作。
- 微动作按情绪功能和当前源文道具/身体状态选择，不按固定人物类型硬套；重复泄露点尽量变化。
- 不说话但重要的可见人物要闭口，并有延迟低幅反应。
- 对白/OS/系统音/OV 要包含时机、语速、音量、停顿/尾音、动机，以及口型或后期处理规则；并且这些声音文本在画面描述中必须有对应可见动作或情绪承接。
- 每个口型时间窗只允许一个可见嘴巴说话；说话者交接要先闭嘴，并留短反应间隔。
- 每个 `【口型分窗】` 都以 `优先级：口型 > 听者反应 > 运镜` 开头。长对白使用稳定画面 + 一个小听者反应，或一个慢运镜 + 听者只保留呼吸/视线；绝不同时组合长口型、可见听者动作和运动镜头。
- OS、系统音、OV、内心独白不驱动画面中人物嘴巴。
- 手机消息、来电名称、通知弹窗默认用画面侧边 AI 绿色气泡/字幕浮层，并预留远离脸和活动手的安全区；纸张、合同、公告栏等非手机 UI 的密集文字不要生成清晰细字，除非用户明确要求。
- 声音重叠按指定优先级：可见对白 > 关键音效 > OS/系统音 > 环境声/音乐。

## 镜头和转场

- 景别匹配可读动作。眼睛、手、道具微细节需要特写/插入，或定时推近/落焦。
- 景别容量不超载：特写/近景最多一个主脸或一个手部/道具加边缘肩线；中近景最多一个说话者加一个听者肩线/低幅反应；中景承载二到三人关系；全景/中远景只建立空间、动线和群体关系。若需要三人以上关系和表情爆点，必须拆成关系镜头 + 表情近景。
- 关键虚化、手距和道具关系可轻量量化：例如前景肩线约占画面1/5、二人相距半身、手距道具约一掌、道具停在两人胸前之间。只在会影响生成的镜头量化，不要求每条都像测量表。
- `#### S场景-节拍` 只是组容器，不输出主镜头提示词。每个本组内的 `【镜号】1/2/...` 都有独立时长且只承担一个主要任务，共同完成该节拍所需的线索、感知变化和/或信息落点；子镜头不得引入无关的新剧情转折。
- 重跑时只以原文和当前技能为输入，不读取或给旧分镜批量补前缀。每条镜头从可见主体、身体朝向锚点、站位、景别、机位、镜头状态和唯一落点重新设计。
- 对白构图服务于可见任务：关系镜头写距离/隔物/靠近或后退；中近景保留必要肩部/手部/空间信息；近景只写可读的脸部或呼吸变化；全景使用距离或环境，不要求展示眼部细节。
- 两三轮对白后，只要距离、隔物、道具归属或表面上风变化，就回到关系镜头。提示词写新的可见安排，不写抽象权力标签。
- 物件或空景切入必须和源文相关：展示变化后的道具、空座位、门缝、手机或其他承载当前关系的细节。不要用泛泛风景填时间。
- 完整物件/空景/结果切入默认是独立视频卡，并用 `【剪辑衔接】` 写明独立生成、后期声音桥和前后锚点状态。
- 插入镜头只有在开头已看见道具、且只是一次连续焦点落点时，才可留在同一视频卡内；不能有硬切、可见说话口型、道具/接触转移、人物穿越、画外状态变化或返回另一张脸。
- 情绪峰值处，若省略动作暗含转移、冲击或人物状态变化，就使用独立结果卡。该卡写清可见结果，画外动作/声音按后期处理，绝不依赖 `留白`、`意象`、`日漫感` 等抽象词。
- 除非静止或接触精度本身就是重点，否则不要用固定镜头承载中景/全景里的细微动作。
- 运镜必须写明开头停顿、路径、距离/角度/速度、焦点目标、落点画面和不变槽位。
- 人物强动作与强运镜不能叠加。若同一卡同时有走位/转身/递物/起身/接触精度、长口型、多名听者反应和明显推拉摇移，判为流畅度过载；应固定镜头、降人物反应或拆镜。
- 快速推拉、快速横移、环绕和手持抖动默认高风险；只有源文情绪强烈且本镜没有复杂口型、道具转移或多人强反应时才允许。若使用，必须写 `主体脸部稳定`、低幅度和单一路径。
- 转场和强特效默认后期处理。直接提示词若要求旋转、马赛克、强闪白、场景变形、大量粒子、强雾或强光晕，判为廉价/高风险转场；可接受的是少量尘埃、浅散景、柔和反光和极淡薄雾，且不能遮脸、嘴和活动手。
- 每个场景先有一条关系景，再按台词、反应、物件或动作选择中近景、特写或明确的单一路径运镜；连续对白不得机械复用固定中近景。人物身体面向必须指向人物或固定物，头部/视线与身体不同才单独说明；画面左右与机位侧不能替代朝向。
- 切换景别、正反打、肩后镜头、从行走/出门/柜台/车窗/道具动作进入对白时，新镜必须重新声明完整身体朝向。普通面对面对话应写为双方身体面向对方；若只写头部/视线转向对方，必须有明确剧情理由：回避、拒绝、离开、被挡住或仍在执行上一动作。
- 检查相邻镜头朝向承接：上一镜 `【状态继承】` 或尾帧若是背向/背对/侧身/面向柜台/入口/出口/道路/门口/手机/屏幕，下一镜若变成面对人、接物、正反打或开口，必须先写转身/回身/肩线转正/双脚停稳。否则判为朝向跳变。
- 正反打必须成对保轴：`A肩后拍B` 的下一条反打写 `B肩后拍A`，不可写成 `B右前方/侧前方` 这类松散机位；两条都重复同一距离、隔物/无隔物、道具位置、前景肩线比例和背景锚点。
- 高风险过载必须拆分或简化，不要靠更长提示词解决。
- 如果同一子镜头包含四个及以上连续物理动作，或同时包含转身/走近、道具转移和运镜，必须拆成准备/定位、接触/转换、终态/余波中的两到三镜；不要用更长提示词掩盖动作链过载。
- 关键帧镜头必须和直接提示词的物理结构一致。人体姿态关键帧每帧重复头部/肩背/腰臀/双腿/双脚/支撑点/接触边界；道具、衣物、门车门和屏幕关键帧每帧重复持有人、接触点、朝向和尾帧状态。
- 带可见动作的闪回/回忆/蒙太奇使用独立片段：触发镜头尾部稳定、插入场景开头稳定、回到现实稳定。白闪、溶解和声音桥写在校验/声音字段。
- 背景/人群用正向控制：数量、区域、虚化、移动方式、没有可读对白；避免 `无清晰口型/无清晰人脸/无口型` 这类宽泛负面句。

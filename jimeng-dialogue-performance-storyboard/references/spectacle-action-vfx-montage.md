# 爆点动作、条件特效与蒙太奇

本文件是 AI 短剧动作爆点、特效、蒙太奇和特殊剪辑修辞的唯一真源。它负责增强观看冲击、压缩过程和制造记忆点，不改变剧情事实、能力规则、伤势、胜负、关键动作或结果。普通表演、动作、声音和摄影已由 [ai-manga-dramatic-direction-engine.md](ai-manga-dramatic-direction-engine.md) 冻结，本文件只在命中重动作、VFX、蒙太奇或特殊剪辑时追加专项。

## 爆点准入与去重台账

先从五段节奏曲线中定位开场钩子、连续加压、主要翻转、兑现和尾钩，再为候选爆点登记：

`镜号/节拍 -> 剧情证据 -> 观众第一读点 -> 主机制 -> 辅助机制 -> 新增信息/关系/结果 -> 前后反差 -> 稳定落幅 -> 后续回收`

主机制只选一类：

1. **重动作/策略动作**：追、夺、挡、扑、退、撞、递、摔、关门、占位、道具控制或环境受力。
2. **条件特效**：剧本/用户设定中的能量、天气、破坏、异常介质，或不改变世界事实的光学/剪辑效果。
3. **蒙太奇/特殊剪辑**：过程压缩、并行对照、证据链、升级连打或主客观揭示。
4. **纯摄影爆点**：景别跃迁、急停、遮挡揭示、空间拉开、焦点/声音先行。

同一时间窗通常保留一个主机制，同一节拍可随前兆、起势、命中、结果连续交接多个机制；同因果辅助响应数量由时长和可读性决定，不设固定上限。响应尽量共享当前阶段的刺激、观看目标和结果，并在时间线上安排清楚的先后。动作、特效、运镜、多人反应、复杂口型和蒙太奇可以达到高负载，但不要让它们无目的地争夺观看重点。

“动作、特效、运镜、多人反应、复杂口型和蒙太奇不能同时争夺主读点”仍是首读点规则；本次放宽的是执行负载，不是观看重点。

主机制与辅助响应在爆点台账中同时写出各自的触发、观看目标、方向和终态。若辅助响应不共享这四项中的任一项，不把它塞入高负载镜头，改走“删除次要插切 -> 连续焦点交接/局部起幅 -> 插切独立成相邻镜 -> 拆成冲击镜/动作镜/结果镜”的源头退路。该退路由生成段时长与实际信息数量决定，不通过成稿后扫描触发。

维护爆点去重台账：

- 相邻爆点尽量避免无意义地重复主机制、观看距离变化和声音落点；若复用仍有新的信息、关系或节奏职责，可以保留。
- 同一场重复甩镜、环绕、慢动作、冲击逼近、粒子爆发、画面闪白、局部特写连打或同结构蒙太奇时，确认第二次是否带来新的信息、尺度、方向、节奏或关系结果；没有收益再删除或换机制。
- 视觉母题可以复用，最好在建立、变形/升级或回收中推进人物、证据或危险的理解；不需要母题时不强加。
- 不按镜头平均分配爆点。稳定段负责蓄力和可读性，真正峰值获得最快速度、最大景别反差、最强声音抽空或最显著特效。

## 重动作爆点

对白戏也可以用改变现实关系的动作制造爆点：突然缩短/拉开距离、占住出口、夺回/放下关键道具、动作中止、门/车/桌面形成边界、接触建立或解除。只有源文支持追逐、碰撞、摔落、破坏、攻击或超常能力时才升级为大动作。

动作先冻结：

`意图/目标 -> 预备与支撑 -> 发力/启动 -> 路径/传播 -> 决定性接触 -> 受力/惯性 -> 终点/余波`

爆点动作通常改变距离、占位、接触、道具控制、出口、身体状态或下一选择中的一项。画面读清行动原因、决定性接触和结果；六阶段可以在同一镜用秒级时间线展开，也可以按生成稳定性拆成相邻段，实际存在的支撑、路径或惯性不要跳过。

用场景制造反馈，但只选择能证明力度和方向的一种主要介质：衣料/头发滞后、杯中液面、纸张滑动、尘土/雨水、灯影摆动、门窗震动、家具受力或脚步回声。反馈不得反向运动、提前发生、循环重播或把装饰物升级为剧情证据。

重动作镜优先让人物、接触和结果可读；摄影机可用全景/中全景看路径，也可按剧情采用跟随、环绕、主观或局部承载。升格、速度变化或冲击镜应服务方向、接触、结果或情绪，而不是默认装饰。

## 条件特效

特效分两类：

- **世界内特效**：剧本/用户设定明确存在的法术、能量、爆炸、破坏、极端天气、屏幕界面或异常现象，严格服从能力规则、范围、代价和结果。
- **导演性光学/剪辑效果**：不被人物视为现实事件的短时曝光脉冲、动态模糊、镜面/玻璃折射、速度变化、画面冻结或色温偏移，只能强化已发生的刺激，不能伪造火焰、伤口、证据、人物或环境变化。

每个世界内特效按“前兆 -> 激活 -> 传播/作用 -> 峰值 -> 消散 -> 现实后果”管理，只输出当前镜真实可见阶段。写清来源、颜色/亮度、形态、范围、方向、速度、遮挡、人物/材质受光、物理作用、消散边界和结束后的真实状态。

特效必须服从：

- 先读清人物/目标和因果，再读特效规模；不让粒子、强光或烟尘吞掉人脸、口型、接触点和证据。
- 特效高复杂度时，优先保留人物主动作、多人反应、摄影机路径和光影受力的完整因果；可以在同一时间线内并行多个高负载元素，只要观看顺序和稳定落幅清楚。若生成模型确实无法稳定承载，再按动作起势/命中/结果拆成相邻段并逐段复述状态，不得把复杂特效无理由降级为静态人物或通用光效。
- 强光必须有来源和照射方向，材质反射与阴影同步；结束后光色、烟尘、破损和人物状态按因果恢复或保留。
- 未激活、未出现或已结束且无后果时零提及；不为“电影感”添加无依据粒子、火花、频闪、能量波或环境变色。

### 华丽特效的规模与分层

世界内特效按剧情证据允许的最高有效规模设计，不以“AI难生成”为由默认缩成手心光、人物站桩或背景泛光：

- **L1 局部显形**：眼、手、武器、符纸、屏幕、伤口或接触点的短促前兆/证据，服务规则和方向。
- **L2 人物尺度**：能量包络、护盾、衣摆/头发受力、近地尘雾、局部投影与角色动作形成完整轮廓。
- **L3 场景尺度**：法阵、冲击波、风压、火焰、冰霜、雷电、群体能力或建筑/地面反馈改变人物路线和光区。
- **L4 世界尺度**：天象、巨型生物、城市/山河尺度、空间裂变或大范围生态变化；只在原文明确且结果需要时启用，并用人物/熟悉物建立尺度。

主要奇观若原文支持 L3/L4，不得只输出 L1 装饰。每个激活特效按需组织七层：`可识别来源/核心 -> 主形态与运动路径 -> 次级流动/碎裂/纹理 -> 粒子/烟尘/水汽等介质 -> 人物与材质局部受光 -> 环境受力/遮挡/投影 -> 消散与现实余波`。层数可多但只有一个主形态和一个首读点；所有层共享来源、方向、速度变化、作用范围和终态。

颜色设计使用“核心/主体/边缘/余波”分层，只在用户设定、母色卡允许的非资产环境或真实能量规则内选择。高亮核心不能过曝吞掉形态；边缘色只帮助读清速度/深度；环境染光按距离、遮挡和材质衰减，不把人物肤色、服装和场景资产永久改色。

华丽来自尺度、纵深、速度差、形态演化、环境反馈、角色动作与声音共同兑现，不来自满屏同质粒子。特效峰值前保留可辨前兆和蓄势，峰值时让决定性传播/接触占据主读点，峰值后至少给出一个人物结果、一个环境/材质结果或一个声音衰减结果。

### 炫技镜头与特效编舞

主要动作/VFX高潮可比较不同承载机制，按复杂度选择需要的数量：

1. **关系/规模全景**：读清阵地、路径、包围、能力范围、群体和环境代价；
2. **动量跟随镜**：跟随人物、武器或能量主方向，接触/命中时急停或撞击切；
3. **效果先行/主观认知镜**：先看尘线、影子、材质受力、人物感知或受限主观，再客观揭示来源和结果。

选择最能读清本场规则与情绪的一套或一组，不拼成无序组合。环绕、升降、俯冲、贴地跟拍、快速拉远、希区柯克变焦、速度坡度、短暂升格、冻结、焦点突转、遮挡切和主客观切换均可使用；使用时说明触发、观看收益、路径、停止点和下一镜交接。主要高潮可复用运动语法，但应确认复用仍有新的信息或情绪职责。

摄影机、角色、特效、灯光和声音按 `前兆 -> 起势 -> 传播 -> 命中/揭示 -> 结果 -> 余波` 编舞。命中瞬间保持一个主峰；其前后可以让摄影、人物、特效、声音和光影依次形成次峰/接管。若特效在命中时主导，摄影机以清楚跟随、固定见证或退让承载；若摄影运动主导，特效保持可追踪方向与形态，其他复杂变化延后到下一窗口。

## 蒙太奇

只在以下情况使用：

- **过程压缩**：重复但必要的训练、等待、寻找、准备、制作、赶路或时间流逝。
- **升级连打**：同一冲突连续出现不同信息、策略、代价或结果，形成递进而非同义重复。
- **并行/对照**：两处行动在原文时间关系内互相解释、讽刺或逼近同一结果。
- **证据链/认知揭示**：多个已建立细节按新的顺序让人物或观众完成判断。
- **主观记忆/想象**：仅在源文明示或用户授权时使用，不擅自生成过去事件。

蒙太奇先冻结入口锚点、统一声音脊柱、3-8 个片段的独立职责、时间/地点标识、片段间匹配关系和出口终态。3-8 只是常用范围，不是配额；每个片段至少保留一个具名主体、一个动作或变化和一个新增读点，常用 0.5-2 秒，口型、接触或复杂动作需要更长时独立成镜。允许多个片段同时有光影、材质和环境反馈，但必须共享声音/形状/方向中的承接脊柱。

生成段内的高价值插切按时长给出常用参考：不足 5 秒通常不内插，5—8 秒常用 0—1 组，关键 8—15 秒常用 1—2 组；更复杂的证据链可以增加，只要每个片段有独立职责、足够时长和入口/出口状态握手。无法稳定承载时再拆成相邻独立镜，不把多个新地点、新身份或新光源无因塞入同一生成段。每个片段说明其主驱动力和与声音脊柱的接点。

每个片段写：

`时间/地点 -> 具名主体 -> 单一动作/变化 -> 新信息/升级 -> 声音或形状/方向/颜色承接 -> 片段终态`

蒙太奇是剪辑结构，不是一条连续运镜。Seedance 无法稳定在同一生成段内完成身份、地点、光源或时间跳变时，拆成独立生成段，再通过声音桥、动作匹配、物体形状、运动方向或颜色亮面剪辑连接。出口镜必须重新建立当前时空、人物状态、道具归属和剧情继续点。

## 特殊手法选择

- **匹配切**：用两镜真实存在的动作、形状、颜色、亮面或声音连接，适合跨时空压缩和关系对照。
- **撞击切/硬切**：在动作命中、关键词、开门、落物或声音峰值直接切到结果/反应，适合主要翻转。
- **速度变化**：动作起势保持实时，决定性接触可短暂升格，结果恢复实时并停稳；不让完整对白处于变速。
- **冻结/延长停帧**：只用于不可逆决定、证据确认、喜剧尴尬或章节钩子；画面仍保留声音余波或下一场先行声。
- **分屏/界面并置**：仅在原文确有同步远程信息、通话、监控或平台界面时使用；手机端保持一个主窗和清楚阅读顺序。
- **主客观切换**：主观感官画面后必须回到客观关系/结果，避免把视觉修辞误当世界事实。
- **甩镜/急摇接切**：由人物突然转向、攻击方向、声音来源或跨场同向运动触发；甩动只作切点，前后都有稳定读幅。
- **俯冲/升降/垂直揭示**：服务地形、阵法、阶层、规模、坠落或群体关系；手机端保持明确动态锚点。
- **贴地/穿行跟拍**：服务脚步、追逐、地面传播、工具/作物工序或威胁逼近；不得穿过实体。
- **反射/框中框/分层玻璃**：服务监视、身份隔离、双重关系或都市权力；反射不复制人物和不存在的信息。
- **变形宽画幅/分屏/漫画格重组**：只在用户风格和平台支持时，用于同步冲突、规则说明或连打压缩；必须保持单一阅读顺序和手机端主窗。

特殊手法必须有明确触发、新增读取和退出点。仅改变滤镜、角度、速度或剪辑花样而没有新信息、动作结果或关系变化，不构成爆点。

## AI 负载、手机端与交付

- 手机端每个爆点仍保持一个首读点；重要脸、手、证据、接触和特效源进入安全可读区域，蒙太奇片段不把唯一信息压在字幕/UI 区。
- 爆点前减少无关动作、背景高对比和声音层；爆点命中后留稳定结果镜或声音余波，避免连续刺激互相抵消。
- 导演版逐场输出“爆点与特殊手法计划”：峰值镜号、主机制、剧情证据、信息收益、前后反差、去重/母题关系、AI 负载和直投映射。
- 主要奇观额外输出允许规模、七层中实际采用的层、角色/环境受光、摄影编舞和现实余波；非特效场景删除该内容。
- 直投版不增加审核字段；把动作写入画面时间线，把特效写入光影、环境色彩与材质及时间线，把蒙太奇拆成实际编号镜头/片段，把剪辑和声音承接写入摄影与声音字段。

## 首次生成必成条件

爆点主机制、错峰、特效阶段、物理结果和相邻去重在爆点台账首次生成时直接成立，不在交付稿后统计或替换：

- 每个爆点有剧情证据、唯一主机制、新增读取和稳定结果，不靠术语宣布“炸点”。
- 动作、特效、蒙太奇和摄影没有争夺同一时段主读点，生成复杂度已错峰。
- 相邻爆点机制不同；母题复用具有升级和回收，不是复制粘贴。
- 特效阶段、光影反应、物理后果和人物状态连续；蒙太奇入口/出口不制造时空、道具或知情跳变。
- 吸睛手法强化短剧承诺、升级、翻转、兑现或尾钩，而非与剧情无关的视觉奇观。
- 原文支持的 L3/L4 奇观已完整兑现尺度、分层、角色动作、环境受力、声音和余波，没有保守缩成局部泛光；普通场景没有滥加世界内特效。

# 实体与道具连续性账本

道具连续性不是只检查“有没有出现”，而是持续回答：它何时被建立、现在在哪里、由谁控制、处于什么状态、镜尾最终留下什么。内部维护账本，不把账本或检查表输出到成稿。

## 道具分类与事实边界

逐场登记三类实体：

1. **源文明示道具**：源文直接写出名称、持有、拿放、开合、交付或使用。
2. **源文强暗示道具**：虽然没有直接命名，但现实刺激明确依赖它，例如“外卖订单已超时”的电子提示可以推出手机或接单设备。只能补出完成该刺激所需的最小实体，不能顺带新增品牌、聊天内容、转账记录或其他剧情证据。
3. **装饰性实体**：为建立环境补充的杯碟、摆件、家具等。装饰物不能在后续突然升级为剧情证据、冲突工具或人物任务，除非源文或既有行动已经给出因果。

每个进入镜头因果链的道具至少记录：

```text
存在依据 -> 首次建立方式 -> 当前是否可见 -> 所属人物
-> 当前控制者 -> 具体位置 -> 开合/亮灭/完整性等状态 -> 本镜最终状态
```

“不在当前画面”不等于“从未建立”。已经在前镜通过画面、动作或声音明确建立的道具可以暂时出画；从未建立的道具不能因为切镜直接成为人物已经握住、压住、打开或使用的起态。

## 首次出现必须在镜内发生

除场景首镜用于建立初始环境外，新道具或强暗示道具不得第一次出现在 `起始状态` 中。它必须在当前镜的刺激与动作过程中被建立：

- 声音先行：提示音响起，人物循声发现衣袋震动。
- 物理反馈：口袋亮起、包内震动、桌下传来碰撞声。
- 人物动作：从衣袋拿出手机、打开抽屉露出文件、从桌面拿起茶杯。
- 遮挡揭示：人物移开身体或前景后，道具第一次进入画面。

强暗示道具的正确链条是：

```text
此前无可见手机
-> 超时提示音响起，宋棠侧袋震动
-> 宋棠发现后伸手压住侧袋
-> 尾帧建立“手压在仍震动的侧袋，手机没有拿出”
-> 下一镜起态复述该状态
-> 画面/表演中再拿出手机
```

禁止写成：

```text
前镜没有手机
-> 切镜
-> 起始状态直接写“宋棠压住亮起的手机衣袋”或“宋棠拿着手机”
```

这会跳过“刺激出现 -> 人物发现 -> 初次接触”的因果过程。

## 镜尾最终状态必须结算

只要本镜发生道具拿、放、递、接、夺、藏、遮、开、关、亮、灭、破损或控制权变化，`尾帧` 必须结算该道具的最终状态。至少写清发生变化的维度，不要求堆砌未变化信息：

- **控制者**：仍在宋棠手中、已经交到陆夫人手中、无人持有。
- **位置**：留在侧袋、放回杯碟、压在文件下、落到地面、藏在身后。
- **可见性**：屏幕朝向镜头、屏幕被身体挡住、只听见袋内震动但手机未拿出。
- **物理状态**：打开或合上、亮起或熄灭、完整或破损、装入或取出。

尾帧只写终幅真正可见或仍可听见的内容。道具在袋内或画外时，若其状态需要跨镜接力，必须留下可见或可听锚点，例如“宋棠的手仍压住震动的侧袋”；不能声称摄影机看见袋内手机，也不能只在内部账本里记住而不让下一镜获得承接依据。

## 相邻镜头双端握手

前镜 `尾帧` 与后镜 `起始状态` 对同一道具逐项比较：

- 位置不变：袋内不能无动作变成手中，桌面不能无动作变成身后。
- 控制者不变：陆夫人手中的茶杯不能切镜后直接由宋棠拿着。
- 手别不偷换：右手不能切镜后直接变成左手；需要换手就在镜内写出。
- 开合与亮灭不偷变：合上的文件、熄灭的屏幕、关闭的门不能切镜后直接打开或亮起。
- 可见性有依据：屏幕由遮住变为朝向镜头，必须在镜内完成转动或移开遮挡。
- 动作方向接续：递出、松手、放下、掉落尚未完成时，下一镜从同方向和同一受力状态继续。

不能用切镜省略会改变剧情读取、人物策略或道具控制的动作。若状态改变不重要且动作极短，优先留在同一连续表演镜内；若必须切镜，前镜尾帧先冻结动作起势或中间态，后镜起态逐字义接住，再完成变化。

## 最终状态审查

每场结束前回放账本：

1. 所有剧情道具是否都有首次建立依据。
2. 每次状态变化是否发生在某一镜的 `画面/表演` 中，而不是发生在切镜空白里。
3. 每次变化后的 `尾帧` 是否结算控制者、位置和必要的物理状态。
4. 下一镜 `起始状态` 是否接住前镜最终状态，且没有换手、换位、开合、亮灭或显隐跳变。
5. 场尾是否保留源文要求的最终归属与结果；没有后续用途的装饰物不必逐一交代去向，但不能在场尾制造与源文冲突的新状态。

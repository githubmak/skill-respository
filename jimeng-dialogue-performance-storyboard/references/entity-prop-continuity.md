# 实体与道具连续性账本

本文件只管理实体从建立、控制、变化到镜尾结算的连续状态。账本供内部使用，不输出到成稿。

## 分类与事实边界

1. **源文明示**：源文直接写出名称、持有、拿放、开合、交付或使用。
2. **源文强暗示**：现实刺激必然依赖的最小实体，如电子提示可推出手机/接单设备；不能顺带新增品牌、聊天、转账或剧情证据。
3. **装饰性实体**：用于建立环境的家具、杯碟等；不能无因升级为证据、冲突工具或人物任务。

进入因果链的实体登记：

```text
存在依据 -> 首次建立方式 -> 可见性 -> 所属人物
-> 当前控制者 -> 具体位置 -> 开合/亮灭/完整性 -> 本镜终态
```

暂时出画不等于从未建立；从未建立的道具不能借切镜直接成为人物已握住、压住、打开或使用的起态。

## 首次建立

除场景首镜的初始环境外，新道具不得第一次出现在后续镜头的 `起始状态`。首次建立必须在镜内发生，可通过：

- 声音/物理反馈：提示音、袋内震动、桌下碰撞；
- 人物动作：从衣袋取出、打开抽屉露出、从桌面拿起；
- 遮挡揭示：人物或前景移开后进入画面。

正确链条是“此前未建立 -> 刺激出现 -> 人物发现 -> 首次接触/取出 -> 尾帧结算 -> 下一镜起态复述”。不能跳过发现与接触，直接在切后写人物已经持有。

## 镜尾结算

凡发生拿、放、递、接、夺、藏、遮、开、关、亮、灭、装入、取出、破损或控制权变化，尾帧按变化需要结算：

- 控制者；
- 具体位置；
- 可见/遮挡状态；
- 开合、亮灭、完整性等物理状态。

只写终幅可见或仍可听内容。袋内/画外道具若要跨镜接力，必须留可见或可听锚点，如“手仍压住震动的侧袋”；不能声称看见遮挡内部，也不能只靠内部账本承接。

## 相邻镜头握手

逐对比较前镜尾帧与后镜起态：

- 位置和控制者不偷换；
- 左右手不无因交换；
- 开合、亮灭、完整性和显隐不跳变；
- 画面朝向/遮挡变化在镜内完成；
- 未完成的递出、松手、掉落等从同方向、同受力和同接触点继续。

不能用切镜省略会改变剧情读取、人物策略或道具控制的动作。极短且低价值的变化留在连续表演镜内；必须切镜时，前镜冻结起势/中间态，后镜起态自足接住再完成。

## 首次生成必成条件

以下状态随动作时间线和落幅同轮生成，不在成稿后补道具账：

- 剧情道具有源文依据和首次建立方式。
- 每次变化都发生在某镜的画面/表演中。
- 变化后的尾帧结算控制者、位置和必要物理状态。
- 后镜起态与前镜终态一致，没有换手、换位、开合、亮灭或显隐跳变。
- 场尾符合源文最终归属；无后续用途的装饰物不必逐一交代，但不得制造冲突状态。

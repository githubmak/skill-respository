# 对白普通运镜语言

运镜负责观众的心理距离、速度冲击和空间层次。先确定要靠近、抽离、追随、截停、揭示、审视、压迫、失衡还是停留，再与起幅和终幅景别联合设计。速度必须响应人物动作与关系变化，不默认缓慢或平稳。最终只写 AI 可理解的摄像机行为，不写工程参数。

## 直接可执行句法

优先写成：

`从具体可见起点起镜 -> 直接运动 -> 最终定格的具体读点 -> 必要时补一次焦点交接`

使用短句和可见名词。直接写摄影机从哪里开始、怎样移动、停在哪里，不借人物视线转述摄影机路径。景别机位负责交代起幅关系，运镜/焦点负责交代运动，两个字段不要重复同一句空间说明。

- 推荐：“从宋棠鞋面缓慢上移，最终定格在兔耳朵，焦点保持在帽子。”
- 推荐：“从茶杯局部快速横移到宋棠松开的手，立即停住。”
- 推荐：“斜俯全景沿街道向下压到刹停的前轮，定格两车未接触的间隙。”
- 避免：“从宋棠身侧看陆夫人的视线由宋棠衣着向上移动，跟随她的视线落到兔耳朵。”这句话把机位、人物目光和摄影机动作混在一起。
- 避免：“镜头带到人物表情”“顺着视线看过去”“以电影感扫过现场”等没有明确起点、运动和终点的写法。

- 推进：镜头从关系景别平稳向人物靠近，随着情绪或动作收紧到中近景、近景或手部细节，抵达后静止，焦点停在具名人物或道具上。
- 拉开：镜头从人物近景平稳向后退开，逐渐露出双人距离或环境处境，拉开后静止，焦点仍保持在核心人物和已改变的关系上。
- 横移揭示：镜头平稳向一侧移动，门框、人物或桌面遮挡逐渐让开，被遮住的人物、道具或反应出现后停住；不无因前后推拉。
- 跟拍：镜头与人物、文件或其他关键动作保持相容距离，沿其移动方向平稳跟随，主体停下时镜头同步停稳。
- 快速跟拍：人物突然追赶、扑向、夺取、逃离、转身离场或逼近时，镜头立即贴住其运动方向快速跟随；主体接触、停步、抬眼或到达落点时镜头同步快速停止，焦点始终锁定一个具名主体。
- 快速停止：镜头正在跟随、推进、横移或斜向下降时，由接触、证据显现、视线相撞、动作受阻或决定完成触发立即停住；停止后的画面必须稳定到足以读清结果，不继续漂移或追加第二个复杂运动。
- 上摇或下摇：直接写可见起点和终点，例如“从鞋面缓慢上移，经过外卖服，最终定格兔耳朵”。不需要先解释谁在打量谁；人物打量动作写进 `画面/表演`。
- 斜俯建立：从大全景或全景的斜俯关系开始，镜头沿建筑、楼梯、街道、桌面或人物队列向下、向前或横向移动，逐步落到明确人物、出入口或行动落点；用于环境压住人物、多人权力格局、行动路线或突发事件前的空间蓄力。
- 前景遮挡揭示：镜头贴着门框、人物肩背、车门、家具或道具移动，真实前景先遮住部分信息，再随着横移、跟随或人物动作让开，新的角色、表情、证据或距离关系出现后立即停稳。
- 视差穿行：前景、中景和后景保持清楚层次，镜头沿人物行动方向快速或平稳移动，让近处遮挡掠过、主体保持可读、远处地标改变相对位置；只用于空间层次和追随压力，不穿过实体。
- 被动退让：人物突然逼近或动作冲向镜头时，摄影机沿可通行方向后退保持主体可读，在人物停止、受阻或控制权建立时立即停住；用于压迫、争夺和距离骤变。
- 急停：镜头沿动作方向做一次短促运动，在递交接触、抬眼、证据显现或关系突变时立即停稳，把注意力钉在结果上。
- 固定：摄影机全程不移动，让观众停留在对峙、等待、证据显现、对白接收或结果余波上；焦点明确落在具名对象。

同一镜默认一个主运动和一次主焦点交接。快速跟拍、斜俯建立、遮挡揭示或被动退让已经构成主运动，不再叠加无关环绕或反复推拉。抽焦写清现实触发、起始对象、终点对象和保持到尾帧；不要在多人和多个道具之间往返巡游。运镜不能制造人物换位、换手、转身、穿墙或道具状态变化。

场景内不要让“缓慢推进、固定反打、再缓慢推进”成为默认节奏。等待和压抑可以固定，突然行动可以快速跟拍，结果可以急停，高价值细节可以切入大特写，空间压力可以用全景斜俯展开；每种选择都由当前刺激和观看收益决定，不按镜头配额轮换。

合格示例：“斜俯大全景沿街道向下沉降，豪车横入后快速压到宋棠刹停的前轮，前轮停在车头前时立即定格，焦点保持在两车间隙。”

禁止写入最终提示词：米或厘米、角度、焦距、坐标、轴向、器材轨道、逐段速度参数、逐秒运动表，以及只有“创意运镜、镜头带到、电影感移动”而没有摄像机行为的空话。

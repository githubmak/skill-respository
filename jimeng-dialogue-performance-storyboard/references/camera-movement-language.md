# 对白普通运镜语言

运镜负责观众的心理距离、速度冲击和空间层次。内部先确定要靠近、抽离、追随、截停、揭示、审视、压迫、失衡还是停留；最终不要解释这些意义，只写摄影机可见的起点、速度、方向、对象和停止画面。速度必须响应人物动作与关系变化，不默认缓慢或平稳，也不写工程参数。

## 直接可执行句法

优先写成：

`具体可见起点 -> 速度与方向 -> 跟随/靠近的具名对象 -> 停止触发 -> 最终可见画面 -> 必要时一次焦点交接`

使用短句和可见名词。直接写摄影机从哪里开始、怎样移动、停在哪里，不借人物视线转述摄影机路径。景别机位负责交代起幅关系，运镜/焦点负责交代运动，两个字段不要重复同一句空间说明。

先在 `景别机位` 锁定具名人物、环境或物体。固定景别直接写一个景别；若运镜从一名人物、身体部位或景别移动到另一处，只允许一次起终幅变化，可写“全景转特写”或“起幅……；终幅为……”。`运镜/焦点` 再使用相同起点和终点。不能用一个“局部特写”概括从鞋到头的整段运动，也不能在同一镜内继续转成第三个景别。

机位描述优先使用低机位、贴地、高机位、平视、仰拍、俯拍、斜俯、正面、侧面、侧后方等定性词。只有遮挡、轴线、出入口、接触位置或空间连续依赖固定实体时，才使用门内、门外、桌边、车内、车外等相对位置；不要为了让句子显得具体而让每个机位依附门、桌、家具或道具。景别机位不写“制造压迫、建立权力、表现孤独”等抽象意义。

- 推荐配套写法：`景别机位` 写“宋棠鞋面局部特写起幅，低机位正面；终幅为宋棠兔耳帽特写。”；`运镜/焦点` 写“从宋棠鞋面缓慢上摇，经过她扣住衣摆的手，最终停在宋棠兔耳帽。”；`尾帧` 只保留兔耳帽和终幅可见背景。
- 推荐：`景别机位` 写“客厅高空大全景”；`运镜/焦点` 写“镜头缓慢向前推进，保持高空大全景。”
- 推荐：`景别机位` 写“宋棠贴地低机位全景”；`运镜/焦点` 写“高速追拍宋棠向前疾驰，保持贴地低机位全景。”
- 推荐：`景别机位` 写“宋棠全景转眼部特写”；`运镜/焦点` 写“缓慢从上至下摇镜，最后停在宋棠眼睛。”
- 推荐：“从茶杯局部快速横移到宋棠松开的手，立即停住。”
- 推荐：“斜俯全景沿街道向下压到刹停的前轮，定格两车未接触的间隙。”
- 推荐：“镜头从门框上方快速下移，跟随陆钦走向门口；两人只剩一步时立即停止，宋棠贴在画面右下门边，半开木门仍露出走廊。”
- 避免：“从宋棠身侧看陆夫人的视线由宋棠衣着向上移动，跟随她的视线落到兔耳朵。”这句话把机位、人物目光和摄影机动作混在一起。
- 避免：“镜头带到人物表情”“顺着视线看过去”“以电影感扫过现场”等没有明确起点、运动和终点的写法。
- 避免：“最终定格控制关系”“停在压迫感上”“呈现完整空间关系”等以抽象意义代替最终画面的写法。

- 推进：镜头从关系景别平稳向人物靠近，随着情绪或动作收紧到中近景、近景或手部细节，抵达后静止，焦点停在具名人物或道具上。
- 拉开：镜头从人物近景平稳向后退开，逐渐露出双人距离或环境处境，拉开后静止，焦点仍保持在核心人物和已改变的关系上。
- 横移揭示：镜头平稳向一侧移动，门框、人物或桌面遮挡逐渐让开，被遮住的人物、道具或反应出现后停住；不无因前后推拉。
- 跟拍：镜头与人物、文件或其他关键动作保持相容距离，沿其移动方向平稳跟随，主体停下时镜头同步停稳。
- 快速跟拍：人物突然追赶、扑向、夺取、逃离、转身离场或逼近时，镜头立即贴住其运动方向快速跟随；主体接触、停步、抬眼或到达落点时镜头同步快速停止，焦点始终锁定一个具名主体。
- 快速停止：镜头正在跟随、推进、横移或斜向下降时，由接触、证据显现、视线相撞、动作受阻或决定完成触发立即停住；停止后的画面必须稳定到足以读清结果，不继续漂移或追加第二个复杂运动。
- 上摇或下摇：直接写带人物归属的可见起点和终点，例如“从宋棠鞋面缓慢上摇，经过她的外卖服，最终停在宋棠兔耳帽”。同时在 `景别机位` 写清起幅和终幅景别。不需要解释谁在打量谁；若陆夫人不在起幅、运动中和终幅构图内，她只能在画外说话，不能继续写“陆夫人的审视落到宋棠”。
- 斜俯建立：从大全景或全景的斜俯关系开始，镜头沿建筑、楼梯、街道、桌面或人物队列向下、向前或横向移动，逐步落到明确人物、出入口或行动落点；用于环境压住人物、多人权力格局、行动路线或突发事件前的空间蓄力。
- 前景遮挡揭示：镜头贴着门框、人物肩背、车门、家具或道具移动，真实前景先遮住部分信息，再随着横移、跟随或人物动作让开，新的角色、表情、证据或距离关系出现后立即停稳。
- 视差穿行：前景、中景和后景保持清楚层次，镜头沿人物行动方向快速或平稳移动，让近处遮挡掠过、主体保持可读、远处地标改变相对位置；只用于空间层次和追随压力，不穿过实体。
- 被动退让：人物突然逼近或动作冲向镜头时，摄影机沿可通行方向后退保持主体可读，在人物停止、受阻或控制权建立时立即停住；用于压迫、争夺和距离骤变。
- 急停：镜头沿动作方向做一次短促运动，在递交接触、抬眼、证据显现或关系突变时立即停稳，把注意力钉在结果上。
- 固定：摄影机全程不移动，让观众停留在对峙、等待、证据显现、对白接收或结果余波上；焦点明确落在具名对象。

同一镜默认一个主运动和一次主焦点交接。快速跟拍、斜俯建立、遮挡揭示或被动退让已经构成主运动，不再叠加无关环绕或反复推拉。抽焦写清现实触发、起始对象、终点对象和保持到尾帧；不要在多人和多个道具之间往返巡游。最终停止画面至少写出一个具名主体或实体及其位置，不用“关系、状态、气氛、姿态”单独收尾。运镜不能制造人物换位、换手、转身、穿墙或道具状态变化。

环绕运镜改变的是摄影机围绕主体的路径和观察方向，不是景别序列。写“保持宋棠中景，从正面环绕到侧后方”，不要写“从全景环绕到中景，再绕到面部特写”。环绕仍遵守单镜固定景别或最多一次 A 到 B 景别变化；路径可以转向，观看距离不能连续跳级。

终幅是运镜停止后的唯一画面事实。尾帧不得保留已经在推进、拉开、横移、上摇或下摇中移出画面的身体部位和道具；如果需要它们同时留在终幅，就扩大终幅景别或改变停止位置。

场景内不要让“缓慢推进、固定反打、再缓慢推进”成为默认节奏。等待和压抑可以固定，突然行动可以快速跟拍，结果可以急停，高价值细节可以切入大特写，空间压力可以用全景斜俯展开；每种选择都由当前刺激和观看收益决定，不按镜头配额轮换。

合格示例：“斜俯大全景沿街道向下沉降，豪车从画面右侧横入后快速压到宋棠刹停的前轮；鞋底撑地时立即停止，宋棠位于左下、黑色车头位于右上，两车之间仍留空隙，焦点保持在前轮。”

禁止写入最终提示词：米或厘米、角度、焦距、坐标、轴向、器材轨道、逐段速度参数、逐秒运动表，以及只有“创意运镜、镜头带到、电影感移动”而没有摄像机行为的空话。

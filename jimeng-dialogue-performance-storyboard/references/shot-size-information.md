# 对白景别与信息承载

景别不从“最大信息量”或“最低风险”开始选择。先完成情绪与行动推导，再决定观众此刻应靠人物多近、应看关系、身体、面部还是道具；随后为必须看懂的事实安排清晰读取窗口。

## 联合设计顺序

```text
情绪与关系变化
-> 可见行动骨架
-> 观众心理距离与观看重点
-> 起幅景别
-> 运镜和焦点交接
-> 终幅景别
-> 反向设计具体站位、动作幅度、道具路径和构图
-> 校正事实覆盖与真实可拍性
```

景别决定某一时刻画面能装入什么，运镜决定这些信息怎样依次出现。起幅和终幅不必相同。一个剧情节拍也不必由单镜承担：必须同时读取的双人关系或接触放在同一窗口，可以顺序读取的环境、动作、细节、反应和结果可以交给镜内变化或相邻镜头。

## 景别与机位必须合写

只写“中景、近景、全景”仍不足以形成画面。`景别机位` 先写具名人物、环境或物体，再补充至少一项高低/俯仰或正侧方向。相对门、桌、家具、车辆的位置不是默认必填；只有遮挡、轴线、出入口、接触或空间连续依赖该实体时才补。优先使用简短摄影指令，例如：

- “陆钦面部近景，低机位仰拍。”
- “沙漠高空大全景。”
- “陆地机车贴地低机位全景，侧后方。”
- 空间确需定位时再写：“宋棠与陆夫人双人中全景，侧后方，摄影机位于半开木门外侧。”

不写“权力机位、压迫视角、孤独构图”等抽象目的；先写摄影机现实位置和朝向，再由人物在画面中的大小、遮挡和距离让目的自然成立。不需要角度、焦距、坐标或器材名称。

## 锁定主体归属与起终幅

景别必须归属于具名人物、身体部位、道具或空间，尤其不能只写“局部特写”让读者猜拍谁。人物身体或服装局部写成“宋棠鞋面局部特写”“陆钦眼部大特写”“陆夫人握杯的手部特写”；单独道具可以写“茶杯局部特写”。

摄影机运动改变拍摄主体、身体部位或景别时，`景别机位` 必须同时冻结起幅和终幅：

- 合格：“宋棠鞋面局部特写起幅，低机位正面；终幅为宋棠兔耳帽特写。”
- 合格简写：“宋棠全景转眼部特写，缓慢下摇。”
- 不合格：“局部特写，宋棠鞋面、外卖服和兔耳帽依次进入画面。”它把不同时间点塞进一个静态景别，无法判断终幅到底看见什么。
- 不合格：“宋棠全景转中景再转近景，最后到眼部特写。”单镜出现三次以上观看距离，动作和表演读取会被运镜路径切碎。

一个镜头默认固定一个景别；确需改变观看距离时，只允许一次 A 到 B 的景别变化。推进、拉开、追拍、摇镜、横移和环绕只是摄影机行为，不自动产生新景别。若同一节拍需要第三个读取距离，把第三个景别交给相邻且具有独立观看职责的镜头。

变化镜头按三张静止画面检查：起幅装得下什么，运动中依次经过什么，终幅装得下什么。`构图/光影` 可以分阶段描述，但 `尾帧` 只能复述终幅仍可见的内容。终幅为兔耳帽特写时，鞋面和扣衣摆的手已经离开画面，不能继续写在尾帧下缘；若必须让手与兔耳帽同时可见，就应把终幅改成能够容纳两者的半身或中景，而不是强行保留“特写”。

## 景别承载范围

- 大全景：整体环境、人物与空间尺度、处境；不承担面部和手部细节。
- 全景：全身、多人站位、出入口和行动路线；不承担眼神和手指接触。
- 中全景：全身姿态、人物距离和进出路径；面部只能承担较大的情绪变化。
- 中景：双人或多人关系、上半身动作、递物和桌面互动；不承担脚下完整路线或道具纹理。
- 中近景：面部、肩颈、呼吸和克制的身体压力；不承担全身走位。
- 近景：完整脸部、眼神、口型、表情策略和情绪破绽；不承担空间全貌。
- 特写：单一人物面部、手部或关键道具成为主要读取对象，用于决定、破绽、接触和证据；不同时承担完整双人关系。
- 大特写：眼睛、嘴唇、指尖、皮肤变化、道具落款或接触边缘等不可替代细节，用于认知冲击、危险确认或情绪爆点；信息读完后立即交给动作或关系结果。
- 局部特写：衣领被抓紧、鞋尖停住、茶水震动、手机提示、手指松开、门锁转动等身体或道具局部，用局部变化代表完整行动的起因、压力或结果。

## 组合原则

- 先用能够承载起幅第一信息的景别，再让运镜把观众带到第二信息；运动结束后必须有稳定可读的终幅。
- 允许有动机的景别跃迁。大全景或全景可以直接切到大特写，把环境压力突然压成一个不可替代的身体或道具细节；大特写也可以快速拉开到全景，让观众重新理解人物处境。跃迁必须由刺激、发现、接触、决定或控制权变化触发。
- 特写、大特写和局部特写可以作为场景首镜或镜头组起点。若先用高价值细节制造悬念，紧接的关系镜只负责补回确实需要的方位和人物关系，不把“先远后近”当固定顺序。
- 大全景或全景可结合斜俯视角与向下、向前或横向运动，先展示人物受环境包围、多人站位或权力格局，再停到明确人物或行动落点；斜俯必须读出空间关系，不能只作为装饰角度。
- 双人递文件可以用中景建立双方距离和递交方向，随文件平稳靠近到手部近景确认接触与归属，再切接收者中近景读情绪。它不是固定模板，只说明关系、接触和反应可以分层覆盖。
- 收到噩耗时，中近景可以保留面部和肩颈压力，再缓慢靠近而不必冲到大特写；若情绪来自孤立处境，也可以从近景缓慢拉开到全景。
- 固定中景合法。它适合对峙、等待、稳定对白接收和关系持续；只有在推进、横移、反打、上摇、跟随、拉开或特写能产生更准确的新读取时，才选择其他组合。
- 连续固定中景不是自动错误，连续没有观看理由的固定中景才是问题。不同景别也不是自动优秀，若只是机械轮换而没有改变观看信息或心理距离，同样无效。

隐式校正：写全身路线必须使用能看见全身的景别；写双人递物必须让双方和道具关系在同镜或紧邻关系镜中成立；写眼神口型至少进入中近景或近景；写单一证据、局部动作或接触点可大胆进入特写、大特写或局部特写。一个读取窗口同时要求全身路径和微表情时，用快速景别变化或相邻镜头先后完成，不用一句“同时清楚可见”掩盖冲突。

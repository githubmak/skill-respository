# 强制审查流程

工程校验只证明文件可交付，不能证明镜头好看、表演准确或 Seedance 不会误解。设计审片必须由大模型完成；有线稿、关键帧或视频时还必须查看真实画面。审查记录与 manifest 均为非投喂文件。

最小事实连续性台账、场景因果主线、角色表演弧、节奏诊断和场景视觉连续性笔记统一记录在审片报告；正式 Markdown 不复制这些内部标题、编号或分析内容，只保留每镜独立成立的可见结果。

## 1. 设计审片

审片者同时阅读完整源文、场景导演方案、全部直投提示和相邻镜。优先使用未参与生成的新上下文；不可用时明确记为 `self_check`，不要伪称独立审查。第一遍先不依赖内部因果笔记，只从源文和最终直投提示判断观众实际能读到什么，第二遍再与导演方案对照，避免用创作者本意替画面证明。

先从最终直投提示反向还原 `触发 -> 人物当下的理解或目标 -> 关系策略与可见行动 -> 对方接收和反应 -> 新的关系、信息或身体状态`，再判断它是否准确表达原文。原文故意保留真相时，不强行补全答案，只检查人物当下认知和观众应保留的疑问。重点检查：

反向还原是保真与可读性检查，不是导演风格评分。审片者不得因为镜头没有采用常见正反打、参考示例的锚点结构、预期的情绪峰值位置或个人偏好的光影方案而判失败；只在事实被改写、因果无法读取、人物响应无权信息、空间或声音不可执行、单镜容量不成立，或已选导演意图在最终提示中没有被兑现时退回。

- 原文事实、关系转折、信息顺序和全部声音是否完整，时长是否给表演与停顿留下现实空间。
- 因果链是否通过可见动作、表演、反应时机和信息释放成立，而不是只存在于场景说明或创作者意图中；无法还原时先定位断在原文理解、触发、策略、听者接收还是新状态。
- 每镜是否只有一个主导观看任务或主要转折，同时允许服务该转折的次级反应、情绪泄露和镜尾余波存在；关键对白的触发、人物策略、听者关键反应和剧情落点能否从连贯画面中读出。审片者可以在内部还原完整链条，但不得因直投提示没有逐项写出口型、闭口、每次接收和所有微表情而判失败。
- 人物行为是否来自此刻目标与压力，听者反应是否在真正接收信息后发生，动作、口型和道具是否能实际执行；场景级角色表演弧是否让常态、转折和余波连续且具有角色专属性。
- 逐条声音的主体、通道、可听范围和获准反应者是否正确；普通连续对白无需重复证明口型与“对方听见”，只有抢话、多人传播、OS/OV、画外声、电话、广播和系统音等风险场景需要在提示中显式控制。
- 每个动作是否具有剧情行为、状态变化、信息传递/遮蔽、关系策略、压力泄露、因果触发、连续性或节奏余波中的至少一项作用。删除后全部不受损的呼吸、抬眼、皱眉、握拳、无目标走动和环境运动是否已经清除；静止或不反应不得因缺少动作数量而判失败。
- 每镜是否用足够少而明确的空间信息独立建立当前关系：普通镜至少能读出区域、关键锚点、人物槽位/关系方向和重要道具；边界、遮挡、越界、交接、转身、起坐或多人高风险镜再检查面向、支撑、接触、轴侧与首尾状态。审片不得要求每镜逐项列出可见背景、双脚、躯干、头脸、闲置手和全部可见面。相邻镜若有位置、道具或边界变化，应有可见转换或明确时间省略；仅换机位造成的投影变化不得误写成人物转身。
- 空间高风险镜的锚点、轨迹、情绪传导和互动逻辑是否互相兼容：固定世界锚点与当前画面投影有没有混写，移动摄影机时是否错误要求所有人物、背景和阴影保持相同屏幕位置；门槛、桌心、道路中轴或其他边界是否真的承担构图与动作约束；目光目标是否双向明确；“站位固定、不越界”等合同是否与迈步、转身、递物、离场等实际动作冲突。
- 信息与动作预算是否可执行：长台词、精细手部、道具转移、多人反应、摄影机运动、转焦和光影变化是否共同服务同一转折；声音、表演/动作和摄影机/焦点是否按并行轨道计算。普通连续对白不要求每句显式写起说点和接收瞬间；只有这些时点影响抢话、动作同步、误解或情绪落点时才成为交付控制。超载时优先删无收益控制、调整时序、重选机位或拆镜，不用补写更多限定词解决。
- 摄影机与剪辑是否帮助观众读取表演、关系或信息；复杂或关键运动应有触发、路径和落幅，普通固定镜与自然跟随无需用长句证明。删除运动若观看结果不变应删去或重选，静止和运动都不能成为模板。
- 相邻镜属于同一连续动作、未完成目光、情绪余波或声音桥时，是否存在一个可读的下一镜入口，如视线方向、屏幕位置、人物距离、道具状态、动作方向、遮挡、光态或声音趋势。交接类型由当前导演方案决定；独立节拍、故意断裂或有意跳切不因缺少交接而失败。
- 使用角度、角速度、距离、线速度或分段停留时，数值是否满足 `扫角=角速度×运动时间`、`距离=速度×运动时间`，推镜、停留、拉镜、焦点和不可并行人物动作是否共同落在本镜时长内。完整环绕、往返运动或多人依次发言若超过平台单镜上限，必须缩小轨迹、调整合理速度、减少串行任务或按真实剧情节拍拆镜，不能只保留看似精确的数字。
- 全局视觉基线是否从真实光源、空间、材质和肤色建立连续逻辑；逐镜 `视觉控制` 是否用一个紧凑句给出当前最重要的主光、综合色彩/材质和曝光或肤色结果。内部仍可逐对比较光源、冷暖、黑位、高光和肤色，但不得要求每镜把整套调色参数重新抄入直投提示。
- Seedance 文句是否清楚区分摄影机、焦点、人物/手部和道具，是否明确先后、参照系、容器归属与稳定终态；没有可见场景依据时是否误用南北方位，焦点是否同时声明多个互斥主体。
- 画面是否有题材和人物专属性，强弱节奏是否合适，是否留下值得保留的结束画面。
- 完成逐镜审查后，再按整场时间线观看：每个节拍是否带来新信息、关系/目标变化、身体或道具状态变化、递进压力、必要蓄力或有效余波；观众已经读懂后仍无新增意义的停滞是否存在，真正需要沉默、倾听、悬念延迟或动作落稳的段落是否反而被压短。不得用总时长、平均镜长、镜头数或快慢标签直接判定节奏。
- 做饭、行走、递物、检查等过程是否被按当前戏剧功能判断，而不是因属于生活或程序动作就被压缩；相似节拍是否真的重复，还是每次改变了证据强度、人物判断、关系压力、喜剧预期或结果可信度。
- 若修订采用合并，合并后的单镜是否仍只有一个观看中心，动作能够顺序执行，台词触发与起说点、获准听者反应、空间可读性和稳定终态是否完整，Seedance 是否仍能唯一理解主语与先后。若任一项损失，撤销合并或重选结构；不得以减少镜头数本身作为收益。
- 每镜时长是否等于三条并行轨道的最长实际持续时间，加上不可重叠串行动作和最终约 `1s` 自然留白；台词与说话中表演、听者逐步接收、运镜、转焦、OS/OV 覆盖动作是否被错误重复加时。镜尾已有台词尾势、动作落稳、情绪余波或转场时，是否与约 `1s` 留白合并而不是再次叠加；删除最后多余时间后若不损失声音、动作完成、关系读取或剪辑接点，应缩短。稳定结尾只核对尾态，不作为第二份停留时间。
- Seedance 收敛是否只减少无必要的逐关节控制、重复状态、伪精确数字和低价值装饰，而保留人物专属表演、关系距离、空间压力、有效构图、材质光影、声音节奏与情绪余波。去掉抽象风格词后应能还原原文；若保留事实后只剩通用说话或动作摘要，则判定视觉表达被过度收敛。修改既有分镜时，比较修改前后是否静默丢失源文事实、已确认物理状态、情绪峰值或仍有叙事价值的画面记忆点；允许用更好的导演方案替换低价值演绎，不要求逐字保留旧稿。

这些是内部判断视角，不是逐镜关键词、字段长度或证据数量清单。反向还原不得迫使创作者把审片过程复制进提示词。简洁镜头、静止镜头、克制表演、自然补间和有意悬念不因省略常识性控制而失败；只有关键事实、因果、空间、声音权限或已选导演意图不可读时才判 `REVISE`。因果可还原、连续性闭合、直投提示可独立理解且工程事实通过后立即停止。

## 2. 真实画面审片

- 空间 SVG/PNG：先核对具名人物、站位、面向、机位、视锥、遮挡、边界和标签可读性。几何正确后还要由视觉能力查看实际 PNG；双 PASS 后才可提升到 `approved-jimeng-2d/`，其中 PNG 可作为即梦空间关系参考，但仍不是成片美术参考。
- 关键帧：查看人物身份和数量、构图、景别、表演、光影、影调、色卡、比例、支撑、道具和文字。只有与导演方案一致的图才可作为 Seedance 参考。
- 视频：查看首帧、关键动作帧和尾帧，并检查动作先后、口型、反应传播、摄影机路径、转焦、光影漂移、肤色、背景稳定和结束保持。任何客观指标都不能代替视觉观看。

纯文本交付没有图片或视频证据时记录 `visual_review=NOT_APPLICABLE`，设计审片 PASS 后可以 FINAL，但证据范围必须标为 `TEXT_ONLY`，不代表 Seedance 成片已经验证。存在任何交付视觉资产时必须查看真实画面并记录 `PASS|REVISE`；只审核线稿、关键帧或其他图片参考时为 `REFERENCE_REVIEWED`，交付视频并通过真实画面审片时才为 `RENDER_REVIEWED`。`NOT_RUN` 只能保持 PROVISIONAL，不能标记 FINAL。

## 3. 修订

先判断失败属于原文理解、因果断点、拆镜/容量、表演、空间、摄影机、焦点、信息与动作预算、光影色卡、平台措辞或素材本身，再由模型重做对应决定。因果断点只展开受影响的一段，不重建全场分析；优先只重做受影响镜头及直接连续性，但不要为了缩小 diff 保留错误结构。

同一问题连续两轮仍只是增加限定词、重复终态或移动字段，停止局部补丁，回到拆镜、机位、动作顺序或信息释放重新设计。脚本不生成修复文案，也不限制模型应选择哪种创意方案。

真实生成失败时，先定位第一个使素材不可用的层级：身份与人数、空间与左右、动作与接触、摄影机路径、表演与口型、焦点与景深、光影与材质。下一次生成只改变一个最可能主因并保留可比较条件；这是模型用于判断因果的测试方式，不是脚本循环，也不要求按固定顺序创作。

参考冲突先修素材；动作无法完成先检查准备态、路径与拆镜；遮挡后重建先检查遮挡前后身份状态；焦点跳动先检查观看中心和转焦终点；曝光或材质闪烁先检查真实光源、高亮动态和细碎纹理。需要完整问题族与停止条件时按需读取 [seedance-generation-diagnostics.md](seedance-generation-diagnostics.md)。

## 4. 提升与最终状态

所有视觉资产先放在 `staging/`。二维空间图通过几何审核和真实 PNG 视觉审核后，使用 `promote_blocking_reference.py record` 与 `promote` 提升到 `approved-jimeng-2d/`；只有提升后的 PNG 可作为即梦空间关系参考，SVG、审核图、未通过或哈希变化的文件不得进入正式层。关键帧与视频也必须记录用途和真实画面 PASS 后再被 Markdown 引用。

使用 `review_manifest.py create --review-report <reports>/design-review.md` 创建 review attestation，声明设计/视觉结论并分别绑定源文、主输出、审片报告和正式资产 SHA-256。审片报告仍保存在 `reports/`，不进入投喂交付；它不证明审查质量、审查者身份或独立性。无需单独执行 verify；最后运行 `validate_delivery.py --final --review-manifest <manifest>` 直接复核哈希。设计 PASS，且视觉 PASS 或确无视觉证据时为 NOT_APPLICABLE，才能标记 FINAL。

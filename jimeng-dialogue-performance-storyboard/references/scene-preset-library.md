# 参数化场景预设库

本文件只提供“候选池”和“选择机制”，不得把任何条目原样套成最终空间锁或色卡。最终输出必须根据源文动作、人物关系、剧情功能和用户指定风格重新生成本场专属句。

## 使用原则

- 先判断剧情功能，再选择场景骨架；同一地点不能默认同一套左右站位、色卡或光影。
- 每个场景最多选 2-3 个空间锚点、1 个主要人物关系、1 个道具活动区和 1 个影调分支。
- 源文明确的地点、动作、道具、人物距离优先于预设库；预设只补足源文缺失的可见制作细节。
- 预设库不输出到最终 Markdown；只影响 `本集空间锁定索引`、`本集影调色卡索引`、`场景状态表` 和每镜压缩视觉前缀。
- 禁止同类型场景机械复用：同一集里两个客厅、两段警局或两条走廊，必须根据剧情功能或人物动线产生不同空间锚点/影调侧重。

## 选择流程

内部先写一行：

`场景ID | 场景类型 | 剧情功能 | 情绪温度 | 空间锚点候选 | 人物关系候选 | 道具活动区 | 影调分支 | 禁止套死项`

剧情功能优先级：

1. 制度/权力压力：柜台、长桌、门框、对称构图、冷光或硬光。
2. 亲密/照顾/暧昧：沙发、床边、吊椅、台灯、近距离但边界清楚。
3. 误会/喜剧错位：开放空间、橱窗、手机、轻暖点缀、反应停顿。
4. 冲突/质问/关系重定义：隔物、前景肩线、手部道具压力、短推近。
5. 孤独/失落/余波：空位、门缝、窗边、走廊留白、缓慢拉远。
6. 救援/保护：入口动线、身体遮挡、受伤状态、暖肤色保护。

## 常见场景候选池

### 客厅 / 公寓

- 空间锚点：沙发、茶几、落地窗、窗帘、台灯、电视墙、玄关门、吊椅、地毯。
- 人物关系：同坐但隔茶几；一人坐一人站；一人靠/躺在承载物上，另一人在侧前方；门口到沙发的进入动线。
- 道具活动区：茶几桌面、沙发扶手、手机、毯子、外套、水杯、药盒。
- 影调分支：亲密暖米台灯；冷战低饱和灰米；夜间独处暗暖；回忆低饱和柔光。
- 禁止套死：不要每个客厅都写同一张沙发正中；人体在沙发/吊椅/床上的支撑点必须按后续动作反推。

### 卧室 / 床边

- 空间锚点：床头、床沿、床头柜、台灯、窗帘、衣柜门、地毯。
- 人物关系：床上/床边高低差；一人坐床沿一人站床侧；一人背对门口；门缝观察。
- 道具活动区：被子、枕头、手机、药、水杯、衣物、床头灯开关。
- 影调分支：私密暖黄；病弱低亮暖灰；压抑冷月光；甜蜜柔和暖粉米。
- 禁止套死：不要让被子、衣物或身体接触关系跨镜重置；亲密姿态必须写接触边界。

### 警局 / 办事大厅

- 空间锚点：办事柜台、缴费窗口、签字台、公告栏、等候长椅、玻璃隔断、走廊门。
- 人物关系：隔柜台；柜台外侧同侧站位；等候区前后关系；入口到柜台动线；民警在柜台内侧。
- 道具活动区：签字台、刷卡终端、罚款单、银行卡、证件、手机。
- 影调分支：制度压迫冷白蓝灰；误会喜剧冷白加少量暖黄；夜间疲惫偏暗蓝灰；救援保护冷白底色保暖肤。
- 禁止套死：不要固定所有人物左右；柜台/窗口只能写内侧外侧、前后和隔物，不写来客位这类抽象词。

### 商业街 / 街边

- 空间锚点：橱窗、店招、路灯、人行道、路沿、玻璃倒影、街边长椅、店门。
- 人物关系：并行走；一人停住另一人多走半步；橱窗前面对面；路沿边前后错位。
- 道具活动区：手机、购物袋、奶茶、车钥匙、橱窗反光。
- 影调分支：轻快奶油橙暖光；尴尬误会暖光中保留冷色阴影；夜街霓虹点缀但低饱和；失落时拉开留白。
- 禁止套死：霓虹不能污染脸和服装；路人只做弱虚化，不抢主角口型。

### 医院 / 诊室 / 走廊

- 空间锚点：护士站、病床、输液架、诊室门、长椅、白墙、走廊灯。
- 人物关系：病床边高低差；走廊长线距离；护士站隔台；一人扶住另一人。
- 道具活动区：病历、药袋、输液架、手机、外套、水杯。
- 影调分支：病弱冷白低饱和；照顾暖肤保护；焦虑走廊冷光拉长；释然时窗光柔化。
- 禁止套死：不要让伤痕、病床、输液管和扶抱关系跨镜消失。

### 学校 / 教室 / 走廊

- 空间锚点：课桌、黑板、窗、讲台、走廊栏杆、储物柜、楼梯。
- 人物关系：同桌/前后桌；走廊擦肩；门口等待；讲台到座位视线。
- 道具活动区：书包、试卷、手机、课本、门把、储物柜。
- 影调分支：青春暖窗光；冷场低饱和教室；公开尴尬用全景关系；暗恋用长焦浅景深。
- 禁止套死：不要让同学人群清晰抢焦；多人教室必须写可见人数和背景弱化。

### 车内 / 车外

- 空间锚点：驾驶座、副驾驶、后排、车窗、车门、后视镜、安全带、路灯反光。
- 人物关系：前后排距离；副驾与驾驶座并排；车外隔窗；车门打开后的内外侧。
- 道具活动区：安全带、车门把手、手机、钥匙、纸巾、方向盘。
- 影调分支：夜车冷蓝窗光；私密暖仪表盘；争执硬侧光；雨夜玻璃水痕。
- 禁止套死：上下车必须拍门把、门线、脚落地和车门状态；车内左右不能随反打重排。

### 餐厅 / 咖啡馆

- 空间锚点：餐桌、卡座、吧台、吊灯、玻璃窗、菜单、餐盘。
- 人物关系：隔桌对坐；同侧卡座；一人站桌边；服务员画外或背景弱化。
- 道具活动区：杯子、餐盘、菜单、手机、账单、纸巾。
- 影调分支：暧昧暖棕；尴尬低饱和暖灰；谈判对称隔桌；回忆柔光散景。
- 禁止套死：不要把所有餐厅都写成浪漫暖光；桌面道具归属和手距必须清楚。

### 走廊 / 门口 / 电梯厅

- 空间锚点：门框、电梯门、走廊灯、墙角、门把、楼梯口、玻璃门。
- 人物关系：门内门外；前后追赶；一人堵门；一人背对离开。
- 道具活动区：门把、钥匙、手机、外套、包。
- 影调分支：压迫冷长廊；离别大留白；追赶轻手持；秘密观察门缝框构图。
- 禁止套死：背对、转身、进出门、电梯开合都必须有动作链，不得跨镜直接面对对白。

## 色卡转译提醒

选中影调分支后，必须重新生成制作级色卡字段；不要把候选词原样复制。每镜只压缩复写：

`画幅/风格 + 本场固定锚点 + 主色 + 色温/光源 + 阴影 + 肤色保护`

示例句只供结构参考，不可固定套用：

`16:9，3D精致韩漫CG，客厅吊椅与落地窗固定空间，暖米主色，3000K台灯侧光，暖棕浅阴影，肤色自然不过曝。`

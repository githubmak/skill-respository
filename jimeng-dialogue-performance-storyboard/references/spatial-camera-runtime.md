# 空间与机位创作参考

本文件帮助模型闭合多人空间。站位、面向、机位、景别和焦段都是导演决定；工具只计算几何事实。

## 空间闭合

在设计镜头前确认人物与关键实体的物理关系：人物位于哪个区域或边界侧，身体面向谁或什么，视线落点，可触达道具，人物之间的距离与隔物，摄影机实际站在哪里、朝哪里拍、会看见哪一面和什么背景。

所有多人镜建立一条最低内部面向状态：`槽位/锚点 -> 躯干朝向 -> 视线目标 -> 画面左右`；转身、换位、正反打或遮挡风险镜再扩展为 `双脚与躯干 -> 头部 -> 视线目标 -> 摄影机轴侧 -> 当前可见面 -> 稳定终态`。这不是新交付字段，也不逐镜机械展开；单人无歧义静态镜仍直接创作，不为完整表格增加分析。

- 画面左/右是最终投影；门内/外、桌同侧/对侧是场景关系。说明参照系，二者不要互相替代。
- `正面可见` 不等于 `面向镜头`。对话人物可以面向对方，同时被摄影机看到正面或侧面。
- 人物、道具或身体朝向没有发生可见转换时，不应因切镜自动换位、换侧、换手或改变正背关系。
- 穿越门槛、走廊边界或家具通道时，动作必须经过真实通道，并留下明确终态。

先用场景参照系完成物理设计，再把当前机位投影成画面参照系。最终提示中，`画面左/右`、`人物自身左/右手`、`屋内/屋外`、`桌同侧/对侧`必须明确归属；不要让一个“左侧”同时承担多个参照系。抽象的关系轴只能用于导演内部判断，投喂时改写为摄影机所在的实体一侧、可见背景锚点和人物在画面中的投影。

切镜不会自动完成身体动作，但换机位可以改变摄影机看见的人物正面、侧面或背面。相邻镜先分别核对两类事实：人物真实位置、躯干朝向、头部与视线、站坐和支撑、活动手、道具归属与接触、边界侧、门窗状态属于物理状态；摄影机位置、拍摄方向、画面左右和可见面属于画面投影。不能把摄影机换到人物另一面误写成人物转身，也不能用换机位掩盖人物真实状态已经无过程改变。

在连续时间内，新镜的物理起态默认继承上一镜稳定尾态。若位置、躯干朝向、头部朝向、视线目标、站坐、持物手、道具持有人、接触关系或边界侧确实改变，由模型选择最符合叙事的一种处理：在前镜尾段拍出转换，在新镜开头拍出转换，明确建立有足够时间完成动作的时间省略，或重选机位证明变化只来自观看角度。转身要说明双脚是否移动、躯干从何处转向何处、头部何时跟随以及最后看向谁；起身要有支撑和重心转换，递物要有接触与松手，拿起或放下要交代原承载面与新终态。没有物理变化时，新镜直接重述必要起态，不写“沿用上一镜”。

成稿后依据事实连续性台账逐对反读`上一镜稳定结尾 -> 下一镜主体与起态`，至少比较固定物、人物区域、躯干朝向、头部朝向、视线目标、站坐支撑、活动手、道具归属与接触、门窗/边界，再单独比较摄影机轴侧、画面左右与可见面。前镜尾帧已经建立的道具状态，只要后镜的人物手部或该道具仍入画，后镜起态就重述最小可见事实；若不再显示，必须交代放下、交接、出画或时间省略。台账只保存客观状态，不进入 Seedance 投喂。

## 机位选择

关系镜、肩后镜、单人镜、插入镜和运动镜都是可选工具，不存在默认比较顺序。根据观众需要看清的关系、信息和表演选择。正反打若共享同一站位，应保持人物物理状态一致，并让摄影机位于关系线的同一物理侧，除非画面明确拍出越轴过程。

摄影机的移动只能改变观看投影，不能改变人物真实站位。复杂路径先写起幅、实际空间方向、速度感、经过的实体、落幅和稳定终态；若路径需要穿墙、穿家具或失去目标视场，应由模型重选机位或镜头结构。

最终提示分别描述四类主体，禁止共享一条含糊路径：

- `摄影机`：起幅、相对固定物的位置、移动方向、落幅和停止。
- `焦点`：开局焦点、触发时机、转移对象和最终保持对象。
- `人物或手部`：动作起点、可见路径和稳定终态。
- `道具`：承载者或承载面、是否移动、接触/松手和终态。

距离与角度只是辅助，必须同时给出可见参照。`向右横移0.2米`要改写为按最终画面向哪一侧移动、沿什么实体、从什么构图到什么落幅；`保持关系轴同侧`要改写为摄影机始终留在哪个实体一侧、哪些背景锚点保持同一画面侧。摄影机运动只在能改变观众对关系、表演或信息的读取时使用；静止也必须有明确观看收益。

细小证据必须匹配景别。指尖、眼神、嘴角、文字或道具边缘若是剧情信息，应使用足够近的起幅、单次推近/转焦或独立插入镜；不要把它藏在多人远景里。一个生成片段若同时承担多次说话者切换、人物位移、道具转移、转焦和复杂运镜，应由模型按因果节拍拆镜，而不是继续增加限定词。

## 动作与终态

会改变身体、接触、道具或边界的动作，按需要闭合为`起态 -> 接触/发力 -> 转换 -> 稳定终态`。简单动作不必机械展开，复杂动作不能跳过决定物理归属的阶段。容器内未被拿起的物体用正向事实说明仍在容器内；不要为静止物体编造路径，也不要用大量否定词强化模型本不该执行的错误动作。

镜头结束时只保留一个可验证终态：最后可见人物、人物位置与朝向、活动手、道具位置、最终焦点、摄影机落幅和光影稳定状态。若这些终态互相冲突，先重选镜头结构，不用同义句重复覆盖。

## 几何工程图

空间关系确实复杂时建立 blocking JSON。模型填写人物坐标与面向、实体障碍、边界/门洞、机位、朝向、视场和入镜主体；禁止 `auto_position`。`render_blocking_reference.py` 只检查参数、碰撞、净距、遮挡、轴侧、门洞通视、完整视场和标签布局。

二维只证明人物位置、双脚/躯干平面朝向、边界、轴侧和视锥。需要证明头部、视线、站坐、接触或真实投影时使用 3D。若人物在同镜内发生决定空间理解的物理变化，为同一镜号建立 `physical_phase=start` 与 `physical_phase=end` 两个状态并分别审核；仅摄影机运动时继续使用 camera `path`。不要在一个状态里同时声明 physical phase 与 camera path；同时复杂运动应拆镜，或仅在用户已有合格参考视频时使用该视频。

线稿只画几何，不画情绪、造型、运镜或美术。输出先进入 `staging/blocking/`，经几何与真实画面双 PASS 后才可提升为工程参考；它不能作为 Seedance 成片风格或 cinematic reference。

直投提示仍要用可见语言重写当前人数、位置、身体面向、视线、机位与背景，不能只写 `空间锁定`、`保持轴线` 或 `沿用上一镜`。

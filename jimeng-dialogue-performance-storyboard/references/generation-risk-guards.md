# Seedance 生成风险参考

本文件列出容易出现错误先验的对象和表达方式。它只提醒模型检查风险，不自动删减动作、固定机位或选择修复。

## 视觉实体

先区分源文实体、用户指定实体和模型为完整画面作出的合理推断。台词或 OS 中提到的地点、职业、人物和道具不会自动成为画内实体。负面提示也可能激活错误概念，因此优先写目标造型、真实地点锚点和当前可见道具，不在负面中首次引入医院、制服、武器等领域概念。

## 手机、屏幕与文字

判断设备用途：操作、展示、通知或通话。操作时写握持、屏幕朝向使用者、拇指动作、视线和镜头实际看见的背面/边缘；展示时才安排屏幕朝向观众或另一人物。精确 UI 文字优先后期叠加，AI 画内文字只在用户明确接受近似时使用。

不要让手机操作、屏幕转向、可读文字、人物转身、长台词和强运镜无序同时发生。模型可根据戏剧需要拆镜、调整先后或使用已审核关键帧。

## 光色与肤色

环境色不应无因覆盖脸、嘴和活动手。写清真实光源、受光面、阴影区域和中性/自然肤色参照。彩色光、体积光或混合光要说明来源与实际落点；避免用“高级肤色”“情绪光”替代物理受光。

## 尺度、人数与画外

人物真实身高、体型和骨架保持一致；画面大小可随距离、焦距和裁切连续变化。肩后前景局部放大不等于人物体型改变。

明确本镜实际可见的人物和画外声音。画外人物不能成为可见身体面向对象，可写人物身体朝向某个门口或方向，视线落向画外声源。多人场面由模型决定谁清晰、谁虚化、谁画外，以保证当前因果可读。

## 正向表达与结束状态

优先写当前真实状态和获准变化，再写少量确有必要的坏相。不要用大段“不要、禁止、避免”替代可见事实。结束时确认人物、道具、摄影机、焦点、口型、光源和背景的实际状态能够同时成立。

风险适配不能删除已选的表演、关系、摄影机或光影意图。若可靠生成需要改变结构，由模型回到导演层决定拆镜、简化同时动作或使用参考素材。

# 回归测试样例库

本文件用于修改技能后做回归验证，不参与常规生成。每次大改后至少用其中 3 类样例生成短分镜并跑 `scripts/validate_storyboard.py`；涉及对应风险时优先选该类样例。

修改后先运行统一套件：macOS 使用 `python3 scripts/run_regression_suite.py`；Windows 使用
`powershell -ExecutionPolicy Bypass -File scripts/run_skill_tool.ps1 scripts/run_regression_suite.py`。
定位失败时才单独运行报告中的测试脚本；真实输出仍需运行 `scripts/validate_storyboard.py --shadow-report <output.md>`。

## 固定样例类型

1. 普通双人对白：双人面对，无道具转移，无 UI；验证轻量镜头不缩水，台词进画面描述，听者有低幅反应。
2. 三人警局多人戏：民警、主角、旁观者/混混；验证可见人数、柜台内外侧、口型唯一、背景弱化。
3. 手机消息文字：手机背面或屏幕不可见但消息需要可读；默认验证直接提示词只预留安全区、具体文字进入后期文字句。另设用户明确要求 AI 画内生成的短气泡样例，验证文字不超过12字、允许文字近似、二维浮层、安全区、不贴手机和不跟随透视。
4. 吊椅/沙发姿态：人物靠坐、蜷腿、后续翻身或坐起；验证人体支撑点跨镜承接。
5. 道具递交：分别用银行卡、铜铃、纸伞、玉佩等已知与未登记实体从A到B；验证都能触发关键帧，并检查起点、接触、握住、松手、新持有人稳定。
6. 正反打：A肩后拍B，再B肩后拍A；验证保轴、肩线比例、双方身体面对、距离/道具复写。
7. 商业街轻喜剧：并行走、误会、停顿反应；验证暖色街景不抢脸、路人弱化、轻喜剧张弛。
8. 情绪峰值余波：拒绝/承认/质问后被击中者停住；验证独立余波镜、关系定格、不新增道具变化。
9. 负向概念泄漏：在住宅女性镜头中故意写 `不要护士帽/不是医院`；验证失败样例被拦截，改成目标发型、服装和客厅锚点后通过。
10. 手机游戏操作：人物双手横持手机玩游戏；验证缺少屏幕用户侧/镜头侧朝向时被拦截，补齐 `屏幕朝向本人 + 手机背面或斜侧边缘朝镜头` 后通过；直接提示词、必要约束、补充负面、关键帧和即梦视频提示任一字段出现 `游戏界面露出/HUD/按钮/技能栏/血条/小地图` 都必须失败，负面字段改用 `手机翻面、屏幕乱字、手机高度跳变、手机漂浮穿手、手指畸形、握持穿模`。
11. 彩色环境光与肤色：蓝灰/暗绿环境光落入人物脸部；验证没有正向中性肤色锚点时被拦截，补齐脸部受光均匀和浅阴影落点后通过。
12. 多人纵深与人物比例：两名具名人物分处前后景；验证只有 `A在前景、B在后景` 时被拦截，补齐到镜头距离、同一连续地面、近大远小的投影尺度和稳定头身比例后通过。环境自身的前景/后景层次不得误报。
13. 门外看屋内的正背关系：A在门外前景背对摄影机并面向B，B固定在门槛内侧面向A且正面可见；验证此写法通过，`A背对镜头、B正面对镜头`、双方同向或只写 `两人对望` 被拦截。
14. 回家与门槛穿越：门外起点、一脚跨槛中间态、双脚进入屋内终态；验证缺少任一阶段、常驻屋内人物跑到门外、摄影机在门外却把门外夜色写成背景时失败。
15. 前景儿童遮挡后景成人：儿童头顶低于成人肩线，脚底共地，真实头身稳定；前景只遮住成人下半身，成人脸/手/支撑物从视觉通道可见。只有百分比或只有 `前景/后景` 时失败。
16. 同类道具辨识：任意两件同类物分别绑定持有人，并以形状、颜色、尺寸或内容物区分；只写数量和笼统归属时失败。
17. 授权直面镜头：源文明示打破第四面墙，双人关系中仅A在限定时间直视镜头，B继续看A，A落幅回看B或保持直视；验证通过。无授权、多人一起看镜头、缺少时间窗/结束状态或把普通正反打写成直视镜头时失败。
18. 词面与镜头语义碰撞：环境水纹不得自动判为空镜，人物躲在他人肩后不得判为过肩镜头，人物摇头和眼神移动不得判为摇镜或移镜；对应的零人水纹特写、摄影机位于人物肩后、镜头推近仍须正常触发。
19. 悬疑证据揭示：人物发现门锁划痕后确认有人进入；验证先限制信息、再给痕迹、后确认事实，不在建立镜提前展示入侵者或答案。
20. 无台词视觉因果：人物发现漏水、寻找来源并关闭阀门；验证原因、动作、环境反馈和新状态可见，不用旁白替代画面。
21. 亲密关系试探：两人共享雨伞，一人迟疑后调整伞面；验证距离和手部变化来自源文，不用粉色滤镜、无依据慢动作或强行触碰代替关系。
22. 时间压缩蒙太奇：同一工作台连续数日完成一件器物；验证固定锚点、每镜一个状态增量、光线/时间变化和最终成果，不写成一镜自动变形。
23. 非战斗行动：人物沿走廊搜寻出口、遇到封路后改道并抵达楼梯口；验证目标、路线、障碍、调整和到达状态连续，不跳过中间路径。
24. 镜头类型与长度建议：准备一条低于建议区间但语义完整的无台词因果镜，以及一条位于建议区间或更长、但缺少结束状态/动作因果的冗长镜头；验证前者语义通过且显示 `length_guidance=short`，后者语义失败并显示 `semantic-incomplete/despite-length`；不存在最低字数硬错误。
25. 类型建议区间：分别准备对白、多人关系、无台词因果、空镜/物件插入、蒙太奇、非战斗行动、道具转移和未分类镜头；验证分类稳定，只有道具/姿态/UI/门车门等转换进入高风险状态转换，环境水纹、人物摇头和人物躲在肩后不因词面碰撞误分类。
26. 古风游戏自动适配：制作要求写“古风游戏”时启用东方空间、自然色、材质分层、动机光与动作重量；同一句只出现在角色台词中时不得触发，最终直接提示词不得保留游戏名称。
27. 现代剧场景生命：住宅、办公室、咖啡馆或夜车对白中，验证光源有现实来源，主体动作与环境/材质响应存在因果和差速，落幅保留一项低幅余波；不得连续重复慢推、眨眼、薄雾或窗帘轻摆。
28. 动态光影：门开、车灯经过、云影变化、手机熄屏或烛火受风只触发一次局部光影变化；验证光线方向、受光面、肤色与黑位连续，体积光和综合色不覆盖脸、嘴和活动手。
29. Seedance 双目标：同一份事实合同导出 `*_Seedance2.0.md`、`*_Seedance2.5.md` 与 `00_双版本索引.md`；两版镜号、时长、台词和道具状态一致，光影适配词有目标差异且索引不可投喂。
30. 全局比例与条件支撑：全局正向锁定必须包含骨骼/头身比例、真实身高体型、四肢长度、地平线/消失关系、两人身高差和物理距离投影规则，并区分站立、行走、坐卧与腾空支撑；通用负面只保留无因尺度跳变、无因浮空、透视、穿模和肢体风险，四类支撑负面只在对应动作镜追加。
31. 语义级去套路：同组连续三镜分别写“缓慢推近、轻推、小幅推进”，验证归入同一 `camera_push` 家族并产生影子诊断；只有两镜命中或三镜分别使用稳定机位、道具接触和现实光源变化时不报。
32. 动静曲线与相位：古风开门侧风、现代车灯掠过、杯子落桌三类场景均先锁静止锚点，再按主体触发、第一响应、延迟响应、余波稳定编译；复杂对白、道具转移、坐卧/腾空镜只保留一个低幅响应。
33. 多证据题材路由：分别准备宫廷关系戏、江湖追踪、仙侠施法、现代住宅对白、都市夜车和乡村家庭场景；每例至少用三个独立证据通道确定基础 profile，并只叠加一个剧情 modifier。单个“古装/夜景/乡村/悬疑”词或台词中的风格词不得独立触发。
34. 三人关系投影：站位与轴线都正确，但看不出谁控制出口或证据时，设计复核 `REVISE`；修订后关系压力必须由距离、隔物、遮挡、可触达性或通道控制可见。
35. 起止边界：直接提示词开头、唯一转换、末20%与 `【状态继承】` 对照；后者新增道具、位置、认知或情绪事件时失败。
36. 表演闭环：仅写表情而无接收刺激、可见处理和选择时 `REVISE`；“伸手后停住并撤回，落幅手已收回”作为有效压住选择通过。
37. 源文提示：`角色（笑）：原台词` 可按策略编译为克制笑意和相容声音；无依据改成怒吼失败。分别测试 `A知道事实` 与 `A知道B已知事实` 不得混同。
38. 显式时间窗：欠覆盖、越界、无效区间和未声明重叠失败；连续全覆盖通过；相对时机继续允许。固定字速估算只出现在 shadow。
39. 审查清单：源文或任一主输出改变一个字节后旧清单变 `STALE`；`self_check` 不得声明 `independent:true`。
40. 事实级揭示：悬疑/误会/画外威胁为每个关键事实记录 show/withhold、载体、触发和保护方式；答案在触发前从背景、反应或制作控制泄漏时 `REVISE`。
41. 风格冲突与回退：古代宫廷不得自动加入江湖动作，现代夜景无店招/车流证据不得加霓虹，乡村不得自动暖黄怀旧，悬疑不得自动染绿，唯美不得自动加雾/辉光/慢动作；证据矛盾或低置信时回到通用电影化默认。
42. 前置源文闸门：空文件/不可读文件必须阻断；缺少场景标题、人物表、视觉细节或只有散文段落只产生 advisory，仍允许建立保守空间锁并进入分镜流程；风险词只路由专项 reference，不直接变成画面事实。
43. OS 说话人绑定：在直接提示词、表演与声音、口型分窗中分别放入裸 `OS：“我没事。”`、代词 `她OS：“我没事。”` 和声音锁定表外的 `陌生人OS：“我没事。”`，验证三者失败；改为声音锁定表内的 `沈星雨OS：“我没事。”` 后通过。OV、系统音、内心独白和旁白不套用人物名 OS 规则。
44. 夜景跨镜光照连续：第一镜写夜晚小院、油灯主光，第二镜切换焦段、门框构图和可见人数但省略时段/门外亮度，验证失败；第二镜复写 `同一夜晚、门外深蓝黑位、油灯仍为主光源、曝光保持` 后通过。若第二镜改成白天日光且没有时间流逝依据，必须产生相邻镜时段和主光源冲突。
45. 门槛人物面向与机位闭环：摄影机在门外朝屋内，A与摄影机同在门外并身体面向屋内B时，A写背面/侧背可见通过，写正面可见失败；同一人物同时面向门外和背对屋外、背对摄影机又正脸可见失败。摄影机在屋内朝屋外时，不得把屋内写成后景。
46. 制作控制语义对齐：控制行写“焦点锁A右脸与道具X、主光照亮A”，直接提示词改成“焦点锁B双眼、主光照亮B”时必须失败；只出现“焦点/光/纹理”类别词不能通过。
47. 逐人空间合同：多人关系镜每个具名入画人物都必须有物理槽位、身体面向目标；关系镜还必须有摄影机位置/方向、可见面、视线目标和关系轴同侧锁定。
48. 关系轴连续：相邻关系镜中人物画面左右交换时必须失败；只有明确拍出中性机位、连续越轴和屏幕方向交换过程时通过。
49. 关键帧事实合同：首帧/尾帧必须逐帧复写直接提示词的时段、主光源、可见人数、人物槽位/面向/可见面/视线、摄影机方向和道具；白天/日光或门槛侧漂移必须失败。
50. 五镜签名镜头密度与上限落地：准备同场 5-9 个子镜头；任一滚动五镜窗口没有完整七项签名合同时失败。只有 `记忆锚点：很震撼`、缺第一眼焦点/情绪载体/相邻三项差异/不可降级核心、关系/认知变化未进入直接提示词、核心出现在全文60%之后或只塞在终端句时均不计数。影子报告对每五镜只有 1 个签名提示 `target=2`，超过 2 个提示强度过载。
51. 开放时段与主光实体：子夜/午夜/入夜归夜晚，破晓/拂晓归黎明，暮色/日暮归黄昏；熔岩、荧光植物、投影灯等未登记实体只要明确承担主光即可通过，相邻镜无依据更换实体必须失败，`无可见天光` 不得误认成日光主光。
52. 通用双侧边界：舱门、轿厢、车厢连接处、帷幕与结界分别建立A/B侧。缺人物所在侧失败；摄影机与人物同侧且人物面向另一侧目标时写正面可见失败，背面/侧背可见通过。
53. 全局比例语义等价：推荐模板原句通过；改用含义等价的骨架、身高体型、透视、支撑接触、站立/行走/坐卧/腾空及距离投影描述也通过，缺少任一概念仍失败。
54. 空间互斥事实：同一人物无转换时同时占画面左右、位于边界两侧、正背面同时可见或同时面向并背对同一目标必须失败；写出完整移动/转身/环绕/穿越过程后允许起终态共存。
55. 物理机位越轴：相邻关系镜摄影机从长桌南侧跳到北侧或东侧跳到西侧，即使未写人物屏幕左右也必须失败；只有连续拍出中性机位和越轴过程时通过，增量与最终校验结论一致。
56. 签名镜关系变化落地：七项合同完整但直接提示词只含构图、焦点和情绪，不含合同声明的关系/认知变化时失败；把变化改写成可见距离、道具归属、信息显露或策略结果后通过。
57. 创意核心前置：不可降级核心虽在终端句之前但首次完整出现位置晚于全文60%时失败；移到场景前缀后的主体画面段并保留后续工程事实时通过。
58. 多人站位面向线稿：双人和三人互动各同源生成同镜头组编号 SVG/PNG；验证真实姓名、稳定槽位、身体面向、实体锚点、边界两侧/通道、机位正斜方向和完整视场。正反打用同一 `blocking_id` 的两个单机位面板，人物/锚点/边界不变且自动近肩机位保持关系轴同侧；坐标越界、重名、实体重叠、墙/家具遮住目标、视线未穿门洞、人物圆点触碰视锥边缘或同 ID 站位漂移时失败，不画人物运动轨迹。
59. 表演创意与传播：准备拒绝、隐瞒暴露和三人得知秘密三个关键转折；分别生成表演候选并验证胜者具有人物专属性、台词与身体有因张力、行为签名留下可继承残留，摄影机看清泄露部位。换名可套用、拼接平均演法、无因升级大动作、三人同时明显反应或炫技运镜遮住反应时设计复核必须 `REVISE`。
60. 普通对白轻量内核：准备双人日常问候、试探和回避各一组，不加载表演专项引用；验证每镜可反推表面台词、关系意图、角色专属行为、唯一听者回应和句末残留。只有台词+皱眉/抬眼、听者无因反应、句末全部复位或连续镜重复同一动作无变化时设计复核必须 `REVISE`，修订不得增加输出字段或候选赛。
61. 表演编译往返：分别准备普通对白与关键转折的内部 IR。先把专属行为泛化成“神情克制”，再把听者回应只放制作控制，验证前置门禁和回译均失败；改为当前景别可见的具名身体/道具/距离行为，并让机位看清、句末残留进入正文后通过。IR、载荷和回译不得成为输出字段。
62. 分级提示词上限：普通镜500字通过、501字失败；复杂镜650字通过、651字失败；复杂且成对关键帧保护时700字通过、701字失败。扩容后的镜头若任务过载仍须失败，不能因未超字数而放行。

## 最小通过标准

- 每个样例至少 1 个镜头组、2-4 个子镜头，组总时长等于子镜头和。
- 全局锁定含空间索引、制作级色卡、角色声音锁定表。
- 每条直接提示词含压缩视觉前缀、景别机位、人物面向、光影/材质、台词/声音文本、结束状态。

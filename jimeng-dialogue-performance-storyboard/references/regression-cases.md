# 回归测试样例库

本文件用于修改技能后做回归验证，不参与常规生成。每次大改后至少用其中 3 类样例生成短分镜并跑 `scripts/validate_storyboard.py`；涉及对应风险时优先选该类样例。

## 固定样例类型

1. 普通双人对白：双人面对，无道具转移，无 UI；验证轻量镜头不缩水，台词进画面描述，听者有低幅反应。
2. 三人警局多人戏：民警、主角、旁观者/混混；验证可见人数、柜台内外侧、口型唯一、背景弱化。
3. 手机绿色气泡：手机背面或屏幕不可见但消息可见；验证二维浮层、安全区、不贴手机、不跟随透视。
4. 吊椅/沙发姿态：人物靠坐、蜷腿、后续翻身或坐起；验证人体支撑点跨镜承接。
5. 道具递交：银行卡/手机/杯子从A到B；验证起点、接触、握住、松手、新持有人稳定。
6. 正反打：A肩后拍B，再B肩后拍A；验证保轴、肩线比例、双方身体面对、距离/道具复写。
7. 商业街轻喜剧：并行走、误会、停顿反应；验证暖色街景不抢脸、路人弱化、轻喜剧张弛。
8. 情绪峰值余波：拒绝/承认/质问后被击中者停住；验证独立余波镜、关系定格、不新增道具变化。
9. 负向概念泄漏：在住宅女性镜头中故意写 `不要护士帽/不是医院`；验证失败样例被拦截，改成目标发型、服装和客厅锚点后通过。
10. 手机游戏操作：人物双手横持手机玩游戏；验证缺少屏幕用户侧/镜头侧朝向时被拦截，补齐 `屏幕朝向本人 + 手机背面或斜侧边缘朝镜头` 后通过，且不生成游戏 UI。
11. 彩色环境光与肤色：蓝灰/暗绿环境光落入人物脸部；验证没有正向中性肤色锚点时被拦截，补齐脸部受光均匀和浅阴影落点后通过。
12. 多人纵深与人物比例：两名具名人物分处前后景；验证只有 `A在前景、B在后景` 时被拦截，补齐到镜头距离、同一连续地面、近大远小的投影尺度和稳定头身比例后通过。环境自身的前景/后景层次不得误报。

## 最小通过标准

- 每个样例至少 1 个镜头组、2-4 个子镜头，组总时长等于子镜头和。
- 全局锁定含空间索引、制作级色卡、角色声音锁定表。
- 每条直接提示词含压缩视觉前缀、景别机位、人物面向、光影/材质、台词/声音文本、结束状态。
- 高风险样例必须出现对应防护字段：可见人数、状态转换、口型分窗、必要约束、补充负面或关键帧。
- 触发人体支撑变化、道具/衣物转移、UI文字、门车门/电梯空间穿越、复杂正反打或强运镜时，必须通过关键帧触发检测：要么添加成对关键帧字段，要么拆成更简单的准备/转换/终态镜头。
- 直接提示词、必要约束和单镜负面不得用否定的职业/制服/地点实体排除错误结果；原台词中的同类词不计入视觉概念泄漏。
- 操作型手机必须锁定屏幕朝使用者、手机背面或斜侧边缘朝镜头，并在 `【状态继承】` 复写手机朝向；没有展示任务时不得写可读游戏 UI。
- 可见人物脸部同时遇到彩色环境词或体积光词时，必须有正向肤色锚点和阴影落点；不能只写“不发青/不发灰”。
- 具名人物分处不同纵深时，必须同时锁定人物距离/层级、连续地面或承载空间、近处较大与远处较小的画面投影，以及稳定头身比例/骨架/真实身高关系；肩后局部遮挡按肩线占比单独判断。
- 校验脚本返回 OK；若失败，优先修生成规则，不给样例硬补丁。

# 空间、机位与连续性规则

## 空间锁定

空间锁定必须包含人物关系调度，不能只写画面左右。若镜头含躺、伏、靠、抱、扶、摔倒、翻身、坐起、披衣、开门、下车、屏幕文字、人群围观等概括动作词，同时应用 `physical-structure-continuity.md`，把概括词翻译成物理结构链。具名人物位于不同纵深、靠近广角边缘或沿镜头纵深移动时，按已加载的 `generation-risk-guards.md` 分离真实体型与画面投影尺度。

多人物或道具密集镜头按以下优先级写：

1. 固定场景锚点：先写 1-2 个不移动、能固定透视的参照物，例如 `同一张长桌横贯画面下半区，桌沿与画框平行，远处窗口固定在背景中线`。
2. 物理槽位：先分配故事空间里的稳定位置，再分配画面区域，例如 `桌内侧左座`、`桌内侧右邻座`、`桌对面左站位`、`桌对面右座`、`门内侧`、`车外侧`、`床左沿`。
3. 画面区域：再把人物放到 `画面左1/3`、`画面中区`、`画面右后1/4`，并写清前景/中景/背景和可见占比。
4. 人物关系调度：写清谁在谁对面、旁边、身后或斜对面，同时写距离和隔物/接触物。
5. 身体朝向和视线：写清身体朝向，例如 `身体面向A`、`身体面向桌对面`、`背向入口`，必要时再写视线目标。不要只写朝左/朝右。
6. 道具锁定：活动道具有独立位置和持有人；除非明确说明，道具不会自动跟随最近的人。

至少写清：

- 固定场景锚点或固定背景锚点；
- 可用时写物理槽位或移动路线；
- 画面中可见人数；
- 坐标基准：`画面左/中/右` 用于屏幕位置，`在A的右侧/桌对面/身后` 用于人物关系位置；
- 必要时写画面左/中/右区域和大致占比；
- 前景/中景/背景；
- 前后层级关系；
- 身体面向、背向或斜向关系；
- 视线目标；
- 大致距离；
- 隔物/接触物，例如桌子、门、车、柜台、自行车、床、墙；
- 活动道具位置和持有人；
- 场景锚点。

可使用这类表述：

- `隔餐桌正对`
- `右后侧半身距离`
- `左前方背向镜头`
- `车门夹在二人之间`
- `手机在A右手靠近B胸前`
- `民警在柜台内侧，A在柜台外侧，二人隔签字台`

避免只写 `A左、B右`。

不要把 `右侧近景`、`左前景朝右`、`空间延续` 这类含糊短语当作完整空间锁定。如果需要画面层级，必须同时配完整物理拓扑：同侧/对侧关系、组内顺序、身体朝向、距离、隔物/接触物和道具位置。

柜台/窗口/签字台/缴费台/前台/问询台场景必须使用“内侧/外侧/外沿/窗口内侧”这类可见词。禁止使用 `来客位`、`办事位`、`工作人员位`、`服务位` 作为最终提示词，因为这些词不会告诉即梦人物在隔物哪一侧。但这不是固定左右模板：示例里的画面左后/右前、人物数量、签字台是否存在，都不能直接继承。先按源文和上一镜尾帧填槽位：`固定物：柜台/窗口/签字台/缴费台是否真实存在；工作人员：是否可见，若可见在柜台内侧/窗口内侧；办事者：在柜台外侧/签字台外沿，或已转身离开柜台；同伴：在办事者身侧/身后/画外，是否同在柜台外侧可触达；隔物：柜台/签字台/玻璃窗；道具：在谁哪只手里或台面哪一侧；画面区域：按当前机位重新分配。`

线稿级桌边坐姿写法：`同一张长桌横贯画面下半区，桌沿与画框平行；A和B是桌内侧同排双人组；以二人坐在桌内侧、面朝餐桌对面的身体左右为基准，A在B左手边，B在A右手边；二人椅背在同一条平行画框的水平深度线、肩线平齐、到镜头距离一致，相距半身，桌沿在二人身前，不隔桌、不面对面、不一前一后；C在餐桌对面，与双人组隔桌，不插入A和B之间；本镜从B侧拍近景，A只作为组内同排前景肩线弱虚化。`

线稿或布局提示词要包含：

- 固定物形状和画面占比，例如 `长桌横贯画面下半区，占画面45%`；
- 带坐标基准的物理槽位和拓扑分组，例如 `A和B为桌内侧同排双人组 / 以二人面朝餐桌对面的身体左右为基准 / A在B左手边 / B在A右手边 / C桌对面左站位`；
- 同侧或对侧关系，例如 `二人肩线并排，桌沿在二人身前，不隔桌、不面对面；C与双人组隔桌`；
- 正面同侧座位的同深度关系，例如 `二人椅背在同一条平行画框的水平深度线、到镜头距离一致，不一前一后`；
- 斜切同侧座位的近端/远端关系，例如 `斜切机位从A这一端拍摄，A是组内近端，B是组内远端；二人仍同侧邻座，不隔桌、不面对面、不换位`；
- 物理拓扑之后再写画面区域，例如 `双人组位于画面中右区域，B为清晰主体，A只占组内前景肩线`；
- 身体朝向和视线，例如 `B身体微转朝A`；
- 空位和道具，例如 `桌对面左站位空出，道具X停在B正前方`。

## 场景状态表和镜头变化

锁人物槽位前先做一次关系投影：`人物 -> 正在施压/保护/回避/观察谁 -> 控制哪个出口/道具/信息 -> 本镜关系如何可见改变`。它只决定距离、隔物、遮挡、可触达性、视线和通道控制，不作为最终字段。若三人站位物理正确却看不出谁控制出口/证据，仍需重做调度。

给每个地点写单镜头前，先建立一条可观察状态表。状态表必须包含：

- 两到三个固定物及其相对位置；
- 每个角色的物理槽位、画面左/中/右区域、前后层级、身体朝向、视线和移动路线；
- 必须保持为空的区域；
- 每个活动道具的持有人、所在手/桌面/接触点和当前状态；
- 可见光源，以及本场允许变化的事实。

把这条状态表当成本场唯一事实来源。直接提示词开头是 start boundary，正文只推进本镜获准转换，最后20%是 end boundary；`【状态继承】` 只压缩复写 end boundary。写下一镜前比较新开头、上一镜结束状态和场景状态表。机位变化可以改变投影，不能偷偷改变座位、身体朝向、持物手、道具持有人、行走路线或人物所知事实。

只使用自然、可画出来的描述：`摄影机靠近窗边拍摄，画面左前景保留A的右肩，B在画面右侧看向A，文件柜留在B身后右侧`。不要使用抽象影视课术语作为最终提示词。

## 空间量化

- 避免含糊写法：`前景保留肩线 / 背景低幅人流`。
- 量化面积和虚化程度：
  - `前景：画面右侧1/4，B左肩弱虚化遮挡，占画面15%`
  - `中景：A清晰中近景，占画面60%，焦点在双眼`
  - `背景：橱窗与远处3-5名模糊行人，占画面25%，重度虚化`
- 同一个角色不能在同一镜头里既是前景虚化肩线，又是中景主表演者。
- 肩后镜头的前景肩线、后脑边缘或局部侧脸因贴近镜头而投影较大，只是局部遮挡关系，不代表该人物完整身体变高或变壮。量化肩线占比和裁切边界，目标人物仍保持完整头身比例；不能把前景肩线的大小外推成两人的真实体型差。
- 背景群演需要写人数、区域、方向、虚化和焦点行为：
  `背景远处3-5名模糊行人沿步行街同向慢走，不正对镜头、不抢焦、不做可读对白。`

## 高风险防弱化规则

把弱省略语替换成具体执行契约：

- 固定锚点：复杂桌边、房间或人群镜头，不能只从人物开头。先写 1-2 个不动固定物，例如桌沿、门框、窗、柜台、沙发、床、壁灯、走廊线或车门。
- 空间锁定必须达到线稿级清楚。每个高风险镜头都要写：固定锚点 -> 物理拓扑 -> 画面区域 -> 前后层级 -> 身体朝向/视线 -> 距离/隔物/接触物 -> 活动道具持有人/状态。任何一项如果只是暗示而非明写，就重写提示词。
- 多人物调度：不要只写 `A左、B右` 或 `三人不换位`。要写 `画面左1/3为A`、`A站在B桌对面约1米`、`C坐在B的右后侧半身距离斜看A`，并点名隔物/接触物。
- 可见人数闸门必须先于朝向。`【出现人物】` 和场景空间锁定只是本组/本场人物索引，不等于每条子镜头都要拍全。多人场景、画外人物或组级人物多于本镜实际拍摄人物时，每条 `【画面描述｜直接复制】` 开头写 `本镜画面内可见人数：X人`，再决定本镜清晰入画、边缘肩线/虚化、画外三类人物。肩线、背影、倒影、虚化人影都算入可见人数；纯画外声音不算。
- 不入画人物不得作为视觉目标。若 B 是画外或不入画，直接提示词不要写 `A面向B、看向B、朝向B、对着B、望向B、盯着B`，这会触发即梦把 B 生成出来。正确写法是 `A身体朝向画面右侧门口方向`、`A视线落向画外右侧声源`、`A朝窗边固定锚点低声回应`，并补 `本镜只出现A，B不入画，不出现身体、肩线、倒影或虚化人影`。
- 坐标基准：不要裸写 `左侧/右侧/前面/后面`。写 `画面左侧`、`A的右侧`、`桌对面`、`镜头前景` 或 `背景窗口前`，让模型知道参照系。
- 服务窗口基准：不要写 `来客位/办事位/工作人员位`。写 `柜台内侧`、`柜台外侧`、`签字台外沿`、`窗口内侧`，再补画面区域和身体朝向，例如 `A站在柜台外侧画面右前方，身体面向签字台；民警在柜台内侧画面左后方，二人隔柜台`。这个例句只表示写法，不固定左右；如果当前机位相反或工作人员不入画，必须重写。
- 画面层级不是人物关系。`前景/中景/背景` 只描述摄影机深度，不能改变剧情站位。如果两人坐在同侧相邻，不要因为其中一人出现在前景就把他写成 `桌对面`。要写 `同侧邻座/右侧半身距离/肩线前景遮挡`，再写真实桌边关系。
- `相互面对` 必须编译成双方各自的可见几何，不作为成品句单独使用。分别记录：`body_facing_target`（身体/胸口/脚尖面向谁）、`camera_visible_plane`（镜头看到正面/背面/侧面）、`eyeline_target`（视线目标）和 `camera_position`（摄影机在两人连线的哪一侧）。例如：`摄影机在A身后；A背对摄影机但身体面向B；B身体面向A，因摄影机位于A一侧而正面可见；二人视线在中间相接。` 不写 `A背对镜头、B正面对镜头`，后一句会诱发B把人物关系改成面对摄影机。
- 双人关系的两种安全构图：侧面关系镜写 `A在画面左侧、身体和脚尖朝右面向B；B在画面右侧、身体和脚尖朝左面向A；两人鼻尖与视线相向，摄影机保持在二人连线同一侧`；肩后镜写 `A的后脑/肩线作为前景局部遮挡，A仍面向B，B面向A且正面可见`。若无法同时说清人物面向和摄影机可见面，拆成关系中景与肩后反应镜。
- 直视镜头只接受源文明示的三类授权：摄影机代表对手眼睛的 POV、对镜口播、打破第四面墙。双人同框时只能指定一人，并写 `2.0-3.0秒仅A短暂直视镜头，A身体仍面向B；B视线始终落在A；3.0秒后A视线回到B`，或明确 `A保持直视观众到落幅`。若A连身体一起转向摄影机，必须拍出从原关系到直面镜头的转向；多人同时看镜头不属于授权。
- 前景/后景与百分比都是软锚点。人物纵深必须再绑定固定物、共同地面、脚底接触、遮挡部位和保留可见部位；比例百分比只能补充为 `左侧约三分之一`，不能独立承担人物大小或站位锁定。儿童前置时用 `头顶低于成人肩线/只到成人胸口、脚底在同一地面、真实头身和四肢比例不变`，必要时改成同一深度或只保留局部肩背。
- 门口机位先做可见性校验：摄影机在门外并朝屋内拍摄，背景必须是屋内墙面、油灯或家具，门外夜色在摄影机身后；摄影机在屋内朝门外拍摄，门外夜色才可作为背景。门框可以框景，不能同时成为互相矛盾的前后空间。
- 同排桌边人物必须先声明为“同侧组”，再写第三人的对侧关系。优先使用带坐标基准的组内位置、同深度/近远端锁定，而不是全局左/右极端：`A和B是桌内侧同排双人组；以二人坐在桌内侧、面朝餐桌对面的身体左右为基准，A在B左手边，B在A右手边；二人椅背在同一条平行画框的水平深度线、肩线平齐、到镜头距离一致，相距半身，桌沿在二人身前，不隔桌、不面对面、不一前一后`。如果 C 站在桌对面，补充 `C在餐桌对面，与双人组隔桌，不插入A和B之间`。不要只写 `A画面左侧、B画面右侧`，否则模型可能把两人分开或转成面对面。
- 标准站位必须保持标准。如果人物没有实际移动，每次都复用同一句物理拓扑，例如 `A和B是桌内侧同排双人组，以二人面朝隔物对面的身体左右为基准，A在B左手边、B在A右手边，二人椅背同一水平深度线、到镜头距离一致、不一前一后`；不要在 `右侧`、`右后`、`左邻位`、`斜对` 之间来回换，除非角色真的换座或转身。
- 机位侧和物理槽位必须分开。写机位变化时不要用连续性省略：`本镜从B侧拍近景，B清晰，A只作为组内同排前景肩线弱虚化；A和B仍是同侧邻座，不隔桌、不面对面`。不要让机位侧描述暗示人物换座。
- 必要时锁空位和动线：`角色C离开后桌对面左站位空出`、`左后出口为离场通道`、`新道具仍在桌对面右座正前方`。
- 道具接触/转移：不要只写 `拿起/递给/放下/接住`。必须写起点锚点、哪只手、接触点、移动路径、松手/新持有人和尾帧状态。
- 道具可触达性：写任何角色移动道具前，先确认道具在镜头开头就在该角色当前手可触达范围内。如果道具在另一个角色那边、另一个槽位或已经转移走，不要让角色直接移动它；要么写角色对道具做反应，要么先安排可信的伸手/走近路径。
- 道具锁定：不要让道具靠暗示继承。写 `道具X固定在角色B面前桌面中线偏右，距离桌沿约一掌，不跟随角色C移动`。
- 道具/人物位置变化必须传递。若一个镜头结尾有人坐下、站起、离开、进入、拿起、放下、穿上、递交或交换物品，下一镜直接提示词开头必须重新写明新的物理状态。只有 `上一镜/继承/仍然` 而没有可见事实是无效的。
- 隔物语言：`越过桌面`、`探过柜台`、`压到车窗里` 会暗示身体越过隔物。如果身体必须留在原处，写 `站直/坐直留在隔物本侧`、`肩背不前压`，只允许 `视线越过桌沿/柜台边缘/车窗线`。如果角色必须弯身或前倾，要写身体角度、脚的位置、手的支撑/接触点、躯干是否越过隔物线和最终姿态；不要让 `越过` 一个词承担所有信息。
- 行走/入场/离场：不要只写 `走来/离开/入画`。必须写画面方向、纵深路线、位移、速度、脚步接触和尾帧。
- 纵深行走还要写投影尺度的连续变化：走向镜头时画面占比连续增大，远离镜头时连续减小；头身比例、骨架和真实身高保持稳定。若摄影机也在推拉，必须说明人物与相机距离变化是否抵消，否则简化为单一运动。
- 运镜：不要只写 `推近/拉远/环绕/跟拍/两人轮流被拍`。必须写起幅、触发点、物理路径、距离/角度、焦点对象、停点和保持不变的空间锚点。
- 连续运镜允许且常常有用，但必须描述成一条带时间锚点的物理路径：开头稳定、开始时间、结束时间、路径、距离/角度、焦点转换、落幅画面，以及哪些空间锁定保持不变。不要只写含糊的 `连续运镜`。
- 关键虚化和可触达关系要轻量量化：前景肩线约占画面1/5、主角与听者相距半身或一臂、手距道具约一掌、道具停在两人胸前之间、背景人物位于画面后1/3并重度虚化。只对会影响生成的主体或道具量化，不要求每个镜头写满数字。
- 人群/背景：不要写 `无清晰口型/无清晰人脸/无口型`。写 `背景人物在远处虚化区低幅活动，不正对镜头、不抢焦、不做可读对白`；如果有人群对白，交给后期声音处理。
- 重要非说话人物：不要只写 `闭口`。写 `闭口 + 延迟微反应`。
- 多人互动要活。一个人说话时，可见听者要有低幅同步互动：视线跟随、眨眼、眉/嘴/肩轻微变化、手搭桌面/道具或小幅姿态调整。这个反应必须写进 `【画面描述｜直接复制】`，不能只写在校验备注里。
- 服装/身体状态连续：不要只写 `衣服不变/状态不重置`。写可见锁定物和身体状态。
- 人体姿态连续：不要只写 `躺着/伏着/靠着/坐起`。写头部、肩背、腰臀、双腿、双脚、支撑点、接触点和非接触边界；下一镜若要翻身或坐起，上一镜姿态必须能物理支持该动作。
- 位置传递：不要只写 `延续上一镜/空间保持/继承`。重新写当前可见事实：画面侧、物理槽位、前后层级、身体朝向/视线、距离/隔物、道具持有人和镜头落点。
- 下一镜第一帧：把 `状态继承` 当成下一镜固定第一帧。下一条直接提示词必须在新动作开始前重写关键结束事实，且不要在直接提示词里写 `上一镜`、`尾帧` 或 `继承`。
- 朝向传递：把身体朝向当成和道具归属同等级的硬状态。若上一镜尾帧是 `A背向B`、`A身体面向出口/柜台/门口/道路/手机/屏幕` 或 `A侧身避开B`，下一镜想进入面对面对话、接物、正反打或近景反应，必须先写可见承接：`A身体从出口/柜台方向转向B，肩线转正，双脚停稳，A身体面向B后再...`。没有转身动作就不能改变朝向。

## 道具和尾帧状态

- 每个活动道具在移动前都需要起点锚点：持有人、哪只手/哪一侧、口袋/包/桌面位置、接触点。
- 道具转移必须展示起始位置、接触、移动路径、松手/新持有人、最终静止状态，并在下一镜第一帧重新写明。不要依赖 `继承` 来传递道具归属或位置。
- 重要道具转移必须同时承担情绪信息，不能只写物流。先保证物理链条成立，再选择一个低风险情绪阻力点：递出后迟半拍松手、接收者手指先停在道具边缘、接住后向掌心收紧、说话者视线落到道具不看对方、道具停在二人之间形成短暂僵持。阻力点只选一个；如果还要可见长台词或运镜，拆成道具/手部插入镜头。
- 跨镜物品归属检查：上一镜尾帧写了某物在谁手里、包里、口袋里、桌面或台面，下一镜第一帧必须从同一事实开始。如果下一镜改变持有人、左右手、表面或容器，就必须在该镜开头拍出完整转移动作。换景别、换机位、反打、插入特写都不能让物品自动换人或换位置。
- 双道具交换比单道具转移风险更高。不要压缩成 `A把X给B、把Y拿回` 或两个同时发生的手部动词。要写成分阶段物理序列：`X起点 + Y起点 -> 角色A用哪只手接触X哪一边 -> X沿什么路径到角色B正前方/手中 -> 角色A松手 -> 角色A再接触Y -> Y沿什么路径回到角色A正前方/手中 -> 角色A松手 -> 尾帧X/Y各自停在新位置，双手离开`。如果道具不能被拿回，要写 `松手后不再拿回`。
- 尾帧状态必须是物理事实，不能只有情绪。

弱写法：`角色B兴奋`

强写法：`角色B右手道具停在胸前，嘴角轻上扬，视线落到道具上，身体仍靠近角色A`

## 跨场景交接和连续性

相邻剪辑镜头如果改变时间、地点、年龄、服装或现实层，不要尝试跨边界继承物理空间。要分别锁定两个状态：

1. **出场状态：** 触发/回到现实的片段尾部保留 0.5-0.8 秒具体姿势、视线和道具状态。这是可剪辑的出场把手。
2. **入场状态：** 插入片段开头使用自己的固定场景锚点、人物位置锁定，并在对白或决定性动作前稳定 0.5-1.0 秒。这是可剪辑的入场把手。
3. **剪辑桥接：** 白闪、叠化、模糊、变速和声画错位衔接属于后期操作，记录在校验/声音字段；它们不是让图像模型生成的物理动作。

如果闪回由某个物件触发，出场稳定前必须先让视线落到这个具体物件上。闪回返回时，先建立现实中的道具和姿势，再开始 OS/对白。这样保留因果连续，同时避免不可能的跨地点变形。

## 普通切镜交接

每对相邻镜头都可以使用 `【剪辑衔接】` 记录交接，即使发生在同一地点：

- **同一时刻换视角：** 出场片段在可读姿势、道具接触或动作阶段上停 0.3-0.6 秒。入场片段先从相同事实开始，再加入新动作。共享环境音保持连续。
- **动作延续：** 记录方向、身体动作阶段、道具接触、摄影机速度和出入画侧。不要让动作从准备姿势重新开始。
- **朝向延续：** 记录身体是否背向、侧身、面向固定物或面向人物。剪到下一镜时，第一帧必须从同一朝向开始；如果需要变成面对面，先拍转身、回身或侧身转正，再开始对白/接物/反应。
- **物品延续：** 记录物品在谁哪只手、哪个容器或哪个表面。剪到下一镜时，第一帧必须从同一归属开始；如果需要换持有人或位置，先拍接触、移动、松手和新终态。
- **反应或物件切入：** 出场动作先落下，入场反应在触发之后开始。重复能让因果关系可读的精确道具状态和固定物。
- **地点/时间改变：** 使用独立交接规则。不要让人物、房间或摄影机位置在一个生成片段里变形。

如果下一段会使用参考图生成，要在交接记录里标明参考图职责：出场最后可用帧、入场第一构图、角色身份或动作参考。这样自动合成和一次性图生视频都可追踪。

## 机位规则

- 不要把抽象影视课机位术语当成最终提示词。要写可见结果：画面左右、前景/背景、前后关系、身体朝向、视线、距离/隔物、机位侧场景锚点和可见背景锚点。
- 按**画面占比和动作可读性**决定景别，不按习惯。安全规划：广景/广中景建立地点和动线；中景承载 2-3 个身体和大动作；中近景承载一个说话者加一个听者肩线/反应；近景或插入镜头承载眼、嘴、手、道具微动作。如果表演细节在画面里低于约 15-20%，必须推近/转焦，或把动作放大。
- 避免两个极端：不要把微动作塞在过远关系镜头里，也不要把一个连续情绪节拍切成过多孤立插入。关系必须可读时，用复合镜头：`0.0-0.6秒关系中景锁位；0.6-X秒沿视线/手臂/桌面轻推0.2-0.4米或转焦一次；X-尾秒落到手部/眼神/道具近景并保留原人物位置`。
- 景别必须匹配可见人物数量和身体层级。中近景可以安全承载一张主脸加一个前景肩线或虚化听者，但不能承载“一个站立 + 两个坐着”的完整三人关系。遇到 `一个站立角色 + 两个坐着角色 + 桌面/道具`，用 `横向中景`、`三人桌边中景`，或拆成关系中景 + 近景/肩后反应镜头。
- 微动作需要足够像素占比。三人桌边中景可写 `整只手离开筷子旁`、`肩背后缩`、`手掌退到桌沿内侧` 这类可读动作；不要依赖 `指尖从餐盘旁收回到膝上`，因为桌子可能遮住结束位置。如果指尖动作是剧情关键，用手部/道具近景。
- 中景到近景的镜内变化适合“先锁空间、再读微动作”。写法：`前0.5-0.8秒三人/双人中景锁静物锚点和槽位；随后摄影机沿桌面/手臂方向直线推近0.2-0.4米到手部或道具近景；原压迫角色保留在边缘弱虚化，空间关系不重排`。除非拆镜，否则只用一次推近或一次转焦。
- 如果镜头包含 `一个站立角色 + 两个同侧坐着角色 + 桌面道具 + 沉默压力反应`，不要用普通中景承担指尖/拳头/餐盘节拍。使用两种安全形式之一：一是先关系镜头，再沿桌面直线推近到相关手部/餐盘；二是先斜切中景，再小幅推近或单次转焦到站立者脸和可见整只手/拳头。直接提示词必须写明站立者留在隔物对面，不插入坐着的两人之间。
- 当戏剧重点是沉默反应者而不是说话者时，镜头可以从说话者开始保证口型，但台词后必须落到反应者：写清台词时间窗、闭口，然后写 `摄影机沿桌沿/人物视线小幅移动或推近到反应者的眼神/整只手/肩背`，原说话者保留为边缘/前景/弱虚化。不要要求中景展示被桌子遮住的指尖或桌下手。
- 默认机位设计应有适度电影感，不要大部分静止。只有高风险时才用固定镜头：精准口型、道具交换/接触、人群/人数锁定、车辆/门精度，或刻意的情绪静止。
- 安全时要变化镜头语法：地理建立、关系中景、肩后对白、情绪转折的控制推/拉、道具揭示的插入/摇镜/转焦、移动时侧跟。
- 运镜不能改变剧情站位。任何推、拉、摇、跟、弧移或转焦前，都要重写固定物、物理槽位、画面区域、身体朝向、隔物和活动道具位置；运镜后写落幅画面和尾帧位置。
- 运镜前先让开头构图稳定 0.3-0.8 秒，让身份、槽位和道具先锁住。
- 近景用于台词落点、隐藏情绪泄露、道具/接触揭示或权力变化。写清裁切和焦点；其他重要人物只作为肩线/边缘/虚化保留，且必须保证他们的物理槽位仍清楚。
- 推近用于压力升高、秘密暴露、关系收紧、OS 领悟变清晰或台词落点。默认直线小幅推近：0.2-0.5 米、一个主体、固定背景锚点。
- 拉远用于被抛下、孤立、连接失败、荒诞尴尬、权力流失或情绪空落。拉远时保持同一个桌子/门/道路锚点可见，让情感距离变大。
- 跟拍用于移动；必须写路线和速度。不要超过角色、绕到角色前方、穿过角色前面，或让摄影机把行走人物左右位置换掉。
- 摇镜或转焦只用于揭示人物、视线目标或道具归属。除非拆镜，否则一条镜头只用一次摇镜或一次转焦。
- 小幅弧移只适合低风险情绪反转、华丽亮相或公共压力揭示：默认 15-30 度；道具交换、密集人群、可见长口型期间禁止弧移；必须保持同一固定背景锚点。
- 避免含糊的 `连续变景别`：如果是一个生成片段，就翻译成物理路径；如果需要硬切，就拆成多个镜头。

机位语言模板：

`[起幅景别/机位高度/镜头距离] + [固定物/物理槽位/屏幕位置/前后层级/朝向/视线/间隔物或接触物/道具] + [0.0-X秒先稳定] + [触发台词/动作] + [摄影机路径/方向/位移/角度/速度] + [焦点对象/是否转焦] + [落幅景别/人物尾帧可见事实]`

安全电影感运镜模板：

- 推近：`前0.5秒固定餐桌/门框/车窗锚点，A在画面右侧固定槽位；听见关键词后，摄影机沿直线推近0.3米到A近景，背景锚点仍在同一侧，B只保留前景肩线，尾帧A眼神停住。`
- 中景推到手部近景：`前0.8秒固定长桌和人物槽位；随后摄影机沿桌面直线推近0.25米到A正前方道具与右手近景，B留在边缘弱虚化，A整只手离开道具并退到桌沿内侧。`
- 拉远：`A说完后闭口，摄影机沿原方向后退0.4米，露出A与B之间的桌面/门框距离，二人座位不动，尾帧保留空位或隔物。`
- 侧跟：`摄影机胸高沿人物行走同侧平行跟拍0.8米，不超过人物；人物从画面右向左小步移动，脚掌贴地，背景店招/门框从右向左滑过。`
- 摇镜：`摄影机从A脸小幅左摇20度到A视线目标B，A保持画面右前肩线，B在画面左侧入清晰焦点，二人中间隔桌/门/车门不变。`
- 转焦：`前1秒焦点在A眼睛，A看向手中道具；1.2秒焦点用0.3秒从A眼睛转到道具边缘，之后保持在道具，不再乱焦。`
- 肩后对白：`摄影机在A肩后，A肩线弱虚化占画面1/5，B清晰说话；A和B隔桌/门/半身距离，B说完后A闭口微反应。`
- 低风险弧移：`固定桌沿/车门为锚点，摄影机围绕A小幅弧移20度，A始终在同一物理槽位，B只从背景边缘变为侧面弱虚化，不交换左右。`
- 斜切桌边关系镜头：`摄影机在餐桌对面偏A这一端约25-35度斜向拍过桌面，C三分之二侧脸清晰；A和B作为同侧双人组，A是组内近端，B是组内远端，二人仍同侧邻座、不隔桌、不面对面、不换位；镜头不沿长桌纵深方向拍成左右分裂。`
- 关系到反应的复合镜头：`前0.6秒中景锁住A、B、隔物和背景锚点；B说完或关键动作落下后，摄影机沿A视线直线推近0.3米到A近景，B只留边缘弱虚化；尾帧A眼神/肩线/整只手反应清楚，二人位置不重排。`
- 关系到道具的复合镜头：`前0.6秒中景锁住人物和道具起点；随后摄影机沿桌面或手臂方向推近0.25米到道具/手部近景，焦点只转一次；尾帧道具最终位置和相关人物边缘位置同时可读。`

不安全运镜默认禁区：

- 人物交换道具、抓手腕、进入车辆、签字、用手进食或长时间可见口型时，不要使用环绕/弧移。
- 不要把以下任务中的两项以上塞进同一镜头：运镜、道具转移、说话者切换、转焦、人物穿越。遇到就拆镜。
- 不要让运镜替代身体动作。如果人物进入、离开、坐下、站起、递交或转身，必须把身体路径和摄影机路径分开写。
- 若同一镜头仍包含四个及以上连续身体/道具动作，必须拆成准备/定位、接触/转换、终态/余波两到三镜；不要靠增加镜头描述长度来掩盖动作链过载。

## 双人肩后构图

在 `【画面描述｜直接复制】` 里不要写 `剪辑`、`切到`、`反打到` 或 `下一镜执行`。

每个双人视角都要写成可见的前景肩线构图：

- `摄影机在A肩后，A前景肩线弱虚化占画面1/5，镜头对准B，B清晰；A与B隔桌约1米，B朝A说/听/反应。`
- 成对反打：`摄影机在B肩后，B前景肩线弱虚化占画面1/5，镜头对准A，A清晰；A与B隔同一桌约1米。`

这里的前景放大只适用于肩线、后脑边缘或局部侧脸，不把局部投影解释为完整人物体型变化；目标人物保持角色锁定的头身比例。

成对正反打必须保持：

- 相同画面地理关系；
- 相同前后层级关系；
- 相同隔物/接触物；
- 相同视线方向逻辑；
- 共享背景锚点；
- 肩线归属和画面占比；
- 听者反应时间。

## 机位触发表

- 建立/广景：新地点、新群体关系、调度改变或物件地理关系。
- 中景/双人镜头：关系拉扯、撒谎/遮掩、身体距离或共同反应。
- 近景：台词落点、隐藏情绪泄露、细小脸部/手指动作、道具/接触揭示。
- 插入/切空：手机、戒指、合同、伤口、门把手、衣物、钱、文字、归属/状态变化。
- 推近：压力升高、秘密暴露、关系收紧、OS 领悟变清晰。
- 拉远：孤立、连接失败、喜剧尴尬、权力流失、情绪空落。
- 侧跟/跟拍：行走、逃离、追逐、陪同穿过空间。
- 摇镜：揭示视线目标、入口、高低差、招牌、门或手持道具。
- 单次转焦：在脸、道具、听者或背景线索之间转移注意；每镜只转焦一次。
- 前景肩线成对镜头：对白交换、接收信息、听者反应、权力变化或情绪回答。
- 蒙太奇：压缩时间、重复尝试、记忆碎片、系统性信息、喜剧快速对比；当作独立短镜头处理。
- 环绕/弧移：关系反转、眩晕、华丽亮相、公共压力、超现实错位；只用于低风险镜头，默认 15-45 度。
- 低幅手持感：恐慌、危险、醉酒、追逐或角色主观视角；只能低幅。
- 静止保持：谎言被撑住、震惊定住、情绪克制、精准口型、高风险连续性。

## 微动作禁止远距离固定镜头

如果提示词要求观众读到指尖、指节、筷尖、眼里光点、喉结、嘴角小变化、卡片边缘、餐盘边缘、桌下/桌边手部移动等细节，不要写中景/广景固定镜头。改用以下方式之一：

- 一开始就足够近的景别；
- 关系到反应的复合镜头；
- 关系到道具的复合镜头；
- 把表演细节放大成整只手、肩膀、躯干或清晰道具接触动作。

只有镜头已经是近景/插入镜头，或“静止”本身就是戏剧点且直接提示词明确把静止写成表演时，才允许固定镜头。

# 情绪反转表演与镜头语法

当人物的态度、认知、权力、亲疏、目标或危险判断发生改变时，先导演表演反转，再设计摄影。大胆景别只能放大已经成立的行动，不能替代行动。

## 冻结反转链

每处反转在内部完整回答：

```text
旧预期与旧表面策略
-> 刺激在哪个词、声音、动作、人物或证据上命中
-> 第一行动冲动
-> 人物因性格、关系或风险怎样压住冲动
-> 冲动从身体哪里泄漏
-> 人物采取什么替代动作或新策略行动
-> 对方怎样被迫反应
-> 距离、占位、道具、接触或谈话主动权形成什么新状态
```

缺少新策略行动或新关系状态时，反转尚未完成。不要把“不高兴变微笑”“冷漠变眼红”直接当成完整反转。

## 生成三类动作候选

为每个重要节拍至少生成三类候选，再选择符合人物性格和事实边界的组合：

- 面部/视线：视线断开或重新锁定、笑容失效、口型中断、眼神绕开证据。只承担先兆、泄漏或余波。
- 手部/道具：松开、压住、藏起、递回、夺回、放下、挡住、改变持物方式或用道具重建体面。
- 身体/空间：重心改变、侧身留退路、绕开边界、逼近、退开、起身、坐下、占住出口、让开路径或主动缩短距离。

最终至少保留一个非面部动作，使人物与空间、道具或他人的关系发生变化。“看、停、微微、缓缓、僵住、眯眼、皱眉、嘴角变化、呼吸变化”不能单独承担关键反转。

动作必须由原文已有刺激、人物目标、空间、道具或关系推出。不要为丰富动作新增交易、冲突、伤害、逃跑、秘密或结果。

## 保留混合情绪残留

新情绪不能抹掉旧情绪。至少保留一处矛盾残留，并把它放到不同表演通道：

- 受辱转逐利：声音变软，但手仍遮住窘迫道具，身体靠近利益来源却避开对方审视。
- 防备转依赖：身体迅速靠近，但抓握仍带攻击余势，呼吸晚于动作才松下来。
- 从容转失控：话术维持礼貌，脚步或手部却先退让、挡住或重新控制出口。
- 温暖转警觉：接触关系仍持续，视线、空闲手和身体重心已转向验证、脱离或保护。

不要把所有情绪变化都集中在脸部。让声音、手部、身体方向和距离互相矛盾，人物才会有层次。

## 拆分反转镜头组

反转同时包含刺激、反应和策略变化时，优先使用 2-4 镜：

1. 冲击镜：交付刺激命中和身体断裂。摄影机可以承担高复杂度，人物只完成一个清楚反应。
2. 策略镜：交付替代动作或新策略。人物行动承担复杂度，摄影机只做清楚跟随、让开遮挡或稳定落幅。
3. 结果镜：交付对方反应与新关系状态。用双人关系、空间占位、道具归属或接触结果冻结变化。
4. 余波镜：仅在旧情绪残留、类型转调或下一场钩子需要独立读取时增加。

不得让一个大特写同时承载“看见证据、理解含义、连续变换多种情绪、执行新动作、对方反应和空间结果”。局部镜丢失的信息由相邻镜头接力，不靠同镜多次抽焦和多阶段拉推补齐。

## 建立可见反差

反转前后至少改变两个真实可见维度：

- 观看距离：关系景跳到局部冲击，或局部冲击拉回关系结果。
- 运动速度：等待转突然行动，或高速动作转瞬间静止。
- 机位关系：平衡对话转遮挡、斜俯、压迫肩后或孤立构图。
- 焦点顺序：人物转道具、声音转眼睛、接触转危险证据。
- 空间占位：隔着边界转主动跨近，靠近转留退路，占据中心转被挤到出口。
- 道具/接触：持有转松开、遮掩转暴露、拒绝接触转抓住或拥抱。

只把中景换成大特写，人物和关系没有发生变化，不算完成反转。

## 按反转类型选择机制

- 态度或价值反转：声音/报价/证据先行 -> 身体或手部泄漏 -> 新策略行动 -> 双人关系结果。喜剧节奏可用“铺垫停留 -> 突然命中 -> 动作改口 -> 结果停顿”。
- 认知或身份反转：遮挡或背影维持旧判断 -> 高价值局部确认 -> 人物沿单一目标快速行动 -> 关系镜确认新身份和距离。
- 权力反转：先让旧主导者控制中心、出口或道具 -> 刺激命中后改变占位或道具控制 -> 用斜向或全景关系冻结新的主动权。
- 温情转危险：稳定接触或亲近关系 -> 异常证据局部 -> 观察者空闲手、视线和重心进入验证/脱离准备 -> 关系镜保留亲近外形与危险内核的矛盾。

相邻反转不要机械复用“短促逼近 + 立即停止”。除非有明确视觉母题，否则应在声音先行、遮挡揭示、空间占位、局部证据、快速行动、斜俯关系或焦点切断之间更换主机制。

## 内部完成度闸门

冻结镜头组前逐项确认：

- 旧策略是否清楚，而不是直接从新情绪起镜？
- 刺激是否落在明确的词、声音、动作或证据上？
- 是否存在一个非面部策略行动？
- 新情绪是否保留旧情绪残留？
- 摄影机复杂度是否在相邻镜头交还给人物行动？
- 反转前后是否至少改变两个可见维度？
- 新关系状态是否能从尾帧直接读出？

任一关键项缺失时，在本次预演中补动作候选、拆镜或重分配镜头职责，不靠增加“强烈、震惊、凌厉、悲愤”等情绪形容词补救。

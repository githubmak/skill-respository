# 题材叙事与类型爆点引擎

本文件是题材识别、类型承诺、题材爆点和跨类型去重的唯一真源。它决定“观众为什么继续看”和“本题材用什么变化兑现”，不替代剧情事实、通用五段节奏、表演、摄影或特效规则。跨类型通用的观众预期、公平线索、选择代价、视觉母题和节奏波形由 `ai-manga-dramatic-direction-engine.md` 一次冻结；本文件只提供类型化的冲突载体、升级单位、记忆点和兑现方式，不重新计算这些通用结论。任何类型增强都不得新增人物、能力、证据、资源、关系、胜负、伤势、事件或结果。

## 拆镜前冻结类型母版

从题材标签、世界规则、人物目标、稀缺资源、主要阻力和源文结果中冻结：

- **主类型序列**：整集可以并存多种类型优势；每个节拍只明确当前主导观看承诺，控制冲突载体、升级单位和兑现节奏，并允许在转场、反转或兑现后交接给另一类型。
- **辅助类型**：按源文证据增强视觉、情绪、关系或局部节拍，不设固定数量；每项都必须写清作用节拍，不能只贴标签。
- **类型承诺**：观众在本片段合理期待看见的过程与结果，不是“紧张、刺激、感人”等空泛形容词。
- **观众核心期待**：本段最需要满足的一个问题，例如“如何反制”“能否收获”“关系是否确认”“谁取得话语权”。
- **冲突载体**：承载争夺的具体对象、规则、位置、关系或信息。
- **升级单位**：每次加压究竟增加什么，如威胁距离、资源缺口、能力代价、身份暴露或关系风险。
- **核心奇观**：最值得被看见的实体变化、空间变化、行动链、群体反应或情绪行为；可以安静，不等于必须有 VFX。
- **结果兑现**：镜头必须读清的物理、信息、权力、资源或关系新状态。

类型母版必须由原文证据推出。源文不足以建立明确类型时，以“人物目标 + 现实阻力 + 可见结果”的通用剧情引擎执行，并明确主类型未定，不伪造类型奇观。

## 题材爆点生成步骤

1. 从整集五段曲线选择类型承诺最适合建立、升级和兑现的位置，不按场平均分配爆点。
2. 为每场指定一个类型职责：建立规则、加压、反制、揭示、奇观、兑现或余波；普通承接场也必须说明服务哪项，不强造峰值。
3. 用“冲突载体受到变化 -> 升级单位增加 -> 人物改变策略 -> 核心奇观可见 -> 结果兑现稳定”生成候选。
4. 关键节拍可比较非同构候选；数量由复杂度决定。优先选择改变控制权、资源、空间、身体、信息或关系并能在手机端读清的方案。
5. 将题材职责编译进现有摄影、表演时间线、声音、光影/色彩/材质与落幅，不给直投版增加分析标签。
6. 在同轮生成中让事实边界、空间连续、动作物理、类型兑现和 AI 负载同时成立并冻结结果。

“吸引眼球”应来自新读取和兑现。关键爆点通常至少包含以下一项：出现不可忽略的新信息；发生改变现实状态的行动；观看尺度、声音、光影或空间关系产生有动机的显著变化。只换角度、甩镜、加速、发光、震屏或堆术语而没有剧情收益时不算爆点。

## AI 短剧观众收益与留存链

每集/目标片段先冻结一个主观看问题和一条观众收益链：

`2秒内异常/欲望/危险/错位 -> 观众立即想知道的问题 -> 人物目标与可见代价 -> 阻力升级/旧策略失效 -> 反制或揭示 -> 证据与见证者确认 -> 现实结果兑现 -> 更大的未完成问题`

比例按原文长度自适应，不为满足秒点新增剧情。开场第一有效画面必须同时交付异常、欲望、危险、关系动作、能力前兆、结果残局或信息缺口之一；不得先用无关景色、走路和生活流程拖延。尾钩必须停在未完成动作、刚改变的控制权、即将到达的威胁、被看见的证据、无法收回的承诺或新规则代价，不以中性表情结束。

为每个主要爽点建立观众收益账本：

`爽点类型 | 前置承诺 | 被压制/误判/欠缺的状态 | 人物主动策略 | 反制触发 | 决定性证据/接触 | 谁亲眼见证或承担后果 | 现实新状态 | 余味/新债`

爽点可来自身份翻转、能力/专业证明、反击制衡、规则破解、资源获得、劳动收成、地位回正、真相揭示、关系确认/拒绝、保护兑现、逃生逆转、喜剧错位、规模奇观或情绪决堤。必须选择源文已经承诺的类型，不能把所有题材改成打脸、复仇或战力碾压。

爽点的“爽”来自被压制状态与兑现状态之间的可见差值。通常改变 `控制权、信息、关系、资源、空间、身体/能力、公共认知、未来选择` 中相关状态；主要爽点是否改变一轴或多轴由剧情决定。兑现镜读到行动结果及其影响对象，必要时用受影响者/群体反应形成社会证明，但不强制添加群体反应。

## 场景记忆点与反同构吸引力

每场可在第一次生成时冻结一个记忆点；无峰值承接场保留其实际观看理由。记忆点从以下机制中选择一个或多个主导：

- 角色专属动作、语气、微表演或关系行为；
- 权力/距离/出口/人群形成的空间构图；
- 已有道具、证据、工序或材质的决定性变化；
- 由真实时间、天气、建筑和介质成立的光影景观；
- 世界规则支持的华丽特效、规模揭示或环境受力；
- 声音先行、抽空、动作声切镜、音乐避让后的落点；
- 匹配切、遮挡切、速度变化、主客观揭示或蒙太奇压缩。

记忆点可写 `首读点、前后反差、主机制、具体触发、稳定终幅、手机端识别方式` 中实际需要的项目。连续场景避免无意义重复同一结构；相邻记忆点若复用，应确认观看对象、空间尺度、速度、声音、色温/亮度关系、动作结果或关系结果中的变化。

刺激波形使用 `吸引 -> 理解 -> 加压 -> 假释放/短确认 -> 翻转 -> 兑现 -> 余味`。高密度不等于持续一级刺激；平静段必须蓄积等待、关系压力、声音距离或动作未完成感，峰值才获得最大的景别差、动势差、明暗差、声音差或特效规模差。

## 反差、反差萌与角色传播记忆

反差从已建立的人设、身份、能力、关系、外观、任务和生活习惯中提取两种同时真实的侧面，不通过降智、人格突变、无因卖萌或新增爱好制造。可用类型包括：

- 强大能力/高身份与具体生活笨拙、细小恐惧、照顾行为或认真执行琐事；
- 冷硬外表/严肃语气与保护、克制温柔、被戳中软肋或不熟练亲密；
- 可爱/弱小外形与果断策略、专业能力、危险判断或巨大力量；
- 威严仪式/古代礼制与真实人情、错误关注点、日常需求或喜剧停顿；
- 都市精英/反派压迫与失控一瞬、尴尬维持体面或道具不配合；
- 怪物/异世界奇观与幼稚逻辑、忠诚、护食、好奇或尺度错位，前提是源文已建立对应行为。

反差萌按 `稳定预期 -> 微小但具体的违和证据 -> 人物仍认真维持原目标 -> 受影响者迟半拍确认 -> 关系/任务产生新结果 -> 角色迅速恢复自身逻辑并保留余味` 生成。喜剧主读点优先落在任务中断、错误关注、动作尺寸、道具关系、语气与行为不匹配或旁观者压住反应；人物自己不提前做搞笑脸。

反差可成为跨集角色母题：第一次建立两面性，第二次在更高压力下升级，第三次用于反转、救场、关系确认或爽点回收。重复时必须改变对象、代价或结果，不能复制同一个表情包动作。

每个主要人物按原文证据冻结 1—3 个传播记忆资产：轮廓/服装或道具识别点、专属动作策略、语气/重音模式、与某类关系对象的独特反应、能力/职业的标志性操作或反差萌触发器。记忆资产只在有任务时出现，并随剧情升级，帮助短剧形成可识别角色而不是通用美型人物。

允许生成可传播的台词落点，但只能对原句做证据化压缩、重音和停顿设计；不能为了“金句”新增观点、承诺或事实。画面、声音和结果必须共同证明台词，而不是让人物对镜喊口号。

## 爆款记忆锚与讨论点

每集/目标片段至少建立一个可单独记住的视听单元，来源可以是身份揭示、反击结果、关系选择、能力规则、反差萌、华丽奇观、情绪决堤、工序收成、喜剧错位或极具构图辨识度的尾钩。该单元冻结：`一帧可识别画面、一个动作/台词/声音落点、一个不可逆结果`，三者共同服务同一事实。

从原文已有的信息差、价值冲突、关系选择、能力代价或结果不确定性中提炼讨论点，让观众自然产生“他是否早已知道、她为何这样选、这个代价值不值、下一步如何反制”等问题；不得靠隐瞒本应交代的信息、伪造误导或中断决定性结果制造廉价悬念。

一个爽点兑现后立即建立新期待：结果暴露的新代价、旁观者改变、未解决的更大目标、能力使用后的后果、关系更进一步的风险或下一步行动起势。新期待必须由刚发生的结果推出，形成 `兑现 -> 再钩住`，不是随机加入新危机。

## 吸睛手法选择器

主要爆点可从以下家族选择一个或多个可行方向，再选择最能服务剧情的组合；同一时间窗通常有一个主读点，不同时间窗可以连续交接多个机制：

1. **表演炫技**：克制泄漏、语气反击、动作中断、身体/道具策略和受话者错峰回声。
2. **调度炫技**：一镜内的占位翻转、出口控制、前景遮挡打开、纵深交接、群体让路或关系宽镜回收。
3. **摄影炫技**：景别跃迁、动作跟拍急停、声音/焦点先行、遮挡揭示、空间拉开、固定目击或主客观切换。
4. **剪辑炫技**：冲击切、匹配切、插切三态、升格命中、冻结余响、平行/工序/证据蒙太奇。
5. **光影构图炫技**：实体光束、剪影边缘、负空间、框中框、反射层、明暗区跨越、天气介质和材质高光路径。
6. **世界奇观炫技**：能力、能量、破坏、群体规模、生态/建筑尺度或规则显形及其人物/环境反馈。

每个时间窗明确一个主炫技语法；一场可以随“蓄势、反制、命中、兑现、尾钩”多次交接不同语法。次级手法与当前主语法共享触发和终态。炫技不是保守降级项：只要事实、物理、空间和首读点成立，优先做足规模、层次、速度、材质和受光；只有明确身份漂移、穿物、口型或几何风险才拆成相邻镜，不把华丽场面自动降成固定中景。

## 常见爆款短剧结构适配

以下结构只从源文已建立的事实、关系和结果中调用，可跨类型组合：

| 结构 | 吸引力发动机 | 分镜与表演重点 | 爽点/结果证明 |
| --- | --- | --- | --- |
| 逆袭/反击/打脸 | 先建立具体压制、错误判断和公开见证，再让人物用能力、证据或策略主动反制 | 压制阶段保留出口/座次/道具/群体结构；反制从低幅控制切到行动，证据与关系宽镜共同落地 | 对方失去的控制权、群体态度、资源/位置或规则结果清楚改变，不只拍震惊脸 |
| 隐藏身份/身份揭示 | 观众与人物之间的信息差、身份标志、能力表现和公开确认 | 先控制尺度/标志/称谓，再由动作、道具、来者态度或空间让路完成揭示 | 谁认出、谁改口、谁让路、谁失去判断优势及身份带来的新代价 |
| 重生/穿越/系统/异能 | 信息优势、陌生规则、任务倒计时、能力代价与旧结果回避 | 用当前选择和现实反馈证明优势，不滥用旁白；规则首次显形必须可视/可听 | 人物成功改变一项策略/资源/关系，同时显露能力边界或新风险 |
| 甜宠/先婚后爱/反差萌 | 表面关系与真实照顾、触碰许可、共同任务、误解和软肋 | 让行为替代告白：替对方完成动作、保留退路、挡住压力、道具细节和延迟反应 | 关系距离、信任、公开态度或未来选择发生不可逆变化 |
| 虐恋/追悔/关系破裂 | 关系债、错过风险、被忽视的证据、行动迟到和边界重建 | 不靠持续哭喊；用空位置、未完成动作、拒绝接取、转身路线、声音余势和前后行为对照 | 道歉/追悔必须有行动代价；接受、拒绝或暂不回应由人物行为和新边界证明 |
| 悬疑/探案/犯罪谜题 | 线索精度、错误解释、嫌疑转移、时间压力和证据链闭合 | 主观误导控制参照，证据插切只给不可替代信息，反应发生在确认之后 | 新解释改变下一行动；揭示后立即读到嫌疑、危险或策略的新状态 |
| 喜剧/沙雕/反差喜剧 | 角色认真目标与观众看见的错位、规则误用、尺寸/身份反差、延迟确认 | 人物不自知卖萌；用稳定客观全景、错误关注点、声音停顿、旁观者压笑和道具结果 | 笑点后任务/关系继续推进，包袱有回收而非纯插科打诨 |
| 家庭/伦理/年代 | 责任、偏爱、资源分配、代际规则、公开/私下态度与旧物记忆 | 用饭桌、门口、座次、家务、旧物、房间距离和声音层表现关系，不只争吵反打 | 谁承担、谁拒绝、谁公开站队、资源/边界/关系发生什么实际变化 |
| 职场/商战/权谋 | 信息、合同、权限、资源、程序、时间、舆论和团队立场 | 让决策通过文件控制、屏幕信息、会议座次、行动指令和执行结果发生 | 权限、交易、职位、证据、团队或市场结果改变，专业能力有可见操作 |
| 校园/成长/体育 | 同伴评价、规则、比赛/考核、训练、团队位置和自我突破 | 训练/比赛用动作全貌、关键技术、体力/伤势与群体节奏；青春关系用任务和空间靠近 | 成绩、技术、队伍信任、公开选择或自我边界获得实际证明 |
| 科幻/末日/生存 | 资源、氧气/能源、时间、地图、设备规则、群体分工和环境危险 | 大尺度先建立世界代价，局部读设备/身体状态；环境持续影响路线、声音和光 | 资源/位置/设备/队伍/生存概率改变，并留下不可忽略的消耗 |
| 恐怖/怪谈 | 已知规则、不可见威胁、声音距离、空间重复、禁忌和人物误判 | 用空镜、受限主观、遮挡、声音、光区和环境先兆建立威胁；不靠随机跳吓 | 规则被验证/破坏、退路改变、身份或危险来源更明确，恐惧推动策略 |
| 治愈/日常/美食 | 缺失、疲惫、手艺、共同劳动、细节照顾、味觉/触觉和生活秩序恢复 | 材质、蒸汽、火候、声音、手部工序、空间温度和低幅表演形成满足感 | 完成的食物/物件/空间、身体放松、关系靠近或生活条件改善可见 |

结构组合时按时间窗决定当前发动机，例如“重生信息优势 -> 商战专业反制 -> 家庭公开站队 -> 反差萌余味”。不同结构可以连续放大，不设固定类型数量；每次交接必须由刚发生的结果或新目标触发。

## 混合类型与未列类型

混合题材按节拍切换主导类型而不是全片只能一个主类型。例如“宫斗权力加压 -> 言情关系选择 -> 宫斗公开兑现”可以形成类型交接；辅助类型可承担多项有证据职责。不同类型高潮可以在相邻时间窗连续升级，但不能在同一瞬间争夺首读点或互相取消结果。

对于悬疑、探案、科幻、末日、生存、商战、校园、家庭、喜剧、体育、恐怖、治愈或任何未列类型，不套用最相近题材的表面手法。按以下问题自动推导同一组类型结论：

1. 观众被承诺看见哪种过程与结果？
2. 人物争夺或保护的稀缺对象是什么？
3. 世界、制度、关系或身体施加的核心规则是什么？
4. 每次升级增加哪种可测的风险、代价或不可逆性？
5. 哪个可见/可听变化最能代表本类型而不依赖解释？
6. 结果镜需要冻结什么新状态，才能证明承诺已经兑现？

由答案生成“主类型、辅助类型、类型承诺、观众核心期待、冲突载体、升级单位、核心奇观、结果兑现”，再进入通用流程。不得让所有题材复用“证据特写 -> 人物逼近 -> 群体震惊 -> 甩镜”的同一爆点结构。

## 跨场去重与首次生成必成条件

跨场冲突载体、升级单位、观看距离与结果形态在类型母版和场景职责首次生成时直接错开，不在成稿后统计同构再替换：

- 连续两场若复用相同冲突载体、升级单位、观看距离变化和结果形态，应确认复用仍有新的信息或关系职责；差异数量不设固定要求。
- 同一母题再次出现时可在尺度、代价、信息、关系或结果上变化；不需要母题时不强加回收。
- 打斗和斗法先保证方向、规则、接触与结果；种田先保证工序和产出；言情先保证关系行为；宫斗先保证信息差和礼制权力。不得用通用特效覆盖类型逻辑。
- 高峰之后保留足以读清结果的落幅、反应或余波；紧凑不等于取消兑现。
- 核心奇观应有清楚的主读点、触发、可执行路径、稳定结果和低歧义主体。复杂动作、VFX、多人反应、运镜与复杂口型按负载和时间安排错峰或交接。

完整项目可输出 `## 类型承诺与题材爆点母版`，写明实际需要的类型结论。每场爆点计划按需写类型职责和本场如何建立、升级或兑现；无峰值场景不强造计划。直投版不出现内部审核标签，只把已选结果编译进现有字段。

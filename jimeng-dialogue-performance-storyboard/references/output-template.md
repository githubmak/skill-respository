# 输出模板

本文件只规定交付结构。`【Seedance 直投提示】` 是每镜唯一创意事实源；工程脚本只核验结构、编号、时长、源文声音、文件和审核声明。

## 文件结构

```markdown
# [标题]｜即梦 Seedance 分镜

## 项目信息
- Seedance 目标：2.0|2.5
- 画幅与风格：[用户指定或模型选定]
- 源文 SHA-256：[route_task 的 source_intake.source_sha256]
- 交付状态：DRAFT|PROVISIONAL|FINAL

## 全局连续性
[只写跨场复用的人物造型、固定道具和不能漂移的源文事实。]

## 事实连续性台账（非投喂）

### S1
- 场景固定事实：[人物、空间边界、道具归属、站坐支撑和不能被创意改写的状态。]
- 镜间状态：[只记录发生变化的 S1-01 尾态 -> S1-02 起态；无变化写“连续继承”。]

## 场景导演方案

### S1｜[场景名]
- 戏剧与表演方向：[关系变化、信息顺序和表演尺度]
- 摄影机与剪辑方向：[观众位置、节奏、运动/静止逻辑和结束距离]
- 视觉连续性基线 VC-S1：[真实主光/辅光的实体、方向、强弱层级和作用区域；主色/辅助色/点缀色与材质落点；白平衡、饱和度、对比度、黑位、高光、背景亮度和肤色基准；必须保持不变的光源与曝光关系；允许变化的物理触发。]

## 分镜投喂卡

#### S1-01｜[镜头名]

【时长】
[>0 且 <=15]s

【出现人物】
[本镜可见人物；无人则写“无”]

【Seedance 直投提示】
主体与起态：[场景、第一观看主体、具名人物槽位与可见锚点、起始动作状态和道具归属。所有多人镜至少写人物槽位、躯干朝向、视线目标与画面左右；转身、换位、正反打或遮挡风险镜再分别写双脚、头部朝向、当前机位可见面和首尾状态；头身同向时合并。]
动作时间线：[按可见先后写触发、具名人物动作、口型、听者反应和接触变化；涉及转身或换位时说明哪个身体部分改变、哪些部分保持不动。]
台词：
[逐行原样放入本镜使用的全部人物台词、OS、OV、系统音和音效原文；无则写“无”。]
摄影机：[仅在机位、景别、运动或落幅需要控制时写；具名说明起幅、路径和停稳。]
焦点：[仅在景深、初始焦点或转焦具有观看价值时写；说明触发与唯一终点。]
视觉控制：[通常写入。不要引用 VC-Sn、同上镜、继承前镜或沿用上一镜。用一个完整句直接写本镜可见的真实光源与方向、受光/阴影区域、综合色彩及材质落点、曝光/对比/饱和度/背景/肤色稳定项；若变化，写明物理触发、开始时机、影响范围、保持不变项和变化后的稳定状态。]
声音设计：[仅在原文声音之外确有环境、拟音、混音或口型关系控制时写。]
稳定结尾：[最后保持的构图、人物口型与动作、位置、躯干/头部朝向、视线、可见面、手部和道具状态、焦点、摄影机以及需要稳定的光态；只写一个可验证终态。]

【审核后参考素材】
[有助于消除空间歧义时才列已审核并提升的关键帧、视频或人偶 clean 空间/动作参考；未列或不上传，不影响直投提示执行。]
```

## 核心与按需分句

- 核心必填只有 `主体与起态`、`动作时间线`、`台词`、`稳定结尾`。它们分别回答谁/在哪里、何时做什么、原文说什么、最后稳定成什么。
- `摄影机`、`焦点`、`视觉控制`、`声音设计` 按这个顺序逐行书写；没有实际控制价值时省略整行，不写空占位。
- `VC-Sn` 只存在于内部连续性台账和场景导演笔记，不得进入任何 `【Seedance 直投提示】` 代码块。Seedance 单独接收本镜时看不到前镜；视觉控制句必须自行包含可见基线。
- 参考素材是可选证据，不是直投前置条件。直投提示必须脱离参考图独立成立；只有本镜列出已审核参考素材且用户选择上传时，才写“若上传该图……”。未上传时，主体与起态、动作时间线中的人物位置、机位、姿态、支撑、持物和接触关系仍完整有效。二维/三维低模只参考空间、机位、姿态、支撑、持物和接触，不参考人物外貌、服装、材质、色彩、光影或成片风格；不得写无条件的“参考图中……”。
- 面向控制对所有多人镜保留最低锁定，对高风险镜再展开：`身体朝向某人` 不等于头部和视线也自动同向，`摄影机看见正面` 也不等于人物看镜头。若双脚、躯干、头部和视线一致，用一个短句合并；若不同，逐项具名说明。摄影机换侧导致的正/侧/背可见面变化属于投影变化，不得伪造人物转身。

## 视觉连续性规则

- 同场所有镜头先共享一个 `VC-Sn`。基线至少锁定：物理光源实体与方向、主辅光强弱关系、主/辅/点缀色的材质落点、白平衡、饱和度、对比度、黑位、高光、背景亮度和肤色基准。
- 无物理变化时，逐镜只调整“哪些区域进入构图”，不得改变光源方向、冷暖归属、曝光基准或材质综合色彩。换机位造成可见受光面变化，不等于场景换光。
- 只有时间推进、光源开关/移动、门窗遮挡变化、天气变化、进入新空间或明确主观视觉转换，才允许改变基线。变化句必须同时说明触发、时机、影响区域、未变化项和尾帧新稳定态。
- 跨镜审片逐对比较上一镜尾态和下一镜起态的光源数量与方向、白平衡、肤色、背景亮度、黑位、高光和主色落点。无因变化判 `REVISE`。

## 声音与交付

- `台词` 是源文声音的唯一规范副本，不再另设 `【声音原文】`。每条声音行在一套交付中按源文顺序出现一次；同一原文行不得拆字改写。
- 普通提示建议 `<=500` 字，复杂镜建议 `<=650` 字，硬上限 `700` 字。超限由模型重选拆镜或压缩表达，脚本不删除创意。
- `both` 输出两套文件；2.0 与 2.5 共享镜号、时长、台词、人物、空间、道具和稳定结尾，只改变表达密度与参考策略。
- 正式 Markdown 不得引用 `staging/`、SVG、审核图或工程线稿。允许引用已审核提升的 `approved-jimeng-2d/` PNG 与 `approved-mannequin/` 三维干净图。二维图只参考位置、面向、边界和机位关系；三维图只参考空间、机位、姿态和接触，不参考人物外貌、服装、材质、色彩或光影。示例：`S1-03_即梦_2D_空间关系.png`、`S1-08_即梦_3D_空间关系.jpg`、`S1-10_即梦_3D_空间关系_start.jpg`、`S1-10_即梦_3D_空间关系_end.jpg`。

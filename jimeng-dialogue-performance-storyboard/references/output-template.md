# 输出模板

本文件只规定可交付 Markdown 的结构。所有影响成片的内容由大模型创作，脚本只校验字段、编号、时长、声音原文和文件状态。

## 文件结构

```markdown
# [标题]｜即梦 Seedance 分镜

## 项目信息
- Seedance 目标：auto|2.0|2.5
- 画幅与风格：[用户指定或模型选定]
- 源文 SHA-256：[source_gate 回执]
- 交付状态：DRAFT|PROVISIONAL|FINAL

## 全局连续性
[只写跨镜复用的人物造型、固定空间、关键道具归属、声音基线和不能漂移的状态。]

## 场景导演方案

### S1｜[场景名]
- 戏剧与表演方向：[本场关系变化、信息顺序和表演尺度]
- 摄影机与剪辑方向：[观众位置、镜头节奏、运动/静止逻辑和结束距离]
- 光影与色卡：[主/辅/点缀色关系，主辅光来源与方向，阴影、背景、肤色和材质策略]

## 分镜投喂卡

#### S1-01｜[镜头名]

【时长】
[>0 且 <=15]s

【出现人物】
[本镜可见人物；无人则写“无”]

【Seedance 直投提示】
起始画面：[开局可见事实、构图、人物槽位/面向/可见面、道具与第一观看主体。]
表演时序：[按先后写触发、人物动作、台词口型、听者反应；每个动作具名。]
摄影机：[机位参照、是否静止，或唯一清楚的摄影机路径与落幅。]
焦点：[起始焦点、实际发生的转焦时机与终端焦点；无转焦就简洁说明持续焦点。]
色卡：[本镜可见主色、辅助色、点缀色及其具体落点；独立于场景总表也成立。]
影调：[本镜对比度、饱和度、亮暗层级、背景亮度、黑位/高光、肤色基准。]
光影：[本镜真实主光/辅助光来源与方向、受光面、阴影区域、材质响应和稳定状态。]
声音：[引用下方声音原文并说明可见口型、OS/OV/系统音或后期关系。]
结束画面：[最后稳定保持的构图、人物动作、道具状态和焦点。]

【声音原文】
[逐行原样复制本镜使用的源文声音行，包含人物标签、OS/OV/系统音标记、标点和文字；无则写“无”。]

【审核后参考素材】
[仅列已经审核并提升到正式目录的关键帧/参考视频；没有则写“无”。俯视工程线稿不放入 Seedance 参考位。]
```

## 使用规则

- `【Seedance 直投提示】` 是每镜唯一创意事实源，可整段复制投喂。不要再输出状态继承、场景合同、表演 IR、七行制作控制或同义复写。
- 九个提示分句用于保证单镜独立投喂并消除主语和路径歧义，不要求每句等长。`色卡`、`影调`、`光影` 每镜独立创作但共享场景连续性；没有动作或转焦时直接说明当前事实，不创建虚假的运动路径。
- `【声音原文】` 只承担逐字对账；声音怎样表演属于直投提示中的创意决定。全部声音行在整份交付中按源文顺序出现一次；同一声音跨镜拆分时，应保留完整原文行并由模型在提示中说明分段，不擅自改字。
- 普通直投提示建议 `<=500` 字，复杂镜建议 `<=650` 字，硬上限 `700` 字。超过硬上限必须由模型重新判断拆镜或压缩，不由脚本删除创意。
- 多场景可每场一份文件；此时每份保留全局原编号，并在最终校验时把所有文件一起传给 `validate_delivery.py`。`both` 输出 2.0 与 2.5 两套文件，两版镜号、时长和声音原文必须一致。
- 正式 Markdown 不得链接 `staging/`。工程线稿保存在独立审核链，不作为视觉风格参考；只有经审核的成片关键帧或参考视频可以写入 `【审核后参考素材】`。

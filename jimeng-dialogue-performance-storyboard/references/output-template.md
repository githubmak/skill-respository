# 输出模板

本文件只规定交付结构。正式文件名必须是 `第{集数}集_总时长{分镜总时长}秒_即梦Seedance分镜.md`；`分镜总时长`等于本集正式镜头时长之和，四舍五入到整数秒。`【Seedance 直投提示】` 是每镜视频生成的唯一创意事实源；人物和场景资产提示词是独立的资产图生成层，不替代镜头提示，也不把资产图的中性状态当作镜头表演。工程脚本只核验结构、编号、时长、源文声音、文件和审核声明。内部事实台账、因果主线、表演弧和节奏诊断写入审片报告，不进入正式 Markdown。

## 文件结构

```markdown
# [标题]｜即梦 Seedance 分镜

## 项目信息
- Seedance 目标：2.0|2.5
- 集数：第[两位数字]集
- 分镜总时长：[本集所有正式镜头时长之和]秒
- 画幅与风格：[用户指定或模型选定]
- 源文 SHA-256：[route_task 的 source_intake.source_sha256]
- 交付状态：DRAFT|PROVISIONAL|FINAL

## 全局连续性
[只写跨场复用的人物造型、固定道具和不能漂移的源文事实。]

## 全局视觉基线
[只写本集跨镜复用且可执行的视觉基线：物理光源实体与方向、主辅光关系、综合色彩与色卡材质落点、白平衡、对比度、黑位、高光、背景亮度和肤色基准。只有时间、天气、光源、遮挡、空间或明确主观视觉发生物理变化时才允许改动；逐镜仍须在“视觉控制”中独立写出当前可见结果。]

## 人物资产提示词

> 本节用于生成人物资产图，不直接投喂 Seedance。每个主要角色一条；配角只有在跨镜需要稳定识别时才单独建立。稳定外观优先，情绪和动作保持中性，避免把某一镜的表演状态固化为角色身份。

### [角色名]
- 资产用途：[角色立绘/半身肖像/全身角色资产/多视图参考等]
- 角色事实与关系：[源文已知身份、年龄观感、关系；没有明确年龄时写“成年观感/年龄待导演定”，不要编造会改变剧情的事实]
- 稳定外观：[脸型、发型、发色、肤色、体态、服装轮廓、主色、材质、固定饰物或身份道具；只写跨镜复用的识别点]
- 中文生图提示词：[可直接用于人物资产图的完整提示；中性或低强度表情、自然比例、写实皮肤、统一画幅/风格，允许模型补足非剧情关键的服装纹理和材质细节]
- 反向提示词：[不同脸、脸型漂移、年龄漂移、换装、错误肢体比例、畸形手、塑料皮肤、过度磨皮、明星/网红脸、文字水印]
- 一致性锁定：[后续镜头必须复用的脸型/发型/服装主色/固定饰物/年龄观感；不得锁定本集某一镜的哭泣、愤怒、奔跑或交接动作]

## 场景资产提示词

> 本节用于生成无人物或低叙事状态的场景资产图，作为环境与构图基准。每个主要空间一条；不要把临时剧情道具、角色动作、特效或台词塞进场景资产。

### [场景名]
- 资产用途：[环境设定图/空场 clean plate/可用于镜头参考的空间资产]
- 空间结构与固定锚点：[边界、门窗、桌椅、通道、墙体、地面分界和可供人物站位的区域；明确哪些实体不能漂移]
- 光源与视觉基线：[时间/天气、画面内真实主光与辅光、白平衡、综合色卡、材质、曝光、黑位和高光控制]
- 镜头可用方向：[关系轴可放置的位置、主要观看入口、可行的全/中/近景区域；只写空间能力，不规定每镜必须使用]
- 中文生图提示词：[可直接用于场景资产图的完整提示；以无人环境、清楚空间层次、固定锚点可读为优先]
- 反向提示词：[人物、临时互动道具、剧情特效、空间拓扑错误、门窗数量错误、比例漂移、光源无来源、文字水印]
- 布局锁定：[跨镜必须保持的边界、固定物相对关系、光源方向和材质色卡；允许镜头改变取景和遮挡，不要求所有物体屏幕位置不变]

## 场景导演方案

### S1｜[场景名]
- 戏剧与表演方向：[关系变化、信息顺序和表演尺度]
- 信息递进与视觉证据：[本场实际存在的环境状态、人物处境、关键证据、人物选择、关系结果/危险余波；不强行补齐节点，不写成镜头清单]
- 声音节拍线：[有观看收益时填写环境底噪、人物/道具状态声、决定性声音证据、余音或声音桥；无独立作用可省略]
- 摄影机与剪辑方向：[观众位置、场级快慢与信息释放、运动/静止逻辑和结束距离；不写目标总时长或平均镜长]
```

## 导演质量要求

- `动作时间线` 中，情绪镜先简短写出本镜可访问的触发前因，再写必要的身体/呼吸、手部或支撑、视线、面部与口型变化，最后落到一个可验证的稳定姿态；普通镜按观看收益删减节点，不机械逐项展开。
- 每镜必须脱离前镜独立成立，不得写“延续上一镜、完全延续S1-01、沿用上一镜光影”等跨镜引用；用一个紧凑句直接重述本镜已经存在的当前姿态、情绪余波、道具承载和可访问刺激，不重新发起上一镜已完成的动作。
- 每镜只保留一个核心动作弧或信息/空间揭示弧：动作镜写意图或触发、物理执行、接触/状态结果和情绪落点；环境/证据镜写状态显露、观众确认和稳定落点。动作写实际方向、力度、路径、接触和结果，不用“很尴尬”“充满压迫感”等抽象词代替。
- 多人镜在同一动作时间线中区分主行动者、直接接收者和关系见证者：直接接收者在刺激抵达后给出一次最有关系价值的反应，见证者维持低强度角色化状态；不默认“其他人全程不动”，也不让所有人同步转头、皱眉或后退。
- 物品发生交接时，在 `主体与起态` 或 `动作时间线` 锁定原持有者、接收意图、接触点、交接时刻和新承载状态；仅换手或转焦不构成新镜，未发生交接不得写成已交付。
- `场景导演方案` 与镜头安排应形成有功能的景别梯度：当关系或路径尚未建立时用全/中全景交代，关系清楚后由中景承载互动、近景/特写交付情绪或证据；已有空间关系清楚时可以直接从近景或证据镜进入。不因配额切换，也不把全场写成全程固定或全程怼脸。至少检查是否有一个转折值得摄影机或焦点推动，若全程静止，静止必须承担压住、等待、审视或未完成结果。
- 双人连续对话先建立关系轴和屏幕左右；摄影机默认同轴侧移动。若越轴，必须有真实换位、过轴路径、中性过渡或新的剧情节拍，并明确新的屏幕侧；视线必须写向具体目标并在镜尾闭环。
- 禁止增加“只执行明确动作、不新增任何表情/肢体/运镜”的项目级负面前缀。默认用相对先后写动作，不为每个自然节点标秒；焦距、百分比、次数和局部负面约束只在解决真实歧义时出现。
- `台词` 中的说话者、括注、正文、标点、重复字和语病全部按源文逐字保留，不进行润色或纠错，也不自行增加“平静、急促、低声”等新括注。

## 精简直投示例

以下示例展示普通双人对白的默认密度。固定机位要说明机位、关键锚点和它保住的关系，不展开无风险的身体、口型、焦点与环境清单：

```text
主体与起态：夜间玄关，门槛是内外分界；林夏站在门外，周谨站在门内，两人隔着半步距离相望。
动作时间线：林夏握住行李箱拉杆准备离开，周谨没有追出门，只在林夏转身前叫住她；林夏停下却没有回头，周谨的强装镇定在句尾落成沉默。
台词：
周谨：你还会回来吗？
摄影机：固定中景，机位位于玄关鞋柜外侧，门框始终横在两人之间，保住“门内挽留、门外离开”的关系边界。
视觉控制：室内暖灯照亮周谨，门外冷灰夜色包住林夏，门框形成清楚明暗分界，肤色自然。
稳定结尾：林夏背对周谨停在门外，周谨留在门内，两人都没有越过门槛。
```

若运动本身承担观看价值，同样只写一条清楚轨迹：`摄影机：从餐桌远端沿桌边缓慢横移，越过前景空椅后停在沉默的母亲侧脸，使缺席者留下的空位先于人物反应被看见。` 不再附加无必要的焦距、角速度、转焦和制动参数。

## 核心与按需分句

- 核心必填是 `主体与起态`、`动作时间线`、`台词`、`视觉控制`、`稳定结尾`，但“必填”只保证语义闭合，不要求长篇。标准镜头通常由一个锚点句、一段完整画面描述、一组原文台词、一个光影句和一个结果句组成。
- `摄影机`、`焦点`、`声音设计` 没有实际控制价值时省略整行。不要为了字段完整给每镜安排推拉、三次转焦、口型说明或环境拟音；这些自然补间默认属于 Seedance 演绎空间。
- 场景视觉连续性分析和跨镜对照仍记录在审片报告；正式 Markdown 的“全局视觉基线”锁定完整光色逻辑。逐镜视觉控制只提取当前画面最有生成价值的主光、综合色彩/材质和曝光或肤色结果，不把整套基线再次展开。
- 参考素材是可选证据，不是直投前置条件。直投提示必须脱离参考图独立成立；只有本镜列出已审核参考素材且用户选择上传时，才写“若上传该图……”。未上传时，主体与起态、动作时间线中的人物位置、机位、姿态、支撑、持物和接触关系仍完整有效。二维线稿只参考位置、躯干平面朝向、边界、轴侧、摄影机与视锥，不参考头部朝向、视线、站坐、手部接触、道具高度、真实透视、人物外貌、服装、材质、色彩、光影或成片风格；不得写无条件的“参考图中……”。
- 普通互动镜只锁关系方向和关键视线目标；高风险镜才增加可验证身体特征和首尾阶段。`身体朝向某人/某物` 不等于人物看镜头，但无需在每镜逐项列双脚、躯干、头部、视线和可见面。
- 每镜空间起态应脱离上一镜可理解，但不必重建整间场景。优先选择一个固定锚点和当前人物关系；只有会影响遮挡、越界、接触、视线、摄影机路径或道具因果的事实才显式写入。

## 信息与动作预算

- 每镜只有一个主导观看任务或主要转折；允许同一节拍内受控的环境/人物/证据交接、次级反应、情绪泄露和镜尾余波存在，但所有表演、空间、台词、道具、摄影机、焦点和光影仍需服务同一主转折。
- 关键对白在语义上闭合触发、人物策略、情绪泄露、听者关键反应与镜尾余波，但正式提示只选择本镜最有表现价值和最容易误读的控制点，不逐项贴标签或逐句编排。
- 触发必须属于人物可访问的信息。可见对白在画内可听并由具名说话者驱动口型；画外对白、门外声、电话和广播只触发实际传播范围内的人物；OS、旁白和默认 OV 只给观众，不触发画内人物；系统音必须明确可听范围。
- 台词起说时机只在它影响抢话、停顿、误解、动作同步或情绪落点时显式写出；普通连续对白允许由标点、语气和上下文自然演绎，只保证说话者与反应先后不歧义。
- 长台词、精细手部、道具转移、多人反应、明显摄影机运动、转焦和光影变化若形成多个独立观看中心或无法在时长内顺序执行，由模型拆镜或调整时序；不能为了缩短提示删去空间起态、情绪链或核心表演。
- 空间不是越完整越好。若空间句的新增信息不能改变构图、边界、遮挡、接触、视线或摄影机路径，就删去；释放出的预算不必重新填满，留给模型自然完成呼吸、目光、重心、手部和口型补间。
- 表演与运镜也不是越多越好。删除某个动作、反应、推镜、转焦或环境变化后，若剧情、关系、信息、情绪证据、物理连续性和观看节奏均不受损，就删除；静止与压住反应可以保留。
- 场级节奏在第一版导演方案完成后复核，不在创作前套目标总时长。逐镜比较新增信息、关系或身体状态、必要蓄力与余波以及真实执行时间；观众已经读懂后仍无递进的段落才是压缩候选，慢镜、停顿、倾听、重复和生活过程本身不构成失败。
- 做饭、行走、递物、开门、检查等过程若承担人物能力、证据、关系策略、压力泄露、悬念、喜剧、动作准备或结果可信度，就按剧情节拍保留；不得依据动作类型直接压缩。重复若每次升级信息、压力或关系，也不能因表面相似而合并。
- 删除、缩短、合并、调整信息顺序、重选机位和拆镜没有固定优先级。合并必须同时满足时空连续、观看中心一致、动作可顺序执行，并保住台词起说点、听者反应、空间读取与稳定终态；合并后重新审查单镜容量和 Seedance 语义。
- 时长使用 `max(声音轨, 人物表演/动作轨, 摄影机/焦点轨) + 不可重叠串行动作 + 约1s自然留白`。同一时段内的台词与表演、听者接收、运镜、转焦、OS/OV 覆盖动作只计算一次；约 `1s` 留白在最终计算后统一加入，最长轨道末端已有台词尾势、动作落稳、余波或转场时与其合并，不重复叠加。`稳定结尾` 只规定尾态必须可验证，不是额外耗时字段。
- 不统计直投提示字符数，不设置建议字数或硬上限。长提示只要主语、先后、空间和观看重点清楚就保留；只有当前平台界面已确认真实输入上限时才按该界面限制处理并记录依据。

## 视觉连续性规则

- 同场所有镜头先在审片报告中共享一份内部视觉连续性笔记，并将其可执行部分压缩到正式 Markdown 的“全局视觉基线”。两者都至少锁定：物理光源实体与方向、主辅光强弱关系、主/辅/点缀色的材质落点、白平衡、饱和度、对比度、黑位、高光、背景亮度和肤色基准；审片报告可补充跨镜判断依据，但不得把内部编号或分数写入正式文件。
- 无物理变化时，逐镜只调整“哪些区域进入构图”，不得改变光源方向、冷暖归属、曝光基准或材质综合色彩。换机位造成可见受光面变化，不等于场景换光。
- 只有时间推进、光源开关/移动、门窗遮挡变化、天气变化、进入新空间或明确主观视觉转换，才允许改变基线。变化句必须同时说明触发、时机、影响区域、未变化项和尾帧新稳定态。
- 跨镜审片逐对比较上一镜尾态和下一镜起态的光源数量与方向、白平衡、肤色、背景亮度、黑位、高光和主色落点。无因变化判 `REVISE`。

## 声音与交付

- `台词` 是源文声音的唯一规范副本，不再另设 `【声音原文】`。每条声音行在一套交付中按源文顺序出现一次；同一原文行不得拆字改写。
- 不按直投提示字符数判断可交付性；平台输入上限只有在当前界面经过确认时才生效。信息过载由大模型依据观看中心、动作并发、时长和可执行性判断，不交给字符计数脚本。
- `both` 输出两套文件；默认共享镜号、时长、台词、人物、空间、道具和稳定结尾。只有当前两个目标界面存在已确认的平台差异且审片证明需要时，才允许目标版本独立调整时长，并在审片报告记录依据。
- 正式 Markdown 不得引用 `staging/`、SVG、审核图或工程线稿。只允许把已审核并提升到 `approved-jimeng-2d/` 的 PNG 作为二维位置参考；它只约束位置、躯干平面朝向、边界、轴侧、摄影机和视锥，不约束人物外貌、姿态细节、服装、材质、色彩或光影。示例：`S1-03_即梦_2D_空间关系.png`。

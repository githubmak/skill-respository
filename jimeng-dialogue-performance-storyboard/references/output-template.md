# 输出模板

本文件只规定交付结构。`【Seedance 直投提示】` 是每镜唯一创意事实源；工程脚本只核验结构、编号、时长、源文声音、文件和审核声明。内部事实台账、因果主线、表演弧和节奏诊断写入审片报告，不进入正式 Markdown。

## 文件结构

```markdown
# [标题]｜即梦 Seedance 分镜

## 项目信息
- Seedance 目标：2.0|2.5
- 画幅与风格：[用户指定或模型选定]
- 源文 SHA-256：[route_task 的 source_intake.source_sha256]
- 交付状态：DRAFT|PROVISIONAL|FINAL

## 全局连续性
[只写跨场复用的人物造型、固定道具和不能漂移的源文事实。]

## 场景导演方案

### S1｜[场景名]
- 戏剧与表演方向：[关系变化、信息顺序和表演尺度]
- 摄影机与剪辑方向：[观众位置、场级快慢与信息释放、运动/静止逻辑和结束距离；不写目标总时长或平均镜长]

## 分镜投喂卡

#### S1-01｜[镜头名]

【时长】
[>0 且 <= 当前已确认平台上限；默认 15]s

【出现人物】
[本镜可见人物；无人则写“无”]

【Seedance 直投提示】
主体与起态：[每镜独立完整说明当前空间区域与边界、固定物、摄影机相对固定物的位置与拍摄方向、实际可见背景、第一观看主体、具名人物槽位、起始姿态与支撑、道具归属和接触。互动人物再写身体面向、头部/脸部方向、具体视线目标和当前画面可见/不可见面；转身、换位、正反打、遮挡或已有转正风险的镜头，按当前景别追加双脚和可验证身体特征。不能写同前、无参照的前后方、仅写面对某人或依赖参考图来省略空间事实。]
动作时间线：[按可见先后写可访问触发、具名人物动作、口型、获准听者反应和接触变化。只保留执行/准备剧情行为、改变状态、传递/遮蔽信息、体现关系策略或压力泄露、触发他人、建立连续性或形成有效余波的动作。多人或多人可见互动镜中，每个动作和反应都使用具名人物作主语；不得用父亲、母亲、孩子、她、他等代称承担动作归属。每句可见台词必须明确“台词起说点”：哪个动作、视线、吸气、停顿或信息接收完成后开始说；若是抢话、打断、边做边说或画外声，写清说话开始时谁在做什么、谁闭口或继续听。关键对白必须把人物控制方式、情绪泄露、台词状态、获准听者接收及镜尾余波转成可见或可听事实；涉及转身或换位时说明改变项与保持项。]
台词：
[逐行原样放入本镜使用的全部人物台词、OS、OV、系统音和音效原文；无则写“无”。]
摄影机：[仅在机位、景别、运动或落幅需要控制时写；具名说明起幅、触发、物理路径、速度感、落幅停稳及由此新增看清的信息、关系、空间、动作证据或余波。静止足够时直接写固定机位，不添加无收益运动。]
焦点：[仅在景深、初始焦点或转焦具有观看价值时写；说明触发与唯一终点。]
视觉控制：[每镜必写。不要引用 VC-Sn、同上镜、继承前镜或沿用上一镜。依据时间、天气、空间开口、真实光源、遮挡、材质和肤色，用一个完整句直接写本镜可见的光源方向、受光/阴影区域、综合色彩及材质落点、曝光/对比/饱和度/背景/肤色稳定项；若变化，写明物理触发、开始时机、影响范围、保持不变项和变化后的稳定状态；若无变化，直接写稳定结果。不要用固定情绪色代替物理与表演。]
声音设计：[仅在原文声音之外确有环境、拟音、混音、传播范围或口型关系控制时写。具名说明声音通道和实际可听者；OS、旁白与默认 OV 只给观众，系统音逐镜限定听者。]
稳定结尾：[最后保持的构图、人物口型与动作、位置、躯干/头部朝向、视线、可见面、手部和道具状态、焦点、摄影机以及需要稳定的光态；只写一个可验证终态。优先写本镜发生改变或下一镜必须继承的状态，不重复主体与起态中没有变化的空间清单。]

【审核后参考素材】
[有助于消除空间歧义时才列已审核并提升的二维位置参考 PNG、关键帧或视频；未列或不上传，不影响直投提示执行。]
```

## 核心与按需分句

- 核心必填是 `主体与起态`、`动作时间线`、`台词`、`视觉控制`、`稳定结尾`。它们分别回答这一镜独立发生在哪里、谁在何时以什么状态做什么、原文说什么、本镜可见的光影与色彩结果、最后稳定成什么。
- `摄影机`、`焦点`、`声音设计` 按这个顺序逐行书写；没有实际控制价值时省略整行，不写空占位。`视觉控制` 每镜必写；没有光态变化时写明稳定的物理光源、受光面、综合色彩、曝光和肤色结果。
- 场景视觉连续性只存在于审片报告，不在正式 Markdown 输出内部笔记名称、`VC-Sn` 或其他基线编号。Seedance 单独接收本镜时看不到前镜；每镜视觉控制句必须自行包含可见的光源、冷暖、材质、曝光和肤色结果。
- 参考素材是可选证据，不是直投前置条件。直投提示必须脱离参考图独立成立；只有本镜列出已审核参考素材且用户选择上传时，才写“若上传该图……”。未上传时，主体与起态、动作时间线中的人物位置、机位、姿态、支撑、持物和接触关系仍完整有效。二维线稿只参考位置、躯干平面朝向、边界、轴侧、摄影机与视锥，不参考头部朝向、视线、站坐、手部接触、道具高度、真实透视、人物外貌、服装、材质、色彩、光影或成片风格；不得写无条件的“参考图中……”。
- 面向控制对所有互动镜保留最低锁定，对高风险镜再增加可验证身体特征和首尾阶段：`身体朝向某人/某物` 不等于头部和视线也自动同向，`摄影机看见正面` 也不等于人物看镜头。若双脚、躯干、头部和视线一致，用一个短句合并；若不同，逐项具名说明。摄影机换侧导致的正/侧/背可见面变化属于投影变化，不得伪造人物转身。
- 每镜空间起态都必须独立成立，即使与上一镜物理状态一致也不能写“同前”或省略；但采用“最小充分空间集”，只保留当前构图中会影响人物关系、遮挡、接触、视线、摄影机读取或道具因果的区域、边界、固定物、机位、可见背景、人物槽位、姿态支撑和道具归属。不会进入画面、不会改变执行或已由明确锚点唯一确定的固定事实不重复堆写。互动镜在此基础上增加面向、头脸方向、视线与可见面。

## 信息与动作预算

- 每镜只有一个主导观看任务或主要转折；允许次级反应、情绪泄露和镜尾余波存在，但所有表演、空间、台词、道具、摄影机、焦点和光影仍需服务同一主转折。
- 关键对白必须保留 `触发 -> 人物控制方式 -> 情绪泄露 -> 台词状态 -> 听者反应 -> 镜尾余波`。这些是语义事实，可以自然合并，不要求逐项贴标签。
- 触发必须属于人物可访问的信息。可见对白在画内可听并由具名说话者驱动口型；画外对白、门外声、电话和广播只触发实际传播范围内的人物；OS、旁白和默认 OV 只给观众，不触发画内人物；系统音必须明确可听范围。
- 台词起说时机是可执行事实，不是可选修辞。每句台词都要能回答“谁在什么动作/停顿/视线变化之后开始说”，并让听者反应发生在真正接收之后；不要求固定秒数，但必须有明确的相对时序。
- 长台词、精细手部、道具转移、多人反应、明显摄影机运动、转焦和光影变化若形成多个独立观看中心或无法在时长内顺序执行，由模型拆镜或调整时序；不能为了缩短提示删去空间起态、情绪链或核心表演。
- 空间不是越完整越好。若空间句的新增信息不能改变当前构图、遮挡、面向、接触、焦点或连续性，就删去它，把预算留给呼吸、目光、重心、手部控制、口型起止和听者反应。
- 表演与运镜也不是越多越好。删除某个动作、反应、推镜、转焦或环境变化后，若剧情、关系、信息、情绪证据、物理连续性和观看节奏均不受损，就删除；静止与压住反应可以保留。
- 场级节奏在第一版导演方案完成后复核，不在创作前套目标总时长。逐镜比较新增信息、关系或身体状态、必要蓄力与余波以及真实执行时间；观众已经读懂后仍无递进的段落才是压缩候选，慢镜、停顿、倾听、重复和生活过程本身不构成失败。
- 做饭、行走、递物、开门、检查等过程若承担人物能力、证据、关系策略、压力泄露、悬念、喜剧、动作准备或结果可信度，就按剧情节拍保留；不得依据动作类型直接压缩。重复若每次升级信息、压力或关系，也不能因表面相似而合并。
- 删除、缩短、合并、调整信息顺序、重选机位和拆镜没有固定优先级。合并必须同时满足时空连续、观看中心一致、动作可顺序执行，并保住台词起说点、听者反应、空间读取与稳定终态；合并后重新审查单镜容量和 Seedance 语义。
- 时长使用 `max(声音轨, 人物表演/动作轨, 摄影机/焦点轨) + 不可重叠串行动作 + 约1s自然留白`。同一时段内的台词与表演、听者接收、运镜、转焦、OS/OV 覆盖动作只计算一次；约 `1s` 留白在最终计算后统一加入，最长轨道末端已有台词尾势、动作落稳、余波或转场时与其合并，不重复叠加。`稳定结尾` 只规定尾态必须可验证，不是额外耗时字段。
- 不统计直投提示字符数，不设置建议字数或硬上限。长提示只要主语、先后、空间和观看重点清楚就保留；只有当前平台界面已确认真实输入上限时才按该界面限制处理并记录依据。

## 视觉连续性规则

- 同场所有镜头先在审片报告中共享一份内部视觉连续性笔记。笔记至少锁定：物理光源实体与方向、主辅光强弱关系、主/辅/点缀色的材质落点、白平衡、饱和度、对比度、黑位、高光、背景亮度和肤色基准；正式 Markdown 不输出笔记名称或内容。
- 无物理变化时，逐镜只调整“哪些区域进入构图”，不得改变光源方向、冷暖归属、曝光基准或材质综合色彩。换机位造成可见受光面变化，不等于场景换光。
- 只有时间推进、光源开关/移动、门窗遮挡变化、天气变化、进入新空间或明确主观视觉转换，才允许改变基线。变化句必须同时说明触发、时机、影响区域、未变化项和尾帧新稳定态。
- 跨镜审片逐对比较上一镜尾态和下一镜起态的光源数量与方向、白平衡、肤色、背景亮度、黑位、高光和主色落点。无因变化判 `REVISE`。

## 声音与交付

- `台词` 是源文声音的唯一规范副本，不再另设 `【声音原文】`。每条声音行在一套交付中按源文顺序出现一次；同一原文行不得拆字改写。
- 不按直投提示字符数判断可交付性；平台输入上限只有在当前界面经过确认时才生效。信息过载由大模型依据观看中心、动作并发、时长和可执行性判断，不交给字符计数脚本。
- `both` 输出两套文件；默认共享镜号、时长、台词、人物、空间、道具和稳定结尾。只有当前两个目标界面存在已确认的平台差异且审片证明需要时，才允许目标版本独立调整时长，并在审片报告记录依据。
- 正式 Markdown 不得引用 `staging/`、SVG、审核图或工程线稿。只允许把已审核并提升到 `approved-jimeng-2d/` 的 PNG 作为二维位置参考；它只约束位置、躯干平面朝向、边界、轴侧、摄影机和视锥，不约束人物外貌、姿态细节、服装、材质、色彩或光影。示例：`S1-03_即梦_2D_空间关系.png`。

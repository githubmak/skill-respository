# 剧情信息与节奏参考

本文件帮助模型判断观众何时知道什么，不给场景贴死标签，也不规定镜头数量或固定节拍格式。

## 认知关系

区分观众已知、各人物已知、人物以为对方已知和暂时需要隐藏的事实。画面、背景、人物反应和声音都可能提前泄露信息；模型根据原文决定何时展示、遮挡、延迟或只让声音进入。

揭示应让观众看到事实或足以确认事实的结果，而不是只看见人物“惊讶”。揭示后的反应、动作中断、距离变化、道具落定或声音退场，为新认知留下后果。简单对白不必建立正式信息表；悬疑、误会或多人知情差复杂时可在内部画出认知状态。

## 常见叙事方向

- 对白关系：让台词、说话前控制、听者接收和句末余波形成关系变化，避免机械一问一答。
- 喜剧错位：先建立正常基线，保护误会信息，依靠停顿和正确人物的反应落梗，不用搞笑滤镜或全员夸张。
- 悬疑揭示：限制视角、控制证据显露、延迟确认；不要用无来源暗角和红光冒充悬疑。
- 亲密关系：用距离、犹豫、共享物件、触碰或回避表达，不用粉色滤镜替代人物选择。
- 威胁惊惧：先建立安全空间，再让异常声、痕迹或边界变化破坏安全；脸和关键动作仍需可读。
- 无台词因果：让原因、动作、反馈和新状态在画面中成立，不用旁白解释已经看见的事。
- 时间压缩：用重复锚点和逐段状态变化让观众感到时间流逝，不要求模型在一镜内变形多个时间地点。
- 非战斗行动：保持目标、路径、障碍、调整和结果可读，避免人物位移与摄影机运动都满负荷。
- 家庭关系：同一句话可能同时作用于亲子、夫妻与手足关系。让证据先被谁接住、谁替谁说话、谁没有反应，决定观众如何理解家庭阵营；不把家庭温度等同于暖色滤镜。
- 群像传播：信息从声源或证据进入后，各人物按距离、知情程度、任务占用和关系策略先后接收。可选择一个关键接力或沉默者作为观看落点，避免全员同步反应。

这些方向可以混合，主次由源文决定。模式名称只供内部思考，不写进直投提示。

## 蒙太奇

时间压缩可使用相同构图、动作落点、物件位置、声音或空间锚点连接片段。每段给出真实时间证据和状态变化，最后让累积结果可见。段数、时长、匹配方式和是否返回原构图由模型根据节奏选择，不设固定数量。

完成后检查信息顺序是否服务原文：没有提前泄底，没有遗漏触发物，没有凭空新增证据、危险、暧昧或笑料。若信息控制与漂亮画面冲突，重新设计画面，而不是改变剧情事实。

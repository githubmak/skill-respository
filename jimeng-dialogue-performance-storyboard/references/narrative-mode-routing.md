# 剧情模式路由

本文件只负责决定一场戏如何释放信息、组织节奏和分配镜头任务。具体运镜由 `cinematic-grammar-library.md` 承担，表演细节由 `prompt-performance-rules.md` 承担，空间与物理连续性仍按原合同执行。不得因选择剧情模式改变原文事实、台词、输出模板或稳定性门槛。

## 选择规则

- 按场景或镜头组选择模式，不按整部作品贴单一类型标签。
- 每场只选一个主模式，可加一个副模式。主模式决定观众认知路径和节奏；副模式只调整表演、声音、构图或光影侧重。
- 没有明确类型信号时，默认 `对白表演`；不要为了“更电影”强行加入悬疑、浪漫、恐怖或喜剧处理。
- 纯打斗、武器对抗、多人混战和重型追逐交给动作专项；本技能只处理冲突前后的人物戏、普通逃离和非战斗行动。
- 模式判断和内部模式卡不新增最终 Markdown 字段。

内部模式卡：

`场景/镜头组 | 主模式 | 副模式 | 观众开场已知 | 角色已知差 | 暂不揭示 | 本组新认知 | 信息载体 | 声音载体 | 余波/遗留问题 | 禁止套路`

## 信息释放合同

- 每个镜头组只完成一个新的观众认知。线索、误会、关系变化、行动结果或时间变化若各自改变理解，拆成不同组。
- 先区分 `观众知道`、`角色知道` 和 `双方暂时不知道`。不得因为画面漂亮而提前展示角色尚未发现、剧情尚未揭示的事实。
- 信息载体必须来自源文或合理可见推断：人物反应、当前道具、空间遮挡、环境变化、声音、动作结果。不得新增证据、危险、暧昧对象或笑料。
- 揭示镜必须让观众看见“事实本身”或足以确认事实的结果；只拍人物惊讶而不交代触发物，不算完成揭示。
- 揭示后保留一个可见后果：闭口反应、距离变化、动作中断、道具落定、空间关系改变或声音退场。不要揭示后立即进入无关镜头。

## 模式合同

| 模式 | 选择信号 | 节奏与信息路径 | 优先载体 | 禁止套路 |
|---|---|---|---|---|
| 对白表演 | 台词、质问、承认、关系重定义主导 | 关系建立 -> 开口前控制 -> 台词落点 -> 主要听者反应 -> 关系余波 | 口型、视线、手/道具、距离 | 连续正反打、每句都特写、死听者 |
| 喜剧错位 | 误会、身份差、预期落空、反应反差 | 正常基线 -> 小错位 -> 0.3-0.6秒闭口停顿 -> 反应落梗 -> 短释放 | 客观关系镜、停住的道具、先理解者反应 | 提前用夸张表情泄梗、搞笑滤镜、所有人同时反应 |
| 悬疑揭示 | 线索、隐瞒、观察、身份或事实确认 | 有限视角 -> 可疑痕迹 -> 延迟确认 -> 单一事实揭示 -> 认知余波 | 遮挡、负空间、局部证据、画外声、视线落点 | 提前拍清答案、无来源红光暗角、连续假惊吓 |
| 亲密关系 | 暧昧、试探、和解、克制靠近、触碰后果 | 共享空间 -> 视线/距离试探 -> 犹豫 -> 源文支持的靠近或接触 -> 关系停顿 | 眼神回避、呼吸、手部距离、共享道具、边缘光 | 粉色滤镜代替关系、无依据慢动作、强行触碰 |
| 威胁惊惧 | 安全感受损、画外危险、边界被侵入 | 安全基线 -> 异常声/痕迹 -> 确认受阻 -> 威胁进入可见边界 -> 后果 | 门框、走廊深处、声源、遮挡、动作骤停 | 全黑看不清脸、先展示完整威胁、浓雾和乱晃镜头堆恐怖 |
| 无台词视觉 | 动作、观察、环境或道具变化承担叙事 | 当前状态 -> 可见原因 -> 人物/物件动作 -> 环境或他人反馈 -> 新状态 | 身体动作、道具、空间变化、环境声 | 用旁白解释已有画面、漂亮空镜代替因果、人物无反应 |
| 时间压缩蒙太奇 | 重复劳动、旅程、等待、成长、时间跳跃 | 固定重复锚点 -> 每镜一个状态增量 -> 明确时间/光线变化 -> 累积结果 -> 回到稳定现实 | 同一构图锚点、道具数量、服装痕迹、光线和声音变化 | 一镜内变形多个时间地点、每段方向跳变、把蒙太奇写成连续实时动作 |
| 非战斗行动 | 搜寻、赶路、逃离、救援准备、普通追赶 | 目标 -> 路径 -> 障碍 -> 决策调整 -> 到达或失败结果 | 路线、脚底接触、呼吸、障碍物、视线和到达状态 | 人物与强运镜同时满负荷、路径跳跃、无动作过渡直接到终点 |

## 混合模式

- `悬疑揭示 + 对白表演`：悬疑决定何时给证据，对白只承载试探和认知反应；台词不能提前说破暂不揭示项。
- `亲密关系 + 喜剧错位`：亲密决定距离与视线，喜剧只决定停顿和落梗；不要用夸张反应破坏人物基线。
- `威胁惊惧 + 无台词视觉`：威胁决定信息边界，无台词模式用声源、门框、动作中断和新状态完成叙事。
- `时间压缩蒙太奇 + 非战斗行动`：蒙太奇决定时间跳跃，行动模式保证每个片段都有路线和结果；每次跳时重写当前状态。
- 冲突时按 `源文事实 > 主模式信息路径 > 连续性硬门槛 > 副模式表现 > 视觉增强` 取舍。

## 完成判断

- 去掉“悬疑、浪漫、喜剧、恐怖”等标签后，观众仍应能从信息顺序、停顿、距离、动作和声音感知该模式。
- 每组检查：开场认知是否明确、暂不揭示项是否泄漏、本组新认知是否唯一、载体是否可见、揭示或结果后是否有余波。
- 模式只改变拍法，不降低直接提示词的信息完整度；无台词、蒙太奇和空景也必须写成真实可见因果，不能用模式名称填充字数。

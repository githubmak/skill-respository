# 物理结构连续性规则

本文件用于把源文中的概括动作词翻译成即梦能生成的物理结构链。核心原则：凡是会改变人物身体、道具、衣物、门窗、屏幕、人群或空间关系的词，都不能只写剧情概括，必须写成可见起点、可见转换和稳定终态。

## 总原则：概括词转物理结构链

遇到 `躺、伏、靠、坐在、坐姿、坐下、换坐姿、抱、扶、摔倒、倒向、急刹、翻身、坐起、起身、披衣、穿衣、开门、下车、递给、拿出、收起、手机响、屏幕显示、人群围观、走过去、离开` 等词时，先内部翻译为：

`起点 -> 支撑/接触/方向 -> 可见转换 -> 稳定终态 -> 下一镜继承`

直接提示词必须写可见事实，不能只写概括动词。若链条无法在同一镜头成立，就拆成定位、转换、终态/余波三类子镜头。

## 后续动作反推

复杂物理结构必须先读后文再写当前镜头。生成前在同一场景或同一连续动作段内做一次后续动作扫描：

`当前状态 -> 后文需要发生什么动作 -> 当前状态是否支持该动作 -> 如果不支持，调整当前姿态/道具/门车门/UI状态或拆镜`

重点扫描后文是否出现：`翻身、坐起、起身、下车、开门、递出、接过、撞到平板/桌角/门框、换座、离场、披衣、脱衣、拿出手机、挂断电话`。

例如后文要 `翻身` 和 `坐起`，前文的 `躺在腿上` 不能写成整个人横压在对方腿上；要倒推成 `腰臀仍在座垫上、双腿蜷在座椅上、手能撑住座垫、头和上半身贴近对方腿侧`。这样后文才有物理空间完成翻身和坐起。

如果源文当前句和后文动作冲突，以后文可行动性为优先，在 `使用说明` 中写明合理推断；不要为了忠于一个概括词而制造后续不可能动作。

## 人体姿态几何

以下动作触发人体姿态几何锁定：`躺、伏、趴、靠在、靠到、靠住、抱住、搂住、扶住、拉住、拽住、摔倒、倒向、倒到、急刹、翻身、坐起、起身、蹲下、跪下、弯腰、前倾、抱起、背起、靠在怀里、躺在腿上、枕在腿上`。

直接提示词必须写清：

`头部位置 -> 肩背位置 -> 腰臀位置 -> 双腿姿态 -> 双脚位置 -> 支撑点 -> 接触点 -> 非接触边界 -> 尾帧姿态`

不要写 `A伏在B腿上`、`A靠在B怀里`、`A摔倒` 这类单句。要改成可生成的身体骨架。例如车后排暧昧睡姿：

`A横向侧躺在后排右侧座椅上，头枕在B左腿外侧，肩背贴着右侧座椅靠背，腰臀仍在右侧座垫上，双腿蜷缩在右侧座椅上，膝盖朝右侧车门，双脚没有伸到B身上；二人接触点只限A头侧和B左腿外侧。`

姿态必须支持下一步动作。若下一镜或后文要翻身、坐起、撞到道具，上一镜姿态必须给出能完成动作的支撑结构：手可撑哪里、腰臀是否在座垫/床/沙发上、双腿是否留在可移动范围内。不能让人物从物理上无法起身的位置突然坐起。

### 座椅/吊椅支撑点继承

座椅、吊椅、沙发、床、车座这类承载身体的物体，和银行卡/手机一样属于连续状态。上一镜只要写过 `臀部、腰臀、腰部、肩背、背部、双腿、双脚` 与 `座垫、吊椅、椅背、扶手、靠背、沙发、床` 的接触关系，下一镜第一句必须把这些支撑点改写成当前可见事实，不能偷换成 `坐在吊椅中间、坐在椅子上、靠着沙发、躺着` 这类概括词。

若身体支撑点真的改变，必须拍出物理转换链：

`原支撑点 -> 手撑/脚踩/肩背离开或贴回 -> 腰臀挪动方向和距离 -> 双腿/双脚如何配合 -> 新支撑点稳定`

例如上一镜是 `A臀部压在吊椅右侧坐垫，腰部靠住吊椅右侧弧形靠背，双腿蜷在吊椅左侧`，下一镜不能写 `A坐在吊椅中间`。正确写法只能二选一：

- 状态不变：`A臀部仍压在吊椅右侧坐垫，腰部贴住吊椅右侧弧形靠背，双腿蜷在吊椅左侧，身体没有挪到吊椅中央。`
- 状态改变：`A左手撑住吊椅坐垫，腰部先离开右侧弧形靠背，臀部沿坐垫向吊椅中央挪半个身位，双腿从左侧蜷缩调整到身前，画面结束时A臀部稳定在吊椅中央坐垫，腰背重新贴住中央靠背。`

不能让景别切换、反打或近景省略身体支撑点。近景拍脸时也要在开头用一句压缩事实写清 `臀部/腰背仍在原支撑点`，否则即梦容易把人物重置到椅子中心或穿进吊椅结构。

翻身必须写清转动范围：只转头、只转上半身，还是腰臀和双腿一起移动。示例：

`A睡梦中只转动头部和上半身，腰臀仍压在右侧座垫上，双腿继续蜷缩在右侧座椅；脸颊从B左腿外侧蹭近到B腰腹旁后停稳。`

坐起必须写支撑点。示例：

`A左手撑住右侧座垫，双腿仍蜷在右侧座椅上，上半身从B左腿外侧猛地直起，头部抬向B膝前平板。`

亲密接触必须写边界：接触部位、非接触部位、没有跨坐、没有双腿缠绕、没有压住对方身体、腰臀仍在座椅/床/沙发上。边界用正向事实写，不要放进负面提示词里。

## 道具和物件结构

道具概括词包括：`拿着、拿出、递给、塞给、交给、放下、收起、接过、握住、摔落、扣下、展示、刷卡、签字、付款`。

必须写清：

`道具起点 -> 哪个人哪只手/哪个容器/哪个表面 -> 移动路径 -> 接收者可触达 -> 接触点 -> 松手/放下 -> 稳定终态`

如果接收者在身后、侧后、背向、隔着桌/柜台/车门或距离不可触达，先写定位镜头让身体关系成立，再转移道具。不要写 `A递给B` 让模型自行补空间。

## 衣物结构

衣物概括词包括：`披上、穿上、脱下、整理、扯住袖口、外套滑落、衣摆垂下`。

必须写清：

`衣物起点 -> 谁哪只手拿住哪一处 -> 接触身体部位 -> 是否穿进袖子 -> 肩/手臂/腰侧/衣摆状态 -> 尾帧衣物归属`

示例：

`外套开头搭在B左臂弯，B右手捏住外套领口，从A背后把外套披到A双肩上；A双臂没有伸进袖子，衣摆垂在A身后，尾帧外套只披在A肩上。`

衣物转移和长台词、运镜、转身同时出现时必须拆分。

## 门、车门、窗和柜门结构

门类概括词包括：`开门、关门、推门、拉门、下车、上车、探进车窗、越过门框`。

必须写清：

`门开头状态 -> 哪只手接触把手/门边 -> 门向哪个方向打开/关闭 -> 人物是否跨过门槛/车门线 -> 尾帧门状态和人物所在侧`

示例：

`右侧后车门开头关闭，A右手握住内侧把手，车门向画面右外侧打开；A右脚先踏到路沿，身体离开后排座椅，尾帧车门打开，A站在车外。`

不要让角色穿过关闭的门或关闭的车门；门状态改变后，下一镜开头必须重写门是开、关还是半掩。

## 屏幕、界面和文字结构

屏幕概括词包括：`手机响了、来电、聊天记录、照片界面、转账到账、系统提示、付款码、警局来电`。

必须先判断文字处理方式：

- 手机聊天消息、来电名称、通知弹窗等 UI 文本：默认 AI 直接生成画面侧边绿色气泡/字幕浮层，具体文字进入 `【画面描述｜直接复制】`。只有用户明确要求“不要AI生成文字/后期叠字处理/后期加字”时，才改为后期叠字路线。
- 画内手机只生成模糊界面、来电框或照片色块，除非用户明确要求画内清晰文字；即使 AI 直接生成绿色气泡，气泡也默认在画面侧边安全区，不贴在手机屏幕上。
- 后期叠字路线下，`【画面描述｜直接复制】` 只写侧边安全区或贴合屏幕平面的预留位置，避开脸、嘴和活动手；具体文字写入 `【表演与声音】` 中的后期文字句，不写进直接提示词。
- 生成前必须先判断“屏幕是否对镜头可见”。若镜头从持机者正面拍手机背面，屏幕朝向持机者本人，则屏幕完全不可见；此时直接提示词禁止写 `屏幕显示/模糊聊天界面/微信聊天界面/屏幕光照出文字`，只能写手机背面、摄像头、纯色机身和持机动作。
- 若屏幕不可见但需要观众看到消息，默认把消息写成画面侧边独立二维绿色聊天气泡/字幕浮层：浮层平行于画面、固定在安全区、不属于手机屏幕、不贴合手机透视、不跟随手机机身。文字较长时仍保持 AI 生成默认，但要写成单个大号清晰气泡、文字居中、气泡周围留白干净。
- 若屏幕可见，才允许写 `手机屏幕朝向镜头/斜向镜头，屏幕只显示模糊聊天界面`；精确文字仍默认放画面侧边绿色气泡/字幕浮层，除非用户明确要求后期叠字或贴合屏幕生成。

示例：

屏幕可见示例：

`手机屏幕斜向镜头，屏幕只显示模糊来电界面，不生成清晰文字；画面右侧安全区出现独立二维绿色来电提示气泡，气泡平行于画面，不属于手机屏幕，不贴合手机透视，气泡内写：“警局来电”。`

屏幕不可见但要侧边消息示例：

`手机背面朝向镜头，屏幕朝向A本人且完全不可见；手机背面只保留摄像头和纯色机身，不出现任何聊天气泡、头像、文字或界面。画面右侧安全区出现独立二维绿色微信消息气泡浮层，气泡平行于画面，不属于手机屏幕，不贴在手机背面，不跟随手机透视。`

屏幕朝向必须写清：正对镜头、斜向某人、扣在桌面、贴耳、停在胸前或腰侧。屏幕状态变化要进入下一镜继承。

## 移动路线和窄空间

移动概括词包括：`走过去、靠近、退后、离开、冲进来、坐下、站起、绕过、下车、上车`。

必须写清：

`起点位置 -> 路线方向 -> 位移距离 -> 是否绕过固定物/人物 -> 脚步接触 -> 尾帧站位和身体朝向`

窄空间包括车内、沙发、床边、柜台、餐桌、门口、走廊。窄空间移动前必须写清人物所在侧、可用空隙、是否隔物、身体是否越线。不要让人物在车厢/沙发/床/柜台内瞬移或穿过固定物。

## 人群和背景人物

人群概括词包括：`围观、路人、混混、宾客、学生、警员、工作人员、群众`。

必须写清：

`人数或范围 -> 所在区域 -> 前中后景 -> 虚化程度 -> 是否靠近主角 -> 是否有可见口型 -> 是否抢焦`

示例：

`三名混混坐在画面左后方长椅边，保持背景中景弱虚化，不靠近A和B，不产生可见口型。`

不要把背景人群写成会抢主角的清晰正脸；若人群声音重要，放进 `【表演与声音】` 或后期声音处理。

## 关键帧同步

若复杂镜头添加 `【关键帧生图提示】`，每一帧都要重复本镜最关键的物理结构，不只在首帧写一次。

人体姿态关键帧每帧重复：头部、肩背、腰臀、双腿、双脚、支撑点、接触点、非接触边界。

道具/衣物关键帧每帧重复：持有人、哪只手、接触点、道具/衣物朝向、稳定终态。

门车门关键帧每帧重复：门开合状态、人物所在侧、接触把手的手、是否跨过门槛/车门线。

屏幕关键帧每帧重复：屏幕朝向、画面侧边绿色气泡/字幕浮层位置、气泡不属于手机的约束，或用户明确要求后期时的安全区预留位置。

如果关键帧和 `【画面描述｜直接复制】` 的物理结构不一致，以直接提示词为准并重写关键帧。

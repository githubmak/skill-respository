# 高级镜头语法库

本文件只在用户明确要求高级运镜、日漫式演出、镜头不平、情绪峰值、人物闯入、空间压迫、时间错位或复杂调度时读取。它把成熟影视拍法转译成即梦可理解的物理描述；不输出导演名，不把高级镜头当默认装饰。

## 使用总则

- 先判断本镜发生的是哪一种变化：`认知变化 / 权力变化 / 距离变化 / 空间变化 / 时间变化`。只选一种变化和一种高级拍法。
- 高级镜头必须写成：`起始稳定画面 -> 单一路径或焦段变化 -> 焦点对象 -> 结束稳定画面`。不要只写“高级环绕”“电影式闯入”。
- 高级运镜命中高风险：默认添加成对关键帧，或拆成稳定起幅、动作/变化、稳定落点三个片段。长台词、递物、签字、UI、复杂姿态、三人强反应不与高级运镜硬叠。
- 直接提示词仍优先空间、面向、口型、道具和动作；运镜只写一条，不能抢掉人物表演。

## 可调用组件

### 1. 半弧环绕：关系温度改变

适合暧昧靠近、权力翻转、两人突然站到同一阵线。人物只做低幅呼吸、视线或一句短台词。

即梦句式：

`前0.6秒固定锁住二人隔着桌沿的面对面关系；摄影机以二人之间的杯子为中心，从A左前方沿半弧缓慢移动约20度到A侧前方，焦点始终落在A脸和B的前景肩线，二人站位、朝向和杯子位置不变；结束时B肩线停在画面左缘弱虚化，A的眼神已经落定。`

禁用：大幅绕圈、镜头越过人物、边环绕边递物、边环绕边多人口型。

### 2. 希区柯克变焦：认知突然失衡

只用于“看见关键事实、意识到真相、空间安全感消失”的瞬间，不用于普通悲伤或日常对白。人物脸部大小保持近似不变，背景透视发生受控拉伸；时长宜 1.0-1.8 秒，结束后切稳定反应镜。

即梦句式：

`A停在走廊中央，门框和尽头安全出口在后方形成纵深；摄影机沿直线缓慢后退约0.4米，同时焦段从50mm平滑拉长到85mm，A脸部在画面中的大小基本保持不变，后方走廊被压缩拉远；A闭口，呼吸骤浅，右手停在门把旁不动，结束时只保留A和被拉长的走廊。`

禁用：长台词、奔跑、多人表情、复杂手部动作、反复变焦。

### 3. 信息闯入：第三人/信息打断既有关系

适合门口出现第三人、手机提示打断、原本封闭的二人空间被侵入。先保证前景人物已稳定，再让新信息进入共享画面；不是让镜头无缘由猛冲。

即梦句式：

`前0.5秒，A和B在门内侧面对面停住，门框固定在画面右侧；门外传来脚步声后，摄影机从二人关系中景沿门框方向快速但平稳横移约0.5米，停在半开的门口。C从门外通道进入画面右后方并在门槛外停住，A和B不换位，只同时把视线转向门口；结束时三人被门框分成前中后层。`

禁用：让C从画外直接贴脸出现；未写入口、路径、停步和可见人数；多人同时开口。

### 4. 日漫式物件/空位切入：把沉默拍出信息

适合拒绝、误会、暗恋、尴尬、台词落下后的余波。物件或空位必须承载刚发生的关系结果，不用泛风景填时长。

可选句式：

- `台词落下后，切入桌面近景：A已经松手，卡片停在B正前方；窗边冷光压在卡边，B的手悬在画面上缘没有接回。`
- `关系拉开中景：A停在画面右侧，左侧门口留出一人宽空位，门框阴影压住空位；A闭口，视线没有追向出口。`
- `空镜只保留半掩门缝和门内暖光，门外脚步声渐远；门没有继续移动。`

禁用：无剧情意义的天空、街景、花草；物件镜同时承担长台词。

### 5. 转焦：在同一空间内转移观众认知

适合从说话者转到听者、从人转到关键道具、从前景遮挡转到后景证据。一次镜头只转焦一次，焦点转换约0.3秒；人物位置不移动。

即梦句式：

`A前景肩线弱虚化占画面左缘约1/5，B在中景清晰说完原台词并闭口；焦点用约0.3秒从B的眼睛平稳转到B胸前被压住的照片，A和B身体朝向、距离和照片位置不变；照片清晰后，B指节缓慢收紧。`

### 6. 压迫拉远：让人物被空间吞没

适合失落、被拒绝、制度压迫、无处可退。人物需静止或低幅反应，环境锚点必须真实存在。

即梦句式：

`A站在冷白柜台外侧，签字台和空长椅向画面后方延伸；摄影机沿原方向缓慢后退约0.4米，A逐渐缩到画面右侧三分之一，左侧保留大面积空等候区，A闭口，肩背在呼吸后轻轻下沉；结束时柜台和空椅清楚包住A。`

### 7. 时间碎片：心理记忆/现实错位

把时间错位拆成独立稳定片段，不要求即梦在一镜内变形。用相同道具、相同声音或相同姿势作为桥接。

结构：

`现实触发稳定镜 -> 记忆片段稳定起幅 -> 记忆动作/台词 -> 现实返回稳定镜`

即梦句式：

`现实镜中[真实姓名]的指尖停在手机边，[真实姓名]OS：“……” 画面人物闭口；独立记忆镜以同一款手机停在旧场景桌面作为起幅，前0.6秒空间和人物姿态稳定后再发生动作；返回现实镜重写[真实姓名]当前站位、手机持有人和闭口反应。` 方括号内容必须替换为声音锁定表中的真实人物名。

禁用：同一直接提示词里要求现实场景自动溶解成回忆场景；时间倒放和多人长对白同时发生。

## 对话覆盖变化公式

连续对白不要只做重复正反打。优先按剧情功能，在 2-4 个子镜头内选择：

`关系镜（谁和谁隔着什么） -> 说话者口型镜 -> 听者受击镜或手部插入 -> 结果空位/物件/拉开镜`

只要台词没有改变认知，不强制切镜；一旦出现关键词、权力变化、道具意义变化、回避或沉默，就选择一次景别、焦点、遮挡、物件或距离变化。

## 日漫/动态漫对白切镜组件

这些组件用于让对白有呼吸和层次，不让人物一直站着说。每个镜头组最多选 1-2 个；必须绑定本组真实道具、空间锚点或台词后果。

- 静物逗号：1.0-2.0秒，固定拍桌面杯水、半掩门缝、空座、停住的手机、卡片、衣袖或窗影。只用于台词后沉默、场景换气或关系停顿；物件必须是当前场景已存在的物理事实。
- 反应切入：1.2-2.5秒，切到被击中者闭口近景或肩后近景；先写说话者已闭口或画外声音，再写眼睑/下颌/呼吸和一项手部/肩背/道具反应。
- 视线落点：1.2-2.0秒，不拍对方正脸，拍人物视线落向地面、门口、杯沿、手机气泡或对方手上；适合心虚、回避、试探和假装不在意。
- 环境回声：1.5-3.0秒，台词或OS结束后，拍走廊线、窗帘轻晃、灯牌反光、警局顶灯或门外空位，环境声保留；用于缓冲，不新增剧情。
- 情绪前摇：关键台词前 0.3-0.8 秒，人物先停住、吸气、手停在道具边或视线避开，再开口；适合拒绝、承认、质问和关系重定义。
- 落梗停顿：喜剧误会后 0.3-0.6 秒，关系镜头里两人都闭口，手机/照片/餐盘停在二人之间，听者先反应，随后再接台词。

禁用：无源文关系的漂亮空镜、与当前情绪无关的风景、连续三次静物逗号、让空镜承载新剧情。

## 声音桥与口型安全

对白切镜可以用声音桥增强流畅，但直接提示词不能让画面中不可见的人强行长嘴说话。

- J切：下一句声音先进入当前反应/物件镜；画面中可见人物闭口，用眼神、呼吸或手部反应承接。下一镜再给说话者可见口型。
- L切：说话者说完后声音尾音延续到听者反应镜；听者闭口反应，避免两张嘴同时动。
- OS/OV桥：OS/OV写入画面描述时，画面人物闭口；用手机、门缝、空位、手部停顿或眼神落点承接声音。
- 手机提示音桥：提示音先响，人物手指停住或抬眼，再给预留安全区和反应镜，具体消息默认后期叠加；不要让手机 UI、人物转身和长台词同镜抢优先级。

## 高风险降级

若本镜同时命中以下任意两项，放弃高级运镜，改为稳定镜 + 插入/反应镜：

- 可见长台词或两个说话者交接；
- 道具转移、签字、刷卡、手机 UI；
- 起身、转身、亲密接触、门车门穿越；
- 三人以上清晰入画且需要可读反应；
- 精确位置、朝向或支撑点必须延续。

高级感来自“变化有动机、画面有稳定落点”，不是来自镜头一直运动。

# 视觉导演 Profile

本文件只在用户提出明确视觉风格、画面质感或题材美术要求，或者场景视觉方向难以判断时读取。它提供导演灵感，不增加输出字段、评分、合同或额外运行阶段。

## 路由

用户明确要求和源文不可改变的视觉事实优先。下表只是帮助模型理解不同方向的观看重点，不能靠单个关键词自动选择，也不能把 profile 名称投喂给 Seedance。

| 触发信号 | profile | 视觉重点 |
|---|---|---|
| 古风游戏、国风武侠游戏、武侠游戏质感 | `chinese_wuxia_game_cinematic` | 东方空间、人物轮廓、自然色、真实材质、动作重量 |
| 写实古风、历史武侠、江湖烟火 | `grounded_historical_wuxia` | 动机光、旧损材质、低饱和、重心与惯性 |
| 写意古风、华丽武侠、诗意江湖、仙侠 | `painterly_elegant_wuxia` | 色彩分区、服装轮廓、山水层次、克制空气光 |
| 宫廷、府邸、朝堂、古装关系戏 | `period_court_cinematic` | 礼制空间、门窗层次、克制华饰、人物关系距离 |
| 现代剧、自然电影感、生活化质感 | `modern_natural_drama` | 现实光源、生活痕迹、自然表演、低幅环境活动 |
| 都市情感、职场、咖啡馆、夜车 | `modern_cinematic_variant` | 场景专属色卡、玻璃/金属/布料差异、移动光源 |
| 乡村、小镇、自然生活、家庭日常 | `rural_lived_in_naturalism` | 地域材质、天气痕迹、生活使用痕迹、自然纵深 |

“古代宫廷”不等于江湖动作，“现代夜景”不等于霓虹，“乡村”不等于暖黄怀旧，“唯美”也不等于雾、辉光和慢动作。没有明确风格时，根据剧情功能、时代、地点、材质、时间天气和现实光源创作具体画面，不需要给它命名。

## 证据与改写

综合观察用户风格要求、时代与现实层、地点建筑、人物身份与服装、道具技术、动作物理、剧情功能、情绪温度、时间天气和现实光源。每个采用的视觉决定都应能回到这些证据之一；证据不足时保持克制，不猜题材。

下列剧情方向可改变视觉重点，但不是只能选一个的 modifier：

| 剧情证据 | modifier | 只改变 |
|---|---|---|
| 悬疑、试探、信息遮蔽 | `suspense_restraint` | 遮挡、留白、局部低照度和揭示顺序 |
| 亲密、重逢、关系缓和 | `intimate_warmth` | 人物距离、柔和反差、肤色与呼吸余波 |
| 喜剧错位、尴尬升级 | `comic_clarity` | 信息可读性、反应时差、明暗清晰，不增加卡通夸张 |
| 失落、离别、压抑 | `melancholic_distance` | 空间留白、冷暖距离和低幅环境余波 |
| 追逐、冲突、动作升压 | `kinetic_pressure` | 重心、方向、惯性和节奏，不自动变成武侠 |

项目视觉方向通常跨场继承；时代、现实层、地点文化、天气光源或用户要求发生变化时，模型可重新设计。无需生成 profile 回执、证据分数或固定内部表格。

## 共同视觉底座

可从四个相互作用的层面建立画面：

1. `light`：动机光源、方向、受光面、衰减、阴影曝光、肤色保护。
2. `color`：主色/辅助色/点缀色、色温关系、黑位、高光保护和跨镜连续。
3. `material`：剧情相关材质及不同反光，保留适合构图的自然不完美。
4. `motion`：起态、触发、主体动作、环境响应、材质响应、余波落幅。

不要用“电影感、高级感、唯美、灵动”替代上述可见事实。游戏名只作内部别名，直接投喂正文写原创可执行事实。

## 场景生命感

寻找真实动力源、静止锚点、人物或环境的差速响应以及结束余波。环境运动应有因果，例如窗光随云层变化、车灯扫过脸侧、门开后冷光进入、杯面因落桌出现水纹、烛焰受风后墙影稍晚恢复。动作、摄影机和环境响应的数量由本镜观看任务决定；避免所有层同步摇动，也避免每镜重复同一套“慢推、轻雾、衣摆”。需要更细的相位与人物微表演时读取 `liveness-motion-grammar.md`。

动态提示词按可见因果顺序描述，并留下稳定落幅。呼吸、灯火、水纹、热气、人流或布料余动只有在本镜看得见且有观看收益时才保留。

## 光影增强

可区分环境基础光、人物表演光和剧情变化光，但不要求三层齐全。每处光影写清来源、方向、接收表面和阴影结果。彩色环境光应有物理依据和具体落点；脸、嘴和活动手遵守项目肤色要求。

同一场景保持基础曝光、主光来源与方向、主要受光面、阴影密度和高光逻辑连续。动态光由门开、车灯经过、屏幕亮灭、云层遮光或烛火受风等事件触发，并写出接收面与新的稳定状态；变化维度由事件物理决定，不设固定数量。

现代场景优先使用窗光、顶灯、台灯、屏幕光、车灯、店招和玻璃反射；古风场景优先使用天光、檐灯、烛火、火盆、月光和湿地反射。增强光影不等于增加辉光、轮廓光、丁达尔光或大面积雾。

## 乡村古风 UE5 次时代 CG

当用户要求 `3D 精致国风次时代CG建模，UE5引擎渲染` 时，模型仍需先判断是宫廷、江湖、乡村平民还是写意现实层。乡村古风优先建立真实可用的土木空间、家庭劳动痕迹、地域植被和天气侵蚀，不借宫灯、鎏金、巨大殿宇或仙雾抬高“古风感”。

次时代质感应分层落在：皮肤的微表面与中性血色；棉麻、旧木、竹篾、夯土、陶器、铁器、水和叶片各自不同的粗糙度与反射；接触阴影、边缘磨损、局部潮湿和受力形变；月光、火光、晨光或天光对这些材质的真实响应。不要把“UE5”直接等同于强轮廓光、泛蓝阴影、镜面泥地、过度景深或全场粒子。

儿童与成人同框时保持真实头身、身高差、触达范围和视线角度；家庭群像先让职责与关系可读，再用材质和环境运动增加生活感。先在内部建立场景视觉连续性笔记，再把本镜实际可见结果压入一个视觉控制句，不能只在全局风格行声明一次。

## 反 AI 感

可用不均匀玻璃痕、磨损桌边、布料褶皱、断续雨痕、破碎积水反光、生活占用和人物自然不对称减少人工整齐感。只保留当前画面真正可见的细节，避免塑料墙、镜面泥地、均匀雨线、同步背景人物、过度磨皮、死黑阴影、过曝灯管和全场同一材质高光。

## 对白分镜消费方式

把选中的视觉方向转译为内部视觉连续性笔记和逐镜一个 `视觉控制` 句，不输出 profile 名称或内部笔记编号。长台词、多人反应或道具转移占用注意力时，压缩视觉句但保留光源方向、综合色彩、曝光/肤色基准和稳定项，优先保障口型、反应、动作与终态。

## 信息主次

遇到信息过载时，先确认观众必须看见的台词/口型、人物身份与位置、动作因果、关键道具和稳定终态；再保留真正服务它们的受光、材质和环境变化。profile 判断和审美解释不进入直投提示。由模型重做信息层级，不使用固定删减表自动修复。

## 模型审片

由模型判断场景是否有可信动力源、光影落点、材质层次、摄影机观看收益、主体与环境节奏，以及同组镜头是否无因重复。长对白不能因质感词过多而挤压口型与终态。真实成片评估必须查看实际图像或视频，不能用提示词或文本校验假装视觉证据。

# 稳定镜头契约

这是即梦对白表演分镜的硬稳定规则。写任何镜头卡之前都要先应用这些规则。

## 1. 前期分镜脚本规范

- 把每个镜头当成一个“视觉 + 情绪”的完整单位。不要只因为有一个微动作就拆镜；先尝试用镜内推近、转焦或轻微移动保持情绪节拍连续。
- 稳定不是平淡。通过空间、朝向、道具和口型硬门槛后，重要对白组至少要有一个非台词张力点：开口前停顿、手/道具压力、距离变化、遮挡关系、视线错位或有意义的插入/切空。
- 张力不是全程拉满。每个镜头组要有张力功能：铺垫、升压、峰值、释放或缓冲。普通句不要强行特写爆点；峰值后必须给短余波、关系定格或物件结果，让画面有呼吸。
- 质感不是形容词。每条直接提示词至少要有一个可见光影或材质执行：光源方向、脸/手/道具受光面、浅阴影、背景弱虚化、玻璃/手机/纸张/皮革/金属/衣料等剧情相关材质。不要只写 `高级感、电影感、细腻质感`。
- 构图和焦段必须服务镜头任务。孤独压抑可用留白和缓慢拉远；亲密/逼问可用近景填满和前景肩线；对峙/制度压力可用对称和隔物；自然对白优先 50mm，中近景/近景情绪优先 85mm，空间建立优先 24mm/35mm。构图不能改变人物真实站位。
- 关键台词不是说完就结束。若台词刺中听者、改变关系，或完成拒绝/承认/质问/归还/保护，默认在口型镜之后补一张 0.8–1.5 秒独立余波镜，重写面向、距离、道具归属和被击中者反应；尾帧必须定格新的关系状态，例如没有后退、没有接回道具、仍面对对方或距离拉开。不要只把余波塞进说话者镜头边缘。
- 人物资产参考图承担脸部身份稳定；不要用“双人锁脸”等抽象词替代可见的外观、站位、朝向和道具连续。
- 只有出现真实结构变化时才拆镜：时间/地点/现实层改变、说话主体切换但没有闭口交接、新的表演主体占主导、道具/接触动作过载、或当前机位无法保住同一空间关系。
- 每个镜头只写画面中实际可见的人物。不要把 OS、系统音、被提到的人、回忆里的人或画外人物列入可见人物。
- 台词、OS、OV、系统音、内心独白和旁白进入直接提示词时，必须和画面动作/情绪绑定。可见台词驱动说话者口型；OS/OV/系统音/内心独白/旁白只作为声音文本，画中人物闭口，但必须出现被声音触发的眼神、呼吸、手部、道具、距离或肩背反应。
- 写镜头前先建立场景拓扑：固定静物锚点、人物物理槽位、画面区域、前后层级、身体朝向/视线、隔物/接触物、移动路线、空位、道具持有人和允许变化。
- 如果人物或道具在第 N 镜改变位置/归属，第 N+1 镜的直接提示词必须把新的可见位置/归属当成当前画面事实重新写明。不要依赖 `继承/延续/保持` 这类省略词。
- 如果人物在第 N 镜尾帧背向、背对、侧身或身体面向固定物，第 N+1 镜不能直接变成面对某人。必须先写转身/回身/肩线转正/双脚停稳，身体完全面向目标后再开口、接物或反应。
- 如果物品在第 N 镜尾帧属于某人、某只手、某个容器或某个表面，第 N+1 镜不能直接变成属于另一个人、另一只手或另一位置。必须先拍接触、移动、松手/放下和稳定终态。
- 如果人体在第 N 镜尾帧有明确支撑点，例如臀部压在吊椅右侧坐垫、腰部靠住吊椅弧形靠背、双腿蜷在座椅一侧，第 N+1 镜不能概括成 `坐在吊椅中间/坐着/靠着`。必须先复写原支撑点；若要改变支撑点，先拍手撑、脚踩、腰臀挪动、重心转移和新支撑点稳定。
- 转身、递物、起身、坐下、靠近、离场、手机离耳和门车门开合都必须写中间过渡帧；不要只写起点和结果。常用链条：`脚步停稳 -> 肩线转向 -> 头部跟随 -> 视线落点`、`伸手 -> 接触 -> 握住 -> 松手 -> 稳定终态`、`手撑支撑面 -> 腰背抬起 -> 脚落地 -> 站稳`。
- 同一镜头若同时出现四个及以上连续动作，必须拆成准备/定位、接触/转换、终态/余波中的两到三段；每段只保留一个主要动作，避免 AI 把中间步骤压缩或跳过。

## 2. AI 提示词量化约束

- `【画面描述｜直接复制】` 是最终正向提示词。它必须是一段语义完整的自然语言，不是表格碎片。
- 直接提示词必须包含：固定锚点、可见人物位置、物理关系、身体朝向/视线、道具位置、表演触发点、面部/身体反应、台词/OS/系统音的处理方式、摄影机路径、焦点落点和画面结束状态。
- 不使用含糊坐标词：写 `画面左侧道路`、`A的右手边`、`桌对面`、`镜头前景`、`背景窗口前`；不要只写 `左边/右边/前面/后面/左外`。
- 关键动作不使用含糊代词。任何人说话、移动、持有、接收、推、指、付款、签字或反应时，都要点名动作人物和道具持有人。
- 直接提示词里不要使用压缩省略语或剪辑元词：`继承`、`延续上一镜`、`上一镜`、`尾帧`、`空间保持`、`位置不变`、`画面切到`、`切到`、`反打到`、`剪辑`、`后期插入`、`脑海浮现`。相邻镜头衔接只能通过下一镜开头当前事实重写完成。
- 负面提示词必须同时包含身份/稳定基础和防僵硬词：`人物僵硬、全身静止、无眨眼、空洞呆滞眼神、面部无任何变化、肢体不动、木偶式静止、死板、定格、面部僵硬`。

## 3. 镜头调度

- 景别必须匹配动作可读性：
  - 广中景/中景：地点、动线、群体关系、全身动作或整只手动作。
  - 中近景：一个说话者加一个听者肩线/反应，可读脸部和上半身表演。
  - 近景/特写/插入：眼睛、嘴角、喉咙动作、手指、拳头、筷子、手机/银行卡/餐盘归属。
- 当镜头依赖细微脸部、手部或道具微动作时，禁止使用距离过远的固定镜头；除非画面已经足够近，并且固定镜头明确服务于精准口型或接触动作。中景/广景里如果要读微动作，必须镜内推近/转焦，或把动作放大成整只手、肩背、身体姿态变化。
- 推荐复合镜头写法：`0.0-0.6秒关系中景锁静物和人物槽位 -> 0.6-X秒沿视线/手臂/桌面轻推0.2-0.4米或转焦一次 -> X-尾秒落到手部/眼神/道具近景并保留原空间关系`。
- 三张及以上子镜头若全部静止，必须有明确的情绪冻结、口型精度或接触精度理由；否则至少安排一次 0.2-0.5 米单向微推/微拉、一次转焦，或一个 1.2-2 秒的源文相关物件/空间缓冲。不得为了变化加入环绕或无因果摇镜。
- 人物强动作时镜头少动，镜头强运动时人物低幅。道具交接、转身、起身、走位、身体接触和长口型不要同时叠加强推、环绕或复杂侧移；只允许固定、轻推、轻拉或一次转焦。
- 快速推拉、快速横移、平稳环绕和手持抖动不是默认高级感。只有强冲突、崩溃、追逐等源文支撑时才轻量使用，并写清主体脸部稳定、低幅度和单一路径。
- 独立余波镜可以静止，但必须有静止理由：被击中者不接话、手/道具/肩线停住、距离没有被修复。若只是普通“闭口看着”，不算余波。
- 三人桌边戏：先建立同侧双人组和桌对面站立者；桌子始终是隔物；不要让站立者插入同侧坐着的两人之间。如果戏剧节拍是“别人说完后，站立者形成压力”，先给说话者口型，闭口后再把镜头落到站立者的眼神、整只手或拳头。
- 不要在 `【画面描述｜直接复制】` 里写硬切。如果需要真正的反打或插入镜头，就另开一张镜头卡，并写清新的肩后/前景构图和入镜第一帧事实。

## 4. 表演微动作

- 避免“死听者”。每个画面中重要的非说话者，都要在直接提示词里有一个由台词或动作触发的小反应，不能只写在 `表演轴`。
- 避免“清晰木偶”。多人戏里，凡是清晰入画的具名人物，都必须被分配为主表演者、受击反应者、观察反应者或背景弱化者。背景弱化者只能边缘/后景/弱虚化；如果人物清晰可见，就至少写闭口、视线方向、呼吸/眨眼或一项低幅身体/手部反应。
- 一条镜头不要让所有人都做明显动作。安全分配是：一个主表演者 + 一个明显反应者 + 其他人低幅活体状态。若三人以上都需要可读表情，拆成关系镜头和反应镜头。
- 对白镜头先保口型，再安排听者。听者反应不要和说话者关键口型同时抢焦：开口前先锁位，关键词后或句末再给一个听者低幅反应，下一位说话者开口前必须看到上一位闭口。
- 说话者是主任务；听者反应保持低幅度，不抢焦点。听者默认反应：视线跟随说话人、自然慢眨眼、眉/嘴/肩轻微变化、手搭在桌面或道具上做小动作。
- 必要时量化听者动作：头部转动 5-10 度，身体/肩膀偏移不超过 15 度，单个微动作持续 1.2-2.5 秒；不要大幅重复动作，不要循环抖动，除非原文明确需要。
- 桌边听者动作库：`视线缓慢跟随说话人`、`自然眨眼`、`手掌轻搭餐盘边`、`整只手离开筷子旁`、`肩背轻僵/下沉`、`嘴唇轻抿`、`眉尾短暂收紧后松开`、`水杯端起1cm停1秒再放下`。每个节拍每个听者只选一到两个。
- 站立旁观者动作库：`脚尖轻微换重心`、`手指在身前收紧又放松`、`视线从说话者移到被说中者`、`肩线短暂停住`、`下颌轻收`、`慢眨眼后避开视线`。每人每镜只选一个，不要循环。
- 情绪必须写成“原因 -> 面部控制 -> 身体/道具动作 -> 声音语气”。示例：`听见“骗人”后，沈星雨眼神停半拍，被牵住的右手轻缩、肩背一僵；OS：“...” 疑惑低音量，画面中沈星雨闭口。`

## 5. 后期补帧与闪回过渡

- 闪回/回忆是独立生成的片段，通过后期转场衔接；不要用单条提示词要求一个地点变形成另一个地点。
- 触发/回到现实的镜头：尾部要保留 0.5-0.8 秒稳定物理把手，例如停住的视线、静止的手、停顿的呼吸/肩膀、或道具接触。
- 插入的闪回镜头：动作/对白开始前，先用 0.5-1.0 秒锁住闪回地点锚点和人物起始姿态。
- 后期桥接写在 `声音轴/剪辑衔接/校验记录`：3-5 帧白闪或短暂模糊闪，现实环境音压低，回忆环境音提前 0.2 秒进入；闪回片段可加低饱和、边缘轻暗角、轻微手持质感。
- 直接提示词可以写 `低饱和闪回质感、边缘轻暗角、轻微手持感`；不要写 `校门变成巷口`，也不要要求模型生成地点变形动画。

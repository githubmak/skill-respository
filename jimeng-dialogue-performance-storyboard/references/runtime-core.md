# 即梦分镜运行核心

本文件是常规生成的唯一常驻合同。字段与顺序只以 `output-template.md` 为准；专项风险只读取 `route_task.py` 返回的引用。任何精简、适配和局部修复都不得降低本文件的创意、审美、运镜、空间、表演或门禁要求。

## 最高优先级边界

大模型独占源文理解、剧情因果、拆镜、表演、情绪、调度、机位、运镜、焦点、光影叙事、色卡与最终提示词语言。确定性脚本只做归一化、结构和参数校验、物理/空间计算、字段对账、预算、排版、staging、哈希、审核状态与文件提升；只能返回错误事实和可行域，绝不自动选择或改写任何创意。任何后续规则与本边界冲突时，以本边界为准。

## 输入与事实

- 唯一硬必填是可完整读取的源文。先运行 `source_gate.py --source <源文> --compact --report <reports>/source-gate.json`，完整通读后冻结人物身份、台词/OS/OV/系统音及标点、事件顺序与因果、场景、道具归属、起止状态和跨场关键状态。
- 缺省风格按题材证据保守补足，画幅默认 `16:9`，Seedance 目标默认 `auto`。每镜不超过15秒；普通直接提示词硬上限500字，复杂镜头650字，只有成对关键帧保护的极少数复合镜头可到700字。多场景默认分文件。
- `both` 从同一事实合同导出2.0、2.5两份主文件和不可投喂索引。两版的镜号、时长、人物、声音原文、空间、道具和终态不变，只改变适配措辞。
- 导演选型后建立一次非投喂 `scene_contract.json`：保存源文锚点、风险向量、有人物表演镜的IR可见事实、场景级摄影机策略、逐镜摄影机设计、空间ID、不可降级视觉核心和 `tone_card`。`tone_card` 至少冻结情绪功能、主/辅/点缀色、色温、主光、阴影色、对比度/饱和度、背景亮度、肤色保护、材质锚点、允许变化和禁止偏色；可另列全局校色基线（18%中性灰、伽马、黑白位、D65/Rec.709）与影调负面。纯物件/空景写 `performance=null`，不虚构演员字段。所有非静止镜头必须追加 `camera.motion_ownership`，分别保存 `camera_path | focus_path | actor_path | prop_path | terminal_state`，无转焦、无人物动作或无道具路径也显式填写。线稿、提示词、关键帧和制作控制从该合同派生；合同只冻结导演已经选定的演法、构图、影调和摄影机收益，不能替导演做选择。
- 有人物表演的 performance IR 不得停在情绪标签：至少冻结 `情绪触发 -> 关系目标 -> 对外策略 -> 身体/道具泄露 -> 唯一听者策略变化 -> 句末残留`；每一环都要能被当前景别看见。缺任何一环，返回导演选型，不用“紧张/愤怒/微皱眉/抬眼”补字数。
- 多镜场景不得全篇固定/静止；两镜以上至少有一处由人物、道具、声音或信息触发的运镜。三镜以上至少形成两种景别和两种观众位置/运动机制，除非源文明确是单一观察实验且仍有不同视觉任务；若只是补字段或机械微推，返回重新选型。
- 直接提示词不能把内部术语当成 Seedance 事实，例如 `朝关系轴拍摄、空间锁定、状态继承、氛围光、情绪光`；必须翻译成摄影机所在侧、真实拍摄方向、固定物/人物位置、光源与受光面、当前第一帧和可见终态。

## 创意与审美

创意最小通过线独立于工程门禁：每个子镜头必须能从直接提示词还原第一焦点、一个源文专属关系/因果、一个光影叙事职责、摄影机对表演或关系的服务，以及一个可继承结束余像。缺任一项先回导演选型，不得用制作控制或校验句补写。

1. 先建立内部导演上限合同：`整场压力曲线 | 观众立场与信息顺序 | 主要人物目标/阻碍/保护对象/对外策略/策略转折/行为签名演变 | 基础/峰值有因变化/结束光态 | 演员调度与摄影机响应 | 场景视觉母题 | 五秒画面余像 | 主动拒绝的俗套`。行为签名按源文证据写 `常态动作 -> 压力下变形 -> 峰值破例或坚持的代价 -> 结束残留`；没有依据时允许保持，不虚构爆发、奇观或动态光。
2. 创作档位控制候选数量而非质量：场景方向为 `fast=1/balanced=2/director=3`；只在拒绝、承认、隐瞒暴露、保护、发现或关系重定义等关键表演转折运行表演候选赛，数量为 `fast=2/balanced=3/director=4`。普通对白只执行轻量内核，不扩张候选。
3. 表演候选先于机位设计。每个候选都写 `台词意图 -> 对外策略 -> 身体真实倾向 -> 不受控泄露 -> 选择或压住选择的代价 -> 对手反应 -> 落幅`，并至少改变策略、泄露通道、道具/空间使用、反应时机中的两项。遮蔽候选来源后只比较潜台词可见性、人物专属性、因果可读性、当前景别可见性和结束余像；淘汰可套给无关人物的通用微表情与无因大动作，锁定唯一表演核心，不做平均拼接。
4. 再为签名镜生成空间关系、信息显露、道具/声画因果三个异质视觉候选；`balanced` 增加反默认挑战者，`director` 再增加删减/静止/留白挑战者。视觉候选必须承载已选表演核心，不能反过来改写演法。候选胜出后、风险适配前先设计场景摄影机运动弧：`观众位置 -> 各节拍视觉任务 -> 静止/运动转换 -> 强弱峰值 -> 结束观众距离`，不能逐镜独立套模板。
5. 遮蔽视觉候选来源后，只比较戏剧必要性、第一焦点、构图不可替代性、情绪证据、关系/认知收益、相邻差异和五秒余像，不比较抽卡风险。胜者未在至少两项明确领先亚军时，只重生最低分候选再比，不做平均化拼接。
6. 胜出后才做生成适配。可以拆动作、降低运动、调整时长或增加关键帧，但不得替换表演核心及胜出的关系几何、第一焦点、策略转折、情绪载体、运镜收益和结束画面；这些组成不可降级视觉核心，并在直接提示词前60%内成为可见事实。
7. 每个镜头组只完成一个新认知并承担铺垫、升压、转折、峰值、释放或缓冲之一。同场滚动五镜至少1个、目标2个签名镜；第2个只有主观看机制不同且不造成强度过载时保留。普通镜也必须有一个源文专属导演选择；去掉人名、地点和关键道具后仍可套用无关剧情时重做。

## 空间、机位与状态

1. 阻塞设计前做关系投影：`人物 -> 正在施压/保护/回避/观察谁 -> 控制的出口/道具/信息 -> 本组可见关系变化`。再分开锁定 `认知/关系/情绪`、`位置/道具物理状态`、`本镜可见表演`，三层不得互相代替。
2. 两人及以上互动先生成站位面向线稿（SVG工程图与同源PNG空间参考图），再编译正式提示词。先比较侧面关系镜、A肩后和B肩后；正反打用同一站位、两个单机位面板并保持关系轴同侧。镜头类型、机位坐标、朝向与视场均由大模型选定；脚本只校验人物姓名、固定锚点、实体障碍、边界通道、身体面向、摄影机站立空间、近肩净距、轴侧、目标遮挡、门洞通视与完整视场，失败时返回事实与可行域。
3. 关系镜逐人锁定物理槽位、身体面向目标、摄影机可见面和视线目标，并锁定摄影机物理位置、拍摄方向及轴线侧。`正面可见` 不等于 `面向镜头`；未经源文明示的 POV/口播/打破第四面墙，不允许人物直视镜头。
4. 双侧边界逐人写所在侧。穿越按 `A侧起点 -> 接触/跨越边界 -> B侧终点`；门口进入必须保留门外起点、跨门槛中间态和屋内终态。摄影机、人物侧别、身体面向、可见面和真实背景必须物理闭合。
5. 道具、衣物、人体支撑、门车门、UI或朝向变化写 `起点 -> 接触/支撑 -> 可见转换 -> 稳定终态`。一镜承担三项以上高风险任务，或人物强动作、长口型、道具转移和强运镜叠加时，先拆成准备、转换和终态/余波，再把已选摄影机收益分配到最适合的子镜；不能以固定机位掩盖过载，也不能在拆镜时丢掉场景运动弧。

## 表演、声音与运镜

- 情绪依据按 `源文明示 > 前情余波 > 当前目标/策略 > 保守推断` 取值，低优先级不得覆盖高优先级。表演按 `触发 -> 接收 -> 可见处理 -> 选择/压住选择 -> 对手反应 -> 落幅` 编译；心理标签只作内部因果，最终写当前景别可见的脸、肩背、呼吸、重心、手或道具结果。台词与身体可以有因不一致，但不能无依据反演人物态度。
- 普通对白逐镜先写内部轻量内核：`表面台词 -> 本句实际维护/争取/回避的关系 -> 角色专属行为载体 -> 唯一听者关系回应 -> 句末可继承残留`。只落成一个说话者行为和一个听者回应；至少一项绑定行为签名、可触达道具、空间边界或声音触发。策略不变时写维持它的可见代价，连续节拍不机械重复同一载体；不新增剧情、候选或输出字段。
- 每镜只设一个主表演者和必要反应层。三人以上按 `触发者 -> 第一接收者 -> 延迟理解者 -> 试图控场者 -> 关系落幅` 选择实际需要的反应传播链；每个时间窗只有一个主要反应者，其余降为低幅活体、肩线、弱虚化或画外，不让全员同时明显动作。
- 可见对白原样进入直接提示词并驱动正确人物口型。OS 写 `人物名OS：“原文”`；OV、系统音、内心独白和旁白使用对应标签，不驱动可见口型，画内人物闭口并给出可见反应。数字口型时间窗必须全时长合法覆盖；固定字速只进入 shadow 建议。
- 机位与运镜在表演核心胜出后、工程门禁前选择。先定整场观众位置与运动弧，再逐镜写 `视觉任务 -> 可见触发 -> 路径或有意静止 -> 关系/信息/距离收益 -> 稳定落幅`。静止只服务等待、压迫、观察、尴尬、僵持、留白或悬念，并用景别、角度、遮挡或焦点形成相邻差异；不得因空间连续或生成风险默认固定。横移显露关系/信息，推近增加心理压力或距离逼近，拉远制造疏离/孤立，转焦转移认知或权力，跟拍响应真实空间变化；不得用机械微推代替不同机制。运动由人物、道具、声音、遮挡或信息变化触发，并在起态与落幅之间改变遮挡、距离感、信息显露或关系压力之一；只放大主体、移动背景或制造动感的运动无效。摄影机路径、焦点转换、人物/手部动作和道具路径必须分别指定主体与终态，并写入 `camera.motion_ownership` 五字段；直接提示词也须用独立分句逐项恢复，禁止共享省略主语的“从A到B”链。运镜经过容器内道具时，明确道具全程留在原容器或表面。人物强动作时镜头少动，镜头明显移动时人物降幅。
- 光影必须来自可解释的物理光源，并承担显露、遮蔽、隔离、吸引注意或关系转折至少一种职责。反光、水光、鳞光、泪光、玻璃、金属或湿面成为焦点时，先闭合 `发光实体 -> 入射路径 -> 反射主体/表面 -> 被动材质响应 -> 与人物/环境受光面的亮度顺序 -> 保留暗部`；光源照脸不能替代它照到道具的路径，容器内部必须有暗部，不能只写“水光晃动/银白点缀”。峰值变化必须有物理触发；环境色不覆盖脸和活动手，体积光不遮五官。美感由具体构图、焦平面、受光面、材质响应和节奏差异实现，不靠空泛质量词或堆料。

## 提示词编译

1. 每个子镜头先冻结 `start_boundary`、唯一获准转换和 `end_boundary`，再建立内部 `performance_ir`：`source_anchor | relationship_goal | speaker_behavior | listener_response | end_residue | readability | camera_service`。不含人物表演的纯物件/空景只保留适用槽位。
2. 在写完整提示词前，把 IR 编译成受保护可见载荷：`关系起态 -> 台词/声音触发 -> 角色专属行为 -> 听者关系回应 -> 句末稳定残留`。前置语义门禁逐项确认源文有据、心理已转成身体/道具/距离/遮挡事实、当前景别可读、摄影机看得见表演载体、一个说话者行为与一个具名触发后的听者回应闭合、残留可进入下一镜；任一失败先改演法、景别或机位，不生成正文。
3. 载荷通过后冻结语义，不冻结措辞。围绕它合并空间、机位、光源、口型和连续性，后续压缩不得删除、替换或泛化人物专属性、触发因果、听者回应和残留。正文顺序为：`视觉场景前缀/当前事实 -> 核心关系与第一焦点 -> 构图/景别/机位/单一路径 -> 受保护可见载荷与声音 -> 一条动作或因果响应 -> 一个动机光影/材质落点 -> 最后20%稳定终态`；载荷与不可降级视觉核心在前60%内可读。
4. 压缩按 `删元说明和空泛质量词 -> 合并重复锚点/光线/机位事实 -> 缩短参数措辞 -> 拆镜` 执行，不删受保护载荷、空间拓扑、口型主体、道具归属或终态。普通镜目标200-420字且不超过500字；复杂镜超过500字必须确有不可合并的空间/表演/状态事实，最多650字；只有复杂镜且使用成对关键帧保护时可到700字，仍过载则拆镜。
5. 完稿后只读直接提示词做回译：必须能无歧义还原 `关系意图 | 角色专属行为 | 具体触发与听者回应 | 句末身体/距离/道具残留 | 景别与机位如何看清载体`，并与 IR 逐项一致；非静止镜头还必须分别还原 `摄影机路径 | 焦点路径 | 人物/手部路径 | 道具路径或不变量 | 稳定终态`。任一对象可被解释为另一条路径的运动主体，或只能从制作控制/内部合同得知其未移动时，均视为转换损失并返回编译前修复；IR、载荷和回译结论均为内部非投喂数据，不增加输出字段。
6. 完稿后运行 `scene_contract.py <contract> --storyboard <output> --strict-completeness --compact --report <reports>/contract.final.json`，机械检查具名触发、行为、回应、景别服务、`motion_ownership` 五链回收、不可降级可见事实、逐镜压缩色调前缀及结尾残留；`prompt_preflight.py` 同时阻断路径主体歧义与缺失的容器道具不变量。机械通过不能证明潜台词和人物专属性，仍由设计盲审判断。
7. 直接提示词必须独立投喂，不写 `上一镜、继承、延续、尾帧、切到、反打到`。下一镜开头重新写当前可见事实；`【状态继承】` 只压缩复写上一镜正文末段，不新增事件、位置、道具、认知或情绪。
8. 每镜只保留一个主机制、最多两个场景锚点、一个具体光影/材质落点、一个构图骨架和一条摄影机决策。摄影机决策必须是可验证的静止收益或单一路径；连续静止不能复制同一视觉任务，连续运动不能只换词不换机制。短而完整的物件、空景、蒙太奇和无台词镜不为凑字数增加人物或装饰；扩容不能掩盖任务过载。直接提示词、关键帧和 `【本镜制作控制】` 必须来自同一事实合同；制作控制不能新增另一套事实。

## 门禁与交付

1. 每生成一个子镜头就运行 `incremental_validate.py <scene_draft.md> --current-shot <shot_id> --compact --report <reports>/<shot_id>.incremental.json`，按返回的 `field/shot/pair/window` 最小范围修复；同级最多两次，仍失败才升级，禁止默认重写整场。
2. 使用当前模板保存后运行 `validate_storyboard.py --compact --report <reports>/storyboard.json --shadow-report --seedance-target <目标> <output.md>`。逐镜通过不替代完整文件、跨场、相邻镜和双版本校验；全部硬错误修复前不得交付。
3. 工程门禁通过后执行 `review-pipeline.md`。设计审美复核始终强制；有本地关键帧/视频时按档位追加真实画面复核。技术指标不能覆盖语义、空间、表演、构图、焦点、美感或运动收益失败。
4. 最终 review manifest 必须绑定源文和所有主输出哈希；任何字节变化使旧结论失效。审查或输出修订后重新运行受影响门禁，并在交付前验证 manifest。

## 不可降级检查点

- 人物、台词、因果、空间连续性、道具归属、口型和终态不因创意或适配改变。
- 创意发散先于风险适配；工程安全不能把签名镜、关系变化、美感或有效运镜降成通用拍法。
- 多人空间、双侧边界、正反打、关键帧和制作控制不得靠含糊词或元规则句通过。

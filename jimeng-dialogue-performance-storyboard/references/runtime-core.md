# 即梦分镜创作运行核心

本文件决定创作方法，不规定创意答案。结构只看 `output-template.md`；平台措辞只看 `seedance-target-adaptation.md`。脚本不能解释、评分或改写本文件中的审美要求。

## 1. 创作主权

大模型对最终画面负责。模型自行决定拆镜、时长、节奏、表演强弱、人物调度、观众位置、景别、机位、运镜、焦点、光源、影调、色卡和提示词语言。不存在必须使用的拍法、运镜次数、景别数量、签名镜配额、情绪术语或关键词。

工程层只验证可确定的交付事实。工程报告不得把“未识别到某个词”改写成“创作缺失”，也不得从提示词反向恢复情绪、机位收益、第一焦点、光影职责或其他自然语言合同。

## 2. 从原文到导演方案

完整通读原文后，在内部形成场景理解：人物此刻想得到或保护什么，阻碍来自哪里，台词表面与真实策略是否一致，信息何时交给观众，上一节拍留下什么身体和关系余波，本场结束后什么状态必须继承。把判断区分为原文事实、合理推断和导演选择；推断不能改写事实，原文故意保留真相时只确定人物当下相信什么和观众应保留的疑问。

同时建立人物的信息权限：本镜开始前各人物已经知道什么，本镜中实际能看见、听见、触碰或从既有事实推出什么。画内人物只能被可访问刺激触发；观众专享的 OS、旁白和默认 OV 不进入人物认知。画外对白、门外声、电话、广播与系统音则按真实传播范围逐镜确定获准听者，不能仅因声音写在原文里就让所有人物响应。

每场在内部压缩一条因果主线：`触发 -> 人物当下的理解或目标 -> 关系策略与可见行动 -> 对方接收和反应 -> 新的关系、信息或身体状态`。简单场景用一句话闭合后立即进入创作；只有误解、试探、隐瞒、反转、多人反应传播或复杂状态转换使其中一段难以直接转译为可见画面时，才展开那个断点，解决后停止。它不是交付字段，不生成 JSON，不逐镜重复，不要求固定节点数量，也不进行复杂度评分。

为每个主要人物建立一条场景级表演弧：入场时正在维持什么、什么触发改变、人物怎样控制或掩饰、压力从哪个身体或道具通道泄露、对方怎样接收、场末留下什么关系与身体余波。简单人物可以一句话闭合，复杂人物按真实转折展开；这是一份非投喂导演依据，不用“开心、愤怒、害怕”等标签替代行为。

先设计整场，再设计单镜：决定观众从哪里进入关系、何时靠近或疏离、什么信息值得改变观看位置、哪里应当静止、哪里应当切镜、场景如何结束。镜头运动必须有观看收益，但“没有运动”同样可以是有力选择。不要为了显得有创意堆叠移动，也不要因生成风险自动退化成安全中景。

第一版整场导演方案不接受预设总时长、平均镜长、镜头数量或动作类别比例的约束。方案成立后再沿时间线做场级节奏诊断：每个节拍分别回答观众新读到什么、人物或物理状态怎样变化、需要多少实际时间完成声音与动作并让变化被读懂、上一节拍的余波是否已经完成。诊断针对已经读懂后仍无递进的停滞，以及转折因时间不足尚未成立；不能把“快”直接当作好节奏，也不能把“慢”直接当作拖沓。

不要把动作按表面类型分成“剧情动作”和“程序动作”。做饭、行走、开门、检查、递物、收拾等过程若承担人物能力展示、证据建立、关系策略、信息遮蔽、压力泄露、悬念延迟、喜剧节拍、动作准备或结果可信度，就是剧情的一部分；只有观众已经取得相同结果，继续展示也没有新增层次时才可压缩。重复同样不自动冗余：举证升级、压力累积、失败递进、仪式感和有意延迟必须比较每次重复造成的差异。

节奏问题没有固定修订顺序。模型根据根因选择删除无收益项、缩短节拍、合并、调整信息释放、重选机位或拆镜。合并只在时空连续、观看中心一致、动作可顺序执行，并且关键对白的触发、控制、泄露、起说点、听者接收和镜尾余波仍可清楚读取时成立；合并后必须重新检查单镜容量、空间语义和 Seedance 可执行性。若合并造成多个观看中心、并发动作或主语歧义，就保持分镜或重新设计，而不是为了减少镜头数量硬塞。

候选发散是模型的自由工具，不是流水线字段。关键转折、复杂关系或普通方案明显乏力时，可比较不同表演、空间或摄影机方案；简单节拍可以直接判断。候选数量、比较维度和是否保留笔记均由模型决定。

## 3. 表演与情绪

从因果而非标签出发表演：人物通过获准通道听见、看见、触碰或认出了什么，试图维持什么关系策略，身体哪里泄露真实压力，对方何时接收到并怎样调整，句末留下什么未完成状态。把心理转译为当前景别真正看得见的脸部、呼吸、肩背、重心、手部、视线、距离或道具行为。

普通对白不需要每句都成为炫技镜头，但必须像这个人物在这个时刻说出的。优先使用角色正在接触的物件、空间边界、说话节奏和对方反应，而不是反复套用皱眉、抬眼、轻笑、握拳。多人场面安排反应先后与强弱，避免所有人同时做同幅动作。表演可克制、停顿、遮掩或留白，只要关系变化对观众可读。

动作只有在执行或准备剧情行为、改变人物/道具/空间状态、传递或遮蔽信息、体现当前关系策略或压力泄露、触发另一人物、建立连续性，或为当前转折提供明确节奏余波时才保留。删除动作后若剧情、关系、信息、情绪证据、物理连续性和观看节奏均不受损，就删除；不要用呼吸、抬眼、皱眉、握拳、无目标走动、衣摆或环境摆动填满静止画面。静止、未反应、压住反应和延迟反应都可以是准确表演。

关键对白必须闭合一条可见表演链：`触发 -> 人物控制方式 -> 情绪泄露 -> 台词状态 -> 听者反应 -> 镜尾余波`。允许自然合并和克制留白，但不能只写说话者口型，或让情绪只存在于内部分析与镜头标题。每镜只承担一个主要情绪或剧情转折；其余动作必须服务该转折，不能与它争夺观看中心。

声音原文只在直投提示的 `台词` 分句保留一次。可见对白由具名说话者驱动口型；画外对白、电话和广播不驱动画内人物口型，但可在实际传播范围内触发获准听者；OS、旁白和默认 OV 只给观众，不触发画内人物；系统音逐镜明确可听范围。内部逐条确认 `声音主体 -> 声音通道 -> 可听范围 -> 口型主体 -> 获准反应者`，再把必要时序自然写进动作或声音设计，不增加机械字段。根据内容、停顿与表演判断容量，必要时由模型拆镜。字符时长估算只提供参考，不能替模型选择拆点。

情绪不强制采用统一曲线。原文确有积蓄、临界和释放时可以这样组织；持续压抑、突然认知、喜剧错位、麻木、延迟反应、克制缓和或无释放时保留其真实形态，不补造爆发、哭泣或通用微表情。

## 4. 空间与动作

每镜都先在脑中或工程图中闭合并在最终 `主体与起态` 独立重述一个最小充分空间集：当前空间区域、会影响本镜读取的固定物或边界、摄影机相对固定物的位置和拍摄方向、实际可见背景、人物物理位置、姿态支撑、持物和接触。不要把整间房的固定物清单搬进每个镜头；画外且不影响执行的事实留在连续性台账。双人/多人互动、单人面对人物或物体、门槛、桌边、窄空间、道具交接或越界场面，再完整说明身体面向、头部/脸部方向、具体视线落点、可见/不可见面和前后遮挡。上一镜相同不构成省略理由，但允许删去不会改变当前观看与执行的冗余描述；`正面可见` 只描述摄影机看到的面，不等于人物面向摄影机。

动作按可见状态变化设计：起态、接触或发力、转换、稳定终态。道具始终有持有人、承载面或容器；容器内物体若没有被拿起，就明确保持在容器内，而不是用“不要飞走”强化错误概念。复杂动作可拆分，但拆分位置由叙事与表演决定。

时长按并行时间线计算，不把所有元素串行相加：分别估算 `声音轨`、`人物表演/动作轨`、`摄影机/焦点轨` 的实际持续时间，以三者最长值作为基础时长；再追加只有在前一事件完成后才能开始、且不能被任何轨道覆盖的必要串行动作。听者可以在台词进行中逐步接收并产生细微反应，摄影机和转焦可以随表演同步，OS/OV 可以覆盖劳动与环境动作，这些并行内容不得重复加时。若有实测配音，以实测声音时长为声音轨依据；没有实测音频时，根据人物、情绪、语气和停顿判断，不用统一字符速度迫使所有角色慢读。

得到 `max(声音轨, 人物表演/动作轨, 摄影机/焦点轨) + 不可重叠串行动作` 后，在镜尾保留约 `1s` 自然留白，用于动作落稳、情绪余波或剪辑接点。这里的“约”允许按当前节奏轻微缩放；若最长轨道末端已经包含台词尾势、动作落稳、余波或转场，该部分直接计入这约 `1s`，不能再次叠加。`稳定终态` 是可继承、可验证的画面状态，不是另一个耗时项目，也不因字段存在自动加时。

空间图只是几何辅助。站位、面向、机位和焦段由模型选择；脚本只能计算碰撞、净距、遮挡、轴侧、视场和路径是否越过实体。几何 PASS 不等于构图、美术或成片 PASS。

## 5. 摄影机、焦点与 Seedance 语义

每镜先确定观众看到的起始画面和结束画面，再决定是否需要摄影机变化。内部用 `起幅 -> 触发 -> 观众新增读取 -> 落幅` 检查运动收益；新增读取可以是信息、关系、权力、距离、空间、动作证据或情绪余波。用可见参照描述摄影机起幅、触发、路径、速度感和落幅；“左/右”说明是按最终画面还是场景实体参照。删除运动后观看结果不变时通常删去或重选，静止足够时保持静止；运动确有收益时也不能只因生成风险退化。不要只给米数、角度或“保持关系轴同侧”这种平台可能不理解的内部术语。

凡是摄影机、焦点、人物/手部和道具同时出现，分别使用具名主语。多人或多人可见互动镜中，动作时间线和稳定结尾也禁止用父亲、母亲、孩子、她、他等代称承载动作归属；只有源文台词中的称谓可以原样保留：

- `摄影机……` 只描述机位和镜头路径。
- `焦点……` 只描述对焦主体与转焦时机。
- `[人物/手部]……` 只描述演员动作与终态。
- `[道具]……` 只描述道具是否移动、由谁承载及终态。

只写实际发生的路径，不为“不动”对象填充机械字段。不要写“摄影机跟随手指从证物落到听者脸”；这会让路径主语和终点归属混乱。应分别明确摄影机怎样移动、焦点何时从证物转到听者、手指停在哪里、证物是否保持在原承载面。

按时间顺序组织表演：开局状态，触发，人物控制与泄露，台词起说点，演说中的状态，听者接收与反应，摄影机或焦点变化，稳定余波。逐镜审查长台词、精细手部、道具转移、多人反应、摄影机运动、转焦和光影变化是否形成多个独立观看中心或无法在时长内顺序执行；超出信息与动作预算时根据根因选择删去无关空间冗余或无收益设计、拆镜、重选机位或调整时序，不设固定顺序，不删情绪链、台词起说点或听者反应，不省略每镜空间起态。该判断不统计提示词字符数。

## 6. 视觉连续性

每场都要有完整的视觉意图，但表达精度由场景决定。先从时间、天气、空间开口、真实发光体、遮挡、表面材质和人物肤色建立物理证据，再确定主色、辅助色或材质色的关系，主光来源与方向，辅助光的来源，受光区域、阴影层次、背景亮度、肤色保护、材质响应和允许的有因变化。不能把“氛围光”“情绪光”当成物理光源，也不能让冷暖形容彼此矛盾而不说明分别属于哪个区域。

光影服务叙事：决定观众先看见谁、关系距离如何被分隔、动作证据是否可读、终态是否稳定。人物肤色保持中性不等于整张脸均匀补亮；可以保留鼻侧、下颌与背光侧阴影。色卡应统一场景而非把画面压成单色，可用环境材质和小面积点缀色建立层次。悲伤不自动等于蓝、亲密不自动等于暖、危险不自动等于红；颜色只能强化已有的物理环境和观看重点，不能代替人物选择与表演。

在内部建立不对外输出编号的场景视觉连续性笔记：锁定真实光源实体与方向、主辅光层级、色彩及材质落点、白平衡、饱和度、对比度、黑位、高光、背景亮度、肤色基准、不可漂移项和允许变化的物理触发。它是跨镜审片基线，不直接替代单镜提示，也不写入正式 Markdown。

逐镜需要视觉控制时，把色卡、影调和光影合并为一个 `视觉控制` 句。句子必须直接复述本镜可见的场景基线，不能写“同前”、`VC-Sn` 或其他内部编号。无物理变化时只改变构图内可见受光区域，不改光源方向、冷暖归属、综合色彩或曝光基准；换机位造成可见面改变不等于换光。

只有时间、光源、门窗遮挡、天气、空间或明确主观视觉层发生变化时才改基线，并写清触发、时机、影响区域、保持不变项和尾帧新稳定态。单镜使用已审核视觉参考且文字不再增加控制价值时可以省略视觉句；普通独立文本生成通常应写，因为 Seedance 看不到场景总表。

## 7. 自审与停止条件

成稿前由模型阅读源文、事实连续性台账和整场分镜，判断：不依赖内部因果笔记时，能否从最终直投提示反向读出每镜唯一主要转折，以及关键对白的触发、人物控制方式、情绪泄露、台词状态、获准听者反应和镜尾余波；原文故意保留的疑问是否仍是疑问；全部声音是否完整且通道、口型、可听范围正确；人物是否只响应可访问刺激；人物行为是否专属于当前关系；每个动作删除后是否会损失剧情、关系、信息、情绪证据、连续性或节奏；动作是否可执行；每镜空间起态能否独立还原空间区域、固定物/边界、摄影机位置与方向、可见背景、人物槽位、支撑和道具归属；摄影机变化是否让观众新增读到内容；逐镜视觉控制是否有物理证据并能独立生成；Seedance 是否会误认主语、先后、参照系、容器归属或焦点终点。然后从整场时间线复核重复是否每次递进、过程是否仍产生新意义、必要蓄力与余波是否完整、无变化段是否在观众读懂后仍停滞，以及每镜是否按并行轨道取最长值、只追加不可重叠动作并统一保留约 `1s` 自然留白；不要用总秒数、平均镜长、镜头数量、动作类别或提示词字符数代替这些判断。

发现创意问题时回到对应导演决定，不用关键词补写。两次修改仍围绕同一句补限定词，说明问题通常在原文理解、拆镜、动作预算、机位或信息顺序，应重选结构。因果可从画面还原、连续性闭合、直投语义独立且工程事实通过后立即停止，不继续扩写内部分析或另起一套方案。工程校验通过不代表创作通过；模型设计审片和真实画面审片才决定质量。

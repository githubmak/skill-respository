# 即梦分镜运行核心

本文件是常规生成的唯一常驻合同。字段与顺序只以 `output-template.md` 为准；专项风险只读取 `route_task.py` 返回的引用。任何精简、适配和局部修复都不得降低本文件的创意、审美、运镜、空间、表演或门禁要求。

## 输入与事实

- 唯一硬必填是可完整读取的源文。先运行 `source_gate.py`，完整通读后冻结人物身份、台词/OS/OV/系统音及标点、事件顺序与因果、场景、道具归属、起止状态和跨场关键状态。
- 缺省风格按题材证据保守补足，画幅默认 `16:9`，Seedance 目标默认 `auto`。每镜不超过15秒，直接提示词不超过500个中文字符；多场景默认分文件。
- `both` 从同一事实合同导出2.0、2.5两份主文件和不可投喂索引。两版的镜号、时长、人物、声音原文、空间、道具和终态不变，只改变适配措辞。

## 创意与审美

1. 先建立内部导演上限合同：`整场压力曲线 | 观众立场与信息顺序 | 主要人物目标/阻碍/保护对象/对外策略/策略转折/行为签名 | 基础/峰值有因变化/结束光态 | 演员调度与摄影机响应 | 场景视觉母题 | 五秒画面余像 | 主动拒绝的俗套`。没有源文支持的剧情、爆发、奇观或动态光不得虚构。
2. 创作档位控制候选数量而非质量：`fast` 一套完整方向；`balanced` 两套明显不同方向；`director` 三套方向并提高比较强度。每个签名镜先生成空间关系、信息显露、道具/声画因果三个异质候选；`balanced` 增加反默认挑战者，`director` 再增加删减/静止/留白挑战者。
3. 遮蔽候选来源后再淘汰，不做平均化拼接。第一阶段只比较戏剧必要性、潜台词可见性、第一焦点、构图不可替代性、情绪证据、关系/认知收益、相邻差异和五秒余像，不比较抽卡风险。胜者未在至少两项明确领先亚军时，只重生最低分候选再比。
4. 胜出后才做生成适配。可以拆动作、降低运动、调整时长或增加关键帧，但不得替换胜出的关系几何、第一焦点、策略转折、情绪载体、运镜收益和结束画面；这些组成不可降级视觉核心，并在直接提示词前60%内成为可见事实。
5. 每个镜头组只完成一个新认知并承担铺垫、升压、转折、峰值、释放或缓冲之一。同场滚动五镜至少1个、目标2个签名镜；第2个只有主观看机制不同且不造成强度过载时保留。普通镜也必须有一个源文专属导演选择；去掉人名、地点和关键道具后仍可套用无关剧情时重做。

## 空间、机位与状态

1. 阻塞设计前做关系投影：`人物 -> 正在施压/保护/回避/观察谁 -> 控制的出口/道具/信息 -> 本组可见关系变化`。再分开锁定 `认知/关系/情绪`、`位置/道具物理状态`、`本镜可见表演`，三层不得互相代替。
2. 两人及以上互动先生成站位面向线稿，再编译正式提示词。先比较侧面关系镜、A肩后和B肩后；正反打用同一站位、两个单机位面板并保持关系轴同侧。人物姓名、固定锚点、边界两侧、身体面向、摄影机方向与完整视场必须通过渲染器校验。
3. 关系镜逐人锁定物理槽位、身体面向目标、摄影机可见面和视线目标，并锁定摄影机物理位置、拍摄方向及轴线侧。`正面可见` 不等于 `面向镜头`；未经源文明示的 POV/口播/打破第四面墙，不允许人物直视镜头。
4. 双侧边界逐人写所在侧。穿越按 `A侧起点 -> 接触/跨越边界 -> B侧终点`；门口进入必须保留门外起点、跨门槛中间态和屋内终态。摄影机、人物侧别、身体面向、可见面和真实背景必须物理闭合。
5. 道具、衣物、人体支撑、门车门、UI或朝向变化写 `起点 -> 接触/支撑 -> 可见转换 -> 稳定终态`。一镜承担三项以上高风险任务，或人物强动作、长口型、道具转移和强运镜叠加时，拆成准备、转换和终态/余波。

## 表演、声音与运镜

- 情绪依据按 `源文明示 > 前情余波 > 当前目标/策略 > 保守推断` 取值，低优先级不得覆盖高优先级。表演按 `触发 -> 接收 -> 可见处理 -> 选择/压住选择 -> 对手反应 -> 落幅` 编译；心理标签只作内部因果，最终写当前景别可见的脸、肩背、呼吸、重心、手或道具结果。
- 每镜只设一个主表演者和必要反应层。清晰听者必须闭口并有由台词/声音触发的低幅反应；无反应容量者降为肩线、弱虚化或画外。连续节拍不得机械重复皱眉、抬眼、握紧、眨眼或同一种微推。
- 可见对白原样进入直接提示词并驱动正确人物口型。OS 写 `人物名OS：“原文”`；OV、系统音、内心独白和旁白使用对应标签，不驱动可见口型，画内人物闭口并给出可见反应。数字口型时间窗必须全时长合法覆盖；固定字速只进入 shadow 建议。
- 运镜必须由人物、道具、声音、遮挡或信息变化触发，并在起态与落幅之间改变遮挡、距离感、信息显露或关系压力之一。只放大主体、移动背景或制造动感的运动无效；改为有构图目的的固定镜或重新设计调度。人物强动作时镜头少动，镜头明显移动时人物降幅。
- 光影必须来自可解释的物理光源，并承担显露、遮蔽、隔离、吸引注意或关系转折至少一种职责。峰值变化必须有物理触发；环境色不覆盖脸和活动手，体积光不遮五官。美感由具体构图、焦平面、受光面、材质响应和节奏差异实现，不靠空泛质量词或堆料。

## 提示词编译

1. 每个子镜头先冻结 `start_boundary`、唯一获准转换和 `end_boundary`。正文顺序为：`视觉场景前缀/当前事实 -> 核心关系与第一焦点 -> 构图/景别/机位/单一路径 -> 触发与表演/声音 -> 一条动作或因果响应 -> 一个动机光影/材质落点 -> 最后20%稳定终态`。
2. 直接提示词必须独立投喂，不写 `上一镜、继承、延续、尾帧、切到、反打到`。下一镜开头重新写当前可见事实；`【状态继承】` 只压缩复写上一镜正文末段，不新增事件、位置、道具、认知或情绪。
3. 每镜只保留一个主机制、最多两个场景锚点、一个具体光影/材质落点、一个构图骨架和固定理由或单一路径。短而完整的物件、空景、蒙太奇和无台词镜不为凑字数增加人物或装饰；高风险镜超过容量时拆镜，不用更长提示词掩盖。
4. 直接提示词、关键帧和 `【本镜制作控制】` 必须来自同一事实合同。制作控制只能解释已有可见结果和降级策略，不能新增主体、焦点、光源、运镜、表演、道具、支撑、人数或终态。

## 门禁与交付

1. 每生成一个子镜头就运行 `incremental_validate.py`，按返回的 `field/shot/pair/window` 最小范围修复；同级最多两次，仍失败才升级，禁止默认重写整场。
2. 使用当前模板保存后运行 `validate_storyboard.py --shadow-report --seedance-target <目标>`。逐镜通过不替代完整文件、跨场、相邻镜和双版本校验；全部硬错误修复前不得交付。
3. 工程门禁通过后执行 `review-pipeline.md`。设计审美复核始终强制；有本地关键帧/视频时按档位追加真实画面复核。技术指标不能覆盖语义、空间、表演、构图、焦点、美感或运动收益失败。
4. 最终 review manifest 必须绑定源文和所有主输出哈希；任何字节变化使旧结论失效。审查或输出修订后重新运行受影响门禁，并在交付前验证 manifest。

## 不可降级检查点

- 人物、台词、因果、空间连续性、道具归属、口型和终态不因创意或适配改变。
- 创意发散先于风险适配；工程安全不能把签名镜、关系变化、美感或有效运镜降成通用拍法。
- 多人空间、双侧边界、正反打、关键帧和制作控制不得靠含糊词或元规则句通过。
- 设计复核与真实画面复核是独立状态；`visual_review=NOT_RUN` 不等于通过，`self_check` 不得声称独立。

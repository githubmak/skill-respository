# 即梦分镜运行核心

本文件是常规生成的最小执行胶囊；最终字段与顺序只以 `output-template.md` 为准。源文命中专项风险时，按
`scripts/route_task.py` 返回的 `read_on_demand` 追加引用，不预读整个资料库。

## 输入与兼容

- 唯一硬必填是可完整读取的源文。先运行 `source_gate.py`，完整通读后冻结场景清单、人物/声音/表演基线、空间ID、影调、道具归属和跨场状态。
- 原样保留台词、OS、OV、系统音、内心独白及标点，不改人物、顺序、因果和结局。缺省风格按源文保守补足，画幅默认 `16:9`，Seedance 目标默认 `auto`。
- 每镜不超过15秒，直接提示词不超过500个中文字符。多场景默认分文件；`both` 从同一事实合同导出2.0、2.5两份主文件和不可投喂的索引，两版只改变适配措辞。

## 生成顺序

1. 先建内部导演上限合同：整场压力曲线；主要人物的目标、阻碍、掩饰策略、策略转折和行为签名；基础/峰值/结束光态；观众信息顺序；演员调度与摄影机响应；五秒画面余像。没有源文支持的反转、爆发或动态光不虚构。
2. 每个镜头组只完成一个新认知并落在压力曲线的铺垫、升压、转折、峰值、释放或缓冲。同场任意连续 5 个子镜头至少 1 个、目标 2 个签名镜；第 2 个必须改变主观看机制。
3. 普通镜按创作档位生成 1/2/3 个微方案。签名镜先生成空间关系、信息显露、道具/声画因果三个候选；`balanced` 增加反默认挑战者，`director` 再增加删减挑战者。遮蔽候选来源后按戏剧必要性、潜台词可见性、构图必要性、画面余像和关系收益淘汰；胜者未在至少两项领先亚军时，重生最低分候选，不混合平均。
4. 内部锁定空间、状态、镜头、表演四系统。双侧边界建立 `边界ID/A侧/B侧/摄影机侧/拍摄方向/人物侧/穿越链`。签名镜另锁定七项合同；关系/认知变化必须进入直接提示词，不可降级核心必须在全文前60%内完成。
5. 直接提示词按此顺序自然写成：`视觉场景前缀 -> 核心关系画面/第一焦点 -> 人物策略的可见行为 -> 构图与机位/演员-摄影机因果 -> 有叙事职责的光影材质 -> 声音与必要响应 -> 最后20%稳定终态`。工程适配不能删除策略转折、关系几何、情绪载体和结束画面。
6. 每生成一镜就写入临时场景草稿，并运行 `incremental_validate.py <草稿> --current-shot <镜号>`。`field/shot` 只修当前字段或当前镜；`pair/window` 只修返回的镜头对或三镜窗口。最多局部修复两次，仍失败才升级一级范围，不默认重写整场。
7. 使用当前模板保存，运行 `validate_storyboard.py --shadow-report --seedance-target <目标>`。逐镜通过不能替代最终完整文件、跨场和双版本校验；修完全部硬错误再交付。

## 不可降级项

- 可见对白驱动正确人物口型，开口前锁位、句末闭口；OS/OV/系统音写成 `标签：“原文”`，不驱动可见口型，画内人物闭口并给出受声音触发的反应。系统音是非实体声源，不计入可见人数。
- 下一镜开头重写当前可见事实；直接提示词不写“上一镜、继承、尾帧、切到”。
- 道具/衣物/门车门/支撑/UI变化写起点、接触或支撑、可见转换、稳定终态。画外人物只绑定画外方向，不写成可见目标。
- 负向具体视觉概念先改写为目标身份、服装、地点、道具事实，避免把坏相写进正向提示词。操作型手机屏幕朝使用者，镜头只见背面或斜侧；具体文字默认后期叠加。
- 人物镜末段锁定人数和槽位、脸手腿边界、道具归属、支撑接触、摄影机终点和曝光；不新增或复制人物。光影必须写成 `当前时段 + 物理实体承担主光 + 方向 + 接收面 + 结果`，实体可来自任意题材，不要求命中预置光源名；环境色不覆盖脸与活动手。
- 五个基础字段和制作质量信息始终保留；可选字段只在降低真实风险时添加，不输出空字段，不用机械句凑校验。
- 只有签名镜在现有 `画面质感` 行追加七项签名合同，不新增字段；第一眼焦点、情绪载体和不可降级核心必须已进入直接提示词。设计复核只看直接提示词和相邻镜做盲描述，再对照合同，不能把自我标注当成质量证据。

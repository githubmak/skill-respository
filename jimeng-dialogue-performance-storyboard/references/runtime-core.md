# 即梦分镜创作运行核心

本文件决定创作方法，不规定创意答案。结构只看 `output-template.md`；平台措辞只看 `seedance-target-adaptation.md`。脚本不能解释、评分或改写本文件中的审美要求。

## 1. 创作主权

大模型对最终画面负责。模型自行决定拆镜、时长、节奏、表演强弱、人物调度、观众位置、景别、机位、运镜、焦点、光源、影调、色卡和提示词语言。不存在必须使用的拍法、运镜次数、景别数量、签名镜配额、情绪术语或关键词。

把流程分成三种权限而不是三套模板：原文事实决定什么不能改变，导演设计决定观众怎样经历这场戏，Seedance 翻译只决定哪些事实需要显式控制、哪些补间可交给模型。必须先完成自由导演设计，再做执行收敛；后两层不得用稳定性、示例格式或审查偏好反向替换前一层的创意选择。允许一个成立的镜头极简、静止、留白，也允许它复杂、连续、反常规，只要主视觉中心、因果和容量成立。

工程层只验证可确定的交付事实。工程报告不得把“未识别到某个词”改写成“创作缺失”，也不得从提示词反向恢复情绪、机位收益、第一焦点、光影职责或其他自然语言合同。

## 2. 从原文到导演方案

完整通读原文后，在内部形成场景理解：人物此刻想得到或保护什么，阻碍来自哪里，台词表面与真实策略是否一致，信息何时交给观众，上一节拍留下什么身体和关系余波，本场结束后什么状态必须继承。把判断区分为原文事实、合理推断和导演选择；推断不能改写事实，原文故意保留真相时只确定人物当下相信什么和观众应保留的疑问。

同时建立人物的信息权限：本镜开始前各人物已经知道什么，本镜中实际能看见、听见、触碰或从既有事实推出什么。画内人物只能被可访问刺激触发；观众专享的 OS、旁白和默认 OV 不进入人物认知。画外对白、门外声、电话、广播与系统音则按真实传播范围逐镜确定获准听者，不能仅因声音写在原文里就让所有人物响应。

每场在内部压缩一条因果主线：`触发 -> 人物当下的理解或目标 -> 关系策略与可见行动 -> 对方接收和反应 -> 新的关系、信息或身体状态`。简单场景用一句话闭合后立即进入创作；只有误解、试探、隐瞒、反转、多人反应传播或复杂状态转换使其中一段难以直接转译为可见画面时，才展开那个断点，解决后停止。它不是交付字段，不生成 JSON，不逐镜重复，不要求固定节点数量，也不进行复杂度评分。

为每个主要人物建立一条场景级表演弧：入场时正在维持什么、什么触发改变、人物怎样控制或掩饰、压力从哪个身体或道具通道泄露、对方怎样接收、场末留下什么关系与身体余波。简单人物可以一句话闭合，复杂人物按真实转折展开；这是一份只写入审片报告的导演依据，不用“开心、愤怒、害怕”等标签替代行为。

先设计整场，再设计单镜：决定观众从哪里进入关系、何时靠近或疏离、什么信息值得改变观看位置、哪里应当静止、哪里应当切镜、场景如何结束。事实与表演可读后，再做一轮轻量视觉提升：为关键关系、证据、空间压力或情绪余波选择更有辨识度的构图、遮挡、景别、焦点或运动，并为真实光源和材质找到能形成层次的受光面与留白。镜头运动必须有观看收益，但“没有运动”同样可以是有力选择；不要为了显得有创意堆叠移动，也不要因生成风险自动退化成安全中景。任何提升都必须能回到原文事实、已建立的物理状态、人物可访问信息或真实场景光源，不能改写事件顺序、人物位置、道具归属、关系轴或人物认知。

导演方案中先建立一份内部情绪节拍表：逐镜记录节拍功能、1-5 相对强度、压力来源、释放或悬置方式和镜尾余波。数字只帮助肉眼识别平铺，不直接投喂 Seedance，也不驱动脚本自动改镜。连续数镜强度相近时判断它们是在有效累积、喜剧递进或有意压抑，还是已经停滞；高强度后判断是否需要停顿、静止、空位、环境余响或景别拉开作为呼吸。原文没有释放或钩子时不补造波形。

让时长、景别和摄影机响应同一节拍功能：需要发酵的对峙、压抑和判断通常允许较长读取，突发冲击和明确结果通常更短促，过渡和空间重定位以看懂为止；具体时长仍由声音、动作和摄影机三轨决定。关系与路径尚未建立时使用全/中全景，互动和物品动作使用中景，情绪或证据需要精确读取时才收近；压力升级可以收紧或推进，情绪回落可以拉开或保持空位。不能把这些对应关系变成固定时长表、景别配额或运镜字典。

第一版整场导演方案不接受预设总时长、平均镜长、镜头数量或动作类别比例的约束。方案成立后再沿时间线做场级节奏诊断：每个节拍分别回答观众新读到什么、人物或物理状态怎样变化、需要多少实际时间完成声音与动作并让变化被读懂、上一节拍的余波是否已经完成。诊断针对已经读懂后仍无递进的停滞，以及转折因时间不足尚未成立；不能把“快”直接当作好节奏，也不能把“慢”直接当作拖沓。

不要把动作按表面类型分成“剧情动作”和“程序动作”。做饭、行走、开门、检查、递物、收拾等过程若承担人物能力展示、证据建立、关系策略、信息遮蔽、压力泄露、悬念延迟、喜剧节拍、动作准备或结果可信度，就是剧情的一部分；只有观众已经取得相同结果，继续展示也没有新增层次时才可压缩。重复同样不自动冗余：举证升级、压力累积、失败递进、仪式感和有意延迟必须比较每次重复造成的差异。

节奏问题没有固定修订顺序。模型根据根因选择删除无收益项、缩短节拍、合并、调整信息释放、重选机位或拆镜。合并只在时空连续、观看中心一致、动作可顺序执行，并且关键对白的触发、控制、泄露、起说点、听者接收和镜尾余波仍可清楚读取时成立；合并后必须重新检查单镜容量、空间语义和 Seedance 可执行性。若合并造成多个观看中心、并发动作或主语歧义，就保持分镜或重新设计，而不是为了减少镜头数量硬塞。

候选发散是模型的自由工具，不是流水线字段。关键转折、复杂关系或普通方案明显乏力时，可比较不同表演、空间或摄影机方案；简单节拍可以直接判断。候选数量、比较维度和是否保留笔记均由模型决定。

## 3. 表演与情绪

从因果而非标签出发表演：人物通过获准通道听见、看见、触碰或认出了什么，试图维持什么关系策略，身体哪里泄露真实压力，对方何时接收到并怎样调整，句末留下什么未完成状态。把心理转译为当前景别真正看得见的脸部、呼吸、肩背、重心、手部、视线、距离或道具行为。

### Seedance 情绪翻译协议

Seedance 不会可靠读取“尴尬、委屈、警惕、愤怒”等心理标签，也不会自动从上一镜推导本镜刺激。每个需要承载情绪变化的镜头，先在 `动作时间线` 中用一句短前因复述当前人物刚刚实际看见、听见、触碰或确认的刺激，再写可见的时序反应和最终落态：

`前因/触发 -> 躯干与肩颈、呼吸 -> 必要手部或支撑变化 -> 视线目标与移动 -> 面部肌肉/眼睫/眼眶 -> 嘴唇与口型 -> 稳定落态`

这是翻译优先级，不是逐项字段或每镜动作清单。普通镜只保留其中真正改变观众读取的两到四个节点；近景、强情绪、交接、遮挡、转身或已出现表演漂移时，才增加眼睫、眼眶、嘴唇等细节。身体姿态、视线和道具结果优先于泪水或面部形容词；“泪流满面”“痛苦万分”不能替代可见落点。触发必须先于反应出现，避免无因瞬间变脸；允许短暂静止或停顿，但只有它承担判断、压制或情绪累积时才写入。镜头结尾必须写人物仍保持的姿态、视线、接触/承载和可见面，作为下一镜可继承的情绪物理状态。

双人镜中分别确认“谁的什么行为触发了谁”，再让受刺激者按同一时序反应；不要让两人同时无因变脸或同时完成同幅动作。人物的表演应是克制写实：肩背、呼吸、手部控制、视线回避/锁定和嘴唇状态承担主要压力，眼眶湿润、眼睫颤动等微表情只在确有情绪证据时加入。

### 多人场面的生命力

多人镜先分配 `主行动者、直接接收者、关系见证者、纯背景人物`，再设计反应，不按人物数量平均分配动作。主行动者承担单镜核心动作弧；直接接收者在刺激抵达后给出最能改变关系读取的一次主要反应；关系见证者保留能证明立场、权力或群体压力的低强度反应；纯背景人物只维持符合身份的自然行为，不抢主视觉中心。

非主要人物不能因为“降低抽卡”被统一写成全程冻结。可以让其目光跟随、动作停在手中物上、重心略改、后退半步、交换一次视线、继续压住反应或保持原任务，但每个反应必须由可访问刺激驱动，并且强弱、时机和方向不同。静止只有在人物被震住、刻意审视、拒绝回应、维持权力或尚未理解时才是表演。不要让所有人同时转头、同时皱眉、同时后退，也不要为了“活”给每个人安排独立动作线；次要反应必须在不争夺主视觉中心的前提下给主转折提供关系证据。

双向反馈不等于无限往返。只保留完成本镜关系变化所需的最短闭环：A 的行动触发 B，B 的可见反应使 A 的策略保持、改变或暴露，镜尾留下新关系。删除任何一端后关系仍完全相同，说明该反应可以交给自然补间或删除。

OS、旁白和默认 OV 只对观众可见，不让画内人物因 OS 自动响应。OS 播放期间默认减少与心理读取竞争的大幅转身、复杂交接和多主体动作，但若原文明确要求奔跑、劳动或其他连续行为，保留该行为并让身体轨道与 OS 并行，不凭“情绪细节”擅自改写剧情。

普通对白不需要每句都成为炫技镜头，但必须像这个人物在这个时刻说出的。优先使用角色正在接触的物件、空间边界、说话节奏和对方反应，而不是反复套用皱眉、抬眼、轻笑、握拳。多人场面安排反应先后与强弱，避免所有人同时做同幅动作。表演可克制、停顿、遮掩或留白，只要关系变化对观众可读。

动作只有在执行或准备剧情行为、改变人物/道具/空间状态、传递或遮蔽信息、体现当前关系策略或压力泄露、触发另一人物、建立连续性，或为当前转折提供明确节奏余波时才保留。删除动作后若剧情、关系、信息、情绪证据、物理连续性和观看节奏均不受损，就删除；不要用呼吸、抬眼、皱眉、握拳、无目标走动、衣摆或环境摆动填满静止画面。静止、未反应、压住反应和延迟反应都可以是准确表演。

关键对白在导演理解中闭合 `触发、人物策略、情绪泄露、听者关键反应、镜尾余波`，但正式提示只显式写最有表现价值或最容易误读的节点。普通连续对白不逐句指定闭口、接收、转眼和口型交接；抢话、多人传播、OS/OV、电话、画外声或权限易错时再展开。每镜保持一个主导观看任务，次级反应与余波自然从属于主转折。

声音原文只在直投提示的 `台词` 分句保留一次。可见对白由具名说话者驱动口型；画外对白、电话和广播不驱动画内人物口型，但可在实际传播范围内触发获准听者；OS、旁白和默认 OV 只给观众，不触发画内人物；系统音逐镜明确可听范围。内部逐条确认 `声音主体 -> 声音通道 -> 可听范围 -> 口型主体 -> 获准反应者`，再把必要时序自然写进动作或声音设计，不增加机械字段。根据内容、停顿与表演判断容量，必要时由模型拆镜，不用字符数推导语速或阻断交付。

执行翻译采用“低控制密度、足够不误解”。只锁原文事实、人物身份、易误读空间、决定性台词或动作、关键作用和剧情结果；自然肢体协调、目光微调、惯性、衣发与次级运动交给模型。保留能让镜头专属于当前人物和场景的一两个强导演证据，如关系距离、动作气质、空间压力、光影材质或声音节奏，不要求每项同时出现，也不把释放出的预算重新填满。

不要用项目级负面前缀封锁模型演绎。禁止把“只执行明确动作、其余人物不动、不新增任何表情/肢体/镜头运动”作为通用稳定策略；改为正向锁定剧情不能改变的身份、接触、边界、声音权限和稳定结果。默认用“触发后、说到关键处、接触完成时、句末”等相对时序；只有关键同步、抢话、接触窗口、停顿长度或真实失败复现需要时才写局部秒数。焦距、推近百分比、动作次数和身体部位顺序同样只在减少真实歧义时使用。

情绪不强制采用统一曲线。原文确有积蓄、临界和释放时可以这样组织；持续压抑、突然认知、喜剧错位、麻木、延迟反应、克制缓和或无释放时保留其真实形态，不补造爆发、哭泣或通用微表情。

## 4. 空间与动作

每镜先闭合空间，再在 `主体与起态` 用一个稳定锚点和必要人物关系简洁重述，使本镜脱离上一镜仍可理解。普通镜只写当前区域、关键锚点、人物槽位、关系方向和重要道具；实际可见背景、支撑、接触、头脸方向、可见面、双脚与遮挡只有影响剧情、构图或生成稳定时才加入。不要搬运整间房的固定物清单，也不要用完整身体清单证明空间。

动作按决定性因果设计：让观众看懂什么触发、什么真正发生、结果怎样即可；中间协调与自然补间默认交给模型。道具在归属或承载面会影响剧情时才显式锁定，复杂动作是否拆分由叙事、容量与表演决定。

空间高风险镜在内部做一次四层闭合，不把它们新增为正式输出字段：

- `空间锚点`：选择真正不会随人物或摄影机运动的实体、边界或中轴，如门槛、门框、桌心、地面接缝、道路中轴、亭柱或御案；同时冻结必要的人物物理槽位、跨界权限和道具承载面。不要把每件家具都升级为锚点。
- `运镜轨迹`：写清摄影机相对锚点的起幅、运动平面、方向、路径、速度感、触发、经过或避开的实体和落幅。固定机位同样是完整选择，但需要说明它保住了哪项边界、交汇点或关系读取。
- `情绪传导`：从人物实际可访问的动作、声音或目光出发，安排谁先受压、谁接收、谁压住或泄露、谁在镜尾留下余波。摄影机扫到某人时可以显露其峰值，但峰值必须由此前刺激和人物策略造成，不能仅因镜头经过而自动发生。
- `互动逻辑`：闭合发起动作、接收对象、接触或视线落点、对方反应和新状态。若一处写“站位全程固定”，另一处又要求同一人物向前迈步，必须选择其一或把允许移动的范围写清。

世界空间与屏幕投影分开记录。人物、桌脚和门槛在世界中不动，不代表移动摄影机下它们在画面中的像素位置也不动；只有被摄影机持续瞄准的中心锚点可以保持画面几何中心，其他实体的透视、遮挡和画面左右允许按路径自然变化。固定机位则可以明确锁定人物画面槽位、交汇点和边界线。人物目光写具体目标，不用“互相看”代替双向落点，也不让低头人物同时承担正面对视。

时长按并行时间线计算，不把所有元素串行相加：分别估算 `声音轨`、`人物表演/动作轨`、`摄影机/焦点轨` 的实际持续时间，以三者最长值作为基础时长；再追加只有在前一事件完成后才能开始、且不能被任何轨道覆盖的必要串行动作。听者可以在台词进行中逐步接收并产生细微反应，摄影机和转焦可以随表演同步，OS/OV 可以覆盖劳动与环境动作，这些并行内容不得重复加时。若有实测配音，以实测声音时长为声音轨依据；没有实测音频时，根据人物、情绪、语气和停顿判断，不用统一字符速度迫使所有角色慢读。

得到 `max(声音轨, 人物表演/动作轨, 摄影机/焦点轨) + 不可重叠串行动作` 后，在镜尾保留约 `1s` 自然留白，用于动作落稳、情绪余波或剪辑接点。这里的“约”允许按当前节奏轻微缩放；若最长轨道末端已经包含台词尾势、动作落稳、余波或转场，该部分直接计入这约 `1s`，不能再次叠加。`稳定终态` 是可继承、可验证的画面状态，不是另一个耗时项目，也不因字段存在自动加时。

量化运动只在能减少执行歧义时使用，并先检查数值合同：`扫过角度=角速度×运动时间`，`位移距离=线速度×运动时间`。推镜、停留、拉镜、转焦和必须串行的人物动作之和不得超过本镜容量；全环绕耗时为 `360°/角速度`。当数值轨迹与 `15s` 上限冲突时，缩小扫角、提高但仍合理的速度、缩短停留或按独立剧情节拍拆镜，不能保留互相矛盾的参数。

空间图只是几何辅助。站位、面向、机位和焦段由模型选择；脚本只能计算碰撞、净距、遮挡、轴侧、视场和路径是否越过实体。几何 PASS 不等于构图、美术或成片 PASS。

## 5. 摄影机、焦点与 Seedance 语义

每镜先确定观众看到的起始画面和结束画面，再决定是否需要摄影机变化。内部用 `起幅 -> 触发 -> 观众新增读取 -> 落幅` 检查运动收益；新增读取可以是信息、关系、权力、距离、空间、动作证据或情绪余波。完成可读性判断后，优先再问一次“是否存在更有画面记忆点、但不增加事实负担的观看位置或路径”，例如利用门框、前景遮挡、负空间、焦点延迟、微小弧移、带结果的拉远或沿真实边界横移；只选择最能服务当前转折的方案，不要求每镜运动。用可见参照描述摄影机起幅、触发、路径、速度感和落幅；“左/右”说明是按最终画面还是场景实体参照。删除运动后观看结果不变时通常删去或重选，静止足够时保持静止；运动确有收益时也不能只因生成风险退化。不要只给米数、角度或“保持关系轴同侧”这种平台可能不理解的内部术语。

凡是摄影机、焦点、人物/手部和道具容易发生主语混淆时，分别使用具名主语；普通单义句不为证明语法而重复角色名。多人关键动作与结果仍使用具名人物避免归属错误：

- `摄影机……` 只描述机位和镜头路径。
- `焦点……` 只描述对焦主体与转焦时机。
- `[人物/手部]……` 只描述演员动作与终态。
- `[道具]……` 只描述道具是否移动、由谁承载及终态。

只写实际发生的路径，不为“不动”对象填充机械字段。不要写“摄影机跟随手指从证物落到听者脸”；这会让路径主语和终点归属混乱。应分别明确摄影机怎样移动、焦点何时从证物转到听者、手指停在哪里、证物是否保持在原承载面。

按时间顺序组织本镜真正需要的节点，并让自然表演连接它们。逐镜审查长台词、精细手部、道具转移、多人反应、摄影机运动、转焦和光影变化是否形成互相竞争的观看任务；超载时删去无收益控制、调整时序、重选机位或拆镜，不通过补写更多微动作解决。

## 6. 视觉连续性

每场都要有完整的视觉意图，但表达精度由场景决定。先从时间、天气、空间开口、真实发光体、遮挡、表面材质和人物肤色建立事实基线，再确定主色、辅助色或材质色的关系，主光来源与方向，辅助光的来源，受光区域、阴影层次、背景亮度、肤色保护、材质响应和允许的有因变化。基线闭合后，再主动寻找一个能形成画面记忆点的层次关系，例如真实光源在材质上的反射、前后景明暗分隔、局部色彩对照、蒸汽/尘埃/水面等有来源的环境响应或有意留白；没有物理证据或会遮挡口型、关键动作的美化一律不加。不能把“氛围光”“情绪光”当成物理光源，也不能让冷暖形容彼此矛盾而不说明分别属于哪个区域。

光影服务叙事：决定观众先看见谁、关系距离如何被分隔、动作证据是否可读、终态是否稳定。人物肤色保持中性不等于整张脸均匀补亮；可以保留鼻侧、下颌与背光侧阴影。色卡应统一场景而非把画面压成单色，可用环境材质和小面积点缀色建立层次。悲伤不自动等于蓝、亲密不自动等于暖、危险不自动等于红；颜色只能强化已有的物理环境和观看重点，不能代替人物选择与表演。

在审片报告和正式全局视觉基线中锁定真实光源、主辅关系、综合色彩/材质落点、曝光层级和肤色等跨镜事实。逐镜仍写 `视觉控制`，但只提取当前画面最有生成价值的主光、综合色彩或材质与曝光/肤色结果，不复述完整调色清单。

逐镜把色卡、影调和光影压成一个紧凑 `视觉控制` 句。不能只写“同前”或内部编号，但也不要求把全局基线逐项复制；无物理变化时说明当前主光、综合色彩/材质和必要稳定项即可。

只有时间、光源、门窗遮挡、天气、空间或明确主观视觉层发生变化时才改基线，并写清触发、时机、影响区域、保持不变项和尾帧新稳定态。单镜使用已审核视觉参考且文字不再增加控制价值时可以省略视觉句；普通独立文本生成通常应写，因为 Seedance 看不到场景总表。

## 7. 资产提示词层

资产图与视频镜头是两个相邻但独立的输出层。先完成角色和场景的稳定基线，再写逐镜 Seedance 提示；不要为了让资产图“更完整”而把镜头动作、台词、临时情绪或特效写入资产提示。

- **人物资产**：每个需要跨镜识别的角色写身份/关系、稳定脸型与发型、肤色和体态识别点、服装轮廓与材质、主色和固定饰物。源文未规定的外观可由模型补足，但不能使用明星或网红肖像，也不能创造会改变剧情的年龄、身份或能力。默认中性或低强度表情、自然比例和写实皮肤；资产图可以选择半身、全身或多视图构图，但不要把某一镜的哭泣、愤怒、奔跑、持物姿势锁成角色常态。
- **场景资产**：每个主要空间写结构边界、固定锚点、门窗/桌椅/通道关系、可用观看入口、画面内真实光源、材质和色卡。优先生成无人空场或低叙事环境基准，不加入临时剧情人物、交互道具、特效、文字或会改变空间拓扑的装饰；镜头可以改变取景、遮挡和景别，但不能随意改变固定物之间的世界关系。
- **提示分层**：资产中文提示词用于资产图生成，`【Seedance 直投提示】` 用于镜头视频生成。镜头必须脱离资产图文字也能成立；资产图若被上传，只作为身份或环境参考，不替代镜头内的空间锚点、表演触发、台词和稳定结尾。资产负向词保持简洁，只有确有风险才加局部约束，不能形成“禁止一切自然演绎”的项目级前缀。
- **一致性复核**：交付前检查同一角色的脸型/发型/服装主色/固定饰物是否跨场一致，同一场景的边界/固定物/光源方向/材质色卡是否跨镜一致；发现冲突时回到资产基线或导演方案修订，不在每镜重复堆砌资产细节。

## 8. 自审与停止条件

成稿前从最终直投提示反向确认：每镜主要转折可读，声音原文与权限正确，人物只响应可访问刺激，决定性动作与结果可执行，必要空间锚点和道具归属不歧义，摄影机与光影实现已选导演意图，Seedance 不会误认关键主语、先后或参照。审查内部可以检查更多状态，但不得因此要求正式提示逐项证明。再从整场时间线复核节拍递进、必要蓄力与余波、并行时长和约 `1s` 自然留白；不要用总秒数、镜头数量或提示词字符数代替判断。

发现创意问题时回到对应导演决定，不用关键词补写。两次修改仍围绕同一句补限定词，说明问题通常在原文理解、拆镜、动作预算、机位或信息顺序，应重选结构。因果可从画面还原、连续性闭合、直投语义独立且工程事实通过后立即停止，不继续扩写内部分析或另起一套方案。工程校验通过不代表创作通过；模型设计审片和真实画面审片才决定质量。

反向复述和相邻镜交接只作为开放式诊断：检查观众能否读回原文变化、人物反应是否由可访问刺激触发、连续动作或余波是否拥有可继承入口；不要求固定节点数量、固定交接类型或与参考示例相同的表面形式。修改成稿时比较修改前后，确保源文事实、情绪峰值、关键关系、有效画面记忆点和必要视觉层次没有因“降风险”被无声削弱；非源文、低价值或已被更好方案替代的演绎不必冻结。审查发现多种同样成立的导演解时保留模型选择，不为统一格式继续修订。

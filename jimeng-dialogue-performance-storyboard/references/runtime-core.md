# 即梦分镜运行核心

本文件是常规生成的最小执行胶囊；最终字段与顺序只以 `output-template.md` 为准。源文命中专项风险时，按
`scripts/route_task.py` 返回的 `read_on_demand` 追加引用，不预读整个资料库。

## 输入与兼容

- 唯一硬必填是可完整读取的源文。先运行 `source_gate.py`，完整通读后冻结场景清单、人物/声音/表演基线、空间ID、影调、道具归属和跨场状态。
- 原样保留台词、OS、OV、系统音、内心独白及标点，不改人物、顺序、因果和结局。缺省风格按源文保守补足，画幅默认 `16:9`，Seedance 目标默认 `auto`。
- 每镜不超过15秒，直接提示词不超过500个中文字符。多场景默认分文件；`both` 从同一事实合同导出2.0、2.5两份主文件和不可投喂的索引，两版只改变适配措辞。

## 生成顺序

1. 每个镜头组只完成一个新认知，标记铺垫、升压、峰值、释放或缓冲；同组只留一个主要张力手段。
2. 每个子镜头只承担一种任务：空间/关系、一个说话者口型、听者反应、线索/道具、一次状态转换或一条简单路径。三项以上高风险任务先拆镜。
3. 内部锁定空间、状态、镜头、表演四系统：当前可见人数和槽位；朝向/支撑/道具；景别、构图和固定理由或单一路径；情绪触发、最小泄露、声音和余波。
4. 直接提示词按此顺序自然写成：`视觉场景前缀 -> 当前主体/关系 -> 构图与主次焦点 -> 景别机位/单一路径 -> 剧情触发与表演/声音 -> 一个动作或因果响应 -> 有来源的光影/材质 -> 最后20%稳定终态`。
5. 每生成一镜就写入临时场景草稿，并运行 `incremental_validate.py <草稿> --current-shot <镜号>`。`field/shot` 只修当前字段或当前镜；`pair/window` 只修返回的镜头对或三镜窗口。最多局部修复两次，仍失败才升级一级范围，不默认重写整场。
6. 使用当前模板保存，运行 `validate_storyboard.py --shadow-report --seedance-target <目标>`。逐镜通过不能替代最终完整文件、跨场和双版本校验；修完全部硬错误再交付。

## 不可降级项

- 可见对白驱动正确人物口型，开口前锁位、句末闭口；OS/OV/系统音写成 `标签：“原文”`，不驱动可见口型，画内人物闭口并给出受声音触发的反应。系统音是非实体声源，不计入可见人数。
- 下一镜开头重写当前可见事实；直接提示词不写“上一镜、继承、尾帧、切到”。
- 道具/衣物/门车门/支撑/UI变化写起点、接触或支撑、可见转换、稳定终态。画外人物只绑定画外方向，不写成可见目标。
- 负向具体视觉概念先改写为目标身份、服装、地点、道具事实，避免把坏相写进正向提示词。操作型手机屏幕朝使用者，镜头只见背面或斜侧；具体文字默认后期叠加。
- 人物镜末段锁定人数和槽位、脸手腿边界、道具归属、支撑接触、摄影机终点和曝光；不新增或复制人物。光影必须有来源、方向、接收面和结果，环境色不覆盖脸与活动手。
- 五个基础字段和制作质量信息始终保留；可选字段只在降低真实风险时添加，不输出空字段，不用机械句凑校验。

# 即梦分镜创作运行核心

本文件决定创作方法，不规定创意答案。结构只看 `output-template.md`；平台措辞只看 `seedance-target-adaptation.md`。脚本不能解释、评分或改写本文件中的审美要求。

## 1. 创作主权

大模型对最终画面负责。模型自行决定拆镜、时长、节奏、表演强弱、人物调度、观众位置、景别、机位、运镜、焦点、光源、影调、色卡和提示词语言。不存在必须使用的拍法、运镜次数、景别数量、签名镜配额、情绪术语或关键词。

工程层只验证可确定的交付事实。工程报告不得把“未识别到某个词”改写成“创作缺失”，也不得从提示词反向恢复情绪、机位收益、第一焦点、光影职责或其他自然语言合同。

## 2. 从原文到导演方案

完整通读原文后，在内部形成场景理解：人物此刻想得到或保护什么，阻碍来自哪里，台词表面与真实策略是否一致，信息何时交给观众，上一节拍留下什么身体和关系余波，本场结束后什么状态必须继承。只保留有源文依据或合理可见推断的内容，不新增剧情事实。

先设计整场，再设计单镜：决定观众从哪里进入关系、何时靠近或疏离、什么信息值得改变观看位置、哪里应当静止、哪里应当切镜、场景如何结束。镜头运动必须有观看收益，但“没有运动”同样可以是有力选择。不要为了显得有创意堆叠移动，也不要因生成风险自动退化成安全中景。

候选发散是模型的自由工具，不是流水线字段。关键转折、复杂关系或普通方案明显乏力时，可比较不同表演、空间或摄影机方案；简单节拍可以直接判断。候选数量、比较维度和是否保留笔记均由模型决定。

## 3. 表演与情绪

从因果而非标签出发表演：人物听见或看见了什么，试图维持什么关系策略，身体哪里泄露真实压力，对方何时接收到并怎样调整，句末留下什么未完成状态。把心理转译为当前景别真正看得见的脸部、呼吸、肩背、重心、手部、视线、距离或道具行为。

普通对白不需要每句都成为炫技镜头，但必须像这个人物在这个时刻说出的。优先使用角色正在接触的物件、空间边界、说话节奏和对方反应，而不是反复套用皱眉、抬眼、轻笑、握拳。多人场面安排反应先后与强弱，避免所有人同时做同幅动作。表演可克制、停顿、遮掩或留白，只要关系变化对观众可读。

声音原文逐字保留。可见说话者的口型、闭口和听者反应要有可执行时序；OS、OV、系统音和后期旁白明确为非口型声音。根据内容、停顿与表演判断容量，必要时由模型拆镜。字符时长估算只提供参考，不能替模型选择拆点。

## 4. 空间与动作

在多人、门槛、桌边、窄空间、道具交接或越界场面中，先在脑中或工程图中闭合：人物物理位置、身体面向、视线、摄影机位置与拍摄方向、可见面、前后遮挡、边界两侧、入口出口和真实背景。`正面可见` 只描述摄影机看到的面，不等于人物面向摄影机。

动作按可见状态变化设计：起态、接触或发力、转换、稳定终态。道具始终有持有人、承载面或容器；容器内物体若没有被拿起，就明确保持在容器内，而不是用“不要飞走”强化错误概念。复杂动作可拆分，但拆分位置由叙事与表演决定。

空间图只是几何辅助。站位、面向、机位和焦段由模型选择；脚本只能计算碰撞、净距、遮挡、轴侧、视场和路径是否越过实体。几何 PASS 不等于构图、美术或成片 PASS。

## 5. 摄影机、焦点与 Seedance 语义

每镜先确定观众看到的起始画面和结束画面，再决定是否需要摄影机变化。用可见参照描述摄影机起幅、路径、速度感和落幅；“左/右”说明是按最终画面还是场景实体参照。不要只给米数、角度或“保持关系轴同侧”这种平台可能不理解的内部术语。

凡是摄影机、焦点、人物/手部和道具同时出现，分别使用具名主语：

- `摄影机……` 只描述机位和镜头路径。
- `焦点……` 只描述对焦主体与转焦时机。
- `[人物/手部]……` 只描述演员动作与终态。
- `[道具]……` 只描述道具是否移动、由谁承载及终态。

只写实际发生的路径，不为“不动”对象填充机械字段。不要写“摄影机跟随手指从叶片落到卫景耘脸”；这会让路径主语和终点归属混乱。应明确摄影机怎样移动、焦点何时从叶片转到脸、手指停在哪里、叶片始终在篮内。

按时间顺序组织表演：开局状态，触发，第一动作或台词，对方反应，摄影机或焦点变化，稳定结束。若模型能力不足以同时完成多个高风险变化，优先依据戏剧节拍拆镜或使用已审核关键帧，而不是删掉情绪与摄影机意图。

## 6. 光影、影调与色卡

每场都要有完整的视觉意图，但表达精度由场景决定。确定主色、辅助色或材质色的关系，主光来源与方向，辅助光的来源，受光区域、阴影层次、背景亮度、肤色保护、材质响应和允许的有因变化。不能把“氛围光”“情绪光”当成物理光源，也不能让冷暖形容彼此矛盾而不说明分别属于哪个区域。

光影服务叙事：决定观众先看见谁、关系距离如何被分隔、动作证据是否可读、终态是否稳定。人物肤色保持中性不等于整张脸均匀补亮；可以保留鼻侧、下颌与背光侧阴影。色卡应统一场景而非把画面压成单色，可用环境材质和小面积点缀色建立层次。

场景级视觉方案只负责连续性，不代替逐镜设计。每镜在同一份直投提示中独立写出：

- `色卡`：本镜实际可见的主色、辅助色、点缀色及其落点。
- `影调`：本镜对比度、饱和度、亮暗层级、背景亮度、黑位/高光和肤色基准。
- `光影`：本镜真实主光与辅助光的来源、方向、受光面、阴影区域、材质响应和稳定状态。

三项必须让单镜脱离场景总表仍能直接投喂，但不要机械复制同一段。模型根据构图主体、动作证据和情绪职责调整各镜内容；不强求颜色百分比、固定色温数字、固定词序或统一光型。

## 7. 自审与停止条件

成稿前由模型阅读源文和整场分镜，判断：原文因果与声音是否完整；人物行为是否专属于当前关系；动作是否真的可执行；空间是否闭合；摄影机是否帮助观看而非装饰；每镜色卡、影调和光影能否独立生成且与全场连续；Seedance 是否会误认主语、先后、参照系、容器归属或焦点终点；结束画面是否稳定并可衔接。

发现创意问题时回到对应导演决定，不用关键词补写。两次修改仍围绕同一句补限定词，说明问题通常在拆镜、动作预算、机位或信息顺序，应重选结构。工程校验通过不代表创作通过；模型设计审片和真实画面审片才决定质量。

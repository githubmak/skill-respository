# 灵动性动态语法

本文件只在用户要求灵动、自然动态、降低 AI 感，分镜显得呆滞/机械，或场景存在明确动力源时读取。它细化现有画面、表演和状态字段，不增加模板字段、运行阶段或额外 Agent。

## 不变量边界

先锁人物身份、骨骼比例、真实身高、支撑关系、空间拓扑、道具归属、光源方向和动作终态。灵动只能发生在这些不变量之间，不能用人物缩放、肢体拉伸、无因漂移、光源跳变或道具抖动制造运动感。

## 场景动静曲线

先给同一场景的相邻镜分配内部动态角色：

`hold 静态蓄势 | initiate 触发 | propagate 传递 | payoff 变化落点 | recover 余波恢复`

按剧情只选需要的 2-4 个角色，不机械凑齐。相邻镜不得连续使用同一运镜、同一微表演和同一空气装饰；峰值镜前后至少保留一个真正稳定或低能量镜头形成对比。内部角色不进入最终 Markdown。

## 单镜因果链

内部建立：

`动力源 | 起始静止锚点 | 主体触发 | 第一响应 | 延迟响应 | 余波 | 稳定终态`

- 动力源必须可见、可听或由源文事件直接推出，例如开门侧风、脚步冲击、车辆经过、云层遮光、手放下杯子、身体转向。
- 第一响应与延迟响应必须共享同一个动力源，不能成为两条独立动作链。
- 保留至少一个静止锚点，让观众读出变化；不要让人物、衣物、光影、道具和背景同步运动。
- 用因果顺序替代装饰性常动：烛焰先偏，袖口稍后摆一次，墙影最后恢复；杯底接触桌面后，水纹扩散两次再减弱。

## 个性化微表演

从 `触发原因 + 人物控制方式 + 泄露部位` 选择一条动作，不默认眨眼、皱眉或抿嘴：

| 表演基线 | 优先泄露 |
|---|---|
| 克制、防御 | 呼吸短停、拇指压紧物件、下颌短暂绷紧、视线先避后回 |
| 外放、进攻 | 重心前移、手势先于台词、句末保留身体余势 |
| 警觉、试探 | 目光先移、头部后转、肩背最后调整 |
| 疲惫、受压 | 动作启动略迟、支撑点加重、呼气后肩线小幅下沉 |
| 亲密、犹疑 | 距离欲靠近但停住、视线短暂下落、呼吸变浅后恢复 |

同一人物相邻三镜不得复用同一泄露部位；台词、口型、听者反应或道具转换复杂时，只保留一项微表演。

## 相位与幅度

- `主体触发` 先发生；材质或光影响应晚约 0.2-0.5 秒；环境余波再晚一拍并自行减弱。短镜只写“先/随后/稍晚”，不要硬塞时间数字。
- 主动作使用可读幅度，耦合响应保持低幅；背景运动比主体慢、弱或更晚。
- 摄影机明显运动时，人物和环境降幅；人物执行复杂动作时优先固定机位。
- 低风险镜允许一条因果响应链，链内最多两个低幅耦合响应；多人、长对白、道具转移、复杂支撑或腾空镜只保留一个响应。

## 四字段消费

- `【画面描述｜直接复制】`：最多写一条 `起态 → 触发 → 主体动作 → 一个必要响应 → 稳定落幅` 动态句。
- `【表演与声音】`：记录情绪原因、个性化泄露和说完/听完后的呼吸或姿态余波。
- `【状态继承】`：只写已稳定的人物位置、支撑、道具和仍可见的低幅余波，不写内部动态角色。
- 第二耦合响应只保留在场景底图，除非它是本镜的剧情视觉落点。不得输出 `hold/initiate/phase/动力链` 等内部标签。

## 语义去套路

把近义表达按家族检查，而不是只比较原词：

- `camera_push`：缓慢推近、轻推、小幅推进、逐渐靠近。
- `generic_eye`：轻微眨眼、眼睫轻颤、眼皮微动。
- `generic_brow`：微微皱眉、轻蹙眉、眉心微收。
- `idle_fabric`：衣摆轻动、衣袖轻摆、衣角轻晃。
- `generic_haze`：薄雾、轻雾、雾气缓慢流动、丁达尔光/无因体积光。

同组或相邻三镜命中同一家族时，替换其中至少一镜：优先使用源文动作、人物重心、道具接触、现实光源变化或空间关系变化；没有可用因果时选择真正稳定，不为“灵动”强加运动。

## 失稳回退

按顺序删除：摄影机运动 → 第二耦合响应 → 空气层 → 第一低幅响应。始终保留剧情主动作、人物比例与支撑、关键道具、台词口型和稳定终态。真实效果只能用用户提供的成片 A/B 评估。

# 隐性提示词风险控制

本文件用于拦截“文字逻辑正确，但词语激活了错误视觉先验”的提示词。所有规则只改变提示词写法，不改变输出模板。

## 1. 源文视觉概念白名单

写镜头前内部提取：

`人物身份 | 实际服装/发型 | 实际地点 | 固定锚点 | 活动道具 | 时代/题材 | 明确要求展示的信息 | 允许推断的生活细节`

完成直接提示词后做概念差分：新出现的职业、制服、地点、特殊帽饰、医疗/警务/学校/婚礼/宗教/军事物件，必须能回指源文事实、用户要求或本场锁定。不能回指的概念立即删除或改写。

台词、OS、OV、系统音中的词只属于声音文本，除非源文同时要求它可见，否则不能进入视觉白名单。例如台词说“我不去医院”，不能据此生成病房、护士或医疗道具。

## 2. 负向概念泄漏

高风险句式：

`不要/禁止/避免/去掉/不是/没有 + 具体职业、服装、地点、道具或时代实体`

错误示例：

- `年轻女性不要戴护士帽，背景不是医院。`
- `人物不穿校服，画面里没有教室。`
- `不要警服、警帽和警局元素。`

模型可能先激活 `护士帽 -> 护士 -> 医院`、`校服 -> 学生 -> 教室`、`警帽 -> 警察 -> 警局`，再部分忽略否定关系。

改写顺序：

1. 删除源文未要求的错误概念，不在正向、必要约束或补充负面中复述。
2. 写人物真实头部、发型、服装和身份。
3. 写目标场景的固定锚点、光源和生活细节。
4. 只有真实抽卡反复出现某坏相且无法用正向事实解决时，才在单镜负面中使用最小上位类词；不得把职业和地点词加入通用负面。

常用正向改写：

- `不要护士帽` -> `头部无遮挡，黑发自然垂落，穿日常浅灰针织衫`
- `不是医院` -> `现代住宅客厅，沙发、茶几、落地窗和暖白窗光固定可见`
- `不要校服` -> `成年女性，穿深灰商务西装`
- `不要军装` -> `穿日常深色夹克`

## 3. 道具用途先于可见性

先给手机、平板、书本、证件和照片分类：

- 操作型：人物玩游戏、刷手机、打字、浏览、阅读；内容服务人物动作，不要求观众读取。
- 展示型：人物把证据、照片、付款码或界面明确展示给另一人物或观众。
- 通知型：消息或来电影响人物，但画内屏幕不必可读。
- 通话型：手机贴耳、免提或画外声音，屏幕不是视觉任务。

操作型默认不得自动升级为展示型。展示型必须有源文明示，不能因为提示词写了 `游戏、聊天、照片` 就把屏幕翻向镜头。

## 4. 手机操作镜头

源文只写 `玩手机游戏、打手游、刷手机、打字、浏览消息、看手机` 时，直接提示词必须同时锁定：

1. 持机方式：单手竖持或双手横持，所在高度和人物姿态。
2. 用户侧：`屏幕朝向A本人`。
3. 镜头侧：`手机背面朝向镜头` 或 `镜头只见手机背面和斜侧边缘`。
4. 操作证据：拇指低幅点击/滑动、屏幕冷光落在脸或指节、视线停在靠人物一侧的屏幕。
5. 结束状态：手机方向、所在手和高度进入 `【状态继承】`。

推荐写法：

`A双手横持手机停在胸前，屏幕朝向A本人，手机背面和斜侧边缘朝向镜头；双拇指在靠A一侧低幅交替点击，微弱屏幕冷光落在指节与下颌，镜头不承担界面展示。`

没有展示任务时，不写游戏角色、HUD、按钮、聊天界面或可读文字，也不写 `屏幕不要朝观众`；后者仍会激活屏幕展示概念。

若观众必须看清界面，拆出独立展示镜：先完成手机转向或另设过肩/插入机位，再明确屏幕朝向、可见范围和文字路线。不要在同一表演镜里同时要求自然操作和正面展示。

## 5. 保存前隐性风险检查

内部检查：

`新增具体概念 | 是否来自源文/锁定 | 是否只出现在否定句 | 可能激活的关联场景 | 道具用途 | 道具朝向 | 是否错误升级为展示 | 正向改写结果`

保存后运行验证器。若报告 `负向具体概念泄漏` 或 `操作型手机缺少朝向锁定`，回到直接提示词重写；不要把报错词搬进更长的负面提示词。

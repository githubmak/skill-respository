# 视觉输入、母色卡、场景图与资产治理

本文件只管理视觉资产输入、资产颜色、场景图解析、空间关系、媒介开关和输入侧语义纯净度。这些规则在导演预演前成立，不在成稿后补贴；固定提示词原文由双文件交付合同唯一管理。

## 输入门

正式双文件需要完整剧本/目标片段、画幅、用户实际提供的视觉风格关键词和全剧母色卡图片。影调、光影与分场环境色彩由“风格 + 母色卡 + 剧本时空/天气/实体光源”推导，不要求用户另写。

母色卡缺失时只请求母色卡并暂停正式拆镜。母色卡到齐但无场景图时，只提醒一次可上传图片、多视图、PDF、文件或文件夹；用户回复暂无后按剧本建立空间，不复问。场景图是推荐输入而非硬门；部分场景有图时混合处理，不把一个地点套到其他地点。

参考拍摄手法是可选输入，可来自文字、分镜、剧照、连续截图、视频或指定技法。收到后按 [shooting-method-reference.md](shooting-method-reference.md) 自动提取，不要求用户复述；未提供时不询问、不阻断输出。

### 事实歧义暂停门

在唯一导演源表开始生成前，集中判断缺失资料是否会改变不可改事实。仅以下歧义允许暂停并一次性提出聚焦问题：`人物身份/关系、事件因果或顺序、地点归属/场景切换、对白说话者、能力规则、伤势/胜负/结果、结局或片段边界`。问题必须指出受影响镜号或场景和两种冲突解释；得到回答后只回填受影响字段，不重跑无关场景。

不会改变事实的视觉不确定性（机位可放区域、未入镜背景、非关键材质、天气细节、光线软硬或装饰颜色）按空间图/剧本和资产优先级做最小可拍推导，并在导演版标记待人工复核；不得因为视觉未知回退到固定中景。母色卡缺失仍按本节输入门暂停，场景图缺失不暂停。

收到视觉资产时，从用户视觉风格判定媒介并向唯一导演源登记 `3D 写实兼容开/关`。用户只写“3D”而未进一步限定，或明确选择 3D CG 写实、次世代写实及语义等价风格时登记“开”；卡通 3D、黏土、低多边形、其他非写实三维，以及二维、真人实拍感、国风水墨、手绘、定格等风格登记“关”。本模块不复制或组装固定提示词；模板原文、顺序和负向联动只由 [seedance-dual-delivery-contract.md](seedance-dual-delivery-contract.md) 在编译阶段执行。

## 颜色与资产优先级

`资产固有色 > 真实实体光照响应 > 全局影调 > 母色卡用于未被资产锁定的环境/空气/背景`

- 母色卡只提供非资产环境的颜色家族、冷暖、明度、饱和、灰阶和肤色保护参考，不继承文字、边框、排版、色块形状或构图。
- 已知资产按参考图冻结五官、发型、肤色基线、服装、家具、材质、花纹、Logo 与固有色；未知资产不猜固有色，只写类型、造型、材质、位置、尺度、新旧和真实受光。
- 资产中的卡外高饱和色可留在对象边界内，但不扩散为环境综合色、污染肤色或复制到其他对象。
- 全局影调统一黑位、中间调、高光滚降、白平衡、人物/背景曝光、肤色和材质响应；场景冷暖/亮度随真实时空与光源变化。

## 场景图自动解析与空间锁定

收到场景图、同场景多视图、PDF 或场景文件夹后，立即使用可用的图像/文档读取能力自动分析，不要求用户再次手工描述：

1. 识别地点、视角、时间状态与可见范围；同地点归组，不同地点分开。
2. 综合同组视图，冻结门窗/开合方向、门槛、墙地面、家具、通道、纵深、固定物、实体灯具、材质、固有色与花纹。
3. 结合剧本动作确定人物起始槽位/活动区/接触距离、摄影机可放置区/禁入区、通行路径、关系轴和屏幕侧。
4. 多视图只补不可见区域，不强融不同房间/时间版本。只有冲突会改变路径、出入口、关键动作或轴线时才问一个聚焦问题。
5. 自动为每个场景生成 5—8 句客观空间描述并写入双文件，不输出分析过程、路径、置信度或内部编号。

空间模型使用两次：输入阶段先冻结客观结构和行动边界；导演首稿后再校验机位、穿物、遮挡和动作距离。场景图不是机位生成器。物理冲突依次通过调度/焦点、减少次要负载、调整站位/遮挡、通过切镜门槛拆镜、缩短/改向路径解决，不自动回固定中景。

所有场景无论有无图都输出 5—8 句空间关系，并标明场景图锁定、剧本推导或混合建立。空间描述不是装饰说明，而是可审核的关系基准；至少覆盖：

1. 空间依据和未冻结区域；
2. 摄影机活动区与禁入区；
3. 前景边界、门口/出入口、家具或遮挡；
4. 人物初始位置、朝向、距离和活动区；
5. 中后景家具、关键道具和空间锚点；
6. 实体光源方向及室内外冷暖关系；
7. 允许路径、关系轴、屏幕侧、越轴方式或具体镜号后的走位限制。

导演首稿后逐场执行空间关系复核：把每个镜头的起幅和落幅映射回摄影机活动区、出入口、家具锚点、人物距离/纵深、路径、遮挡和光源方向；标出穿物、瞬移、遮挡吞掉关键动作、越轴、距离跳变、手别偷换和场景图视角冲突。直投版不输出内部审核表，但必须把复核后的客观关系写回当前资产与连续性、起幅状态、摄影与构图、光影/色彩/材质和落幅状态。

导演版可写待复核物理假设；直投版只保留自然语言空间事实。空间简述只冻结静态结构/边界，逐镜仍写当前人物、道具、机位、动作接点和终态。

## 直投语义隔离

直投版不得出现内部版本名、查表键、色卡/资产编号、特效阶段英文、HEX/RGB、图片占位符、本地路径、置信度或分析过程。颜色用自然中文写色相、明度、饱和、冷暖、区域和面积/强度；特效状态只转为当前镜可见形态、范围、速度、反射、物理作用和消散结果。

特效来源、生命周期、物理反馈和零提及完整执行 [spectacle-action-vfx-montage.md](spectacle-action-vfx-montage.md)；本文件只负责把已选特效转成无内部标识的自然语言。

## 人脸与实体光

环境可暗、硬、偏色或高反差，但可辨人脸保持稳定五官、自然肤色、暗侧纹理、连续白平衡与运动曝光。柔和补光必须来自墙地面、天空、灯具或其他真实反射，只把脸托回当前景别可读的中间调，不抹平主光方向、体积和环境暗度。远景保护身份色/轮廓；全景/中景保护五官结构与肤色；中近景/近景保护双眼、鼻梁、嘴唇、下颌和低频纹理；特写控制湿润高光、发丝投影、锐化和细碎阴影。

## 模板路由

本模块只向导演源输出媒介开关、人物可辨认状态、资产固有色边界和实体光结论。交付编译器据此从 [seedance-dual-delivery-contract.md](seedance-dual-delivery-contract.md) 读取一次固定模板；本文件不保留第二份模板原文，避免重复加载、版本漂移和逐镜误复制。

## 面部情绪提示词控制

正向提示词优先写希望实际出现的可见状态，不在正向层反复堆叠否定对象。每个面部情绪镜只选 1—3 个主读信号，按时间线分配给视线、眼睑/唇线、呼吸、手部/距离或声音；不要同时堆叠湿润、红肿、血丝、泪线、毛孔和皮肤细节。

描述忍泪或湿润眼眶时，写稳定干净的眼球高光和局限在眼睑边缘的轻微泛红；“泪珠、泪线、流泪、湿润脸颊、哭相”等禁止概念只在全局或本镜负面层各出现一次，不在正向提示词反复否定。红润、苍白、湿润和污渍必须限定区域、幅度和边界，不能扩散为随机黑斑或面部色块。

# AI 漫剧时长与读取带宽

本文件只在台词、动作、反应、多人调度、镜内切点或特效存在明显时长竞争时读取。它负责验证内容能否在镜长内自然完成，不重新决定剧情节奏、表演方式、镜头数量或摄影风格。

## 计算原则

时长从已经选定的内容反推，不先定秒数再挤压人物。每个时间窗先保证主动作、主台词、主声音、主焦点或主视觉变化能够读清，再让共享刺激、观看目标和终态的低竞争响应并行。

常用关系：

- 边说边做且共享目标：`T_shot = max(T_speech, T_act) + T_result + T_buf`
- 动作、对白和反应串行：`T_shot = T_act + T_speech + T_result + T_buf`
- 多小节、插切或蒙太奇：`T_shot = Σ(各小节实际时长) + T_buf`

`T_buf`只覆盖起幅识别、切换、口型收尾和镜尾停稳，不用于添加无职责停顿。无法共享刺激、方向或终态的复杂动作不能硬塞进并行关系，应改为串行小节或相邻镜头。

## 台词自然试读

`T_speech`以人物化自然试读为准。先确定说话者对谁完成什么现实行动、自然语义组怎样连接、哪里真正需要换气或等待回应，再记录实际试读总时长。

约 4.0—4.5 字/秒只作为普通中文对白的初始估算，用于发现明显超载；它不是演员语速档位。激烈、悲伤、迟疑、低沉、克制等情绪标签不得直接映射为固定字速、停顿长度、音高或声线。快速反击可能因思路清楚而快，也可能因压迫而慢；悲伤可能迟缓，也可能为掩饰而加快。

停顿只在语义边界、真实换气、人物判断、等待回应、喜剧确认、证据落地、关系压力或剪辑接点需要时保留。标点不自动生成固定秒数，逐词停顿不能用来制造重音。某段必须减速或停顿却只能靠其他部分赶词完成时，视为时长冲突。

## 动作与结果

动作时长根据实际距离、支撑、路径、接触、受力、惯性和停止状态估算。普通视线或身体调整只写到可读；递接、搀扶、扑抱、碰撞、追逐、破坏和多人接触必须给出真实完成窗口。

受话者反应和结果确认发生在信息或动作真正到达之后。关键关系、道具、身体、空间或声音结果必须留出可辨时间；没有结果变化的短反应不靠呼吸、皱眉和停顿拉长。

## 时间线颗粒

对白触发动作、复杂接触、多人错峰、道具控制变化、光区/特效变化、镜内切点或高风险运镜使用连续时间窗：

`0.0—X.X秒｜阶段：具名主体；触发或继承基线；主要动作/声音/摄影过程；阶段终态。`

第一行从 `0.0秒` 起，最后一行到镜尾，相邻时间窗首尾相接。时间码表达阶段顺序和可承载窗口，不承诺某个字落在某个小数秒点；只有快速接触、明确声音命中或剪辑点需要0.1秒级精度。

单一稳定状态或普通信息对白可以用一到两个窗口完成。时间线不要求逐项写刺激、微动作、路径、接触、材质、光影和余波；只保留本镜真实发生、会影响理解或连续性的部分。

## 密度与镜长

高密度段可以通过短镜、镜内调度、焦点交接、声音先行、遮挡或动作阶段产生新读取，不等于每2秒强切。长镜可以持续积累压力、触感、规模或人物价值；短镜只有在主体、信息、策略、动作阶段、空间关系或结果改变时成立。

单镜建议范围和平台上限服从用户与当前生成工具。没有用户总时长时，根据自然台词、不可并行动作、必要结果和转场计算预计总时长及合理浮动，不暂停任务。

总时长不足时依次处理：

1. 删除装饰镜、重复建立、同义反应和无收益停顿。
2. 压缩不改变理解的程序过程。
3. 让真实可并行且低竞争的反应与主驱动力同窗。
4. 调整镜长或拆分无法承载的独立链条。

不得压缩逐字台词、关键接触、因果过渡和结果，也不得把自然对白改成均速机械朗读。

## 输出

普通镜只需给出最终镜长和必要时间窗。只有多任务时长竞争镜、总时长冲突或用户要求计算依据时，导演版才记录 `T_speech/T_act/T_result/T_buf/T_shot` 和并行/串行关系；不要求每镜登记一行预算表。

复核只判断：台词能否自然说完，动作和口型是否争抢，反应是否提前，接触和结果是否有时间，时间窗是否连续，总时长是否满足用户要求。发现问题只调整受影响镜头，不按平均镜长、固定字速或情绪档位重算整集。

# 节拍级别与叙事/表达镜头决策

不凭“情绪很强”“台词很重要”判断关键反转。本参考在导演直觉首稿之后使用：先检查刺激是否改变人物接下来怎样行动、怎样控制关系，以及观众怎样理解现实，再验证首稿的表达力度和镜头职责。L0-L3 不从零决定景别、机位或运镜，也不把叙事镜自动翻译成固定中景。

## 分类的后置位置

导演直觉首稿已经为每个节拍提出最强起幅、唯一主要主体、一个主视觉动词、明确落幅和相邻镜头反差。本参考只做三件事：确认这种观看强度是否有剧情依据；确认表达性瞬间之后是否缺少策略或结果读取；确认镜头组有没有把同一信息重复拆开。

首稿力度高于节拍所需时，去掉没有依据的主观夸张，但仍另选一个干净、明确的视觉句；不得自动改成双人中景或肩后反打。首稿遗漏真正反转时，增加表达性冲击或策略/结果镜。分类不是审美配额，不规定 L0 必须平、L3 必须动，也不要求每个 L2/L3 使用相同镜头组模板。

## 五个状态轴

刺激命中后，只检查以下五个轴是否发生可持续变化：

1. **目标轴**：人物接下来想得到、阻止、隐藏或确认的东西改变。
2. **策略轴**：人物说话、靠近、退让、遮掩、控制道具或占位的方法改变。
3. **关系轴**：主动权、亲疏、信任、依赖、控制或接触边界改变。
4. **危险判断轴**：人物对安全、威胁、退路、对方意图或异常程度的判断改变。
5. **现实认知轴**：身份、证据、空间事实、因果或观众对前情的理解被重新解释。

短暂惊讶、尴尬、愤怒、悲伤或眼眶发红本身不构成反转。只有它推动至少一个状态轴改变，并影响下一动作、下一句策略、关系状态或场景走向，才进入反转设计。

## 四级节拍

### L0 信息节拍

条件：只建立人物、空间、道具、任务、台词信息或动作过程，五个状态轴均未改变。

镜头模式：叙事性镜头。优先清楚交付谁、在哪里、做什么、道具归属和动作结果。可以使用高空大全景、贴地跟随、单主体近景、局部证据镜或果断固定镜；不为了“有情绪”额外切无职责特写，也不因为是 L0 就默认固定中景。

### L1 情绪波纹

条件：人物产生短暂反应，但目标、策略、关系、危险判断和现实认知没有持续改变；下一步仍按原计划执行。

镜头模式：叙事镜头内嵌表达。可以用镜内焦点交接、身体停顿、一次局部变化或轻微距离变化承载；当首稿中的单主体反应镜确实改变心理距离、观看顺序或形成不可替代的静动反差时也可保留。只有重复同一信息、没有独立视觉句的反应特写才合并。

### L2 战术反转

条件：至少一个状态轴改变，并直接改变人物下一动作、下一句说话策略、道具控制、距离/占位或是否继续当前任务；场景总体目标尚未彻底改写。

镜头模式：表达性冲击镜与叙事性策略/结果镜组合，通常 2-3 镜：

```text
刺激或证据的表达性读取
-> 控制断裂/动作起势
-> 新策略行动与关系结果的叙事读取
```

表达镜负责让观众“感到变化发生”，叙事镜负责让观众“看懂变化导致什么”。不能只用一个同景别短推同时包办。

### L3 结构反转

条件：两个以上状态轴同时改变，并改写场景目标、人物关系、身份认知、危险等级或后续剧情方向；或者构成场尾/集尾钩子。

镜头模式：完整反转镜头组，通常 3-4 镜：

```text
原策略/关系锚点
-> 刺激或证据冲击
-> 控制断裂与新行动
-> 新关系/危险/现实结果
```

可以先近后远、先局部后关系，也可以由空间压迫进入局部爆点。每镜必须有独立职责，不机械凑数。

## 叙事性镜头与情绪表达性镜头

两者不是按场景二选一，而是在镜头组中分工。

### 使用叙事性镜头

当观众首先需要稳定看懂以下内容时使用：

- 人物位置、行动路线、出口和空间关系。
- 谁说话、谁听见、谁没有听见。
- 道具由谁控制、怎样拿放、递接、开合或显现。
- 动作因果、接触结果和新关系状态。
- 长段台词、OV/OS 的现实承载动作和连续表演。

叙事性不等于固定中景。人物快速行动可以跟拍，空间事实可以斜俯展开，道具结果可以从局部拉开；核心是画面首先服务事实读取。

### 使用情绪表达性镜头

只有出现以下任一条件时使用：

- 刺激命中需要改变观众心理距离。
- 不可替代的身体或道具细节证明控制已经断裂。
- 人物主观危险、依赖、羞耻、震惊或认知错位需要被观众直接体验。
- 景别跃迁、快速跟拍急停、遮挡揭示或空间拉开能改变观众对关系的理解。

表达性不等于大特写，也不等于快速运动。它必须改变观看顺序、心理距离或关系读取，并在结果出现后停稳。

## 决策顺序

每个节拍依次回答：

```text
读取导演直觉首稿的起幅、主体、主视觉动词、落幅和相邻反差
-> 外部刺激是什么
-> 五个状态轴哪些改变
-> 是否影响下一动作/策略/关系/场景走向
-> 判定 L0/L1/L2/L3
-> 验证首稿的观看力度是否有依据
-> 补足缺失的叙事锚点、表达性冲击或策略/结果读取
-> 执行切镜准入、必要合并与跨镜握手，同时保留不可替代视觉句
```

可以先凭导演直觉提出“这里从单主体特写起镜”或“这里突然切到斜俯大全景”，但必须在本步骤找到源文刺激、行动、关系或信息依据；找不到就更换视觉句，不伪造理由。不要因为有长段 OS 就把冲击、反应和结果全部放进稳定中景。

L0-L3 是内部推理工具，不是输出标签、镜头数量公式或平台配额。不得写进最终分镜，也不得为了“L2 必须两镜、L3 必须四镜”机械拆分。只要单镜能通过明确起幅、运动过程和终幅完成不同观看职责，L2 可以单镜；如果一个 L1 的局部证据会成为后续因果锚点，也可以独立成镜。最终只问每个保留镜头是否有不可替代的观看职责，以及合并后是否损失事实或情绪冲击。

## 典型判例

“订单超时提示音响起”如果人物只是听见后继续原动作，是 L1；如果它暴露当前身份、迫使人物压住手机、从谈判位置退回并改变遮掩策略，则是 L2。正确结构是手机/侧袋局部冲击镜，接人物控制断裂与退回动作，再用稳定关系镜承接 OS，而不是 14 秒同一中近景短推。

“人物眼眶发红”如果不改变下一动作，是 L1；如果驱赶动作断住、重心转向对方并开始扑抱，则是 L2；如果同时改写身份认知、亲疏关系和场景目标，则升级为 L3。

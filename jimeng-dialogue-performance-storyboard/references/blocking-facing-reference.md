# 多人站位面向线稿

本文件只处理俯视站位、身体面向和摄影机位置，不生成美术概念图、人物造型、动作轨迹或最终关键帧。线稿是非投喂辅助物，文字空间合同仍是唯一事实源。

## 触发

- `blocking_reference=off`：不生成。
- `auto`：所有两人及以上清晰互动镜头组生成；命中后失败阻塞交付。
- `required`：扩展到所有两人及以上同框镜头组，即使人物没有直接互动；失败阻塞交付。

同一物理站位跨多个镜头组完全不变时可以复用规格，但文件仍按当前镜头组重新命名。一个镜头组只输出一个 SVG；同组存在多个稳定站位或机位时在同一文件中分面板，不用轨迹箭头连接。每个面板只画一套实际机位，`state.label` 写 `侧面双人关系镜`、`卫景耘肩后看沈青乔` 等用途，避免多个视锥叠加。正反打使用两个面板和同一 `blocking_id`：人物坐标、身体面向、锚点和边界必须逐项相同，只改变机位。线稿必须在正式提示词编译之前完成。

## 事实顺序

1. 先完成关系投影和文字空间合同。
2. 为镜头组建立 JSON 规格；每个状态至少写一个桌、门、柜台、墙、沙发、床、车门或道路等固定场景锚点。人物坐标和面向必须来自文字合同，不从线稿反推剧情。
3. 运行 `scripts/render_blocking_reference.py <spec.json> --output-dir <用户导出目录>`。
4. 检查人物数量、姓名、相对槽位、面向、固定锚点、摄影机侧和视锥。
5. 冲突时修 JSON/线稿；只有文字合同本身错误时才回修分镜。

## 机位选择

对白关系镜先比较 `侧面双人关系镜 | A肩后看B | B肩后看A`。要建立空间或同时观察双方时用侧面关系镜；要突出施压、接收或反应时优先用对应肩后机位。正反打采用 A/B 身后偏侧两套机位，并保持在人物关系轴同一侧；墙、门框、柜台或近景人物身体遮住目标脸、机位无可站空间、目标圆点不在完整视场内时淘汰该候选。只把胜出的实际机位写入面板。

## JSON 规格

坐标为画布归一化值 `0-1`；`facing_deg` 使用屏幕坐标：`0=向右、90=向下、180=向左、270=向上`。

```json
{
  "shot_group": "S1-03",
  "scene": "客厅",
  "states": [{
    "blocking_id": "B1",
    "label": "子镜1起幅",
    "anchors": [{"label": "长桌", "shape": "rect", "x": 0.5, "y": 0.5, "width": 0.5, "height": 0.18}],
    "boundaries": [{"label": "门槛", "side_a": "门内", "side_b": "门外", "x1": 0.1, "y1": 0.2, "x2": 0.1, "y2": 0.8}],
    "characters": [
      {"name": "沈青乔", "x": 0.25, "y": 0.7, "facing_deg": 0},
      {"name": "卫景耘", "x": 0.75, "y": 0.7, "facing_deg": 180}
    ],
    "cameras": [{"label": "CAM1", "x": 0.5, "y": 0.95, "facing_deg": 270, "fov_deg": 50}]
  }]
}
```

`blocking_id` 标识一套不变站位；同 ID 的面板只能改变机位。`anchors.shape` 只用 `rect|ellipse|line`，标签写真实场景物。每个状态至少一个固定锚点、两名人物且恰好一个机位，姓名必须使用项目真实角色名且不重复。出现门槛、门、柜台、车门、帷幕、结界等双侧边界时必须写 `boundaries`，用边界线和 `side_a/side_b` 明确门内/门外、柜台内/外等两侧。人物箭头只表示身体面向；摄影机箭头和延伸至场景边界的视锥表示拍摄方向与范围。渲染器按 `facing_deg` 自动把机位标成 `正向·下→上` 或 `斜向·左下→右上` 等，无须另写方向字段。

每个机位默认必须在 `fov_deg` 内完整覆盖当前状态的全部人物圆点并保留 2° 边缘余量，否则拒绝生成；人物中心刚好入锥但圆点被裁也判失败。单人特写等不应覆盖全员的机位才写 `subjects: ["沈青乔"]`，渲染器只校验这些实际入镜主体；`subjects` 只能使用当前状态中的真实姓名。

## 导出

- 首次输出：`<导出目录>/S1-03_站位面向线稿.svg`。
- 同名文件已存在时默认生成 `-v2/-v3`，不得静默覆盖；确认替换当前版本时才使用 `--replace`。
- 文件名必须以正式镜头组编号开头；一个文件不得混入其他镜头组。
- 最终交付列出所有线稿绝对路径，但不把 SVG 内容或线稿说明写进即梦直接提示词。

生成模型不得直接绘制姓名、箭头或摄影机标注。若确需空间质感底图，可用内置 image generation 先生成无人物、无文字、无箭头的低对比线稿底图，再由确定性渲染器叠加标注；底图不能改变固定锚点和可通行区域。

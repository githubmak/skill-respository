# 提示词与表演规则

## 原文保真

不要只保留台词。源文里的每个段落或节拍都必须有镜头落点，包括 `△` 画面动作、叙述、人物反应、场景标题、闪回标记、OS/内心独白、系统音、人群反应、道具变化和状态变化。

- 需要审计时，建立 `## 原文保留检查表`，覆盖所有源文节拍，而不是只覆盖可说出口的台词。
- 检查表列名用中文：源文序号、原文摘录、类型、对应镜头、处理方式。
- 处理方式只能从以下选项中选择：`直接入画面描述`、`压缩入画面描述`、`进入声音轴`、`进入状态继承`、`后期蒙太奇/字幕`、`合并到相邻镜`。
- 推动剧情的非对白节拍必须进入 `【画面描述｜直接复制】`，不能只写在校验字段里。
- 不要用 `三人反应停住`、`气氛变化`、`众人议论`、`关系尴尬` 这类含糊词替代具体源文节拍；除非同时写出可见动作。

## 直接提示词写法

`【画面描述｜直接复制】` 是最终投喂即梦的正向提示词，不是导演备注。

- 组级 `【出现人物】` 只是本组曾经可见的人物索引，不是每条子镜头的画面人数要求，也不要随单条子镜头一起投喂即梦。每条直接提示词只写本镜真正可见的人、道具和固定锚点；如果本镜只拍一个反应近景，不要为了照顾组级人物表把其他角色塞进背景。
- 控制在 `<=500` 个中文字符。
- 使用一段可读的叙事自然语言。
- 这一段必须是语义完整的自然语言，不能是压缩状态表。避免 `A右、B左、道具不变` 这类坐标碎片。用完整句子写出可画关系：谁坐/站在哪里，在谁旁边/对面/身后，身体面向哪里，中间有什么隔物，每个活动道具停在哪里。
- 不要偷懒或写得过空。直接提示词本身必须足够生成片段：空间、状态、表演、声音、机位、反应和画面结束状态都要在这一段里。校验字段可以补充，但不能成为唯一出现位置。
- 镜头专属的信息要放在风格修饰前：身份、位置、动作、口型、道具、机位。
- 单独复制粘贴时，也至少包含这些可见锚点：固定场景锚点、主体画面区域、坐标基准、前后层级、身体朝向关系、视线、距离/隔物、活动道具、核心动作、可见情绪泄露、原台词或后期声音处理方式与语气、摄影机路径、尾帧状态。
- 连续镜头开头，要把上一镜结束状态翻译成当前可见事实写进直接提示词：可见人物、画面区域/物理槽位/身体朝向、道具位置/持有人。不要只留在 `【状态继承】`，也不要在直接提示词里写 `上一镜` 或 `尾帧`。
- 每条直接提示词的自然化场景前缀必须独立写出当前时段和承担主光的物理光源，例如 `同一夜晚的小院屋内，右侧油灯是唯一主光源`；不能只写 `暖褐夜景、冷白氛围、电影感`。末尾必须锁定背景亮度、主光方向、色温或曝光保持到结束。
- 门外、屋外、窗外、门框或窗框进入画面时，必须写外部亮度和天空/天光状态。夜景优先写正向可见事实：`门外保持深蓝黑位，天空无可见亮面，室内曝光由油灯决定`，不能只靠 `不要白天`。
- 同场相邻镜头即使改变景别、焦段、构图或可见人数，也要重新写 `同一夜晚/同一白天、同一物理主光源`。源文没有时间变化时，不允许后一镜把油灯主光改成日光、窗光或自动变亮的门外环境。
- 桌边、房间、人群镜头，人物出现前先写不动的空间锚点：桌沿、门框、窗、柜台、沙发、床、壁灯、走廊线、车门或其他能固定透视的物体。
- 空间词必须无歧义：`画面左/右/中/前景/背景` 用于屏幕位置；`在A的右侧/桌对面/身后半身距离` 用于人物关系位置；最好在同一句里同时写两者。
- 组内左/右必须说明基准。不要只写 `组内左座/右座`。写 `以二人坐在桌内侧、面朝餐桌对面的身体左右为基准，A在B左手边，B在A右手边`；如果机位斜切，再单独写画面近端/远端或前景/背景。
- 不要把摄影机深度当成剧情站位：`左前景` 只表示更靠近镜头，不一定是桌对面。先保留源文人物关系，再描述画面层级。
- 门槛、门框和室内外关系必须依次写清：摄影机在门内还是门外、朝哪一侧拍；每个人在门槛哪一侧；每个人身体面向谁或哪个固定空间；摄影机看到其正面、背面还是侧面。人物与摄影机同在门外且人物面向屋内时，只能写背面/侧背可见，不能同时写正面可见。
- 同一人物不得在同一稳定阶段同时 `面向门外` 与 `背对屋外`、同时 `面向A` 与 `背对A`、或 `背对摄影机` 与 `正脸可见`；若源文确有转身，必须写起始面向、可见转向过程和新面向稳定后的结束状态。
- 稳定坐姿场景有换位风险时，直接提示词必须加入物理拓扑句：`A和B是桌内侧同排双人组；以二人坐在桌内侧、面朝餐桌对面的身体左右为基准，A在B左手边，B在A右手边；二人椅背在同一条平行画框的水平深度线、肩线平齐、到镜头距离一致，相距半身，桌沿在二人身前，不隔桌、不面对面、不一前一后；C在餐桌对面，与双人组隔桌，不插入A和B之间`。
- 直接提示词里不要写 `继承`、`延续上一镜`、`空间保持`、`位置继承` 或 `物理座位不变`。这些是校验概念。要改成可见事实，例如 `A和B是同侧邻位双人组，A在组内左位，B在组内右位，道具X停在B正前方`。
- 不要在句末挂标签：`声音语气：`、`表情：`、`动作：`、`表演增强：`、`情绪：`。把它们改写成身体化叙事。
- 不要写 `剪辑`、`切到`、`反打到` 或 `下一镜执行` 这类剪辑/元叙事词。双人镜头意图必须表现为可见前景肩线、主体位置、身体朝向和背景锚点。
- 不要用 `脑海浮现`、`原剧情闪过` 或 `后期插入` 承载剧情关键画面。如果观众必须看到动作，就拆成独立闪回/蒙太奇镜头，给它自己的场景锚点、人物、动作和尾帧状态。
- 如果画面里有重要听者，而另一个角色正在说台词或出现 OS，直接提示词必须给听者一个由台词触发的低幅反应：视线跟随、眨眼、眉/嘴变化、肩/手/道具微动作或姿态变化。只写 `闭口` 对重要听者无效。
- 台词、OS、OV、系统音、内心独白、旁白进入直接提示词时，必须和画面表演写在一起。可见台词写 `人物动作 + 开口说：“...” + 听者反应`；OS/OV/系统音写 `人物闭口 + 标签：“...” + 被声音触发的眼/眉/呼吸/手/道具/距离变化`。不要只把声音文本贴在句尾。

推荐顺序：

`[时长/画幅/镜头方式] + [时段/外部亮度/物理主光源] + [静物锚点/物理槽位/画面分区] + [摄影机所在侧/拍摄方向/人物面向与可见面] + [隔物/同侧/桌对面关系] + [触发原因] + [眼神/眉尾/嘴角/呼吸] + [手/肩背/步伐/道具动作] + [台词或后期声音处理方式与语气] + [摄影机物理路径/焦点/落幅] + [时段与光照终态/其他尾帧事实]`

弱写法：`她说：“...”；声音语气：语速轻快、尾音上扬。`

强写法：`说话者眼睛一亮、身体微前倾，以轻快语速、尾音上扬说：“...”。`

弱写法：`A皱眉，脑海浮现B被多人围住，C报警并挺身而出。`

强拆法：

- `现实反应镜：A站在固定场景物右侧看向B远去方向，皱眉，闭口思考。`
- `闪回镜：独立新场景，B被3名路人从三侧围住，C在右后举手机报警并上前半步。`
- `回到现实镜：A回神，抬眼寻找C。`

## 闪回转场交接

把闪回当成由多个独立生成片段组成的连续剪辑节拍，不要当成一个地点变形成另一个地点的单条提示词。

- **触发/返回镜头：** 尾部停在 0.5-0.8 秒的具体稳定视觉把手上，例如视线停在道具、手保持静止、呼吸/肩膀落定。直接提示词只描述这个物理停顿；不要写 `闪白进入回忆`、`淡出`，也不要要求模型让场景变形。
- **插入镜头：** 开头保留 0.5-1.0 秒稳定建立把手：固定场景锚点、人物已处在起始姿势，新时空可读前不要出现可见口型。口型必须在这个把手之后开始。
- **后期桥接：** 在 `【声音轴】` 或 `【校验记录】` 写清白闪/叠化时长和声画错位衔接。实用默认值：3-5 帧白闪，现实环境音在白闪下压低，回忆环境音提前 0.2 秒进入。
- **返回现实：** 反向使用同一规则。最后一个回忆镜头停在稳定姿势上；现实镜头先建立现实锚点并静默稳定，再开始 OS 或对白。

弱写法：`现实场景里A看着B离开，尾端闪白变成回忆场景。`

强配对：

- `现实触发镜：B离开后，A视线从出口落到正前方道具，右手悬停，尾0.6秒保持静止。`
- `回忆起幅镜：回忆道具横在画面下半区，B在左侧做准备动作、A在右侧站定，前0.7秒二人闭口不动，随后A开始说原文。`

弱写法：`B右侧近景，A左前景朝右，C左后虚化。`

强写法：`同一张长桌横贯画面下半区，桌沿与画框平行；A和B是桌内侧同排双人组，双人组位于画面中右区域，以二人面朝隔物对面的身体左右为基准，A在B左手边、B在A右手边，二人椅背在同一水平深度线、肩线平齐、到镜头距离一致，不隔桌、不面对面、不一前一后；本镜从B侧拍近景，A只作为组内同排前景肩线弱虚化；C在餐桌对面，与双人组隔桌，不插入二人之间。`

## 情绪和表演

每个情绪都必须由以下链条驱动：

`触发原因 -> 表情控制 -> 肢体动作 -> 说话语气`

写链条前先在内部判断：`角色当前目标 -> 正在保护什么 -> 遇到的阻碍 -> 本句对外策略 -> 想掩饰什么 -> 哪个部位先泄露 -> 哪个触发使策略改变 -> 变化后的稳定行为`。这些标签不进入最终提示词；最终只写能被当前景别看见的策略结果。例如同一句拒绝，可以是身体不退但视线避开、先把道具推回再开口，或保持微笑但拇指持续压住杯沿，不能统一写成皱眉和握拳。

为主要人物建立本场内部“表演签名”：一个惯常控制方式、一个压力下最先泄露的身体区域、一个不能反复使用的默认动作。签名不是固定招牌动作；当策略变化时，可见行为载体也要变化。连续三个节拍若同一人物仍靠相同的抬眼、皱眉、握紧、停顿或屏息表达，视为表演没有推进，必须改用距离、道具处理、说话节奏、身体朝向或主动不反应中的剧情适配结果。

每个重要节拍必须产生“策略差值”，不要求情绪升级：可以从试探转为掩饰、从解释转为放弃、从压制转为观察，也可以坚持原策略但付出更明显的身体代价。源文没有策略转折时不得硬造，改由对手反应、空间距离或余波显示原策略产生的后果。

如果原文没有明说情绪，就从角色当下目标、阻碍、关系和上一节拍残留推断。用可见微动作和声音语气表达，不要只贴情绪标签。

常用可见泄露：眼神停顿、眉尾压紧、嘴角控制、憋住呼吸、肩膀绷紧、手指停住、握紧、小半步、衣物/道具接触。

每个重要节拍，直接提示词应包含一条紧凑的自然语言表演链：

`触发后 + 眼/眉/嘴/呼吸 + 手指/肩膀/身体/道具 + 语速/音量/尾音 + 听者延迟反应`。

弱写法：`A很生气，B尴尬。`

强写法：`听见“没关系”后，A眼神停半拍、下颌线绷紧，垂在裤侧的右手攥紧又松开；B夹在中间，筷子停在餐盘上方，肩背轻僵但闭口。`

不要让表演只存在于 `【表演轴】`。主要情绪转折至少要在直接提示词里写出两个可见面部/身体线索；如果另一个重要角色可见，还要写一个延迟听者微反应。

人物资产参考图负责脸部身份和外观连续。本文件只规定“表情如何被看见”，不要求写“双人锁脸”等抽象稳定词。近景/肩后近景的关键情绪，至少加入一个面部微表情（眼睑、眉尾、嘴角、下颌、喉咙或呼吸）和一个身体/道具证据；中景则把面部细节降级为肩线、距离、手和道具，避免远景写不可读的眼部微变。

### 情绪动作链组件

这些组件是生成提示词时的可变体库，不是固定模板。每次只按剧情触发、角色性格和景别容量选 3-5 个可见节点，改写成自然句；不要整条照抄，也不要在远景里写指尖、泪痕、瞳孔等不可读细节。

- 假装生气：眉心轻皱、眼神先顿住、嘴角压下轻抿、指尖捏住袖口或当前衣物、视线故意移开、眉尾轻挑。适合轻喜剧、撒娇、嘴硬、口是心非；语气可压低但尾音不真正发狠。
- 高傲打量：呼吸平稳、肩颈不动、下巴只抬很小角度、视线从对方衣着/手中道具扫到脸、嘴角不笑或只轻压、停半拍再开口。适合权力位、审视、轻蔑、看不上；避免直接写“高级”，改成克制、冷、稳的可见动作。
- 开心惊喜：嘴唇微张、眼底发亮、眼角弯起、右手或当前空手快速轻柔捂到唇前、指尖停住、不敢相信地慢眨。适合收到好消息、误会成甜蜜结果；动作轻快但身体不大幅乱跳。
- 惊讶恐惧：呼吸变浅、嘴唇微张却发不出声、喉间发紧、肩颈僵住、手指攥紧衣袖/包带/被角、身体下意识后退半步。适合威胁、突然真相、被发现；若有道具或障碍物，先写手抓住最近支撑物。
- 耍小性子：鼻尖轻吸气、双手缓缓抬起、袖口/衣摆自然下垂、双臂轻轻抱起、肩膀微收、下巴轻抬、斜斜瞟人后又躲开。适合亲密关系里的不满、撒娇式抗拒；不能拍成真正愤怒。
- 失望无奈：垂眸半秒、缓慢抬眼、眼神从受伤转为疏冷、说话前轻吸气、用很轻的音量说出关键句、说完移开视线。适合“你信不信都随你”这类放弃解释；尾帧给视线离开或距离拉开。
- 伤心怨恨：单侧泪痕或眼眶湿亮、下巴轻颤、呼吸短促、抬眼时目光湿冷、指尖点住掌心或压住当前道具、原本的笑意慢慢收回。适合爱恨交织、被背叛、压住疯狂；优先近景/特写，不要多人中景硬写泪痕。
- 悲伤痛苦：下颌发紧轻颤、肩颈收住、闭眼低头、抬臂遮住眼睛、借手臂克制擦泪、身体随呼吸细微发颤。适合崩溃前的压抑、独处痛感、被击中后的余波；强烈情绪后必须给 0.8-1.5 秒闭口余波。

使用这些链条时遵守三条硬规则：

- 先写触发原因，再写表情和身体：`听见“...”后，A眼神顿住...`，不要无因出现表情。
- 一条直接提示词只保留一个主情绪方向；若从惊喜变恐惧、从假生气变委屈，拆成两个子镜头或写清中间触发。
- 情绪链必须绑定当前物理事实：手只能碰到已经在身边的袖口、手机、杯子、卡、包带、桌沿、被角或支撑物；不能为了情绪让道具闪现到手里。

### 对白画面质感

对白戏的质感来自“表演被光和物件托住”，不是靠华丽形容词。重要对白镜头在直接提示词中按需加入一项可见质感落点：

- 脸部质感：侧光落在一侧脸颊，另一侧保留浅阴影；眼下/下颌/喉咙在近景中可读。
- 手部质感：手背或指节受光，卡边、手机边框、签字笔或杯沿出现微反光。
- 隔物质感：柜台、玻璃、桌沿、门框或车窗形成前景遮挡，反光压暗不遮挡口型。
- 背景质感：公告栏、橱窗、灯牌、走廊线或窗帘弱虚化，只固定空间和氛围，不生成清晰文字抢戏。

质感不能增加生成负担：一条镜头最多一到两项，且必须服务当前关系、情绪或道具状态。若本镜已经有长台词、多人反应或道具转移，只保留一个光影锚点，不再堆材质。

## 张力补偿

张力补偿不是给提示词加华丽形容词，而是在安全物理关系内加入一个“台词之外也能被看见”的戏剧动作。重要对白镜头组在输出前检查：如果整组只有说话者开口、听者闭口和固定中近景，就必须重写其中一个子镜头，加入以下任一类非台词张力点：

- 反应延迟：关键台词前或后停 0.3-0.8 秒，人物先看道具/避开视线/呼吸停住，再开口或回应。
- 手部/道具压力：手指压住卡边、拇指扣住手机、整只手停在签字笔旁、递出后迟半拍松手、接住后向掌心收紧。
- 距离变化：靠近半步、后退半步、身体留在原位但肩线缩起、原本并肩变成面对面或原本靠近变成隔物相对。
- 遮挡关系：门框、玻璃反光、柜台、桌沿、前景肩线或手机边缘切开两人关系。
- 视线错位：身体面向对方，但视线落到道具、门口、地面或对方手上；只有剧情回避、心虚、压制、观察或克制时使用。
- 有意义的插入/切空：手机、银行卡、签字笔、空位、门缝、杯子、衣袖、伤口、玻璃倒影等承载当前关系的物件；不使用泛泛风景填时间。

关键台词不要默认第一帧开口。若台词是质问、拒绝、承认、反击、关系重定义或情绪落点，直接提示词默认加入开口前 0.3-0.8 秒的可见停顿，再让说话者开口。停顿必须对应可见动作，例如 `垂眼看卡`、`指腹压住卡边`、`下颌绷住`、`视线避开对方`，并相应增加时长。

重要道具转移不能只像物流流程。除了起点、接触、移动、松手和稳定终态，还要加入一个情绪阻力点：不立刻松手、接近但不敢碰、接住后呼吸停半拍、指节压白、手停在空中、对方视线先落到道具再落到人。若加入阻力会让同镜过载，就拆成道具/手部插入镜头或反应镜头。

### 张弛节奏

张力不是每句都拉满，而是让观众感觉压力在呼吸。对白或对手戏按下面节奏选择镜头强度：

`松弛铺垫 -> 轻微升压 -> 峰值落点 -> 余波释放 -> 短缓冲`

- 松弛铺垫：用双人/多人关系镜头，动作自然，表情不重，给空间和人物关系留呼吸。
- 轻微升压：只选一个压力点，例如视线错开、手停在道具边、身体靠近半步、前景遮挡或短推。
- 峰值落点：只给真正改变观众理解的台词、动作或反应。此处可切近景/特写/插入，但避免同时加复杂运镜和多人强反应。
- 余波释放：说话者闭口，被击中者或关系结果停住 0.8-1.5 秒，动作比峰值少，但信息更清楚。
- 短缓冲：用拉开关系镜、物件结果、空位、门缝、环境声或低幅动作，让下一组重新起势。

连续对白中，不要三句都用同一种强度。普通解释句承担铺垫，试探句承担升压，关键词句承担峰值，沉默/道具落定承担释放。若源文连续高压，也要在每个峰值后用 0.5-1.2 秒可见余波让观众吸收。

喜剧错位的张弛节奏不同：先轻松正常地拍，再用 0.3-0.6 秒停顿让误会显形，最后用听者反应或道具/UI落梗。不要把喜剧误会拍成沉重压迫。

张力手段必须和景别绑定：

- 中景/关系镜负责“松”：让观众看清谁和谁隔着什么、谁更靠近出口/柜台/桌边，动作自然，不靠眼神细节撑戏。
- 中近景负责“升”：保留双方肩线、手和道具，加入一个短停顿、视线错位、手停住或半步距离变化。
- 近景/肩后近景负责“刺”：只拍一个说话者或被击中者，台词关键词、下颌/喉咙/嘴角/眼睑变化和一项手部或肩背证据同场出现。
- 特写/插入负责“泄露”：手、卡、手机、杯水、衣袖、伤口、签字笔等只承担一个可见心理动作，不同时承载长台词。
- 拉开/物件结果负责“缓”：峰值后把关系重新放回空间，或拍道具停在谁手里、门缝/空位/桌面结果，让下一组有重新起势的空间。

## 情绪弧与释放余波

短对白组不要求人物爆发，但要让情绪至少经过两个不同阶段：触发前的原状态 -> 触发后的压住/回避/接近 -> 台词落点后的可见余波。不要让同一人物每镜都重复“眼神停半拍、皱眉、手指收紧”。

如果源文在拒绝、承认、质问、关系重定义、道具归还、保护动作或“听者被一句话击中”后停住，默认新增独立余波子镜头，而不是把反应压在说话者镜头边缘。余波通常 0.8–1.5 秒，只呈现源文已经产生的情绪后果：视线抬起又避开、嘴唇动一下压回去、肩线下沉、呼吸乱一拍、手松开道具、人物之间空出半步或镜头短暂拉开，不新增哭喊、反击和新台词。只有下一组第一镜已经专门承接该反应，或源文立即进入更高优先级动作，才允许把 0.6–1.2 秒余波压回信息落点镜尾部。

独立余波镜的直接提示词必须先写本镜开头当前事实：谁面向谁、二人距离、道具在哪个人哪只手或哪个台面、说话者是否闭口。然后只给被击中者一个可读反应，近景/肩后近景写一项面部证据加一项身体或道具证据；关系镜头写距离、遮挡或空位变化。画面结束时要给出关系定格：角色是停在原地、后退半步、没有离开，还是仍然面对对方；关键道具是被留下、未接回，还是稳定在某人手里。不要再让说话者继续解释，也不要让道具位置在余波镜里跳变。

女主/男主不按性别套固定反应。若源文只支持克制或隐忍，释放可以是微小但不同于前镜的身体事实；若源文明确支持爆发，再升级为后退、甩手、声音卡住或独立反应近景。

## 动作和表演密度

每条直接提示词至少包含一个可见表演泄露点，以及一个物理动作或静止契约。

- 最低画面密度：除手部特写、纯物件插入、空景外，普通对白/剧情镜头必须自然包含 `固定锚点 + 人物物理关系 + 前后层级/遮挡 + 身体朝向 + 道具状态 + 情绪泄露动作 + 镜头静止理由或单一路径 + 尾帧余波`。不要把画面描述写成 `地点 + A在左B在右 + A说台词`。
- 景别容量先行：写提示词前，先检查本镜景别最多能承载多少信息。特写/近景只承载一个主脸或一个手部/道具，最多加一个边缘肩线；中近景承载一个说话者加一个听者肩线/低幅反应；中景承载二到三人关系和大动作；全景/中远景承载空间、动线和群体关系。超过容量就拆镜，不要把所有出场人物塞进同一画面。
- 反应强度分级：
  - 轻反应：眼神停顿、慢眨眼、嘴角压住、呼吸变化；可留在说话者镜头里。
  - 中反应：肩背缩起/下沉、整只手停住或离开道具、道具被压紧、身体转向或避开；至少写一项身体/道具动作。
  - 强反应：后退半步、声音卡住、想开口又吞回、手把道具压在胸前或桌沿、距离关系改变；优先给独立近景/肩后反打。
  - 爆点反应：观众理解因反应改变，例如被刺中、承认、崩住、突然意识到、关系失衡；必须独立镜头或道具/手部插入承载，不能只做说话者镜头边缘反应。若它发生在镜头组结尾，优先成为最后一张无台词余波镜。
- 切镜触发器：出现权力关系变化、听者被刺中、道具意义变化、说话者压迫升级、对方回避/不敢回应、台词后的沉默比台词更重要时，检查是否需要换成关系镜头、肩后反打、听者近景、手部/道具插入或拉开关系镜头。不要连续三张同景别固定对白。
- 表情可读规则：表情词必须落到景别能看见的部位。近景/特写写 `眼睑压低/睫毛颤一下/眉尾收紧/嘴角压住/下颌绷紧/喉咙轻动/呼吸停半拍`；中近景加 `肩背缩起/手停在道具边/身体不退或后撤半步`；中景/全景不要写细微眼神作为信息落点，改用距离、遮挡、道具和身体动作。禁止用 `眼神复杂、微微皱眉、表情平淡、神色变化` 当作主要表演。
- 把镜头当成一个“视觉情绪单位”，不是一句文本。如果某个微动作属于同一个情绪节拍和同一个物理关系，不要自动拆出去。可以用镜内分阶段机位路径保持节拍连续，例如 `关系中景起幅 -> 轻推/转焦到可读手部或眼神 -> 尾帧回到情绪状态`。
- 只有镜头任务过载时才拆分：可见说话者切换但没有闭口间隙、时间/地点/现实层变化、新主体成为主要表演者、两个以上道具转移、身体接触 + 运镜 + 长对白同时存在、或微动作藏在画面下方且无法安全推近/转焦读到。
- 长动作链拆分：若同一镜头包含四个及以上连续物理动作，或同时包含转身/走近、道具转移和运镜，按“准备/定位 -> 接触/转换 -> 终态/余波”拆成两到三张子镜头；每张只保留一个主要动作，避免 AI 简化中间步骤。
- 写提示词前，先按动作所需画面占比选择景别。大调度和群体关系需要广景/中景；对白和脸部反应需要中近景/近景；指尖、手机、卡、餐盘归属需要近景，或带时间锚点的推近/转焦落点。如果提示词包含 `眼神细变、嘴角、喉间、手指、拳头、筷子、银行卡、餐盘边缘`，镜头必须开头就足够近，或按时间锚点移动到足够近。
- 依赖细小手部、手指、眼睛或道具细节的戏剧信息，不能使用中景/广景固定镜头；除非画面已经是近景/插入镜头，且固定镜头服务于精准口型或接触动作。中景/广景里要使用推近/转焦落点，或把动作放大成整只手、肩膀、身体动作。
- 用身体证据替代情绪标签：不要只写 `慌乱`，要写 `眼睫颤一下、指节压住领口、肩膀微缩`。
- 重要情绪转折至少用两个脸部/身体细节加强：眼神、眉尾、嘴角、呼吸、肩膀、手指、姿态、小步、衣物/道具接触。
- 先写触发，再写反应：`听见关键词后，听者延迟半拍抬眼，指尖停在道具边`。
- 微动作必须匹配景别。多人中景可以展示整只手、肩膀或身体后缩，但不能稳定展示指尖细节。如果节拍依赖 `指尖`、`指节`、`戒指`、`签字笔尖`、`筷子尖` 或桌下手部动作，就用手部/道具近景，或把动作放大成 `整只手离开道具、退回桌沿内侧`。
- 如果中景必须先建立多人物关系，而情绪揭示落在手、拳头或餐盘反应上，就写连续镜内机位路径：先锁空间锚点和槽位，再推近/转焦到可读细节，最后说明其他角色仍留在哪里。这优先于把整个节拍塞进静止中景。
- 限制动作预算：每个节拍一个主动作 + 一个听者微反应。如果同时出现两个手部动作、说话者切换和运镜，就拆分或简化。
- 写清动作路径和结果：`右手把道具沿桌面推到角色B当前座位正前方，手离开道具边`。
- 分开写视线和身体移动。除非身体真的要前倾或越过隔物，不要写 `角色越过桌面/越过柜台看道具`。如果只是视线越过隔物，写 `角色站直留在隔物对面，上半身不前压，视线越过桌沿/柜台边缘落到道具`。如果确实前倾，要写成量化身体契约：`角色脚步留在原位，上半身向前倾约10-15度，单手/双手撑在桌沿，胸口不越过桌面中线，视线落到道具，尾帧保持前倾但不穿桌`。
- 不要移动一个不在当前起始位置可触达范围内的道具。如果 `道具Y` 上一镜停在 `角色B正前方`，下一条直接提示词不能写 `角色A把道具Y挪回`，除非先让 `角色A` 进入可触达位置，并展示伸手/接触路径。
- 交换两个道具时，不要写成一个同时发生的句子。先写两个道具的起点，再移动道具 X 到新持有人/新位置并松手，再移动道具 Y 到新持有人/新位置并松手，最后写尾帧。最终归属重要时，补 `双手离开` 或 `不再拿回`。
- 静止也是动作：写 `尾0.6秒筷子悬在餐盘上方、眼神停在桌面`，不要只写含糊的 `保持`。
- 关键虚化、手距和道具关系要轻量量化：例如前景肩线约占画面1/5、二人相距半身、手距道具约一掌、道具停在两人胸前之间。只在会影响生成的镜头量化，不把每条提示词写成测量表。

## 机位执行强度

直接提示词里的机位词必须是物理可读、图像/视频模型能理解的。

- 固定镜头：写出视觉原因，例如 `摄影机固定，焦点锁手腕和银行卡接触点`。
- 推/拉：写路径和距离，例如 `摄影机沿直线缓慢推近0.3米，焦点锁主体双眼`。
- 跟拍：写路线和速度，例如 `摄影机胸高沿餐桌右侧平行侧跟1米，不超过人物`。
- 前景肩线镜头：写清机位归属、肩线占比、清晰主体、隔物和共享锚点。
- 避免会暗示剪辑或模型不可见逻辑的机位词：不要在直接提示词里写 `镜头语言表达压迫`、`正反打`、`沿轴线` 或 `连续变景别`。

## 台词和时长

源文括号表演提示与原台词绑定，优先级高于常规情绪推断：`角色（提示）：台词` 与 `角色：（提示）台词` 都先保留原提示，再把它一致投影为可见表演和声音处理。提示写“笑”不等于夸张大笑，应按人物策略选择有依据的克制幅度；不得同时编译成相反的怒吼、哭喊或无因爆发。情绪依据统一按 `源文明示提示 > 前情/余波 > 当前目标与策略 > 保守推断`，低优先级只能补空缺。

每个重要表演节拍使用同一闭环：`触发 -> 接收 -> 可见处理 -> 选择/压住选择 -> 对手反应 -> 落幅`。表情只是“可见处理”的一部分；若人物收到刺激后没有可见处理、选择或压住动作，只写皱眉/眼神复杂仍判表演未完成。有效克制可以是手伸到一半停住并收回，落幅保留手已撤回的新状态。

- 原文台词必须逐字保留。
- 可见人物说出口的台词，默认必须原样写进 `【画面描述｜直接复制】`，并保留引号、标点、省略号和疑似错名。`【表演与声音】`、`【口型分窗】` 可以重复原台词用于语速、停顿、口型窗口，但不能是可见台词唯一出现的位置。只有用户明确要求“不要把台词放进画面描述”，才允许不进入直接提示词。
- 短中文台词可按每秒约 4-6 个中文字做 shadow 估算，再加反应余量；实测配音/音频时长优先，估算不单独判失败。
- 2-4 个字的短句，口型窗口通常为 0.4-0.9 秒；说完后写 `说完即闭口`。
- 长台词如果真实配音或 AI 配音音频加反应余量超过 15 秒，必须拆分。
- 除非原文明确要求打断或重叠，同一镜头只允许一张可见嘴巴说话；真正重叠台词交给后期声音处理。
- 每条台词、OS 或系统音都要有语速、音量、停顿/尾音、情绪动机，以及“可见口型或后期声音处理方式”。
- OS、OV、系统音、内心独白、旁白默认写进 `【画面描述｜直接复制】`，同时仍按后期声音/画外声音处理；画面中可见嘴巴保持闭合。手机聊天消息、来电名称、通知弹窗等需要准确读取的 UI 文本默认后期叠加：直接提示词只预留安全区或屏幕平面，具体文字进入 `【表演与声音】` 的后期文字句。只有用户明确接受文字近似并要求 AI 画内生成时，才把单条短文本写进直接提示词。
- OS、OV、系统音、内心独白、旁白只要有具体文本，必须保留原标点；其中 OS 必须写成 `人物名OS：“原文。”`，人物名与本集角色声音锁定表一致，其他声音写成对应 `标签：“原文。”`。语速、音量、停顿、情绪动机写在引号外。不要写成 `OS以低音量响起：“原文。”`，要写 `[真实姓名]闭口，听见对方话后指尖停在手机边；[真实姓名]OS：“原文。” 低音量，尾音心虚收住。` 方括号内容必须替换为声音锁定表中的真实人物名。

## 口型分窗和说话交接

只要存在可见台词，都必须在内部完成开口前锁位、台词窗口、说完闭口和句末余波规划。只有多说话者、长对白、抢话、复杂停顿、可见说话者交接或运镜与口型并存时，才在最终 Markdown 输出 `【口型分窗】`。输出时每个说话窗口都需要一行：

`D1｜可见说话者｜原文台词｜开始-结束｜开头姿势 → 说完闭口｜停顿和重音词｜其他可见人物闭口规则｜触发后的听者反应`

- 一个窗口只有一个可见说话者。说话者脸和嘴必须可读；如果无法稳定保证，就把台词改为后期配音，或拆镜。
- 时间窗可保持相对描述；一旦写数字区间，必须另列锁位、静默/反应和落幅区间，使所有区间从0秒连续覆盖镜头结束，无越界、空档或未声明重叠。
- 新的可见说话者只能在上一位说话者说完、闭口并留出短反应间隙后开始。除非源文明示抢话，规划时默认留 0.2-0.4 秒间隙。
- 用自然语言标注有意义的标点：短逗号停顿、省略号拖住、问句尾音上扬、某个词被加重。不要把所有标点机械分配同样时长，要适配自然说话和真实配音或 AI 配音音频。
- 抢话时写清被打断的具体字、第一位说话者闭口时刻、第二位说话者开始时刻，以及被冻结或改变的手势。真正重叠时，保留一个可见口型，另一个声音交给后期。
- 在台词让画面过载前拆分：说话者切换、情绪转折、动作转折、视角变化、强停顿，或一条台词让开头姿势、可读口型、闭口和听者反应时间不足，都是合理拆点。时长不是唯一标准。

### 对白活体节奏

对白镜头不是“说话者动、其他人停”。每条可见对白都要按时间分三段规划：

`开口前锁位 -> 台词触发 -> 句末余波`

- 开口前锁位：0.2-0.5 秒，所有可见非说话者闭口，身体朝向和视线稳定，先让空间和口型对象清楚。
- 台词触发：说话者开口，只有一个可见嘴巴说话；在关键词后 0.2-0.6 秒，安排一个主要听者低幅反应。
- 句末余波：说话者说完即闭口，留 0.3-0.8 秒给被影响者反应或关系定格；下一位说话者不能无缝开口，除非源文明确抢话。

多人对白中，每个口型窗口只允许一个“主要反应者”。其他清晰人物只写活体状态，例如呼吸、慢眨眼、视线保持或极小幅度换重心。若三人都需要可读表情，拆成关系镜头、说话者镜头、听者反应镜头，不要让一个镜头同时生成三张表情。

听者反应要写进 `【画面描述｜直接复制】`，不能只放在 `【口型分窗】`。`【口型分窗】` 负责时机和优先级；直接提示词负责让即梦看见反应。

OS/系统音写法：

`[真实姓名]闭口；[真实姓名]OS：“原文。” 偏快语速、低音量，尾音心虚收住。`

更完整写法：

`[真实姓名]身体面向门口但没有迈步，右手停在手机边，嘴唇闭合；[真实姓名]OS：“原文。” 低音量，尾音压住，[真实姓名]听到内心声后慢眨一次，视线从门缝落回手机。`

如果需要可见系统文字：

`系统文字仅在侧边安全区作彩色悬浮字幕，不遮脸、不遮手、不生成系统实体。`

## 听者反应

不要只用 `闭口` 解决不说话角色。

- 反应时机：在说话者触发词后或台词落下后 0.2-0.6 秒开始。
- 反应预算：每个节拍每个听者只给一个微动作。
- 动作幅度：听者动作小于说话者。头部转动约 5-10 度，肩膀/身体偏移低于 15 度，单个微动作 1.2-2.5 秒，慢速自然眨眼；除非源文要求，不要重复抖动。
- 反应原因：写出他们对什么反应，例如 `听见“帅哥”后`、`被当众点名后`、`看到餐盘被推走后`。
- 闭口规则：非说话者保持闭口，除非他们拥有自己的台词窗口。
- 焦点规则：听者反应服务于主说话者，不能抢主焦点。
- 轮换规则：连续三句以上对白时，不要每句都让同一个听者重复同一种动作。按剧情压力轮换为 `视线反应 -> 手/道具反应 -> 肩背/距离反应 -> 独立余波`，但每个镜头只选一种。
- 降级规则：如果听者不承担本句反应，就写成 `前景肩线弱虚化，闭口呼吸平稳`、`后景低幅站立，视线停在说话者方向` 或直接不入画；不要清晰站在画面中央却没有反应。

示例：

`角色B说话时，角色A延迟半拍抬眼，整只手停在自己道具边、肩背轻僵但闭口；角色C视线从A移到B，下颌轻收不说话。`

# 角色表演基线库

本文件用于避免同一人物的表演手感无因漂移。下面是可拆分、混合和改写的观察角度，不是人格分类器；模型以源文人设、当前策略、关系压力和已经发生的身体状态为准。

## 使用方法

理解主要人物平时怎样控制自己、压力从哪里泄露、动作幅度如何变化、什么事件足以打破常态。可以只在内部记住结论，不要求固定表格。爆发必须来自源文事件和关系积累，不能为了戏剧性随意升级。

## 常用基线

### 克制冷感型

- 常态控制：表面平稳，反应慢半拍，先压住再说。
- 泄露部位：眼睑、下颌、手指、当前道具边缘。
- 动作幅度：低幅；不轻易后退或大幅摆手。
- 爆发阈值：被羞辱、被误解到关系破裂、重要人物受伤。
- 禁止：连续捂嘴、夸张瞪眼、每句都强皱眉。
- 句式：`听见关键词后，A眼神停半拍，下颌线收紧，右手指腹压住手机边缘，开口时音量仍低。`

### 外松内紧型

- 常态控制：表面轻松，身体姿态松，手部或视线泄露真实紧张。
- 泄露部位：嘴角、眼神停顿、指尖、脚尖方向。
- 动作幅度：中低幅；允许轻快小动作，但不能乱跳。
- 爆发阈值：玩笑被戳破、亲密关系受威胁、隐瞒暴露。
- 禁止：一直严肃冷脸、每个反应都哭。
- 句式：`A嘴角还挂着笑，眼神却在听见那句话后顿住，指尖轻轻扣住衣袖，视线故意滑向别处。`

### 直球外放型

- 常态控制：反应快，身体先动，语气直接。
- 泄露部位：眉眼、身体前倾、整只手、步伐。
- 动作幅度：中幅；允许靠近半步、抬手、转身。
- 爆发阈值：保护、告白、正面冲突、被阻拦。
- 禁止：长期沉默不反应、过度阴冷。
- 句式：`A听完立刻前倾半步，眉眼亮起，右手从身侧抬到胸前，话出口前只停了很短一拍。`

### 敏感讨好型

- 常态控制：先看别人反应，再调整自己。
- 泄露部位：视线、肩膀、双手、衣袖/包带。
- 动作幅度：低幅；常有后缩、停住、低头。
- 爆发阈值：被当众否定、被抛下、努力被误解。
- 禁止：突然强势压迫、过度潇洒。
- 句式：`A先看向对方的脸，又迅速垂眼，双手攥住包带，肩膀微微缩起，声音小到尾音发虚。`

### 权力压迫型

- 常态控制：不急，少动，用停顿和视线压人。
- 泄露部位：视线落点、下巴角度、手中杯/笔/戒指。
- 动作幅度：低幅；动作慢而稳。
- 爆发阈值：权威被挑战、计划被破坏、公开失控。
- 禁止：急促乱动、表情过多。
- 句式：`A呼吸平稳，肩颈几乎不动，视线从对方手中道具慢慢扫到脸上，停半拍后才开口。`

### 隐忍受伤型

- 常态控制：先吞回反应，再用短句或沉默释放。
- 泄露部位：喉咙、下颌、眼眶、手背。
- 动作幅度：低到中幅；允许声音卡住、后退半步、手松开道具。
- 爆发阈值：背叛、失去、保护对象受伤、长期压抑被戳中。
- 禁止：一开始就嚎哭、无触发地泪崩。
- 句式：`A嘴唇动了一下又压回去，喉咙轻轻滚动，手从道具边松开，沉默半拍后才低声回应。`

## 组合规则

- 一个角色可以从多个观察角度获得灵感，但最终表演要收束成当前时刻单一、连贯的行为策略，不能把标签并排写进提示词。
- 常态、掩饰和失控之间的变化应由事件触发；不要按“普通镜/峰值镜”机械分配表演强度。
- 如果源文没有强烈情绪，优先写“动作变小、反应变慢、视线改变”，不要主动升级哭、怒吼、甩手。
- 表演基线不能覆盖剧情事实：源文明确开心就不能强行冷感，源文明确害怕就不能只写高傲。

## 年龄与家庭关系观察

### 儿童表演

- 儿童的注意力往往先被具体物、成人语气或眼前结果吸引，再理解抽象关系；可用视线先到物、半拍后到人表现理解过程。
- 直率不等于持续大动作。孩子可以认真扶稳篮子、急着举证、先抿嘴再复述学到的话；动作幅度由任务和性格决定。
- 成人身高差会改变仰视、递物高度和触达范围。儿童不应为了同框被无因拉长身体，成人也不应始终弯腰迁就镜头。
- 同一家庭的孩子仍需不同策略：一个抢着解释，另一个守住物证；一个观察成人脸色，另一个先保护母亲。不要让孩子同步眨眼、同步点头或共同说同一句非原文台词。

### 亲子与照顾关系

- 保护可落在挡住危险、扶稳容器、替孩子接住成人视线、降低音量或把身体转成屏障；温柔不只靠微笑和暖光。
- 父母怀疑孩子时，提问、视线落点和接近方式决定压力。孩子的回答可能先维护事实、维护另一位家长，或先确认自己是否被责怪。
- 成人听见孩子复述另一位家长的教导时，可出现认知延迟：目光先落证据，呼吸或手势停住，再抬眼看人；是否显露愧疚由原文决定。

### 夫妻、手足与长幼

- 夫妻克制常通过共享空间却不共享视线、替对方收拾残局、让出或守住门槛表达；不要统一处理成冷脸对峙。
- 手足协作可以拆分职责：一人说、一人托物；一人冒进、一人把他拉回；听者反应应体现熟悉彼此节奏。
- 长者动作可以更经济，但不等于迟钝；一次抬眼、手离开茶盏、坐姿重新立直都可改变群体权力。

## 群像、喜剧与沉默

- 群像反应按信息传播发生：最近或最知情者先接收，随后才影响旁人；不要求固定波次，也避免全员同拍转头。
- 主要发言者承担口型，关键听者承担关系变化，其他人用不同视线目标、任务动作或暂不反应维持个体性。
- 喜剧表演先保护正常行为和人物自尊，再让误解、过度认真、动作冻结或错误接话形成落差；笑点落在最懂或最晚懂的人身上，而不是全员做鬼脸。
- 无台词段落仍需策略：人物看到什么、决定什么、身体先做哪一步、谁注意到结果。表情只是证据之一，不能代替原因与结果。

## 倾听者与持续行为

“边听边点头、一直敲桌、反复捻衣角、持续转笔”容易被解释为没有停止条件的循环。需要这类动作时，说明触发、有限动作、停止后的手部或身体终态；剩余时间可以是专注倾听、维持任务或真正静止，不必用眨眼和呼吸填满。

工作、行走、择菜、驾驶等功能性行为可以持续，但要让观众读到它何时开始、因新信息怎样改变节奏、最后停在什么动作相位。多人背景优先按关系或空间分组错时响应；角色足够清晰时可以分别设计，人数和遮挡复杂时则减少不服务主因果的细节。具体反应数量和时间窗口由模型依据景别、台词与剧情触发决定，不设统一额度。

# 角色表演基线库

本文件用于解决“同一人物表演风格漂移”。它只影响生成前的内部表演基线，不新增最终 Markdown 字段。使用时按源文人设、当前关系和已发生剧情选择或混合，不按性别套模板。

## 使用方法

内部先为主要人物写：

`人物 | 常态控制方式 | 优先情绪泄露部位 | 默认动作幅度 | 明确爆发阈值 | 禁止表演习惯`

- 常态控制方式决定普通对白如何反应。
- 优先情绪泄露部位决定重复出现的“角色个人手感”，例如总是先动眼睑、总是先压手机边、总是先移开视线。
- 默认动作幅度决定是否允许大幅后退、捂嘴、抱臂、急转身。
- 爆发阈值必须来自源文事件，不得随意升级。

## 常用基线

### 克制冷感型

- 常态控制：表面平稳，反应慢半拍，先压住再说。
- 泄露部位：眼睑、下颌、手指、当前道具边缘。
- 动作幅度：低幅；不轻易后退或大幅摆手。
- 爆发阈值：被羞辱、被误解到关系破裂、重要人物受伤。
- 禁止：连续捂嘴、夸张瞪眼、每句都强皱眉。
- 句式：`听见关键词后，A眼神停半拍，下颌线收紧，右手指腹压住手机边缘，开口时音量仍低。`

### 外松内紧型

- 常态控制：表面轻松，身体姿态松，手部或视线泄露真实紧张。
- 泄露部位：嘴角、眼神停顿、指尖、脚尖方向。
- 动作幅度：中低幅；允许轻快小动作，但不能乱跳。
- 爆发阈值：玩笑被戳破、亲密关系受威胁、隐瞒暴露。
- 禁止：一直严肃冷脸、每个反应都哭。
- 句式：`A嘴角还挂着笑，眼神却在听见那句话后顿住，指尖轻轻扣住衣袖，视线故意滑向别处。`

### 直球外放型

- 常态控制：反应快，身体先动，语气直接。
- 泄露部位：眉眼、身体前倾、整只手、步伐。
- 动作幅度：中幅；允许靠近半步、抬手、转身。
- 爆发阈值：保护、告白、正面冲突、被阻拦。
- 禁止：长期沉默不反应、过度阴冷。
- 句式：`A听完立刻前倾半步，眉眼亮起，右手从身侧抬到胸前，话出口前只停了很短一拍。`

### 敏感讨好型

- 常态控制：先看别人反应，再调整自己。
- 泄露部位：视线、肩膀、双手、衣袖/包带。
- 动作幅度：低幅；常有后缩、停住、低头。
- 爆发阈值：被当众否定、被抛下、努力被误解。
- 禁止：突然强势压迫、过度潇洒。
- 句式：`A先看向对方的脸，又迅速垂眼，双手攥住包带，肩膀微微缩起，声音小到尾音发虚。`

### 权力压迫型

- 常态控制：不急，少动，用停顿和视线压人。
- 泄露部位：视线落点、下巴角度、手中杯/笔/戒指。
- 动作幅度：低幅；动作慢而稳。
- 爆发阈值：权威被挑战、计划被破坏、公开失控。
- 禁止：急促乱动、表情过多。
- 句式：`A呼吸平稳，肩颈几乎不动，视线从对方手中道具慢慢扫到脸上，停半拍后才开口。`

### 隐忍受伤型

- 常态控制：先吞回反应，再用短句或沉默释放。
- 泄露部位：喉咙、下颌、眼眶、手背。
- 动作幅度：低到中幅；允许声音卡住、后退半步、手松开道具。
- 爆发阈值：背叛、失去、保护对象受伤、长期压抑被戳中。
- 禁止：一开始就嚎哭、无触发地泪崩。
- 句式：`A嘴唇动了一下又压回去，喉咙轻轻滚动，手从道具边松开，沉默半拍后才低声回应。`

## 组合规则

- 一个角色最多混合两个基线，例如 `克制冷感 + 隐忍受伤`；不要三种人格混在一起。
- 同一场景内，普通镜头沿用常态；只有峰值镜头才触发爆发阈值。
- 如果源文没有强烈情绪，优先写“动作变小、反应变慢、视线改变”，不要主动升级哭、怒吼、甩手。
- 表演基线不能覆盖剧情事实：源文明确开心就不能强行冷感，源文明确害怕就不能只写高傲。

# 全景、远景与空镜语法

本文件是全景带和空镜的唯一专项参考。它们不是只用于开场交代环境或结尾喘气，而是可承担爆点、行动、权力、认知、喜剧、转场和声音节奏的主动镜头。

## 全景的六种职责

1. **空间钩子**：首镜同时交代异常人物、危险距离、出口、障碍或未完成动作，不先拍无关风景。
2. **动作全貌**：看清起点、路线、接触、受力和终点，避免连续特写切碎动作物理。
3. **关系/权力翻转**：用人物大小、中心/边缘、前后纵深、出口占位和负空间，让控制权变化在一个画面里成立。
4. **规模揭示**：从局部误判切到全景/大全景，揭示真实数量、距离、包围、环境代价或人物处境。
5. **喜剧客观镜**：人物认真执行错误理解后，突然用稳定全景展示客观反差和旁观关系。
6. **结果/余波**：峰值后读清身体、道具、环境和关系造成的不可逆新状态。

全景可以是峰值镜。局部高速动作、主观恐惧或紧张近景之后，突然切到静止全景展示真实后果，往往比继续推近更有冲击。全景也可直接起镜，关键是第一读点明确，不要求先中景过渡。

## 全景构图与运动

每个全景先冻结：

`第一读点 -> 人物/物体画面大小与位置 -> 前中后景层次 -> 出入口/路径/轴线 -> 实体光源 -> 动态锚点 -> 声音落点 -> 稳定终幅`

可选机制：

- **固定图形全景**：用对称、框架、负空间或人物阵列等待动作/证据进入，适合审讯、等待、尴尬和权力僵持。
- **斜俯/高位展开**：沿道路、楼梯、桌面、队列或建筑结构落向行动点，适合规模、路线、包围和环境压迫。
- **贴地/低位全景**：放大脚步、车辆、门槛、障碍和逼近速度，同时保留身体全貌。
- **横移视差全景**：前景掠过、人物持续可读、背景锚点改变相对位置，适合追随、搜索和空间揭示。
- **急拉全景**：从人物/道具局部快速拉开，在真实关系或后果完整出现时急停，适合认知翻转和喜剧揭底。
- **长焦压缩全景**：压近人物与环境/人群距离，适合监视、追赶、危险逼近和无法逃离。

全景不承担眼睑、口型细节、小字或精确手指接触。手机端用轮廓、身份色、运动方向、明暗面积和清楚地标保持第一读点；人物过小时，紧邻补一个情绪/证据镜，不在全景里声称微表情可见。

## 空镜的七种职责

空镜指没有当前主要人物清楚入镜，但环境、道具、痕迹、光影或声音仍在叙事。它必须至少承担一种职责：

1. **声音先行**：先听到脚步、门响、刹车、提示音、呼吸、广播或台词，再让人物/事件进入。
2. **证据/痕迹**：无人持有的文件、晃动杯水、未关门、空座、脚印、破损、亮起屏幕或仍在运动的物体证明刚才/即将发生什么。
3. **威胁与等待**：空走廊、未打开的门、道路尽头、暗处入口或静止车辆用声音/光变化蓄力。
4. **人物缺席**：离开后的空位置、仍摇动的椅子、未收回的物品或环境声，让缺席成为关系结果。
5. **时间/天气变化**：天光、钟表、雨雪、水汽、交通、灯具亮灭或环境活动压缩时间，不虚构新事件。
6. **转场承接**：用形状、运动方向、颜色亮面、实体遮挡或声音桥连接新时空。
7. **客观反差/余波**：人物主观高压后切到冷静环境或受力后的物理残局，让观众重新判断尺度和后果。

空镜不是“房间很安静、街道很美”的装饰句。必须写具名环境/道具、当前状态、唯一变化、声音来源、光源和退出触发。没有新增信息、压力、时间、转场或结果时删除。

## 空镜拍法

- **极短标点空镜**：0.5-1.5 秒，道具反馈、门缝亮起、鞋印、屏幕提示、杯水震动或声音命中后立即切人物。
- **等待型固定空镜**：1.5-4 秒，构图先空着，人物/车辆/声音/影子进入后触发下一镜；不能无变化干等。
- **运动空镜**：沿走廊、道路、桌面、窗外或痕迹移动，终点必须是证据、入口、声音源方向或人物即将进入的位置。
- **人物退出后的残留空镜**：人物离开画面，摄影机不追；让门、空位、道具、灯影或声音保持 0.8-3 秒，交付关系后果。
- **主观空镜**：人物看向画外后切其所见/所误判空间；必须在后续回到人物反应或客观关系，不能让主观误判成为事实。

空镜每个时间窗有一个主动态锚点；较长空镜可以让声音、风雨/烟尘、车辆/人群、灯光和物理余波依次接管，但同一瞬间保持清楚阅读顺序。

## AI 漫剧节奏组合

- **钩子**：异常空镜/局部 -> 人物反应 -> 客观全景揭示。
- **动作爆点**：动作起势近景 -> 全景看清路径/接触 -> 结果局部或残留空镜。
- **权力翻转**：双人近景压迫 -> 突然全景显示出口/占位变化 -> 空位置或道具终态收尾。
- **喜剧**：人物严肃近景 -> 极短停顿 -> 稳定全景展示客观反差 -> 0.5-1 秒道具/环境空镜补刀。
- **悬疑**：人物听见声音 -> 空走廊/门口承载声音先行 -> 局部证据 -> 全景重建真实威胁。

组合只取当前节拍需要的 2-4 项，不机械套齐。全景和空镜都必须进入观看距离/动势曲线；连续两场不得用同构“空景建立 -> 人物入画”开场，除非构成有升级的视觉母题。

## 首次生成必成条件

全景与空镜的职责、第一读点、时长和终幅在观看距离曲线首次生成时直接成立，不在成稿后按景别比例补镜：

- 每个全景有第一读点、空间/动作/关系职责和稳定终幅，不只是“交代环境”。
- 生成动作峰值时直接比较全景与继续近景的读取收益；路径、规模或后果由全景更清楚时，当场选为峰值或结果镜。
- 每个空镜有具体叙事对象、唯一变化和声音/光影触发，不是填时长或装饰。
- 全景与空镜在手机端仍能通过轮廓、运动、明暗或地标快速识别。
- 使用后确实改变信息、节奏、心理距离或关系读取；无收益则删除。

# 一次内部导演预演

本预演只在八字段落稿前进行一次。它从源文本直接生成并冻结镜头答案，不是成稿后的审查或返工循环。

## 导演直觉首稿先行

锁定源文事实、台词、人物初始关系和不可改变的道具事实后，先完整观看整场，不先做 L0-L3 分类、镜头数估算、连续表演单元合并、详细道具账本或生成风险计算。先凭动作、声音、空间尺度和情绪能量形成一版干净的导演视觉答案；这些治理步骤在首稿后介入。

每个拟定镜头只回答六项：

```text
最强起幅是什么
-> 唯一主要拍摄主体是谁
-> 摄影机的一个主视觉动词是什么
-> 最强落幅是什么
-> 与相邻镜头形成哪一种主要反差
-> 观众为何必须用这种方式看这一刻
```

主视觉动词只选停留、逼近、拉开、跟随、掠过、上移、下沉、揭示、环绕等一个主行为；不在首稿里堆事实覆盖、多人反应、道具说明和多次焦点交接。相邻反差优先从远/近、静/动、遮挡/揭示、单人/关系、持续/急停中选一个最有收益的轴。大胆不是运镜配额：一个静止的大特写接一个斜俯大全景，可以比每镜缓推更有力度。

关系和空间已经在前镜建立后，允许下一镜成为干净的单主体近景、特写、大特写或局部特写。除非遮挡本身是该镜的视觉机制，不惯性保留另一人物肩部、桌角、门框或关系背景；不把“持续交代空间”当成每镜义务。一个镜头只形成一个清楚的视觉句，不设计“先看双人关系，再扫道具，再转到反应，最后拉回环境”的委员会式覆盖路径。

首稿为每条视觉句冻结一个不可牺牲项：起幅、主视觉动词、落幅或相邻反差。后续情绪推导、节拍分类、连续性、道具、物理空间和复杂度预算可以校正其他部分；若方案无事实依据或不可拍，另选一条同样明确的视觉句，不能自动回退为固定中景、普通肩后反打或缓慢推近。

## 连续情绪与行动时间线

先连续播放整场，不从机位或信息清单开始：

```text
原文事实与上一状态
-> 旧预期、旧表面策略与残留情绪
-> 人物实际获得的刺激及精确命中点
-> 人物怎样解释刺激、想得到或隐藏什么
-> 核心情绪、混合情绪与第一行动冲动
-> 源文已给出的强情绪结果怎样由旧控制失效、可见泄漏和动作起势形成
-> 冲动怎样被压住、从哪里泄漏、转成什么替代动作与新策略
-> 距离、占位、道具、接触或进退姿态怎样形成现实压力
-> 直接听者和旁观者的错峰反应
-> 新关系状态、未释放势能和下一行动倾向
```

为重要节拍先比较面部/视线、手部/道具、身体重心/距离/占位三类动作候选，至少选择一个非面部外部行动；再冻结观众应该感到什么、第一读点是什么、摄影冲击采用什么机制、镜头怎样稳定落幅。选择必须符合人物性格、目标、风险、空间、道具和前因，并确实改变关系读取。眼神、呼吸、手指、嘴角和停顿只能作为先兆或余波。

源文若已经给出“眼眶发红、快哭、震惊、愤怒、悲伤、害怕、僵住、颤抖”等结果，不得把该词或近义词搬进 `画面/表演` 就视为完成。先把结果反推为三项导演化增量：旧表面策略在哪里失效；控制从声音、下颌、肩背、手臂、重心或道具哪里可见地破裂；身体怎样开始朝下一动作方向蓄势。源文只写红眼眶时可以保留湿亮、声音受阻或强忍状态，但不能新增落泪、痛哭或情绪崩溃。

动作阶段只冻结情绪方向、动作性质、先后因果和关键接触，不提前把站位、路径、幅度和遮挡写死。允许补充递出前压平纸角、接收者先看落款再接文件、接触后延迟松手、旁观者翻页停顿等即时演绎，但不得改写剧情事实、台词、人物性格或结果。

## 连续表演单元与切镜准入

导演直觉首稿后，再按人物目标、说话策略、主要行动方向和空间关系划分连续表演单元。连续表演单元要求动作、情绪与道具状态不断线，不要求单镜覆盖；刺激证据、控制断裂、动作起势和关系结果需要不同观看距离时，可以在同一单元内组成镜头组。句号、停顿、视线、表情或无收益摄影变化不能单独切镜，但首稿中改变主要主体、心理距离、观看顺序或静动关系的不可替代视觉句可以成立切点。

每个拟切点必须至少获得一个成立理由：主体转移；策略、权力、亲疏或危险判断改变；刺激证据或控制断裂需要独立读取；动作改变距离、朝向、占位、道具、接触或出口；心理距离、观看顺序或静动关系发生决定性改变；新事实无法在当前镜内稳定读取；明确转场。普通对白通常 1-2 镜，一般冲突通常 2-3 镜，关键反转通常 2-4 镜；这些不是硬上限，镜头数量由不可替代观看职责决定。

镜头组形成后反向逐对检查：若后镜只增加重复表情、视线、相似景别或同一信息，且没有形成独立视觉句，则改成镜内变化；每个保留镜头必须独立交付刺激证据、控制断裂、动作起势、策略行动、关系结果、空间重建、不可替代情绪冲击、转场承接，或通过单主体强构图、远近跃迁、遮挡揭示、静动反差改变观看顺序。允许连续三个不超过 3 秒的短镜组成因果短句，随后用不少于 4 秒的稳定镜完成台词、OS/OV、行动或情绪余波。合并若会形成 10 秒以上同一中景/中近景覆盖关键反转，或抹掉已冻结的强起幅、落幅与相邻反差，必须撤销合并。

## 实体与道具状态时间线

完整执行 [entity-prop-continuity.md](entity-prop-continuity.md)。导演直觉首稿完成后再逐场登记源文明示、强暗示和装饰性实体，记录首次建立方式、所属人物、当前控制者、具体位置、可见性、开合/亮灭/完整性及每镜最终状态。首稿前只锁定不可改变的存在、归属和初始事实，不让道具位置预先生成摄影机位；强暗示道具只补完成现实刺激所需的最小实体。

除场景首镜的初始环境建立外，新道具不能第一次出现在 `起始状态`。把首次出现放回镜内因果链：声音或物理反馈发生，人物发现，首次接触或拿出，尾帧冻结已建立状态。若订单超时提示暗示手机，应先让提示音与侧袋震动命中宋棠，再让她伸手压住，尾帧明确手机仍在袋内；下一镜起态接住后才允许拿出。

每镜发生拿、放、递、接、夺、藏、遮、开、关、亮、灭、装入或取出后，立即更新账本，并在 `尾帧` 结算变化后的控制者、位置和必要物理状态。逐对比较前镜尾帧与后镜起态；任何换手、换位、开合、亮灭、显隐或控制权变化都必须发生在某一镜的 `画面/表演` 中，不能利用切镜省略。袋内或画外道具要用手压衣袋、震动声、轮廓或遮挡等画内/声音锚点承接，不能声称看见遮挡内部。

## 显式转场承接

原文出现明确【转场】时，完整执行 [transition-shot-grammar.md](transition-shot-grammar.md)。先冻结上一场尾帧锚点、承接机制、下一场第一读点和声音进入时机，再继续设计下一场。至少生成一个实际编号的转场承接镜头；仅把下一场首镜写成 `转场起镜`、直接切新场大全景或写“画面切换”不算完成。

转场后紧跟信息型 OV 时，转场镜先交付第一个背景事实或身份反差，其余信息拆到下一场 1-3 镜。没有明确过去场面的背景信息只通过当前状态、环境反差、已有道具、声音和现实行动证明，不新增闪回事件。

## 情绪反转与动作策略

出现态度、认知、权力、亲疏或危险判断改变时，完整执行 [emotional-reversal-performance-grammar.md](emotional-reversal-performance-grammar.md)。先冻结“旧策略 -> 刺激命中 -> 反应断裂 -> 替代动作 -> 新策略 -> 新关系”，再进入摄影设计。新情绪必须保留一处旧情绪残留，并让残留出现在声音、手部、身体方向、距离或道具控制中，不能只靠表情形容词宣布变化。

反转包含刺激、反应和策略改变时，先执行切镜准入；无法在同一镜内稳定读取时，再拆成冲击镜、策略镜和必要的结果镜。冲击镜可以让摄影机承担高复杂度；策略镜必须把复杂度交给人物行动，让摄影机只做清楚跟随或稳定落幅；结果镜冻结对方反应、距离、占位、道具或接触的新状态。一个大特写不能同时承担完整反转链，但一个连续运动镜头能够清楚交付的内容也不能机械拆开。

关键冲突、权力博弈和危险判断先确定压力来自哪里：迫近距离或收窄退路、占住中心/出口、控制道具、限制或维持接触、身体朝向与进退姿态至少成立一项，再选择能放大该关系的构图和运镜。视线锁定可以加强压力，但不能在物理关系完全不变时单独作为压迫机制。

关键刺激之后冻结一项可传递的未释放势能：悬置动作、未松开的道具、仍被占住的出口、尚未解除的接触、保留退路的重心或声音余势。非全文末镜由下一镜起始状态接住它；全文末镜只保留稳定余波。普通信息镜和已经完成释放的节拍不制造假钩子，只冻结连续性所需状态。

## 用情绪和事实增强首稿摄影

回到导演直觉首稿，每个节拍同时回答“观众必须看懂什么”和“观众此刻应该感到什么”。先检查首稿的观看距离曲线，再联合校正：

```text
起幅景别 -> 起幅第一读点 -> 动作或台词触发 -> 摄像机行为
-> 焦点交接 -> 终幅景别 -> 终幅新增读取 -> 相邻镜头怎样继续
```

景别和运镜是一个方案。起幅可以建立空间或人物关系，运动过程可以跟随动作、让开遮挡或收紧压力，终幅可以落在表情、接触、证据或结果。不要把每个可用阶段都塞进同一镜：只保留属于该主视觉动词的读取。若另一信息需要不同主体、心理距离或观看顺序，且拟切点通过准入，拆成相邻有职责镜头；不能把互斥信息写成“同时清楚可见”，也不能先把摄影力度降级为中景覆盖。

为每镜建立三张内部静帧：起幅、运动中、终幅。每张静帧分别写清具名拍摄主体和当前景别能看见的范围；身体或服装局部必须注明属于哪名人物。三张静帧最多只能包含两个景别：固定同一景别，或一次从起幅 A 变化到终幅 B。发生变化时，最终 `景别机位` 可写“A 转 B”或显式写“起幅”和“终幅”，`构图/光影` 按阶段描述；若运动中需要第三个景别才能读清，拆给相邻有职责镜头。

整场首稿已经冻结两条互相咬合的曲线：观看距离如何从环境、关系进入身体、脸部或局部细节，再怎样回到新关系；动势如何从停留、蓄力进入快速行动、急停或余波。现在只依据刺激、行动、关系和事实缺口校正，不从零重建曲线，不机械套远中近顺序，也不把固定中景、普通反打或缓慢推近当安全默认。

关键转折把首稿作为候选 A，至少再比较一种机制不同的候选 B，并优先达到三种：表演与调度、构图与遮挡、景别跃迁、快速跟拍与急停、全景斜俯或垂直展开、焦点或声音先行。比较的目标是确认最明确的视觉句，不是把候选优点折中进同一个镜头。惊喜必须改变观众怎样理解人物策略、关系或证据，不能只换低机位、普通推近或无信息环绕；普通正反打和固定中景不得作为未比较候选时的默认答案。

高价值细节可以直接用特写、大特写或局部特写起镜；突然追赶、扑抱、夺取、逃离或决断可以让摄影机快速跟拍，并在接触、落点、抬眼或证据出现时立即停止；人物被环境、权力或困境压住时，可以用大全景或全景从斜俯关系展开，再沿空间落向人物。局部信息读完后，只有人物方位、路径或关系可能丢失时才补关系镜，不机械退回中景。

## 具象画面翻译与表演余地

摄影方案冻结后，把内部的“压迫、失衡、权力、孤立、控制”等意义翻译成可直接想象的画面，不把意义词原样写进最终字段：

```text
具名人物/环境/物体 + 景别 + 高低/俯仰 + 正侧方向
-> 仅在遮挡、轴线、出入口、接触或连续性需要时补相对实体位置
-> 前景/中景/后景与画面左右位置
-> 实体光源、进入方向、受光对象与阴影结果
-> 速度、运动方向、具名对象、停止触发与最终可见画面
```

优先使用低机位、贴地、高机位、平视、仰拍、俯拍、斜俯、正面、侧面、侧后方等定性词。门内、门外、桌边、车内、车外、人物胸口下方等相对位置只在空间逻辑需要时使用，不作为每镜必填。禁止让“控制关系、矛盾关系、职业姿态、压迫感、完整关系、稳定中心”单独成为构图或运镜终点；这些意义必须被人物、前后景和画面边缘的实际位置替代。

表演只冻结五项：刺激命中、主要行动方向、关键接触/道具变化、关系结果、尾帧余势。其余呼吸、表情过渡、动作速度、身体细小调整和台词中的自然停连由人物在性格与目标范围内完成。不要逐帧规定眨眼、指尖、头部角度、每一步和每次停顿，也不要用一串“随后、接着、立刻、再”把动作写成机械指令。自由度不能改变动作起点、因果、接触对象、道具归属和尾帧状态。

保留表演余地不等于省略情绪因果。冲击镜可以不规定每次眨眼和呼吸，但必须写清旧控制的断点与下一动作起势；若下一镜将扑抱、退开、追赶、夺取或离开，本镜尾帧必须已经出现同方向的手臂、重心、身体朝向或道具变化，不能让人物静止在情绪标签上后突然启动。

动作连续性按“起态 -> 主动作 -> 受力/接触 -> 稳定落幅或未完成余势”检查。前镜尾帧若动作尚未结束，后镜必须从同一方向、同一道具归属和同一身体重心接续，人物不能因切镜重新起演。

画外人物只进入声音时间线。若说话者不入镜，写“人物不入镜，在画外说话”，不把视线、目光、打量或审视写成画外可见物，也不在只拍被观察者的镜头里继续描述观察者怎样看。若观察者的眼神本身具有表演价值，就把观察者纳入起幅、运动中或终幅构图；否则只保留画内人物受到台词或现实处境后的可见反应。

## 表现力闸门与复杂度预算

镜头组冻结前，在同一次预演中完成一次表现力闸门：

- 若完整场景长期停留在中景、中近景和近景，检查是否遗漏了不可替代的环境尺度、局部证据、身体接触或认知冲击；有依据时改用大全景、全景、特写、大特写或局部特写。
- 若连续镜头反复使用固定、缓慢推进或普通肩后反打，必须说明这种重复怎样制造等待、压迫或喜剧节奏；没有新增收益就更换为调度、遮挡、景别跃迁、快速跟拍、急停、斜俯或声音先行。
- 若重大刺激发生后人物仍只靠眼神、嘴角、呼吸或手指反应，重新选择会改变距离、朝向、占位、道具控制或行动方向的可见动作，再让摄影机响应。
- 若源文中的“眼眶发红、快哭、震惊、愤怒、悲伤、害怕、僵住、颤抖”等词在成稿中被原样或近义复述，而没有旧控制失效、可见破裂和动作起势，判定为导演化增量不足并重做；禁止只增加“强烈、明显、彻底”等程度副词补救。
- 若冲突只写“目光锁死、气场压迫”，而距离、占位、道具、接触或进退姿态都没有变化，重做物理压力来源，再让摄影机强化结果。
- 若关键刺激所在镜的尾帧已经让人物完全放松、松手、退回安全距离或恢复日常姿态，检查是否过早消解戏剧势能；依据事实保留一项下一镜可接住的未完成状态。普通信息镜不做此强制。
- 若同一人物连续依赖“看、停、微微、缓缓、僵住、眯眼、皱眉、嘴角变化、呼吸变化”，回到动作候选，加入由既有空间、道具、任务和关系推出的拿放、遮掩、退让、逼近、占位、松手、让路或接触动作。
- 若一个 10 秒以上镜头把刺激命中、控制断裂、策略动作、关系结果或长段 OS 中的三项以上放进同一中景/中近景，即使写了短促推进或立即停止也判定为过度合并；拆成局部冲击、反应/策略和稳定承接镜。
- 若连续出现三个不超过 3 秒的镜头，先检查是否分别承担刺激证据、控制断裂和动作起势/结果；三项职责成立则保留。只有出现第四个连续短镜，或前三镜重复同一信息、表情和策略时才合并。
- 若相邻镜头只有景别、角度、视线或表情不同，没有新增事实、策略动作、关系结果、空间重建或转场承接，合并为一个具有镜内变化的镜头。
- 若 `景别机位` 用一个景别概括了从一名人物或身体部位移动到另一处的过程，重写为具名起幅和具名终幅；若 `尾帧` 仍保留已经移出终幅的鞋面、手部、脸或道具，删除该元素或扩大终幅景别。
- 若单镜出现三个及以上景别，保留最有价值的一次 A 到 B 变化，把第三个读取距离交给相邻有职责镜头。环绕、横移或追拍只改变路径时保持原景别，不把运动方向变化误写成多次景别变化。
- 若出现“视线在画外、打量落在画外、目光停在画外”，改成“具名人物不入镜，在画外说话或保持声音”，并让画内人物与摄影机行为承担观察结果。
- 不为追求变化强行加入无动机特写、甩镜、环绕或俯拍；所有大胆镜头都必须有清楚的触发、读取和稳定落幅。

低抽卡使用复杂度预算，而不是把镜头降级为保守覆盖：摄影机运动可以承担高复杂度，人物仍可完成单方向、单目标的大动作，但不叠加复杂换位、换手、多人反应和重特效；人物调度或特效承担高复杂度时，摄影机再降载。复杂度按镜头交接，不按整段永久压低人物：冲击镜给摄影机，策略镜给人物，结果镜给关系读取。快速运动结束后必须留下稳定可读的结果，不在同镜继续叠加多次抽焦、多人换位或重特效。

校正失败时依次尝试：镜内调度或焦点交接；缩小人物动作幅度并保留情绪方向；调整人物站位或加入真实前景遮挡；通过切镜准入后拆成必要镜头组；把多次焦点交接压成一次；缩短、换向或分段完成摄影机路径。只有剧情本身需要停留、等待、对峙或稳定关系读取时才改为固定中景。每次调整都在本次预演中完成，不等成稿后返工。

## 反向设计可拍画面

摄影方案形成后，再为它设计具体站位、朝向、动作幅度、道具路径、前后景、遮挡、光影和声音。每个阶段只写当前景别确实看得到的内容：近景不承担全身路线，全景不承担细微眼神，特写不承担完整双人关系。

只提前冻结墙、门窗、固定家具、出入口、人物初始关系、关键道具归属和实体光源。此时进行一次物理校正：摄影机有真实摆放和连续移动空间，不穿墙、家具或人物；演员可以完成坐站、转身、递接和拿放；遮挡不吞掉主动作、口型、证据或反应；切镜不制造瞬移、换手或无因转身。

候选不成立时，在本次预演中改调度、景别、视角、焦点、遮挡、运动范围或拆镜。物理成立是底线，不是自动退回固定中景的理由。最终 Markdown 只保留语义化画面和摄像机行为，不输出机位证明、器材、坐标、距离、角度、焦距或工程参数。

## 多人和 OV/OS 时间线

每个清楚可见且影响关系读取的人物都有：

`实际获得的信息 -> 正在维持的任务 -> 反应阈值 -> 触发点 -> 可见反应 -> 下一倾向`

直接听者在有效语义点开始错峰反应，不等整句结束；旁观者继续工作、观察、护物或准备介入。OV 是非现场声音，画中人物不回应它，也不等待 OV 结束。旁白段的摄影机可按情绪曲线快速跟随、斜俯沉降、遮挡揭示、推进或拉开；当摄影机承担高复杂度时，人物只保留一处主要现实变化、持续任务或小幅身体压力，其余人物主动保持。现实关系再次变化时才增加新的主要反应。OS 不做口型，其他人物不能读心。

## 镜尾冻结

每镜结束时冻结下一镜真正需要的少量可见状态：人物屏幕侧和朝向、姿态与重心、道具最终控制者/位置/必要物理状态、未完成动作、声音或环境残留、关系余波。关键冲突、反转和非全文末尾的场尾额外保留一项未释放势能；普通信息镜不强行悬置。下一镜用动作接力、状态接力、反应接力或转场起镜自足复述这些状态。显式转场还必须让上一场尾帧留下声音、实体遮挡、运动方向、颜色/亮面或未完成动作中的一个承接锚点，并由下一场转场镜接住。全文最后一镜仍写稳定收束尾帧，并与源文要求的道具最终归属一致。

预演按剧情保真、情绪行动、观看收益、多人生命感、物理可拍、场景专属性和镜间推进的综合结果选定镜头组；完成一次相邻镜头强制合并后冻结，不启动第二轮导演审查。

# 一次内部导演预演

本文件是对白技能的生成阶段核心参考。只进行一次，发生在八字段落稿前；它不是成稿后的审查，也不是把问题镜头先写出来再返工。预演结束后冻结镜头答案，再一次编译 Markdown。

## 预演时间线

将整场从首个起态到最后收束尾帧连续播放，并在同一条时间线上同步记录：

`现实刺激/台词语义点 -> 人物理解与混合情绪 -> 表面策略/身体破绽/隐藏诉求 -> 行动选择 -> 直接听者与旁观者的错峰反应 -> 摄影机/景别/焦点揭示 -> 新关系状态 -> 尾帧与下一镜起态`

每个重要节拍都先回答“人物现在想得到、保住、确认、拒绝或隐藏什么”，再选择动作。情绪必须改变距离、朝向、道具控制、谈话主动权、暴露程度或下一步选择之一；眼神、呼吸、手指和停顿只能作为身体先兆或余波，不能独立代替行动。动作候选至少比较两种，选择依据落在人物目标、关系、风险、空间、时间、道具和前因，不因“更好看”凭空增加事件。

## 物理空间准入

在比较表演或镜头惊喜前，先冻结一张现实空间图：房间边界、门窗、桌椅、柜台、墙柱、固定灯具、人物槽位与高度、身体朝向、视线目标、关键道具高度/归属、180度轴线、前后景关系和摄影机可放置区域。

每个候选必须证明：

- 现实摄影机、机身/支撑和操作者有实际摆放空间；摄影机从起幅到落幅有连续通道。
- 镜头不穿过墙体、家具、门板、人物身体或其他不透明实体；不靠“镜头切到”让人物瞬移、换手、换桌位或突然转身。
- 当前景别确实能拍到正文要求读取的脸、手、道具、身体范围和人物关系；近景不承担全身路径，远景不承担微表情。
- 演员的坐站高度、转身、伸手、递交、拿放和目光方向在当前场地可完成；前景物不会遮掉主动作、口型、关键证据或听者反应。
- 机位、人物视线、镜头焦点和道具运动分别成立，不把它们写成一个含混的“镜头带过去”。

任一项不成立，候选直接淘汰；在同一次预演中改站位、景别、机位、焦点、遮挡关系或拆镜，再继续比较，不在成稿后补救。

## 多人和对白时间线

为每个清楚可见且影响关系读取的人物写一条任务线：

`实际听见/看见什么 -> 当前任务 -> 与说话者/事件的关系 -> 反应阈值 -> 触发点 -> 可见反应 -> 下一行动倾向`

说话者把口型、呼吸、视线、手部和身体距离作为同一策略；直接听者在有效语义点开始小幅错峰反应；旁观者依据自己的信息和任务继续核对、观察、护住道具、承受环境或准备介入。反应可以与台词重叠，不等一句话或动作完成后再统一启动。

OV是非现场声音，画中人物不能回应旁白本身，也不能等OV说完再行动。预演时为整段选一个主要时间承载：一处现实微动作、正在维持的任务或环境动态。默认一名关键人物发生一次主要变化，其余人物以目光、呼吸、重心、持物或任务维持生命感；现实关系再次变化时才增加第二处错峰变化。OS不做口型，其他人物不能读心。

## 景别、机位和焦点

景别切换必须新增观看信息，并说明“观众此刻必须新看见什么”：

- 全景/中全景：空间、人物距离、行动路径和家具关系。
- 中景：双人/多人关系、桌面互动、上半身动作。
- 中近景/近景：策略破绽、对白接收、表情与身体压力。
- 特写：手、道具、身份证据或单一高价值细节。

这不是固定远中近顺序。没有新增关系、证据、反应、尺度或控制权信息时，保持景别，改用表演、遮挡或声音推进。

对白技能默认只用现实摄影机：固定机位、肩扛/手持、稳定器、滑轨、摇臂等只能在场地容得下时使用。镜头字段写明 `起幅 -> 触发 -> 路径/速度 -> 落幅 -> 新增读取`，不写“创意运镜、带到某人、镜头穿梭”。

固定机位必须明确写“摄影机全程固定不移动”。焦点只落在具名人物的面部/眼睛/手、具名道具或明确空间平面；“焦点交给双人关系、情绪、氛围”不可执行。多人同时可读就写中等或较深景深与清晰范围；抽焦时默认只做一次主交接：

`现实触发 -> 起始焦点对象 -> 平缓/快速移焦 -> 终点对象 -> 保持至尾帧`

后景人物可以略微虚化但动作仍须可辨，不要在同镜三名以上人物和多个道具之间往返巡游。

## 惊喜和镜间接力

关键转折至少比较表演/调度、构图/道具、声音/摄影机三种非同构方向。选中的方案必须改变观众的观看顺序、关系读取、道具意义或策略理解；普通推近、无信息环绕、突然低机位和高速甩镜不算惊喜。

每镜冻结终态快照：人物屏幕侧/朝向、身体姿态与重心、肢体/道具归属、未完成动作方向、环境/声音残留、情绪/关系余波。下一镜只继承当前景别可见且高漂移的2-4项，并选择动作接力、状态接力、反应接力或转场起镜。末镜仍写稳定收束尾帧。

预演最终按“物理可拍、人物因果、情绪行动、观看信息、多人生命感、场景专属惊喜、镜间推进”的综合收益选一套方案；物理成立是底线，但不是把所有创意降级为普通正反打的理由。预演内完成候选替换后立即冻结，不启动第二次预演。

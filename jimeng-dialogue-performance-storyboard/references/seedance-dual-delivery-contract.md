# 双文件交付与 Seedance 独立直投合同

本文件只负责把唯一冻结导演源编译为导演审核版和直投版；不重新设计剧情、观众预期、选择代价、视觉母题、节奏波形、表演或摄影。生成时只读取源表结论一次，避免交付阶段重复调用导演模块。本文件同时是身份、条件 3D 和面部负向固定模板的唯一生成期原文来源。

最终固定输出两个独立 Markdown 文件：

- `作品名_导演审核版.md`：呈现可复核的结构化导演结论，不直接投喂 Seedance。
- `作品名_Seedance独立直投版.md`：只含可直接执行的自然语言，不依赖导演版或“上一镜”文字。

两份文件来自同一次预演，同一镜号、顺序、时长、最终执行台词、关键动作、动作结果、道具归属和起落状态逐镜一致。导演版额外保留原句到最终执行句的事实映射，不得泄露隐藏思维链或候选推理；直投版不得出现原句对照、导演分析、评分、内部节拍编号、审核术语、风险推理、查表标识或省略指代。

## 运行效率与质量边界

- 先冻结一份内部镜头蓝图，再从同一蓝图连续编译两份文件；不得在直投阶段重新导演或二次拆镜。
- 同一任务的入口、核心参考和命中专项各读取一次；剧情、情绪、摄影、声音和连续性结论均来自同一份冻结导演源。交付验证失败只回到报错字段，不重读全部参考。
- 秒级时间线、情绪状态、六阶段动作、面光材质、场景关系、道具终态和声音层全部来自冻结蓝图；交付验证不检查创作关键词、不发起创作回归，也不因缺少形容词重写镜头。
- 导演版五字段不复制直投版七字段正文；直投版不复制导演分析。全局只写常驻规则，分场写继承与变化，逐镜写完整执行快照和真实差量。
- 除单一静止状态且没有台词触发、微动作、道具变化或光影反馈的低风险镜头外，均按统一逐行格式写秒级时间线；复杂接触、多人传播、内部插切、VFX、蒙太奇和复杂运镜必须从 `0.0秒` 连续覆盖到结果与保持，不得压成动作清单或无时间标记的散文。
- 交付验证器只核对时间窗逐行格式、从 `0.0秒` 起、相邻首尾连续和末行到达镜头总时长；不对动作数量、创意强度、表演载体或时间分配优劣打分。
- 默认采用高表现负载。只有身份漂移、穿物、错误换手、口型冲突或几何失败等具体风险才拆分/降载；不得为了“AI负载控制”自动回退到固定中景、无反应、通用窗光或删减物理反馈。
- 提示词压缩按 `不可删核心 -> 可压缩支撑 -> 可删除装饰` 分层；出现具体风险时按“删除装饰 -> 压缩支撑 -> 拆分独立链条”降级，并保留视觉句、首读点、动作因果、结果和母题阶段。
- 一次完成全局和逐场结论后，不因格式修正重算剧情、摄影或光影；只局部修复报错章节和镜头。
- 任何提速不得减少剧情深度、题材广度、非同构摄影候选、表演因果、光影设计、空间连续、爆点职责、声音层次或直投可执行性。

## 一镜规则

- 每个时间窗明确主要拍摄主体、主视觉动词、行动因果和阶段终点；较长镜头可以由关键词、接触、揭示或剪辑点触发主体/驱动力交接，所有阶段最终汇入同一剧情结果。
- 连续运镜每个窗口保持一条可追踪路径和清楚起终幅；需要 A -> B -> C 等多阶段观看距离时，用明确时间窗、遮挡/焦点交接或内部切点写清先后，不把它写成无因连续变焦。推进、跟拍、横移、摇镜和环绕不自动等于景别变化。
- 起幅、运动中、终幅分别检查可见范围。尾帧只保留终幅可见或仍可听内容；身体局部必须写人物归属。
- 画外只描述具名人物不入镜及其台词、脚步、动作声或环境影响；不得让画外视线、目光、打量或审视成为可见物。
- 每镜先锁定拍摄主体归属，再写构图、表演、运镜与尾帧；运镜停止点必须是具体人物、身体部位、道具、实体或画面位置。
- 前镜落幅与后镜起幅双端握手，直投每镜仍须自足复述当前状态，不依赖前镜文字。

## 直投纯净度

直投版禁止出现：原台词/改写对照，内部视觉/影调/光影/色卡版本名，色卡编号，HEX/RGB，对照表，本地路径，图片占位符，特效模块号/英文阶段，导演理由，节拍等级，曲线分值，内在强度/外显幅度数值，审核过程，“沿用/同上/继承上一镜”等省略词。

实际投喂当前镜头时按顺序组合：

`全局摄影规则 + 全局影调 + 全局光影 + 全局环境色彩 + 全局正向 + 当前场景空间位置关系 + 当前场景视觉方案 + 当前镜头从“当前资产与连续性”到“落幅状态”的完整正文 + 本镜特殊正向 + 全局负面 + 本镜特殊负面`

不存在的 OS、OV、BGM、特效或本镜特殊约束直接删除，不留空字段或“无”；不存在场景图时仍保留按剧本推导的场景空间位置关系。

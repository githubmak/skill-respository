# 按需分镜参考

本文件只在任务需要补充经验时读取。它是参考库，不是模板库；先满足原文保真、真实可拍、单镜单主观看任务，再从对应小节领取可用方法。任何示例都必须按当前剧本、站位、遮挡、景别和人物动机重建。

## 1. 读取路由

- 空间不清、遮挡复杂、多人同框、桌边、门口、柜台、车内：读“空间与遮挡”。
- 景别、机位、运镜、焦点冲突：读“景别与摄影机”。
- 情绪抽象、表演平、人物反应僵：读“表演与情绪可见化”。
- 画面普通、光影色彩不成体系：读“构图、光影与色彩”。
- 剧情节奏、钩子、信息释放不清：读“信息、节奏与钩子”。
- Seedance 生成崩坏或提示词混乱：读“Seedance 表达与复盘”。
- 需要二维空间参考图：读“二维空间参考图脚本”。

## 2. 空间与遮挡

先写固定世界锚点，再写人物槽位、身体朝向、视线目标、隔物、距离和道具归属。不要用“来客位、办事位、侧后方、深景、靠近”这类没有参照的词独立承担空间事实。

常用顺序：

`固定锚点 -> 人物物理槽位 -> 画面位置/纵深 -> 身体朝向/视线 -> 距离/隔物 -> 道具归属/状态`

二维俯视图只能证明平面站位、躯干朝向、边界、轴侧、摄影机位置和视锥。它不能证明头部视线、坐站高度、手部接触、道具高度、沙发/茶几真实遮挡、人物外貌、光影材质或最终景别。凡是二维图无法证明的事实，必须在分镜文字里说清。

桌边、茶几、柜台、车门、门框都先当实体遮挡处理。前景物可以增强关系压力，但会占画面：如果它挡住表情、手部、鞋、证据或口型，就必须改前景位置、改景别或拆镜。

道具连续性和人物连续性同级处理。杯子、茶盏、手机、文件、钥匙、包、证件、药盒这类关键物品必须跨镜保留持有者、落点、朝向、开合状态和可见数量；除非镜内明确交接、放下、拿起、打开、合上或被遮挡揭示，否则不能突然消失、换手、换桌位或变成不同大小。

明确转换才允许改变空间事实：

- 人物朝向变化：必须有转头、转身、起身、走位、反打关系建立或过轴过渡。
- 人物坐站变化：必须在镜内完成坐下、站起、半起身、重新落座，或上一镜结尾已经准备。
- 道具归属变化：必须有拿起、放下、递交、接过、打开、合上、遮挡揭示。
- 镜头轴线变化：必须有中性过渡、人物真实换位、肩后反打/正反打说明，或新场景/新空间节拍。
- 时间地点变化：必须有转场、空镜、声音桥、字幕、环境改变或明确的新起态。

无效转换包括：只写“镜头切到”、换一个景别、换一个机位、换成更漂亮的构图、让人物突然在画面另一侧出现。这些只能改变观众看到的角度，不能改变人物和道具在世界里的真实状态。

### 镜间终态接力

切镜前把人物屏幕侧/朝向、身体姿态、道具归属、未完成动作方向、可见残留和情绪/关系余波写入 `尾帧`。下一镜在 `起始状态` 中选择 `动作接力、状态接力、反应接力、转场起镜`，并复述其中最容易漂移且当前景别可见的 2–4 项，再在 `画面/表演` 中发动新动作。动作接力保留速度、受力和方向，状态接力保留稳定姿态与关系，反应接力保留接收者位置/面向/持物后再由声音或视线触发，同时保留上一镜留下的防御、试探、压制或失控倾向。禁止只写“上一镜继续”“状态不变”，也禁止在切镜后把未收势的人物重置成中性站姿。全场最后一镜同样保留 `尾帧`，改写为可稳定停留的收束终态，锁定最终人物姿态、道具归属、表情、关系压力与环境/声音余波；不得写“结束、无后续镜、无需承接”，也不得新增原剧本没有的离场或后续动作。

典型场景锚点：

- 客厅：沙发、茶几、落地窗、电视墙、玄关门、地毯、台灯。注意坐姿高度和茶几遮挡，不要让坐着的人承担全身审视。
- 柜台/窗口/签字台：写内侧、外侧、隔物、可触达关系和道具在哪一侧；不要写抽象“办事位”。
- 车内/车外：车门、车窗、前后排、安全带、方向盘先作固定隔物；写清谁在车内、车外、门开或关。
- 门口/走廊：门框、门槛、通道方向和人物进出动线必须闭合；不要用“门边”替代内外侧。

## 3. 景别与摄影机

景别必须绑定可见范围。若镜头任务要求超过可见范围，必须改景别、改站位或拆镜。

- 全景：全身、行动路径、主要家具关系。
- 中全景：膝盖或大腿以上，适合关系和上半身动作，不承担鞋面细节。
- 中景：腰部以上，适合双人互动、桌面动作、手部道具，不承担脚部信息。
- 中近景：胸口或肩部以上，适合对白、脸部控制、局部前景，不承担全身关系。
- 近景/特写：表情、手、道具、身份细节，空间关系弱化。

人物视线移动、摄影机移动、焦点变化要分开写。人物“视线从鞋到帽子”不等于摄影机也上下摇；只有观众必须看见检查过程时，才设计上下摇镜或细节镜。

焦点必须对应可定位的焦平面：具名人物的脸/眼睛/手、具名道具、门框前沿或明确背景平面。不要写“焦点交接到双人关系、情绪、氛围、带到旁观者”；这些没有唯一焦点距离。多人关系需要同时清楚时，写中等或较深景深并明确哪些人物/道具保持可辨；需要抽焦时，默认只做一次主交接，写成 `触发点 -> 起始焦点对象 -> 平缓/快速移焦 -> 终点对象 -> 保持到尾帧`。次级人物的反应可在略虚化背景中保持幅度可辨，不必再触发一次移焦。

面对面交锋的两人，如果都处在同一情绪拍点上，不要只保一个人近景、把另一人压成后景旁观者。要么让两人都保持可读的同层次对峙关系，要么明确使用肩后反打/正反打；如果一方真的只是背景观察者，那这一镜就不再是双人对峙，而应改写镜头任务。

上一镜如果已经明确是面对面，下一镜就不能在没有人物真实转身、换位、过轴过渡、肩后反打或正反打说明的情况下，突然把两人都写成同向、同侧或同一方向看。那不是“镜头换角度”，而是人物朝向断裂；先补连续动作或过渡镜，再谈后续构图。

运镜只在新增观看收益时保留。写清：

`起幅 -> 触发 -> 参照物 -> 速度感 -> 落幅 -> 新增读取`

数值运镜要验算：扫角 = 角速度 × 运动时间，位移 = 速度 × 时间。完整环绕、长距离跟拍、多人依次反应如果超过单镜时长，缩小轨迹、重排时序或拆镜，不靠更强限定词硬压。

180 度轴线默认保持。越轴只能由真实换位、明确过渡镜、正面中性过渡或新的空间节拍承担。换机位造成的可见面变化，不等于人物转身。

可靠性排雷：

- 关系镜如果承担两人对峙，就不要把其中一人写成后景轮廓。后景轮廓只能是陪衬，不是同一情绪拍点的对手。
- 细节镜如果要看身份物，就不要同时承担完整关系距离。身份物特写读完，再切回关系镜。
- 坐姿人物被桌子、柜台或车门挡住时，不要承担全身打量。改看可见的衣领、袖口、手部、胸牌、帽子、包带。
- 观众必须看见的内容，不能只靠另一个人物的视线说明。要么拍见内容，要么把任务改成拍“审视者的反应”。
- 摄影机物理移动、原地摇镜、变焦、焦点切换、人物视线移动是五种不同动作。一个镜头里可以组合，但必须分别写清主语和终点。

## 4. 表演与情绪可见化

### 人物锚点

人物锚点是场景级声音和行为基线，不是人物小传。每个主要人物只需固定：`基准音色`（音高、声质、共鸣、吐字、常态语速）与 `基本性格锚点`（面对压力时的稳定行动倾向）。台词和旁白的临时情绪、停顿、声量与动作由本场刺激重新推导；锚点只帮助保持人物辨识度，不得阻止人物在剧情转折中改变策略。

不要写抽象心理。先问人物此刻想得到、确认、隐藏、拒绝或保护什么，再把情绪落到可见动作。

当剧情里已经有明显情绪、喜剧错位或反差转折时，可以适度放大，但放大必须建立在原文既有刺激、人物策略和关系压力之上，优先放大停顿、视线、动作幅度、表情保持时间、构图失衡和反应错时。

可用通道：

- 身体：坐姿收紧、重心后撤、肩颈僵住、胸口起伏。
- 头脸：下颌收住、眉心轻压、眼睫停顿、嘴角压平、咬合收紧。
- 手部：指腹停在杯沿、手指收拢、掌心压住文件、触碰前停住。
- 视线：先避开、延迟接住、落在道具、越过对方看向出口。
- 距离：不靠近、隔物保持、退半步、停在门槛内。

动作幅度用轻微、小幅、中等幅度、大幅度。铺垫镜收敛动作幅度，冲突和笑点可放大，但不能全程高强度。沉默、停顿和不反应也必须有策略意义：压制、审视、震住、拒绝回应或等待对方暴露。

多人镜按刺激传播写反应：主行动者、直接接收者、见证者、背景人物分层错时，不要全员同步皱眉或集体木然。

表演只写外部可见结果，不写 3D 骨骼、关节 rig、肌肉参数或模型控制。可写“右肩小幅上提、下颌轻收、右手指腹压住杯沿”，不要写“肩关节旋转、脊柱骨骼弯曲、IK 控制手臂”。动作量化是给表演幅度，不是给内部骨骼控制。

把情绪翻成画面时，优先选择一个主通道：

- 压迫：前倾、隔物压画、视线延迟落下、语速放慢。
- 试探：视线先看道具再看人、手指停在物件边缘、身体不完全转正。
- 防御：重心后撤、肩颈收紧、双手靠近身体、回答前停顿。
- 反击：下颌抬起、视线正面接住、身体从后撤回到稳定坐姿/站姿。
- 识破：动作停住、焦点落到证据、嘴角小幅收平、眼睫短暂停顿。
- 喜剧反差：表情保持礼貌但动作卡顿半拍，或严肃台词落在不体面的身份细节上。

## 4b. 情绪反差与转折

重点不是“情绪多”，而是“前后是否有落差”。先判断人物表面状态和真实策略是否一致，再找出落差是被谁、被什么、在什么时刻撬开的。

常见反差类型：

- 语气平稳，但手指、下颌或呼吸先露破绽。
- 口头礼貌，但身体后撤、隔物压住、视线回避。
- 前半段压得很稳，关键词一出才突然变紧。
- 先强势推进，听到关键事实后迅速收回或改口。
- 表面沉默，实际在等对方先暴露。
- 轻松玩笑里藏着试探、否认或防御。

分析顺序：

`表面状态 -> 暗层目标/防御 -> 触发点 -> 可见破绽 -> 反差结果 -> 镜尾余波`

反差的作用不是夸张，而是让观众看见人物策略在变化。若人物前后没有任何心理或立场位移，就不要硬写“转折”；如果真的要转折，就必须在动作、视线、距离、停顿、口型或道具上有可读落点。

常用转折写法：

- 先抑后扬：先压住反应，再在关键事实后松开或反击。
- 先扬后收：先用轻松、礼貌或自信包住，随后被戳穿或收紧。
- 由外冷转内裂：表面平静，内部受击后在肩颈、呼吸或手部出现裂口。
- 由强压转审视：先推进控制，发现信息后改成看、等、试探。
- 由躲闪转确认：先避开，等证据成立后才正面接住。

每个反差都要有一个最小可见证据。没有证据的“反差感”只能停留在概念里。

多人对白按 `说话者策略 -> 直接听者的语义触发反应 -> 旁观者的既有任务与独立信息反应` 生成，不只驱动说话者。反应可以很小，但必须有来源且错峰发生；主动克制也要通过目光、呼吸、重心、持物或任务维持被读到。OV期间先选一个主要时间承载：一名关键人物的一处现实微动作、人物正在维持的任务，或一个环境动态。默认只保留一次主要变化，其余人物主动保持；只有现实关系再次变化时才增加第二处错峰反应。画中人物可在 OV 未结束时行动，但不能回应非现场旁白，也不能等待 OV 说完再反应。OS持有者不做口型，其他人物不能读心。

## 5. 构图、光影与色彩

先定能不能拍，再定怎么好看。构图、光影、色彩只能强化已成立的物理关系和人物策略，不能补空间漏洞。描述时先写观众能直接看见的事实：人物在画面哪一侧、彼此隔着什么、谁遮住谁、光从哪里来、脸和手哪一侧亮、背景比人物亮还是暗、关键道具是否醒目；再说明这些事实怎样表现关系或情绪。不要只写“压住背景、局部强调、主辅关系、光权变化、曝光层级”等抽象术语。

常用构图功能：

- 关系镜：交代位置、距离、隔物、屏幕侧和权力关系。
- 细节镜：交代身份物、证据、手部动作、道具归属。
- 情绪镜：交代压迫、迟疑、判断、释放、余波。

构图手段：

- 前景遮挡：形成压迫或窥视，但先检查是否挡住关键信息。
- 负空间：表现距离、等待、孤立、未完成关系。
- 框架构图：门框、窗框、车窗、柜台压出边界。
- 对角线/纵深：表现进入、逼近、退让和阵营。
- 特写/大特写：只交付一个高价值信息，不兼顾空间关系。

光源必须来自场景内说得通的实体：窗光、台灯、顶灯、走廊灯、车灯、屏幕光。色彩不替代表演；冷暖、明暗、材质反差只能帮助观众读懂关系、证据和情绪余波。

避免一场戏只有单一色系。肤色自然优先，高光受控，玻璃、茶釉、金属、屏幕等反光材质不要抢过人物表演。

逐镜前先生成 `全局风格锁定`：用户明确风格优先，模型只依据剧本补用户未定义的维度，再合并成无冲突的最终执行风格。美术可以是超现实、梦境化或漫画夸张，但现实空间、人物走位、实体遮挡和摄影机承载仍须实际可拍；不得把风格词当成穿墙、瞬移或道具漂移的许可。随后生成场景级 `全局影调、全局色卡、全局光影`，三个字段都用不懂摄影术语也能复原画面的自然语言。`全局影调` 完整说明时间天气、整场亮暗层次、人物/环境亮度关系、暗部与最亮处保留的脸手和材质细节、空气质感及关系压力；`全局色卡` 把环境底色、各人物服装/身份色与肤色、关键道具和实体灯光色逐项分配，并说明冷暖、明暗、饱和度与关系功能，优先使用 `低饱和雾霾蓝、偏灰莫兰迪豆沙、冷白纸张色、收暗酒红` 等可感知描述，默认不写 HEX；`全局光影` 逐个写明光源实体、方向、高度、覆盖对象、遮挡阴影、距离变化和材质反射，以及人物/道具移动或关系转折时怎样具体变亮、变暗或偏色。三项必须互相咬合，并服从最终执行风格；不得只列“清冷、高级、莫兰迪、低调、反差、黑位、主光、辅光、动机光、统一塑造、曝光层级、色温”等模糊标签。每镜 `构图/光影` 用“具体对象 + 画面位置 + 光源来源 + 受光/遮挡结果 + 本镜变化”写当镜可见结果，不能无因换滤镜，也不需要复述完整母版。

全局母版之后输出一份 `Seedance 2.5 专属提示词`：正向词先编译最终执行风格，再明确统一环境曝光、禁止前景主角额外面部补光、收敛面部高光、保护肤色与皮肤纹理；负向词只描述本场不应出现的失败现象。颜色、强光和静止必须带原因限定，例如 `无剧情或光源依据的荧光偏色、无任务依据的木偶式静止、所有人物长时间同步冻结`，不能无条件禁止某种颜色、静止姿态或全员无动作；若与用户风格、剧本、服装、灯光、道具或特效冲突，删除该负向词。

## 5b. 画面演绎

让画面替情绪转折说话，不只让角色“有情绪”。当反差或转折出现时，优先考虑这些演绎动作：

- 切换观看距离：关系镜切近，近景再切特写，或在关键事实后拉开让余波落下。
- 改变遮挡：从无遮挡到前景压住，从透明到半遮半显，借遮挡表现防御、退让或窥视。
- 改变重心：前倾表示压迫、后撤表示防御、停住表示审视。
- 改变构图平衡：对称打破、人物离开中心、留白突然增大，表现失衡或立场变化。
- 改变视线终点：从看人改为看证据、看门口、看桌面、看对方手部。
- 改变运动方向：逼近改为停住，顺势改为回撤，追问改为静听。
- 改变光影重心：人物从均匀受光转为被边缘光、窗光或局部阴影切开。

画面演绎要服务转折类型：

- 压住后松开：先保持稳定构图和低动作幅度，在触发点后切近、加强表情或道具落点。
- 识破后收缩：让人物从开放姿态变成收紧姿态，或者让摄影机从外放关系镜收回到局部证据。
- 试探到确认：先保留模糊或半遮挡，确认后才显出关键细节或关系真相。
- 假平静被撕开：前半段尽量稳、平、克制，触发后让视线、手、呼吸或构图平衡突然失稳。

如果某个情绪转折没有画面上的变化，就说明还没真正演出来，继续补动作、补节拍、补构图，不要只补台词。

## 5c. 惊喜镜头与创意画面

可以加入惊喜感，但让模型根据剧情自行判断是否需要。本节只是灵感示例库，不是固定清单；可以不用、改写，或选择更贴合剧情的其他方法。所有被采用的创意都要转成 AI 可执行语言：触发点、运动类型、速度/时长、起止画面、焦点落点、光源来源、稳定结尾。若选择高风险技法，要先转成更稳的 Seedance 表达。

灵感示例：运镜手法：

- 甩镜转场：只用于冲击、揭秘、突发进入。写成“0.2-0.4s 向画面左/右快速甩动，运动模糊遮住信息，下一镜在新主体/新场景急停定格”。不要写长距离乱甩或连续甩动。
- 渐推加框内揭示：用于人物出场、身份物或真相慢露。写清前景遮挡物、推进速度、遮挡让开的方向和最终露出的主体。优先用门框、窗帘、柱子、茶盏、文件边缘。
- 环绕情绪释放：只做半圈以内，适合高光、顿悟、重逢、压迫爆发。写成“低速环绕 20-60 度，情绪点小幅加速，结尾稳住主体脸/动作”。避免 360 度环绕、剧烈抖动和多人复杂环绕。
- 抽离拉镜：用于个人情绪和环境反差。写成“近景/特写先锁脸，0.6-1.2s 快速拉到中景/全景，露出环境或旁观者”。不要从脸直接拉到超大世界观全景，除非分成两镜。
- 俯仰突变：用于权力压迫或气场转变。写成“平视起幅，短促下摇到俯拍/小幅上仰到低角度，最后定在可读脸部或身体姿态”。避免瞬间大角度翻转。
- 穿物/穿墙感转场：奇幻、梦境、回忆可用。AI 安全写法是“镜头贴近玻璃/纱幔/水面/黑色遮挡物，画面被材质填满后切入下一空间”，不要要求真实穿过厚墙或复杂透明物体内部。

灵感示例：镜头巧思：

- 焦点跳转：先让前景虚化、背景清晰，触发点后焦点切到前景，让隐藏人物、证物或身份细节变清楚。只设一个焦点终点。
- 镜像欺骗构图：用镜子、水面、玻璃反射先给不完整信息，镜头小幅横移或焦点切换后揭露现实位置。必须写清反射面位置，避免让人物本体和镜像混成两个人。
- 遮挡偷换：用门板、文件、背影、黑场、路人经过短暂挡满画面，挡开后揭示人物表情、道具状态或位置变化。只表现已由剧情允许的变化，不凭空换人换物。

灵感示例：光效设计：

- 边缘轮廓爆发光：用于人物出场高光。写成“主体处于较暗环境，背后/侧后方出现短促金色轮廓光，面部保留可读阴影”。不要把脸照成纯白。
- 光束扫掠揭示：用于密室、回忆、揭秘。写清硬光来源和移动方向，例如窗缝阳光或手电光从画面左扫到右，扫到哪里哪里显现。
- 瞬闪频闪：用于法术爆发、记忆闪回、冲击瞬间。限制为 2-3 次短闪，每次只持续几帧，中间回暗；不要长时间频闪。
- 棱镜色散漏光：用于浪漫、奇幻、觉醒。写清光线来自玻璃、水晶、窗边反射，彩色光斑只在画面边缘或人物脸侧轻微游走。
- 逆光吞噬后露面：用于身份揭晓或情绪反转。先强逆光剪影，随后曝光压低或人物小幅转头，让面部细节露出。
- 环境光色突变：用于心境转变、幻境切换。保持光源位置不变，只改变色温或环境色，例如冷蓝转暖橙/赤红；不要无来源乱闪。

组合示例，可不用也可改写：

- 人物高光出场：渐推加框内揭示 + 侧后轮廓光。
- 反转揭秘：短促甩镜转场 + 光束扫掠揭示。
- 奇幻觉醒：抽离拉镜 + 棱镜色散漏光。
- 记忆闪回：焦点跳转 + 2-3 次短促瞬闪。

惊喜镜头是否采用、采用多少、放在哪一镜，由模型根据剧情、人物动机、镜头任务和画面效果自行判断。选择能增强信息读取、反差和可看性的做法，不要为了“新鲜”硬加不成立的机位变化、无依据的越轴、突然的全身展示或与剧情无关的奇观镜头。

## 6. 信息、节奏与钩子

区分观众已知、人物已知、人物误以为对方已知、暂时隐藏的事实。OS、旁白和默认 OV 只进入观众认知；画外对白、电话、广播、系统音只进入真实传播范围内的人物认知。

每镜结束时回答：观众读到什么新状态？人物关系或目标有什么变化？身体、道具、距离或声音留下什么可继承结果？没有新增读取的动作和镜头变化删掉。

钩子只能来自原文真实张力：未完成动作、被压住的回答、道具只露一角、视线落在门口、声音中断、对方没接反应。不能为了钩子新增事实、危险、暧昧或反转。

节奏来自信息释放、停顿、空间距离、视线接收、遮挡显露、景别收放和声音余波，不来自固定镜头数量或固定运镜字典。

## 7. Seedance 表达与复盘

Seedance 提示要把导演方案翻译成可见、单义、低污染语言。先写身份、当前空间、主因果动作和口型归属，再写摄影机、焦点、光影和质感。

避免混淆：

- 摄影机、焦点、人物手部、道具分别用具名主语。
- 左右说明参照：画面左侧、人物自身右手、屋内朝门看去的右侧。
- 焦点转换写触发和终点；不要同时要求人脸和证物都作为唯一焦点。
- OS/OV 不驱动画内口型；普通画内对白不必重复“对方听见”。
- 参考图不能替代镜头文字中的动作和终态。

常见失败定位：

- 身份漂移：补角色稳定外观、服装主色、固定饰物，减少同框近似人物。
- 空间左右翻转：重建轴线、屏幕侧、固定锚点和机位参照。
- 动作无法完成：检查准备态、接触点、路径、遮挡和是否需要拆镜。
- 焦点跳动：减少同等重要主体，写清焦点终点。
- 光影闪烁：回到真实光源、受光面、反光材质和曝光控制。
- 口型/声音错配：明确说话者、画外声、OS/OV 和获准反应者。

## 8. 二维空间参考图脚本

保留 `scripts/render_blocking_reference.py` 和 `scripts/promote_blocking_reference.py`。只在空间关系高风险、文字仍可能歧义时使用；普通对白和单人镜不需要。

二维图职责：平面站位、躯干朝向、实体边界、关系轴、摄影机位置、视锥和简化运动路径。它不是成片美术图，也不证明高度、真实遮挡、细节姿态、口型、表情或光影。

渲染脚本输入是 JSON spec，至少包含一个或多个 `states`；每个 state 需要 `blocking_id`、不少于两名 `characters`、实体 `anchors/boundaries`（按需）、且只能有一个 camera。人物和摄影机坐标使用 0 到 1 的归一化平面坐标；camera 需要 `x`、`y`、`facing_deg`、`subjects`，可选 `shot_type=relationship|over_shoulder`、`fov_deg` 和 `path`。`path` 必须有 `mode`、终点、`trigger` 和 `dramatic_gain`。

运行示例：

```powershell
python scripts/render_blocking_reference.py spec.json --output-dir staging/blocking --png --replace --compact --report reports/blocking.render.json
python scripts/promote_blocking_reference.py record --render-report reports/blocking.render.json --decision PASS --review reports/blocking.review.json --compact --report reports/blocking.record.json
python scripts/promote_blocking_reference.py promote --review reports/blocking.review.json --delivery-dir approved-jimeng-2d --compact --report reports/blocking.promote.json
```

渲染通过只代表几何自检通过。PNG 必须由视觉能力查看姓名、平面位置、躯干方向、机位、视锥、实体边界和标签可读性后，才能作为即梦空间参考。若图和文字冲突，以重新设计分镜为先，不用文字硬压参考图。

# 类型化色卡库

本文件按需读取，用于避免同类场景色调套死、同场景跨镜漂移和画面质感普通。它是灵感与物理可行性参考，不是选色器。模型从人物关系、观众立场、时段、真实光源、构图主体和剧情材质共同创作色卡；地点类型不能直接决定颜色答案。

项目若提供标准校色要求，可把 `18%中性灰、伽马、黑白位、灰阶、D65/白平衡、Rec.709` 作为全局技术基线，把 `过曝、死黑、灰雾、偏色、色彩/明暗断层、过度磨皮、光影混乱` 作为影调负面。三点布光、6500K、2:1或4:1光比只是可选的棚拍基准；夜景月光、火光、窗光等有明确物理来源时，场景色卡应优先服从剧情光源，不得为了统一而强行改成三点布光或中性白光。

## 创作方法

先判断本镜要把注意力落到谁、哪个动作证据或哪段空间关系，再决定主色、辅助色和小面积点缀色分别落在哪里。随后确定主光实体、方向、受光面、阴影层次、背景亮度、肤色基准和相关材质响应。比例、色温数字和光型都由当前画面决定，不设固定值。

最终在每镜 `色卡`、`影调`、`光影` 中分别写出本镜实际可见结果。场景连续性负责保持同一物理光源和综合色彩逻辑，不能代替逐镜根据构图与表演重写具体落点。

## 选择规则

- 同一场景内色卡稳定；只有闪回、梦境、明确换时间/光源或情绪峰值才允许局部变化。
- 先用明暗分配、受光面和材质反应表达关系，再选择颜色；不能用冷/暖色替代人物距离、遮挡、信息显露或表演变化。
- 同类型场景不能自动同色：警局可冷硬、误会喜剧、深夜疲惫；客厅可暧昧、冷战、崩溃、日常松弛。
- 主色控制空间，不改变人物固定服装、发色、肤色和关键道具颜色。
- 点缀色通常适合落在灯牌、屏幕、警示灯、金属边缘、首饰或杯沿等小区域，避免无因污染全场。
- 肤色保护要写成可见受光结果：中性或符合项目要求的肤色、主要受光面以及鼻侧、眼窝、下颌或背光侧的阴影层次。环境主色不应无因覆盖脸和活动手。
- 优先选择与剧情动作相关的材质锚点，例如柜台、手机、沙发、床品、玻璃、车窗、门把或杯水。

## 参数化色卡案例

### 客厅/公寓

- 日常松弛：暖米主色；浅木棕辅助；台灯琥珀点缀；2800K-3400K台灯或窗边柔光；暖棕浅阴影；低对比中低饱和；沙发布料哑光、茶几低反光。前缀：`暖米客厅，台灯低暖光，浅木棕阴影，肤色自然不过曝。`
- 暧昧靠近：奶油米主色；琥珀暖光辅助；玻璃杯/手机边缘低亮点缀；2800K-3200K侧暖光；阴影柔软；低对比；背景弱虚化。前缀：`奶油米客厅，琥珀台灯侧光，背景柔和虚化，肤色微暖。`
- 冷战对峙：暖米主色不变；灰蓝阴影辅助；台灯低亮点缀；窗外6500K冷光混入；中低对比；人物肤色保暖但背景降饱和。前缀：`暖米客厅混灰蓝窗影，台灯低亮，脸部保暖但背景降饱和。`
- 独处崩溃：暗暖米主色；深棕阴影；台灯低亮点缀；2800K低照度；对比略高；床毯/沙发布料保留褶皱。前缀：`暗暖客厅，低亮台灯，深棕浅阴影，脸部不过曝。`

### 警局/办事大厅

- 制度压迫：蓝灰主色；冷白墙面辅助；警示暖黄小点缀；5200K-6000K顶光；冷灰阴影；中对比低饱和；金属柜台和签字台低反光。前缀：`冷白警局，蓝灰主色，5200K顶光照亮脸部正面，鼻侧与下颌只留冷灰浅阴影，肤色自然偏暖。`
- 误会喜剧：冷白主色降低压迫；浅蓝灰辅助；桌面暖黄反光点缀；5000K柔顶光；低对比；人物脸部更柔，公告栏文字弱化。前缀：`冷白警局带少量暖黄桌面反光，低对比，脸部柔和。`
- 深夜疲惫：暗蓝灰主色；冷白局部顶光辅助；走廊灯低亮点缀；5600K低照度；阴影偏深但不死黑；金属边缘冷亮。前缀：`深夜警局暗蓝灰，局部冷白顶光照亮脸部，眼窝与下颌保留浅阴影，肤色自然偏暖。`
- 救援保护：冷白底色；人物肤色保暖；少量暖黄门灯点缀；顶光压制度感，主角脸侧保留暖反光。前缀：`冷白警局底色，门侧暖反光照亮主角脸侧，鼻侧与下颌只留浅蓝灰阴影，肤色自然偏暖。`

### 商业街/街边

- 轻喜剧：奶油橙主色；暖白店招辅助；绿色手机气泡小点缀；3200K-4200K混合街光；浅暖棕阴影；中低对比；橱窗反光压暗。前缀：`奶油橙商业街，暖白店招，浅暖棕阴影，橱窗反光不抢脸。`
- 热闹误会：暖橙主色；浅粉/浅蓝店牌辅助；手机或购物袋点缀；路人弱虚化；对比略高但饱和受控。前缀：`暖橙街边店招，浅色霓虹只作点缀，路人弱虚化，肤色自然。`
- 夜街失落：低饱和蓝灰主色；路灯暖黄点缀；湿地反光压暗；冷暖对比中等；人物占比可小。前缀：`夜街蓝灰低饱和，路灯暖黄点缀，湿地反光压暗，脸部保留自然偏暖受光。`
- 橱窗暧昧：暖橙橱窗主色；玻璃反光辅助；浅金点缀；背景散景柔；脸部柔光。前缀：`暖橙橱窗光，玻璃柔反光，浅金散景，脸部微暖不过曝。`

### 卧室/床边

- 私密暖夜：暗暖米主色；床品浅棕辅助；床头灯琥珀点缀；2700K-3200K低亮侧光；柔阴影；低对比。前缀：`暗暖卧室，床头灯低亮侧光，床品哑光褶皱，脸部柔和。`
- 病弱照顾：低饱和冷白主色；浅灰蓝辅助；水杯/药盒低亮点缀；窗边柔光；人物保留自然偏暖肤色。前缀：`低饱和卧室冷白窗光照亮脸部，鼻侧与下颌只留浅灰蓝阴影，肤色自然偏暖。`
- 压抑冷月光：灰蓝主色；暗米床品辅助；窗外冷光约6500K；阴影偏蓝灰；低饱和中对比。前缀：`灰蓝卧室冷月光，暗米床品，蓝灰阴影，脸部保留自然肤色。`
- 情绪崩溃：暗暖主色；深棕阴影；局部台灯或手机冷光点缀；对比略高；眼下/下颌浅阴影可读。前缀：`暗暖卧室低照度，深棕阴影，局部手机冷光，脸部不过曝。`

### 医院/走廊

- 冷白病弱：冷白主色；浅灰蓝辅助；医疗绿/蓝小点缀；5600K顶光；低饱和；白墙不过曝。前缀：`医院冷白空间，浅灰蓝阴影，顶光柔化，白墙不过曝。`
- 照顾暖肤：冷白底色；窗边柔光辅助；浅暖肤色保护；低对比；病床金属低亮。前缀：`冷白医院里带窗边柔光，肤色保暖，病床金属低反光。`
- 焦虑等待：蓝灰主色；长廊冷白灯辅助；安全出口绿小点缀；走廊线拉长；中对比低饱和。前缀：`蓝灰医院走廊，冷白灯拉长空间，安全出口绿只作小点缀。`
- 释然窗光：低饱和暖白主色；淡蓝阴影；窗光柔；对比降低；背景安静。前缀：`低饱和暖白医院窗光，淡蓝浅阴影，背景安静柔化。`

### 车内/车外

- 暧昧夜车：深蓝窗光主色；仪表盘低暖光辅助；玻璃水痕点缀；低照度低对比；脸部柔暖不过曝。前缀：`深蓝夜车窗光，仪表盘低暖光，玻璃水痕反光压暗。`
- 争执车内：冷蓝主色；硬侧光辅助；红色尾灯小点缀；中高对比；车窗反光不遮口型。前缀：`冷蓝车内硬侧光，尾灯红只作小点缀，车窗反光不遮脸。`
- 雨夜失落：蓝灰主色；路灯暖黄点缀；雨痕玻璃半透；低饱和；人物脸部暗部保留细节。前缀：`雨夜车窗蓝灰，路灯暖黄点缀，玻璃雨痕半透，脸部暗部保留自然血色。`
- 救援急停：冷蓝夜色；车灯白光强点缀；地面湿反光；对比略高；主体边缘轮廓清楚。前缀：`冷蓝夜色与车灯白光，湿地反光压暗，人物轮廓清楚。`

### 餐厅/咖啡馆

- 暧昧暖棕：暖棕主色；奶油白辅助；杯沿/吊灯琥珀点缀；低对比；浅景深。前缀：`暖棕餐厅，奶油白柔光，杯沿低亮反光，背景浅虚化。`
- 尴尬暖灰：暖灰主色；木色辅助；桌面冷阴影；低饱和；餐盘反光压暗。前缀：`暖灰餐桌空间，木色辅助，桌面冷阴影，餐盘反光不抢脸。`
- 谈判对峙：低饱和棕灰主色；桌面横线辅助；吊灯小点缀；中对比；对称隔桌。前缀：`棕灰低饱和餐厅，桌面横线居中，吊灯低亮，肤色自然。`
- 回忆散景：暖金主色；浅米辅助；背景灯点散景；低对比柔光；玻璃反光柔。前缀：`暖金咖啡馆柔光，浅米背景，灯点散景，玻璃反光轻柔。`

### 学校/教室

- 青春窗光：浅暖白主色；木桌浅棕辅助；窗外淡绿点缀；自然窗光；低对比中饱和。前缀：`浅暖教室窗光，木桌浅棕，窗外淡绿点缀，肤色清透。`

- 雨天低饱和：灰蓝主色；冷白窗光；桌面暗木辅助；低饱和；雨线背景弱化。前缀：`雨天教室灰蓝，冷白窗光，暗木桌面，背景雨线弱虚化。`

## 禁用和降级

- 若源文没有光源证据，不要发明强霓虹、强月光、强聚光灯；回到现实可见光源。
- 若本镜有复杂口型、多人物和道具转移，色卡只用压缩前缀 + 一个光影落点，不再叠加复杂材质。
- 若角色服装色与场景主色冲突，优先保角色服装；场景色退到背景墙、灯光和阴影。
- 若多场景文件复用同一地点，优先继承同一场景的物理光源和综合色彩身份；每镜仍按构图、人物与动作重写色卡、影调和光影。时间、灯光或剧情功能改变时，由模型设计有因变化。

## 乡村古风逐镜案例

### 月夜农家门屋

- 守护与举证：冷月蓝控制屋外和可见侧脸，土墙灰褐与旧木深棕承接空间，灶火琥珀只落在竹篮边缘和背光侧；低饱和、中低对比，脸和活动手保持中性肤色。月光方向与受光面跨镜连续，火光不随机覆盖口型。
- 家庭疏离：灰蓝月光压住院外，屋内土褐保持低亮，门缝暖光形成边界而非温馨滤镜；人物之间的亮暗差服从站位和门框遮挡。
- 夜归喜剧：清晰冷月光建立人物与门槛，低亮暖火光帮助读清道具误会，暗部保留土墙纹理；不用高饱和橙蓝对撞或全员暖脸制造搞笑。

### 清晨灶房

淡青晨光从门窗进入，灶火暖黄落在锅沿和手背，烟灰土墙与旧木案板保持低饱和；影调柔和但黑位不发灰。蒸汽只在锅口形成局部高光，不能遮住口型和儿童面部。

### 正午田地 / 阴天泥院

- 正午田地：天空浅青、叶片自然绿、干土黄褐，硬日光的受光与投影方向一致；降低叶面镜面高光，人物面部可由斗笠、云层或地面反射获得可读补光。
- 阴天泥院：云层冷灰作大面积柔光，干泥土褐与局部湿地深灰褐区分；低对比不等于灰雾，肤色和服装明度仍与背景分离。

### 河岸与集市

- 河岸：天空灰蓝、岸石冷灰、旧木与麻绳低饱和棕，水面只反映当前天空和岸边亮物；水下深浅、湿石粗糙度和人物肤色分开控制。
- 村集：布棚褪色红、木摊灰棕、蔬菜自然绿作局部信息色，天光统一空间；色彩丰富来自物件差异，不把背景摊位做成高饱和色墙。

## UE5 材质与光照落点

- 皮肤：保留细微粗糙度、耳鼻软骨透光和中性血色；月光、火光和环境反射分别落在有物理依据的面，不做蜡像高光或全脸磨皮。
- 旧木与竹：旧木粗糙度不均、边缘磨损；竹篾有细长高光但整体偏哑光，编织缝隙产生接触阴影。
- 土墙与陶器：土墙依靠细微凹凸和遮蔽读形，陶器釉面与无釉部位反光不同；避免两者共享塑料高光。
- 棉麻：纤维与褶皱靠侧光可读，高光宽而弱；湿布只在沾水区域变深并改变反光。
- 金属：铁锅、刀具、门件各按磨损和粗糙度区分，亮边不应无因常亮；火光反射服从金属朝向。
- 水、火与叶片：水面反射随角度和扰动变化，火焰亮度不抬高全场曝光，叶片区分蜡质与粗糙表面并保留薄叶透光。

这些案例仍需逐镜分别写入色卡、影调和光影；材质名不能替代本镜光源方向、接收面、阴影和曝光结果。

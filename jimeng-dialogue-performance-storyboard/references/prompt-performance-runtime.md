# 表演提示词运行合同

本文件只保留生成阶段必须由导演判断、不能交给机械校验的表演规则。格式、字数、口型区间和字段一致性由脚本检查；同类表演连续失败或需专项诊断时再读 `prompt-performance-rules.md`。

## 先选演法

- 关键转折按 `台词意图 -> 对外策略 -> 身体真实倾向 -> 不受控泄露 -> 选择或压住选择的代价 -> 对手反应 -> 落幅` 生成异质候选，再选唯一胜者。候选至少改变策略、泄露通道、道具/空间使用、反应时机中的两项；不拼接平均演法。
- 普通对白不运行候选赛，只写轻量内核：`表面台词 -> 本句维护/争取/回避的关系 -> 角色专属行为载体 -> 唯一听者关系回应 -> 句末可继承残留`。每镜只落成一个说话者行为和一个听者回应。
- 行为必须来自源文、行为签名、可触达道具、空间边界或声音触发。换名仍可套用的皱眉、抬眼、握拳、屏息不能承担主要表演。
- 情绪依据按 `源文明示 > 前情余波 > 当前目标/策略 > 保守推断`。台词与身体可有因不一致，不得无依据反演人物态度。

## 编译可见事实

每镜建立内部 `performance_ir`：

`source_anchor | relationship_goal | speaker_behavior | listener_response | end_residue | readability | camera_service`

再编译受保护载荷：

`关系起态 -> 台词/声音触发 -> 角色专属行为 -> 听者关系回应 -> 句末稳定残留`

- 心理标签必须变成当前景别可见的眼睑/眉尾/嘴角/下颌/呼吸、肩背/重心、手/道具、距离或遮挡事实。
- 特写/近景用脸、喉咙和呼吸；中近景用脸加肩背/手；中景/全景用距离、隔物、重心和道具，不写不可读微表情。
- 机位必须看得见泄露部位和听者回应。演法胜出后才选构图、景别、焦点和运镜，不能让运镜改写演法。
- 直接提示词中的触发、行为、回应和残留必须具名。完成后只读正文回译；任一槽位无法还原就返回编译前。

## 对白和反应

- 可见对白原样进入直接提示词并驱动正确人物口型；说完闭口。OS/OV/系统音/内心独白不驱动口型，画内人物闭口但要有声音触发后的可见反应。
- 一个时间窗只有一个主要反应者。三人以上按 `触发者 -> 第一接收者 -> 延迟理解者 -> 试图控场者 -> 关系落幅` 选必要节点，其余降为呼吸、肩线、弱虚化或画外。
- 重要听者不能只有闭口；回应必须改变关系读取或留下状态。连续镜不重复同一泄露载体。
- 长口型、明显运镜、道具转移和多名强反应不能同镜叠加。优先级固定为 `口型 > 听者反应 > 运镜`。
- 拒绝、承认、质问、保护、发现或关系重定义后，除非马上发生更高优先级动作，保留0.8-1.5秒可见余波；余波不新增台词和道具变化。

## 创意保护

脚本只能检查具名触发、可见动作、回应、残留和景别服务，不能选择情绪动作、潜台词、构图或表演强度。设计盲审继续淘汰通用演法、无因大动作、全员同时反应、机位遮演法和句末全部复位。

# 对白表演创作参考

本文件帮助模型做表演判断，不定义输出字段，也不接受脚本关键词校验。

## 表演因果

阅读台词时区分表面内容和关系策略：人物正在争取、保护、回避、试探或掩饰什么；对方的哪句话或动作改变了策略；身体是否泄露了语言没有说出的压力。把判断转成当前景别能看见的呼吸、视线、脸部、肩背、重心、手部、道具或距离变化。

角色专属性来自此刻可触达的物件、空间边界、习惯动作、说话节奏和前情余波。普通对白可以克制甚至几乎不动，但不能机械复用皱眉、抬眼、握拳、轻笑。重要转折可在内部比较不同演法；是否发散以及候选数量由模型决定。

## 说话与反应

- 可见说话者驱动口型，说完闭口；OS、OV、系统音和旁白不驱动画内人物口型。
- 听者反应发生在真正接收到信息之后。反应可以是动作、停顿、目光、距离或对道具的处理，也可以有意压住反应。
- 多人场面安排反应传播的先后与幅度，不让所有人同时抢同一情绪动作。谁成为主要反应者由关系和信息决定，不设固定顺序模板。
- 台词、停顿、表演、听者反应和镜头变化共同占用时长。字符速度只作容量参考；模型决定是否拆镜和拆点。
- 关键对白闭合 `触发 -> 人物控制方式 -> 情绪泄露 -> 台词状态 -> 听者反应 -> 镜尾余波`；允许自然合并，但不能只写口型或用情绪标签代替可见表演。
- 每句台词都要标出台词起说点：触发动作完成后、视线落点建立后、吸气/停顿结束后，或画外声刚刚被听见时开始说。不要只写“开口”“说完”；要让 Seedance 知道台词开始前画面正在发生什么，以及台词结束后谁先接收。
- 每镜只承担一个主要情绪或剧情转折。摄影机、焦点、道具和多人反应必须服务同一观看落点；出现多个独立中心时拆镜或调整时序，不按提示词字符数压缩情绪。

### 抢话、打断与重叠声音

普通交接要让前一位说话者完成台词并闭口，下一位在听见后启动自己的动作与口型。抢话或打断不是“两个人激烈争论”：写清前一句在哪个原文词或未完成语气处被截断、先说者何时闭口、后说者由什么动作或吸气启动，以及打断后谁承担当前清晰口型。

原文确有重叠对白时保持声音事实，但画面不必同时追求两张精确口型。模型可选择一个当前视觉中心承担清晰口型，另一人的声音来自画外、侧后方或后期；若剧情必须同时看见双方发声，则降低其他动作、遮挡和摄影机负担并在真实视频中重点审片。

耳语、哭声、笑声、喘息和喊声同样需要具名归属与发生时机。电话、广播、门外声、OS 和 OV 只作为声源触发画内人物反应，不让画内听者无因张嘴。

## 摄影机服务表演

先决定观众需要看清哪种身体证据，再选景别、构图、遮挡、焦点与运镜。细微眼神需要足够近的景别，空间压力可以在关系镜中用距离和隔物表达。摄影机不应迫使演员改变已经选定的真实行为，也不应因为“高级感”遮掉关键反应。

完成后只读直投提示，确认能唯一回答：谁先动或开口，谁在何时接收到，哪个身体或道具事实承载情绪，句末留下什么状态。若答案不唯一，由模型重写时序或拆镜，不由正则补词。

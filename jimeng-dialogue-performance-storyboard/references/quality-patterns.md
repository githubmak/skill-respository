# 质量组件库

本文件按需读取：当需要提升镜头语言、多人稳定、画面质感、关键帧判断，或用户要求“更高级、更有张力、更稳”时使用。组件只提供拍法语法，不原样套模板。

## 镜头小组件

使用方式：每个子镜头最多选一个组件；组件必须被改写成当前人物、空间、道具和台词。

- 听者被击中：85mm近景或肩后近景，前景说话者肩线约1/5；听者闭口，眼睑/下颌停半拍，手指收紧当前道具或衣料，尾帧距离不被修复。
- 关系拉开：35mm/50mm中景，二人之间保留桌面、门框、空位或走廊留白；用于拒绝、冷场、误会后的缓冲。
- 手部情绪泄露：近景/插入，镜头只承担手压、攥紧、松开、停在物边；手部动作必须来自上镜状态，不能凭空出现道具。
- 递物防闪现：道具起点 -> 持有人伸手 -> 指尖/边缘接触 -> 接收者握住 -> 原持有人松手 -> 新持有人稳定。
- 正反打保轴：A肩后拍B后，下一条用B肩后拍A；双方身体面对，前景肩线约1/5，距离、隔物、道具归属每镜复写。
- 手机消息浮层：手机屏幕不承载精确文字；画面侧边独立二维绿色气泡，安全区内，不属于手机、不贴手机、不随手机透视。
- 口型交接：上一说话者闭口0.2-0.4秒，听者低幅反应，再让下一人开口；长台词镜头少运镜。
- 结果空镜/物件缓冲：台词峰值后切空椅、门缝、停住的手机/卡/杯，声音桥承接；不新增剧情，只定格关系结果。
- 行走转对白：脚步停稳 -> 肩线转正 -> 头部跟随 -> 视线落点 -> 开口；不能边背向边面对说话。

## 多人可见身份预算

- 默认预算：1个主表演者 + 0-1个强反应者 + 0-2个弱化人物；其余画外。
- 清晰入画者必须有功能：主表演、受击反应、观察反应或背景弱化。无功能者降为肩线、后景弱虚化或画外。
- 三人以上若都需要清晰情绪，拆成关系镜 + 反应镜；不要用一个中近景拍全体表情。
- 组级出现人物不等于本镜可见人物。每镜只写本镜实际可见人数；肩线、倒影、虚化人影都算人，纯画外声不算。

## 高级色卡 / 光影组合

每个色卡组合都要转译为制作级字段，不直接复制成最终色卡。

- 冷战客厅：暖米主色、灰蓝浅阴影、台灯低亮；人物肤色保暖，背景降饱和，茶几/沙发布料哑光。
- 暧昧客厅：暖米主色、琥珀台灯、柔和边缘光；低对比，肤色自然微暖，玻璃/杯沿只给低亮反光。
- 崩溃卧室：暗暖主色、低亮台灯、阴影加重；床品哑光褶皱，脸部不过曝，眼下保留浅阴影。
- 警局制度压迫：蓝灰主色、5200K-6000K顶光、冷灰阴影、少量警示暖黄；肤色不发青，金属/签字台低反光。
- 警局误会喜剧：冷白底色降低压迫，保留少量暖黄提示灯或桌面反光；人物脸部更柔，背景文字弱化。
- 商业街轻喜剧：奶油橙店招、暖光橱窗、浅暖棕阴影；路人弱虚化，手机/橱窗反光不抢脸。
- 夜车暧昧：深蓝窗光、仪表盘低暖光、玻璃水痕反光；脸部柔和不过曝，车内暗部保留细节。
- 雨夜失落：低饱和蓝灰、路灯暖黄点缀、地面湿反光压暗；人物占画面偏小，肤色避免青灰。
- 医院照顾：冷白底色、窗边柔光、低饱和；人物肤色保暖，病床/白墙不过曝，输液架金属低亮。

## 关键帧触发机制

不是每镜都加关键帧；以下触发时优先添加 `【关键帧生图提示】` + `【即梦视频提示｜配合关键帧】`：

- 人体支撑：躺、靠、伏、坐吊椅/沙发/床、翻身、坐起、起身、摔倒、扶抱、亲密接触。
- 道具转移：递卡、递手机、签字、刷卡、付款、接杯、披衣、拿包、收起手机。
- UI文字：手机绿色气泡、来电、聊天、转账、屏幕朝向变化。
- 空间穿越：开门、关门、上下车、电梯开合、走廊追上、从背向转面对。
- 镜头风险：连续正反打、三人以上多人戏、强运镜、闪回/梦境。

关键帧写法：首帧锁起点，动作帧锁接触/转向/支撑变化，尾帧锁稳定终态；每帧都重复人物位置、身体朝向、支撑点、道具归属、画幅风格和场景锚点。

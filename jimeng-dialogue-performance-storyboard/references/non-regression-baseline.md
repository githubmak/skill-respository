# 不可回退能力基线

本基线锁定技能已经验证有效的行为。后续优化可以改变措辞、组织方式和实现，但不能删除、弱化或用相反规则覆盖以下能力。

## 剧情与表演

1. **事实与台词边界**：不改剧情事实、事件顺序、因果、人物性格、台词事实载荷、归属、知情、关键顺序及 OS/OV；台词、OS、OV 默认逐字保留，只有用户明确授权改写时才可在既有事实内调整。导演化扩写只能从既有刺激、空间、道具、任务和关系推出。
2. **强情绪导演化**：源文的“眼眶发红、震惊、愤怒、僵住”等是结果锚点，不是完整表演。必须补出旧控制失效、身体或声音泄漏、下一动作起势，不能只换近义词，也不能擅自升级为落泪、痛哭或攻击。
3. **情绪推进为行动**：关键反转至少落地一项非面部外部行动，改变距离、朝向、占位、道具控制、接触、出口或谈话主动权。眼神、呼吸、嘴角、手指和停顿只能辅助。
4. **混合情绪与钩子**：新策略保留旧情绪残留；关键刺激后的未释放冲动、悬置动作、道具控制、距离或声音余势要进入尾帧并由下一镜接住。
5. **多人及 OV/OS 活性**：听者错峰反应，旁观者维持自己的任务；OV/OS 不让画内人物集体站桩，OS 持有者不做口型，其他人物不读心。

## 镜头表现与可读性

6. **导演视觉首稿先于治理规则**：锁定事实后，先为每个节拍冻结最强起幅、唯一主要主体、一个主视觉动词、明确落幅和相邻远近/静动反差；再按目标、策略、关系、危险判断和现实认知五个状态轴判定 L0-L3。分级直接决定表达力度与叙事/表达职责，不从零生成机位，也不把 L0/L1 自动压成中景覆盖；不因出现情绪词滥用特写，也不因存在长台词压掉真正反转。
7. **表现性摄影不是软建议**：L2/L3 冲突和反转把导演首稿作为候选 A，至少再比较一套非同构候选；允许主动使用大特写、局部特写、快速跟拍急停、斜俯全景、遮挡揭示和景别跃迁。候选比较用于选出最明确的视觉句，不把多个候选折中塞进同一镜；不能把固定中景、普通反打或缓慢推近作为默认避险方案。
8. **具体摄影语言**：景别机位写具名人物/环境/物体、景别、高低/俯仰和正侧方向；相对实体位置只在遮挡、轴线、出入口、接触或连续性需要时补充。构图写前中后景和左右位置；光影写实体光源、方向、受光对象与阴影结果；运镜写速度、方向、经过内容和具体停止画面。禁止用“压迫感、关系、职业姿态”等抽象意义代替画面终点。
9. **主体与终幅无歧义**：脸、眼、手、鞋、衣摆、帽子等局部必须写人物归属；镜内改变主体、部位或景别时必须写清唯一的具名起终幅，可以使用“A 转 B”简写。尾帧只保留终幅真实可见或仍可听见的内容。
10. **画外人物不执行视觉动作**：未入镜人物只能通过台词、脚步、动作声或环境影响存在；不能把视线、目光、打量或审视写成画外可见物。
11. **保留自然演绎余地**：只冻结刺激、主动作方向、关键接触、关系结果和尾帧余势，不逐帧规定眨眼、指尖、头部角度、每一步和每次停顿。
12. **清楚机位与多阶段观看距离**：使用“具名人物/环境/物体 + 景别 + 高低/俯仰 + 正侧方向”，空间逻辑需要时补相对实体位置。连续运镜的每个窗口保持可追踪路径；较长镜头可通过时间窗、遮挡/焦点交接或内部切点完成多阶段景别，不允许无因连续变焦。

## 镜头组织与连续性

13. **切镜有门槛但不设硬压缩配额**：主体、策略/权力、空间或道具结果、刺激证据、控制断裂、新事实读取、明确转场至少改变一项即可切镜。句号、停顿、视线、表情、换角度和无收益景别变化不能单独成为切镜理由，但同一表演单元可以用有职责的镜头组连续演绎。
14. **职责化拆分与必要合并**：只增加重复表情、视线、相似景别或同一信息且没有独立视觉句的相邻镜头才合并；刺激、证据、控制断裂、动作起势、策略行动、关系结果，以及改变主要主体、心理距离、观看顺序或静动关系的视觉句可以分别成镜。允许连续 1-4 个 0.5-3 秒短镜连打，职责持续升级时可扩展到 5-6 个，不强制第三镜后进入长稳镜。禁止为减镜数把关键反转合成 10 秒以上同一中景/中近景、抹掉强起幅/落幅反差或让长段 OS 吞掉冲击瞬间。
15. **显式转场必须导演化**：原文每个【转场】至少对应一个实际编号的承接镜头或双端镜头组，使用声音、动作、物体/形状、遮挡、光影或运动方向承接；只标记 `转场起镜` 或直接切新场大全景不算完成。
16. **动作与空间双端握手**：前镜尾帧和后镜起态要保持人物朝向、重心、动作方向、接触、屏幕侧和空间关系，不能因切镜瞬移、转身、重新起演或无桥越轴。
17. **道具全生命周期连续**：逐场维护道具账本。非场景首镜的新道具必须在镜内通过声音、震动、拿出、打开或遮挡揭示完成首现；每次拿放、递接、换手、藏露、开合、亮灭或控制权变化都要在尾帧结算控制者、位置和必要状态，并由下一镜起态接住。
18. **短剧节奏前置**：拆镜前先完成观看承诺、即时目标/代价、升级、策略失效/翻转、释放和尾钩；只压缩非关键过程，不改变剧情节奏、台词、关键动作、因果与结果，且任何压缩都保留前状态、必要过渡和后状态。
19. **一镜多动作的同因果许可**：单镜可包含必要准备与两至四个低负载子动作、微表演、错峰反应或物理反馈；它们必须共享刺激/目标/策略/因果、按时间串行或自然联动、后动作承接前终点，并收束到同一结果。不得回退为“一镜只能一个人物动作”，也不得放任多条独立动作线并发。
20. **视觉输入与资产边界**：最终直投前必须取得用户视觉风格和全剧母色卡；全局影调/光影/分场环境色彩由模型推断。母色卡只作用于非资产环境，资产固有色优先；场景图在导演首稿后用于空间校正，不生成保守机位。
21. **人脸实体光保护**：环境可以暗或高反差，但可辨人脸按景别保持五官、自然肤色和暗侧纹理。允许真实墙面、地面、天空或灯具反射形成柔和补光，不得误写成无方向平光，也不得以环境统一曝光为由制造黑脸。
22. **特效白名单与零提及**：特效只来自剧本/用户设定并按镜触发；未激活、未出现、已结束且无现实后果的特效在直投正向、负面、色彩、光影、时间线和参考图中完全不出现，不写“特效：无”。
23. **双文件单蓝图**：导演审核版和 Seedance 独立直投版由同一预演编译，镜号、顺序、时长、台词、关键动作/结果、道具归属和起落状态一一对应；直投每镜自足，不依赖导演版或“上一镜”省略。
24. **全局与本镜正负向分层**：全局正负向只写每镜共同成立的常驻模板和失败边界，各出现一次；本镜特殊正负向只写当前镜新增风险，没有新增风险则删除字段，不重复全局模板。
25. **直投语义纯净**：直投版不出现内部版本名、色卡编号、HEX/RGB、路径、图片占位符、特效阶段英文、导演分析、节拍分值或审核术语；内部信息必须转成可见自然语言。
26. **叙事立场必填**：拆镜前冻结观众情感站位、观众/人物信息差、信息释放顺序、主观看法和切换条件；导演版必须输出结论，不能只用景别或“主观感”暗示。
27. **完整摄影圣经**：主/辅焦段、摄影机性格、人物/情境摄影原则、景别信息、运动停止、焦点/景深/轴线和动作/特效反馈尺度在拆镜前冻结；逐镜可以有依据地例外，不能无因漂移。
28. **整集/片段节奏曲线**：完整剧本按钩住、目标/代价、连续加压、主要翻转、兑现/新钩建立相对曲线；片段任务明确集外未知。比例不反向制造剧情或镜头配额。
29. **手机端可读性**：默认保证主首读点、关键主体尺寸、中心安全阅读区、字幕避让、背景降噪和运动后稳定终幅；不得让全景承担不可读微表情或把唯一证据压在平台覆盖区。允许服务主读点的次级信息。
30. **所有场景空间可审核**：有无场景图都输出摄影机活动区、边界/出入口、人物槽位/距离、固定锚点/遮挡、实体光源、路径和轴线/屏幕侧；无图按剧本建立最小可拍空间，不能删除空间关系章节。
31. **动作、特效与蒙太奇爆点去重**：从五段节奏选择峰值，为爆点每个时间窗冻结主机制并允许阶段交接；重动作、条件特效、蒙太奇、摄影、多人反应和复杂口型错峰。相邻爆点不得复制同一观看机制；母题复用必须推进信息、尺度、关系或结果并完成回收。所有手法都需剧情证据、明确第一读点、稳定结果和 AI 可生成路径，不新增事实或用奇观吞掉人物。
32. **AI 漫剧时长公式与紧凑密度**：并行镜按 `max(T_speech,T_act)+T_react+T_buf`，串行镜按四项相加，混合镜按小节求和；总时长先扣台词与关键动作最低时长。高密度段平均每 2-4 秒产生新读取，允许有职责的 0.5-3 秒短镜连打，不以稳定镜配额压低爆点。
33. **参考拍摄手法可选适配**：用户提供文字、分镜、图像或视频参考时，自动提取观看距离、机位、运动、剪辑、焦点、遮挡、声音和停止语法，只迁移方法不复制内容；参考手法进入摄影圣经与实际镜头，冲突时保留观看效果并做空间/AI 等效适配。
34. **全景与空镜主动叙事**：全景可承担动作全貌、权力翻转、规模揭示、喜剧反差和结果爆点；空镜必须承担证据、威胁、声音先行、人物缺席、时间变化、转场或余压。两者都需唯一第一读点和实际叙事收益，不能只交代环境或填时长。
35. **题材承诺与非同构爆点**：拆镜前冻结主类型、辅助类型、类型承诺、观众核心期待、冲突载体、升级单位、核心奇观和结果兑现；每场承担建立、加压、反制、揭示、奇观、兑现或余波职责。打斗、种田、异世界、斗法、都市、古代、言情、宫斗及未列类型均按自身规则推导，不得复用同一套证据特写、人物逼近、群体震惊和甩镜结构。
36. **摄影指导级光影圣经**：拆镜前冻结曝光层级、主辅光比、白平衡/色温、实体光源/方向、反差/黑位/高光、色卡层级、光影剧情曲线、分场光影继承表和特效受光。导演版可保留技术参数，直投版转为可见自然语言；逐镜只写真实差量，不用通用窗光或重复色卡替代设计。
37. **运行提速不降级**：普通生成按输入触发专项参考，不预加载全部文件；先冻结唯一镜头蓝图，再连续编译双文件，格式错误只局部修复。减少的只能是重复读取、重复文字、第二次导演重算和无风险逐秒编舞，不得减少剧情深度、题材广度、非同构候选、表演因果、光影系统、空间连续、爆点职责、声音层次或直投可执行性。
38. **单一源头导演引擎**：剧情曲线、反转链、表演/微动作、台词语气、景别运镜、压迫/情绪传递和光影触发在需要时由同一蓝图预演，直投编译不无因改写已锁定事实。高价值节拍可比较不同摄影机制，也可直接采用明显成立的方案。
39. **反转、微动作与台词语气**：主要反转按剧情改变相关状态并形成新策略或新现实状态。微动作在使用时应在当前景别可见、由具体刺激引发并符合人设；稳定基线不强制添加动作。台词根据实际戏剧需要冻结目标、策略、语气和声音细节。
40. **创作质量优先在源头生成并允许有证据局部提升**：切镜与镜长、表演载体、景别曲线、运镜机制、全景/空镜、转场桥、台词前中后、光影材质、爆点去重和负向约束应在导演源表首次生成时直接成立；回看发现具体创作失败时可局部重开受影响项，不限于硬错误。普通生成和交付验证不得运行创意评分、关键词覆盖、景别占比、平均镜长、微动作词频或保守运镜扫描，也不得建立自动、无证据或全剧反复返工闭环。
41. **场景事实/知情预演表**：每场在第一镜前同轮冻结入场/出场状态、不可改事实、观众新增信息、人物知情边界、目标/代价、阻力、策略阶梯、控制权转移、反转、兑现和钩子；该表直接喂给逐镜源表，不另开分析返工。
42. **主驱动力与耦合响应预算**：每个时间窗保持一个清楚首读点，摄影、表演、声音、道具、光影、VFX、插切和多人反应可沿共享触发/观看目标/方向/阶段终态连续交接；不同因果只有在时长、空间或物理无法承载时才走相邻镜头，不用后置解释争夺首读点。
43. **高价值插切退路**：插切必须有用途、三态握手和声音连续点；容量按生成段时长估算，超载时按删除次要插切、焦点/局部起幅、独立相邻镜、冲击/动作/结果拆分的顺序在源头处理。
44. **视觉版本继承**：全剧按 `STYLE -> TONE -> MASTER PALETTE -> SCENE VERSION -> SHOT DELTA` 继承；资产固有色和实体受光优先，版本升级必须有真实触发，直投不泄露内部版本标识。
45. **关系覆盖与回收**：关系宽镜、双人镜、动机化 OTS、干净单人、听者反应、证据插切和压力后的关系宽镜按信息/权力/空间结果选用，不机械按镜头清单补齐。
46. **事实歧义暂停门**：只对身份、因果、地点、对白归属、能力规则、结果或结局歧义暂停；视觉细节不确定按最小可拍空间推导并标待复核，不回退固定中景。
47. **情绪双曲线与性格准入**：关键节点分离内在强度1—10与外显幅度0—5，动作必须经过性格、目标、危险判断、惯用策略和关系对象准入；直投只保留可见/可听结果，不泄露数值。
48. **完整表演链与镜头组覆盖**：表演从前镜基线、刺激、泄漏、控制、行动、反馈推进到关系结果/残留；镜头组按需覆盖空间、行动、情绪承受、证据、旁观反应和结果，不以交替中景或重复特写充数。
49. **插切时空与声音握手**：插切必须明确直接切入/切回、同机位/焦段/轴线/光源返回、主镜保持方式和声音连续；不足5秒通常不内插，5—8秒常用0—1组、8—15秒常用1—2组仅作稳定参考，更多插切须逐组具备独立职责、完整三态和实际时长，必要时转相邻镜头组。
50. **爆款观众收益与再钩**：源头冻结停留钩子、观众主问题、爽点承诺/压制/反制/证据/见证/兑现/新债，以及兑现后的再钩；每场写观众获得的即时信息、情绪收益或关系变化，不以空泛“震撼”替代结果。
51. **反差萌与角色传播记忆**：主要人物各自建立1—3个有任务触发的记忆资产或反差母题，沿稳定预期、违和证据、人物认真维持目标、迟半拍确认和结果回收升级；不为卖萌新增事实或打断主线。
52. **五轨短剧节奏**：信息、行动、情绪、视觉、声音五轨在源表中安排错峰接管、蓄压、假释放、峰值、结果确认和再钩，节拍紧凑但保留必要理解窗口与余波。
53. **高级光影候选与条件大气**：光影由实体光源、空间压力、认知翻转、关系状态、天气介质或奇观受光推导；主要节拍比较不同机制，丁达尔/体积光仅在方向光、介质、遮挡和暗背景成立时使用，不得把示例当全剧模板。
54. **奇观规模与七层受力**：条件特效按L1局部显形、L2人物尺度、L3场景尺度、L4世界尺度选择实际规模，并落实来源/主形态/纹理/介质/人物材质受光/环境受力/消散余波；原文允许高规模时不得自动降为局部泛光。
55. **非同构吸睛手法**：高级运镜、全景、空镜、遮挡、焦点、反射、贴地、俯冲、急停、冲击切和蒙太奇从视觉任务选择，示例只作候选；相邻峰值必须在主体、尺度、空间、运动机制、揭示顺序或结果读法上真实升级或换机制。
56. **题材广度与灵活继承**：打斗、种田、异世界、斗法、都市、古代、言情、宫斗、喜剧、悬疑、家庭、职场、科幻、恐怖、治愈等按自身承诺生成，不以单一证据特写/逼近/甩镜结构覆盖所有题材；用户参考手法只迁移方法，不固定全剧拍法。
57. **风格/影调/滤镜/灯光/景深分层与条件特效库**：STYLE不冻结单镜摄影，TONE不抹平场景物理光，FILTER BASE固定颗粒/扩散/光晕/色散/拖影等影像质感边界，景深随信息职责变化；项目级特效默认关闭，逐镜门控并只输出当前可见阶段和现实余波。
58. **单一能力与防漏读覆盖账本**：复杂项目按需读取入口和相关参考；命中的专项有明确承载，不要求为未命中项输出删除清单。导演源冻结前，当前任务涉及的事实知情、情绪表演、摄影、空间道具、时长负载、光影/滤镜资产、对白声音与交付有对应承载列；覆盖账本只防漏读，不做创意评分或成稿后返工。
59. **创意感染力源头自检**：在导演源冻结前，以定性“成立/需补强及位置”检查刺激/升级/翻转/释放/尾钩、情绪行动、不可替代视觉句、说前/说中/说后口型与声音桥、插切/轴线/视觉因果、光影/滤镜/空间/手机端首读点是否共同放大既有剧情。该自检不评分、不统计关键词/镜长/景别、不进入交付验证器；未成立时回填首次导演源，不在直投成稿后建立自动创意返工闭环。
60. **直投动作时间线格式**：除单一静止状态且无台词触发、微动作、道具/光区变化或镜内剪辑的低风险镜头外，直投每镜“画面与表演时间线”必须从0.0秒到镜尾按连续时间窗逐行输出，写清具名主体/主驱动力、触发或继承基线、动作/表演/物理过程、实际耦合响应和阶段终态；相邻时间窗首尾相接，不得压成无时间顺序的动作清单或散文。简单静止镜可合并为一行完整时间窗，但仍保留持续状态、观看收益和镜尾接点。交付验证检查时间窗行格式、起止与连续覆盖，并拦截只有抽象情绪词而缺少触发、可见/可听载体或停止/保持结果的压平表演；它不评价动作数量、载体创意优劣、创意强度或时间分配审美。
61. **样例兼容直投结构与条件模板**：直投版按项目直投参数、全局摄影/影调（含滤镜/后期影像）/光影/环境色彩、分场光影继承表、全局正负向、场景和逐镜排列；场景/镜头标题使用竖线分隔。逐镜使用“起幅与连续性”承载第一帧完整执行快照，使用“光影、环境色彩与材质”承载当前镜环境色、受光、曝光、材质和真实变化，不再拆回旧字段；本镜特殊正负向仅在新增风险时保留，无风险则删除整项。全局正向必须逐字且一次包含 `人物面部身份与识别特征严格继承参考图，脸型及眉眼鼻唇的基础比例、轮廓和相对位置保持稳定；表情肌肉、眼球视线、眼睑、嘴唇、下颌、头颈姿态与呼吸按剧情自然联动，允许受光、泪光、伤势和动作产生真实变化，但不得改变人物身份、五官基础比例或重新采样面部结构；所有镜头人物面部基准统一`。用户只写“3D”或明确 3D CG/次世代写实时，正向另须逐字且一次包含 `3D CG写实电影渲染，人物建模采用高精度次世代角色标准，8K纹理贴图，皮肤细腻完整，均匀皮肤光照，柔和面部补光，次表面散射皮肤，干净面部光影，皮肤纹理稳定`，负向另须一次包含 `法线错误，贴图错乱`；明确非写实三维或非 3D 风格时两者必须均为零次。全局负向必须逐字且一次包含 `面部斑驳，脸部黑斑，脏色块，皮肤阴影斑块，面部噪点，脸部脏污，跨镜头人脸不一致，同人物多张脸`。缺失、改写、重复或媒介误用均为交付硬错误，模板不得在本镜特殊正负向重复。

62. **观众预期与公平回收**：每个主要转折在导演源中冻结 `观众预期 -> 公平线索 -> 误判窗口 -> 重解释触发 -> 兑现画面 -> 新债`；线索必须来自原文、已建立道具/空间/行为或已知信息，不得靠新秘密制造惊讶。没有可回看线索的突然揭示不得作为高感染力反转。
63. **选择、收益与不可逆代价**：主要转折必须写人物本来可选的替代路径、当前选择、即时收益、不可逆代价、见证者和关系传播；只改变表情、声量或信息而没有选择代价时，降为普通状态变化。
64. **视觉句与母题生命周期**：关键镜头冻结 `具名主体 + 主视觉动词 + 空间/关系对象 + 不可逆结果`，并写 `首读 -> 次读 -> 结果确认`。每场主视觉母题登记建立、变体升级、反转变体和结果回收；重复必须改变信息、尺度、关系、代价或结果读法。
65. **节奏波形与声音母题**：每场冻结实际成立的 `蓄压 -> 加速 -> 屏息/停顿 -> 断裂/命中 -> 结果保持 -> 余波/再钩` 波形，并绑定镜长、景别/运动、台词密度和环境声。关键声音母题登记首次出现、压力变形、回收和退出；相邻场至少两项节奏/压力/观看距离/释放方式/声音职责反差。
66. **注意力路径与反应传播**：高价值镜头写 `首读 -> 次读 -> 结果确认`；关键事件写 `主承受者 -> 直接受话者 -> 关键见证者 -> 空间/群体回声` 的错峰传播，不让所有人物同步反应或让多个元素争夺同一首读点。
67. **创意保真降级与提示词压缩**：每镜将信息分为 `不可删核心 -> 可压缩支撑 -> 可删除装饰`；出现具体生成风险时按“删除装饰 -> 压缩支撑 -> 拆分独立链条”处理，并保留视觉句、首读点、动作因果、结果、身份和母题阶段。不得以AI负载为由回退无职责中景。
68. **单源编译与局部复验**：入口和五个核心参考各读取一次，专项按命中各读取一次；剧情、情绪、摄影、声音和连续性统一写入一份源表，连续编译导演版和直投版；验证失败只局部修复和复验，不重读全部参考或重算整集。
69. **固定模板唯一真源**：身份、条件 3D 和面部负向模板的生成期原文只保存在 `seedance-dual-delivery-contract.md`，视觉输入模块只输出媒介开关和资产/实体光结论，不复制模板。验证器与维护基线可以保留校验常量，但普通生成不得加载第二份模板定义。
70. **创作、编译与审核阶段隔离**：蓝图冻结前只加载入口和当前内容实际触发的导演专项，不提前加载交付合同或用字段/门禁预防性导演；蓝图冻结后默认从单一镜头源展开双文件，不无因更换导演选择。审核先处理有证据的事实/物理/时长/连续性硬错误；发现表演被压平、关系不可读、语气失真、核心情绪/类型收益未被呈现或镜头实际平庸等具体创作失败时，也可局部重开必要的观看立场、人物策略、主动作、摄影机制或镜尾余效，修复后重新冻结和编译。无实际失败时不得以稳妥、完整或易审核为由重做成立选择，也不得建立全剧自动返工闭环；最终栏目、资产交付、时间线、双文件一致性和直投纯净度不得减少。
71. **表演—情绪—语气同源**：每段对白在导演源只做一次人物判断，以知情、关系对象、句子现实作用、外在策略、内在压力和旧情绪残留共同推导身体表演与声音弧线。时间线只承载可见/可听过程及关键词时点，台词字段只出现一次完整原句并绑定自然语义转折；两者不得生成冲突情绪。细腻度以少量人物专属载体和清楚变化为准，不以通用微动作、情绪形容词、逐字标注或声音参数数量为准；普通直给对白不得被强造潜台词。

## 修改协议

修改本技能时执行以下约束：

1. 先阅读本基线，确认变更影响哪些能力。
2. 不通过删除旧规则、把硬规则降为可选建议、扩大模糊例外或只保留格式门禁来解决新问题。
3. 新规则与旧规则冲突时，优先寻找同时满足两者的生成顺序、复杂度分配或校验方式；确需改变行为时必须由用户明确决定。
4. 修改技能源头、参考文件或校验器后，同步更新 `scripts/test_skill_regressions.py`，让新问题成为永久测试用例。
5. 回归测试只验证技能维护边界，不参与普通分镜生成，不设置目标镜头数、景别比例、运镜配额或“必须清零”的创作得分。每项限制至少考虑一个允许案例，防止测试把合法导演选择一并封死。
6. 正常成稿校验只运行格式、事实、可见性、道具和连续性硬错误检查。技能不提供表现力、镜长、碎切、景别占比、关键词覆盖或保守倾向扫描入口；这些质量决策全部写入导演源表首次生成规则，不能进入自动返工闭环。
7. 完成后运行回归测试、技能结构校验、Python 语法检查和 `git diff --check`。任一失败都不能视为修改完成。

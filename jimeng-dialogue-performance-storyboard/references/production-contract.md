# 分镜生产与双文件合同

本文件在内部导演蓝图冻结后完整读取，负责把同一蓝图编译为规定交付并执行后置复审。它保留全部导演质量与交付结构，但不在编译阶段重新选择镜头或用门禁替代创作。具体导演设计已由模型依据剧情、人物、空间、时长、视觉风格和用户资产完成。

## 单一镜头源与冻结边界

完整项目先冻结一份内部导演蓝图，再编译两个文件；局部任务只冻结完成当前范围所需的最小蓝图。蓝图先锁定每场从进入秩序到离场结果的主变化轴、真实转折/释放、镜头组边界和每组不可替代职责，再逐镜至少锁定：

- 事实、知情、逐字台词载荷、动作结果和不可改变的镜尾结果。
- 主/辅题材承诺、场景任务、人物现实任务、观众收益，场景级情绪/信息/关系/过程曲线及摄影、空间、声音、表演能量的递进/错峰/释放，以及逐镜把“发生什么”转成“观众怎样看见并感受什么”的导演命题、剧情职责、首读点、注意力推进或有意保持、起态、刺激、人物理解、旧情绪残留、外在策略、任务动作变化、反馈和落态；真实压力任务另锁来源、主方向、受限选择和镜尾结果，跨场仍起作用的状态继续继承。
- 人物/道具/空间连续状态，以及主动作路径、关键接触、受力和停止状态。
- 题材适配的主导拍摄叙事语法与场景主节奏，以及逐镜采用连续拍摄、时间线内有因切镜或独立拆镜的摄影结构、各段起幅/观看距离/构图纵深/可实现路径/终幅，人物性格化做事方式、人物—场景共同透视/受光/接触/材质响应、声音触感、不改剧情的氛围性世界细节和时长；普通镜同样先作为简单完整的成片冻结。
- 本镜不可删核心、可压缩支撑、可删除装饰和已经识别的具体生成风险。

蓝图冻结后，编译只展开已有过程、把抽象结论转成可见/可听自然语言、补齐独立投喂所需事实，并从同一状态生成两个文件，不无因更换导演选择。导演版承担创作指导与人工判断，保留整场视听设计、镜头组曲线和关键创作结论；直投版删除分析过程但完整保留已冻结的空间纵深、人物做事方式、演绎变化、人景/材质/声音响应、主摄影机制和镜尾画面。信息颗粒由镜头实际复杂度决定，不得因提示词长度、字段展开或预设 Seedance 执行负担而缩成标题复述或动作清单。后置回读只修事实、知情、物理、时长、口型、空间、连续性和实际编译损失，不在成稿中临时创造质感；若发现源蓝图本身未完成，只局部退回导演阶段重新生成。内部蓝图不交付候选或思维过程。

## 栏目编译映射

- “起幅与连续性”把前镜落态、当前场景状态与本镜起态合并为第一帧完整执行快照；“落幅状态”只结算蓝图终态，不另创一套结果。
- “场景导演曲线与镜头组”把场景级蓝图压缩为进入秩序、主变化轴、转折/命中、结果保持和各组职责；“画面与表演时间线”再按本镜位于曲线中的职责展开起态、人物/环境行为、可感知变化、反馈和落态，它可以承载一次连续摄影，也可以用带明确切点的子镜组成同一视频生成单元。“台词与声音层次”承载只出现一次的完整台词、动作材质、空间声场和跨切声音桥，不重复导演分析，也不把无对白误写成无声音设计。
- 摄影、光影、材质和声音字段共同展开蓝图中已经冻结的逐镜导演命题、题材拍摄语法、主节奏、人景融合与可执行选择；固定镜头也须有完整构图、空间和表演结果，不为字段完整虚构运动。压力场景的各部门须服务同一主方向；内部候选不进入交付。
- 本镜特殊正向只保护当前镜最易丢失且丢失后会改变结果的核心，本镜特殊负向只处理已经识别的新增风险；二者不能重写动作、召回未出场元素或复制全局模板，不得描述或臆测平台内部优先级、识别机制或未经证实的控制能力，正向目标与负向排除不得互相矛盾。

## 表演合同

完整项目前先为主要人物建立简洁表演锚点：性格底色、当下目标、核心顾虑、关系策略、压力下的控制方式、最可能泄漏的可见通道、禁演方向，以及惯常语义分组、咬字松紧、气息连接、句尾处理和关系差异构成的说话身份。锚点来自剧本证据，只约束人物真实性；它是相对倾向，不规定统一动作库、固定语速、音高或情绪读法。逐句偏离锚点时须由当下对象、话语行动和压力解释。

情绪词只能命名状态，不能替代表演。凡刺激改变人物的认知、关系、目标、危险判断或自我形象，按实际剧情形成可变长度因果链：

`刺激进入 -> 确认或误判 -> 第一冲动 -> 性格化控制/泄漏 -> 新行动或台词策略 -> 对方/空间反馈 -> 镜尾残留`

每个有效节拍写明时间窗、具名主体、触发、至少一个可见或可听载体，以及变化后的停止或保持状态。载体可由视线、呼吸、瞳孔、嘴唇、下颌、肩背、重心、手指、道具控制、人物距离、声线、语速、停顿或尾音承担；根据景别选择真正可读的载体，不机械堆动作。

普通镜不套完整深演链，但须形成完整表演整体：人物位于真实任务、关系和环境中，进入状态、性格化做事方式或有意保持、当前注意、身体/道具/环境反馈和镜尾余势共同成立；无人镜由物件、环境、时间或声音的状态变化承担。价值重估、能力认知、身份判断和安静的亲近/疏离即使无冲突也按戏剧价值深化。不得把阶段名复述成“看、走、说、继续”，也不强加低头、皱眉、吸气等通用动作；前镜已完成的认知无新刺激不得重演。

关键转折镜按可拍顺序选择 `既有任务/身体基线 -> 刺激与判断 -> 第一冲动 -> 性格化控制/泄漏 -> 有目标的任务动作、台词或主动保持 -> 对方/道具/环境反馈 -> 关系结果与镜尾残留` 中的实际发生项。任务动作优先来自职业、劳动方式、身体条件、工具和真实空间；纯内在冲击可以由表情、声音、注意力、静止、构图或空间隔离承担，只要触发、变化及其后果清楚，而不是一行心理结论。景别只决定可见粒度，不规定动作数量：特写/近景保留有因的眼睑、呼吸、指节、口唇、肌肉控制或接触细节，中景联合任务动作、重心、距离与关键面部变化，全景/远景优先姿态轮廓、走位、群体关系和环境反馈；不得跨镜重复同类微动作代替情绪发展。

双人或多人戏同时结算关系调度：距离、朝向、视线、空间或道具控制权、话语主动、刺激传播次序，以及变化后谁靠近、退开、遮挡、占据前景或成为焦点。摄影机读取关系变化，不用无动机正反打或同步反应替代调度。

对白按同一潜台词策略完成：

`说前刺激/准备 -> 台词开始 -> 关键词或语义转折 -> 受话者延迟 -> 最后一个字后的余波`

完整台词只在“台词与声音层次”出现一次；时间线只引用必要关键词。说话者保持可见口型时，不同时安排竞争性大动作。OS 不产生口型，OV 不被画内人物无因听见。

台词语气由人物知情、关系对象、该句在当下要完成的现实作用、对外策略、内在压力与旧情绪残留共同推导。先确定这句话是在说明、试探、遮掩、拒绝、逼迫、安抚、求助或完成其他实际行为，再按自然语义单元组织“开口基线 -> 关键词/语义转折 -> 话落状态”；例举不是封闭词库。只选择足以区分当前演绎的最少声音变化，不填满参数，不以标点、停顿、重音、语速、音高和气息反复强调同一语义结果；关键词可以获得自然重音，但完整语义组不得被切成逐词停顿。标点只提供语法边界，不能单独决定语气；禁止整句只写情绪标签或逐字标注。若换成关系、性格和目的不同的人物后现有声音描述仍完全成立，只重写话语行动、语义推进或话落期待，不增加参数凑差异。

台词语气不得由“平静、认真、愤怒、悲伤、冷漠、紧张”等状态词直接映射为声音形容词。平静、冷静、克制和礼貌只限制情绪外显幅度，不等于语气平直、均速、无重音或没有自然起伏；认真不等于播报或训诫，愤怒不等于提高音量，悲伤不等于默认哭腔，紧张不等于默认结巴。除非原文明示机械、麻木、背诵、播报或失去情感，直投声音描述必须保留自然口语的语义分组、轻重层级、音高运动、呼吸连接和句尾方向。

编译声音前先用人物化自然语言说明说话者正在对谁完成什么现实行动、希望对方怎样理解或回应，以及人物准备显露什么、控制什么；这项话语行动在导演版可以解释，在直投版删除长篇分析后仍须以一句简洁自然语言保留。再按自然语义单元写开口基线、真实转折和话落结果；声音参数只补充实际采用且能区分演绎的变化，不能取代人物意图。

完整台词的时长先按符合人物、关系和情境的自然试读确定，并按实际字数、真实停顿总量和各语义段速度复核发声窗口，再安排同窗动作、受话反应和摄影。复杂信息若无法共享观看目标时串行或拆镜；人物揭示、群体反应、长对白和复杂运镜同时出现时，先按主观看任务排出先后，不让它们并行抢读。某段同时要求减速或停顿却只能靠赶词完成时视为时长冲突；现有镜长不足时，先压缩装饰动作、非关键反应或延长镜头，不得把台词压成快速、均匀、机械的朗读，也不得靠全员同步动作或持续运镜硬塞时长。时间线和声音字段的开口、结束及留白长度必须一致。

情感深度来自外在策略与内在压力之间可被观众感知的张力，以及新情绪中仍存在的旧残留。关键对白中，“画面与表演时间线”承载开口前后的身体、距离、道具、视线、口型和受话反馈，只引用必要关键词与时点；“台词与声音层次”只出现一次完整台词，并承载同一人物状态推导出的声音弧线。两栏必须来自同一话语行动和关系策略，但音画同源不等于动作与声音逐点同频，身体与声音可以存在符合人物的延迟、错位或反差，只在开口触发、语义转折和话落结果等真实关键节点相互承接；细腻度以少量人物专属载体和清楚变化为准，不以微动作数量为准。

## 摄影与物理合同

- 先确认墙、门窗、家具、人物和摄影机活动区，再按逐镜导演命题、题材承诺、场景任务、人物现实任务和结果兑现，选择连续长镜头、时间线内有因切镜或独立拆镜及各段主摄影机制；摄影机不得穿墙、穿物或从不可达区域拍摄，也不得以生活戏、过渡镜或信息少为由默认中景覆盖。
- 起幅、运动中和终幅分别检查人物、面部、手部、道具和背景人物是否仍在构图可见范围。
- 连续运镜在一个时间窗内保持一条可追踪路径；写清方向、距离或幅度、速度变化、锁定目标和停止条件。
- 人物揭示从脚部、背影、影子、局部道具或声音开始时，每次释放须增加身份、空间反应、关系或观众判断；若只是身体扫描则缩短或直接给全身。低机位跟移、后退扩大景别、机身升降、俯仰和焦点交接须按实际机制分别写清，不把“从脚到全身”笼统编译为推镜。
- 轴线变化必须由人物真实换位、摄影机可见越轴过程或中性机位建立，不得无因翻转屏幕方向。
- 动作和道具遵循重力、支撑、接触、受力、惯性和终点保持。落幅不自动复位。
- 每个时间窗保持一个主首读点，可有共同服务导演命题的空间、表演、材质和声音次级层次；人物和场景共享透视、景深、曝光、白平衡、锐度/颗粒和运动状态，并通过接触阴影、环境反射、遮挡、天气或材质形成真实共同响应。常规关系镜、过程镜和环境参与明显的镜头从前景遮挡/虚边、中景主体、背景环境中选择至少两个真正参与叙事的空间层次；纯肖像、主观压迫或有意压平空间可用单层，但须以受光、负空间、声音或表演承担等效作用，不机械添加虚焦前景。一个视频生成单元不自动等于连续摄影镜头：同一动作重量、空间压力、对白表演或沉浸需要完整时保持可追踪路径；观看对象、信息尺度、人物立场或情绪落点转换且能新增读取时允许内部切镜；子镜具有独立叙事落点、需要不同起落状态或在实际时长内争抢主读取时才拆镜。内部切点须承接人物位置、轴线、视线、动作、道具和声音，不能以切镜制造瞬移。
- 完整项目可用一句话冻结摄影关系倾向：摄影机默认陪伴、观察或参与事件的程度、常用观看距离、允许突破的剧情触发和突破后的回归方式。它是全剧观看人格，不是焦段、景别或运镜配额。
- 声音透视与观看位置、人物远近、遮挡和空间材质一致；每场先规划底层环境、动作/空间中层与台词/关键音顶层怎样进入、让位、抽空和回归，单镜只启用实际需要的层次，不要求三层同时响，静默或声音抽空也可成为顶层设计结果。对白、动作声、环境底噪和混响随人物进入/离开空间自然变化；跨镜声音母题只有承担信息、关系、节奏或记忆职责时才建立。

## 场景合同

完整项目每场建立；局部任务只建立当前范围真正需要的部分：

- 场景空间位置关系：写到足以审核空间依据、出入口、固定锚点、摄影机可进入/不可进入区、人物起始槽位和距离、允许路径、遮挡、实体光源、关系轴与屏幕侧；通常 5—8 句，但不设固定句数。有图按图锁定，无图按剧本建立最小可拍空间。
- 一组不含人物的场景资产图提示词。先写“拓扑共识”，用自然语言冻结出入口、固定锚点、相对方位与尺度、可通行/可拍摄区域和实体光源，不使用坐标或俯视图；再写“正向提示词”和“负向约束”。正向锁定建筑或地形、前中后景、时间天气、材质、环境色彩、画幅和视觉风格；负向排除人物、文字、Logo、重复家具、错误出口、空间穿透、拓扑漂移和新增关键实体。提示词必须把项目母色卡翻译为可执行影调、光比、冷暖、饱和与材质响应，同时保持建筑、家具和道具固有色。需要反向机位、横向调度、进出路线或多个表演区的重要复用场景，从同一拓扑共识派生空间总览和实际需要的功能视角，按每个视角分别给出正向/负向提示词；视角只改变摄影方向与覆盖范围，不改变门窗、家具、通道、尺度、实体光源与材质。普通单轴场景只输出一组正负向提示词。
- 关键道具资产提示词：凡进入因果链、被拿放递接、承担证据、支撑或身份功能，或需要跨镜保持外观的道具，按单体无人物资产输出“正向提示词 + 负向约束”，锁定形制、尺度、材质、固有色、磨损、可动结构和当前完整状态，并适配项目影调而不改固有色。无关键道具时写“无关键道具资产”。
- 场景视觉方案：为逐镜导演命题提供可复用的空间层次、构图/过程/结果对象，清楚主光、大面积低频明暗、稳定中间调、受控背景，人物与场景的真实共同响应，以及实际存在或由导演源合理建立的接触阴影、环境反射、材质、大气和生活状态。原文未锁死具体时段、天气细节或非关键环境活动时，可按时代、地域、季节、地点、已知日夜和题材气质补充可信天光、风、植被、炊烟、远景活动、生活声及材质反馈；不得改变已锁时空/拓扑，新增线索、危险、关键人物行动、剧情证据或因果。明显入画、持续或影响人物的增补须进入连续状态；图案光只有来源、形状、方向和叙事职责明确且不破坏身份读取时使用。

不输出俯视调度图。

## 导演审核版

## 直投纯净度

直投版禁止原句对照、导演分析、评分、内部版本名、色卡编号、HEX/RGB、本地路径、图片占位符、英文特效阶段和“沿用上一镜/同上”等省略指代。不存在的 OS、OV、BGM、特效或特殊约束删除整项，不写空标签或“无”。

## 模型语义复审

交付前由当前模型回读源剧本和两份正文。先检查事实、逐字台词、知情、物理、时长、口型、空间、道具和连续性。再检查场景是否由进入秩序发展到真实转折/释放与离场结果、镜头组是否各自增加信息/触感/压力/关系/进度、摄影声音表演能量是否有对比而非连续慢推/逐镜收紧/重复特写；每镜除基础信息外还须有至少一项与职责相关、观众可感知的空间、表演、光影、声音、节奏、静止或留白结果，若只是平光中景中的动作/台词转述则局部重开导演源。随后检查题材承诺，替换人物、题材任务或地点后方案是否仍可原样使用，相邻镜是否无增长地重复同一作用，以及题材化节奏、人物专属变化、关系与爆发结果、真实压力来源/方向/受限选择/应对/镜尾结果、人物揭示、摄影是否通用、人物—场景融合、干净影像、资产拓扑与交付自足；有效手法可以在同题材复用，但不得跨镜、跨场无变化地同质化套用。命中时只重开对应场景曲线、镜头组或逐镜蓝图并局部编译。

台词语气复审先忽略状态标签，再判断剩余声音描述能否听出人物在对谁说、想完成什么、语义怎样推进及话落后希望形成什么结果。把平静写成平直、把认真写成播报、把愤怒写成喊叫、把悲伤写成默认哭腔、把紧张写成默认结巴，逐词停顿、参数堆叠、音画逐点同频，声音策略与身体表演冲突，或实际字数、停顿总量和语义段速度只能靠赶词落入窗口，均视为具体语气编译失败；时间线与声音字段的开口、结束和留白必须一致，只重编受影响声音弧线、必要表演接点和时间窗。

审核必须指出具体事实、执行或编译失败及其所在内容，不能用关键词命中、字段长度、形容词数量或“更稳妥”的偏好代替判断；没有实际失败时，不得改写已冻结方案。复审不得通过临时增加微动作、景别、运镜、光效、环境声或美术细节来制造完成度；源蓝图未完成时只局部重开对应导演设计重新生成，随后重新冻结和编译，不重算其他成立部分。

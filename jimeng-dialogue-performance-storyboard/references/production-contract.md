# 分镜生产与交付合同

本文件在完整项目首个场景底稿冻结、开始直投整理前完整读取，负责把同一底稿逐场整理为默认直投主稿、用户要求的衍生内容并执行后置复审；整理阶段不重新选择镜头或用门禁替代创作。

## 单一镜头源与冻结边界

本合同接收技能入口已经冻结的一份内部镜头设计底稿，不重述其导演方法。完整项目沿“整集—场景—镜头”连续继承：整集一次锁题材、关系轨迹、影调资产、全剧摄影机观看位置和总体节奏；场景锁进入状态、压力/行动变化、离场结果及入口已定的观看生成源；镜头先锁唯一主变化及观众确认它的证据，再整理新增信息、关系、压力、任务进度、画面位置强弱、主观感受、身体动作或结果余波。长项目按场景执行入口既定的逐场写入顺序，只继承人物、道具、空间、情绪、声音与摄影状态；无可写目标时不声称已经写入，不以已写直投正文重新导演；局部任务只冻结当前范围。

底稿须已锁剧情事实、人物知情、关键动作/信息、关系、台词授权边界、题材/场景/人物任务、主读点、压力过程、连续状态、主动作路径/接触/受力/停止、题材拍法、镜头组织、时长和本镜新增风险，以及本场实际观看任务、峰值/过程乐趣或结果停留、镜头力度曲线和增补边界；它必须是具体、连续、可见/可听的同源演绎。冻结后只编译独立投喂事实：直投版删除分析过程但完整保留空间、行为、反应、人景/材质/声音、主拍法和镜尾；导演审核版仅按需保留创作结论。细节服从复杂度，不因篇幅或预设执行负担缩成标题或动作清单；回读只修事实、知情、物理、时长、口型、空间、连续与整理损失，源头不足才局部退回，内部底稿不交付。

**整理原则**：同一执行事实只在最合适的栏目完整写一次，其余栏目只写新增变化；仅删除重复基线、跨栏复述和无风险空项。栏目合并只减少复述，不改变已冻结的观看关系、景别距离、镜头力度或镜头组职责。场级观看生成源不新增交付字段，须编译为既有栏目中的实际观看关系、表演、摄影、时间线和镜尾结果。不得用更短、更整齐或栏目更少替代人物化处理、动作因果、构图/运镜、色影/声音、连续时间线和镜尾结果。

## 输出栏目整理映射

- “起幅与连续性”只把前镜落态、场景基线和本镜起态中影响执行的事实编译为第一帧完整执行快照；“落幅状态”只结算本镜发生变化的终态，未变项不重复。
- “本场变化与镜头组”把场景级底稿压缩为进入秩序、核心变化、转折/命中、结果保持和各组剧情作用；“画面与表演时间线”再按本镜位于变化中的作用展开起态、人物/环境行为、可感知变化、反馈和落态，它可以承载一次连续摄影，也可以用带明确切点的子镜组成同一视频生成单元。“台词与声音层次”承载只出现一次的完整台词、动作材质、空间声场和跨切声音桥，不重复导演分析，也不把无对白误写成无声音设计。
- 摄影、光影、材质和声音字段共同展开底稿中已经冻结的逐镜拍法、题材对应拍法、主节奏、人景融合与可执行选择；固定镜头也须有完整构图、空间和表演结果，不为输出栏目完整虚构运动。压力场景的各部门须服务同一主方向；内部候选不进入交付。
- 本镜特殊正向只保护当前镜最易丢失且丢失后会改变结果的核心，本镜特殊负向只处理已经识别的新增风险；二者不能重写动作、召回未出场元素或复制全局模板，不得描述或臆测平台内部优先级、识别机制或未经证实的控制能力，正向目标与负向排除不得互相矛盾。

## 表演合同

人物表演基线只保留会改变当前交付的差异：主角的目标/顾虑、关系策略、失控边界、注意与面部控制、泄漏/压回通道、运动节律和说话身份；关键配角的小目标、任务、立场、刺激阈值与镜尾；群体按身份/空间/任务分组。它们不是固定动作、表情、语速或音高；逐句或行为偏离人物表演基线时，须由对象、知情、话语行动、距离或压力解释。任何戏份先写成可观看事件，不能用情绪词、剧情结论、工序概述、景别/运镜名称或 OS 取代人物怎样接收、判断、处理及留下变化。时间线按实际发生项整理 `刺激进入 -> 确认或误判 -> 第一冲动 -> 性格化控制、伪装、抵抗或释放 -> 任务、身体、距离、接触、道具或声音变化 -> 外部反馈与镜尾`：普通镜可简洁但必须保留一项由当前事实引起的可观察处理变化，关键镜保留必要过程；“看、说、笑、转身、继续做事”只有对象、前后差量和可见/可听结果都明确时才算成立。任务动作保留启动、换重心、发力/制动、精度、惯性和恢复，掩饰动作有真实任务/关系目的与有因泄漏，遮住的脸不写不可见表情，信息未到或无新刺激不重演认知。

多人戏整理距离、朝向、视线、道具/空间/话语主动和刺激传播：可辨认配角带任务、注意和立场入镜，未受刺激者继续，受刺激者按距离、知情、利益和性格错峰调整，再回到任务或进入新状态；群体用少量行为组，次要动作降幅、降焦或降声，不集体停机或抢第一眼主读点。完整台词只在声音栏出现一次，时间线仅引开头词、关键词、转折或结束点；可见口型不安排遮嘴或抢读动作，OS 无口型，OV 不被画内人物无因回应。

声音先写说话者对谁完成什么现实行动、期待什么回应及显露/控制边界，再按自然语义组保留最少够用的轻重、音高、气息、停顿和句尾；状态词和标点不能直接决定语气，平静/克制不等于平直均速，认真不等于播报，愤怒不等于喊叫，悲伤不等于哭腔，紧张不等于结巴。先按字数、真实停顿与语义段速度自然试读并复核发声窗，再安排动作、受话反应和摄影；复杂信息若无法共享观看目标时串行或拆镜。镜长不足先压缩装饰/非关键反应或延长，不赶词、不靠全员同步或持续运镜硬塞；时间线与声音栏的开口、转折、话落和留白一致，细腻度看人物专属变化、控制程度和清楚后果，不看微动作数量。

## 摄影与物理合同

- 先确认墙、门窗、家具、人物和摄影机活动区，再按入口冻结的题材/场景/人物任务、观看收益与结果执行连续长镜头、时间线内有因切镜或独立拆镜及主拍法；摄影机不得穿墙、穿物或从不可达区域拍摄。起幅、运动中和终幅均检查人物、面部、手部、道具和背景人物仍在可见范围；人物揭示每次释放增加身份、空间反应、关系或判断，身体扫描则缩短或直接给全身。
- 连续运镜在一个时间窗内保持一条可追踪路径，写清方向、距离/幅度、速度变化、锁定目标和停止条件。情绪突破、注意突变、逼近/退离、接触许可、关系中心或控制权改变时动态介入为第一候选；强运镜只在注意、任务、重心、距离、接触、声音或控制权已有外化拐点时启动、变速或停止，写清主体/关系中心、可达路径、速度/加速度、停止与停后新信息、距离或权力构图，同窗一个主运动。真实峰值至少有可感知的镜头力度变化，可由运动、骤停、拉远、焦点交接或切镜完成；固定必须产生更强承受、凝固、距离反差或不可逃离感，普通场景不设配额。
- 轴线由真实换位、可见越轴或中性机位建立；动作和道具遵循重力、支撑、接触、受力、惯性和终点保持，持物手与落幅不自动复位。每个时间窗保持一个第一眼主读点，空间、表演、材质和声音可作同向次级层；人景共享透视、景深、曝光、白平衡、锐度/颗粒和运动状态，并以接触阴影、环境反射、遮挡、天气或材质共同响应。常规关系/过程/环境镜至少两个真正参与叙事的空间层次；纯肖像、主观压迫或有意压平可由受光、负空间、声音或表演等效承担，不机械添加虚焦前景。
- 一个视频生成单元不自动等于一次连续摄影：动作重量、空间压力、对白表演或沉浸需要完整时保持可追踪路径；观看对象、信息尺度、人物立场或情绪落点转换且增加读取时内部切镜，每次切换须新增信息、触感、情绪、关系或结果；子镜有独立落点、不同起落态或争抢第一眼主读点时才拆镜。内部切点承接人物位置、轴线、视线、动作、道具和声音，不以切镜制造瞬移。全剧摄影机观看位置只冻结一次；声音透视随观看位置、远近、遮挡和材质变化，每场按需安排底层环境、动作/空间中层与台词/关键音顶层，声画反差、主观听觉、J-Cut、L-Cut、声音匹配切或前景动作/背景画外声并发只在有信息、心理或节奏收益时整理，不作为固定配置。

## 场景合同

完整项目每场建立；局部任务只建立当前范围真正需要的部分：

- 场景空间位置关系：写到足以审核空间依据、出入口、固定锚点、摄影机可进入/不可进入区、人物起始槽位和距离、允许路径、遮挡、实体光源、关系轴与屏幕侧；通常 5—8 句，但不设固定句数。有图按图锁定，无图按剧本建立最小可拍空间。
- 一组不含人物的场景资产图提示词。先写“拓扑共识”，用自然语言冻结出入口、固定锚点、相对方位与尺度、可通行/可拍摄区域和实体光源，不使用坐标或俯视图；再写“正向提示词”和“负向约束”。正向锁定建筑或地形、前中后景、时间天气、材质、环境色彩、画幅和视觉风格；负向排除人物、文字、Logo、重复家具、错误出口、空间穿透、拓扑漂移和新增关键实体。提示词必须把项目母色卡翻译为可执行影调、光比、冷暖、饱和与材质响应，同时保持建筑、家具和道具固有色。需要反向机位、横向调度、进出路线或多个表演区的重要复用场景，从同一拓扑共识派生空间总览和实际需要的功能视角，按每个视角分别给出正向/负向提示词；视角只改变摄影方向与覆盖范围，不改变门窗、家具、通道、尺度、实体光源与材质。普通单轴场景只输出一组正负向提示词。
- 关键道具资产提示词：凡进入因果链、被拿放递接、承担证据、支撑或身份功能，或需要跨镜保持外观的道具，按单体无人物资产输出“正向提示词 + 负向约束”，锁定形制、尺度、材质、固有色、磨损、可动结构和当前完整状态，并适配项目影调而不改固有色。无关键道具时写“无关键道具资产”。
- 场景视觉方案：为逐镜主要变化提供可复用的空间层次、构图/过程/结果对象，清楚主光、大面积、不过碎的稳定明暗、稳定中间调、受控背景，人物与场景的真实共同响应，以及实际存在或由内部镜头设计底稿合理建立的接触阴影、环境反射、材质、大气和生活状态。原文未锁死具体时段、天气细节或非关键环境活动时，可按时代、地域、季节、地点、已知日夜和题材气质补充可信天光、风、植被、炊烟、远景活动、生活声及材质反馈；不得改变已锁时空/拓扑，新增线索、危险、关键人物行动、剧情证据或因果。明显入画、持续或影响人物的增补须进入连续状态；图案光只有来源、形状、方向和剧情作用明确且不破坏身份读取时使用。

不输出俯视调度图。

全局只写每镜都成立的规则。直投正文删除分析、候选、审核语言和重复基线，但完整保留内部底稿的空间、人物化表演、动作因果、主摄影与构图、光影材质、声音和镜尾层次。细节多少不设人为字数、输出栏目长度或细节数量上限，服从本镜复杂度与实际风险；同一信息不在多栏复述。环境色彩不得覆盖人物服装、家具、道具和场景资产固有色。

全局正向先逐字且只写一次身份固定模板：

`人物面部身份与识别特征严格继承参考图，脸型及眉眼鼻唇的基础比例、轮廓和相对位置保持稳定；表情肌肉、眼球视线、眼睑、嘴唇、下颌、头颈姿态与呼吸按剧情自然联动，允许受光、泪光、伤势和动作产生真实变化，但不得改变人物身份、五官基础比例或重新采样面部结构；所有镜头人物面部基准统一`

该模板只锁定人物身份和五官基础比例，不限制符合剧情与物理的表情幅度、眼球与眼睑、嘴唇与下颌、头颈、呼吸、受光、泪光、伤势或身体联动。

普通 3D 或明确 3D CG/次世代写实项目再逐字且只写一次：

`3D CG写实电影渲染，人物建模采用高精度次世代角色标准，稳定清晰的皮肤材质与五官结构，自然方向性面部受光，暗侧保留连续纹理，合理的皮肤次表面散射，受控高光与干净面部光影，跨镜皮肤质感稳定`

卡通 3D、黏土、低多边形等非写实三维，以及二维、真人实拍感、水墨、手绘或定格项目不加入上述 3D 写实模板。

全局负向先逐字且只写一次：

`面部斑驳，脸部黑斑，脏色块，皮肤阴影斑块，面部噪点，脸部脏污，跨镜头人脸不一致，同人物多张脸`

启用 3D 写实模板时再加入且只加入一次`法线错误，贴图错乱`。

其余全局负向只集中全剧持续风险：人物身份/面部污染、人体与接触、资产/拓扑/材质漂移、噪点及文字水印；不把摄影选择写成全局禁令。本镜特殊负向只处理该镜新增风险，不复制全局项或召回未出场元素。

“起幅与连续性”必须是可独立投喂的第一帧完整快照，把前镜结果和当前场景状态改写成已经发生、当前可见或可听的事实，不写“沿用上一镜”等省略指代。按实际需要依次交代时间地点、出场人物及数量与身份、位置/纵深/距离、朝向/视线、姿态/重心/伤势、进入情绪与身体基线、服装、道具控制者/持物手/物理状态、动作接点、关系轴/屏幕侧、固定锚点、焦点、所在光区、实体光源方向及正在延续的声音；不存在或不影响执行的项目删除，但不能把必要状态散落到别处后留成概括句。

**直投语义优先级**：不改变任何既有栏目。每镜先在“起幅与连续性”“摄影与构图”及时间线的首句明确第一眼主读点：具名主体、正在发生的动作或状态、对象/空间关系；随后才补充实现它所必需的摄影、光影、声音、道具和连续条件。丰富导演底稿必须完整保留并编译为可见/可听事实，但不把推理、候选方案或重复全局基线混入直投正文，避免主体被低优先级约束淹没。

“光影、环境色彩与材质”只写独立投喂需要知道的当前主光/光区与面部可读状态、相对场景视觉基础真实发生或由内部镜头设计底稿合理建立的颜色/曝光/遮挡/天气/生活状态/材质，以及会影响下一镜的稳定结果。无真实差量时用一句简洁当前状态完成自足，不重复母色卡、滤镜、手部受光和所有材质；关键手部、道具或材质只有参与动作、证据、接触、天气或余波时才展开。人物和场景保持共同透视、景深、曝光、接触阴影与环境反射，避免人物贴片感、随机暗斑、脏块、噪点和环境纹理污染。

完整项目的场景资产图和关键道具资产提示词在直投主稿逐场输出；导演版承担创作指导与人工判断，不重复整段提示词。局部镜头、修复或审核只输出用户要求的资产范围。直投不得用“同导演版”“沿用参考图”等省略指代；已有参考图时锁定复现，未提供场景图时建立最小可拍场景。

场景资产的“拓扑共识”在同场全部功能视角中逐字保持。单轴场景只写一组正负向提示词；重要复用场景才增加具名功能视角，各视角不得改造空间结构或另起风格。

**时间线是不可压缩的主执行层**：时间线第一行从 `0.0秒` 开始，末行到镜头总时长，相邻时间窗首尾相接；全镜所有阶段共同服务已冻结的唯一主变化，不能平均罗列多个同等工序或情绪结果。每窗写具名主体、刺激/进入基线、人物化处理、动作物理过程、必要的摄影/焦点/声音/道具/光影/材质响应和阶段终态；能由画面、动作、关系、物件、空间或声音证明的内容不得改由 OS、情绪标签或剧情结论转述。所有改变剧情、人物、空间、动作因果、道具、摄影能量或镜尾结果的过程均不得省略，也不得缩成“情绪升级/镜头推近/人物爆发”。连续段写清可追踪路径；内部切镜用 `子镜A/子镜B·景别或机位` 写清切因、切前落态、切后起态、轴线/视线/动作/道具承接和声音桥，不把切镜写成摄影机瞬移。时间码只表达阶段顺序、动作窗和关系节奏，不宣称逐帧或逐字控制。

“台词与声音层次”用自然语言按播放顺序写最终执行台词且只出现一次。先用一句简洁、人物化的自然语言保留说话者对谁完成什么现实行动、希望对方怎样理解或回应，再写与时间线一致的开口准备或声音基线，把真实采用且最少够用的声音变化绑定到分句、关键词或语义转折，最后写话落余波及实际需要的受话者延迟、口型、拟音、环境和对白避让；普通信息对白只保留意图、自然读法和话落状态，关系/策略对白写清转折，关键情绪对白才展开完整声音弧线。不要求出现固定标签，不用逐词停顿制造重音，不存在的类别删除。OS/OV 只按其自身声音职责描述，不套现场口型链。

“落幅状态”必须结算人物姿态、重心、位置、朝向、视线、接触、道具控制者和物理状态，以及摄影机终幅、焦点、面部曝光、材质、声音接点和情绪余波。

## 直投稿清洁规则

直投版禁止原句对照、导演分析、评分、内部版本名、色卡编号、HEX/RGB、本地路径、图片占位符、英文特效阶段和“沿用上一镜/同上”等省略指代。不存在的 OS、OV、BGM、特效或特殊约束删除整项，不写空标签或“无”。

## 模型语义复审
交付前由当前模型回读源剧本和已生成正文：先查核心事实、知情、物理、时长、口型、空间、道具和连续性；未获授权时查逐字台词，获影视化改编授权时查说话者、核心信息、到达时点、关系策略、人物口吻和结果。再查场级观看生成源是否在拆镜前冻结，并在正文中落实实际观看任务、峰值/过程乐趣或结果停留、镜头力度变化和允许增补的作用；缺失时只局部回到底稿，不在成稿补爆点、运镜或情绪。场景须从进入秩序到真实转折/释放与离场结果，镜头组各自增加信息、触感、压力、关系或进度，各部门强弱有对比而非连续慢推、逐镜收紧或重复特写。

逐镜查主要呈现方式与低调辅助信息、人物外化与镜尾、配角/背景任务和错峰、掩饰动作的目的/泄漏/后果；压力戏再查来源、方向、受限选择、策略、累积、释放或未解除状态，不能由运镜、喊叫、静默或音乐代替。再查反事实专属性：替换人物、题材任务或地点后能否原样使用，以及相邻镜无增长地重复同一作用、题材节奏、人物揭示、摄影、人景融合、干净影像、资产拓扑和交付自足；爆发、突袭、关系重排或控制权翻转确认动态介入为第一候选且镜头力度有触发、路径、速度、停止和结果，未位移时由骤停、拉远、焦点、切镜或固定形成更强结果。信息转述或装饰充数时，只局部重开对应变化、镜头组或逐镜底稿。

台词语气复审忽略状态标签后，仍须听出人物对谁说、想完成什么、语义怎样推进及话落期待；平直/播报/喊叫/默认哭腔/默认结巴、逐词停顿、参数堆叠、音画逐点同频、声身冲突或只能靠赶词落入窗口均为具体失败，时间线与声音字段的开口、结束和留白必须一致。审核指出具体事实、执行或整理失败及位置，不能用关键词、栏目长度、形容词数量或“更稳妥”偏好代替判断；没有实际失败时，不得改写已冻结方案。复审不得通过临时增加微动作、景别、运镜、光效、环境声或美术细节制造完成度；源底稿未完成时只局部重开对应设计，重新冻结和整理，不重算其他成立部分。

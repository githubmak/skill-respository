# 分镜生产与双文件合同

本文件在内部导演蓝图冻结后完整读取，负责把同一蓝图编译为规定交付并执行后置复审。它保留全部导演质量与交付结构，但不在编译阶段重新选择镜头或用门禁替代创作。具体导演设计已由模型依据剧情、人物、空间、时长、视觉风格和用户资产完成。

## 单一镜头源与冻结边界

完整项目先冻结一份内部镜头蓝图，再编译两个文件；局部任务只冻结完成当前范围所需的最小蓝图。蓝图逐镜至少锁定：

- 事实、知情、逐字台词载荷、动作结果和不可改变的镜尾结果。
- 剧情职责、观众首读点、起态、刺激、人物理解与策略、主要变化、反馈和落态。
- 人物/道具/空间连续状态，以及主动作路径、关键接触、受力和停止状态。
- 摄影起幅、观看距离、可实现路径与终幅，实体光源、关键受光、声音和时长。
- 本镜不可删核心、可压缩支撑、可删除装饰和已经识别的具体生成风险。

蓝图冻结后，编译只能展开已有过程、把抽象结论转成可见/可听自然语言、补齐独立投喂所需的当前事实，并从同一状态生成两个文件。除非发现事实、知情、物理、时长、口型、空间或连续性硬错误，不能更换镜头职责、观看立场、人物策略、主动作、摄影机制或镜尾关系结果。内部蓝图不作为第三份交付文件，不输出候选比较或思维过程。

## 栏目编译映射

- “当前资产与连续性”和“起幅状态”来自前镜落态、当前场景状态与本镜起态；“落幅状态”只结算蓝图终态，不另创一套结果。
- “画面与表演时间线”按起态、刺激、理解/策略、动作/台词、反馈和落态展开；“台词与声音层次”只补完整台词及实际声音策略，不重复导演分析。
- 摄影、光影、材质和声音字段分别展开蓝图中已经冻结的可执行选择；固定镜头不为字段完整虚构运动，普通受光不为丰富栏目制造变化。
- 本镜特殊正向提炼必须生成成功的核心，本镜特殊负向只处理已经识别的新增风险；二者不能重写动作、召回未出场元素或复制全局模板。

## 表演合同

完整项目前先为主要人物建立简洁表演锚点：性格底色、当下目标、核心顾虑、关系策略、压力下的控制方式、最可能泄漏的可见通道和禁演方向。锚点来自剧本证据，只约束人物真实性，不规定统一动作库。

情绪词只能命名状态，不能替代表演。凡刺激改变人物的认知、关系、目标、危险判断或自我形象，按实际剧情形成可变长度因果链：

`刺激进入 -> 确认或误判 -> 第一冲动 -> 性格化控制/泄漏 -> 新行动或台词策略 -> 对方/空间反馈 -> 镜尾残留`

每个有效节拍写明时间窗、具名主体、触发、至少一个可见或可听载体，以及变化后的停止或保持状态。载体可由视线、呼吸、瞳孔、嘴唇、下颌、肩背、重心、手指、道具控制、人物距离、声线、语速、停顿或尾音承担；根据景别选择真正可读的载体，不机械堆动作。

普通镜最低颗粒度是：可见的进入基线、意图或触发、一个主要可见/可听过程、明确停止或保持状态。受话者反应、道具变化或摄影响应只在能推进信息、关系或连续性时加入。简短不等于概括，禁止用“自然走过去”“递给他”“错愕后平静”等结果句吞掉过程。

关键转折镜必须按可拍顺序展开实际发生项：承接姿态/空间/道具/光线，刺激进入，人物感知或确认，认知或关系判断改变，第一冲动，性格化控制与可见泄漏，动作启动/路径/接触/停止，对方或空间反馈，镜尾关系结果与情绪余韵。节点数量由剧情决定，不强凑完整链；但不能把心理结论当成画面。

双人或多人戏同时结算关系调度：距离、朝向、视线、空间或道具控制权、话语主动、刺激传播次序，以及变化后谁靠近、退开、遮挡、占据前景或成为焦点。摄影机读取关系变化，不用无动机正反打或同步反应替代调度。

对白按同一潜台词策略完成：

`说前刺激/准备 -> 台词开始 -> 关键词或语义转折 -> 受话者延迟 -> 最后一个字后的余波`

完整台词只在“台词与声音层次”出现一次；时间线只引用必要关键词。说话者保持可见口型时，不同时安排竞争性大动作。OS 不产生口型，OV 不被画内人物无因听见。

## 摄影与物理合同

- 先确认墙、门窗、家具、人物和摄影机活动区，再选机位。摄影机不得穿墙、穿物或从不可达区域拍摄。
- 起幅、运动中和终幅分别检查人物、面部、手部、道具和背景人物是否仍在构图可见范围。
- 连续运镜在一个时间窗内保持一条可追踪路径；写清方向、距离或幅度、速度变化、锁定目标和停止条件。
- 轴线变化必须由人物真实换位、摄影机可见越轴过程或中性机位建立，不得无因翻转屏幕方向。
- 动作和道具遵循重力、支撑、接触、受力、惯性和终点保持。落幅不自动复位。
- 每个时间窗保持一个主首读点，可有服务主读点的次级信息；复杂信息若无法共享观看目标时串行或拆镜。

## 场景合同

每场必须建立：

- 场景空间位置关系：写到足以审核空间依据、出入口、固定锚点、摄影机可进入/不可进入区、人物起始槽位和距离、允许路径、遮挡、实体光源、关系轴与屏幕侧；通常 5—8 句，但不设固定句数。有图按图锁定，无图按剧本建立最小可拍空间。
- 一组不含人物的场景资产图提示词，分为“正向提示词”和“负向约束”。正向锁定空间拓扑、建筑或地形、出入口、固定家具与道具锚点、前中后景、摄影机活动区、实体光源、时间天气、材质、环境色彩、画幅和视觉风格；负向排除人物、文字、Logo、重复家具、错误出口、空间穿透和新增关键实体。提示词必须把项目母色卡翻译为可执行影调、光比、冷暖、饱和与材质响应，同时保持建筑、家具和道具固有色。
- 关键道具资产提示词：凡进入因果链、被拿放递接、承担证据、支撑或身份功能，或需要跨镜保持外观的道具，按单体无人物资产输出“正向提示词 + 负向约束”，锁定形制、尺度、材质、固有色、磨损、可动结构和当前完整状态，并适配项目影调而不改固有色。无关键道具时写“无关键道具资产”。
- 场景视觉方案：影调、环境色彩、实体光源、人物与压力源/出口/道具的构图关系，以及实际存在的材质、大气或滤镜变化。

不输出俯视调度图。

```markdown
# 作品名｜Seedance独立直投版

## 【全局摄影规则】

```

全局只写每镜都成立的规则。环境色彩不得覆盖人物服装、家具、道具和场景资产固有色。

全局正向先逐字且只写一次身份固定模板：

`人物面部特征严格继承参考图，面部潜变量保持不变，脸型眉眼鼻子嘴唇形态全程固定，只改变表情肌肉，不改变五官基础形态；禁止重新采样面部基础结构；仅面部肌肉做表情运动，骨骼五官参数锁定；所有镜头人物面部基准统一`

普通 3D 或明确 3D CG/次世代写实项目再逐字且只写一次：

`3D CG写实电影渲染，人物建模采用高精度次世代角色标准，8K纹理贴图，皮肤细腻完整，均匀皮肤光照，柔和面部补光，次表面散射皮肤，干净面部光影，皮肤纹理稳定`

卡通 3D、黏土、低多边形等非写实三维，以及二维、真人实拍感、水墨、手绘或定格项目不加入上述 3D 写实模板。

全局负向先逐字且只写一次：

`面部斑驳，脸部黑斑，脏色块，皮肤阴影斑块，面部噪点，脸部脏污，跨镜头人脸不一致，同人物多张脸`

启用 3D 写实模板时再加入且只加入一次`法线错误，贴图错乱`。

时间线第一行从 `0.0秒` 开始，末行到镜头总时长，相邻时间窗首尾相接。含台词、情绪转折、接触动作或关系反应的镜头，应让相关刺激、人物变化、行动/台词、反馈和镜尾状态可追踪；不要求每镜凑齐同一套节点，复杂情绪按剧情增加节拍。

“台词与声音层次”用自然语言按播放顺序表达最终执行台词、开口前准备、台词中的声音或策略变化、话落后的余波，以及实际需要的受话者延迟、语速、声线、声量、停顿、重音、尾音、口型、拟音、环境和对白避让；不要求出现“说前/说中/说后”固定标签，不存在的类别删除。OS/OV 只按其自身声音职责描述，不套现场口型链。

“落幅状态”必须结算人物姿态、重心、位置、朝向、视线、接触、道具控制者和物理状态，以及摄影机终幅、焦点、面部曝光、材质、声音接点和情绪余波。

## 直投纯净度

直投版禁止原句对照、导演分析、评分、内部版本名、色卡编号、HEX/RGB、本地路径、图片占位符、英文特效阶段和“沿用上一镜/同上”等省略指代。不存在的 OS、OV、BGM、特效或特殊约束删除整项，不写空标签或“无”。

## 模型语义复审

交付前由当前模型回读源剧本和两份正文。先检查事实与逐字台词、知情、物理、时长、口型、空间、道具和跨镜连续等硬错误；命中时只修对应蓝图项、镜头或章节并局部重新编译。再检查表演是否呈现刺激到反馈和镜尾状态、普通镜是否具备最低过程、关键转折是否达到可拍颗粒度、关系是否通过调度与摄影可读、资产是否在两版落地以及直投是否独立自足。

审核必须指出具体失败及其所在内容。字段存在、关键词命中、形容词数量或“更稳妥”的偏好不能代替语义判断；没有实际失败时，不得改写已冻结的长镜头、留白、静止、特殊机位、景别跃迁、复杂调度、表演策略或镜尾余效。发现质量问题也只回填缺失的可见因果或执行信息，不重新导演已经成立的部分。

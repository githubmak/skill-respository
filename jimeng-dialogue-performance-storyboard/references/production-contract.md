# 分镜生产与双文件合同

本文件在内部导演蓝图冻结后完整读取，负责把同一蓝图编译为规定交付并执行后置复审。它保留全部导演质量与交付结构，但不在编译阶段重新选择镜头或用门禁替代创作。具体导演设计已由模型依据剧情、人物、空间、时长、视觉风格和用户资产完成。

## 单一镜头源与冻结边界

完整项目先冻结一份内部镜头蓝图，再编译两个文件；局部任务只冻结完成当前范围所需的最小蓝图。蓝图逐镜至少锁定：

- 事实、知情、逐字台词载荷、动作结果和不可改变的镜尾结果。
- 主/辅题材承诺、场景任务、人物现实任务、观众收益、剧情职责、首读点、起态、刺激、人物理解、旧情绪残留、外在策略与内在压力、任务动作变化、反馈和落态；跨场仍起作用的压力、控制权、关系距离、未完成行动和声音余势继续继承，无影响时不建立额外账本。
- 人物/道具/空间连续状态，以及主动作路径、关键接触、受力和停止状态。
- 题材适配的主导拍摄叙事语法与场景主节奏，以及逐镜摄影起幅、观看距离、可实现路径与终幅，人物—场景共同透视/受光/接触/材质响应、干净影像、声音和时长。
- 本镜不可删核心、可压缩支撑、可删除装饰和已经识别的具体生成风险。

蓝图冻结后，编译默认只展开已有过程、把抽象结论转成可见/可听自然语言、补齐独立投喂所需的当前事实，并从同一状态生成两个文件，不无因更换导演选择。回看的失败范围不限于硬错误；若出现事实、知情、物理、时长、口型、空间或连续性硬错误，或表演被压平、关系不可读、台词语气失真、核心情绪/类型收益未被呈现、镜头实际平庸等具体创作失败，可局部重开受影响的镜头职责、观看立场、人物策略、主动作、摄影机制或镜尾余效，修复后重新冻结并编译；创作失败须指向实际成片结果，不能由格式、关键词、评分或无证据审美偏好触发。内部蓝图不作为第三份交付文件，不输出候选比较或思维过程。

## 栏目编译映射

- “起幅与连续性”把前镜落态、当前场景状态与本镜起态合并为第一帧完整执行快照；“落幅状态”只结算蓝图终态，不另创一套结果。
- “画面与表演时间线”按起态、刺激、理解/策略、动作/台词、反馈和落态展开；“台词与声音层次”承载只出现一次的完整台词及与表演同源的声音弧线，不重复导演分析。
- 摄影、光影、材质和声音字段分别展开蓝图中已经冻结的题材拍摄语法、主节奏、人景融合与可执行选择；镜长、切镜、运镜和声音须服从同一节奏，固定镜头不为字段完整虚构运动，内部候选不进入交付。
- 本镜特殊正向只保护当前镜最易丢失且丢失后会改变结果的核心，本镜特殊负向只处理已经识别的新增风险；二者不能重写动作、召回未出场元素或复制全局模板，不得描述或臆测平台内部优先级、识别机制或未经证实的控制能力，正向目标与负向排除不得互相矛盾。

## 表演合同

完整项目前先为主要人物建立简洁表演锚点：性格底色、当下目标、核心顾虑、关系策略、压力下的控制方式、最可能泄漏的可见通道、禁演方向，以及惯常语义分组、咬字松紧、气息连接、句尾处理和关系差异构成的说话身份。锚点来自剧本证据，只约束人物真实性；它是相对倾向，不规定统一动作库、固定语速、音高或情绪读法。逐句偏离锚点时须由当下对象、话语行动和压力解释。

情绪词只能命名状态，不能替代表演。凡刺激改变人物的认知、关系、目标、危险判断或自我形象，按实际剧情形成可变长度因果链：

`刺激进入 -> 确认或误判 -> 第一冲动 -> 性格化控制/泄漏 -> 新行动或台词策略 -> 对方/空间反馈 -> 镜尾残留`

每个有效节拍写明时间窗、具名主体、触发、至少一个可见或可听载体，以及变化后的停止或保持状态。载体可由视线、呼吸、瞳孔、嘴唇、下颌、肩背、重心、手指、道具控制、人物距离、声线、语速、停顿或尾音承担；根据景别选择真正可读的载体，不机械堆动作。

普通镜最低颗粒度是：人物正在进行的现实任务/关系行为、可见进入基线、意图或触发、一个主要过程、明确停止或保持状态。短反应不自动展开完整表演链或强加低头、皱眉、吸气等准备动作。关键情绪、冲突、选择或爆发必须留下当前景别可感知、会影响后续读取的变化；任务、距离、占位、道具、接触许可或话语主动是优先载体，但人物有依据地失语、注意力断裂、冻结、声音失稳、空间隔离或维持原动作时，无须强造外部动作。前镜已完成的认知由后镜继承，无新刺激不得重演。

关键转折镜按可拍顺序选择 `既有任务/身体基线 -> 刺激与判断 -> 第一冲动 -> 性格化控制/泄漏 -> 有目标的任务动作、台词或主动保持 -> 对方/道具/环境反馈 -> 关系结果与镜尾残留` 中的实际发生项。任务动作优先来自职业、劳动方式、身体条件、工具和真实空间；纯内在冲击可以由表情、声音、注意力、静止、构图或空间隔离承担，只要触发、变化及其后果清楚，而不是一行心理结论。

双人或多人戏同时结算关系调度：距离、朝向、视线、空间或道具控制权、话语主动、刺激传播次序，以及变化后谁靠近、退开、遮挡、占据前景或成为焦点。摄影机读取关系变化，不用无动机正反打或同步反应替代调度。

对白按同一潜台词策略完成：

`说前刺激/准备 -> 台词开始 -> 关键词或语义转折 -> 受话者延迟 -> 最后一个字后的余波`

完整台词只在“台词与声音层次”出现一次；时间线只引用必要关键词。说话者保持可见口型时，不同时安排竞争性大动作。OS 不产生口型，OV 不被画内人物无因听见。

台词语气由人物知情、关系对象、该句在当下要完成的现实作用、对外策略、内在压力与旧情绪残留共同推导。先确定这句话是在说明、试探、遮掩、拒绝、逼迫、安抚、求助或完成其他实际行为，再按自然语义单元组织“开口基线 -> 关键词/语义转折 -> 话落状态”；例举不是封闭词库。只选择足以区分当前演绎的最少声音变化，不填满参数，不以标点、停顿、重音、语速、音高和气息反复强调同一语义结果；关键词可以获得自然重音，但完整语义组不得被切成逐词停顿。标点只提供语法边界，不能单独决定语气；禁止整句只写情绪标签或逐字标注。若换成关系、性格和目的不同的人物后现有声音描述仍完全成立，只重写话语行动、语义推进或话落期待，不增加参数凑差异。

台词语气不得由“平静、认真、愤怒、悲伤、冷漠、紧张”等状态词直接映射为声音形容词。平静、冷静、克制和礼貌只限制情绪外显幅度，不等于语气平直、均速、无重音或没有自然起伏；认真不等于播报或训诫，愤怒不等于提高音量，悲伤不等于默认哭腔，紧张不等于默认结巴。除非原文明示机械、麻木、背诵、播报或失去情感，直投声音描述必须保留自然口语的语义分组、轻重层级、音高运动、呼吸连接和句尾方向。

编译声音前先用人物化自然语言说明说话者正在对谁完成什么现实行动、希望对方怎样理解或回应，以及人物准备显露什么、控制什么；这项话语行动在导演版可以解释，在直投版删除长篇分析后仍须以一句简洁自然语言保留。再按自然语义单元写开口基线、真实转折和话落结果；声音参数只补充实际采用且能区分演绎的变化，不能取代人物意图。

完整台词的时长先按符合人物、关系和情境的自然试读确定，并按实际字数、真实停顿总量和各语义段速度复核发声窗口，再安排同窗动作、受话反应和摄影。某段同时要求减速或停顿却只能靠赶词完成时视为时长冲突；现有镜长不足时，先压缩装饰动作、非关键反应或延长镜头，不得把台词压成快速、均匀、机械的朗读。时间线和声音字段的开口、结束及留白长度必须一致。

情感深度来自外在策略与内在压力之间可被观众感知的张力，以及新情绪中仍存在的旧残留。关键对白中，“画面与表演时间线”承载开口前后的身体、距离、道具、视线、口型和受话反馈，只引用必要关键词与时点；“台词与声音层次”只出现一次完整台词，并承载同一人物状态推导出的声音弧线。两栏必须来自同一话语行动和关系策略，但音画同源不等于动作与声音逐点同频，身体与声音可以存在符合人物的延迟、错位或反差，只在开口触发、语义转折和话落结果等真实关键节点相互承接；细腻度以少量人物专属载体和清楚变化为准，不以微动作数量为准。

## 摄影与物理合同

- 先确认墙、门窗、家具、人物和摄影机活动区，再按题材承诺、场景任务、人物现实任务和结果兑现选择机位；摄影机不得穿墙、穿物或从不可达区域拍摄，也不得以生活戏为由默认对白中景。
- 起幅、运动中和终幅分别检查人物、面部、手部、道具和背景人物是否仍在构图可见范围。
- 连续运镜在一个时间窗内保持一条可追踪路径；写清方向、距离或幅度、速度变化、锁定目标和停止条件。
- 轴线变化必须由人物真实换位、摄影机可见越轴过程或中性机位建立，不得无因翻转屏幕方向。
- 动作和道具遵循重力、支撑、接触、受力、惯性和终点保持。落幅不自动复位。
- 每个时间窗保持一个主首读点，可有服务主读点的次级信息；人物和场景共享透视、焦段、景深、曝光、白平衡、锐度/颗粒和运动状态，并通过接触阴影、环境反射、遮挡、天气或材质形成真实共同响应；复杂信息若无法共享观看目标时串行或拆镜。
- 完整项目可用一句话冻结摄影关系倾向：摄影机默认陪伴、观察或参与事件的程度、常用观看距离、允许突破的剧情触发和突破后的回归方式。它是全剧观看人格，不是焦段、景别或运镜配额。
- 声音透视与观看位置、人物远近、遮挡和空间材质一致；对白、动作声、环境底噪和混响随人物进入/离开空间自然变化。跨镜声音母题只有承担信息、关系、节奏或记忆职责时才建立。

## 场景合同

完整项目每场建立；局部任务只建立当前范围真正需要的部分：

- 场景空间位置关系：写到足以审核空间依据、出入口、固定锚点、摄影机可进入/不可进入区、人物起始槽位和距离、允许路径、遮挡、实体光源、关系轴与屏幕侧；通常 5—8 句，但不设固定句数。有图按图锁定，无图按剧本建立最小可拍空间。
- 一组不含人物的场景资产图提示词。先写“拓扑共识”，用自然语言冻结出入口、固定锚点、相对方位与尺度、可通行/可拍摄区域和实体光源，不使用坐标或俯视图；再写“正向提示词”和“负向约束”。正向锁定建筑或地形、前中后景、时间天气、材质、环境色彩、画幅和视觉风格；负向排除人物、文字、Logo、重复家具、错误出口、空间穿透、拓扑漂移和新增关键实体。提示词必须把项目母色卡翻译为可执行影调、光比、冷暖、饱和与材质响应，同时保持建筑、家具和道具固有色。需要反向机位、横向调度、进出路线或多个表演区的重要复用场景，从同一拓扑共识派生空间总览和实际需要的功能视角，按每个视角分别给出正向/负向提示词；视角只改变摄影方向与覆盖范围，不改变门窗、家具、通道、尺度、实体光源与材质。普通单轴场景只输出一组正负向提示词。
- 关键道具资产提示词：凡进入因果链、被拿放递接、承担证据、支撑或身份功能，或需要跨镜保持外观的道具，按单体无人物资产输出“正向提示词 + 负向约束”，锁定形制、尺度、材质、固有色、磨损、可动结构和当前完整状态，并适配项目影调而不改固有色。无关键道具时写“无关键道具资产”。
- 场景视觉方案：题材与场景任务对应的构图/过程/结果对象，清楚主光、大面积低频明暗、稳定中间调、受控背景，人物与场景的真实共同响应，以及实际存在的接触阴影、环境反射、材质、大气或滤镜变化。图案光只有在实体来源、连续形状、运动方向和叙事职责明确且不破坏身份读取时使用；不得用满屏逆光、雾、粒子或光晕制造唯美。

不输出俯视调度图。

全局只写每镜都成立的规则。环境色彩不得覆盖人物服装、家具、道具和场景资产固有色。

全局正向先逐字且只写一次身份固定模板：

`人物面部身份与识别特征严格继承参考图，脸型及眉眼鼻唇的基础比例、轮廓和相对位置保持稳定；表情肌肉、眼球视线、眼睑、嘴唇、下颌、头颈姿态与呼吸按剧情自然联动，允许受光、泪光、伤势和动作产生真实变化，但不得改变人物身份、五官基础比例或重新采样面部结构；所有镜头人物面部基准统一`

该模板只锁定人物身份和五官基础比例，不限制符合剧情与物理的表情幅度、眼球与眼睑、嘴唇与下颌、头颈、呼吸、受光、泪光、伤势或身体联动。

普通 3D 或明确 3D CG/次世代写实项目再逐字且只写一次：

`3D CG写实电影渲染，人物建模采用高精度次世代角色标准，稳定清晰的皮肤材质与五官结构，自然方向性面部受光，暗侧保留连续纹理，合理的皮肤次表面散射，受控高光与干净面部光影，跨镜皮肤质感稳定`

卡通 3D、黏土、低多边形等非写实三维，以及二维、真人实拍感、水墨、手绘或定格项目不加入上述 3D 写实模板。

全局负向先逐字且只写一次：

`面部斑驳，脸部黑斑，脏色块，皮肤阴影斑块，面部噪点，脸部脏污，跨镜头人脸不一致，同人物多张脸`

启用 3D 写实模板时再加入且只加入一次`法线错误，贴图错乱`。

“起幅与连续性”必须是可独立投喂的第一帧完整快照，把前镜结果和当前场景状态改写成已经发生、当前可见或可听的事实，不写“沿用上一镜”等省略指代。按实际需要依次交代时间地点、出场人物及数量与身份、位置/纵深/距离、朝向/视线、姿态/重心/伤势、进入情绪与身体基线、服装、道具控制者/持物手/物理状态、动作接点、关系轴/屏幕侧、固定锚点、焦点、所在光区、实体光源方向及正在延续的声音；不存在或不影响执行的项目删除，但不能把必要状态散落到别处后留成概括句。

“光影、环境色彩与材质”只写独立投喂需要知道的当前主光/光区与面部可读状态、相对场景基线真实发生的颜色/曝光/遮挡/天气/滤镜/材质差量，以及会影响下一镜的稳定结果。无真实差量时用一句简洁当前状态完成自足，不重复母色卡、滤镜、手部受光和所有材质；关键手部、道具或材质只有参与动作、证据、接触、天气或余波时才展开。人物和场景保持共同透视、景深、曝光、接触阴影与环境反射，避免人物贴片感、随机暗斑、脏块、噪点和环境纹理污染。

完整项目的场景资产图提示词和关键道具资产提示词在导演审核版与 Seedance 直投版每场都独立输出，内容来自同一资产结论。局部镜头、修复或审核任务只输出用户要求的资产范围。直投版不得用“同导演版”“沿用参考图”等省略指代；已有参考图时锁定与复现，未提供场景图时按当前交付范围建立最小可拍场景。

场景资产的“拓扑共识”在同场全部功能视角中逐字保持。单轴场景只写一组正负向提示词；重要复用场景才增加具名功能视角，各视角不得改造空间结构或另起风格。

时间线第一行从 `0.0秒` 开始，末行到镜头总时长，相邻时间窗首尾相接。含台词、情绪转折、接触动作或关系反应的镜头，应让相关刺激、人物变化、行动/台词、反馈和镜尾状态可追踪；不要求每镜凑齐同一套节点。时间码表达阶段顺序、动作窗口和关系节奏，不宣称某个字必然落在某个小数秒点；台词以开头词、关键词或语义转折作自然锚点，不用小数秒堆叠呼吸、停顿和语调控制。

“台词与声音层次”用自然语言按播放顺序写最终执行台词且只出现一次。先用一句简洁、人物化的自然语言保留说话者对谁完成什么现实行动、希望对方怎样理解或回应，再写与时间线一致的开口准备或声音基线，把真实采用且最少够用的声音变化绑定到分句、关键词或语义转折，最后写话落余波及实际需要的受话者延迟、口型、拟音、环境和对白避让；普通信息对白只保留意图、自然读法和话落状态，关系/策略对白写清转折，关键情绪对白才展开完整声音弧线。不要求出现固定标签，不用逐词停顿制造重音，不存在的类别删除。OS/OV 只按其自身声音职责描述，不套现场口型链。

“落幅状态”必须结算人物姿态、重心、位置、朝向、视线、接触、道具控制者和物理状态，以及摄影机终幅、焦点、面部曝光、材质、声音接点和情绪余波。

## 直投纯净度

直投版禁止原句对照、导演分析、评分、内部版本名、色卡编号、HEX/RGB、本地路径、图片占位符、英文特效阶段和“沿用上一镜/同上”等省略指代。不存在的 OS、OV、BGM、特效或特殊约束删除整项，不写空标签或“无”。

## 模型语义复审

交付前由当前模型回读源剧本和两份正文。先检查事实、逐字台词、知情、物理、时长、口型、空间、道具和连续性。再检查题材承诺是否改变拍摄对象、过程颗粒与结果兑现，替换人物/题材任务/地点后动作、观看机制、节奏和结果是否仍可原样使用，相邻镜是否无增长地重复同一作用，场景节奏是否由题材/任务/拍摄语法产生且没有匀速碎切，关键情绪是否留下人物专属且影响后续读取的变化而没有强造动作，关系与爆发结果是否可读，摄影是否仍为通用反打/重复中景/无动机推近，人物位置或接触改变后共同摄影关系是否完全不变，画面与人脸是否存在贴片、随机暗斑、脏块、噪点或背景斑驳，有来源的图案光是否保持五官可读，重要复用场景的多方向资产是否来自同一拓扑，资产是否按任务范围落地且直投自足；命中时只重开对应蓝图项并局部编译。

台词语气复审先忽略状态标签，再判断剩余声音描述能否听出人物在对谁说、想完成什么、语义怎样推进及话落后希望形成什么结果。把平静写成平直、把认真写成播报、把愤怒写成喊叫、把悲伤写成默认哭腔、把紧张写成默认结巴，逐词停顿、参数堆叠、音画逐点同频，声音策略与身体表演冲突，或实际字数、停顿总量和语义段速度只能靠赶词落入窗口，均视为具体语气编译失败；时间线与声音字段的开口、结束和留白必须一致，只重编受影响声音弧线、必要表演接点和时间窗。

审核必须指出具体失败及其所在内容。字段存在、关键词命中、形容词数量或“更稳妥”的偏好不能代替语义判断；没有实际失败时，不得改写已冻结的长镜头、留白、静止、特殊机位、景别跃迁、复杂调度、表演策略或镜尾余效。发现硬错误或具体创作失败时，只局部重开解决该失败所必需的蓝图项，允许重新选择受影响的表演、观看立场、主动作、摄影机制或镜尾余效，随后重新冻结和编译，不重算其他已经成立的部分。

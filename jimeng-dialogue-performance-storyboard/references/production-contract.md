# 分镜生产与交付合同

本合同接收技能入口已经冻结的内部镜头设计底稿，将其逐场整理为 Seedance 独立直投主稿。整理阶段不重新导演，不用格式门禁替代创作；只修复事实、连续、时长、口型、空间、资产或整理损失。

## 1. 单一底稿与冻结边界

底稿须已锁定剧情事实、人物知情、台词授权、人物关系、题材任务、主读点、压力/过程、主动作路径、接触/受力/停止、场景拓扑、连续状态、时长和本单元新增风险。每镜必须把事实转成可见/可听过程；不能用情绪词、剧情结论、景别名或运镜名代替表演。

完整项目按全剧、场景、生成单元三级继承：全剧冻结人物/资产/色影/声音/摄影基线；场景冻结进入状态、变化、场尾、空间和相对全剧的视听变化；生成单元只写独立执行所需起态、过程和落幅。每个执行事实在最合适栏目完整出现一次，其他栏目只补新增变化。

## 2. Seedance 默认能力

- 默认平台：Seedance 2.5。
- 默认同步生成：画面、人物动作、对白声音和口型。
- 单个成片镜头生成时长上限：30 秒。生成单元可承载多个连续成片镜头，但单元时长仍须服从用户指定的平台能力。
- 用户明确指定其他平台、模型或时长时，以用户指定为准。
- 全项目人声保持清晰干声，不使用混响、回声、延迟尾音、双重人声或拖尾处理。

## 3. 直投整理规则

- 直投稿只保留可执行的画面、表演、摄影、光影、材质、声音、连续和资产信息，不写导演推理、候选方案、审核结论或内部编号。
- 不使用“同上”“沿用上一镜”“承接上一个镜头”等省略指代；每个生成单元独立投喂所需上下文。
- 台词、OS、OV 按原归属和顺序保留；实际发言原文在“台词与声音层次”中只出现一次，时间线只引用语义节点。
- 时间线从 `0.0秒` 连续覆盖到单元末尾，时间窗不重叠、不留空档；单元内剪切写清镜号、切因、轴线、动作、道具和声音承接。
- 人物资产未锁定时，不补造脸型、年龄、肤色、发型、服装、饰品或体型；只写身份、动作、姿态、朝向、位置、关系、临时剪影和受光。

## 5. 栏目验收

- **场景资产图提示词**首次出现时完整写拓扑、材质、色彩、实体光源和拍摄区；复用时只写变化。
- **道具资产图提示词**只为进入因果链、承担证据或需要跨镜保持的关键道具建立；无关键道具时写“无关键道具资产”。
- **场景空间位置关系**必须能用自然语言说明摄影机站在哪里、人物面向哪里、被观看对象位于哪一侧、镜头能看到每个人哪一面。
- **起幅与连续性**写当前第一帧完整事实；**落幅状态**只结算后续仍需继承的变化。
- **画面与表演时间线**必须写具名主体、具体动作、必要物理过程、阶段终态和声音/摄影响应，不以“情绪升级”“镜头推近”“人物爆发”替代过程。
- **台词与声音层次**必须写说话人、受话人、实际话语、自然读法、口型/画外声状态、环境/拟音/音乐让位和跨单元声音接点。
- 特殊正负向约束只处理本单元新增且会改变结果的风险，不复制全局模板，不召回未出场元素。

## 6. 交付后复审

按事实、观看、人物、连续、执行、模板六层复审。发现失败时修复最小受影响范围；源稿缺陷不能由分镜解决时，在交付说明中指出具体限制，不擅自改写剧情。用户只要求分镜文本时，不声称已完成动态预演或成片验证。

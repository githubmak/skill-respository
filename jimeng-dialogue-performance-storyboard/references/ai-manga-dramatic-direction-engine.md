# AI 漫剧复杂剧情、表演与摄影导演引擎

本文件只在多阶段心理反转、三人以上反应传播、连续关系控制权变化，权力入场、公开审视、威胁逼近、资源挤压、空间困锁或关系压制等真实压力任务，或首轮出现表演压平、动作无人物专属性、关系结果/压力方向不可读时读取。冷调、沉默、多人同场不单独触发；普通对白、单次情绪变化和已经成立的关键镜不加载本文件。

它是按需导演知识，不是第二套交付合同、全镜头检查表或固定节拍模板。生成以 `SKILL.md` 和 `production-contract.md` 为边界；只使用当前场景真正需要的模块，未命中内容不登记、不输出，也不为了“深度”补反转、微动作、旁观反应、母题或奇观。

## 最小导演源

复杂场景先冻结六项核心结论：

1. 不可改事实、人物知情和镜尾结果。
2. 题材承诺、本场任务、人物现实任务和观众等待。
3. 当前主关系、人物目标/顾虑、外在策略与表演基线，以及真实存在时的压力来源、主方向、受限选择和既有承受/应对策略。
4. 从进入秩序到离场结果的场景级冲突/情绪/信息/关系曲线，真实转折、策略继续/换法/失效、释放或未解除压力和结果保持方式。
5. 镜头组边界、每组不可替代职责，以及空间、摄影、声音和表演能量怎样递进、错峰或释放。
6. 跨镜必须继承的人物、道具、空间、声音和情绪状态。

其余内容按需补充：只有发生误导才记录公平线索，只有存在选择才记录代价，只有复杂接触才展开物理阶段，只有多人传播才记录传播顺序，只有出现真实时长不足、主读点竞争或物理冲突时才划分不可删核心/可压缩支撑/可删除装饰。不得建立要求每镜填满的巨型源表或能力覆盖账本。

## 题材、剧情与节奏

节奏不得先套统一波形。先从题材承诺、场景任务、人物现实任务和主导拍摄语法确定一个主节奏机制；复杂场景可以让一个从属机制在真实转折处短暂接管，但不能让多套同强度节奏同时争抢。

过程推进、累积蓄压、延迟揭示、误判回收、喜剧等待、动作升级、关系偏移、结果先行和持续观察只是开放选项。短剧感不等于全程快切；爆发前需要积累，命中后必须读到结果。镜长、切镜、运镜、焦点和声音都从同一节奏轴派生。

升级只在信息、策略、关系、危险、距离、空间、道具控制、工序进度或人物选择发生可读变化时成立。提高音量、重复质问、换同义表情或再次推近不能单独构成升级。

### 场景级冲突曲线

冲突场景先确定进入时谁占据空间、话语、资源或道德判断，压力通过什么逐步到达主要承受者，人物原有承受/应对策略怎样继续、换法或失效，哪一次人物行动或信息命中真正改变控制权，以及离场时谁获得、失去或暂时悬置了什么。把议论、忍耐、保护、反制、重磅信息、破防和追问等具体节拍放在同一因果坡度上时，前一节拍必须为后一节拍增加压力、知情、选择限制、承受代价或行动理由，不能只是更近的景别和更重的表情。

根据整场曲线分配空间、摄影、声音和表演能量：入口先建立可被侵入的秩序，升级阶段逐渐改变距离、遮挡、行进速度、声音清晰度、话语主动或人物维持原策略的代价，爆发/释放处让既有积累真正改变动作、声音、关系、构图或声场，信息命中后保留身体、关系和空间的新平衡或未解除压力。各部门不必同步增强；人物喊出时摄影可以前顶，也可以固定承受，重磅消息可以继续逼近，也可以骤停并抽空声音。关键是人物与关系的前后差值，不是每镜慢推或仅靠摄影制造释放。

镜头组按建立、推进、蓄压、打断、命中、反应、反制或余波中的实际职责划分，不要求固定阶段或数量。连续两组若只重复皱眉、握拳、呼吸或推近而没有新压力/策略/信息，合并为同一生成单元的错峰表演或删除重复；反应与开口属于同一次不可分割转折时，可用内部切镜连接，不必为了每个微动作另建一镜。

剧情存在主要转折时，可用以下问题校准，不要求全部形成独立节点：

- 观众原本怎样理解？已有的公平线索是什么？
- 哪个台词、动作、声音、证据或结果迫使人物重新判断？
- 人物第一冲动与其性格、风险、关系控制之间有什么张力？
- 新策略、选择或现实状态具体改变了什么？
- 谁看见、承受或误读了结果？镜尾留下什么？

没有旧预期、选择或不可逆代价时，可以只是信息揭示、情绪转折或关系偏移，不强行升级成反转。不得靠新秘密、突然证据、无依据见证者或新增危险制造爆点。

## 表演表现力与任务动作硬门

主要人物先继承正在进行的任务、姿态、道具、身体条件、关系策略和跨镜表演基线：平常如何控制面部与注意，受刺激时哪一通道最先泄漏并怎样压回或残留，动作通常怎样启动、换重心、发力、制动和恢复任务。每个人物镜都须形成完整表演整体：人物正在做或有意保持什么、什么使其受影响、如何按性格处理、身体/道具/空间怎样响应，以及镜尾留下什么；这些是同一行为过程，不是动作、表情或参数配额。关键情绪必须留下当前景别可感知、会影响后续读取的变化，但不强制转化为夸张外部动作。

### 由内而外的自然表演

关键情绪先问五件事：前一状态还残留什么，人物此刻真正想得到什么，最怕失去或暴露什么，这次刺激对他具体意味着什么，他期待或害怕关系接下来变成什么。刺激的“主观意义”比“愤怒、悲伤、惊讶”等情绪名称更重要：同一句羞辱对一个维护体面的人可能意味着失控风险，对一个保护孩子的人可能意味着必须越界，对一个等待证据的人可能意味着继续忍住。

由此推导 `内在判断变化 -> 注意/身体/声音的第一冲动 -> 性格化控制、伪装、抵抗或释放 -> 任务、重心、距离、接触、道具、话语行动的改变 -> 对方或空间反馈 -> 混合残留`。面部从既有控制基线出发，只写当前景别看得见且由同一刺激造成的起势、压回/维持、失守或残留，让视线、眼睑、口唇、下颌、头颈和呼吸自然联动，不凑完整表情阶段，也不让五官同时等幅变化。这是一条因果检查线，不是要求逐项表演或逐段占时；本能爆发可在同一瞬间跨过数项，克制者可以让声音先稳住而手上任务改速，也可以身体先冻结、声音稍后才失稳。细腻来自变化方向、控制程度、内外错位和后果，不来自微动作数量。

优先让内在变化附着在人物本来就在做的事情、身体中心、空间选择、接触许可或说话策略上；眼睑、眉峰、嘴唇、呼吸和指节只在有具体触发且当前景别能读到时辅助。若换成另一个性格、目标或关系位置的人仍可原样表演，重选外化载体。摄影、光影、声音和环境只响应同一个已经可观察的外化拐点，不得分别给人物贴上互不相干的情绪效果，也不得由运镜抢先替人物宣布变化。导演审核版可简洁解释刺激意义与控制逻辑；Seedance 直投版只写可见、可听、可执行结果，不把内部判断写成分析性旁白，也不新增原剧本没有的 OS。

### 用完整行动掩饰细小反应

人物想隐藏反应、维持体面、避开目光或接触、转移注意、结束话题、保护他人或重新夺回控制时，先寻找其此刻本就能做的现实行动：继续工作、整理或搬放、起身或坐下、转身或换位、开合门窗、照料他人、接管道具等。采用较完整的大动作，必须让行动本身完成任务或改变距离、遮挡、接触、道具控制、话语主动中的至少一项；若删除动作后现实任务和关系读取都不变，它只是无意义忙碌，应删除。

大动作可以遮住表情、切断对视或占满身体，但情绪不是消失，而是从人物没能完全控制的地方泄漏：启动比平时略早或略迟、速度/力度/精度改变、动作做到一半换法或停住、声音仍维持而身体已经偏离、物件落点与平时不同，或重新露面后残留未清。只选择当前景别看得见且最符合人物的一两处，不凑动作与微表情配额。摄影优先读清行动路径、身体中心、任务和空间后果；脸被真实遮住时不写不可见的眉眼变化，必要微表情放在遮挡形成前或解除后的短暂可见点。

任务继续/中断/速度/方法、距离/朝向/重心、空间占位/退路、道具控制/接触许可和话语主动是优先载体。动作载体优先来自人物职业、劳动方式、身体条件、当前工具和真实空间，并继承人物怎样启动与换重心、何处发力/制动、精度如何改变、惯性怎样回收、中断后怎样继续或换法的运动节律；只选择当前动作真正改变且景别可读的部分，不逐项填参数，因此同一情绪在不同人物、题材和关系中不会套用同一动作。

人物有依据地短暂失语、注意力断裂、身体冻结、声音失稳、退入环境声音、与他人形成空间隔离或执意维持原动作时，可以不增加外部动作。主动不行动无需局限于拒绝或守位，只要刺激、人物判断、可读变化和镜尾后果成立，就是真实表演。不得为了通过本门强造触物、走位、皱眉、吸气或任务中断。

情绪词只能命名状态。根据复杂度从下列因果中选择实际发生项：

`继承基线 -> 刺激到达 -> 确认/误判 -> 第一冲动 -> 性格化控制或泄漏 -> 行动、台词或有意保持 -> 对方/空间反馈 -> 镜尾残留`

普通状态维持只需基线、触发或意图、主要过程和停止状态。多阶段心理转折才分段展开；一个词或一句即时短反应不自动增加准备动作链。关键镜若剧情真实存在对外策略与内在变化的差异，须以两个不同通道让二者同时可读；没有差异时不强造潜台词。面部、呼吸和声音可以独立承担内在变化，只要不是无因的同义表情，并且后续读取能看见它造成的影响。

微动作只在当前景别可见、由具体刺激触发且能区别人物演绎时使用。写清必要的开始与停止即可；次数、角度、幅度、速度等只在连续性、物理或表演分寸确实依赖时补充，不做逐帧编舞。

完成关键表演后做换人检验：若把同一动作和声音原样换给目标、关系、职业或身体条件不同的人物仍然成立，说明演绎只表达了通用情绪；回到人物现实任务、惯用控制方式、风险判断和关系策略，只替换缺乏专属性的载体。连续三镜若仍以同一种微动作、道具细节、前景遮挡、景别推进或声音手法表达同义情绪，第三镜须更换通道或在意义、强度、控制权、信息或结果上明确推进。反之，静止或极小变化只要具有人物专属性并改变后续读取，不因幅度小而判为不足。

## 对白与自然语气

每段对白只做一次人物判断：对象与知情、现实行动、期待回应及显露/控制边界；身体与声音从此共同派生。

普通信息对白只留自然开口、话语行动和话落；关系/策略对白写真实转折；关键情绪对白才展开必要的刺激、控制/泄漏、关键词、受话延迟和余波，不套说前/中/后三段式。

状态词不得直接映射固定声音参数。先人物化自然试读，再选最少可听变化：平静不等于平直，认真不等于播报，愤怒不等于喊叫，悲伤不等于哭腔，紧张不等于结巴。

完整台词只在声音栏出现一次，时间线只引必要语义锚；音画同源不等于逐点同频，可有符合人物的延迟、错位或反差。受话者只回应已到达信息，OS 无口型，OV 不被画内人物无因听见。

## 多人关系与反应传播

多人戏同时设计主关系传播链与配角生活反应轨。先按叙事权重区分主要人物、本场关键配角、功能性人物与背景群体：关键配角只需当前小目标、现实任务、关系立场、刺激阈值、惯用反应和镜尾状态；功能性人物与群体按身份、空间位置或共同任务归成少量行为组，保持场景成立所需的工作、交谈、等待、服务、警戒、观察或回避，不逐人建立完整心理链。

传播链只记录会改变观看的部分：谁首先承受，信息何时到达直接受话者，谁因位置、遮挡、注意方向、知情、利益或关系而延迟，以及结果怎样改变空间、道具或话语控制。未受相关刺激者继续原任务；受刺激者才以人物化方式选择继续但改速/换法、短暂确认、与身边人交换反应、避开/靠近、介入或有意不回应，随后回到任务或进入新的可持续状态。配角行为可持续并行，通过背景/边缘位置、较小幅度、弱焦点、遮挡或较低声音层退后，不另占强制节拍；不让全员同步同幅度，也不把不抢戏误写成静止木偶。有职责的站岗、礼仪列队、震惊冻结或装作没看见仍可成立，但必须能读出不动的原因。

关系变化优先落到距离、朝向、接触许可、空间占位、出口、遮挡、中心/边缘、道具或话语主动。若关系只在内心改变，可以通过观看距离、焦点、声音、停顿或人物与环境的隔离呈现，无须强行走位。

对白覆盖按信息任务选择关系宽镜、双人镜、动机化 OTS、干净单人、听者反应或证据插切中的最少组合，不机械补齐正反打。只有空间结果、相对位置或权力结构需要重新建立时才返回关系宽镜。

## 场景压抑、压力传导与释放（按需）

压力不是一种滤镜或固定拍法，而是人物的可选行动被权力、危险、资源、时间、群体判断、关系、空间，或由剧本证据支持的羞耻、自责、责任、自我形象与道德约束实际收窄。按真实发生项写成一条状态因果：`压力来源与主方向 -> 主要承受者及受限选择 -> 既有承受/应对策略 -> 跨镜累积标记 -> 新刺激使策略继续、换法或失效 -> 人物化释放 -> 人物/环境回应 -> 新平衡与余波`。没有释放的场景停在未解除压力、仍在使用的策略和后续接点，不为闭环强造爆发；若说不清受限选择，只按普通气氛或关系戏处理。

同一时段只选一条主压力方向。人物进入后让全场秩序改变，是“人物压向空间”；群体目光、议论或阻断选择集中到人物，是“空间/群体压向人物”。两者都成立时须按时间错峰或让一方退为次级，不能用等强表演、运镜和声音同时表达两条相反方向。跨镜累积须改变压力强度、选择余地、承受代价、应对方法或控制权中的实际一项，不用景别收紧、音量增大或同义微表情假装升级。

表演、调度、摄影、声音和光影从同一方向选择最少够用的载体：人物怎样继续、停下、改速、绕开、控制道具或抢回话语权；空间怎样收紧出口、距离、遮挡、中心/边缘或前后景；声音怎样打断、抽空或改变原有秩序；摄影机让观众站在施压者、承受者或旁观者哪一侧。释放可以是直接爆发、受控说破、动作越界、部分泄漏、失败释放、假性平静或延迟到后镜的安静释放，其强度由累积、人物、风险和触发决定；若只有暗光、推近、慢动作、甩镜、喊叫、音乐抬升、全员转头或长出一口气，而人物的任务方式、行动能力、身体/声音控制、距离/接触、道具/话语主动、关系或空间秩序没有进入新状态，压力或释放都没有成立。

多人反应按“最先听见/看见的人 -> 直接受影响者 -> 关键关系人 -> 其余背景”传播，个体保留不同任务、刺激阈值、延迟和恢复方式。群体反应必须最终影响主要人物的选择、位置、话语权、空间秩序或关系结果，并在释放后显示秩序真正改变、暂时恢复还是仅形成假性平静；配角在命中前后仍保持自身可持续行为。若只形成整齐侧目、全体停机和说明性议论，关键关系人毫无反馈，或爆发后全场无状态差值，视为传播没有命中。

人物揭示镜只有在逐步释放能够增加身份、空间反应、关系变化或观众判断时使用。脚部、背影、影子、局部道具或声音可以作为起点，但不得只做从脚到脸的身体扫描；空间秩序没有随揭示改变时，缩短揭示或直接给全身。写清真实摄影机制：低机位跟移、摄影机后退扩大景别、机身升降、俯仰和焦点交接分别说明；“从脚到全身”本身不是推镜。

## 摄影与视觉句

摄影先回答跟随谁、先知道什么、保持何种距离、怎样看见变化及结果停在哪里。明显成立的方案直接采用；只有观看机制实质改变结果且难取舍时才比较一套非同构替代。

关键镜可冻结视觉句：`具名主体 + 主视觉变化 + 空间/关系对象 + 结果`。首读、次读和结果按复杂度选择，不要求三层；所有摄影剪辑手段均按收益选用，不设配额。

运镜只写可见起点、触发、路径、锁定主体、停止条件和终幅。插切只在改变方向、接触、归属、证据、认知或结果时使用，并保持切入前状态、局部变化和切回继承。不得用快速推近再倒退伪装插切，也不得无桥越轴、穿物、换手或复位。

## 动作、空间与连续性

普通动作按真实因果写到足以拍摄即可。重动作、复杂接触、递接、碰撞、追逐或破坏再展开：

`意图/支撑 -> 启动 -> 路径 -> 接触/命中 -> 受力/惯性 -> 终点/余波`

不存在的阶段删除，不要求每阶段独立成镜。人物位置、朝向、重心、伤势、持物手、道具控制、接触、光区、轴线、声音和未完成动作从前镜落幅传给后镜起幅；只有真实变化才写过渡。

环境压力必须来自已有空间、天气、设施、声场、出口、遮挡、任务或原文危险，不得为氛围新增人物、怪物、机关、爆炸、伤害或线索。普通道具可以承载支撑、任务、距离和材质反馈，但不能无因获得证据、武器、钥匙或身份功能。

## 一次蓝图与交付编译

复杂场景只建立一份最小导演源，先冻结场景级曲线与镜头组，再冻结组内逐镜方案。核心项保持六项，条件模块按实际发生添加，不为未命中能力写“明确删除”。蓝图冻结后按 `production-contract.md` 编译；编译只展开可见/可听过程、补足独立投喂事实和时间顺序，不重新导演。

时间线从 `0.0秒` 连续覆盖镜尾；每个窗口写具名主体、触发或继承基线、主要过程和停止/保持状态。只有对白、复杂接触、多人错峰、道具变化、镜内切点或高风险运镜需要多窗口；单一稳定状态可以一行完成。

只在实际时长不足、主读点互相竞争或物理连续冲突时，先保留事实、主因果、人物策略、关键接触、结果、摄影机制和镜尾余效，再删除重复/互相抵消的装饰、压缩同义支撑、串行信息或拆分具有独立叙事落点的链条。复杂度、提示词长度和预设 Seedance 执行负担本身不构成删减理由；时间允许、内容相容且主次清楚时完整保留，不得统一退回固定中景、浅动作、通用窗光或全员无反应。

## 源头复看

冻结前只检查实际结果：整场是否从进入秩序发展到可读的转折和离场结果，各镜头组是否分别增加信息、触感、压力、关系或进度，摄影/声音/表演能量是否有对比而非连续慢推或重复特写；再检查题材满足、人物专属性、面部与动作基线、关系/选择、镜头起落、声音动作同源、空间物理，以及爆发的积累、命中和结果。真实压力任务还须能跨镜读出来源、主方向、受限选择、承受策略、累积与镜尾未解除压力；发生释放时还须读出策略为何继续/换法/失效、释放的性格化方式、外部回应、新平衡和余波。若只有气氛效果、整齐侧目、说明性对白或摄影能量变化，局部重推压力—释放链。未出现的压力、释放、反转、母题、代价、见证者、光影变化或复杂情绪不检查。

只有发现具体的表演压平、关系不可读、台词语气失真、题材收益未呈现、空间/物理错误或镜头实际平庸时，局部重开相关结论；不得因字段、关键词、镜头平均值或“更稳妥”的偏好重算整场。

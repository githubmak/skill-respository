# AI 漫剧剧情、表演与摄影导演引擎

本文件是正式拆镜前的唯一导演源。在一次连续预演中同时冻结剧情因果、反转、创意导演策略、表演、微动作、台词语气、景别、运镜、压迫感、情绪传递和镜头落幅。后续参考只提供题材、时长、光影、特效、空间连续或交付专项，不得重新导演。

本引擎吸收同类分镜规范时只合并能力，不建立第二导演模式。事实/知情、情绪双曲线、场景压力、物理过渡、道具终态、台词前中后、面部/资产边界与创意摄影共同进入下述一张源表；任何模块都不得把另一模块的结论重算或覆盖。

## 目录

- 导演源锁
- 剧情张力与短剧节拍
- 观众预期、公平线索与选择代价
- 反转与爆点源
- 深度表演、微动作与台词语气
- 拒绝同构的景别与运镜设计
- 视觉句、注意力路径、母题回收与节奏波形
- 压迫感、情绪传递与光影握手
- 六阶段物理动作与环境反馈
- 场景关系、镜头职责与视觉因果
- 对白前中后表演与声音层
- 提示词层级与创意保真降级
- 一次蓝图与编译
- 能力覆盖与漏读防护
- 首次生成必成条件

## 1. 导演源锁

先同时冻结：

- **事实锁**：人物、关系、知情、事件顺序、因果、能力、伤势、关键动作、胜负、结果和结局。
- **叙事立场**：观众情感站位、观众/人物信息差、信息释放顺序、主/客观看法和切换条件。
- **类型母版**：主类型、辅助类型、类型承诺、观众核心期待、冲突载体、升级单位、核心奇观和结果兑现。
- **全局摄影圣经**：画幅/平台、主辅焦段、摄影机性格、人物/情境摄影、景别信息、运动停止、焦点/景深/轴线和动作/特效反馈尺度。
- **手机端规则**：唯一首读点、关键主体尺寸、中心安全区、字幕避让、背景降噪和运动后稳定终幅。
- **视觉版本继承**：`STYLE -> TONE -> MASTER PALETTE -> SCENE VERSION -> SHOT DELTA`；资产固有色优先，只有真实时空、实体光源或世界内特效改变时才升级场景版本。

立场必须改变信息顺序和看见方式；类型必须改变冲突载体和兑现结果；摄影圣经只统一作者性，不把全剧锁成同一机位。

进入第一场镜头前，建立一张内部能力覆盖账本：

`能力域 | 核心/专项 | 已读取规则 | 输入命中证据 | 导演源承载列 | 输出映射 | 状态（已冻结/明确删除/待确认）`

- 核心能力域必须全部是“已冻结”：事实与知情、类型与观众收益、情绪与性格准入、摄影与非同构、空间与连续、时长与负载、光影/滤镜/资产、对白与声音、双文件交付。
- 专项能力域必须逐项判定：重动作/VFX/蒙太奇、关键道具、显式转场、全景/远景/空镜、参考拍摄手法、场景图/空间排错。输入或导演选择命中时完整读取专项并写明源表承载列；不命中时写“明确删除”，不能留空或默认已处理。
- 覆盖账本是防漏读路由，不是创意评分表。它只决定哪些规则必须在首次源表中生效，不统计关键词、景别比例、镜长倾向或创意分数。

## 2. 剧情张力与短剧节拍

不增加剧情事实，从原文重排观众的看见顺序、确认时机和结果强度。拆镜前建立：

`0—10% 异常/危险/信息缺口 -> 10%—30% 即时目标与代价 -> 30%—60% 策略递进与阻力变质 -> 60%—80% 主要反转 -> 80%—100% 结果兑现与新钩子`

百分比是戏剧职责，不是镜头配额。每场在写第一镜前，先在同一导演源表中生成一行事实/知情/节奏预演表：

`场景 | 时间/地点/出场人物 | 入场状态 | 出场状态 | 不可改事实/能力规则 | 本场新增观众信息 | 观众预期/公平线索/误判窗口/重解释 | 人物A知道/不知道 | 人物B知道/不知道 | 当前目标 | 失败代价 | 主要阻力 | 2—4级策略阶梯 | 选择/即时收益/不可逆代价 | 见证者/反应传播 | 控制权转移 | 主要反转 | 结果兑现 | 视觉母题阶段 | 节奏波形 | 场尾钩子`

这行不是另一次分析，也不是事后审稿；它直接为每镜的首读点、台词证据、动作目标、关系覆盖、光影触发和终态提供输入。任何镜头不得改变表中的入场/出场状态、知情边界、能力规则或结果。每场仍须冻结入场时已存在的压力、开场控制者和稳定结果。

剧情状态至少沿 `信息/知情、目标、策略、关系、危险、距离/空间、道具控制、身体/能力状态` 八轴记录；升级必须改变其中至少一轴，并说明改变如何迫使下一镜选择。

每次升级至少改变信息、策略、关系、危险、距离、道具控制或类型升级单位中的一项；只提高声量、重复质问或换同义表情不算升级。采用晚进场、早离场，只压缩程序动作、重复解释和无收益停顿；必须保留前状态、必要过渡、决定性接触和后状态。

高密度段平均每 2—4 秒交付新信息、新策略、动作结果、观看对象、焦点/景别或声音落点之一，不等于每 2 秒强切。允许 1—4 个 0.5—3 秒的有职责短镜连打；职责持续升级时可扩展至 5—6 个。

节奏同时维护三档视觉脉冲：一级脉冲只给决定性证据、命中、身份揭示、不可逆交接、情绪破裂或重要喜剧落点；二级脉冲承担方向、策略、压力和关系变化；稳定段承担建立、等待、压制、结果确认和余波。生成连续 6—8 秒段落时直接安排至少一个有职责的新读取或有意蓄压；生成连续一级脉冲时直接插入结果确认、空间重建或余波，避免刺激透支、空间迷失和生成负载同时失控。

### 2.1 刺激—升级—翻转—释放—尾钩硬握手

每场在第一镜前冻结五段观看承诺，并在源表中逐段写明观众此刻要看什么、人物此刻知道什么和状态如何交接：

1. **刺激/停留**：在开场最短时间内交付异常、危险、关系压力、未完成动作或信息缺口之一；第一读点必须能被画面、声音或动作证据感知。
2. **升级**：相邻有效节拍至少改变信息精度、人物策略、权力位置、危险距离、可用空间、道具控制、行动速度、公开程度或情绪外显中的一项；只加大音量、重复质问、换同义表情或重复推近不算升级。
3. **翻转**：旧策略被具体台词、证据、动作、声音或对方反应击穿，人物重新解释局面，采用新策略并迫使对方/环境出现可见新状态。主要翻转至少改变目标、策略、关系、危险判断、现实认知五轴中的两项。
4. **释放/确认**：命中后必须留出足够窗口读取身体、空间、道具、关系或声音结果；释放可以短，但不得用下一刺激覆盖必要的状态确认，也不能让未解压力无因归零。
5. **尾钩/再钩**：从已兑现的结果、道具新归属、未完成动作、关系新状态、声音先行、目光目标或新代价推出下一观看问题；不得凭空增加秘密、追兵、证据、危险或剧情事件。

五段不等于固定镜头数量或固定百分比。某段不成立时明确删除；成立的每一段必须在事实/知情表、导演源表和镜尾状态中找到对应承载，不得只写“节奏紧凑”“有反转”或“留下悬念”。

### 2.2 观众预期、公平线索与选择代价

主要反转先冻结观众可能形成的旧预期，再放入已经存在于原文、场景、道具、台词或人物行为中的公平线索。公平线索可以被人物误读、被遮挡或暂时缺少解释，但在兑现后必须能回看解释旧信息；不得用未建立的新秘密、幕后事实或突然出现的证据制造惊讶。

每个主要转折补一行：`观众预期 -> 可见公平线索 -> 误判窗口 -> 重解释触发 -> 人物选择 -> 即时收益 -> 不可逆代价 -> 见证者/关系反应 -> 兑现画面 -> 新债`。没有选择或代价的状态变化只算信息变化，不算高感染力戏剧转折。

人物选择必须回答“他本来还能做什么、为什么现在选这个、选完失去什么”。代价可以是退路、公开形象、关系信任、道具控制、时间、能力资源或身体状态；只有原文已有依据时才写入。见证者按主承受者、直接受话者、关键旁观者、空间/群体回声错峰传播，不让所有人同步反应。

## 3. 反转与爆点源

每处有效反转完整经过：

```text
旧预期/旧策略
-> 具体台词、声音、动作、人物或证据命中
-> 人物重新解释当前局面
-> 第一冲动与性格/关系/风险抑制
-> 声音、手部、重心、距离或道具控制泄漏
-> 替代动作与新策略
-> 对方被迫反应
-> 信息/关系/危险/空间/道具/接触的新现实状态
```

主要反转至少改变目标、策略、关系、危险判断、现实认知五轴中的两项；局部战术反转至少改变一轴并直接改变下一句话或下一动作。只有震惊、红眼、愤怒、加特写或甩镜，没有新策略和新状态，属于假反转。

爆点至少同时具备两项：不可忽略的新读取、改变现实状态的行动、有动机的观看尺度/声音/光影/空间显著变化。每个时间窗有一个主机制并读到触发、决定性变化、稳定结果和余波；同一爆点可按“前兆/起势/命中/兑现”连续交接多个机制，特效与运镜不能代替这条因果。主要爆点还要登记本场视觉母题处于建立、变体升级、反转变体或结果回收哪一阶段；母题重复必须改变尺度、关系、代价、信息或结果读法。

## 4. 深度表演、微动作与台词语气

为每个关键节拍建立“内在冲动 -> 社会控制 -> 可见泄漏 -> 外部行动”。先比较面部/视线、手部/道具、身体/空间三类载体，最终至少保留一个改变距离、占位、道具、接触、退路或话语权的非面部行动。

强情绪不只换形容词，而是补足旧控制失效、可见破裂和下一动作起势。原文没写落泪、崩溃、攻击、摔物或跌倒时不得升级。新情绪保留一处旧情绪残留，把两者分配给声音、手部、身体方向、距离或道具控制的不同通道。

微动作必须同时满足：当前景别可见、由具体刺激引发、符合人物惯性、改变或预示下一行动。每个节拍至少登记一个主先兆、一个控制/破裂信号和一个余波；同一镜可以叠加多个同因果微动作，但必须按秒级时间窗错峰，写清主体、触发、延迟、幅度、停止点和跨镜残留。全景只读重心、姿态、距离和占位；中景读上半身行动；中近景/近景才读眼睑、唇线、下颌和吞咽；局部特写只读一个不可替代细节。禁止用“微表情丰富”代替可见触发链。

每句台词在内部冻结：

` 说话者/受话者 -> 已有事实与知情 -> 话语目标 -> 攻/防/试探/诱导/隐瞒/反击策略 -> 表层语气 -> 被压住的底层情绪 -> 语速/声量/声线 -> 重音/停顿/尾音 -> 受话者延迟与动作反应`

台词可保留、删除同义重复，或用说话者已知且原文已建立的人物、时间、地点、道具、行为、矛盾、证据和后果进行证据化增强。攻击性来自证据精度、动词、句式压缩和有任务的停顿，不来自无据辱骂或音量。OS/OV 默认逐字保留。

口型、视线、手部和距离执行同一潜台词策略。关键口型期间不叠加快速行走、大幅转身或多步道具操作；直接听者在关键词后错峰反应，旁观者只回应可感知信息并维持自己任务。

### 4.1 情绪双曲线与性格准入

把人物性格底色/稳定应对模式与当前情绪/危险判断/行动策略分开。只在目标、认知、态度、策略、权力或危险判断改变的关键节点建立情绪因果节拍，不为每句台词机械建点。每个关键节点同轮冻结：

- 造成判断的具体台词短语、动作、声音、道具变化或已发生事实；人物实际看见/听见/确认什么，仍不知道什么。
- 表层目标、深层欲望、核心恐惧和内部矛盾；旧表面策略及其被哪个词、动作、证据或反应击穿。
- 第一行动冲动、不能直接执行的关系/风险原因、一个角色专属主泄漏、性格化控制动作、新策略行动和关系结果。
- 内在强度 1—10 与外显幅度 0—5 分开。高内在强度可以低外显；数值只进入导演源和审核版，直投必须转成可见/可听状态。
- 控制权变化以及旧情绪在呼吸、视线、重心、距离、持物或声线中的一处残留。

动作按 `人物性格底色 -> 当前目标 -> 当前危险判断 -> 惯用防御/控制策略 -> 关系对象 -> 可执行动作` 准入。重要节拍内部至少比较两个动作载体，保留最能同时体现人物性格、当前任务和关系策略的一项，不输出候选。谨慎、冲动、控制、回避、讨好、试探、命令、隐瞒、护人或抢占空间必须形成不同动作逻辑；与性格/目标冲突的动作只有在原文明示、旧策略被具体刺激击穿或人物故意伪装时才可出现。

“符合性格”不等于重复同一动作。同一策略应换载体连续表达，例如谨慎可依次表现为减慢脚步、保留门边退路、先听环境、暂不接取道具；相邻镜已用手部泄漏，下一镜优先延续结果或转向声音、距离、任务中断，不再次握紧。

### 4.2 完整表演链与静止锁定

主要人物表演遵循：

`前镜继承状态 -> 人物/场景刺激 -> 一个主非自主泄漏 -> 性格化压制/掩饰/试探/释放 -> 有目标的行动或台词链 -> 场景/道具反馈 -> 空间/道具/距离/关系结果 -> 镜尾身体与情绪残留`

节点允许写“保持、维持、停在、没有继续”，不要求全身持续运动。每镜可依次使用一个主面部读点、一个身体/道具读点和一个声音/呼吸读点；同一时段只突出一个，其他未指定的头、肩、躯干、手脚保持当前姿势。默认子动作只执行一次，写清触发、延迟、次数、幅度、速度、方向、目标、接触、终点和保持；后动作从前终点开始，不循环、反弹、复位或追加无因动作。

双人同一时刻明确一名主读取人物；受话者可按时长完成“泄漏 -> 控制 -> 反制/残留”的连续响应，不设固定动作个数。扑抱、搀扶、拉拽、递接、推挡等接触可形成双人互动链，按剧情容纳多次攻防/控制权交接，但每次接触都要有明确发起目标、受力关系和阶段终点。高张力优先用可见证据、距离、构图和声音压力，不用“极度、疯狂、猛烈”等形容词替代设计。

### 4.3 对说前/说中/说后、口型与声音桥握手

对白不是把文字贴到画面上，而是沿同一潜台词策略完成三个连续阶段：

- **说前**：写清上一刺激如何到达说话者和受话者；说话者只选一个可读准备点（停手、吸气、抬眼、收回视线、调整重心或护住道具），并写清是否压住第一冲动。受话者在台词开始前只能保持已知基线，不能提前读取未说出的内容。
- **说中**：完整口型优先。每句台词只在必要关键词、语义转折或停顿处触发一个可承载的动作、焦点或声音变化；说话者不同时执行快速行走、大幅转身、多步递接、复杂接触或竞争性特效。口型可见时必须锁定说话者面部归属、景别、曝光、视线方向和受话者延迟；OS 无口型，OV 画内人物不听见、不回应。
- **说后**：最后一个字结束后保留尾音、呼吸、视线、手部张力、距离、道具控制或受话者延迟中的至少一个结果，直到关系/空间状态稳定。说话者不能在尾音落下时自动回到中性，受话者不能在关键词之前完成反应。

声音桥与环境声必须写成可追踪的声场链：`声源/人物 -> 距离与方向 -> 遮挡/材质/混响 -> 进入或先行时刻 -> 跨切保持 -> 新空间声接替或退出`。声音桥可以承接尾音、脚步、摩擦、机械、风雨、门响或已存在的环境底噪，但不得无因重启、改变声源归属或替人物补写未发生的信息。台词出现时，非关键环境、情绪音效和音乐主动避让字头、关键词、停顿和尾音；环境声仍须保留足以证明空间、压力和距离的最低层。

每镜在时间线上明确“说前刺激/准备 -> 台词开始 -> 关键词触发 -> 反应延迟 -> 台词结束 -> 余波/声音桥接”，完整执行台词只在台词字段出现一次，时间线只引用必要关键词。声音、口型、动作、摄影和焦点必须共享同一观看目标；如果不能共享，改为串行时间窗或相邻镜头，不用混写掩盖冲突。

## 5. 拒绝同构的景别与运镜设计

每镜先锁定具名拍摄主体归属，再冻结“最强起幅 -> 唯一主体 -> 一个主视觉动词 -> 稳定落幅 -> 相邻主反差”。景别由必须读到的信息和心理距离决定：全景读路线/占位/规模，中景读上半身行动/关系，近景读面部策略/口型，特写读单一证据/接触/破裂。不机械远中近，不以低风险为理由默认中景。

为摄影候选登记六维指纹：

`[主要主体，起幅景别，机位高度/方向，主运动/静止机制，信息揭示顺序，终幅景别/结果]`

主要反转必须在拆镜前比较三套非同构候选，其他关键节拍至少两套。候选必须来自不同机制家族，例如：距离跃迁/局部命中、空间权力/负空间、遮挡揭示、声音/焦点先行、动作跟拍急停、固定压迫与调度、全景规模兑现。

两候选六维中有四维相同，或只替换焦段、俯仰、左右、速度形容词和终幅表情，即判定为同构并废弃。最终候选至少在主体、观看距离、空间关系、运动机制、揭示顺序或结果读法中改变三项，再按剧情收益、人物策略、空间成立、手机可读、光影强化和 AI 负载只选一套。不折中拼接候选。

跨镜也拒绝同构：相邻爆点不得复用同一主运动、同一揭示顺序和同一终幅类型；连续三镜同时落在相近景别、机位高度/方向和固定/缓推时，只有等待、仪式、喜剧重复或持续压迫能作为理由。母题复用必须在尺度、信息、代价、关系或结果上升级。

禁止用同一中景/中近景和缓推覆盖 10 秒以上关键反转。刺激、断裂、策略和结果无法在同镜稳定读取时才拆成有职责镜头组；能用人物调度、遮挡、一次焦点交接或一次景别变化完成时不机械拆分。

运镜执行句统一为：

` 可见起点 -> 触发 -> 速度/方向/路径 -> 锁定的具名主体 -> 停止触发 -> 终幅具体画面`

连续摄影运动在一个窗口内保持一条可追踪路径；较长镜头可以通过明确切点或焦点/遮挡交接完成多个景别阶段，不能把 A→B→C 伪装成无因连续变焦。任何阶段都不能制造穿墙、穿人、换手、换位或无因转身，运动/切换后必须留稳定读取窗。

### 5.5 具象机位、轴线与视觉因果握手

每个镜头的摄影句必须同时回答五个问题：`摄影机在哪里、先拍谁/什么、观众先看到哪条因果、如何经过、停在哪里`。源表至少冻结：具名主体、起幅景别、机位高度/俯仰、正侧方向、焦段或观看距离、前中后景与左右位置、轴线一侧、主运动/静止机制、触发、路径、锁定对象、停止条件、终幅可见范围和相邻镜头反差。不能用“压迫感更强”“关系更紧张”“职业感”“电影感”替代具体画面终点。

视觉因果按 `原因 -> 先兆/传播 -> 接收/接触 -> 状态改变 -> 余波/确认` 选择真正需要可视化的环节。每个镜头必须标明本镜唯一新增读取；若观众需要先看环境受力、声音或材质再看事件主体，允许效果先行，但必须在后续镜头给出可靠的主体/方向/尺度参照，不能用主观误导制造事实矛盾。

插切必须完成三态握手：`切入前状态 -> 唯一变化/唯一证据 -> 切回后继承状态`。源表登记直接切入、直接切回、切回时同机位/焦段关系、轴线侧、构图方向、光源和声音连续点；切回不得重新起势、改变空间侧别或让道具/身体状态回退。插切不足以独立承担信息时，改用连续焦点、遮挡揭示、局部起幅或相邻职责镜，不用快速推近再倒退伪装因果。

轴线变化只在人物真实换位、正面中性机位、明确跨轴动作或主观视点改变时发生；必须写出越轴原因和新的屏幕侧。机位、人物、道具、声音和光影的终态必须共同落在同一可达空间，任何穿物、瞬移、遮挡吞掉关键接触或无桥换手都退回导演源修正。

### 5.6 视觉句、注意力路径与母题回收

关键镜头在源表中冻结一条可复述的视觉句：`具名主体 + 主视觉动词 + 空间/关系对象 + 不可逆结果`。镜头不是只写“拍到什么”，还要写观众先看什么、随后看什么、最后确认什么：`首读 -> 次读 -> 结果确认`。首读由动作、对比、视线、声音或构图承担；次读补充关系、证据或代价；结果确认必须落在可见身体、空间、道具、材质或声音状态上。

每场只选一个主视觉母题，并登记首次建立、变体升级、反转变体和兑现回收。母题可以是出口、门槛、光区、空位、容器、距离线、反射、影子、声音源或动作形状；没有新增信息、关系、代价或结果时，不重复母题。

### 5.7 节奏波形、声音母题与场景反差

每场在源表冻结一条节奏波形：`蓄压 -> 加速 -> 屏息/停顿 -> 断裂或命中 -> 结果保持 -> 余波/再钩`。为每段绑定镜长倾向、景别/运动倾向、台词密度、环境声密度和音乐/静默状态；不要求每场包含全部阶段，但成立的阶段必须有镜尾承载。

关键人物、关系或威胁可建立声音母题，例如脚步、机械节拍、门响、呼吸、提示音或一句尾音。声音母题必须有首次出现、压力变形、关键回收和退出条件，不得把不存在的音乐或声源强行加进普通场景。整集相邻场景至少在压力载体、观看距离、节奏波形、释放方式或声音母题中的两项形成有职责反差。

### 5.4 高级运镜候选生成器

运镜先由视觉任务决定，再由题材、人物、空间和平台约束具体化。每个主要节拍至少比较三个不同机制家族，候选可以跨越并交接，不得把“推近=紧张、环绕=高级、甩镜=爆点”当默认映射：

- **空间/权力**：固定目击、横向视差、前景侵入、低位压迫、长焦压缩、急拉全景、垂直升降、斜俯/俯冲、出口反向占位；
- **认知/信息**：遮挡揭示、焦点接管、声音先行、反射/玻璃折射、主观受限视点、视线匹配、静止后硬切、由局部拉开尺度；
- **行动/动量**：单向跟拍、被动退让、贴地追随、动作轨迹环绕、接触急停、冲击切、速度坡度、短暂升格、固定机位让目标冲出画面；
- **情绪/关系**：缓慢逼近、拉远孤立、双人中轴保持、侧向分离、绕过遮挡重新建立、推拉错觉、静止留白、人物进入/离开光区；
- **喜剧/反差**：严肃近景突然稳定客观全景、错误关注点的横移、旁观者迟到半拍的焦点交接、道具结果反打、构图过度正式后切生活化细节；
- **规模/奇观**：地面到高位的尺度揭示、建筑/阵法纵深、人物与巨型对象反向运动、环境先兆穿行、空间连续拉远、垂直坠落/上升视角。

候选冻结 `任务收益、起幅、机位/焦段、运动路径、触发、观看对象、速度变化、停止/交接、终幅、手机端首读点、光影/声音配合`。相邻高峰不得只改速度形容词或焦段；候选间至少改变主体、空间关系、运动机制、揭示顺序或结果读法中的三项。AI 负载只影响交接方式和时间窗，不得先删掉高级机制。

### 5.2 主驱动力与耦合响应预算

每镜首次生成时冻结主驱动力序列：`人物动作｜对白/声音｜环境压力｜摄影机运动｜焦点/遮挡｜道具状态｜光影变化｜剪辑切点`。每个时间窗只有一个当前主驱动力承担首读点；较长镜头可以由明确关键词、动作接触、焦点揭示、特效命中或剪辑点触发主驱动力交接，其余元素作为当前窗口的耦合响应。

每个耦合响应都与当前主驱动力共享四项：`同一触发证据、同一观看目标、同一传播方向、同一阶段终态`，并在秒级时间线上错峰。生成时可按 `声音先行 -> 人物/道具行动 -> 摄影/焦点接管 -> 特效/光影命中 -> 关系/空间结果` 交接；不同高复杂度元素可以在不同窗口接管，不得在同一瞬间争夺首读点。若不同触发和终态能在时间线上先后成立，保留为驱动力交接；只有时长或连续性无法承载时才拆成相邻镜头。

源表同时冻结读取带宽：`首读窗口、主变化窗口、耦合响应窗口、结果确认窗口`。人物大动作主驱动时，摄影机做相容的跟随/退让/急停；对白主驱动时，口型优先，听者、同策略动作和摄影变化可按关键词和停顿依次进入；摄影机/焦点主驱动时，人物保持清楚基线并在揭示点接管；VFX主驱动要求世界规则、人物、材质和阴影共同响应。只要时间线明确，多个窗口可连续完成，不通过降低表演深度解决。

主驱动力不是低负载限制。高表现镜可以并行多层并连续交接，只要每个窗口有清楚首读点、同因果耦合和可追踪终态。

### 5.3 镜头组覆盖与景别梯度

先把相邻镜头设计为共同完成一个剧情节拍的镜头组，再决定单个生成段是否内部插切。镜头组按需从六类职责选择，不要求全部使用：

- **空间关系镜**：人物、出口、障碍、轴线、距离和权力位置。
- **行动全貌镜**：动作起点、路线、接触和终点，防止特写切碎物理过程。
- **情绪承受镜**：拍真正被信息击中的人物，而非总跟随说话者。
- **决定性证据镜**：眼、手、脚、武器、道具、裂纹、影子或材质提供不可替代信息。
- **旁观反应镜**：一名关键旁观者的低幅反应证明冲击扩散到关系网。
- **结果/余波镜**：展示空间、道具、身体或关系的不可逆变化。

普通节拍通常由关系/行动主镜加一个情绪、证据或结果落点完成；翻转、峰值和重要喜剧点可用三段式，但第三段必须增加后果或认知。景别梯度可为“关系/行动 -> 不可替代情绪或证据 -> 关系/后果”，悬念也可为“局部异常 -> 人物判断 -> 客观关系揭示”。同一信息不得用中景、近景、特写连续重复；每次距离变化都要改变观看对象、信息精度、心理距离、权力读取或动作可见范围。

连续两个近景/特写后，若空间已变、存在多人或下一动作需要位移，直接在源头使用关系镜重建；空间未变且近距离停留正在制造压迫、亲密或喜剧等待时可以继续，但必须交付新表演信息。大全景/远景不承担手指、口型或眼内变化；ECU 只承担一个决定性读点。

多人场景只让真正收到刺激、信息改变或承担职责的人反应。通常选择一至两名关键旁观者错峰低幅反应；群体立场、恐慌或秩序确实改变时，按刺激传播顺序分层发生并保持一个主承受者。反应只能提示真实影响、群体立场、权力变化或下一策略，不得新增立场和剧情。

### 5.1 画幅与手机端执行

画幅不是输出参数登记，而是逐镜构图约束：

- **9:16 手机竖屏**：主脸、关键手部、证据和接触点优先进入中心安全区；顶部状态栏、底部字幕/按钮区不承载唯一信息。人物横向移动前先留出运动方向，运动后停在可读终幅。
- **16:9 横屏**：先保证左右人物关系、出入口和动作路线完整；字幕避让不能遮住手部接触、地面落点或关键道具。
- **2.35:1 宽银幕**：用横向空间、前后纵深和负空间表达权力/规模；重要面部或证据必须通过画面尺寸或切镜补回，不把细节压在边缘。
- **1:1 或自定义画幅**：重新计算主体尺寸、运动方向、头顶/脚底余量和字幕安全区，不直接裁切 16:9 构图。

每个高价值镜头只设一个手机首读点，并复核起幅、运动中和落幅是否仍可识别。背景降噪只能降低无关对比、粒子和运动，不得用模糊吞掉空间锚点、道具路径或人物身份。

## 6. 压迫感、情绪传递与光影握手

压迫感必须先有可见的压力源：人物逼近、退路消失、门口/座次/道具被控制、时限、多人围合、空间狭窄、信息差或危险规则。再从六类载体中按时间窗选择和交接主机制：

- 前景侵入、真实遮挡或框中框收紧可用空间；
- 负空间、出口占位或高低差让权力可见；
- 长焦压缩距离，或近距离广角让威胁占满画面；
- 摄影机被动退让、下压、贴地或固定目击人物失去选择；
- 声音逼近、环境抽空或关键拟音先于画面命中；
- 实体光源遮挡、人物移入窄光或背景对比上升，但人脸仍可读。

人物压力和环境压力分开登记。环境压力可以来自出口/遮挡/狭窄空间、已存在的时限或灯具状态、脚步/机械/过度安静/天气、松动构件/湿滑地面/火焰/车辆，以及公共空间的注视和礼仪限制。必须沿物理链执行：

`已有压力源 -> 可见/可听/可感知载体 -> 传播方向与强弱 -> 人物何时感知 -> 符合性格的危险判断 -> 策略/动作 -> 环境后续反馈`

人物只能响应自己已经看见、听见或感受到的信号；环境压力不得凭空变成新事件、危险或线索。撤销压力时也要写解除来源、人物判断和空间/声音恢复状态。

压迫形成“可用空间缩小 -> 人物原策略失效 -> 观看距离/声音/光影收紧 -> 人物行动选择被迫改变 -> 结果落幅”。不写“压迫感升级”就算完成。

情绪传递使用“刺激源 -> 主角控制破裂 -> 受话者延迟反应 -> 群体/空间回声 -> 新关系落幅”。反应幅度按知情、关系和利益不同而错峰，不让全员同时瞪眼、回头或后退。

### 6.1 爆款短剧压迫曲线与反制释放

每场把压力拆成可累积的向量：`谁/什么施压、从哪条路径到达、人物可用空间、剩余时间、规则/身份限制、公开见证人数、失败代价、可用退路`。压迫可以来自对手、制度、礼制、群体目光、环境、倒计时、能力代价、身体状态、信息差或观众已知而人物未知的危险；多个来源可以叠加，但必须分别有可感知载体和传播顺序。

压力曲线优先形成：`可见压力建立 -> 人物维持旧策略 -> 第一处退路/资源被夺 -> 短暂假释放 -> 更近或更公开的二次加压 -> 性格化反制 -> 压迫源失效/转移 -> 爽点结果与见证者确认 -> 新代价/尾钩`。原文不足时只使用其中成立的节点，不新增事件。

加压不只靠推近和提高音量。可让出口被占、人物被迫进入窄光、前景侵入、群体停止动作、声音从远到近、规则被公开宣读、道具控制权改变、人物被挤出中心、背景空间逐步不可用或摄影机从主动逼近转为被动退让。每次加压至少改变压力距离、公开程度、退路、时间、规则、资源或关系中的一项。

反制必须由人物目标和既有证据发动：改变站位、抢回话语权、让对方进入自己的规则、公开证据、完成专业操作、保护/拒绝接触、利用场景或能力克制。反制镜不能只拍表情变狠；必须让压力源、见证者、道具、空间或关系出现可见新状态。释放可以用关系全景、群体让路、声音恢复、光区打开、道具归位或人物终于完成未完成动作，但不能把未解压力归零。

压迫与爽点形成反差：压迫越具体，兑现越需要读到“之前失去什么、现在夺回/改变什么、谁看见、后续要付什么”。主要反击可同时用表演、调度、摄影、光影、声音和特效连续交接，不设手法数量上限，只控制每个时间窗的首读点。

光影在本阶段冻结剧情触发与情绪任务；具体曝光、景别级面光、光比、色温、实体光源、分场继承、逐镜材质反馈和特效受光按 [cinematic-lighting-color-bible.md](cinematic-lighting-color-bible.md) 一次完成。每镜必须写当前人物实际受光、暗侧可读性、关键道具/材质反馈和落幅稳定状态；无物理变化时也要明确继承的光区与材质基线，不得只写“光影不变”。

## 7. 一次蓝图与编译

每场只建立一份内部导演源表，并在第一次生成时一次填满；后续编译和验证不得重新创作：

`镜号/节拍 | 剧情/节奏/类型职责与切镜依据 | 不可改事实与知情 | 观众预期/公平线索/兑现/新债 | 选择/即时收益/不可逆代价/见证者 | 叙事立场/首读→次读→结果确认 | 视觉句/母题阶段 | 节奏波形/声音母题 | 主驱动力/触发/观看目标/方向/终态 | 耦合响应/错峰 | 进入情绪/残留/目标/危险判断 | 刺激->冲动->控制->泄漏->新策略 | 反应传播链 | 秒级微动作/受话者反应 | 六阶段物理动作 | 关系覆盖/插切三态与声音接点 | 场景槽位/轴线/路径 | 道具控制者/物理终态 | 选中摄影指纹/起落幅/相邻差异 | 景别级面光/材质反馈/视觉版本差量 | T_speech/T_act/T_react/T_buf/T_shot | 提示词层级/降级顺序 | 本镜新增正负约束 | 下一镜接点`

这张表是质量生成源，不是事后检查表。剧情深度、动作、表演、摄影、光影、声音、空间和连续性必须在冻结表里互相推导并共同决定镜头；不得先写简版镜头，再靠验证器扫描关键词或重写正文补齐。

再按切镜准入拆分：主体、策略/权力/危险、刺激证据、控制断裂、空间/道具/接触、新事实、心理距离/观看顺序或明确转场至少改变一项。句号、停顿、视线或微表情本身不构成切点。

所有状态变化执行“前状态 -> 必要过渡 -> 后状态”硬握手。转身、落座、站起、位移、逼近、退让、拿放、递接、换手、接触建立、伤势变化和进入新光区可以缩短、并入相邻时间窗或独立成镜，但不得彻底省略。上一镜未完成的动作从原接点继续，不得重新起势、自动复位、无桥越轴或直接跳到结果。

一镜可包含时长能够承载的同因果子动作、微表演、错峰反应、环境反馈、驱动力交接和特效阶段，不设固定动作数量上限；允许摄影机、人物调度、动作、多人反应、特效和光影达到高表现负载。负载控制只负责把无法在时间窗内读清的独立链条拆成相邻生成段、明确交接和保持状态，不得把动作降级成静止中景、把光影降级成通用窗光、把多人反应删成全员无反应，或用“模型难生成”取消爆点。

### 7.1 首次生成质量决策

导演源表不是先写镜头再勾选项目。生成每一行时按同一因果顺序直接做出以下决定，当前决定立即成为后续列的输入：

1. 先定本镜新增读取、人物策略或物理结果，再定是否切镜和镜长。连续短镜只有在职责逐级升级时生成；重复表情、视线、相近信息或同级刺激直接并入同一表演单元。长对白按语义行动分段，不用平均镜长、目标镜数或固定短镜配额反推。
2. 从刺激和人物目标直接生成情绪状态、控制方式、可见泄漏、非面部策略动作和受话者错峰反应。相邻镜主动更换表演载体，在面部/视线、声音、手部/道具、重心/距离、朝向/占位之间按人物策略选择；不得先生成再统计“看、停、呼吸、嘴角”等词频才换动作。
3. 从必须读到的信息、空间权力和手机端尺寸直接选择景别、具名主体、机位高低/俯仰/正侧方向、构图层次、主运动和具体落幅。固定镜、中景或缓推只有在等待、压制、完整口型、空间僵持或结果确认最准确时才选；关键刺激、控制断裂、策略改变和结果不得无因塞进同一长中景。全景/大全景、特写/大特写/局部特写只在承担空间、规模、证据、接触或认知职责时生成，不按比例补镜。
4. 选中摄影指纹时同时写明它与前后爆点在主体、观看距离、空间关系、运动机制、揭示顺序或结果读法上的实际差异。急停、斜俯、遮挡揭示、冲击逼近、甩镜等机制连续复用时，必须在生成第二镜前完成信息、尺度、方向、代价或关系升级；否则当场换成声音先行、焦点交接、空间调度、局部证据、全景兑现或固定目击等不同机制。
5. 运镜句在生成时就拆清摄影机、人物和视线三个主语，写可见起点、触发、路径、锁定主体、停止条件和具体终幅；构图与光影分别写空间层次和实体受光。不得先生成“顺着视线看、停在压迫感、关系更紧张”等抽象句，再靠文字检查改写。
6. 依据台词、动作、反应和缓冲公式直接生成秒级时间线。复杂镜先保留刺激、预备、接触、惯性、结果和保持，再决定并行或拆段；不在成稿后依据语义标点数、动作词数量或平均时长重新拆镜。
7. 显式转场在源表生成旧场尾锚、新场接锚、承接机制、跨场情绪/道具/声音余势和稳定新事实；不把“转场起镜”标签留给验证器判断。全局负向与本镜负向只禁止无动机乱晃、身份漂移、穿物、错手、复位、口型冲突等具体失败，不得无条件禁止快速运动、高速运镜或剧烈镜头。
8. 光影、面部曝光、材质反馈、道具控制者、物理终态和下一镜接点与摄影/动作同时生成。任何位置、距离、朝向、接触、光区、持物手或控制权变化都在本行时间线完成，并直接写入落幅与下一行起态。

上述决定只做一次并写入表格，不另建创意评分、关键词覆盖、景别占比、运镜保守度、微动作词频或平均镜长审核。若某种克制或重复具有明确剧情职责，直接把职责写进源表；若没有职责，在首次生成时就不产出。

### 7.1.1 提示词层级与创意保真降级

每镜把执行信息分为三层：`不可删核心`（事实、人物归属、主动作因果、首读点、关键接触、结果、口型/声音接点、落幅状态）；`可压缩支撑`（次要材质、次级反应、辅助运动、非关键环境层）；`可删除装饰`（不改变剧情、关系、空间、状态或观看顺序的纹理、粒子、花式运动）。

只有出现具体身份漂移、穿物、错误换手、口型冲突、空间不可达或时长不足风险时才降级，并按“删除装饰 -> 压缩支撑 -> 拆分独立链条”执行；不可删核心不得被删除或改成抽象词。降级后必须保留同一视觉句、首读点、结果和母题阶段，不能用“更稳”把镜头退回无职责中景。

### 7.2 逐镜情绪状态账本（执行层）

逐镜必须继承并更新人物状态，不得只在场景级写一次情绪。每镜正文至少写出：

`进入状态（主/次情绪、旧残留、危险判断、目标、内在强度1—10、外显幅度0—5） -> 本镜刺激证据 -> 第一冲动 -> 社会控制 -> 可见泄漏 -> 新策略或保持 -> 退出状态`

- 每个状态变化写具名人物、触发来源和反应延迟；没有新证据时明确保持上一状态及其身体基线。
- 微动作必须落到身体、视线、手部/道具、重心/距离或声音中的具体载体，写明开始秒点、持续区间、幅度、速度、次数和停止状态。
- 允许内在强度高而外显幅度低，也允许在剧情证据支持时达到高幅度；不得把强度数字直接翻译成夸张表演。
- 退出状态必须交给下一镜：姿态、呼吸、视线、重心、距离、声音尾势和未完成动作都要可追踪。

情绪状态不能因切镜、景别变化、换台词或转场自动归零。没有新的剧本证据、危险解除、目标达成、关系变化或明确时间跳跃时，主导情绪、次级情绪、旧残留和惯用策略继续继承；新情绪默认叠加而非无因覆盖旧情绪。稳定镜可以用“保持”承载持续压力，不为填满时间线强加眨眼、手指或呼吸动作。

### 7.3 六阶段物理动作与环境反馈

重动作、打斗、斗法、追逐、碰撞、递接、开合、破坏和大幅位移，必须从以下六阶段推导；不要求每阶段独立成镜，但不能跳过因果：

`意图/目标 -> 预备与支撑 -> 发力/启动 -> 路径或能量传播 -> 决定性接触/命中 -> 受力与惯性 -> 终点/余波`

- **意图/目标**：具名主体想改变谁、什么位置、哪件道具或哪种能力状态；写清战术目标和失败代价。
- **预备与支撑**：脚步、重心、支撑手、握持、蓄力方向、身体朝向和可用空间；动作不能从静止瞬移到接触。
- **发力/启动**：明确哪一侧先启动、力量从何处传出、速度如何变化，摄影机只跟随同一主方向或主动反应。
- **路径或能量传播**：写轨迹、传播介质、遮挡、速度、范围和中途是否改变方向；斗法/特效必须写规则、媒介和衰减。
- **决定性接触/命中**：写接触对象、位置、受力方向、碰撞关系、道具控制变化和首读点；必要时允许一次局部插切，但必须能切回同一状态。
- **受力与惯性**：写身体、道具和环境如何延迟、回弹、滑移、倾斜、碎裂、震动或停住；反馈不得反向、提前或循环。
- **终点/余波**：写人物最终姿态、距离、伤势、道具归属、环境损伤、声音衰减和可持续保持状态；余波只选一项主介质，必要时加一项晚半拍同源反馈。

复杂动作可以并行高负载，但时间线必须分别标出支撑、启动、接触、惯性和终点；若必须拆段，每段都复述当前起态和终态，不得把中间状态留给模型自行补全。

### 7.4 场景关系与连续性生成

每场在导演源内冻结一张关系地图：入口/出口、门槛、主要家具、危险区、固定光源、关键道具、摄影机活动区与禁入区；每个人的起始槽位、纵深、朝向、目标位置、可行路径、关系轴和屏幕侧；谁占据中心、谁控制退路、谁被遮挡、旁观者看向谁。

新场通常用大全景、远景、全景或有职责空镜同时建立时间地点、人物数量/位置、出入口、锚点、前中后景和主光方向；建立镜必须为后续移动、视线与冲突提供坐标，不拍无关风景。突然、主观、惊吓或故意隐藏空间时可从局部起镜，但随后必须在信息需要前补回可理解的关系空间。

每镜在首次生成时写入并交给下一镜：

- 人物画面左/中/右、前/中/后景位置，身体朝向、视线对象、移动方向和距离。
- 摄影机轴线一侧、机位活动区域、越轴原因、前景遮挡和固定空间锚点。
- 人物持物手、支撑脚/手、伤势、服装、未完成动作和光源方向。
- 道具控制者、手别、具体位置、显隐、开合、亮灭、完整性、受力状态和最终归属。
- 当前镜的刺激、反应延迟、动作接点、情绪残留、声音尾势和下一镜起幅。

只要位置、距离、朝向、控制者、接触、光区或屏幕侧改变，就必须写出真实过渡或独立过渡镜；不能用切镜、换焦段或“镜头切到”代替物理变化。场景图只锁定客观结构，不自动决定机位；首稿完成后还要复核穿物、遮挡、路径、接触距离和光源方向。

每场同时登记人物压力和场景/环境压力。环境压力只能从既有空间、时间天气、设施运行、可感知声场、出口/遮挡、当前任务或原文危险推导，并执行 `压力源 -> 可见/可听/可感载体 -> 传播方向/强弱 -> 人物实际感知 -> 性格化判断 -> 策略/动作 -> 环境后续反馈`。压力原因未解除且人物仍在作用范围内时跨镜继承；不得为氛围凭空增加未出场人物、追兵、怪物、机关、爆炸、伤害或新线索。

普通场景道具只能承接手部停顿、支撑重心、遮挡、距离控制、材质反馈或已有任务，不得突然获得证据、身份、钥匙、武器、药物或其他新剧情功能。关键道具的首现、拿放、换手、开合、显隐、亮灭、受力和控制权全部进入连续性账本并由镜尾结算。

### 7.5 镜头职责、视觉因果与峰值保护

每镜冻结一个主要剧情职责和一个主导节奏职责。剧情职责可为建立空间、交代动作、传递信息、展示反应、强化情绪、完成转折、建立/回收道具、转场或尾钩；节奏职责可为建立、蓄力、叠加、停顿、释放、翻转、峰值或余波。没有独立信息、关系、动作结果或情绪状态变化的镜头合并。

重要节拍先写：

`第一读点 -> 原因/先兆 -> 传播或接触 -> 状态改变 -> 余波/确认`

需要误导时写暂时隐藏的尺度、身份、来源或归属，并在客观揭示镜提供可靠参照。眼、手、脚、武器、道具接触点、裂纹、影子和材质只有在提供方向、目标、接触、归属、认知或结果时才插切；插切必须完成“前状态 -> 唯一变化 -> 切回继承状态”三态握手。

主观误导只能隐藏或延迟真实信息，不得伪造事实。先冻结视点属于谁，并用遮挡、尘幕、逆光、局部身体、画外声、景深或暂时移除尺度参照控制认知；误导镜不得意外露出完整身体、地面接触点、门框、固定家具、身份标志或当前持有人。客观揭示至少给出一个可靠参照，并立即交付人物/关系结果；同一真相只做一次完整误导与揭示。

#### 7.5.1 关系覆盖与回收

对白或关系戏先按信息任务选择最小但完整的覆盖结构，而不是按固定镜头清单铺满：关系宽镜/双人镜负责谁控制空间、距离和退路；动机化 OTS 负责受话者的观看压力；干净单人镜负责策略性口型或证据落点；受影响听者反应镜负责延迟与关系回声；证据插切负责已建立物件/动作改变认知。压力逼近后，只在空间结果、人物相对位置或关系权力需要重新建立时返回关系宽镜。覆盖选择必须写入本镜“唯一新增读取”，不得机械补齐反打或两人镜。

连续对白若连续两镜都以单人近景承载，下一镜必须在源头决定是保持单人以保护口型、转为 OTS/双人以揭示权力，还是切证据/听者反应以改变信息；不能等成稿后补关系镜。

#### 7.5.2 高价值插切容量与过载退路

插切只在能改变方向、接触、归属、证据、认知或结果时生成。每个插切在源表登记 `用途、唯一读点、前状态、变化、切回继承状态、声音连续点`，执行句明确“直接切至”与“直接切回”，不得伪装成摄影机高速推近再倒退。切回必须返回插切前同一机位、焦段关系、轴线侧、构图方向和光源条件，同时继承插切造成的新状态。

插切期间主镜只选择一种状态：保持不动、单方向低负载动作在画外继续、或由插切直接完成状态改变。声音默认连续，用环境、动作、台词画外延续或声音先行维持时空；刻意静音必须有剧情职责。台词中的插切优先放在开口前、自然停顿、关键词后或说完后，插切画面不产生第二个错误口型。

按生成段分档冻结容量：不足 5 秒通常不内插；普通 5—8 秒为 0—1 组“切入/切回”；关键 8—15 秒为 1—2 组且职责不同；15 秒以上仍以两组为连续身份/空间状态的上限，更多证据改成相邻镜头组。超过容量时不删除决定性证据，按以下顺序处理：`删除次要插切 -> 用连续焦点交接/局部起幅承载 -> 将插切独立成相邻镜 -> 拆成冲击镜/动作镜/结果镜`。插切数量不是质量配额，独立镜可重新获得完整起落幅和稳定结果。

ECU、景别跃迁、声音抽空、急停和强特效只给决定性证据、命中、身份揭示、不可逆交接、情绪破裂或重要喜剧落点。峰值后必须留下身体、空间、道具、声音或关系的可读结果，不能用下一个刺激覆盖确认窗口。

### 7.6 对白前中后表演与声音层

对白镜按“说前 -> 说中 -> 说后”组织：说前写刺激、呼吸/停手/抬眼/重心中的一个准备读点；说中只在关键字触发一个稳定口型可承载的动作或反应；说后保留视线、呼吸、手部张力、距离或道具控制，不在最后一个字落下时归零。受话者反应必须标明即时、延迟、压住或转向第三人，不能提前。

每镜按实际内容组织人物声音、关键动作拟音、空间环境、场外信息、情绪音效和音乐的主次、距离、方向、混响、进出、遮挡和跨切。台词/OS/OV优先，关键动作声次之，环境声承担空间与压力；未授权音乐不添加。声音先行、动作声切镜、环境抽空和声音桥都必须写触发与接替时刻。

台词、动作、反应与摄影必须形成唯一执行顺序：`起幅 -> 外部刺激 -> 说前反应 -> 台词开始 -> 关键词触发表演/焦点/摄影 -> 台词结束 -> 受话者反应 -> 镜尾残留`。完整执行台词只在台词字段出现一次，时间线仅引用短关键词。短台词通常设置 0—1 个触发点；长台词按语义转折设置少量触发点，每个必须改变声音、观看对象、策略、动作或关系结果，不能逐词绑动作。

多人轮流说话按 `A说前/台词 -> B反应 -> B说前/台词 -> A或旁观者反应` 写成一条时间线，不把动作与台词分成无关列表。说前/说中/说后三阶段通常只有一处最鲜明动作读点；需要走近、转身、落座或多步操作时放在台词前后，台词中只保留口型可承载的低幅变化。

声音透视必须说明声源距离、方向、遮挡和空间材质；人物远离时声音变远、变窄或被空间吸收。台词出现时非关键环境、情绪音效和音乐降低存在感，避开字头、关键词、停顿和尾音；声音桥写前镜进入点、跨越切点及下一镜被新空间声接替的时刻，不无因重启。

OS逐字保留且无口型；OV逐字保留，人物不得听见或回应；声音先行/同步/延后/反差并置必须说明与画面关系，不得靠旁白补写原文没有的事实。

#### 7.6.1 直投动作时间线编译

导演源中已经冻结的动作、表演、摄影、声音、环境和物理状态不得在直投编译时压成无先后的描述段。除单一静止状态且没有台词触发、微动作、道具/光区变化或镜内剪辑的低风险镜头外，每镜使用连续时间窗逐行输出：

`0.0—X.X秒｜阶段名：具名主体与当前主驱动力；触发/进入基线；动作、表演或物理过程；摄影/焦点/插切；声音/台词触发；环境/道具/光影/材质响应；阶段终态/保持。`

- 第一行从 `0.0秒` 起，最后一行到本镜总时长；相邻时间窗首尾相接，不留未解释空档或重叠。时间码用于锁定顺序与可承载时长，不宣称逐帧控制。
- 每行只写实际发生项，不存在的类别删除；但具名主体/主驱动力、触发或继承基线、实际动作/保持和阶段终态不能省略。不同人物或高复杂度机制并行时，在同一时间窗内写明各自主体与共享触发，不拆成无关列表。
- 动作按真实因果展开：`进入基线 -> 刺激 -> 反应延迟/准备 -> 启动/路径 -> 接触/受力 -> 结果/余波 -> 保持`。没有接触或受力的镜头删除对应阶段，不为了填格式虚构动作。
- 台词时间窗只引用必要关键词作为触发，完整台词仍只在“台词与声音层次”出现一次；说前、说中、说后、受话者延迟、口型和声音桥必须落在对应时间窗。
- 简单静止镜可以合并为一行 `0.0—镜尾｜稳定保持`，但仍写清具名主体、持续压力/声音/观看收益和镜尾接点，不能用“保持不动”掩盖状态变化。

逐场维护人物、实体与道具连续性账本，所有变化在镜内发生并由落幅结算。画外只描述具名人物的台词、脚步、动作声或环境影响，不执行可见视线、表情或微动作。

蓝图冻结后，一次连续编译导演审核版和 Seedance 独立直投版。直投阶段不二次拆镜、不替换摄影候选、不重写表演和光影；动作时间线按 7.6.1 的连续时间窗原样保留其顺序、触发、物理阶段和终态，不得缩写成动作清单或无时间标记的散文。格式或硬连续错误只修报错镜头/章节，不回到全剧重新导演。

## 创意感染力源头自检（非评分）

这不是交付后的创意审稿，也不是关键词、镜长或景别统计。它只在导演源冻结前做一次定性检查：每项写“成立”或“需补强及补强位置”，需要补强时回到对应源表行完成导演设计，再继续冻结；不输出分数，不建立自动创意返工闭环。

### 每场自检

- **停留**：开场是否在最短合理时间内交付一个可感知的异常、目标、危险、关系压力、未完成动作或信息缺口？是否明确观众主问题？
- **升级**：相邻有效节拍是否真正改变信息、策略、权力、危险、距离、空间、道具、时间、公开程度或情绪外显中的至少一项？
- **翻转**：旧策略是否被具体证据击穿？人物是否重新解释局面、采用新策略，并让对方、环境、道具或关系出现新现实状态？
- **释放**：决定性动作或信息命中后，观众是否能看清身体、空间、道具、声音或关系结果？是否保留了必要余波而不是立即清零？
- **尾钩**：尾钩是否由已兑现的结果、未完成动作、道具归属、关系新状态、声音先行或新代价推出？是否避免凭空新增事实？
- **公平与代价**：主要反转是否有可回看的公平线索、清楚的误判与重解释？人物是否做出有替代路径的选择，并留下不可逆代价、见证者和新债？
- **波形与母题**：本场是否有实际成立的加速、停顿、命中、结果与余波？视觉/声音母题是否推进到建立、升级、反转或回收，而不是原样重复？

### 关键转折自检

- 情绪是否经过“刺激 -> 旧策略 -> 控制/泄漏 -> 非面部行动 -> 关系结果”，而不是只换表情词？
- 摄影是否形成一条不可替代的视觉句：具名主体、明确起幅、一个主视觉动词、清楚终幅和相邻反差？
- 首读、次读和结果确认是否依次成立？反应是否从主承受者传播到受话者、关键见证者和空间/群体回声，而不是同步抢读？
- 口型、说前/说中/说后、受话者延迟、声音桥和环境声是否形成同一观看目标，并在关键词与结果处让位/接管清楚？
- 插切、轴线、遮挡、焦点和视觉因果是否让观众更早或更准确地读到原因、传播、接触、状态改变或余波？
- 光影、滤镜/后期影像、材质、特效和空间压力是否放大已经成立的剧情因果，而没有替代因果、随机换质感或制造无源事件？
- 手机端是否只有一个首读点，关键脸、手、道具和接触是否在运动前后都可读？
- 高负载镜是否冻结不可删核心、可压缩支撑、可删除装饰和具体降级顺序，并保证降级后视觉句、因果和结果不变？

### 通过标准

自检通过不是“所有镜头都更强”，而是每场的停留、升级、翻转、释放和尾钩都有实际承载，关键转折的表演、声音、摄影和物理结果互相增强，稳定段也有明确等待、压制、确认或余波职责。若某一项不成立，先修改导演源，不在直投正文里补形容词或随机特写。

## 首次生成必成条件

下列条件与导演源表同轮生成，不在蓝图之后逐项扫描、评分或返工；生成某一行时直接调用对应规则并产出成立的镜头设计：

- 开场承诺、目标/代价、策略升级、主要反转、结果兑现和尾钩均有原文依据。
- 主要反转有观众旧预期、公平线索、误判窗口、重解释、人物选择、不可逆代价、见证者、兑现画面和新债；没有靠新增秘密制造惊讶。
- 主要反转修改两个状态轴，台词语气、非面部行动、受话者反应和新现实状态完整。
- 微动作可见、有刺激、符合人设并推动下一行动，不是通用小动作堆积。
- 主要反转已比较三套非同构摄影候选；选中指纹与相邻爆点不同构，且不是中景/缓推默认解。
- 压迫感有现实压力源和可见载体；情绪按刺激、破裂、错峰反应、空间回声和结果传递。
- 重动作、斗法、递接和破坏已通过意图、支撑、启动、路径、接触、惯性和终点七个物理节点；环境反馈有来源、方向和停止状态。
- 场景关系地图、摄影机轴线、人物槽位、道具控制者、光源方向和镜尾/镜首接点逐镜可复核，没有用切镜制造瞬移。
- 每镜有剧情职责和节奏职责；重要因果、认知误导、插切三态、峰值结果和声音落点均有唯一读取价值。
- 对白前中后动作、受话者延迟、OS/OV口型和声音主次、进入/退出/跨切关系已写入同一执行链。
- 景别承载的信息在该距离可见；运镜有起点、触发、路径、停止和稳定终幅。
- 关键镜头有可复述视觉句、首读/次读/结果确认路径和母题阶段；每场节奏波形、声音母题与相邻场反差已冻结。
- 光影由剧情与物理触发；滤镜/后期影像有稳定基线，变化有剧情或光学触发并保护人脸/资产；两者强化而不代替反转，蓝图只冻结一次，双文件不重复导演。
- 每场事实/知情预演表已为所有镜头提供入场、出场、信息释放、策略阶梯和结果锚；每个时间窗主驱动力清楚，交接有触发，耦合响应共享触发/目标/方向/阶段终态；关系覆盖和插切容量在源头决定。
- 内在强度与外显幅度分离；关键表演经过性格/目标/危险/关系策略准入，表演链从前镜基线持续到关系结果和镜尾残留。

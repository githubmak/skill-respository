# 青岚古林：重构示例

这是美术方向与提示词示例，尚未在MJ验证。场景目标为东方仙侠世界的万年妖兽森林，允许晨光与生机，不强制恐怖、阴暗或邪恶。

硬锁：清晨，无人物和动物出镜；入口林径通向中央可活动台地，再沿右侧缓坡深入；主巨树在左后；右后根桥跨石隙连接较高林坡，不遮主路。没有来源依据，不新增爪痕、兽骨、巢穴、建筑或发光法阵。

偏差：原稿的疏朗冠盖、清旷空地、精致金绿晨光容易共同指向游赏仙林。增强年代与巨大生灵栖居的环境尺度，同时保留路线和清晨。

采用方向：巨木构成覆盖林下空间的连续高大结构，树根、岩台与林冠具有不同世代的生长层次；普通乔木成为相对尺度参照。中央台地仍能活动，但被体量庞大的根壁与高冠包围，右侧出口可通行，深处视线被交错巨干与地势遮断。东方形态来自不对称虬曲树势、根石嵌合和远山虚实，不依赖建筑、青橙调色或漂浮山。

# 场景母版锁定与内部机位底板

当用户提供场景参考图，或要求某个摄影机位严格保持原场景时，读取并执行本规范。

## 目标

为最终含人物多关键帧准备以下内容：

1. `@Image1 场景母版锁定描述词`：告诉生图/视频模型什么是唯一场景母版、哪些固定内容不可改变、哪些内容允许新增、画外未知区域如何延续。
2. `指定机位场景空镜板生图提示词`：把分镜和内部空间推理得到的摄影机位置翻译成可直接执行的提示词。
3. `内部机位底板PNG`：使用上述提示词和原场景参考图生成、视觉检查的同一地点新视角纯场景摄影图。它用于后续人物与道具合成，默认不作为最终交付物。

不要把内部空镜板误当成最终成片关键帧。文字机位约束或用户明确要求的调度图负责定义空间和路线；内部空镜板定义固定背景、透视、构图、材质和摄影机视角；最终起幅、中间关键帧和落幅必须继续合成分镜中的人物、动物和道具，并通过形体检查。

## 先建立场景三层清单

### 永久锁定层

只写参考图可直接确认的内容：

- 主体建筑数量、相对位置和尺度；
- 屋顶形式、轮廓、坡度、檐口和瓦色；
- 门窗数量、位置和比例；
- 台阶、平台、院墙、石墙基、围栏和入口；
- 道路走向、地面材料、树木和固定植被；
- 固定家具/道具；
- 主色、核心材质、光线方向和阴影状态。

任何看不见的建筑背面、院落纵深或画外结构都不得伪装成已确认事实，应进入“画外未知层”。

### 本镜允许新增层

从分镜中提取并写明精确数量、位置和归属：人物、动物、车辆、临时道具、施工材料、特效或天气变化。若原文使用“几名/一些”等模糊数量，可选择满足画面可读性的最小明确数量，并标注“合理推断”；不得擅自增加新的类别。场景母版锁定词可列出这些视频阶段新增项，但场景空镜板必须进一步区分：

- `空镜允许的静态场景陈设`：必须跨镜连续的落地材料、木梁、桌椅、施工基础等；只有分镜明确需要时才生成。
- `Seedance 人物/动态层`：人物、动物、手持物、正在移动的道具、动作特效；不得出现在场景空镜板中。

### 画外未知层

新机位看到参考图之外的区域时：

- 只延续已确认的墙体厚度、高度、材质、瓦片尺度、石基高度、地面纹理、道路宽度、植被品种和光向；
- 不新增新的建筑类别、门窗、棚架、车辆、人物、动物或装饰；
- 没有剧情要求的空白区域保持空白；
- 若未知区域决定关键剧情或建筑拓扑，明确提示需要先制作并审核该视角静帧，不能承诺单张二维参考可完全还原三维场景。

## @Image1 场景母版锁定描述词模板

根据实际参考图改写方括号内容并删除所有占位符：

```text
@Image1是[场景名]唯一场景母版，严格定义并锁定：[主体建筑及其位置]、[屋顶轮廓与材料]、[门窗数量和位置]、[台阶/平台]、[左右附属建筑]、[院墙/石墙基/围栏]、[入口的宽度、形状和开启状态]、[道路走向]、[树木与固定植被]、[固定道具]、[建筑比例]、[光线方向]及全部可见固定背景。

这些固定内容在本镜中不得增加、删除、替换、移动、翻转、变形或改变数量。不得把[关键入口]改成另一种门洞，不得把[主体建筑]替换成空墙、棚架、工棚或其他建筑。@Image1原本空置的地面和空白区域继续保持空置。

视频阶段只允许新增：[逐项列出人物、临时道具、材料或特效的精确数量、区域和状态]。场景空镜板只允许保留其中的静态场景陈设：[逐项列出，若无则写“无”]；所有人物、动物、人体局部、人物剪影、手持物和动态特效都不出现在空镜板中。除这些明确项目外，不出现其他人物、动物、车辆、家具、棚架、房屋、门窗或装饰物。

新机位看到的画外区域只延续@Image1已经确认的[墙体/屋面/石基/地面/道路/植被]材质、尺度、结构规律、年代感和光向；不得创造新的建筑类别或改变场景身份。只改变摄影机观察位置与本镜允许新增层，场景永久锁定层保持不变。
```

输出时应尽量采用参考图中的具体名词和可数信息，不要只写“严格参考原图”。

## 指定机位场景空镜板提示词结构

每个关键机位单独输出一条提示词，禁止把多个互相冲突的机位写进同一张静帧。

```text
图像职责：
生成一张“纯场景摄影机位板 / clean scene plate”，不是人物首帧。@Image1是[场景名]唯一且不可改动的场景母版。严格继承[关键固定结构清单]。只改变摄影机观察位置和明确允许的静态场景陈设，不改变场景身份、建筑布局、数量、比例、材质、年代和光向。画面中不出现人物、动物、人体局部或人物剪影；人物由Seedance后续生成。

世界坐标：
以[主体建筑/稳定地标]为[北/其他方向]、[入口/道路]为[南/其他方向]，建立固定方向。所有机位方位都用这套世界坐标，不使用含糊的“画面左/右”代替。

摄影机位置：
摄影机位于[稳定地标]的[方位]，距离[入口/虚拟主体点]约[距离]，机位高度约[高度]，镜头朝向[稳定地标或世界方向]，位于虚拟人物运动轴线的[同一侧]，不越轴。虚拟人物点和运动轴线只用于计算机位，不得画出。

摄影参数与构图：
[焦段]，[预期景别]，[水平/微俯/微仰]；为后续人物在[构图区域]预留无遮挡负空间，但空镜板中不画人物；前景是[固定遮挡物]，中景是[空置行动区/静态场景陈设]，背景是[固定建筑]；[门框/树枝/柱子等]只遮挡[范围]，不能遮住关键场景锚点。摄影机不继承@Image1原始机位，只继承同一场景结构与材质。

虚拟人物占位（不可画出）：
[逐个写明后续人物预计出现的世界坐标、运动方向、相互距离以及需要预留的画面空间]。这些信息只决定构图和焦点平面，画面中不得出现人物、影子、衣角、手、脚、头发或剪影。

静态场景陈设：
[列出允许在空镜板中出现的落地且必须跨镜连续的静态道具、数量和位置；若无则明确写“除@Image1既有固定物外不新增任何物体”]。

画外延续：
参考图未显示的区域只延续@Image1既有的[材质与结构规律]；原本空白区域保持空白，不新增[容易被模型误加的内容]。

光影和材质：
保持@Image1的[光线方向、时间、综合色调]；[两项核心材质]保持一致；所有允许的静态陈设产生符合原光向的落地接触阴影。

禁止：
[场景结构负面词]；人物、动物、人体局部、人物剪影、人物影子；现代物品或额外内容；错误机位、错误焦段效果、越轴、镜像或穿模。
```

## 内部空镜图生成与验收

1. 使用内置生图能力，以原场景图为唯一参考图；每个焦段/机位单独生成，不在一次生成中混合多个焦段。
2. 本地参考图若尚未在当前对话中打开，先打开检查，再执行基于参考图的新机位生成。
3. 生成后检查：固定建筑数量、屋顶轮廓、门窗数量、入口宽度和开启状态、台阶/围墙/道路/树木位置、主要比例、光向、机位方向、焦段观感以及是否完全无人。
4. 发现一个明确问题时，只针对该问题修正提示词并再生成一次。仍有关键结构漂移时将图标为“待确认草稿”，不得称为准确空镜。
5. 不覆盖原场景图。内部空镜可保留在工作目录或生图默认目录，默认不复制到用户输出目录。
6. 只有用户明确要求纯场景空镜时，才将其另行保存并展示；默认最终答复只展示已合成人物和道具的起幅、中间关键帧和落幅 PNG。

若内置生图能力不可用，保留完整提示词并明确说明缺少图像交付；未经用户明确选择，不切换到需要API Key的CLI模式。

## 机位描述必须可落地

至少包含：

- 世界坐标参照：例如“以正房为北、院门为南”；
- 摄影机位于哪个固定地标的哪个方向；
- 摄影机高度；
- 与入口或虚拟人物点的近似距离；
- 拍摄朝向和轴线侧；
- 焦段、景别与透视效果；
- 画面前景、中景、背景以及人物预留负空间；
- 门框、肩部、柱子等遮挡范围；
- 新视角画外区域的延续规则。

不要只写“从侧后方拍摄”“换一个角度”“参考原场景”。

## 多关键帧机位决策

- 摄影机起幅与场景参考图原视角不同：必须先建立起幅内部场景板提示词。例如“50mm侧后跟拍”不能只写侧后方，必须换算成相对院门、道路或建筑的具体方位、距离、高度、朝向和轴线侧。
- 最终大全景必须精确恢复原场景：先建立落幅内部场景板，并将其作为人物合成的场景/构图底板；不得把无人底板直接作为最终落幅。
- 同一连续镜头出现多个关键机位：为起幅、需要交付的中间关键帧和落幅分别建立文字机位约束；场景拓扑复杂或机位变化明显时，为每个独立机位建立内部场景板。不要把50mm、35mm、24mm写进同一张静图提示词。
- 若平台中精确首尾帧模式与普通多参考模式互斥：纯场景空镜板优先用于普通场景参考模式。若严格首尾帧中必须出现人物，先把人物合成进空镜板再作为端点；否则空镜端点可能迫使人物消失或突然出现。

## 50mm侧后跟拍空镜的机位换算

当分镜要求从路人或角色侧后方跟拍、但空镜板不允许出现人物时：

1. 先在平面图上定义一条不可见的虚拟行走线，并标出角色起始虚拟点。
2. 摄影机通常放在虚拟点后方约 `1.2–2.0m`、横向偏移约 `0.5–0.9m`，机位高度约 `1.35–1.60m`；具体值依景别和场地缩放调整。
3. 50mm镜头朝向虚拟行走线前方，同时让门、窗、正房或其他身份锚点落入中后景；保持在运动轴线同一侧，不环绕、不越轴。
4. 在生图提示词中写“为后续人物侧后方轮廓预留前景空间，但画面保持无人”，不能要求模型画背影占位人。
5. 若终幅是24mm原场景大全景，为24mm落幅另写独立空镜提示词；不得要求一张图同时表现50mm起幅和24mm落幅。

## 防止自动补充的固定句式

按任务需要选用并具体化：

```text
@Image1原本空置的区域继续保持空置。
除明确允许新增层外，不添加任何新类别的可见物体。
画外声音不生成可见声源。
临时作业只占指定区域，不改造整个场景。
所有新增物体必须落地承重，并产生与@Image1光向一致的接触阴影。
参考图未显示的区域只做同材质、同尺度、同结构规律的最小延续。
```

## 输出自检

- `@Image1`是否被明确指定为唯一场景母版？
- 是否列出了可数的固定建筑、门窗、入口、道路和树木？
- 是否把永久锁定层、空镜静态陈设层和Seedance人物/动态层分开？
- 是否明确原本空白区域保持空白？
- 是否把画外未知内容标为延续规则而不是既有事实？
- 机位是否包含世界方位、高度、距离、方向、焦段、景别、三层构图和人物预留区？
- 是否说明只改变机位，不改变场景身份和固定结构？
- 是否明确空镜中无人物、动物、人体局部、人物剪影和人物影子？
- 是否明确内部空镜不能直接替代含人物与道具的最终起幅/中间关键帧/落幅？
- 是否已为每条关键机位提示词实际生成并检查内部场景板？
- 是否已继续完成人物与道具合成，并按主技能要求检查形体和结构？
- 提示词是否已替换所有占位符，可直接复制使用？

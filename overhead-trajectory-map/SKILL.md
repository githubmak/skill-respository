# 场景关键帧与轨迹调度

默认目标是生成可直接用于视频画面约束的起幅、中间关键帧和落幅成片 PNG。不要改变剧情动作，不要把参考图未显示的画外结构写成已确认事实。

## 模式选择

### 默认：含人物与道具的关键帧模式

只要用户提供 `场景参考图 + 分镜/动作提示词`，默认执行此模式。

默认不绘制、不生成、不交付俯视图、正视图、双视图、模型参考调度图或导演调度图，也不生成或交付 SVG 源文件。

默认交付包括：

1. 起幅 PNG：必须包含分镜在起幅中可见的人物、动物、道具和静态陈设；
2. 中间关键帧 PNG：默认至少一张，必须覆盖镜头内部的重要动作转折、机位/焦段变化、遮挡揭示、视线变化或人物/道具状态变化；
3. 落幅 PNG：必须包含分镜在落幅中可见的人物、动物、道具和静态陈设；
4. 与全部关键帧对应的场景锁定词、实际生图提示词及精简负面约束；
5. 简短的连续性与形体质检结论。

除非用户明确要求只生成首尾帧，否则不得省略中间关键帧。若分镜已有时间段或动作节点，按这些节点选取中间关键帧；若没有明确节点，在不重复起幅和落幅的前提下选择最能说明动作因果的中段时点。通常输出 1–3 张中间关键帧，只有多个独立叙事转折确有需要时才增加。

场景空间、人物路线、遮挡、运动轴线和摄影机位置仍需在内部完成推理，但默认不另行绘制调度图，也不额外输出空间锚点表或人物调度表，除非用户明确要求。

### 显式：调度图模式

只有用户明确要求以下任一内容时才进入：`俯视轨迹图`、`正视轨迹图`、`双视图调度图`、`调度图 PNG`、`人物运动路线图`、`摄影机轨迹图`。

- 默认只交付一张合并式调度 PNG；若用户明确要求“模型参考版＋导演查看版”，再输出两个 PNG 版本。
- 不生成或交付 SVG 源文件。
- 可用 Canvas、HTML 或临时矢量层进行确定性渲染，但最终只交付 PNG。
- 进入此模式时读取 [references/visual-spec.md](references/visual-spec.md)。

## 关键帧职责与选点

- 起幅、中间关键帧和落幅都必须是含人物与物件的实际成片关键帧，不是纯场景空镜。
- 分镜写明可见的人物、动物、车辆、轮椅、工具、手持物、施工材料和其他关键道具，都必须按该时点的状态进入画面。
- 用户提供人物或道具参考图时，必须锁定身份、年龄、脸型、发型、服装、体型、材质、颜色和结构；不得用相似但不同的替代品。
- 全部关键帧必须保持同一角色、服装、道具设计、建筑拓扑、光向和任务区域连续。
- 可先生成或使用无人场景板锁定新机位，但它只是内部中间层，默认不作为最终交付物。

中间关键帧优先放在以下时点：

1. 动作从准备进入执行，或执行结果首次清楚可见；
2. 人物改变方向、停步、回头、起身、坐下、交接物件或形成新互动关系；
3. 门框、人物肩部、柱子等遮挡完成揭示，画面信息量发生变化；
4. 摄影机改变焦段、景别、方向或由运动转为停机；
5. 新人物/动物/道具进入或离开可见区域，或关键物件状态发生变化。

每张中间关键帧都要标注时间点或对应动作节点。不得为了凑数量输出与相邻帧几乎相同的画面，也不得把两个相互冲突的机位或动作阶段揉进一张图。

## 默认工作流

1. 打开并检查场景、人物、动物和道具参考图，明确每张图的角色。
2. 内部提取固定场景、各关键帧动作、人物位置、视线、遮挡、运动轴线、机位、焦段和前中后景。
3. 将场景分为 `永久锁定层`、`本镜允许新增层`、`画外未知层`；必要时先生成并验收内部纯场景机位板。
4. 根据时间线先建立 `起幅—中间关键帧—落幅` 清单，为每帧标注时间点、动作状态、可见人物/动物/道具、机位与焦段；每个独立机位分别制作，不混合摄影参数。
5. 按清单逐帧制作。人物、动物和道具较多或参考图超过工具单次上限时，分层合成：先加入主角和主要动作，再加入次要人物、动物与道具；每一层都要求上一层和场景完全不变。
6. 使用人物/道具参考图进行身份保真合成，匹配场景透视、景别、尺度、光向、遮挡与接触阴影。
7. 打开每张最终 PNG 原尺寸检查场景结构、人物身份、服装、动作、脸、手、四肢、坐姿、轮椅/工具结构、动物肢体、物体承重、接地和逐帧连续性。
8. 发现清晰可见的形体或物件变形时必须定向修复；单帧最多进行两次针对性修正。仍不合格时不得标为最终帧，应调整构图、缩小远景主体、增加自然景深/运动模糊或合理遮挡；若仍无法避免，明确报告需要更清晰资产或人工合成。
9. 将通过检查的起幅、中间关键帧和落幅 PNG 保存到用户输出目录，并返回最少必要说明。

场景锁定与内部机位底板规则见 [references/scene-lock-and-keyframes.md](references/scene-lock-and-keyframes.md)。人物、道具合成和形体质检规则见 [references/keyframe-compositing.md](references/keyframe-compositing.md)。

## 不变形质量标准

### 清晰人物

- 五官位置、脸型和身份与参考图一致；双眼、鼻、口、耳不得错位、重复或融合。
- 手掌、手指、手臂、腿和脚的数量、关节与受力合理；不得出现多肢、断肢、粘连或穿模。
- 坐姿、轮椅、骑乘、持物和多人交互必须符合人体与重力关系。
- 不得用“景深”掩盖本应清晰的主角面部或关键动作。

### 远景人物

- 允许符合焦段和距离的自然景深模糊、轻微运动模糊、背身、侧身或合理遮挡。
- 远景可以低细节，但轮廓、头身比例、肢体数量和动作方向必须正确。
- 不允许交付清晰可辨的扭曲脸、融合手脚、多余肢体或断裂身体；应修复，或通过符合镜头逻辑的模糊/遮挡降低其可辨识度。

### 动物与物件

- 动物的头、躯干、腿、爪、耳和尾巴数量与连接正确，必须落地并有接触阴影。
- 轮椅、车辆、工具、家具、武器和施工材料必须结构完整、透视一致、正确承重；轮、轴、把手、脚踏、刃口、握持点不得融合或漂浮。
- 手持物必须与手掌形成正确抓握，不能穿手、粘腕或漂浮。

## 场景与机位规则

- 参考图中可数的建筑、门窗、入口、道路、树木和固定道具不得增加、删除、移动、镜像或替换。
- 原本空白区域继续保持空白；只加入分镜和用户参考明确要求的内容。
- 画外未知区域只能按已见材质、尺度、结构规律与光向做最小延续。
- 机位提示词应包含世界坐标、相对固定地标的位置、机位高度、距离、朝向、轴线侧、焦段、景别、前中后景和固定遮挡物。
- 同一连续镜头的起幅、落幅使用各自焦段和机位，不把互相冲突的摄影参数写进同一张静帧。

## 默认输出格式

```markdown
## 关键帧｜镜号/场景名

### 起幅
- PNG：{已生成、检查并保存的含人物与物件关键帧}
- 实际使用提示词：{完整提示词}

### 中间关键帧 01｜{时间点/动作节点}
- PNG：{已生成、检查并保存的含人物与物件关键帧}
- 实际使用提示词：{完整提示词}

{按实际需要继续列出中间关键帧 02、03……}

### 落幅
- PNG：{已生成、检查并保存的含人物与物件关键帧}
- 实际使用提示词：{完整提示词}

### 场景锁定与负面约束
{精简文本}

### 验收
{身份、形体、物件结构、接地、光向和连续性结论}
```

推荐文件名：

- `{镜号}_{场景名}_起幅.png`
- `{镜号}_{场景名}_关键帧01_{时间点或动作节点}.png`
- `{镜号}_{场景名}_关键帧02_{时间点或动作节点}.png`
- `{镜号}_{场景名}_落幅.png`

最终答复按时间顺序展示全部已验收关键帧并提供文件链接；不附加调度图、SVG、内部空镜、额外表格或重复说明，除非用户明确要求。

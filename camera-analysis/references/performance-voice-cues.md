# 角色情绪表演与台词配音执行参考

供单镜与连续分镜按需读取。先以剧情事实、角色既有声音和已锁定画面为准；词汇只是可选手段，不是角色原型模板或部位配额。

## 表演设计

1. 记录前态、本镜可证实的刺激、角色如何理解刺激、当下想得到或保住什么、受话者是谁，以及公开/私密、被监视、时间压力、伤势和持物等限制。
2. 设计第一冲动和人物特有的控制方式。将“触发→情绪→外在控制或释放→一个可见泄漏→镜尾新状态”落在时间线上。若角色说一套、心里另一套，明确外在表层如何维持、底层从哪里泄漏。
3. 四维检查：眼神看向何处且是否聚焦；嘴角与唇线是上扬、平直、下压还是单侧牵动；呼吸是平稳、屏住、短促还是受阻；眉心、下颌或咬肌是放松还是收紧。四维不必全部写入成稿，只保留景别、遮挡、时长支持的变化。手指、肩、重心、动作精度、接触许可和与他人的距离可以比面部更能说明人物。
4. 微表情应有顺序与因果，如“听到指控→视线停在对方手中的证据→下颌收住→手指松开杯沿→回答时维持平稳语气”。不可凭空安排泪痕、面红、青筋、伤势变化或没有剧情依据的心理背景。
5. 多人镜逐人核对知情、注意对象和职责，按刺激到达的时刻错峰。跨镜保留角色习惯与情绪残留；突变须有新刺激，安静或反高潮不强制升级。

### 按观看条件选择细节

| 观看条件 | 优先让观众看到 |
|---|---|
| 面部近景/特写 | 眼睑与视线、唇线、下颌、呼吸中的一项主变化；口型与说话同步 |
| 中近景/中景 | 视线、手、肩、持物、重心与受话者距离；面部细节只写真正可读者 |
| 全景/远景或面部被挡 | 停步、转身、退让、接触、任务动作的速度/精度和空间关系；不写不可见眉眼 |
| OS/OV 或非实体角色 | 声音目的和听者/环境反馈；不强配说话口型或实体微表情 |

可选表达词：视线停住/躲开/重新锁定；唇线抿平/单侧轻提/欲言又止；呼吸短暂屏住/缓慢吐出；下颌收紧/松开；手指压住杯沿/松开衣料；肩膀先缩后稳住。使用时必须绑定本镜原因、方向、可见性和结果，不能直接整套复制。

## 配音设计

1. 确定台词类型（对白、画外对白、OS、OV、旁白）、说话者、受话者、话语行动和角色既有声线。只设计本段语气、语速、气息、咬字、重音、语调转折和句尾，不凭角色身份创造音色或声纹。
2. 按语义、换气、人物控制和期待回应分组。逗号、句号、问号、感叹号、省略号、破折号都只提供意图，不自动给秒数；问句也可以尾音下沉，怒意也可以轻声。`/` 可标微换气，`//` 可标长留白，只在听感和人物行动确实需要时用。
3. 关键话语行动可采用“前段控制→关键词或重音命中→受话者承受→句尾收束”。宣判、揭露、威胁、决裂、告白、命令是否在关键词前停顿，取决于权力策略与镜头节拍。暂停可标短/中/长；需要精确同步时才估合理秒数并纳入总时长。
4. 长句仅在语义转折、换气或听感匀速风险处切分；短句仅在紧急、打断、命令或喜剧节拍有依据时采用。原文字词、归属与顺序冻结；调整标点须不改语义并保留原句。若项目要求逐字逐标点保留，将停连写在演绎说明，不改台词原文。
5. 声音停顿对应可见的眼、手、呼吸、受话反应或有职责的静止；台词与动作能并行就并行，确有物理或注意力冲突才串行。说话者可见时配口型；画外对白、OS、OV 不让画内非说话者对口型。

### 声音标注与交付

- 标注优先写可执行变化，如“前半句维持礼貌、‘你知道’压低并加重，句尾收住，等对方抬眼再继续”。只在有用时给【语速偏慢／气息收住】等简短标签，不堆四项标签。
- 单独要求配音分析时，交付原句、可直接复制的配音用台词或演绎标注、语义组、重音、停顿位置与理由、必要的时长估计、口型/声音来源。若未改标点，明确写“沿用原句”。
- 单独要求情绪分析时，交付触发与目的、心理流、表层/底层、景别可见的表演支点、四维联动取舍、声画对应和镜尾状态。缺前情时标明推断或未知，不虚构故事。
- 完整分镜或精修稿按原有时间线、画面/表演、台词/声音和落幅字段落地，不增设重复的分析报告栏目。重要台词应能同时找到声音落点和可见反应；无台词镜头不得编造配音。

## 复核

检查情绪转折有触发、表演与物理状态相容、细节在镜头中可见；语义/标点/停顿一致，角色之间的声音策略有差异；台词不漏不重、OS/OV 不错配口型；停顿和动作合计时长可执行。抽象词、角色原型标签、固定停顿秒数、强制标点或生理反应不可替代这些证据。

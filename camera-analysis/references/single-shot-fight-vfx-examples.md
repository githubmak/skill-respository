# 单镜打斗与术法示例库

> 本文件只在技能检测到相应打斗、术法、粒子、VFX或机甲活动时按需读取。示例用于迁移机制，不覆盖用户输入、冻结剧情或主技能合同。

### 打斗与术法示例库（单镜参考，不固定套用）

以下示例用于检查“本镜里必须看见什么”，不是固定模板。先服从用户术法视觉输入、全局影调和前后镜状态；只选择能在本镜时长、景别和机位内成立的证据，不替整场新增攻防轮次。

- **火焰/热能**：本镜至少交代一个源点和一个方向；成形、喷出、接触三者要能看出先后。命中石、木、布或金属时分别留下裂纹/粉尘、焦痕/卷曲、燃烧边缘或热变色，落幅保留烟、余烬或热浪。
- **冰霜/寒气**：让霜线从源点向目标传播，再给局部冻结、裂纹或冰屑；避免只有白色闪光而没有冻结表面和受力结果。
- **雷/电**：明确施术者、法器或目标之间的导电路径；电弧沿路径分叉、接触并短暂残留，不能从画外随机落雷，也不能用满屏闪白代替命中。
- **水/雾/流体**：粒子必须有流向和停下的理由；冲击留下波纹、凹陷、喷柱或蒸汽，遇热升雾、遇寒结冰、遇电传导，不能无因消失或逆受力飞溅。
- **符箓/法阵/墨迹**：本镜交代阵眼、符纸或刻痕中的至少一个源点；线条先成形再闭合或扩散，接触后留下断线、焦黑、残墨或失效边界，不使用无来源的通用光环。
- **剑气/能量刃**：从剑锋、刀锋或手臂读出方向；本镜至少呈现挥击路径、接触点和一个结果证据，例如切痕、火花、碎屑、护盾凹陷或残弧。
- **护盾/领域**：先看见边界和受力面，接触时出现局部凹陷、裂纹、能量流或亮度衰减；被挡后保留裂痕、碎片、余电或逐渐熄灭的残留，不让整面护盾同时无差别闪光。
- **身法/冲击波**：先锁脚下支撑、重心和移动方向，再让尘土、衣摆、碎石或水面沿同一受力方向响应；镜头抖动只能辅助，不能替代身体路径和结果。

动作词的单镜落地示例： “骤然结印”应在同一可见窗口完成抬手和关键手势；“凭空炸燃”应让源点与点燃同时发生；“笔直浇落”应让竖直路径快速进入并命中；“齐齐扑来”应先建立群体方向再进入接触；“猛然僵住/彻底沉寂”应在接触后短促锁死并留下安静余波。不得把这些词改成无因蓄力、横向旋转、随机爆炸或重复慢动作。

单镜材质证据可按需选择：石/混凝土用崩角、裂纹、粉尘；木/竹用弯曲、劈裂、纤维或余火；金属用火花、凹陷、振动、热变色；冰/雪用放射裂纹、冰屑、融化水汽；布料/发丝沿气流、热量或电流改变方向；玻璃/晶体用裂纹传播、折射和有重力的碎片；土壤/沙尘用凹坑、喷散和风切痕。只保留服务本镜主读点的粒子层。

景别承载示例：大远景读战场尺度、人物相对位置和术法占画范围；全景读完整起势、脚步和路径；中景读攻防关系、闪避与接触；近景读手势、表情、武器接触和局部材质反馈。若当前镜头景别无法同时证明路径和命中，优先在本镜保留主动作与结果，并标记前后镜需要承接的方向或残留，不私自改写景别和运镜。

单镜落地示例：镜头 S2-03 为 40mm 侧前方中近景，玄火束从画面左后方的符阵射向右前方的玄冰护盾。0.0—0.8 秒先看到玄火源点和符线闭合；0.8—1.6 秒火束沿明确方向进入画面，摄影机只做短促跟移；1.6—2.4 秒火束撞上护盾，护盾受力面凹陷，冰面局部融化并升起一层蒸汽；2.4—3.2 秒护盾把火束向右侧石柱偏转，石柱出现焦黑切痕和少量碎石；3.2—4.0 秒固定停住，保留裂纹、蒸汽、烟尘和低亮余烬。镜头不绕圈、不用满屏闪白，也不在本镜新增第二轮攻击。

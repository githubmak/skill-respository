# 审核报告模板

严格按以下顺序输出。没有对应内容时写“无”，不要省略结论和人工核验项。

```markdown
# 《<剧本名>》即梦剧本审核报告

## 一、制作结论

- 结论：通过 / 修改后复审 / 不建议制作
- 最高风险：A / B / C / 无
- 统计：A <n> 项，B <n> 项，C <n> 项，M <n> 项
- 一句话判断：<指出决定结论的核心原因>

> 本报告依据用户提供的即梦社区规则和短剧专项要求进行制作前预检，不代表平台最终审核结果，也不构成法律意见。

## 二、审核范围

- 已审内容：<标题、梗概、人物、场次、对白、动作、声音、字幕等>
- 未提供内容：<如配乐、成片画面、授权证明、人物年龄>
- 关键假设：<仅列会影响结论的假设>

## 三、不符合与高风险项

| ID | 等级 | 位置 | 原文短引 | 命中要求 | 风险说明 |
|---|---|---|---|---|---|
| R-01 | A | <场次/行号> | “<最短必要引用>” | <规则类别> | <结合上下文说明为何命中> |

### R-01 对照修改

**原文**

> <原文片段>

**首选改写**

> <可直接替换的文本；同时处理对白、动作、音效和镜头语义>

**保留张力的备选方案**

1. <方案一：冲突机制、画面处理、后续影响>
2. <方案二：仅在确有不同可行路线时提供>

**联动修改**：<需要同步调整的伏笔、身份、道具、后续场次；无则写“无”>

## 四、文字与质量优化

| ID | 位置 | 原文 | 建议 | 原因 |
|---|---|---|---|---|
| Q-01 | <位置> | <原文> | <替换文本> | <错字/病句/画面不清/原创风险等> |

## 五、人工核验项

| ID | 待核验事实 | 需要的证据或确认 | 未确认的影响 |
|---|---|---|---|
| M-01 | <授权/年龄/来源/监护人同意等> | <具体材料> | <为何不能直接判通过> |

## 六、复审清单

- [ ] 所有 A 项已删除、替换或重构
- [ ] 所有 B 项已按画面、声音和文字三个层面整改
- [ ] 未成年人年龄、权益与监护事项已确认
- [ ] 时政/真实事件的时间、地点、来源已补齐
- [ ] 版权、肖像、商标和音乐授权已确认
- [ ] 修改未造成剧情因果断裂或新的违规暗示

## 七、复审结论

<说明当前能否进入即梦分镜制作；若不能，明确下一次复审所需版本或证据。>
```

## 填写规则

- A/B 问题使用 `R-01` 起连续编号；C 问题使用 `Q-01`；人工核验使用 `M-01`。
- 原文引用必须短而准确，不能改写后冒充原文。
- `位置` 优先使用原文件稳定行号；否则使用集、场、段落、角色台词等可复查锚点。
- 同一个问题若同时命中多条，只在“命中要求”中并列最相关规则，不重复生成多条。
- A/B 项的首选改写必须能直接落回剧本，不可只写“删除敏感内容”“弱化处理”。
- 对会损失爽感、反转或悬念的修改，必须提供至少一个等价戏剧功能替代；最多两个，避免无边界改写。
- 只有用户要求完整修订稿时，才在报告后输出或另存完整剧本。

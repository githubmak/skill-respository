# 合规改写模式

仅在发现问题并需要重写时读取。优先保留原有人物目标、因果顺序、信息揭示和情绪结果，只替换违规的冲突载体。

## 暴力与复仇

- 私刑复仇 -> 证据公开、合同反制、董事会表决、司法外的普通合法程序、利益联盟瓦解、声誉与资格损失。
- 扇耳光/重击 -> 被制止的抬手、拍桌、撕毁文件、撤回资源、当众出示证据、关系决裂。
- 直接伤害 -> 事前阻止 + 画外结果 + 安全后果；不要保留撞击音、血迹或痛苦特写形成等价展示。
- 极端反派 -> 具体利益冲突、误判、制度压力、错误信息或有限自利，避免纯粹残暴与全员降智。

## 未成年人

- 受伤/拐卖卖点 -> 走失警报、成年人及时阻止、误会澄清、监护流程、信息失联但人身安全可确认。
- 吐血/血迹 -> 脸色苍白、体力不支、及时休息或就医提示；不写可视血液。
- 危险模仿 -> 取消操作步骤，改为成年人制止、风险教育和明确安全结果。
- 若核心情节必须由成年人承担，可在不破坏人物关系时将角色明确调整为成年，并同步学校、监护、职业等设定；不能仅改年龄数字却保留未成年语境。

## 性暗示与身体接触

- 娇喘/暧昧音效 -> 急促但清晰的呼吸、环境声、物件声；避免镜头凝视身体部位。
- 撞击/摩擦 -> 错身避让、隔物阻挡、画面外停止、物件落地、人物各自站稳。
- 婚姻/身体交易 -> 能力、合同、资源、声誉或共同目标的谈判，不让角色价值依附于身体和婚姻。
- 偷窥/两性悬疑 -> 权限滥用、数据泄露、商业窃密、身份伪造或证据篡改。

## 迷信与玄学

- 现实有效的邪术教程 -> 明确虚构世界规则，删除现实可模仿步骤、口诀、材料配比和功效承诺。
- 仪式正面展示 -> 道具不完整的象征镜头 + 角色反应 + 后果镜；不连续展示操作链。
- 迷信解决现实问题 -> 调查、医学、心理、自然或技术解释；玄学只作为人物误解或世界观符号。

## 身份与机构

- 军警身份 -> 普通安保、物业、企业风控、民间救援、社区工作人员等非军警身份；同时替换制服、称谓、场所、徽章、设备和职业动作。
- 官方媒体/机构冒用 -> 虚构组织名与清晰虚构标识；不要使用易与真实机关、媒体或即梦官方混淆的名称。
- 历史人物屈辱动作 -> 平等礼仪、主动致意、拱手、退让或沉默承诺，避免下跪。

## 冲突与爽感

- 小事引爆全员极端 -> 增加长期利益矛盾、旧承诺、证据误差或关键资源竞争，让触发点成为最后一根稻草。
- 单纯羞辱打脸 -> 信息差翻转、规则反制、专业能力证明、公开证据、对方自证矛盾。
- 极端亲友 -> 给出可理解但错误的目标和边界，让其因选择承担后果，而非不断升级恶行。
- 群体丑化 -> 将问题落到具体角色的具体行为，补充同群体中的正向或中性人物，删除群体标签化台词。

## 操作检查

每次改写后确认：

1. 原人物目标和本场戏剧功能是否仍在。
2. 是否同时清理了对白、动作、音效、镜头、服装、道具和后续回声。
3. 是否引入新身份、新授权、未成年或真实事件风险。
4. 反派行为是否有因果，主角手段是否合法且价值导向清晰。
5. 画面仍然可演、可拆镜，并能自然衔接下一场。
